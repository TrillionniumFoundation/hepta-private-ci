# Original notebook code cells

This inactive directory preserves exact UTF-8 source strings from original HCSN/RR-SNN notebook code cells. It omits notebook outputs, images, execution history and four comment-only cells. The original notebook bytes remain preserved in the source collection. Each object records the original parent Git blob, SHA-256, size, cell index and JSON pointer. No code was run, imported, trained or benchmarked.

These additional source objects are outside the frozen 6116-candidate union. They add zero to the formal 5887 verified count. Preserving child cells does not verify the complete original notebook, the original archive, dot files or worktree history. Current archival context is not unique historical ownership, and historical assertions in code are not current scientific or native qualification.

The newly authored verify_sources.py checks only bytes. Optionally pass --original-notebooks DIRECTORY containing the exact SHA-named original notebooks to verify JSON extraction. It rejects optimized Python and never executes cells. DRAFT / SHADOW_ONLY / DENY_ALL / HOLD_NO_GO remain; no original was deleted.
