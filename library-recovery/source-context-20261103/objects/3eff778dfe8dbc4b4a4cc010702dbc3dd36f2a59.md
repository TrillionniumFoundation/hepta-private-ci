# HCSN P3 four-modal source admission (research-only)

**Status: DRAFT / DENY_ALL.** This isolated directory is an executable, fail-closed **data-source preflight**, not a four-modal encoder, training run, certified annotation audit, or successful P3/P4/P5 scientific gate. `real_four_modal_quality_established=false` and `production_activation_allowed=false` remain hardcoded in every successful receipt.

## Problem and scope

The existing HCSN work includes audiovisual experiments, but does not yet establish independently versioned text, image, audio **and** video on actually paired source events with no train/validation/test leakage. This gate requires four different declared encoder IDs/revision SHA-256 digests, checks all four source assets' SHA-256 bytes, verifies nonempty UTF-8 text, full PNG/JPEG/WebP image pixel decode, complete PCM WAV frame read, and video stream + an actual **first decoded video frame** through FFmpeg. It also checks consistent event/entity IDs and overlapping timestamp windows, and rejects split reuse of actor/session/event/source/path/modality-content hashes.

The validator reads existing asset files; it does not call any model or change the training corpus. The manifest is declarative, so its declared event, entity, actor, label, timestamp, and encoder revision metadata **must still be independently audited** against raw source and actual encoder checkpoints. It cannot detect consistent false labels, prove video content beyond the first decoded frame, establish optimal HCSN fusion or protect against a concurrently malicious file-mutating process. Byte-equal repeated captions in different splits are rejected conservatively and can produce false positives; no silent bypass is provided.

## Manifest format and invocation

A strict JSON object has exactly `schema_version`, `max_skew_ms`, `encoders`, `samples`. The schema version is `hcsn-fourmodal-source-v1`, and `max_skew_ms` is an integer in `[0,1000]`. `encoders` has exactly `text`, `image`, `audio`, `video`; each has `{ "encoder_id": "distinct-name", "revision_sha256": "64-lowercase-hex" }`. Each sample requires `sample_id`, `split` (`train`, `val`, or `test`), `actor_id`, `session_id`, `event_id`, `entity_id`, `label`, and `modalities`.

Each of the four `modalities` records has exactly `path` (POSIX-relative, under asset root, not a symlink), `sha256` (actual file digest), `source_id`, `event_id`, `entity_id`, `start_ms`, `end_ms` (nonnegative integer timestamps; same time axis). The modality event/entity must match the sample, and the four time windows must intersect within the declared tolerance. Nonstandard `NaN`/`Infinity`, duplicate JSON keys, unspecified extra keys, missing splits and missing files are all refused. All assets must be available under the declared trusted local root.

Requires Python 3.11+, Pillow, and accessible `ffprobe`/`ffmpeg` binaries; if a decoder is unavailable, the preflight refuses instead of silently accepting. This v1 preflight accepts PCM WAV for audio, PNG/JPEG/WebP for image, and video files supported by the installed FFmpeg. Decoder first-frame verification is not a complete-video integrity proof.

From the repository root:

```bash
python -m unittest -v experiments.hcsn_fourmodal_admission_v1.test_manifest_gate
python -m experiments.hcsn_fourmodal_admission_v1.manifest_gate \
  /path/to/frozen_manifest.json /path/to/immutable_assets
```

Exit code `0` means only the stated structural preflight succeeded; invalid input exits `2` and outputs `{"status":"DENY",...}`. The output SHA-256 receipt hashes a canonical serialization of the supplied manifest; freeze that hash **before** inspecting scientific outcomes.
