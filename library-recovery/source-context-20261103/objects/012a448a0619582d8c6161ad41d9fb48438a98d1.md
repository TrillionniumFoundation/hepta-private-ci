# HCSN P0–P5 独立研究验证工具包（2026-10-31 UTC）

**重要：这是本地可复现实验/拒绝式门禁工具，既不是原仓库的已合并提交，也不是 HCSN 产品验收。** 生成时连接的 GitHub 账户返回 `403: Sorry. Your account was suspended`，没有读取到当时最新 `main` 或当前 PR 的 HEAD，也没有对任何远端分支执行写入。本地没有 Rust/GPU 开发栈与真实 HCSN 训练配置；所有产品级门禁维持 `OPEN / DENY_ALL`。

## 开始使用

```bash
python -m pip install -r requirements.txt
PYTHONPATH=. python -m unittest discover -s tests -v
python run_audit.py
```

生成 `reports/unit_tests.log`、`reports/local_audit.json`、`reports/evidence_template.json`。实验报告时间属于**本地执行时间**，不是远端 PR 的更新时间。项目未使用依赖任何真实训练模型、私有数据集或 GPU；没有伪造此类结果。

## P0 实测数值（局部研究，不是原始完整 HX）

- 历史冻结反例的参数：`x=log(1.000000000000002)`、`σ=1.8581469732429565`、`drift=0.007595780582070804-3.5072936797757205e-7-σ²/2`、`T=2.2216211523554883e-8`、`q=0.007595780582070804`。
- 独立高精度结果：`F-G ≈ 9.715164183943247e-22 > 0`，但 **双精度浮点二者均存为 `0.9999999999942438`，差值仅约 `8.75e-6 ULP`**，无法将该差值直接当成可靠浮点证据。当前诊断输出 `DENY_F64_UNRESOLVED_GAP`，不允许 silent clipping。
- 240 个固定随机种子的有限参数样本中：240 个参考公式在 110 位精度下通过物理顺序检查；按保守的 32 ULP 差值准则，72 个标记为 `DENY_F64_UNRESOLVED_GAP`，168 个仅作 `REFERENCE_CHECK_ONLY`。**这既不是全参数域证明，也不是 72 个真实 HCSN 故障。** 未认证实数舍入界、低精度误差与耦合边界，不能把前者当作正式准入。
- 有限状态再生 toy QVI 的价值迭代与枚举策略最大值差约 `8.17e-14`，Bellman 残差约 `1e-14`，至少有一个重置策略激活、至少有一个继续策略激活。它只检查数值求解代码的一个简化反例，不是 HX 论文中的 rollover QVI。

## 原论文模型与研究变体的界限

He–Xiong, *Rollover Risk and Credit Risk*, *Journal of Finance* 67(2), 391–430, DOI `10.1111/j.1540-6261.2012.01721.x` 的原模型包含债券估值、equity ODE 与内生违约边界，并非神经脉冲网络。在原模型中违约导致终止，而周期性 reset/再生需要独立建立新的模型和 QVI。我们的 FPT / QVI toy 是特意收缩的可复现验证，不可以据此宣称重现附录 A7 或证明网络最优。

## 集成指导与证据边界

1. 重新获取 `hepta-private-ci` 最新 `main`、HX 研究 PR、完整原始源文件及精确 blob SHA；本包无法核验当前远端状态。此前用户保存的台账只曾记录 `main 732e934...`、PR #4455 HEAD `8a216c3d...`，这些是**历史观察而非最新值**。
2. 在新建研究分支上逐项比对 `fpt_reference` 与原 `experiments/hcsn_hx_unified_v3/hx.py`，先在真实已完成测试的源码基础上做限定性接入，不要用本包覆盖原工程。重新核验 `q` 的定义、`a` 的定义和全量 He–Xiong 方程，特别是相依的债券/股权参数。
3. 以真实训练生成 P1 八臂结果，而不是把 `tests/test_experiment_protocols.py` 里的 synthetic fixture 充当证据。P2 训练时冻结 generator、train/validation/holdout、长度、种子、评估预算、外部强基线。
4. P3 实际读取真实成对媒体、验证 hash 与持有权；P4 用确定的 Rust/GPU kernel 和经过校准的能耗计量跑实体硬件，并执行故障注入与恢复；P5 须把训练、推理、准备、验证、切换、清理成本一起核算。
5. 各门必须经独立审查和逐条原始日志确认，直到真正齐全才考虑解除拒绝式准入。`gate_contract.py` 故意无法给出 production PASS，只给出尚缺证据数，不允许靠伪造 JSON 解锁。

## 文件列表

- `fpt_reference.py`、`stress_envelope.py`：高精度首达参考与保守数值解析度扫描。
- `qvi_toy.py`：再生 QVI 的独立离散小模型对照。
- `event_memory_tasks.py`：连续时间戳事件任务、答案核验及 hash。
- `fair_ablation.py`：八臂同信息/同预算对照的数据一致性检查。
- `multimodal_gate.py`、`native_gate.py`：P3/P4 输入/测量元数据完整性与泄漏拒绝。
- `gate_contract.py`：P0–P5 缺项台账，强制生产拒绝。
- `tests/`：22 项本地单元测试。
- `reports/local_audit.json`：本轮有限的数值结果、24 任务配置、六阶段缺项。
- `reports/unit_tests.log`：实际测试 stdout/stderr。
- `reports/evidence_template.json`：后续实际实证填报空模板。

依赖仅 `numpy` 和 `mpmath`（`scipy` 仅用于报告版本识别）；Python 3.10+。所有哈希仅证明本包生成的同一输入决定同一输出，不等同于源数据的真实性。
