# P0 有理数首达区间证书：证明范围与可重放算法

**研究范围：** 固定吸收边界、恒定漂移与波动率的标量布朗过程
`dX_t = μ dt + σ dW_t`、`X_0 = x > 0`，`τ = inf{t: X_t ≤ 0}`；有限期限 `T>0`，折现 `q>0`。这**不是** He–Xiong 原论文的债权—股权耦合估值、全局内生违约自由边界或神经网络动力学。当前模型使用**字符串表示的精确十进制有理参数**，不是输入二进制浮点的真实物理误差。

## 核心恒等式

定义 `a=μ/σ²`、`λ=sqrt(a²+2q/σ²)`、`u=σ sqrt(T)`，标准正态累积分布函数 `Φ`。则

- `F = Φ((-x−μT)/u) + exp(−2ax) Φ((-x+μT)/u)`；
- `G = exp((−a+λ)x) Φ((-x−λσ²T)/u) + exp((−a−λ)x) Φ((-x+λσ²T)/u)`；
- `F−G = E[(1−exp(−q τ)) 1{τ≤T}] ≥ 0`。

代码实际对 `F`、`G` 分别构造区间并做区间相减；只有 `lower(F−G)>0`、物理范围检查通过才给出 `CERTIFIED_POSITIVE_F_MINUS_G`，绝不采用 `max(0,F−G)` 遮盖逆序。

## 区间端点为什么是有界的

1. **π：** 精确 Machin 恒等式 `π=16 atan(1/5)−4 atan(1/239)`。`atan(z)=sum[(-1)^n z^(2n+1)/(2n+1)]` 对 `0<z<1` 交错递减；余项绝对值 ≤ 首个遗漏项。所有有限和与端点均使用 Python `Fraction`。
2. **平方根：** 对非负有理数 `a=n/d`，取 `S=10^k`、`u=isqrt(floor(n S² / d))`，则 `u/S ≤ sqrt(a) ≤ (u+1)/S`。整数运算精确，完全平方数时上下界相同。
3. **指数：** 先将有理数绝对值二分缩放至 `≤1/2`。泰勒多项式之后的余项 ≤ `2 |y|^(N+1)/(N+1)!`；依据 `exp(1/2)<2`。负参数由正参数包围区间倒数得到。重复平方与每次十进制外向量化均使用有理数区间运算。
4. **标准正态：** 对 `z≥0`，`Φ(z)=1/2+1/sqrt(2π) × sum[(-1)^n z^(2n+1)/(2^n n!(2n+1))]`。当 `n>z²/2` 后项绝对值单调递减，因此交错级数余项在首项遗漏项之内。负 `z` 使用精确对称关系 `Φ(-z)=1−Φ(z)`。间隔输入通过 `Φ` 单调性以端点包围。
5. **导数：** `∂F/∂x` 按解析导数计算，正态密度以相同有理数指数和 `sqrt(2π)` 区间包围。在 `x=0` 使用**右侧导数**；`x≤0` 常数 1 的左侧延拓一般不光滑，因此没有错误地声称风险通道满足零梯度 smooth pasting。
6. **QVI：** 对单独定义的有理数有限状态折现重置 MDP，枚举全部 `2^n` 确定性策略，精确高斯消元解 `(I−βP_policy)V=r_policy`，求每个状态的最优值并用精确有理数验证 Bellman 最大方程与最佳确定策略。仅证实这个 *toy MDP*，绝非连续 HX 自由边界 QVI。

## 保守拒绝

- 输入必须是有限十进制**字符串**，参数必须严格属于特定紧致研究域：`0<x≤8`、`0.01≤σ≤4`、`|μ|≤4`、`0<T≤10`、`0<q≤4`；变换出的正态变量绝对值必须 `≤8`，指数实参数绝对值 `≤40`。区间/级数收敛超出预算时抛错，不以裁剪代替。
- 不接受实际模型实现的 FP32、BF16、GPU 的舍入证书；不接受参数域全覆盖、自由边界偏微分误差、神经模型训练质量或生产性能声明。
- 此处的“certified”是**假定公式正确、Python 任意精度整数运算正确且区间代码正确时**，经解析级数余项严格约束的实例值包围。没有进行外部形式化证明系统认证。
