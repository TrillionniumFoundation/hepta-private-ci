# HCSN P0/P2 独立再生 QVI 与确定不应期参考

**日期**：2026-10-31。**交付性质**：`RESEARCH_ONLY`, `DENY_ALL`; add-only offline overlay，未通过整仓测试/未取得生产权限；不能把简化神经 QVI 视为 He–Xiong 完整债权—股权内生均衡。

## P0：有全局 QVI 数学证明的标量子问题

状态：`dX = mu dt + sigma dW`，`rho>0`、`sigma>0`、固定重置位置 `r<K`，发放即时收益为 `x-K`；经过**确定**的 `tau>=0` 之后从 `r` 再生。

- `L f = mu f' + sigma² f''/2`；`M J(x) = x-K + exp(-rho*tau) J(r)`；`max{LJ-rho*J, MJ-J}=0`。
- 正根 `k=(sqrt(mu²+2*rho*sigma²)-mu)/sigma²`（代码采用防抵消的等价式）。
- `log q0 = -rho*tau - k*(K-r)`、`psi(z)=z+expm1(logq0-z)`。唯一 `z∈(0,1)`；`b=K+z/k`, `q=exp(logq0-z)=1-z`。
- `J(x)=exp(k*(x-b))/k`（`x<b`），`J(x)=x-K+q/k`（`x>=b`）。
- 解析域中：继续区 `J-MJ=(exp(y)-1-y)/k>=0`，其中 `y=k*(x-b)<0`；停止区 `(L-rho)J <= -sigma²*k/2 < 0`；边界满足 value matching 与 smooth pasting。因此**仅这个子问题**有全局 QVI 校验。
- 实现了六个参数方向（drift/sigma/discount/cost/reset/refractory）的隐式边界梯度；和独立 Lambert-W 表达式、中心有限差分及完全分离的稀疏有限网格 Howard 策略迭代比对。
- 浮点中遇到未解决的根分支、超大/超小指数、非有限参数和非单调网格生成元时直接拒绝，避免把失效误报为成功。二进制浮点检验不是有向舍入区间证明。

**不可推断的结论**：这不是原论文耦合的 `HX Eq.(8)/(12)/(A7)` 完整模型；不能由标量 QVI 证明多神经元耦合固定点、多模态内容质量或移动自由边界的全局收敛。

## P2：确定不应期与重复发放

在一段恒定速率 `lambda>0` 下，ACTIVE 等待 `Exp(lambda)` 首发；每次事件后进入恰好 `tau>=0` 的 REFRACTORY，不应期后重新 ACTIVE。令 `N_T` 为 `[0,T]` 内发放次数：

`Pr(N_T>=n) = P(Gamma(n,lambda) <= T-(n-1)*tau)`，当 `T>(n-1)*tau` 时成立，否则为 0。期望事件次数是 `E[N_T]=sum_{n>=1}Pr(N_T>=n)`，而首次发放概率始终为 `1-exp(-lambda*T)`。零不应期精确退化为 Poisson 事件计数。

- 新 `constant_rate_stats` 输出首次发放概率、期望次数、>=2 次与 >=3 次概率；有限 `tau` 有最多 `ceil(T/tau)` 个非零尾项；大于数值预算则拒绝。
- 另有 `PathState`（版本、物理时钟、确定不应期剩余量、未消耗的指数 hazard、事件计数、SHA-256 counter-seed 伪随机流）与 `advance_path`，允许速率分段改变、无需偷看未来。哈希只用于**确定性随机性**，不证明 checkpoint 真实性或权限。
- 做独立采样（每种参数 20,000 路径 × 3 组合）、400 个分段与单步组合一致性案例、跨 Python 进程状态恢复，以及过量事件/格式/初始 checkpoint 拒绝测试。

**不可推断的结论**：没有构建真实 HX 首达过程、全网 CTMC/Erlang、多模态任务或真实 Rust 原生 runtime；分段浮点事件时间临界情况没有全域有向舍入保证。平均事件计数不能当作低能耗证据。
