# Hepta Neuron: isolated experiment scaffold

Research harness, **not** a Hepta production implementation. Synthetic results do not establish learning, calibration, causal NDU gains, multicell production performance, fault recovery, or Laya equivalence.

## Run

```bash
python experiment.py head --output head.json
python experiment.py stress --output stress.json
python experiment.py gate --output gate.json
```

Experiment 01: fixed synthetic teacher/data/steps and per-kind budgets, measures accuracy, Brier, ECE, shifted-distribution accuracy and CPU timing. It reports over-budget configurations rather than falsely describing matched sizes. `old_before_accuracy`/`old_after_accuracy` are a smoke proxy, **not** future-task retention. The "OOD" shifted inputs are a controlled distribution shift, not a calibrated OOD detector metric.

Experiment 02: gated until the real Laya and alternative encoder weights, tokenizer, joint question/options/state input format, per-task datasets, exact train/val/future splits, trained artifacts and independent evaluation are available. No real shared-computation claim from this scaffold. `gate` always blocks production promotion; a nonempty receipt string isn't verified evidence.

Experiment 03: grid of 64/256/1024/4096 Cells; 10%, 50%, 100% active; same/partial/distinct feature reuse. CPU-only Python toy Head latency and cache hit counting, **not** a valid production load test. Expand with real backends and metrics sinks, native Batch, peak GPU, p95/p99, WAL/checkpoint durability, restart, cache invalidation and worker-generation fencing.

## Required actual evidence to graduate

- Frozen no-change baseline and source/driver/hardware/encoder/artifact hashes.
- Identical input/task/split and optimizer budgets for Head variants; disjoint grouped episodes and future windows.
- Independently measured Brier/ECE/OOD/negative transfer and causal NDU benefit.
- Cross-token joint-question/options/state vs cached-state representation ablation.
- Real semantic Encoder forward pass, cache authorization/freshness/generation validation and real backend batches.
- Recovery, fault injection, signed artifact publication, CAS state migration and CNS cutover receipts.
- Pass only via independent evaluator/selector/executor under existing Hepta authority gates; no automatic promotion.
