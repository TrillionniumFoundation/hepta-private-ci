## 快速复现

在具有 Python 3.10+、`ffmpeg`/`ffprobe` 与 CPU PyTorch 的环境中运行：

```sh
cd hcsn_p0_p5_research_v3
python -m pip install -r requirements.txt
PYTHONPATH=. python -m unittest discover -s tests -v
python precision_limits.py
python cpu_kernel_replay.py
python toy_four_modality_run.py --steps 450
python recurrent_factorial_pilot.py --task overwrite_reset --steps 160 --seeds 13 29 43
python recurrent_factorial_pilot.py --task irregular_time --steps 160 --seeds 13 29 43
python recurrent_factorial_pilot.py --task mqar --steps 120 --seeds 13 29
python recurrent_factorial_pilot.py --task long_range --steps 120 --seeds 13 29
python run_v3_audit.py
```

以上 Python 审计会创建数值与元数据报告，但**不会将任何实验升级为生产 PASS**。本包已有生成完成的 40 个合成配对媒体样本及对应收据。如需重新生成，先删除 `reports/toy_media_corpus`，再运行 `toy_four_modality_run.py`。CPU/GPU 性能与实际能源数据不可由固定合成收据替代。

Rust 草稿仅可在实际安装 Rust 工具链后自行运行：

```sh
cd rust_cpu_research
cargo test
cargo run --release --bin hcsn_cpu_bench
```

此 sandbox **未安装 rustc/cargo，不曾编译或运行 Rust 代码**，不能把该 crate 当作通过的原生计算核。

## 实测摘要（不要外推到 HCSN 产品）

- **82/82** 本地 Python 单元测试实际通过，见 `reports/v3_tests.log`。新测试包括跨 split 重复、路径穿透／软链接、数学正反例、再生 QVI 先前对照、真实子进程异常退出的简化 crash/recovery 和 P5 负迁移拒绝。
- **P0** 的 200/400/800 节点独立有限差分，在精确有限右端 Dirichlet 值情况下与简化方程解析解最大误差约为 **0.0010093 / 0.00025485 / 0.00006387**；不是金融模型真实自由边界的数值解。首达时间分片的近似上下界随着 16/32/64 块收敛，**不具备认证的浮点区间性质**。
- **P0** 极端 frozen 首达反例 `F−G≈9.715e−22` 在高精度下严格为正，但转存为 binary64/FP32/BF16 的标量 F/G 均失去该正差。仅检查转存，不是实际原生 FP32/BF16 测试。
- **P1/P2** 共 80 个训练单元：覆盖写入（3 seeds）两侧饱和，普通 / 全机制 **1.0000 / 1.0000**；不规则时间（3 seeds）约 **0.9913 / 0.9878**；MQAR（2 seeds）约 **0.7057 / 0.7031**；长程（2 seeds）约 **0.4844 / 0.4844**。此样本规模极小且差异不支持 HCSN 增益。Call/Risk/Margin 组合训练时间通常更多；其全特征计算预算**未匹配**。
- **P3** 40 个媒体样本，holdout 12 个。程序生成颜色文本、图像、频率音频和同色视频，特征简单易识别；holdout 四模态分类与所有 12 个跨模态**同类** top1 检索都是 **1.0**，**不代表真实跨模态性能**。对持出集特征添加高斯扰动后的 image/video 类准确率下降到约 0.917/0.833，非原始字节受扰动的真实 OOD 测试。
- **P4** NumPy CPU 96 事件小测中四档 Cell p99 约为 **0.051 / 0.058 / 0.090 / 0.260 ms**（仅本 sandbox 的 toy 向量算子，无控制平面、网络、批处理验证、GPU、能耗或 4096 物理生产 Cell）。该数字不能同生产性能指标并列。
- **P5** 未启动任何真实扩模；研究门禁输出 **DENY**。注入完整但不可信的自报获胜元数据时也仅给 **REVIEW_REQUIRED**，永远不会自动打开生产权限。

## 原论文与新模型严格分开

He & Xiong (2012), **Rollover Risk and Credit Risk**, *Journal of Finance*, 67(2):391–430，DOI: [10.1111/j.1540-6261.2012.01721.x](https://doi.org/10.1111/j.1540-6261.2012.01721.x)，原模型讨论债券/股权互动、债务期限与内生违约边界。单独首达概率、常成本简化最优停止和有限状态再生 MDP 都是重新定义的研究问题。不能把这些小模型的数值收敛认作完整金融 HX 系统、自由边界自洽最优性或神经动力学闭式解。

**安全边界补充：** 本地 checkpoint 的裸 SHA-256 无密钥，不能阻挡能重新计算摘要的恶意更改；不是生产 AuthBus、签名回执、代际 fencing 或可信恢复的替代。
