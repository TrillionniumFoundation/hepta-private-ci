# Hepta CellSplit — local next-step patch

## Scope and source identity

This is a **local patch package**, not a change to the live Hepta repository or a run on the user's target host. The original `scripts/hepta_cell_split_matrix_capture.py` was reconstructed byte-for-byte from the connected repository source: Git blob `2808276286f95dd4d15f4e1deba8afa9ab279f83`, inspected at source commit `f11fec0d52fc9529eb2bffbf4f968a461e20ccea`. The same file blob was reverified at the later branch head `031fe0f79642a4606fbd56f147102370c39d4d5a`; the branch is actively changing, so the **blob hash**, not a moving branch name, is the patch precondition.

The patch improves *diagnostic* evidence integrity for the existing 16-arm (4 Cell counts × 4 split modes) capture; it does not construct, sign or authorize a production operation receipt.

## Changes

1. Refuse an already existing result file *before* each subprocess invocation, including dangling symlinks. Earlier runs can no longer pre-seed later cases and have them accepted as fresh.
2. Reject symlink, hardlink, device, nonregular, replaced, changing or overlarge evidence files. Read and hash the same bounded byte stream used by JSON validation.
3. Preserve per-case `measurement_source`, raw JSON SHA-256, stdout/stderr SHA-256, command argument SHA-256, and full manifest SHA-256 for the independent Observer.
4. Create the run directory privately (`0700` on Unix) and write manifest/diagnostic artifacts create-only with file and directory `fsync`; a partial crash leaves a non-reusable diagnostic directory.
5. Continue to report `production_activation_authorized = false`. The hashes are **not** an independent host signature or real resource measurements.

## Apply safely

Use a **clean checkout or separate Git worktree** with the original capture script still at the indicated Git blob. Never apply this patch over someone else's uncommitted changes. From the repository root:

```bash
git hash-object scripts/hepta_cell_split_matrix_capture.py
# Must equal 2808276286f95dd4d15f4e1deba8afa9ab279f83
git apply --check hepta_cell_split_capture_integrity.patch
git apply hepta_cell_split_capture_integrity.patch
python3 -m unittest discover -s tests -p 'test_hepta_cell_split_*.py' -v
```

The new files reside in `scripts/hepta_cell_split_capture_integrity.py`, `tests/test_hepta_cell_split_capture_integrity.py`, and `tests/test_hepta_cell_split_matrix_integration.py`. Commit the patch before any real run; the original matrix script intentionally refuses dirty source checkouts and a manifest must pin the **new exact commit SHA**.

## Local evidence

The patch was applied with `git apply --check` to a clean local verification checkout seeded with the exact original Git blob. 10/10 Python tests passed, including all 16 subprocess cases *using explicit test-only synthetic measurements* and a hostile previous-run preseed attempt. This is proof of the capture control's behavior only, not any Hepta learning, throughput, target-host performance, rustc/cargo, CNS cutover or physical split. The local execution container does not have the Hepta workspace or Rust toolchain mounted.
