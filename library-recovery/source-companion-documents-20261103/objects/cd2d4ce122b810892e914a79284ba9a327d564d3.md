## Executable reproducible gate

`cost_parity_gate.py` generates all four raw decoded synthetic outputs for
both training methods and both inference methods on the same test source group,
re-scores each with the separately maintained `independent_observer.observe`,
then validates exactly one source × arm row, common input digest, source truth,
complete roster, admissible action, *executed* modeled cost and observed decoded
loss. It reports paired static-minus-dynamic loss and dynamic-minus-static
executed cost **per seed and training**, without treating four outputs as four
independent sampling units.

`test_cost_parity_gate.py` rejects forged scores, costs, action names, incomplete
or repeated source/arm rows, cross-arm input changes, malformed media shapes,
unknown train split, invalid numeric thresholds and unsupported census. An
integration test exercises the real v5 `factorial` and `independent_observer`
imports; the frozen report test preserves the seed-29 negative result and zero
modality refinements. Tests use stdlib only.

Use from the `v5` directory:

```bash
python3 -m unittest discover -p 'test_*.py' -v
python3 -m compileall -q cost_parity_gate.py test_cost_parity_gate.py
python3 cost_parity_gate.py > /tmp/hepta-v5-paired-cost-audit.json
```

The full run replays the **already used development** seed set (17,29,43), 768
train + 256 dev + 512 test per seed. The output is a diagnostic, *not* a new
prospective or physically attested confirmation experiment. The frozen v5
independent observer already has its own source/audit locks, and this additive
gate cannot substitute a second external institution, a hardware meter, or new
natural source acquisition.

The bounded-loss Hoeffding LCB is a deliberately conservative diagnostic with
Bonferroni for six within-seed/training comparisons. Synthetic source worlds
are the declared sampling units. It does not make a statistical claim about
natural human task distributions or cross-seed scientific replication.
