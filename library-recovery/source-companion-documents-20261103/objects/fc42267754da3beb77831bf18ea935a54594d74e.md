# Pinned three-arm repeated CPU diagnostic (not production evidence)

The earlier [single-forward run 38095795540](https://github.com/TrillionniumFoundation/hepta-private-ci/actions/runs/38095795540)
physically loaded and executed all three fixed Laya checkpoints. That run had
one synthetic invocation per arm, so neither its p99 nor a throughput speedup
claim is meaningful.

`hepta-neuron-matched-cpu.yml` runs only after the existing PR's
`hepta-neuron-physical-smoke` label is **explicitly added**. It downloads the
three already pinned *public* weight variants to a disposable runner, checks
exact revision/SDK/weight bytes, and executes each model in a fresh CPU Python
process. It uses one identical synthetic no-label English choice question,
forces the same 512 input / 192 head token caps, CPU thread limit 2, 5 warmups,
and 100 serial measured calls per model.

The collected JSON per arm includes exact model + SDK + weights identities,
model-load time, raw 100 latencies, nearest-rank p50/p95/p99, serial-only
invocations/sec, process RSS before/after model load and after forwards, and
actual token usage. Linux `/proc/self/status` supplies `VmRSS` and `VmHWM`.
Only JSON metadata is retained; never publish weights, HF cache, user records,
secrets, authorization tokens, or unredacted model input.

Limits: **not** backend batching, 4,096-Cell throughput, GPU profile,
independent host attestation, concurrency p99, real-domain accuracy, independent
future-window evaluation, NDU gain, or permission to alter any Cell. Cache state,
noise from shared-host scheduling and tokenizer differences remain possible.
Use a separate target-host 64/256/1024/4096-Cell benchmark for production costs.

Offline tests (do not download or use real model weights):

```sh
python3 -m unittest discover -v -s .github/scripts -p 'test_hepta_neuron_cpu_benchmark.py'
```

For a named host with independently materialized public weights and pinned SDK:

```sh
python3 scripts/hepta_neuron_cpu_benchmark.py \
  --catalog qualification/neuron-model-trials/upstream-weights.lock.json \
  --arm laya --artifact-dir /ABSOLUTE/pinned/laya \
  --sdk-python-sha256 YOUR_VERIFIED_SDK_TREE_SHA256 \
  --device cpu --threads 2 --warmup 5 --samples 100 \
  --output /ABSOLUTE/fresh/diagnostic.json
```

No evaluator, selector, final-use authority, NDU, or product route consumes this
schema; all such admission flags must remain false.
