# Hepta Cell Split P0 — independent offline transcript observer

Target source: `TrillionniumFoundation/hepta-private-ci`, draft PR #1468,
`codex-rs/hepta-operator-acceptance/src/cell_split_execution_owner.rs`.
Independent Python 3.10+ implementation of the four-effect signature/chain
verification protocol. The native Rust implementation remains authoritative.

## Run

Requires the `cryptography` Python package (tested with the pinned
`requirements.txt`). No model, network connection or private signing key is
required for verification.

```sh
python3 -m unittest discover -s . -p 'test_verify_transcript.py' -v
python3 verify_transcript.py \
  --transcript /secure/review/cell-split-transcript.json \
  --trust-pins /secure/review/cell-split-owner-trust-pins.json \
  --trust-pins-sha256 "$INDEPENDENTLY_PINNED_SHA256"
```

The trust-pins SHA-256 MUST originate from an independent authority, not be
recomputed as the trust value from the untrusted file during verification.
The trust file uses the existing native, immutable
`cell-split-owner-trust-pins.json` format; it binds the plan digest, the four
owner IDs and the four independently controlled Ed25519 public keys.

The accepted transcript is either the JSON object printed by the operator's
`cell-split-execution transcript` command or its nested `transcript` field.
Unknown fields, malformed/weak/reused public keys, identity/step/order drifts,
changed original effect bytes, fake digests, missing signatures, missing
receipts, duplicate JSON keys and substituted trust pins are rejected.

**A successful return only demonstrates offline cryptographic consistency.**
The tool does not connect to original Artifact CAS, child-state migration,
CNS, Supervisor, final-use/NDU/Selector or the target host. In particular, it
cannot prove that the external effects occurred or remain current: the four
original owners must supply fresh independent, nonce-bound live readbacks,
with their original durable receipts and identity/policy/frontier evidence.
An independent host/observer must also verify actual power-loss/restart,
longitudinal utility, and the frozen 16-combination benchmark. The output
hardcodes `productionActivationAuthorized=false` and
`physicalSplitAuthorized=false`; there is intentionally no override.

The tests sign **synthetic fixtures only** with hard-coded test keys. Never
carry those keys or receipts to production or represent a local test pass as
an actual Hepta target-host execution.
