# V12 — source-bound public Stem family identity for V5/V10 handoff

Research only. No independent publisher authentication, model efficacy, NDU
qualification or production admission follows from this mechanism test.

## Verified problem

V10 outputs publicly named candidates `mmbert-small` and `granite-97m-r2`.
V5's prior research fixtures used `mmbert_small` and `granite_97m`, and its
native Granite CLS/L2 precheck recognized **only** `granite_97m`. Reusing
V10's hyphenated candidate in V5 could therefore bypass a label-specific
feature-policy check even if the independently signed V6 operator identity
was valid. In addition, a user-chosen unrelated label could refer to the
same public Hub repository without adhering to its reviewed feature policy.

## Additive remediation

The V12 code binds **both legacy and public candidate labels** to an immutable
research catalog identity from V8: upstream model repository, model kind,
384-dimensional feature interface, pooling and normalization. If the trusted
V6 model policy mentions either public repository, no other candidate label
may impersonate that model. The V5 CLI checks wrong official Granite pooling
*before* opening untrusted external material, then calls the existing V6
Ed25519 admission and only after success verifies the entire public-native
profile against the **V6-verified** `upstream_repo` policy. Neither a filename,
user-supplied alias nor a digest alone grants authority.

Other independently reviewed model families remain possible under the existing
V6 admission contract. The mmBERT masked-mean profile remains a **research
baseline**, not a claim that masked-mean is the optimal mmBERT representation.

## Tests and limits

Offline regressions cover the V5 and V10 name spellings, wrong Granite CLS/L2,
wrong width and model kind, label ↔ upstream-repository substitution, original
V10 profile compatibility, and the invoked V5 nonfixture admission callback.
Mocked operator admission in tests is explicitly **not** an actual signature,
pretrained checkpoint or independent outcome observation.

Run locally:

```bash
PYTHONPATH=experiments/shared_stem_cell python -m unittest discover \
  -s experiments/shared_stem_cell -p test_multimodal_public_identity_v12.py -v
```

Hosted V12 CI fixes a CPU dependency environment and requires this suite to
run with **zero skips**, retaining the tested Git commit and file checksums.
This does not replace V10's physical two-model forward job, V11's exact stock
MLM weight-load job, a frozen no-change baseline or future-window evaluation.
All production paths remain **DENY_ALL / NO-GO**.
