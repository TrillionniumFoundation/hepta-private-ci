# Historical source byte archive — 2026-11-03

This Draft preserves 537 exact source objects (8,513,937 bytes) from 22 original research/development packages attributable to `TrillionniumFoundation/hepta-private-ci`. It adds only this isolated archival directory. The repository is public.

`SOURCE_MANIFEST.json` maps each stored object to its original package, member, nested archive chain, SHA-256, Git blob SHA and byte length. Source bytes, line endings and original copyright notices are unchanged. Necessary bundled third-party license text is retained separately; license objects do not enlarge the frozen source-candidate denominator.

The source projection is incomplete: other package contents, notebook outputs, binaries, experimental data, long logs and unresolved mixed review containers are excluded. Hash-named files preserve differing historical versions without replacing active project paths. This archive is not a runnable package reconstruction or an assertion that a historical patch applies to current main.

To check the saved bytes without running any recovered source, run `python3 verify_projection.py` from this directory. The verifier only reads and hashes files listed in the manifest.

No archived source was imported or executed during preservation. No production build, model experiment, benchmark, scientific gate, CI acceptance, deployment or release is claimed. Original DRAFT, RESEARCH_ONLY, SHADOW_ONLY, DENY_ALL and HOLD_NO_GO boundaries remain in force. The original source materials remain retained.
