# Original presentation resources

Makepad widgets/resources are copied unchanged from the pinned Git revision in
Cargo.lock. original-font-notices.json records their byte SHA256, sizes and
original embedded copyright/version/license notices. primary-sources.json pins
the retrieved full license texts; the older Liberation Mono 1.04 uses GPL2 with
the original font exception, rather than the newer Liberation OFL license.
New Computer Modern Math retains its embedded GUST notice and full GUST license.
The other fonts retain the corresponding OFL and embedded notices. Font Awesome
6.7.2 font and SVG terms are recorded separately in its upstream full license and
CC BY 4.0 text. Robrix and Makepad retain their MIT texts.

No font outlines, embedded notices or upstream resource bytes are modified.
The bundle includes these files beside the resources. Exact bundle file hashes
are generated after staging and retained with the normal executable proof.
