## Deliberate limits and release blockers

These are ordinary agent conversations, not a Matrix homeserver room client or
full Robrix feature parity. Latest/older timeline pages are bounded; room-list
pagination, attachments, docking and durable offline delivery remain absent.
All messages shown must be observed by the backend. Fixture conversations and
screenshots are test evidence, not deployed-account evidence.

Production still must instantiate and qualify the authenticated HTTP composition.
No deployment, credential creation, new permission, merge, acceptance or release
was performed. The existing ui.control.v1 session contract requires at least one
known runtime permission, so a genuinely zero-runtime-permission chat principal
needs an explicit session-contract extension. Native chat-only entry is a separate
host capability. Server requests for approval are visibly declined by these chat
surfaces rather than silently authorized.
