# A parameter field theory of LLMs 与 Hepta：五项正式 comments

审阅日期：2026-10-31。论文固定为 R45 `f8df0a6075f58f3ab9431a889b773cdf8d6e771d`；Hepta 依据科学 C2 `bc4e757f5c90f6365f383c1127be710d2ded874a` 的冻结设计与实现。**这是理论与已登记设计评审，当前没有本轮新增科学结论。**下述证据要求用于判读已登记结果；超出本轮设计的实验应另行预登记。

## 总体关系

R45 提供可执行的控制研究框架：分别核算遗漏动力学、隐藏信息、受限行动和估计误差。本轮 Hepta bridge 尝试把这套研究方法实例化。R45 已明确否认普适二维 Markov 充分性，并区分切线保证、非线性观测和受限预训练模块；评审应尊重这些边界。目前 bridge 的 ridge heads 并未求解 Riccati、HJB 或 FBSDE；神经元序列递推、训练时 optimizer 过程和随机控制的反向价值方程也需要分别定义。[R45 正文][paper]

论文完整词表缓存定理提供受限输出模块的精确计算等价；冻结骨干、不能改变组内概率比例等限制已有明文说明。其二次干预努力也不等于工程运行成本。这些局部命题可以指导接口设计，但不会自动成为 Hepta 的非线性误差预算。

## Comment 1：先确认 guard 后的有效行动与完整状态

**已知依据。**R45 从完整 optimizer 更新构造状态与系数，参数之外包括 momentum 或 AdamW 矩。Hepta A/B 为共同终点288、宏步48；C 为96、宏步16。四种倍率经 clipping、guard、rollback 后才形成真实转移，拒绝仍消耗时钟和已尝试工作。[协议][protocol] [更新与状态身份][branch]

**判断。**请求倍率不同不保证参数或动量后继不同；相同物理后继也不保证 controller history、累计成本和未来 history-policy 相同。应以实际受控 kernel 为理论连接点，不能把论文加性参数干预的系数直接移植给学习率倍率与回滚机制。同策略跨模型迁移与同动作空间的信息差各有前提，实现转移等式尚不能提供非线性全局保证。

**决定性证据。**按注册的分支比较与 replay，对齐 parent、optimizer、clock、后续 tape 和剩余预算，串联报告请求、接受、物理后继、输出及成本。用于重放的未来 tape 不因此成为策略输入。保留相等分支和无效 override。C 的逐决策分量范数/参数—优化器诊断未注册，应明确“未测”，不能由全状态哈希差异推断具体分量。[C 证据范围][cscope]

## Comment 2：认可 baseline advantage 的改进意义，核对误差与实际选择

**已知依据。**标签使用候选合法动作后接固定 baseline 至共同终点。对同一合法 kernel、初始律及有限时域加性期望回报，定义真实期望优势 $A_t^b=Q_t^b-V_t^b$，由 Bellman 望远镜求和得到

$$
J(\pi)-J(b)=\mathbb E_{\pi}\sum_t A_t^b(X_t,A_t),
$$

其中 $J$ 越大越好，期望取部署策略的状态分布。因此 baseline-tail 本身完全可以支持反复策略改进；此离散恒等式不自动推广到一般非线性递归效用。[R45 Bellman 证明背景][proof] [标签与控制协议][protocol]

**判断。**缺口在单条配对 tape 的 realized contrast 如何代表条件期望，以及误差如何覆盖部署分布。当前标签是终点 utility 差值，训练与观察 CPU 成本另计，不能解释为已内化全成本的净优势。A 每头12个校准状态存在路径依赖并跨 heads 复用；最大校准过预测阈值是经验筛选。R45 已区分未来路径覆盖与期望收益保证，Hepta 不能继承未经证明的覆盖率。[head 实现][heads]

**决定性证据。**原 supplement 已实现 advantage 与保存的 reward 均值的重新核对；还应联读实际 gated 选择的收益、regret、fallback 和 B 闭环效果，不能只报告 ungated argmax。有限输入和系数仍可能溢出成非有限分数；已准备的数值防护及其测试不等于冻结执行核已部署该防护。[数值防护审查][numeric] 按父状态或路径解释依赖，保留拟合、校准与评价的角色分离；可达收益为零时，误差/收益比应为未定义。更强期望保证需要另行预登记的未来 tape 重复或部署分布误差控制；当前应保留 `certificate=false`。[原 supplement][supplement]

## Comment 3：区分信息不足、解码不足与可达性

**已知依据。**R45 将全状态闭合与策略可达分布上的遗漏 forcing 分开，信息分解也使用被评估策略的 occupancy。Hepta 比较 field12、history114 与 full-current-state54740，均受同一四动作及冻结 ridge 过程约束。[R45][paper] [协议][protocol]

**判断。**完整状态 ridge 不是 oracle；即使它未胜过 field，也可能反映高维小样本拟合困难，不能证明 field 充分。应分别归因表示限制与估计误差；四倍率中的小信息差也不能证明更广更新方向没有价值。history 保留更多已观察信息，也支付 H12 观察成本。W 的三个预定动量反射对是构造的近场、off-policy 诊断，不能代替部署可达性证明。

**决定性证据。**联合报告 B 配对效应、实际选择 regret 与观察成本。W 应给出两侧完整最优动作集合及共同动作损失：排名不同但仍有共同最优动作时，并不存在被迫 regret。更强充分性结论需要可达状态上的决策误差控制；不应重新攻击 R45 已排除的普适二维主张。[五问解释映射][fieldmap]

## Comment 4：限定“独立任务”，把普通、轻量基线和净成本分开

**已知依据。**B 固定三份历史模型，新增16条 schedule、512个task与812个clean留出 source pairs；仍是同一 MNIST 图像/caption 任务，适应面板仍属已暴露开发数据。strong ordinary 是逐模型历史选出的常数动作；taper 固定为 `[b,b,2,1,1,0]`，不新增 probe 或拟合。[协议][protocol]

**判断。**该设计可提供同任务内的独立留出确认，尚未检验跨任务或新模型总体。taper 提供具体轻量对照，但不代表经等预算调优的最佳控制器；history 也不能当廉价基线。原 field 通过布尔值没有包含 taper 优越性或成本 Pareto 条件。[分析规则][analysis]

**决定性证据。**保留全部10个正式对比、两个 observer、逐固定模型效应及 retention，尤其正确解释“taper减field”的方向。并列核算离线标签/拟合、观察、部署、拒绝、评分和运行成本；局部 ledger 不能替代全成本，未知历史工作仍为未知。净收益遵循注册的质量—成本条件，不事后拟合交换率。跨任务、更多模型和更强轻量基线留给独立预登记研究。

## Comment 5：用两个简单效应解释架构交互，限制系统外推

**已知依据。**C 注册八个配对训练 seed、四个主臂、匹配初始化与固定 baseline2。每架构有540,328个可训练参数，其中12,064个为时序参数；只在文本 encoder/decoder 比较匹配的 sigmoid 与 FPT 事件律，原生成器其余模块保留，全部参数继续训练。[协议][protocol] [架构实现][architecture]

**判断。**交互为 $\Delta_{dual}-\Delta_{ordinary}$。例如两臂 field 增量分别为−0.01与−0.02，交互仍为+0.01；这是解释例子，不是实验结果。原 interaction+retention 判据不要求 dual 简单效应下界为正，必须保留原判据并单独说明收益方向。论文同动力学下的嵌套行动定理，也不自动保证换架构后的协同。此处常规基线没有逐架构调优，八个配对种子的近似区间也不能当作大模型总体保证。

**决定性证据。**完整呈现两简单效应、交互、dual-field减ordinary-field及四个own-warmstart retention，对照双方 observer、逐seed结果与成本。所得证据最多支持此约54万参数 PyTorch 处理。生产 Rust Hepta、完整 NDU、LLM迁移，以及原 FBSDE 的神经系数/鞅识别仍需各自验证；R45 已承认这些识别边界。本轮结果可据此决定后续系统扩展的价值。[R45][paper] [八对比分析][analysis]
