# HIA example-validation continuation — source contract

This Draft-only candidate migrates the positive/negative example-validation **continuation decision** to HIA (`example_validation_continuation.hepta`). The six-word input encodes version, mode, example count, current index, prior miss count and current match flag; the result encodes event, next index, updated misses and reserved zero. It preserves strict no-write behavior on errors. Event 4 stops on the first negative example that matched; events 2/3 ask the Rust caller to render a missing positive example. Rust still owns callbacks, `shlex::try_join`, error/debug materialization and unwinding.

The source includes the corrected empty-sequence contract: `total=0` requires `index=misses=matched=0`, matching the independently prepared checked Rust adapter. The previous standalone source accepted `matched=1` for an empty sequence, even though no callback could supply it. The isolated source-interpreter regression demonstrated two such false accepts and verified unchanged reachable nonempty transitions. The program uses a new symbol; no old HIA or Rust symbol is replaced. The restricted source screen rejects extra entry-block ABI parameters, typed store discards, duplicate JSON constant fields and noninteger constant payloads, including malformed unreachable instructions.

`tests/example_validation_source_vm.py` deliberately supports only a strict subset of the HIA assembly instructions and interprets the actual checked-in HIA text. `tests/test_example_validation_source_contract.py` is **not** the Hepta compiler, verifier, native execution, Rust product test, formal proof or end-to-end qualification. No module is registered with `toolchain.json`, `build.rs` or default dispatch in this source-only stage. Full compilation, multi-owner comparisons, malicious callee guards, callback/panic/error fidelity, installed CLI, performance and platform gates remain open. Prior failed evidence is retained. The original Rust implementation must remain active until the complete replacement is qualified; the PR must stay Draft and unmerged.
