This additive study continues R12 at commit
`1eb979ff62499abf82118b6a4196c44324c11242` (PR #4539). The local R12
working directory had later result files that were not part of its local Git

## Executed questions

1. **Does a complete restart preserve the future process?** An independent
   forward diffusion solver retains both active-position probability and the
   refractory-age queue. Continuous renewal quadrature supplies age-bin and
   age-moment references. The audit tests three grids, irregular observation
   partitions, JSON round trips, a fresh-process restart, and intentionally
   damaged recovery states. Exact partition equality is a same-lattice
   implementation statement; continuum accuracy is tested separately.
2. **Does each executed action deliver its claimed value?** The inherited
   STOP/READ/SKIP task has a deterministic, public, content-preserving SKIP.
   The new wrapper removes only a chain of SKIPs that the unchanged policy
   would follow with STOP before any READ. Ordinary and analytic backbones,
   lightweight, original Q-star, matched Q-star and selected Q-pi policies
   all receive the same intervention. Actual trajectories, all-history
   values, forced-first continuations and wrapper compute costs are retained.
3. **How do the existing content results compare after accounting for cost?**
   Independent code reconstructs the R12 raw prediction tables and joins
   their candidate identities to complete-process receipts and measured
   model profiles. All fitting seeds and stress conditions are reported.
   Only actually profiled shapes receive inference-cost values.

There is no new content training in these three extensions. The R12 content
study has eight real, fixed-budget architecture candidates, but its
`frozen_frontend` setting freezes only the encoder. It is not the full
frozen/joint content-backend by controller cross required for a unified model
claim. The numerical diffusion model, the value task and the renewal content
gate retain their separate scientific identities.

## Scope of the action improvement

For the inherited finite task, SKIP preserves the hidden content and terminal
classification, and each SKIP costs a nonnegative amount. If the original
policy takes `k` such steps and then stops without acquiring information,
immediate STOP preserves terminal correctness and saves `k * skip_cost` on
every realization. The wrapper does not receive a label, a teacher posterior,
an unread observation, or a counterfactual action value. It stops its public
simulation at the first READ. Its additional policy evaluations are counted.

This argument applies only to that explicit transition and payoff contract.
It does not authorize suppressing physical waiting when hidden state, recovery
age, external opportunity, or terminal payoff evolves during the wait.

## Evidence interpretation

- `numerics/PROTOCOL.json` fixes the continuum comparison and checkpoint tests.
- `value/PROTOCOL.json` fixes the unseen configuration confirmation and all
  factorial/strong-controller comparisons before evaluation.
- `cost/` performs historical reanalysis, explicitly after R12 outcomes were
  seen; it is never labeled a new holdout or a retraining replication.
- `SOURCE_BASELINE.json` and `BASELINE_READBACK.json` identify inherited source.
- `evidence.py` reconstructs exact repository-relative files from hash-indexed
  archive parts and refuses to overwrite different content.

The fixed-coefficient renewal gate uses an expected-event-count feature. It
does not transport the full conditional distribution or recovery age across
content tokens. The separate numerical reference does not establish that
training, value estimation and native execution use that full state.

CPU seconds, warm request latency, wall time and process peak memory are
reported as their own measured units. Joules remain unmeasured. Training
amortization is a reuse scenario, not a fabricated conversion to currency or
energy. Three existing fit seeds do not establish population-level superiority.
