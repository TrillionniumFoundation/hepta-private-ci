**风险/干预通道。** `dual_flow − value_call` 为 +0.065674，八个 seed 中七个均值差为正；ID 增加约 0.013051，OOD 增加约 0.118296。描述性、未经四项校正的 bootstrap 95% 区间为 [0.019686, 0.116102]，不得用它替代预注册主判定。该消融同时增加 P 和当前首达风险 F，识别的是损失/风险输入包的增量，不能单独归因于 Put。

**双通道结构。** 相对同输入、同训练预算的普通 GRU，signed dual-bank 的均值差仅 +0.001318，未建立其符号约束带来的额外收益。区间仍包含有意义的正负差，不能宣称两种结构已经等价。

**连续 flow。** 与观测到首达事件后的复位相比，平均差为 −0.000427。该已注册区间的上限 0.004062 低于 +0.005 最小收益线，因此本任务的现有证据尤其不支持为了所设效用收益而替换 event 反馈；本轮没有另设或通过正式等价性检验。两臂共同获得当前风险信息，这里隔离的是预期复位比例与事件复位比例的使用。

## 实现对象及与 He–Xiong 的关系

任务是有限期限、有限决策窗口的扩散维护模拟：每窗口选择等待、维护或停止，效用为折现生产收益减维护和失败成本。物理首达失败边界为 B=0；任务干预边界是由任务价值决定的另一个对象。边界来自 64 状态数值网格上的价值差及线性根插值；存在内部交点时满足：

\[
b_n:\quad Q_{\rm repair,n}(x)-\max\{Q_{\rm wait,n}(x),Q_{\rm stop,n}(x)\}=0.
\]

全域不维护或全域维护时采用协议的端点约定，不主张这些端点满足 value matching。仅在协议声明的 threshold-shaped 域使用单一边界，形状不满足时拒绝。双通道输入满足：

\[
P(x)=L H(x;\mu,\sigma,\Delta t,r),\qquad
C_n(x)=Q_{\rm wait,n}(x)+P(x).
\]

H 是窗口内的折现首达量；C 包含生产及后续续行价值，因此 `Q_wait=C−P`。预期 flow 和事件版本的核心对照为：

\[
\widetilde h_t=(1-F^{\rm action}_{t-1})h_{t-1}
\quad\text{与}\quad
\widetilde h_t=(1-\mathbf 1_{\rm failure,t-1})h_{t-1}.
\]

这是窗口化的条件风险反馈。没有在窗口内部连续积分新的 neuron ODE 或 Fokker–Planck PDE，`F/dt` 也未被当作精确瞬时边界通量。

文献层面需区分两种对象：He 与 Xiong 的 [Rollover Risk and Credit Risk (2012)](https://www.princeton.edu/~wxiong/papers/rollover.pdf) 用权益价值边界与 smooth-pasting 条件确定内生违约边界；[Dynamic Debt Runs (2012)](https://www.princeton.edu/~wxiong/papers/dynamic.pdf) 研究债权人的动态协调与阈值均衡。本轮没有重建其中任一完整金融均衡，也没有验证原闭式 Call/Put 算子或连续时间 smooth fit。C/P 是本任务的明确价值分解，双通道是一个可检验的神经结构先验。

### 模型与训练预算

| 连续模型 | 输入 / 持久状态 | 实际分配的可训练系数 | 训练方式 |
| --- | --- | ---: | --- |
| signed dual-bank GRU | 18 / 6 | 464 | 全序列 BPTT |
| ordinary GRU | 18 / 6 | 464 | 全序列 BPTT |
| Elman + MLP | 18 / 6 | 464 | 全序列 BPTT |

dual 与 ordinary GRU 共享 156 个固定符号系数、相同有效初始化及优化预算。唯一结构限制是 dual 对指定 candidate/head 系数的幅度作非负投影；gate 不受同样限制，所以这不是全局单调性定理。Elman 采用 150 个 recurrent、288 个隐藏读出、26 个输出系数；参数分配和计算量不同，另行测量。

所有连续候选训练 120 epoch、三种预定学习率；损失包含 teacher-action 交叉熵和按 DP 动作 regret 加权的期望损失。开发选择按真实原生动作所得净效用，平局取较小候选索引。通道消融屏蔽 C/P/F 列，相关输入系数按设计没有数据梯度；严格的 464 个有效训练系数匹配适用于完整信息 dual/GRU/Elman。直接边界另拟合 20 个系数。native sparse 为 420 个冻结 encoder 系数加 42 个拟合 head 系数。

BPTT 只穿过连续 recurrent policy。边界求解、特征 clip、Q24 量化和 NDU 离散动作仍在微分链外，因此没有端到端可微 SNN 或多层自由边界传播网络的验证。

## 与实际 Hepta 执行路径的关联

195,584 个连续模型确认步在 Python 中计算隐藏状态与分数，然后由未修改的原 NDU 实际选择动作；这些步没有调用 sparse kernel。另有 23,809 个 native sparse 参考步执行原 Rust kernel 与 NDU。独立审计重算全部连续状态与分数、Q24 动作、物理账本及封存身份。原生 sparse 路径核查 profile、原生收据与 checkpoint 链，并独立重算 head；没有另写第二个 sparse 核心模拟器。

所以这里已经有一个有限期限维护**模拟任务**消费 margin、续行值、风险与活动历史的真实软件闭环。新连续 cell 的推理仍在 Python；NDU 收据明确不将 Python 模型推理冒称为原生执行。没有生产业务、物理设备部署或生产 admission，研究 authority 为 DENY_ALL。

本轮没有把旧研究的 96 次 Agentd owner/journal/witness 冷恢复移记到新模型名下；新工程检查的范围是 Python recurrent state 加新的 NDU 进程。

所有方法使用同一个动作后的解析首达预测器。Brier/ECE 描述各策略访问分布下的校准，不能写成 dual cell 学到了更好的风险预测器。始终停止没有风险暴露，其校准指标未定义；始终维护虽然失败风险低，OOD 净效用却为负，风险必须结合任务效用解释。完整 ID/OOD、episode 等权和 window 等权指标均见结果文件。

三个选定模型（seed 2203 的 dual_flow、generic_gru、elman_mlp）分别完成 8,192 次持续状态更新，共 24,576 次原 NDU 决策，零 sparse 调用。hidden state 在物理任务切换时不清零；新任务会清除先前任务的风险/失败/维护历史。各 1,024 步设置恢复点，21 个新 Python+NDU 进程各续行 16 步，336 个 replay step 与未中断记录逐步哈希完全一致。最终 8,192 步检查点仅保存，不声称已验证其后的恢复。

没有数值或执行稳定性失败。隐藏状态和分数分别受实现的 1 与 8 幅度界限制；这是有限工作量的有界性及可恢复性证据，不是无限时域收敛、Lyapunov 稳定性或 durable native owner 的证明。工程检查没有增加独立确认样本。

小型有理数 DP 夹具穷举 729 个两步 Markov 策略，精确最优值为 2563/3200。它验证该有限夹具的 Bellman 实现，不能把实际扩散任务的 64 状态网格参考变成连续时间精确真值。旧研究的网格诊断不自动延伸为本轮新策略的跨网格鲁棒性结果。

## 下一步最值得做的实验

建议固定原 native sparse kernel、420 个冻结 encoder 和同样 42 个 head 参数，比较三种读出训练程序：闭式 ridge Q 拟合作工程参考；同一优化器、初始化和步数的迭代 Q-MSE；成本敏感的 teacher-action 交叉熵加 DP regret 策略蒸馏。三者共享状态轨迹、teacher、输入、期限/成本信息、开发选择预算和原生执行接口。

主因果比较应设为 **迭代 Q-MSE 对成本敏感策略目标**，从而隔离目标函数；ridge 对照描述整个训练程序的差别。只比较闭式 ridge 与梯度分类会同时改变优化方法，不能把全部差异单独归因于 loss。

使用另行提前发布的新协议、独立确认种子与固定最小收益线，继续测量任务效用、动作 regret、风险校准和完整成本。当前证据给出的优先级是改进真实原生读出策略的训练，并保持价值/风险接口可消融；在严格对照建立额外收益后，再考虑新的双通道动力学或原生实现。不得给本轮追加 seed、重选模型或改用描述性区间翻转 0/4 结论。
