# Hepta NDU-OOP v5: executable 2 × 2 factorial (development only)

**Status: DRAFT / RESEARCH_ONLY / DENY_ALL / HOLD_NO_GO.** This is a small, standalone, deterministic CPU experiment on *synthetic binary facts* and *toy generated text/audio/image/video objects*. No natural pretrained Encoder/Decoder, verified independent witness, NDU research production owner, signed outcome evidence, natural language/media generation, foundation model or general FBSDE claim is made. It does **not** close P2–P5 scientific efficacy.

The purpose is to isolate the **learned generator** and **online control** effects, including failures. This pilot cannot establish general neural NDU performance or real-world preference identifiability.

## Two independent axes and immutable data

- Train **S**: four independent learned sigmoid Head decoders with identical SGD initialization, batches, step count and per-step Head forward count, minimizing external fact-label BCE.
- Train **N**: same architecture, initialization, minibatches and step count; 70% entropic tail-weighted per-world BCE gradient + 30% fixed BCE anchor. Record per-Head gradient attribution; decoder parameters are actually updated rather than selected by a rule. Encoders/features are fixed.
- Inference **S**: the best single static EMIT / one-modality REFINE / independently paid QUERY action, chosen only on the development split using the **same** risk/value objective as dynamic control.
- Inference **N**: development-fitted, six-bin contextual Value Head maps only public input mode + current generated Head disagreement to one feasible action. It is frozen on test, with a fixed minimum support guard and static fallback.

All four arms (S/S, S/N, N/S, N/N) use the same synthetic source worlds and exact common random draws within each training seed, a disjoint train/development/test split, and the same 7 modeled physical-unit cap (4 mandatory emissions; +1 refinement or +3 independent witness). **Equal maximum budget is not equal realized cost**: every arm reports actual executed modeled units and measured local wall time separately. NDU entropic-risk training performs extra mathematical work despite equal SGD steps and Head forward counts; its training wall time is reported separately.

The model/policy APIs accept `PublicObservation` (source ID, observable difficulty and four source reports), not hidden truth, true common-cause error flag or a future witness. The evaluator sees full `World` with the heldout fact **only after generating all four raw toy outputs**. A witness can be used only when QUERY is selected, and its fixed 97%-accurate synthetic channel is treated as an explicit assumption.

Correlated wrong-source reports are generated by a common flip followed by per-modality error channels. If every observable modality agrees but the hidden fact differs, joint wrongness is charged to every decoded output, without mistaking cross-modal agreement for truth. The independent scorer penalizes wrong facts and explicit crossmodal disagreement. Fractional-mass CVaR90 uses the worst exact 10% of the observed test worlds, not an integer-rounded surrogate.

## Reproduce

Only standard-library Python >=3.10 is required. No checkpoints, GPU, network, or model weights are fetched.

```sh
cd experiments/multimodal_output_portfolio/v5
python3 -m unittest discover -p 'test_*.py' -v
python3 -m compileall -q factorial.py test_factorial.py
python3 factorial.py > /tmp/hepta-ndu-v5-development.json
```

All displayed results are development evidence; once a prospective objective, data cohort, and acceptance thresholds are frozen, a distinct new independent confirmation experiment is required. Do **not** reinterpret the exploratory seed-29 negative result or tune on the test set.
