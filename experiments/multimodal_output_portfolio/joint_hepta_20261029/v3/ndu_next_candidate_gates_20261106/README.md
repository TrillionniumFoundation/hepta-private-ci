## 2. 先修正目标解释：真实支付时间与局部风险重置

[语义包](../ndu_clock_semantics_20261106/README.md) 比较两个明确不同的目标：

\[
Q(s,a)=\operatorname{CE}_{\eta}(r-c+e^{-\rho d}V(s')),
\qquad V(s)=\sum_a\pi(a\mid s)Q(s,a)
\]

是旧 JAC 的固定事件节点、固定局部风险参数递归；随机动作在 CE 之外平均。它是合法的已声明偏好。若改为评价物理支付序列的时间 0 轨迹风险，目标则为

\[
J(\pi)=\operatorname{CE}_{\eta_0}\!\left(\sum_j e^{-\rho t_j}r_j\right).
\]

两者不能混用。一个支付 .01、一个模型时间单位后以等概率得到 0 或 1 的查询，在 η=2、γ=.5 时：

| 图编码 / 目标 | 查询价值 | 与立即 STOP=.16 比较 |
| --- | ---: | --- |
| 旧局部风险，完成转移直接分支 | .17994274652086124 | 查询 |
| 旧局部风险，插入无选择、无信息、零额外时间的强制解析节点 | .1315547923792432 | STOP |
| 时间 0 轨迹风险，正确传输 η；两种编码均相同 | .17994274652086124 | 查询 |

强制节点没有改变此例的收费、观测时刻或合法行动。固定局部参数的变化反映其事件划分偏好；不能因此把旧实现标成违反原定义的 bug。如果应用确实要重置局部风险，需要先固定触发重置的物理事件。

对轨迹目标，恒等式

\[
\operatorname{CE}_{\eta}(\gamma X)=\gamma\operatorname{CE}_{\eta\gamma}(X)
\]

给出 η_(t+d)=η_t exp(−ρd)。这也是要求所有有界非退化彩票在无信息等待细分下保持价值不变时的必要条件。带随机持续时间的递归必须使用联合条件核；已实现现金流和持续时间须进入子历史，或子历史对续行指数矩条件充分。未观测且与未来收益相关的历史现金流需要额外信息状态。

实际执行了预先记录的 81 个有限格点、162 种图编码：518 项核查通过；固定局部风险有 2 个根动作翻转，参数传输与独立完整终端收益枚举的差异为 0。单独的内部复核调用原 `ndu_jac/core.py` 手工建图，并以闭式指数矩重算既有格点，266 项核查通过。普通 110 位 Decimal 的一致性不是向外舍入区间证明。内部复核也不是外部数学审稿。

该例相对 STOP 有 .01994274652 的付费收益空间；相对匹配的经典轨迹规划器，增益为 0。故风险参数传输保留为语义守门器，不提升为算法贡献。相关扩展状态方法已有直接先例，见 Bäuerle–Rieder (2014) 以及 [最近邻矩阵](PRIMARY_SOURCE_MATRIX.md)。

## 3. 实现一个有收益空间的具体候选

[候选包](../root_influence_candidate/README.md) 使用新的、明确构造的四任务合同：持久传感器的准确率/方向来自 {.1,.3,.7,.9}，先验均匀，控制器知道 family、看不到其真实成员。冷启动校准装置先付准备费并耗时，随后可以支付单次或成对标签费。部署时可以 STOP、跟随传感器或反转标签。

外部评分固定为四个任务的期望正确数减声明的部署、校准、时间、计算和验证费用；此候选没有 η 参数。四任务批量、价格和模型时间都属于这个新合同，不改变上一批 `.01` 审计收费合同的结论。

最强不校准策略是 STOP，价值为 2；已知真实信息规律的免费信息 oracle 是 2.8，差距 .8。这个 .8 只是 oracle ceiling，不证明截止前能获取足够信息。完整同信息 DP 与独立原始历史似然求解器给出了真正可达的值：

| ---: | ---: | ---: | ---: | ---: |
| 0 | 2.0000 | 1.998990910 | 1.998990910 | 1.998993940 |
| 1 | 2.0000 | 1.998990910 | 1.998990910 | 1.998983840 |
| 2 | 2.3100 | 2.308936370 | 2.308936370 | 2.308961620 |

T=0/1 时，冷装置无法完成有信息的校准，实际信息收益为零。T=2/3/4 时，同信息解在声明费用后有正空间，因此该模型没有因“无利可图”而被提前排除。T=4 的候选在整个合同内期望使用 2.3 个标签、3.3 个校准时间单位，付 .099 校准费和 .033 时间价。

## 4. 候选被强基线等价性门槛拒收

候选优先展开

\[
S(v)=\frac{I(v)[U(v)-L(v)]}{c(v)}
\]

最大的前沿节点，其中 I(v) 是乐观根值对 v 的反向导数。具体实现保留部分图、缓存、增量回传、确定平局和行动证书；当一个行动的下界不小于所有竞争行动的上界时停止计算。

对期望目标，选定行动的 Bellman 导数正是转移概率。因此

\[
I(v)=\sum_{u\to v} I(u)P(v\mid u,a^+(u)),
\]

等于乐观策略在共享 DAG 上的访问权重。候选采用反向 tape；强基线采用独立 Kahn 正向传播，均为 O(E)，并且享有相同边界、缓存、热启动、收费、平局规则及 STOP 证书。不是让基线展开指数规模路径树后再比较运行速度。

实际检查覆盖五个截止、七个可展开状态的 128 个子集中的全部 34 个合法部分缓存，以及完整有限闭环轨迹；另补四节点共享菱形图，核对多父路径累加。510 项确定性检查通过，两者的优先级、展开次序、校准决策、停止、热启动轨迹和声明费用均相同。

T=4 时，候选和强 anytime 基线都是期望 365.3 个声明计算单位；缓存 full DP 为 168.3，账目净值还高 .000198970。这个计算单位比较不能用来声称真实硬件速度优势。候选相对合格 anytime 基线的净增益严格为 0。

核查过程中发现经济格点的乐观子图没有共享后继，最初强制要求出现共享后继的 coverage assertion 失败；原失败保留，随后添加独立菱形结构测试。另一次报告修订分开了 perfect-law ceiling 与截止可行 upper bound，没有改费用、任务、策略或结果。完整版本链见候选包 `history/`。既有解析等价性在执行前已经预期，不能称盲测发现。

对熵风险，局部导数为 γ_i p_i exp(−η[r_i+γ_iV_i]) / Σ_j p_j exp(−η[r_j+γ_jV_j])，仍对应正确风险倾斜核下的折扣访问权重。给当前规则换一个风险权重名称也不能自动越过这个门槛。完整证明及范围见 [独立规则审查](CANDIDATE_IDENTITY_NO_GO.md)。

**本候选停在此门槛，不进入独立任务、训练或 LLM 扩展。** 这是对本规则的否决；不排除未来在某类模型中提出更便宜的有效界更新或其他严格可区分的方法。

## 5. 标准全时间置信集与完整费用边界

[理论合同](BOUNDARIES_AND_RESEARCH_CONTRACT.md) 给出可直接作为强基线使用的有限 family 构造。对真模型属于冻结 Θ、可预测采样设计、正确联合观察/持续时间/删失 likelihood，记 L_θ(n) 为序列似然，取固定正权重 w，m_n=Σ_θ w_θ L_θ(n)。则

\[
C_n=\{\theta:L_\theta(n)>\delta m_n\},
\qquad
\Pr_{\theta_*}(\forall n:\theta_*\in C_n)\ge 1-\delta.
\]

保证来自 m_n/L_(θ*) 的非负超鞅与 Ville 不等式。它允许自适应行动和停止，无需对所有历史再分配 union-bound 预算。超时必须使用 survival likelihood；重复轮询不是独立样本。此处没有模型失配保证，也没有免费获得未知 family 的保证。这是经典 LR confidence sequence 的应用，见 Emmenegger–Mutny–Krause (NeurIPS 2023)。

独立证明参考对 78 节点自适应删失树用 Fraction 枚举：76 项条件鞅检查成立，两种真模型的曾排除概率均为 127/2000=.0635，小于 δ=.2。结果见 [证明参考收据](theory_reference/NEXT_THEORY_VERIFICATION.json)。这不是新的样本 bank、性能任务或独立算法确认。

置信集可给当前条件续行的遗憾上界、相对基线的收益下界；它不能自动偿还先前校准、失败 fallback 和已经消耗的时间。净收益必须从任务起点比较完整策略。时间 0 CE 下，若纯等待至少折扣 γ 且开始成本 c，继续计算的正确风险上界需用 γU_(ηγ)−c；通常不能用 γU_η−c。相应假设和反例已在理论合同写明。

## 6. 最近邻与下一轮的实际准入条件

16 项 primary sources 的 [矩阵](PRIMARY_SOURCE_MATRIX.md) 区分正文已核对和仅核对官方摘要。直接影响结论的包括：

- COLT 2026 的 Essakine–Vernade 已有 trajectory entropic BPI 的 KL 探索、停止证书和匹配指数依赖；不能把“熵风险＋识别＋停止”当成空白。
- Mortensen–Talebi 的递归折扣风险学习给出 generative-model 的上/下界；确定奖励与固定折扣下，旧 core 的不同写法可通过风险参数重写对应。
- AISTATS 2026 的 Kone–Jamieson 已有计算高效的策略识别；其唯一最优策略、Gaussian 奖励等具体假设仍需逐项核对，不能直接搬来覆盖本合同。
- IJCAI 2015 的 metareasoning 已把计算内部状态与物理状态联合建模；AI 2026 的 anytime POMDP 规划已有确定性行动界。计算状态、时间成本和有证书停止本身不足以构成原创性。

后续工作须提交一个能被反驳的具体增量：相同合法输入、数据、结构、费用与数值约定下，产生非平局的不同有效更新，或得到严格更便宜且具有正确界的计算方法。先证明总收益空间超过必付代价，再与经过缓存/热启动/anytime 优化的强基线比较。只有完整开发账目通过，才冻结方法去独立任务确认。

当前状态是：**具体本轮候选已关闭；语义、可达性、置信集、费用账目与基线资格标准得到加强；原创 RL、真实独立净收益与规模训练门槛尚未通过。**
