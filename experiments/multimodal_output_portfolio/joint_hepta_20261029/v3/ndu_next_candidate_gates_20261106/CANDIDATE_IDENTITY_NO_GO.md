# Root influence × interval width / cost：等价性拒收准则

日期：2026-11-06。本文是独立数学审查，不声称已运行候选的实现 trace。已只读检查 `next_candidate_work/root_influence_candidate/anytime.py` 及其合同；具体代码执行结果由候选负责人提供。它补充 `BOUNDARIES_AND_RESEARCH_CONTRACT.md`，将下一步从泛化建议收窄到一个具体可否决规则。

**当前判定：该已实现候选在规则层面被等价性门槛拒收。** 其目标是期望净效用，没有 η 参数；反向 Bellman tape 和正向 Kahn DAG flow 计算同一普通 occupancy。下文额外写出熵风险推广，是为了明确“换成风险倾斜权重”也不能自动成为一个新增量，不是把新候选重新定义为另一目标。

## 1. 候选规则

候选给每个待展开计算节点 v 一个优先级

S(v)=I(v)[U(v)−L(v)]/c(v)，

其中 I(v) 是根值对该节点值的影响，区间为当前数值界，c(v)>0 是共享口径下的展开成本。若 I 由 Bellman 计算图的反向导数得到，这一规则必须与使用相同风险变换和共享 DAG 的经典 occupancy/AO* 式规则比较，不能仅比较原始转移概率的 occupancy。

## 2. 熵风险的影响等于倾斜核下的折扣 occupancy

在当前期望目标的实现中，局部式为 F(x)=−cost+Σ_i p_i x_i，故 ∂F/∂x_i=p_i；因此本节的路径和恒等式直接退化为普通 occupancy，不需要风险偏好假设。

对一个局部事件节点，令

F(x)=−η^−1 log Σ_i p_i exp[−η(r_i+γ_i x_i)]，

并定义

w_i(x)=p_i exp[−η(r_i+γ_i x_i)] / Σ_j p_j exp[−η(r_j+γ_j x_j)]。

逐项求导给出 ∂F/∂x_i=γ_i w_i(x)。这些权重非负，且 Σ_i w_i=1。η→0 时退化为 γ_i p_i。静态时间 0 CE 的传输参数版本在每个节点用该节点正确的 η，局部导数仍为此式。

在有向无环的值计算图上，从根设 I(root)=1，并沿边传播

I(child) += I(parent) × γ_edge × w_edge。

按拓扑序归纳，I(v) 等于所有根到 v 路径的上述边权乘积之和；这既是链式法则的根导数，也是风险倾斜核下的折扣 visitation weight。共享子节点必须把所有父路径的贡献相加；将共享 DAG 展开成树或反向自动微分不会产生新的数学量。

此陈述对固定行动分支成立。存在 max/action 节点时，在唯一活动分支上应用导数；在平局处，必须给两种实现相同的活动分支或次梯度约定。若一侧使用另一种 bound point、不同 max 分支或未经控制的有限差分，那是另一个规则，不能未经核对便宣称等价。

## 3. 逐步规则等价命题

**命题。** 两个部分规划器拥有相同初始 DAG、L/U、合法动作集合、成本表、数值精度约定、缓存状态、局部展开/回传算子、tie-break、行动提取及 STOP 条件。规划器 A 用根导数 I，规划器 B 用上述倾斜核折扣 occupancy。则每一步选中的展开节点、更新后状态、返回行动与证书均相同。

**证明。** 初始状态相同。假设第 k 步前的全部状态相同，则各局部值及倾斜核相同。上一节的链式法则给出每个节点 I_A=I_B，所以优先级相同；共享 tie-break 选中同一节点。相同展开/回传算子与缓存产生相同新状态，完成归纳。行动与 STOP 都是该状态的同一函数，故同样相同。随机展开时，在相同随机流下耦合上述归纳即可。∎

若同一物理操作的耗时、输出及费用也共享耦合，两者在环境中的完整轨迹和净值亦相同。实际实现的额外记录、导数计算、数据结构或不同浮点顺序可以造成运行成本/临界平局差异；这种差异必须作为实现成本单独报告，不能被说成新的决策原则。

该命题是一个可执行的否决条件，不是对所有 future candidate 的不可能性结果。它也没有声称任意名为 AO* 的现有包都已正确实现了当前风险目标。应给强基线正确目标、相同 DAG 优化与合法 stopping 能力，再检查具体 trace。

## 4. 当前候选如何判定

源码核对结果与命题前提一致：`reverse_influence` 用反向 tape 累加 adjoint，`classical_occupancy` 用独立的 Kahn 正向流程累加流量；两者都保持共享 DAG，使用同一 optimistic action、区间、cost quote、行动证书与 tie-break。因此应关闭本次“新调度算法”候选，执行 trace 用于检验实现是否忠实，而不是再寻找统计阳性。无需新增 bank 来寻找看似阳性的随机波动。它可以留下有用的性能实现或守门器，但不能用“真实时钟、内部状态、证书和 STOP”重新包装为新增 RL 贡献。若两侧实际计算成本不同，只能先提出并测量一个清楚的计算实现改进。
