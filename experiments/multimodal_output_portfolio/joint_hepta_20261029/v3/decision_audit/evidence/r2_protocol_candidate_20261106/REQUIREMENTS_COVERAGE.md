# 用户要求与现有 R2 候选的覆盖边界

本表只映射已存在的实现、候选定义和未完成工作。`PROTOCOL.json`、所有旧合同、7 方法 roster
及7个 CE 对比保持原字节。A、C、tiny-sd 是实现机制增量，尚未构成新的确认性四臂实验。

## 四臂与必须比较的策略

| 用户要求 | 已有覆盖 | 当前缺口与可成立结论 |
| --- | --- | --- |
| 00 固定控制/冻结生成 | 旧协议有定义，compile 产生 32 条 NOT_RUN 计划；固定 schedule 接口已有 | 未执行新来源下的配对 panel；必须提供显式 no-gradient、冻结字节与实际成本收据 |
| 10 训练控制/冻结生成 | 旧协议有定义；C 执行合成标签的线性动作价值 SGD | 缺真实独立开发标签、完整控制器 fit、实际选择与冻结生成器四臂联动；机制测试不证明控制收益 |
| 01 固定控制/训练生成 | 旧协议有定义；tiny-sd 旧开发图上实际更新 conv_out 并冷装载 | 缺新来源任务完整训练与配对 panel；单次 loss、参数 delta 和 PNG 不证明质量收益 |
| 11 训练控制/训练生成 | 旧协议有定义和配对初始化约束 | 尚未把真实控制与生成训练共同运行成完整 fit；没有联合额外收益结果 |
| 固定资源配置 | 00 为 fixed alias；12 个候选合法 schedule、验证 CE 选择和确定性 tie-break 已声明 | 尚未实际执行完整验证选择；fixed 不另算一次执行或重复收费 |
| 相同总预算的简单生成 | 旧候选声明 same_total_budget 与固定策略 | 未定义并执行独立的等总预算简单生成对照；总预算仍 null，不能把 00 自动视为已满足该要求 |
| 一步净信息价值策略 | greedy 候选定义；C 提供“实际单步效用增量减声明成本”的拟合前驱 | 尚无真实开发标签 fit 和策略资格；该目标不证明 EVSI、continuation Q 或已成立的强 greedy 基线 |
| 同风险、同观测、同动作 actor–critic | 当前 7 方法合同中没有单独的匹配 actor–critic 定义与执行收据 | 缺策略/价值网络、风险目标、观察/动作一致性、预算与训练选择控制；C 线性预测器不等于 actor–critic |
| 计入搜索成本的强规划器 | 声明 depth 2/3、beam 2/4、expansion cap 8/16、每决策最多 16 模型调用；账本可保留未选展开 | 实际 transition/value 模型、强 planner、开发选择、完整搜索成本尚未绑定；历史机制 DP 不能代替神经未来结果 |
| 完整 NDU 策略 | 用户要求是目标；旧7方法中的11只表示控制/生成都训练 | 尚无满足本轮所有机制的完整 NDU 实现/资格/确认性结果；不能把11、C回归或内部NDU分数当完整NDU已验证 |
| train-only retrieval | 旧候选额外登记冻结 VLM 特征、cosine、top-k/threshold 及索引成本规则 | 实际视觉特征接口、冻结索引、开发选择和真实查询未绑定；它不替代用户要求的其它基线 |

## 必需消融

| 用户要求 | 现有覆盖 | 待完成工作 |
| --- | --- | --- |
| 去掉动态偏好 | 当前7方法不单独编码该因素 | 定义偏好固定方式及匹配其余训练/观测/预算；提供独立候选身份与执行 |
| 去掉未来规划 | greedy 与 planner 的候选名称有相关性 | 尚不能当作匹配消融；须固定共享价值模型、风险、观察、动作及总预算，只改变规划机制 |
| 去掉跨模态共享状态 | A 记录实际公共状态，并非共享状态开关实验 | 需定义分离状态方案、保持可用信息/模型容量/成本匹配，执行一致性与联合质量比较 |
| 替换 Hepta 核心 | 当前包没有替换控制条件 | 需明确被替换组件和替代实现，冻结匹配训练预算、参数/模型身份及公平观察/动作边界 |

## 扩展统计方案前的约束

现有统计程序只接受旧的7方法坐标和7个预登记 CE 对比。它可复用于该既定设计的算术与账本，
不能据此声称已覆盖上表全部基线和消融。任何新增方法 roster、actor–critic、完整 NDU 或匹配
消融都需要在新结果和测试访问之前预先修订：方法/候选身份、基线选择规则、对比族与多重性、
配对与重采样单元、总预算、质量门槛、功效与 N 选择。应另建可审阅 addendum 保留原协议身份，
不改写历史冻结对象，也不在结果出现后改变目标函数或扩大摊销部署次数。

JSON hash、另一个共享工作区 agent 的审阅、机制测试通过均不等于独立评价 custody。
这份覆盖表不授予训练、测试调度、数据访问或产品晋级资格。
