## 2. 语义：通过的是明确目标下的有限问题

实现将准入成本放在耗时折扣之前；STOP 为终端，不继续 bootstrap。
风险聚合包含策略随机动作和环境随机结果。独立计算路径得到：

| 核验 | 最大绝对误差 |
| --- | ---: |
| Bellman 最优值 vs 独立策略树枚举 | 2.220446049250313e-16 |
| actor 梯度 vs 独立高精度中心差分 | 4.163336342344337e-17 |
| 无折扣时 vs 仓库既有完整轨迹梯度 | 1.5612511283791264e-17 |
| 小风险完整路径值 vs 风险缩放递归值，eta 从 1e-6 到 1e-30 | 5.551115123125783e-17 |
| 同一小风险路径比较的梯度 | 2.7755575615628914e-17 |

风险中性极限另行核验：eta=1e-9 时，与 eta=0 的值差为
`3.885633481637285e-11`，梯度差为 `1.9163615139206058e-11`。
这些随 eta 消失的目标差，不能和上表的数值参考误差混为一谈。

必须区分两种折扣风险目标。固定 eta 的逐层 entropic CE 作用于
`-cost + exp(-rate * duration) * continuation`；完整折扣轨迹的单次 CE
需要后续风险参数 `eta_next = eta * exp(-rate * duration)`。
在 eta=2、rate=0.13 的同一随机策略下，两者分别为
`0.16021313558444195` 和 `0.1691229013621947`，并不相等。
同一目标内的算法比较才有意义。

反例也保留了明确的失效条件：

- 随机耗时仍每决策步只乘一次 gamma，会将正确梯度
  `(-0.0625, +0.0625)` 翻成 `(+0.125, -0.125)`。
- 普通期望回报的 advantage 在风险 CE 任务上优化了另一目标；在注册反例中更新方向相反。
  这不构成“所有 GAE 都失效”的结论。
- 耗时和结果相关时，`E[discount * value]=0.729`，而
  `E[discount] * E[value]=0.8145`。
- 已付成本若误放进折扣，注册反例的值从正确的 `-0.15` 变成 `+0.15`。

开发复核还发现完整路径参考先以 float 构造概率和 score，会在 eta 很小时放大误差。
冻结前已改为从 softmax、路径概率、score 到折扣都使用 Decimal，并随 eta 调整精度。
这修复的是验证器的数值稳定性；不是算法效果证据。
详见 [语义定义](SEMANTICS.md) 和 [独立算术复核](evidence/review_semantics/REVIEW.json)。

## 3. 结构：强简单基线很强，神经与 direct-gradient 没有稳定优势

11 个 panel 分别覆盖基准、零／极低／高内部噪声、四维状态、高调整成本、
零互补性、资源／驻留限制、环境模型偏差、总可重置、不可重置。
所有 critic 可访问相同的带噪 value stencil。Direct-gradient 标签由这些共同观测的
有限差分得到；Z 标签仅为同一梯度标签乘 sigma，没有额外提供解析真梯度。

660 条记录包括 480 个实际拟合模型、165 条精确／固定／冻结参考和
15 条零噪声 Z 不可识别记录。645 条完成记录的 **82,560 个决策全部可由
保存参数和原始数组重放**，没有异常失败模型。不可识别的 Z 没有被填成零梯度。

下表为五 seed 的平均 regret，即精确合法一步策略与该策略的目标值差，越小越好。
二次 value 是结果复核中统一展示的描述基线；原协议未指定 primary learning-method contrast。

| Panel | 二次 value | 线性 direct gradient | 神经 direct gradient |
| --- | ---: | ---: | ---: |
| 基准 | 0.00009411 | 0.00017424 | 0.00015188 |
| 极低噪声 | 0.00013506 | 0.00022870 | 0.00005691 |
| 高噪声 | 0.00185206 | 0.00065166 | 0.00122667 |
| 四维状态 | 0.00048008 | 0.00018452 | 0.00041816 |
| 资源／驻留限制 | 0.00006467 | 0.00001681 | 0.00008369 |
| 环境模型误差 | 0.01678880 | 0.01773787 | 0.01701799 |

完整 11-panel 和逐 seed 数字见 [结构复核报告](evidence/review_structure_20261105_001/REVIEW.md)。
神经 value critic 在全部 11 panels 的每个 seed 都弱于二次 value；这是本次训练配置的负结果。
Direct-gradient 的差异跨 panel 和 seed 改变方向。高噪声 panel 中神经 direct 的均值较好，
但五 seed 中只有两个优于二次 value，不能仅凭均值宣称稳定优势。

全部 **150 个正噪声 direct/Z 配对动作相同**，最大预测差约 `6.24e-14`。
因此这次等信息的缩放对照没有观察到低噪声学习优势。零噪声的不可逆性是另一条结论。
模型误差则将主要 critic 的 regret 提高到约 `0.0168–0.0177`，更换表示没有消除共同的模型偏差。

基准训练 CPU 均值：二次 value `0.292 ms`、线性 direct `0.227 ms`、
神经 direct `10.194 ms`。参数量和训练工作量没有匹配；普通特征推理路径还构造未使用的
Jacobian，当前推理计时不能证明优化后的神经效率优势。更低的梯度 MSE 也没有保证更低的决策 regret。
结构探针的效用未将 CPU 折算为费用，因此它不是物理成本净收益检验。

## 4. 真实工具与四格归因：零收益，且低于精确自适应参考

冻结生成器是仿射 Python 函数的固定字符串修复规则。任务有 0／1／2 个预置 bug，
控制器只读公共动作与观察历史，最终 ORACLE 用 25 个输入独立核验函数输出。
修好代码但未 STOP 的案例不计为成功交付；最终验证费用也计入失败、到期和取消案例。

训练的两行分别是 inherited flat CE 与 recursive CE，均优化 eta=2 的无折扣目标。
3 seeds × 2 fits × 500 次更新，共 **3,000 次实际更新**；训练使用随机 softmax，
服务部署使用注册的 greedy 策略。旧 Torch learner 的有限样本训练未执行，
这里执行的是与既有精确公式交叉核验的完整分布更新，不能冒称复现旧训练器或 rsEAC。

| 训练 | 推理 | 服务数 | 外部质量 | CE | 平均动作费用 |
| --- | --- | ---: | ---: | ---: | ---: |
| 完整轨迹 CE | 最强固定计划 | 27 | 1 | 0.815 | 0.185 |
| 递归 CE | 最强固定计划 | 27 | 1 | 0.815 | 0.185 |
| 完整轨迹 CE | 学习后动态控制 | 27 | 1 | 0.815 | 0.185 |
| 递归 CE | 学习后动态控制 | 27 | 1 | 0.815 | 0.185 |
| 精确自适应参考，额外实际执行 | 按观察规划 | 9 | 1 | **0.8757424020** | **0.120** |

四格的全部服务都选择 `REPAIR → REPAIR → STOP`，再进行最终 ORACLE。
各 seed 的训练效应、推理效应和交互效应均为 **0**。固定列不消费训练参数，
它的训练效应结构性为零；本轮只是等价性／归因检查，不是用户所要求的完整训练收益检验。

31 个合法固定计划已穷举。精确自适应参考先 CHECK，再决定修复次数；同样信息和合法动作下，
其 CE 高出 `0.0607424020`。这说明环境确实有自适应收益，冻结的学习器在
500 次更新预算下未学到它。不能把所有策略都达到质量 1 解释为动态控制有效。

两训练行最终参数最大差 `1.0658141036401503e-14`，68 个状态的 argmax 分歧为零。
这符合数学等价的预期。当前递归 Python 实现的训练 CPU 是向量化完整轨迹实现的
`14.62–23.71` 倍；仅代表这次规模与实现，不构成一般复杂度结论。

服务共执行 324 个工具子进程，加上模型资格 54、故障资格 5、精确参考 27，
总计 **410 个真实工具子进程**。108 次服务均 STOP 成功；9 个资格案例因到期未 STOP 保持零交付质量。
语法失败、exit-zero 坏 JSON、进入执行后超时 kill/reap、一次动作后取消四种负例全部留存。
详见 [工具定义](TOOLS.md) 和 [工具复核报告](evidence/review_tools/REVIEW.md)。

这些是注册目标费用，不是实际货币价格。CPU、wall、RSS、旧 meter 的示意 tariff 也各有口径。
环境准备、数据获取、外部基础设施、审查和发布的一次性完整成本尚未齐备。

四格执行同样的工具序列，观察 CPU 差跨 seed 变号。原结果中的 181／380 次
`services_measured_scope_only` 只是在局部 CPU 小计下的算术商，不是经济回本点。
合格的 `services` 始终为 null；不能宣称已经满足同质量、正单次净节约、完整一次性成本三个条件。
精确规划虽节约 research credits，也不自动节约实际 CPU。

每 seed/cell 只有 9 个服务观察；保留并复算 P95/P99 有助于透明记录，不能据此声称生产尾延迟稳定。
每次服务的资源峰值没有受支持观测时保持 null；整个进程高水位不能冒充服务级峰值。
