# Actual owner, durable feedback, and complete continuation study

This is a new, frozen finite experiment around the **unchanged original
`AgentdNeuronOwner`**, `NeuronRuntime`, sparse kernel, journal, and witness store.
It closes an execution gap in the earlier finite simulator and kernel-only
feedback study: hypothetical futures and actual post-delivery decisions now run
through the same real owner boundary, preserve its state, honor its future
abstention, and pay for their computation. It does not reproduce or promote the
earlier failed semantic qualification.

## Results and qualification boundary

Run002 executed 240 actual multimodal delivery episodes and independently
replayed their complete native transcripts. Each episode has four current
candidate ticks, three restored future branches of three ticks each, and three
committed post-delivery ticks. The actual transport produces text, PNG, PCM tone
WAV, and AVI files; an independent auditor reads their bytes using different
decoding calculations.

Replay equality covers every semantic field exposed by this host, including
full checkpoint identities, eligibility, activation, abstention, authority,
and resource byte counts. The host JSON is a projection of the original Rust
runtime structs, not a serialization of all daemon fields. Measured elapsed
times and allocator totals are retained but are not required to repeat exactly.

These are exact weighted results in the registered finite environment, not
population estimates from independent speakers, writers, videos, or outages.
The target and transport laws are declared in `PROTOCOL.json`, not estimated
from the evaluation targets. No confidence interval or natural-world
generalization claim is attached to this census.

All native signals retain **`DENY_ALL`**. Native non-abstention is a necessary
condition in the research host, not a grant of generation authority. Actual
media writes require a separate user-authorized research permit confined to the
run directory, native non-abstention, and sufficient remaining media units.
Consequently, the study has actual composed owner/host episodes, but **zero
native authority grants and zero production semantic qualifications**. It does
not activate the daemon or change production authority code.

The new native calibration target is deliberately narrow: whether an input is
inside the registered finite public encoder domain. On that domain, the frozen
encoder's prediction equals its computed drive. Its zero residual, ECE, and
false-acceptance values therefore concern this exact deterministic identity.
They are not semantic-quality calibration. The original numerical confidence
and false-acceptance gates remain in effect, including expiry; the new artifact
must not be substituted for the old failed selected-action semantic ECE test.
Complete-policy terminal forecasts are a separate, externally audited result.

## What the actual continuation does

Each episode begins with four actual owner ticks checking current candidate
eligibility. The public cue and candidate identity are bound in the evidence
digest; this finite phase-0 encoder emits zero drive and does not perform
semantic candidate evaluation. Candidate values come from the explicitly
registered task law outside the owner.
Three future branches copy the current original journal, independent witness,
and durable host event ledger. Each copy is recovered through the original
runtime and runs the same registered three-tick continuation that will later be
followed in the committed owner. The parent checkpoint stays unchanged.

The host then writes the initial four media files and reads them back. Only
after this real delivery does it derive numeric feedback from the observed
transport fault. That scalar enters the original owner once, at sequence 5.
Sequence 6 is a zero-drive hold. Sequence 7 reads the recurrent eligibility
state with an eleven-coefficient learned logistic head. Neither the fresh
scalar nor a private target is supplied to that final readout.

The later controllable action is an actual reliable repair delivery. If the
head proposes repair but the original calibration has expired at sequence 6,
sequence 7 abstains and the repair is denied. A one-unit media budget also
denies a second delivery. The already delivered initial output is then retained
as the final output, with its actual defect and irreversible initial damage.
The complete cost includes initial delivery, realized transport, computation,
any real repair, and a denied-attempt fee. A hypothetical repair is never scored
as if it had been delivered.

This makes feedback a causal intermediate event rather than an observation
after a terminal EOS. In the matched numeric/zero comparison, the initial action
is held fixed. The 48 context-by-fault pairs have sixteen changed later repair
proposals and four changed executed repair deliveries. Numeric feedback avoids
unnecessary repairs and denied attempts, producing the positive return gap.
There is **no semantic-quality gain in that particular intervention**, and the
same-information history policy matches it exactly. The result supports a
working state/action mechanism; it does not establish a unique informational
advantage for the neuron over public history.

The head is trained on 96 actual delivered training cases using only public
repair-need labels and actual original-owner eligibility states. Its eleven
weights receive 600 registered gradient updates. The sparse kernel and codecs
are fixed. This is a learned state readout, not joint training of a natural
multimodal generator.

## Complete-policy risk prediction

For each candidate initial action, a forecast includes the realized future
repair proposal, owner abstention, host media budget, delivery or retention,
irreversible damage, and every registered task charge. Its entropic moment is

\[
M(a\mid c)=\sum_f p(f\mid a)\sum_y p(y\mid c)
\exp\{-\gamma U(y,f,a,\pi,\text{owner},\text{budget})\}.
\]

The exponential is inside both expectations. The implementation does not use
the exponential of an expected utility. The target is unavailable to generation
and feedback; the external scorer integrates target utilities only after final
delivery. The frozen model, protocol, root table, source identities, and binary
are recorded before the formal census begins.

The risk and mean controllers choose different real initial outputs in three
contexts. Their losses are not just differently labeled copies of one action:
the registered actions have different semantic utilities, tail losses,
transport laws, initial prices, and subsequent repair costs. The conservative
action has modest utility for all targets but never counts as an exact target
match. This explains the tradeoff below; utility and strict accuracy are
different registered measures.

| Policy | Mean external return | Average conditional entropic CE | Mean task cost | Strict target success |
|---|---:|---:|---:|---:|
| Risk, numeric feedback | 0.224875 | -1.134598 | 0.066875 | 0 |
| Mean, numeric feedback | 0.296703 | -1.617080 | 0.066422 | 0.165000 |
| Risk, zero-feedback intervention | 0.188500 | -1.163836 | 0.103250 | 0 |
| Risk, same-information history | 0.224875 | -1.134598 | 0.066875 | 0 |
| Mean, blind-future ablation | 0.225706 | -3.837436 | 0.052481 | 0.543375 |

The blind-future arm deliberately models future admission and budget as always
available while its actual executor still obeys the real owner/host rules. It
receives and pays for the same shadow computation. It is an old-bug ablation,
not the strongest feasible-policy baseline. The same-information history arm
provides the stronger feedback comparison.

## Durable event identity and restore

Run001 had no host event deduplication. Its closed results and exact compiled
binary were preserved before adding the guard. Run002 introduces one registered
event identity per processing phase. The event identity and delivered receipt
digest enter the original native checkpoint's bound evidence, so changing an
earlier identity or payload changes the checkpoint chain.

The host appends and fsyncs each acknowledged event with its native receipt.
An exact retry returns that receipt with `duplicate_event_ignored=true` and
`native_transition_executed=false`. A conflicting phase, scalar, or receipt
digest under an already committed identity is rejected before any owner tick,
journal change, witness change, or ledger append. Physical RPC processing time
is still measured; a duplicate is not presented as physically free.

Cold restore rebuilds every ledger event with the original sparse kernel,
checks the bound checkpoint chain and learned readout, and requires the final
checkpoint to equal the original witness. The original journal is then recovered
normally. Forecast forks carry the same ledger and restore contract. If a native
commit happened without a complete acknowledged ledger record, the live host
is poisoned and a later restore rejects the inconsistent frontier. It preserves
the evidence rather than silently processing the event again.

The actual guard study exercised three acknowledged duplicate RPCs, with zero
duplicate native transitions: in the live process, after a genuinely new owner
process restored the files, and after a restored forecast fork inherited its
parent's event. It also rejected live/cold/fork payload conflicts and five
mutated restore cases: a missing final ledger commit, changed event payload,
changed event identity, changed proposed action, and changed abstention. All
rejected cases preserved the durable files byte for byte. A real repair was
delivered after the restored feedback state reached its later decision.

This is a single-writer, registered-identity protocol. It does not detect a
physical event deliberately relabeled with a new valid identity, protect against
a hostile filesystem owner, or guarantee exactly-once external media dispatch.
The restart probe is a real process restart; no hardware power-loss experiment
is claimed. Incomplete commit/ledger pairs fail closed rather than promising
automatic lossless crash recovery.

## Cost-accounting amendment

The first frozen run charged sixteen owner API calls per episode. It already
replayed four native journal records in each of its three forecast restores, so
there were twelve additional original-kernel invocations that its API-based
fee contract did not price. Run002 explicitly prices that existing restoration
and the twelve new ledger-validation invocations. The original run is retained
verbatim; `evidence/COST_ACCOUNTING_ADDENDUM.json` documents the limitation and
the measured version comparison.

| Per episode | Run001 | Run002 |
|---|---:|---:|
| Actual owner.tick API calls | 16 | 16 |
| Original-journal sparse replays | 12 | 12 |
| Event-ledger sparse validations | 0 | 12 |
| Total original-kernel invocations | 28 | 40 |
| Priced control task units | 0.0016 | 0.0040 |

Every run002 original-kernel invocation costs the registered 0.0001 task units.
The terminal-return shift of -0.0024 splits into -0.0012 for pricing preexisting
journal restoration and -0.0012 for the new guard. All root actions are unchanged
across versions, and the measured mean shift residual is below 7e-17. The
matched return gaps consequently stay the same.

These synthetic task units are not an empirical wall-time, dollar, FLOP, or
energy price. Run002's evaluation episodes measured 33.18 seconds of episode
wall time and 30.95 seconds of host RPC processing elapsed time. Recorded Python
CPU time is 1.69 seconds and excludes Rust/media subprocess CPU. Per-tick native
timing, allocator observations, checkpoint size, and journal bytes are retained;
no total-machine CPU estimate is inferred from them.

## Evidence and reproduction

`evidence/` holds both immutable numerical summaries, source/binary freeze
identities, calibration scope, model/training records, build receipts, the guard
result, independent audits, asset-recovery scope, and the cost addendum. The
full evidence archive also includes every actual media file, native request and
response, journal, witness, event ledger, independent replay, and the exact
compiled v1/v2 source trees and binaries. Large raw evidence is not committed
to the repository.

Build from the unchanged repository crates with a pinned Rust toolchain and the
previous preserved minimal Cargo lock:

```sh
python3 -m experiments.multimodal_output_portfolio.continuation_20261027.control.build \
  --repository /path/to/hepta-private-ci --destination /path/to/new-owner-build \
  --compiler /path/to/pinned-rust/bin --prior-archive /path/to/ndu_neuron_feedback_evidence_20261026.tar.gz
```

The builder checks every resolved dependency name, version, source, and checksum
against the repository lock. It builds an isolated owner example to avoid
pretending that a full daemon build or deployment occurred. The original owner
and all three source crates are byte-identical to the baseline.

```sh
python3 -m experiments.multimodal_output_portfolio.continuation_20261027.control.run \
  --binary /path/to/new-owner-build/target/debug/examples/owner_host --output /path/to/fresh-run
python3 -m experiments.multimodal_output_portfolio.continuation_20261027.control.audit \
  --run /path/to/fresh-run --binary /path/to/new-owner-build/target/debug/examples/owner_host \
  --output /path/to/fresh-audit
python3 -m experiments.multimodal_output_portfolio.continuation_20261027.control.guard \
  --binary /path/to/new-owner-build/target/debug/examples/owner_host \
  --model /path/to/fresh-run/MODEL.json --calibration /path/to/fresh-run/ENCODER_DOMAIN_PROOF.json \
  --output /path/to/fresh-guard-check
```

Outputs must be fresh directories; incomplete or failed attempts are retained.
The auditor checks the exact unique 240-episode and 80-group Cartesian grids,
all frozen artifact identities, the phase-1 feedback/readback mapping, actual
media, dispatch conditions, all charges, and complete native replay. It computes
terminal utilities and exponential expectations independently and rejects
consequential dispatch-receipt mutations.

Remaining open work includes production semantic qualification and actual
daemon integration; learned natural-media generation and joint foundation-model
training; uncertain learned environment laws with calibrated predictive error;
and a generalized long-horizon policy, including durable external dispatch
idempotence. This finite owner study supplies executable evidence for those
interfaces without treating them as already established.
