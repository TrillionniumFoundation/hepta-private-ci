continuation, post-update deployment and terminal evaluation. It completes a
bounded mechanism demonstration. It does not change any frozen qualification,
select a new model, certify semantic generation, or grant production authority.

## The trajectory and its gradient

Each episode executes the original fast owner with mandatory cold recovery.
The initial natural forward pass uses context video/audio alone, performs two
shared neural transitions, draws the four stochastic emissions, writes PNG,
WAV, FFV1 Matroska and UTF-8 files, then physically reopens them. Predeclared
fault scenarios truncate the newly generated initial video to eight bytes.
Only the observed public transport failure or success enters the original
owner as its registered scalar feedback.

The unchanged native readout proposes the continuation. Expiry and the bounded
media budget can deny it. An admitted retry generates a **new** independent
sample from the advanced episode RNG under the same fixed parameters. Denied
retries create no sample and no fictitious log-probability term. Failed initial
samples still retain their actual score and costs.

After the owner closes, a separate private callback reopens the final physical
files and applies the frozen natural `SCORE_SPEC` to the private reference.
Incomplete final delivery has zero gross utility. The complete trajectory
return subtracts the explicitly declared native, generation, delivery, refusal,
identity-verification, codec, scoring and CPU charges exactly once.

For a batch of two complete episodes, the implemented surrogate is

\[
L(\theta)=\left(\frac1K\sum_{k=1}^K
\frac{\exp(-\gamma R_k)-1}{\gamma}-b_{\mathrm{previous}}\right)
\sum_{k=1}^K\sum_{t\text{ actually emitted}}\log p_\theta(a_{kt}\mid h_{kt}).
\]

The mean already divides by `K`; there is no second division. The baseline is
zero initially and the previous batch's mean moment cost afterward. It is
independent of the current random draws. The joint batch score retains cross
terms if observed costs couple the two episodes. Fixed Gaussian normalization
constants are restored in this helper, without changing the frozen sampler.
Parameters update only after both complete owner trajectories and terminal
scores have finished. Each update records raw gradient hashes, norms and
maxima for every component before clipping.

## Cost and authority boundaries

The corrected run measured 19.892040 self-plus-child CPU seconds in total.
Episode returns charged 16.383601427 CPU seconds plus the explicit execution
tariffs, totaling 0.364383601427 normalized utility units over twenty episodes.
Every episode includes public input tensor preparation, public input digests,
checkpoint/parameter hashes and policy-manifest assembly before the owner call.
That preparation consumed 0.348375 CPU seconds and has its own charged ledger
event, separate from the repeated in-episode checkpoint/code verification.
The remaining 3.508438573 measured CPU seconds belong to one-time corpus/model
setup, backward/optimizer work, checkpoint writing and report bookkeeping.
Training and archival costs are reported separately from deployment return.

The first diagnostic run, `native-joint-gradient-001`, excluded per-episode
preparation CPU. It is preserved with its exact sources, checkpoints, outcomes
and mathematical audit as a retired trial. Run `002` freezes a new profile and
repeats the identical source/seed/scenario/update plan with this charge included.
No model selection or additional qualification occurred between those runs.

CPU time is observed and charged, but treated as conditionally exogenous for
the stochastic-action gradient. Direct parameter derivatives through runtime
are not estimated. The inherited `native_cpu_seconds` ledger field includes
all child processes, including FFmpeg; it is not a pure owner CPU counter.
Future CPU time has no enforced finite bound, so no bounded-return tail
certificate is issued.

The native authority remains `DENY_ALL`. The original calibration supports its
registered scalar encoder domain only. It does not certify natural semantics,
these new neural parameters or the new host reward. Bounded research dispatch
has separate user authorization. This new profile does not retroactively make
the earlier single-bundle natural objective and transport-only native profile
identical.

## Evidence and interpretation

`results/NATIVE_JOINT_GRADIENT_SUMMARY.json` contains the counts and checks;
the adjacent profile, protocol and freeze records contain their exact bindings.
The raw supplement retains every step checkpoint, actual owner transcript,
physical output file, episode cost ledger and per-update gradient receipt,
together with the exact executed source bytes. The independent gradient audit
reconstructs the recorded samples and checks a separate normalized-density
calculation without additional owner episodes.

The final independent audit matched all 104 recorded component-gradient hashes
exactly. Using separate normalized `Normal` and `Categorical` distributions,
its maximum component gradient relative L2 discrepancy was `1.66119e-7` and
maximum absolute element discrepancy was `2.00272e-5`. Joint log-density values
differed by at most `0.015625` from floating-point reduction order; the gradient
comparison covers every model parameter. This audit performed forty neural
forward replays to reconstruct existing evidence, zero new owner executions,
zero new deliveries and zero optimizer updates. It also verified all twenty
cost ledgers and the four final-checkpoint deployment receipts.

The four development returns are descriptive mechanism outputs. The deliberately
mixed success, retry and denied-failure scenarios are not an efficacy benchmark.
All previous failed natural capability gates remain failed. No fresh
qualification, generalization improvement, semantic adequacy or production
promotion is claimed.
