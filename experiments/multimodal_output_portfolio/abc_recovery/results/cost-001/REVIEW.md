## 1. 队列、配对、风险和成本口径

- 仅分析完整八视图 `supplementary_all` 运行：**8 个预选来源对、5 个训练 seed、8 个视图、2 个生成场景、2 个 timing 回合、18 个条件**。每条件 1,280 条成本记录，合计 23,040 条；canonical round0 的质量每条件 640 条，合计 11,520 条。
- 这 8 个来源对来自原 128 来源队列。它们没有提供 128 来源的时延分布，也不是额外独立的质量复现样本。三视图原计时与八视图补充保持分开，不合并成更大的独立样本量。
- round0 固定为 canonical quality；round1 重放同一生成随机过程。所有条件的输出、实际路径和两个 observer 分数在回合间一致，因此可以把同一实际输出的 raw U 与两个实测回合的成本逐一配对。重复回合不会产生额外独立生成任务。
- 全部 23,040 行状态为 completed，未观察到 generation failure 或 offline scoring failure；两个 observer 无缺失，输出／路径重放完整，生产完整性 gate 为 true。18 个条件、两个 observer 均满足注册的价格曲线资格。该事实只描述本次 census，不证明未来无故障。
- 计时为已驻留模型、batch=1、固定线程和串行请求下的实测 wall/CPU 时间。请求内包含 encoder、策略、真实规划、采样、媒体提交与关闭 ZIP 后回读。预构造输入、冷加载与离线评分在请求时钟外，另由外层进程账目记录；训练总成本不能并入单次 resident latency。CPU ms 是进程 CPU 时间，不应和 wall ms 相加。
- 4,000 次 crossed bootstrap 共用训练 seed 与来源索引，保留视图、场景、回合及策略间的配对。**除开头复述的 A/B 主比较区间外，下文成本及匹配队列比较均为描述性 95% CI**，没有为这组附加比较、价格点和 observer 宣称总体确认性覆盖率。
- 下文 P50/P95 成本差是候选分布的 P50/P95 减参考分布的 P50/P95，**不是逐请求差值的 P50/P95**。正的成本差表示候选更贵，正的效用差表示候选更好。

## 5. 全部前置价格情景：不选择赢家

完整网格为 `λ_ms ∈ {0, 0.00001, 0.00003, 0.0001, 0.0003, 0.001, 0.003, 0.01}`，单位是**任意设定的效用单位／wall ms**。这些数值没有外部校准，不代表美元、业务价值、能耗、推荐价格，也不是 `.002/action` 的换算。

## 7. 可以支持和不能支持的结论

| 主张 | 成本证据判定 |
| --- | --- |
| MPC 的实际规划成本很小或可忽略 | **本次实测不支持**：MPC 平均 wall 约为 feedback 的 4.982 倍，绝对增量区间明显为正。 |
| MPC 的质量提升已经覆盖这些成本 | **未建立**：原始质量区间跨零；是否值得支付需要外部用途和已校准偏好。 |
| feedback 稳定优于强静态的质量／成本组合 | **未建立**：相对 tuned static，平均/P50/P95 wall 与 CPU 成本增加，匹配队列的质量增量仍不确定。 |
| 任意正时间价格都支持 feedback 优于 MPC | **未建立**：低价格区间跨零，点估计最初更有利于 MPC；只有列明的较高价格情景出现正区间。 |
| 可以用高价格网格结果宣布 A/B 主成功 | **不能**：价格分析全部描述性，原 128 来源两条 97.5% 主区间未过的结论不变。 |

| 已证明全局最优、全模态有效或生产资格 | **未证明**：这些问题不由本图文 resident 成本报告解决。 |

本成本章节与 128 来源的 A/B 质量章节分别保留：质量主结论不因八来源子队列、价格、observer 或回合选择而改变；没有新增独立来源、没有将训练／冷启动成本摊入单次 resident 请求后再宣称推理更快，也没有把未校准效用价格解释为经济成本。
