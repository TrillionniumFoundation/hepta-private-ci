# Hepta 多模态生成的风险敏感控制：实现与结论边界

本轮实现检验一个具体、可证伪的版本：Encoder 建立共同条件和初始生成状态；生成器提供会改变后续实际输出分布的动作；控制器依据已经看到的生成结果，在有限预算内选择后续动作；训练与评价使用预先声明的联合任务效用及风险 profile。有限动作的最优控制有严格的数学定义。神经生成器、条件价值函数及跨任务泛化的全局最优性需要额外证据。

本文件给出方法解释。实际数值以 `results/` 的冻结运行回执为准；方法推导、合成测试和真实留出实验属于不同证据。

## 1. 与 Merton 问题的对应

Merton 的连续时间消费／投资问题提供的是“状态、可行动作、随机动力学、预算与终端效用”的建模方式。[Merton 原论文](https://www.sciencedirect.com/science/article/pii/002205317190038X)及其 [MIT 工作论文](https://dspace.mit.edu/entities/publication/45b93de3-551e-475d-9d42-4724ecd84484)可作为这一对应的起点。

在多模态生成中，应将 portfolio 定义为一个联合生成过程的状态与控制安排。文字、图像、声音及视频之间有内容依赖；改变共享语义会改变多个后续输出的分布。因此，仅对已生成的四份结果分配权重，通常不足以表达用户提出的问题。

建议的状态为

\[
S_t=(h_t,z_t^{\rm text},z_t^{\rm image},z_t^{\rm audio},z_t^{\rm video},
      \widehat Y_{\leq t},b_t,\tau_t,m_t,\eta_t),
\]

其中：

- `h` 是共享语义；各 `z` 是模态局部的生成状态。
- `Y` 是已经产生并可观察的真实输出；`b` 是剩余计算预算，`τ` 是时间及提交进度。
- `m` 是可用输入模态、信任和缺失标记；`η` 是必要的历史摘要或隐变量后验。

Encoder 给出 `S0 = I(E(x))`。持续条件可以通过注意力、条件缓存或其他有界接口提供。只用 `S0` 可能在一个确实充分的状态表示下成立；这是一项需要验证的结构假设。单次推理时清除条件缓存的消融，只能识别已训练模型对该缓存的依赖，不能回答重新训练的“只用初值”架构是否同样有效。

动作可同时包含共享语义修正、局部模态推进、跨模态耦合、额外观察、停止与提交。必需模态、已提交内容不可逆、内存和延迟上限应进入可行域 `A(S_t)`。效用中的软惩罚不能代替所有硬约束。

## 2. 一个明确的 NDU profile

本轮将风险敏感效用实例化为固定 `γ` 的指数确定性等价：

\[
C_\gamma(X)=-\frac1\gamma\log E[e^{-\gamma X}],\qquad C_0(X)=E[X].
\]

`X` 是整个输出组合的联合任务效用减去成本。一般的 Hepta NDU 契约还可以使用其他合法 profile；本轮结果只对应声明的实例。

对于终端效用 `U` 及剩余成本，固定生成器的因果控制问题为

\[
V_t(h)=\sup_{\pi\,\text{adapted}}
C_\gamma\!\left(U-\sum_{k=t}^{T-1}c_k\mid H_t=h\right).
\]

这里的 `h` 表示公共历史。私有目标、未来随机数和事后最优路径不能成为在线策略输入。一个神经特征向量是否足以替代完整历史，需要单独检验。

令 `Z = exp(-γV)`，正确的递推是

\[
Z_t(h)=\min_{a\in A(h)}
E[e^{\gamma c_t}Z_{t+1}(H_{t+1})\mid h,a].
\]

若真实任务目标在终止时仍不可观测，边界为

\[
Z_T(h)=E[e^{-\gamma U}\mid h],
\]

不能把它换成 `exp(-γ E[U|h])`。随机成本与相应的下一状态保留在同一个条件期望中。

固定 `γ` 下的条件指数效用通过条件期望的塔式法则满足这一时间一致递推。改变风险 profile 或加入其他路径约束时，应重新推导相应递归结构。条件风险控制的一般背景见 [Ruszczyński 的风险厌恶动态规划论文](https://optimization-online.org/wp-content/uploads/2009/12/2497.pdf)。本仓库的具体有限模型证明、隐藏目标处理与适用假设见 [DYNAMIC_RISK.md](DYNAMIC_RISK.md)。

### 连续时间形式的用途

如果某一段潜状态确实可由受控扩散近似，

\[
dS_t=f_\theta(S_t,a_t)dt+G_\theta(S_t,a_t)dW_t,
\quad \Sigma_a=G_aG_a^\top,
\]

在 Markov、正则性及有效边界等条件下，对确定的瞬时成本率 `c`，指数变换给出的价值方程为

\[
0=\partial_tV+\sup_a\left\{
f_a^\top\nabla V+\tfrac12\operatorname{tr}(\Sigma_a\nabla^2V)
-\tfrac\gamma2\nabla V^\top\Sigma_a\nabla V-c_a\right\}.
\]

这是此处给出的形式推导；本轮没有数值求解该 PDE。离散 token、输出提交、预算跳变和音画时钟通常更自然地构成混合或离散控制过程。有限动作 Bellman 递推因此是更直接的第一实现。多模态任务也没有自动获得金融资产模型中的自融资或可交易假设。

## 3. 训练生成器与训练控制器分别做什么

固定生成器参数 `θ` 后，拟合 `Z(h,a)` 并选择条件矩最小的动作，是推理控制问题。改变 `θ` 则改变输出概率、状态转移及整个控制问题。

理想的联合目标可写为

\[
\max_{\theta,\phi} C_\gamma\left(U(Y_{\theta,\pi_\phi})-C_{\theta,\pi_\phi}\right),
\]

但非凸参数化和有限数据不能自动给出全局最优解。实际可采用分阶段或交替优化，并在新的冻结来源上评价每个阶段。本轮先训练生成器，再冻结生成器并拟合控制器，尚未执行联合参数优化。

### 本轮实际训练目标

令 `L = -U`、`Mθ = E[exp(γL)]`、`Aθ` 为常规联合生成辅助损失，实际目标是

\[
F(\theta)=\frac{M_\theta-1}{\gamma}+\lambda A_\theta,
\quad \gamma=2,\quad\lambda=0.05.
\]

风险中性实际输出臂使用 `γ=0` 的连续极限和相同辅助损失。另一个 SFT continuation 臂继续常规联合生成训练。三臂从同一种子对应的共同 warm start 出发。

当 `λ=0` 时，最小化该指数矩等价于最大化 joint CE。保留辅助项时，必须报告上述实际目标：

\[
\nabla F=M_\theta\left[-\nabla C_\gamma(U_\theta)+
\frac{\lambda}{M_\theta}\nabla A_\theta\right].
\]

这给出了当前位置的梯度尺度关系；它不是另一个带有可变系数 `λ/Mθ` 的目标函数的完整梯度。常数平移效用会改变指数矩相对于辅助项的权重，所以效用尺度也属于协议。

实际 Bernoulli 像素和自回归 categorical token 的终端效用由保存并重新读取的 PNG／UTF8 输出计算。离散输出采用 score-function 梯度；同条件的其他独立样本提供 leave-one-out baseline。对当前固定生成程序，可以使用终端实际输出的联合 log probability。将训练扩展至反馈动作后，必须计入会影响轨迹的动作概率和生成概率；不能直接复用固定程序的终端公式。

Joint task/noise CE 与先按任务计算条件 CE 再取平均的目标不同。主评价与训练声明使用相同的 joint 定义；每来源／视图的条件 CE 另外报告。训练 seed 的波动在统计外层处理，不作为生成风险直接混入指数期望。

## 4. 本轮 A/B 的可识别比较

核心 `2×2` 比较 SFT continuation／NDU 输出训练与 fixed／feedback 推理。额外的 `output_mean` 训练臂保持实际输出评分及辅助损失方式一致，用来识别从风险中性到声明风险 profile 的增量。

预先声明的两个主比较为：

1. 固定推理下，`output_ndu` 对 `output_mean` 的净 joint CE 增量。
2. `output_ndu` 下，feedback 对 fixed 的净 joint CE 增量。

四格交互直接计算四个 CE 的差中差；对逐输出差值先求 CE 会改变估计对象。

其他机制比较如下。

| 比较 | 能识别的内容 |
| --- | --- |
| 反馈与只分配 image/text 动作 | 增加共享内容动作及相应价值拟合后的整体差异 |
| 固定 semantic/couple 与夹住共享状态 | 该固定路径上所有共享状态更新的因果贡献，包括 couple 的共享更新 |
| feedback 与 draft-masked feedback | 当前特征、拟合方法下，已产生的真实草稿信息是否有用 |
| feedback 与 one-shot route | 动态反馈与只按根状态选完整路径的差异 |
| 风险中性与风险敏感反馈 | 固定生成器下的控制目标变化 |
| 模态局部奖励与联合任务奖励 | 去掉跨模态一致性项并重新归一化后的差异；前者仍使用联合指数风险 |
| 持续条件与 initial-only 推理干预 | 该生成器推理时继续访问条件的作用 |
| 快速反馈与独立随机流 MPC | 实际额外规划的质量及成本变化 |

这些比较没有把现有 v6 的 surrogate 风险聚合和 content gate 训练同时改变，然后统一归因于一个“NDU 训练”标签。本轮实际输出训练是另一个明确版本；旧 v6 的结果继续保留。

## 5. Oracle 诊断与可达到的控制收益

实验 A 在同一个固定生成器、初始草稿、候选动作和随机过程下实际执行 21 条有限路径。Primary oracle 按真实净效用逐样本选最好结果，只在所有公共策略选择封存后产生。

因此它是这组潜在路径结果的事后诊断上界。它可以量化动作集合中的收益空间，以及允许共享内容动作相对只分配计算的差异。若 oracle 相对固定策略仍没有收益，应先审查动作、任务和目标是否具有可控空间。

较大的 oracle 差距不能单独证明条件价值或策略学习失败。例如，隐藏公平比特 `T` 决定两个动作的效用 `U_A=T`、`U_B=1-T`；选择前没有任何信息能揭示它。在 `γ=2` 时，任何因果策略的 CE 都是约 `0.28311`，事后 oracle 是 `1`。约 `0.71689` 的差距全部来自不可提前获取的信息。需要条件风险模型、可观察信息干预或可计算的因果参考值进一步分解差距。

Primary oracle 的选择用 secondary observer 重评分后，只是迁移评价；它不是 secondary 的最优上界。改变动力学的 clamp/context 干预也不属于原生 21 路径的同一个上界。

平均 calibration 残差、有限 replay 的拟合误差和合成数学测试都没有建立神经条件价值函数的统一误差界。若要给出策略接近最优的证书，仍需在相关可行历史上证明模型正确性和误差约束。

## 6. 成本、时序及证据边界

控制目标中的 `0.002/action` 是效用单位的代理项。实际 CPU、工作计数、媒体落盘、回读、P50/P95 和训练总成本独立记录。Resident episode 计时包含当前请求的 encoder、策略、规划、实际采样与媒体交付；模型冷加载及离线评价另列，完整进程账目同时保留这些成本。

完整质量评价包含 128 个来源对。计时子队列只有其中预先选定的 8 个来源对。对质量和实际成本的联合比较必须在同一个子队列上进行；其结果不能自动代表全部 128 个来源的延迟分布。

若使用成本价格 `λ_ms`，应计算 `CE(U - λ_ms × actual_ms)`，把随机成本留在指数期望内。`CE(U) - λ_ms × mean(actual_ms)` 一般是另一个量。任何价格网格都是明确的情景分析，需要外部用途才能解释其货币或业务含义。

真实时序扩展分两层积累证据：先验证实际媒体、时钟、缺包、因果观察、不可逆提交与完整成本；再验证神经生成的内容、共享语义的延迟收益和独立音唇一致性。GRID 源时间戳的 AV 流恢复实验是第一层。其网络时间由冻结模拟过程产生，MKV 保留源媒体时间线；零源时钟误差、成功回读或网络缓冲收益均不足以证明语义生成或音唇同步学习成功。

当前评分器通过的是预先声明的原始图像与 Bernoulli 扰动资格检查。两套冻结评分器的复核能发现部分奖励利用和测量敏感性，仍不是对任意生成分布的无误差外部认证。

来源、训练 seed、视图和生成场景的依赖保留在成对统计中。重复播放、恢复验证、两个 observer 以及候选路径不会增加独立来源数量。五个训练 seed 的 bootstrap 区间还具有有限样本覆盖率限制。

## 7. 与原生 Hepta owner 的衔接

本轮 Python 研究执行器保存真实生成、观察、动作选择、模型身份及成本证据。接入原生 owner 时，应沿仓库已有的 inference、Neuron、terminal learning、plasticity 与 evaluation 接口提交各自契约需要的证据；研究回执本身没有授予生产权限。

旧原生 Neuron 校准及 journal 前置条件的实际失败记录仍见 [v6/GATES.md](../v6/GATES.md)。新的图文风险训练或媒体资格通过不能自动消除那些失败。外部 observer trust、目标主机资源资格、有效 journal/checkpoint、参数映射与生成器梯度归属需要各自实际建立。

本轮可以给出“在预先固定的模型、动作、来源和成本口径下有没有观察到收益”的结论。全模态大模型的规模扩展、可认证的全局最优，以及原生生产资格，应由对应的新证据推进。
