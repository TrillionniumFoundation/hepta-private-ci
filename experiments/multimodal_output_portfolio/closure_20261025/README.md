## 1. 原始 V6：先确认模型，再测实际输出

[V6报告](v6_oracle/REPORT.md) 恢复的是历史 full-002 的 seed17 NDU base + gate，checkpoint SHA为 `8fa76a13cdeee48e41b84e29211659a065d9573e2fdfecc4281f882248b508b6`；没有重新训练或用V7模型替代。强固定策略只在旧dev上选定。新64对、每对两个初始噪声，实际产生12,800个终端输出及1,280次可行策略请求，全部策略输出和最终状态与对应枚举端点相同。

使用gamma=2的原始效用certainty equivalent（CE），来源对配对bootstrap的描述性95%区间为：

| 对比 | CE差 | 95%区间 |
| --- | ---: | --- |
| full oracle − 原risk-aware策略 | +0.050821 | [+0.021408, +0.089882] |
| full oracle − 同初态allocation oracle | +0.027687 | [+0.007505, +0.056300] |
| 原risk-aware − dev选择的strong fixed CE | +0.017803 | [−0.031643, +0.063450] |

前两项确认这棵有限真实输出树有内容余量。第三项没有证明现有控制器能可靠变现余量。oracle读取私有Target及所有已实现输出，且没有承担枚举成本；本报告不把它当作可行策略或条件最优值。

## 2. 动作差与成本：保留负结果

[控制报告](control/README.md) 的481维公共输入包括当前latent、实际像素摘要、实际token投影和剩余horizon。critic学习动作相对停止的指数矩差；H2后续决策由其他来源fold拟合，避免把已经实现的最优grandchild当作在线回归目标。蒸馏actor与critic一致且置信度够高时才走廉价动作，否则实际调用原cached强控制器。

主检验使用256新来源、五个拟合种子，完成81,920个实际请求。主检验81,920＋历史新future 10,240＋探索性对照40,960＋独立修复确认3,072＝136,192个实际请求，零执行失败。修复确认使用另外96新来源，独立新来源总数为352；补充策略行和新随机future没有重复增加N。

| 主检验策略 | 原始CE | 严格joint success | 平均请求wall |
| --- | ---: | ---: | ---: |
| cached强控制器 | 0.163550 | 54.1211% | 12.9716ms |
| 配对critic | 0.162466 | 53.0127% | 10.4049ms |
| 蒸馏actor | 0.167432 | 53.3740% | 9.2467ms |
| 开发集选定gate | 0.163550 | 54.1211% | 13.1473ms |

五个gate全部选中不做廉价预检查的fallback；20,480个配对请求的动作路径和输出与teacher完全相同。因此gate这行不能支持新控制算法收益。独立actor较快，但严格成功率下降0.7471个百分点，名义97.5%区间为[−1.4551, −0.0048]个百分点。

容量修复将actor从32hidden/600steps增加到预先规定的128或256hidden/2000steps，仅使用旧fit/selection。训练动作拟合从68.6%提高至最高86.1%，selection只提高至54.2%，泛化差距仍大。唯一选出实际廉价分支的seed17候选在另96新来源随机交错确认：CE差+0.001786，区间[−0.009143,+0.013000]；成功率差−0.2604个百分点，区间[−1.1068,+0.5868]；wall差+0.1860ms，区间[−0.0752,+0.4867]。三道原门均未通过，未追加新来源调参。

真实请求计时包含公共特征、模型／规划、回退重叠、生成、持久化commit、媒体写入与回读；完整子进程另外覆盖导入、来源、观察评分和分析。成本曲线使用实际观测值，保留共享主机长尾。nominal每动作0.002不会被说成真实时间或能耗。

## 3. 哪个机制带来收益

[因子报告](factorial/REPORT.md) 在256新来源、三个已拟合种子上，枚举并回读516,096个真实输出，产生98,304个策略行。新训练四个基础模型；同一种子内两种基础目标具有完全相同初始化、batch/noise/action日程与更新数。两种gate也保持同样公共输入与训练日程。

| 主效应 | CE差 | 七项比较调整后的名义99.2857%区间 |
| --- | ---: | --- |
| 基础风险损失 | +0.00557869 | [−0.00120601,+0.01284943] |
| gate风险目标 | +0.00108930 | [−0.00216023,+0.00446767] |
| 动态执行 | **+0.01347725** | **[+0.00722054,+0.01979210]** |

动态因素保留gate选择的第一步，然后根据当前真实draft重选第二步或停止，三个seed均为正；第二个独立observer得到+0.01300166。所有困难视图留在严格分母。这里用的是统一entropic critic，因此包含算法改变，不能把结论扩大成已完全剥离决策规则后的纯反馈信息价值。

在控制研究另行冻结的探索性比较中，强反馈控制器对fixed allocation的CE差为+0.019399，97.5%区间[+0.004625,+0.034722]；对强非反馈为+0.012322，区间[−0.000272,+0.025082]。这些额外对照在主收集开始后登记、分块计时，不能升级为事前主检验或随机交错成本优越证据。

## 4. 实际四模态：本地内容／时间门通过，声音副审未闭合

[媒体报告](media/REPORT.md) 使用真正的声音和视频输入编码器，将公共后验接到共享state，再执行文字、图片、训练VAE声学decoder及图像条件运动decoder。实际WAV和带H.264/ALAC流的MP4由codec编码、解码与回读，20帧在0.0至1.9秒的presentation clock上与16,000个8kHz音频样本对齐。视频具有真实的时空状态，不能靠重复静止帧通过检查。

初始声学生成和早期observer资格失败均保留。有限修复只用既定generator/reward角色训练，audit从未参与反向传播。最终采用原2秒规格的训练VAE，55项执行身份在读取最后64对与FSDD test前冻结；仅执行一次正式收集。

| 公共输入模式 | 本地数字评分器／时钟联合成功 | 来源对分母 |
| --- | ---: | ---: |
| 图片 | 49 / 64 = 76.5625% | 64 |
| 文字 | 64 / 64 = 100% | 64 |
| 声音 | 62 / 64 = 96.875% | 64 |
| 视频 | 55 / 64 = 85.9375% | 64 |
| 声音＋视频 | 59 / 64 = 92.1875% | 64 |

hard与soft公共后验两种桥接各执行320份输出，得到相同的联合成功计数；不能据此宣称soft更好。五种输入与两种桥接复用相同64来源对，640是实际输出数，不是独立样本数。图片模式只略高于预设75%的样本工程门；不能把一次样本门通过解释成总体成功率的置信下界超过75%。

独立mel auditor在300个test录音上准确率96.33%，音频输入encoder为98%；条件音频和视频检查均通过，静音、声音事件交换、视频事件交换、重复帧、缺模态五种实际负控全部拒绝。整段运行wall430.150s，Python和codec子进程CPU约422.904s；单行计时包含推理与输出codec，输入媒体构造／读取、模型加载在整段成本中，不能将重复计入共享encoder的逐行计时相加当作整段成本。

**最终独立声音副审提供了明显的负证据。** 冻结Whisper读取同64对真实波形，对真实输入识别55/64（85.94%），对VAE生成输出仅22/64（34.38%），生成逐digit为47/128。它不替代原主检验，也不是人类评分；但生成与真实输入的差距使“自然可懂语音／广义四模态质量已闭合”的说法不成立。额外副审wall70.350s、CPU约70.26s，另行保留，不含在canonical430.150s之内，也没有增加独立N。没有根据该最终负结果调整模型。

此前修复后的12对开发Whisper输出为7/12，真实录音输入为9/12。另一条Piper参考profile虽可生成可识别载体，其通用ASR真实录音资格未通过，因此被阻止开启最终集。正式主结果没有靠替换observer或延长输出时钟取得。当前跨模态桥接仍是分阶段训练，尚未端到端联合优化四个decoder的NDU。

## 5. 原生执行闭环与生产边界

[原生报告](native/REPORT.md) 直接编译执行固定产品提交中的 `AgentdNeuronOwner`。真正的在线顺序为：公共prefix进入模型port，owner执行head及原准入门，先同步写入动作，再由实际generator产生PNG/text，独立observer读取媒体，原 `NduProjectionStore` 提交后验utility，下一tick或恢复读取已提交状态。没有把未来结果预先送入选动作接口。

新64对共128个候选forward，37对获准后真实生成并提交观察，27对拒绝。37是覆盖数，不是37个正确答案。20项非法输入／outcome检查、pending decision后SIGKILL恢复、正常提交后重开均通过。runtime p95/p99为818/1150µs，整个owner.tick为1422/1662µs；保持原3000/8000µs门。原生transient为13,016B，整个Python/Torch流水线RSS约381MiB，两者不可混用。

本轮只把原本有资格的correctness head接入上述闭环，选择规则是获准动作中的概率argmax。NDU已参与后验记录、下次tick绑定与恢复，尚未变成新action-value策略的生产优化器。完整Agentd daemon、模型服务transport、正式Dataset/Generator/Observer/Evaluator身份和生产信任根都没有凭研究脚本自动获得。`authority=deny_all`保持不变。

当前Rust源已按仓库原始 `just fmt` 格式化；已执行主结果的原始源码、binary和protocol保持其原SHA，另有仅旧dev的格式化等价验证。没有将发布格式化版本的摘要填回历史记录。

## 6. 来源、复现与结论范围
