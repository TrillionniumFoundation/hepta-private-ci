# 基础风险、计划风险与动态执行的完整因子对照

## 结论

在本轮独立分配的 **256 对来源**、三个已拟合种子上，能够单独通过预登记主检验的是动态执行：在同一 gate 已选定第一步后，依据当前真实 draft 重新选择第二步或停止，平均原始输出 certainty equivalent（CE）增加 **0.01347725**；七项比较校正后的名义区间为 **[0.00722054, 0.01979210]**。第二个独立 observer 得到同方向的 **0.01300166**。基础风险损失和 gate 风险目标的主效应未通过主检验，不能把动态收益归功于 NDU 训练已经优于基础训练。

这回答的是一个有界模型和有限动作过程中的机制问题。它不证明一般全模态模型的最优性，也不是完整随机 FBSDE、原生在线执行或实际成本覆盖的证据。

## 实际执行了什么

实验完全交叉三个二水平因素，共八个组合；每个组合在三个种子上执行：

| 因素 | 水平 0 | 水平 1 |
| --- | --- | --- |
| 基础训练 | mean teacher-forced surrogate loss | conditional latent-noise entropic surrogate loss |
| 计划 gate | 有限实际输出 mean 目标 | 有限实际输出 entropic 目标 |
| 动态执行 | 执行 gate 预先选择的完整计划 | 保留第一步，在当前 draft 上重选第二步／停止 |

基础模型使用当前 ABC/V7 的共享 source-slot 生成器，承接 V6 的真实文本和图像生成机制。这里没有把 V7 结果倒写成原 V6 checkpoint 的结果；原 V6 的精确冻结诊断单列于本轮 `v6_oracle`。

seed 17 复用原始成对基础模型；seed 29、43 各重新训练两种基础目标，共新增四次 2000-step 训练。每个种子内部两臂的初始化参数、batch/noise/action 日程、更新数和配置逐项相同。旧 seed 17 使用两个 Torch 线程，新 seed 29、43 使用一个线程；结论条件于这三个已拟合种子，不把它们冒充大规模随机种子总体。

每个冻结基础模型枚举 stop、四个单步动作、十六个两步动作，共 21 个实际输出节点。动作是 `refine_semantic`、`refine_image`、`refine_text`、`couple`。每个节点实际采样二值像素和自回归 token，持久化为无损 packed-pixel/token 档案，关闭后重新打开、核对 SHA，再由两个冻结独立 observer 评分。不是对预测分数取最大值。

正式执行共生成并重新打开 **516,096 个输出**，为八组合×三种子选取 **98,304 个策略行**。独立来源单位仍只有256对；视图、随机场景、动作节点、模型和策略行均未增加统计 N。

## 如何隔离训练与评估

gate 和最后一步 critic 只用旧 `forecast_fit[0,128)` 来源。强 fixed 与 allocation-only 序列只在另外的旧 `forecast_calibration[0,64)` 上选择。新来源来自原预留池的 pair `[0,256)`，通过未改变的根角色检查器读取；它们没有进入拟合、阈值选择或超参数调整。

训练 gate 的公共输入为384维当前 latent，不含 Target、source ID、future 或 observer 输出。同一来源与视图的两个 scenario 具有完全相同的 gate context，真实输出差异来自已登记的生成随机流。两种 gate 从相同参数和小批次日程开始，唯一变化是目标。

critic 对每个当前 child 的公共 draft 预测五个下一步指数矩：停止及四个动作。它没有用事后最优 grandchild 作为回归标签。最后一步的 semantic 动作只改变 latent 而保留现有实际输出，在正动作价格下被停止严格支配，因此按模型定义排除。

动态选择在函数实现中只读取 root，以及已经选中的第一步所对应的 child。独立审查把其他 child 特征全部毒化，选择不变；改变已选择 child 的当前 draft 能改变第二步，同时第一步不变。所有 public features 都在私有 observer 读盘评分前构造。

## 主结果

输出效用使用原独立评分定义。每个 cell 的原始输出 CE 为

\[
\mathrm{CE}(U)=-\frac12\log\mathbb E[\exp(-2U)].
\]

主效应是其余两个因素均衡平均后的 cell CE 差。七项包括三个主效应、三个二因素交互、一个三因素交互；同用标准化 parity contrast。二因素数值为通常未归一化 DID 的一半，三因素为 DDD 的四分之一。

| 主检验项 | CE效应 | 名义99.2857%区间 | 正向质量门 |
| --- | ---: | --- | --- |
| 基础风险损失 | +0.00557869 | [-0.00120601, +0.01284943] | 未通过 |
| gate风险目标 | +0.00108930 | [-0.00216023, +0.00446767] | 未通过 |
| 动态执行 | **+0.01347725** | **[+0.00722054, +0.01979210]** | **通过** |
| 基础风险 × gate风险 | -0.00013531 | [-0.00319381, +0.00298657] | 未通过 |
| 基础风险 × 动态执行 | -0.00045254 | [-0.00460261, +0.00366465] | 未通过 |
| gate风险 × 动态执行 | +0.00010684 | [-0.00191905, +0.00228448] | 未通过 |
| 三因素交互 | -0.00101186 | [-0.00315705, +0.00101984] | 未通过 |

区间来自4096次配对 source-pair cluster bootstrap，所有 cell、种子、视图和 scenario 一起保留，以七项 Bonferroni 分配名义错误率。这是条件于已拟合种子的名义 bootstrap，不提供有限样本覆盖保证，也没有假定未知 MNIST writer 的独立性。

动态效应在三个种子上分别为 **+0.01122865、+0.01298927、+0.01621382**。第二个独立 observer 的动态效应为 **+0.01300166**，描述性95%区间 **[+0.00834763, +0.01768574]**；它不替代主 observer 的七项检验。

跨 cell 平均原始 CE 从静态的 **0.14718671** 增至动态的 **0.16066396**。严格 joint-fact success 从 **51.5137%** 到 **51.9267%**，差 **+0.4130个百分点**；这项 success 差是描述性辅助指标，不能代替 CE 的预登记主结论。平均 continuation 动作数从 **1.68355** 降至 **1.52722**。

所有八种视图，包括严重缺失和信息不足样本，都留在严格分母中。没有用拒绝或删除困难任务提高成功率。

## 事后上界与真实可达收益

真实21节点枚举还给出了冻结模型内的事后上界。六个基础模型的该上界 CE 约为 **0.465–0.472**，开发集选定 strong-fixed 在新来源上约为 **0.137–0.155**。这证明有限动作空间内存在更好的实际候选内容，但最大化者知道私有 Target 和已经实现的随机结果。它不能直接作为可部署策略、可实现条件 regret 或全局最优性证明。

动态策略是只读公共当前状态的有限控制器，主效应比这个事后上界小得多。这一区别保留在报告中，不能将上界差额当作模型未来必然能实现的收益。

## 成本与解释限制

正式完整枚举的精确 child-process 成本为 **536.750s wall、536.888s CPU、557,088,768B peak RSS**，包括启动、导入、来源读取、真实生成、存盘、回读评分和退出。它执行了所有候选分支，因此不是部署一个策略的请求成本。

新增基础训练的进程内计时分别为 seed29 **369.220s wall / 368.596s CPU**，seed43 **375.762s / 375.210s**。三个 seed 的 gate/critic 拟合与开发枚举进程内计时分别为 **102.122s / 101.988s**、**110.809s / 110.686s**、**109.104s / 108.975s**。这些训练计时从模块内部开始，不能伪装成包含所有解释器导入的精确启动到退出成本。原 seed17 的历史训练成本另存于训练报告。

训练与控制使用每步0.002的登记动作价格，但这只是 nominal work regularizer，不是测量所得的毫秒或能耗。真实请求成本与成本调整后的 CE 在单独的 `control` 在线研究中测量。

动态因素包含“读取当前 draft＋使用统一 entropic critic 重选第二步”的整体干预。mean gate 分支第二步也使用这一个 risk critic，所以这里不能宣称测出了剥离所有算法变化后的纯信息价值。gate 训练 softmax 混合分布、部署采用 argmax；优化的是有限小批次目标，不提供总体 NDU 梯度无偏性或所训练混合 CE 的全局最优保证。
