# Native semantic portfolio execution

This experiment connects the selected, frozen semantic posterior model and a
finite external-evidence controller to the **original** `AgentdNeuronOwner`.
The owner source, sparse dynamics implementation, calibration residual,
resource ceilings and `deny_all` authority are unchanged. This is an actual
research execution adapter; it does not deploy or authorize a product daemon.

## Execution boundary

The Python host reads a public input and executes the frozen image, text,
speech or temporal-video encoder. It sends 176 bounded public features to the
native process: two 78-dimensional feature vectors and two 10-class raw
probability vectors. Neither private targets nor source identity labels enter
the posterior or value model.

Rust executes the selected 78 → 32 → 10 residual posterior network for each
digit and forms the registered factorized 100-class target distribution.
Literal text bypasses the residual network. The selected candidate's residual
bound and all parameters come from its exact exported model file; this phase
does not refit those parameters. The native controller evaluates the 100
semantic endpoint codes and, when external speech is available, acquisition.
Actual owner ticks supply the current admissibility mask. The chosen action
is committed to a durable controller log before the host executes it.

For an emission, the host calls the frozen canonical renderer anew. It writes
actual UTF-8 text, a PNG, a PCM WAV and an MP4, decodes the physical files, and
observes their contents. Rust verifies all four byte identities, the PNG and
WAV profiles, and the exact presentation clock before committing the outcome
to the original NDU projection store and controller history. Full MP4 decoding
and the frozen image/speech observers run in the pinned host. They are not
claimed to have been ported into Rust. The host is a trusted, measured component
of this research pipeline, not a cryptographically attested hostile-host
security boundary.

The presentation has 32,000 mono samples at 8 kHz and 20 frames at 5 fps over
four seconds, with the second event at sample 16,000 / frame 10 / two seconds.
Actual input video also passes through a physical codec in the shared case
reader. These are bounded two-digit tasks with real source images and speech,
and constructed digit motion. They do not establish unrestricted natural
audio/video understanding or general large-model scalability.

## Finite objective and its limits

The separately measured 100-endpoint output table was obtained by actually
rendering and observing all codes. For this frozen renderer it is exactly

\[
U(a,t)=K(a,t)=\mathbf 1\{a=t\}.
\]

`K` denotes terminal strict success. At equal emission cost, immediate mean
utility and entropic utility therefore rank semantic codes identically. The
experiment makes no independent risk-training claim from that ranking.

With risk coefficient 2 and emission cost `c_e = .002`, the immediate moment is

\[
M_e(a\mid q)=e^{2c_e}\{1-(1-e^{-2})q_a\}.
\]

Operation confidence is a separately fitted, frozen monotone mapping of
predicted terminal strict success. Seven raw-score cuts and weighted
pool-adjacent-violators calibration are fixed before fresh-source execution.
The original owner evaluates its `.75` confidence floor and all original
activity, projection and resource gates. Content screening avoids ticking
the many candidates that provably fail the confidence floor. The first actual
owner tick still executes and charges the frozen native layers. A missing or
entirely low-confidence request executes a real rejecting owner tick.

For image/video routes, the other root option is to acquire the registered
external speech. The host does not read that waveform until the native acquire
decision has been committed. The actual frozen input CNN returns a class pair
`o`. Rust updates

\[
q_o(t)=\frac{L(o\mid t)q(t)}{\sum_j L(o\mid j)q(j)}.
\]

The likelihood is fitted on previously used real speech and is a Kronecker
product of two digit confusion likelihoods. Its conditional independence and
distributional accuracy are assumptions requiring evaluation, not facts proved
by matrix normalization. In particular, two utterances from the same speaker
can have correlated errors.

A metadata audit subsequently identified a stronger, concrete mismatch: four
of the 40 ID qualification pairs and eleven of the 170 registered confirmation
pairs use exactly the same waveform bytes on both sides. The deterministic
input CNN must return identical labels for those aliases. The frozen Kronecker
likelihood nevertheless assigns positive probability to unequal observed labels
in the corresponding equal-target columns. Independence is therefore known to
be false for that subset. The registered policy is retained for this phase;
those cases are not removed and the likelihood is not repaired using the
confirmation panel. An alias-aware joint observation law is a remaining
research requirement.

The acquisition backup enumerates all 100 possible observations, applies the
same frozen future confidence mapping, and includes future rejection as utility
`-1` with strict success zero. The acquisition cost `.002` stays inside the
exponential expectation. If an actual later owner gate refuses emission, the
actual episode is retained as a terminal failure. Future stochastic execution
time or resource rejection is not modelled or certified. The exact arithmetic
claim is conditional on the supplied posterior, likelihood, measured endpoint
table, fixed cost law and specified continuation policy. It is not a solution
of an unrestricted stochastic owner-control problem.

There is no initial delivered bundle, so a retained-output stop action is not
silently invented. Text/audio routes use one decision. Audio is not acquired a
second time and treated as independent evidence. Own generated media update
delivery observations and numeric context; they do not update the hidden-target
posterior.

## Numeric NDU path

The public delivery proxy is

\[
u=1-\mathbf 1\{\text{invalid caption}\}
     -\mathbf 1\{\text{crossmodal or physical delivery disagreement}\}.
\]

It is not private task utility: a consistently wrong output can receive `+1`.
The observed scalar is both bound into the original NDU projection identity and
fed numerically into a known-context coordinate on the next owner tick. The
same known value appears in drive and prediction at that coordinate, preserving
the original correctness residual at coordinate zero. It is explicitly not
presented as a prediction of a future latent variable.

Public eligibility readback is bound into the next request, and actual original
owner admissibility is used by the native portfolio choice. The conditional
semantic value forecast has no invented coefficient that forces this context
to change the answer. Registered positive, zero and negative transport-history
probes actually generate files first, preserve original/delivered caption
identities, and then observe the delivered bytes. The final old-source smoke
observed three distinct pure temporal-state digests with the same prediction
residual, while the next selected code remained unchanged. This establishes an
executed numerical state path and records the absence of demonstrated policy
benefit in that contrast.

In the formal two-stage episodes, acquisition writes numeric delivery context
zero and the only emission ends the episode. Consequently, a nonzero delivery
modulator has no subsequent action to influence within that formal episode.
The formal primary comparison tests external-evidence control. It cannot
identify a benefit from nonzero numerical NDU feedback. A task with subsequent
decisions after an actual delivery observation is required for that separate
research question.

## Source and qualification boundaries

Each independent source/policy request receives a new owner root. Its actual
external-evidence continuation remains in that owner. Pending decisions survive
graceful process exit and are restored only if descriptor, binary and the
native/controller/NDU frontiers match. Cross-store partial commits fail closed.

The old five-refinement-action qualification is not reused. With 100 mutually
exclusive semantic endpoints, a `.75` coherent raw confidence threshold allows
at most one endpoint per state, so the old requirement that 25% of candidates
be admitted cannot describe this action family. The new preregistered
nonemptiness measure is the fraction of ID requests with at least one actually
admitted action, with a `.25` minimum. Candidate-level coverage is still reported.

Dynamic and the old-development-selected `fixed_late` reference each execute
160 ID requests from the same ten untouched writer/speaker groups and 600
all-input-missing source requests. The two policies have separate qualification
results. Routes, repeated views and policies do not multiply independent source
units. The main selected ECE uses the initial chosen operation's confidence
against actual strict success at the end of its entire episode. H1 ECE is
separate. Pooled code ECE uses the already measured canonical endpoint table as
a counterfactual; it is not 100 fresh output generations per ID request.

All-missing requests contain the same absent public numerical input and fresh
numeric owner state. Separate original speaker identities do not make these
600 different model inputs. Duplicate input/state/RNG groups, structural
rejection and the conditional binomial bound are reported separately. That
bound depends on the declared source-request sampling interpretation and cannot
certify natural OOD robustness. The allocated source census itself is a fixed
hash-based sample without replacement, so an IID superpopulation interpretation
is an explicit modelling assumption.

Independent failures remain failures. `qualified` startup requires that
policy's own complete verification. A failed policy may complete the fixed
research comparison in `qualification_collection` mode; that mode does not
turn a failed independent result into a qualification pass. Operational
exceptions and ordinary owner refusals are preserved separately.

## Primary comparison and cost accounting

The reference is selected once from `fixed_initial` and `fixed_late` using old
development observations. That selection composes the actual old CNN labels
with the actually enumerated renderer endpoints offline; it is not an extra
owner execution study. Fresh-source outcomes cannot change that reference.

The primary comparison is dynamic minus `fixed_late` on all 340 paired
image/video cases, in 85 matched writer/speaker clusters. The reported endpoint
is entropic certainty equivalent of actual output utility minus `.002` per
emission and `.002` per acquisition, with utility `-1` for no delivered output.
The paired source-cluster bootstrap uses seed 46117 and 10,000 replications.
The two-sided interval is 98.3333333333%, as registered for the three correlated
research families. Its lower bound must be positive to pass the primary gate.
Audio/text functional execution is reported separately and cannot substitute
for that primary result.

The `.002` amounts are declared utility costs, not measured seconds converted
into utility. Actual owner, planning, encoding, external-waveform, codec,
observer and whole-request costs are retained. Process launch and completion
receipts record wall time, CPU, peak RSS and shared cgroup observations. Runtime
economic sensitivity is secondary and keeps the registered efficacy criterion
unchanged.

### Resource-gate scope

The original resource envelope applies to native candidate ticks, not the full
four-modality request. The retained profile has a 3,000 microsecond p95 and
8,000 microsecond p99 ceiling for native resource samples, a 512 KiB transient
allocation ceiling, a 1 MiB checkpoint ceiling and a 4x journal write-amplification
ceiling. In the original `NeuronRuntime::tick`, `execution_micros` times the
in-process inference-control call, sparse state/journal work and calibration.
The runtime sets abstention when this measured interval exceeds 8,000
microseconds or its other checked limits fail. This is a check after work was
performed, not a preemptive 8 ms cancellation of the request. The p95 condition
belongs to the supplied-sample resource summary; it is not a separate 3 ms
deadline imposed on every request.

The experimental `online.rs::tick` also measures the complete `owner.tick` call
as `owner_us`, and uses its observed Rust allocator peak for the additional
transient-allocation admission check. `owner_us` and `native_execution_us` are
different timing boundaries. The allocator values and `whole_owner_peak_bytes`
are native allocation measurements, not Python/Torch or whole-process RSS.
The separate preliminary forecast in `online.rs::command`, iteration over
candidate ticks, process startup, IPC and later outcome handling do not become
one aggregate 8 ms request budget. The first actual tick recomputes the frozen
model/kernel after the preliminary forecast cache is cleared, but that does
not make the preliminary work free or include the whole decision in one tick's
gate.

As shown by `episode.py` and `host.py`, initial Python encoding happens before
the native decision; external waveform loading/CNN execution and selected
output rendering happen after an admitted action. Python model memory,
renderer work, ffmpeg encode/decode, ASR or exact-PCM cache access, observation
and end-to-end wall time are measured in the recorded host/process costs.
They are not submitted to the original native envelope as a combined request
budget. Outcome timestamp checks establish ordering, and the four-second
presentation clock establishes media alignment; neither is an enforced
end-to-end compute deadline. The bounded action horizon is also a logical
decision limit, not such a deadline.

Consequently, a native resource-gate pass, or a completed policy-specific
qualification, does **not** establish a four-modality end-to-end latency,
memory, throughput or resource SLA. That would require a separately specified
host-wide budget, admission/cancellation behavior and representative workload
evaluation. This phase reports the actual host costs and their registered
sensitivity while retaining this scope limit. The read-only boundary check
changed no owner, resource threshold, policy, frozen analysis or launch plan.

## Evidence entry points

`FROZEN_QUALIFICATION.json` locates the exact prospective specification and its
dependency closure. `PROTOCOL.json` states the source census, order and gates.
`REFERENCE_SELECTION.json` preserves the prechosen baseline. Raw build,
calibration, numerical parity, actual media smoke, negative probes and subsequent
source execution are separate immutable run directories. No CI query, original
phase edit, raw external upload or product authority change is part of this work.
