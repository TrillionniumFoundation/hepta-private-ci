# 冻结生成器与语义 adapter：完整四模态确认结果

## 结论

**已登记的 5440 个实际输出 bundles 全部完成，强制完整性审计通过；预先选择的 NLL 修复没有通过独立来源的训练收益主检验。** 三个固定 seed 的平均 CE 相对 canonical 未训练基线增加 0.0015802911，严格成功率增加 0.0009803922（0.098039 个百分点），但两项配对区间均跨过零。不能宣称 CE 优越性，也不能宣称零容差的严格成功率非劣性；这些区间同样不能证明等价或显著劣化。

全部八个实际分支、三个已选 seed、失败的 Brier 对照、两种基线和完整执行尾部都保留。没有因为本次结果重新选择 seed、残差边界、来源、route、指标或终止位置。以下结论来自 [正式结果](evidence/CONFIRMATION_RESULTS.json)、[完整性审计](evidence/CONFIRMATION_AUDIT.json) 与 [组合判定](evidence/CONFIRMATION_CHECKED_RESULT.json)。原有失败登记继续保留，新增 [正式负结果回执](evidence/CONFIRMATION_NEGATIVE_RESULT.json) 记录这一阶段的最终状态。

## 主终点与正式判定

令每个 bundle 的效用 \(U\) 为四种实际输出内容正确指标的均值，严格成功率 \(S\) 要求四种输出共同通过已冻结的任务检查。本次所有 presentation clock 均通过。风险系数固定为 2，经验 certainty equivalent 定义为

\[
\widehat C=-\frac12\log\left(\frac1n\sum_{i=1}^n e^{-2U_i}\right).
\]

主估计量为三个 seed **各自 CE 的平均**减 canonical CE；不是把三个 seed 的输出混合后计算一个 CE。严格成功率差采用同样的固定面板平均。85 个来源簇作成对 bootstrap，每次保留簇内两对任务、四条路径、全部 seed 和基线；固定 bootstrap seed 240809，10000 次重采样。根协议的三个 efficacy family 采用 `.05/3`，本研究区间置信度为 98.333333%。两个要求为合取门，不用任何次要对比替代。

| 主比较：NLL 三 seed 面板 − canonical | 点估计 | 98.333333% 配对簇区间 | 预登记通过条件 | 结果 |
|---|---:|---:|---|---|
| CE 差 | +0.0015802911 | [−0.0195989454, +0.0240368001] | 下界 > 0 | 未通过 |
| 严格成功率差 | +0.0009803922 | [−0.0122549020, +0.0151960784] | 下界 ≥ 0；容差为 0 | 未通过 |

旧开发选出的边界 8 面板 CE 为 0.6950579672，优于当时的 canonical 0.6827755769；这个旧开发优势没有在预登记的新来源检验上获得确认。正式负结果没有被旧开发点估计、单个 seed、route 或后见更好的失败对照覆盖。

## 静态风险目标的退化检查

100 个语义动作均实际生成并观察后得到的端点表满足 \(U[a,t]=S[a,t]=1[a=t]\)。令 \(d=1-e^{-2}\)，则风险成本矩阵为 \(C_{risk}=\mathbf1\mathbf1^T-dI\)，均值成本为 \(C_{mean}=-I\)。对任何归一化 posterior，两者的动作排序相同。原登记目标去常数并作共同 RMS 规范化后，回归目标及梯度相同；三组最终 mean/risk 参数 SHA 也相同。

因此，在本次静态、等成本、二值语义端点问题里，独立的风险训练优势不可识别。这是实际端点和代数共同支持的结论，不是把同一目标换名后的收益。主 CE 指标衡量质量分布，没有扣除实测 wall time；不能根据本报告断言质量收益覆盖了搜索、核验或推理费用。信息到达和不同动作成本带来的动态风险问题由另行冻结的 control/native 研究检验。

## 完整性、复现与推断边界

强制审计核实完整 `(case, route, arm)` Cartesian 集合、每个 arm 的 85 个簇各八个任务、全部 21760 个实际输出文件 SHA、170 个输入视频 codec receipt、固定执行顺序、来源目标与 public swap、5440 次独立标量重评分以及 4760 次 posterior/选择检查。全部通过。这里的独立指另一个标量实现和完整字节核对，没有声称新增神经观察器家族或重新训练观察器。

实际文件不等于独立内容。输出不同 SHA 的计数为 text 97、image 578、audio 95、video 583；重复语义端点与重复波形在这一有限任务中按设计出现。原始文件全部保留，但统计有效样本仍只有来源簇层级。确认音频的 340 次来源出现来自 296 个不同 WAV；其相关性不能被出现次数抹去。

另行冻结的动态 late-evidence 模型还有已证实的依赖失配：某些 pair 两个 slot 使用同一 WAV，确定性编码产生完全相同的观测，而单数字 likelihood 的 Kronecker 积会给不可能的不同标签观测分配概率。这是已知模型失配，不只是未经验证的独立假设；详见上级 [证据别名审计](../control/review/EVIDENCE_ALIAS_AUDIT.md)。本研究的静态确认没有为该缺陷重调候选；也没有证据证明它单独造成某一资格失败。自身生成内容没有被用作未知目标的新证据。

本研究支持的完成项是：部署一致的实际端点表、冻结生成器加小 adapter 的执行方法、完整未训练参考、保留失败的训练候选、四模态真实文件及 clock、来源隔离的完整确认与成本审计。**训练收益这一科学主张仍未闭合为正结果。** 不能将其改写为开放词汇全模态大模型训练成功、自然音视频理解完成、五组件再次联合训练、全局 NDU 最优性证明或生产资格。
