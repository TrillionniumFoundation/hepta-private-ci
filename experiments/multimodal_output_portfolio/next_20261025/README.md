# 全模态输出组合：下一阶段实际执行与结论

本轮完成了新增来源上的控制、配对动作价值、音视频接入、六模型联合训练比较，以及真实 Hepta owner 的两步原生执行。全部模型实验已经结束，失败、原始输出、冻结协议和独立审计均保留。**实现可以运行，部分内容控制和四模态任务通过了原门；所有科学收益门并未通过，不能宣称全部 blocker 已关闭或已求出全局最优输出组合。**

最明确的正面结果是：冻结 cached teacher 在新来源上优于强 nonfeedback 和 allocation 对照；修复后的真实四模态流程通过五条输入路线的既定门槛；H2 的独立正确性准入头通过原四项 pooled 点门，冻结 teacher 在该准入机制下完成真实 owner 的生成、观察、恢复和继续决策。最明确的负面结果是：新 signed critic 更不准确且没有替代资格；严格的增量反馈 CE 门没有通过；本轮联合训练的 entropic 目标在实际输出 CE 上低于 mean 目标；原生受限 NDU 策略未建立质量或经济优势。

数学定义、梯度和全局控制条件见 [METHOD.md](METHOD.md)。环境与来源见 [RESTORATION.md](RESTORATION.md)，八份完整归档见 [EVIDENCE.md](EVIDENCE.md)。机器可读结论见 [STATUS.json](STATUS.json)。本轮没有查询或处理 CI，也没有改变生产授权。

## 二、内容控制有收益，但动作价值学习仍失败

[control/REPORT.md](control/REPORT.md) 保留完整设计、价格曲线和成本尾部。以下控制比较使用名义 97.5% writer-cluster 区间，全部 views、futures 与固定三个 seed 留在同一 writer 内。

| 对比 | CE 差 | 区间 | 原判定 |
|---|---:|---|---|
| cached teacher − strong nonfeedback | +0.016851 | [+0.009682, +0.023929] | 原次要质量家族通过 |
| cached teacher − allocation | +0.018562 | [+0.011218, +0.025769] | 原次要质量家族通过 |
| fresh − stale draft feedback | +0.002669 | [−0.000811, +0.006003] | 严格反馈家族未通过 |

cached 与 compiled 的全部 24,576 个配对路径、实际媒体和公共观察一致；编译没有改变被测函数。但 compiled 的平均 wall 差为 +2.3644 ms，区间 [−0.3434, +9.9247]，速度门未通过。保留了非首次请求中约 61.8 秒 wall、48.4 秒 CPU 的极端样本；没有把它删掉，也没有在缺乏 profiler 时编造原因。

cached teacher 相对强 nonfeedback 的平均 wall 差为 −1.8769 ms，区间 [−2.2702, −1.5451]。这一对照下质量与平均成本均改善，但把实测时间放进 `CE(U − price × time)` 后，长尾和价格假设仍然重要，不能由平均时延推出所有价格下的经济优势。

这组比较的六个策略每步均承担相同公共 reader/cache 开销，不能据此声称支配专门跳过无用特征计算的优化固定实现。

[action_value/REPORT.md](action_value/REPORT.md) 给出另一轮独立确认。新 signed critic 的同状态 Δ MSE 比零差预测高 **0.009260**，区间 [+0.002244, +0.016476]；比旧 teacher 高 **0.014739**，区间 [+0.010314, +0.019316]。它选择的 13,979 次非 stop 动作实际平均 Δ 为 −0.028051，平均确实有益；但预测减实际的偏差为 −0.131673，明显过于乐观。

其原始 CE 相对旧 teacher 的差为 −0.001461，区间 [−0.007151, +0.004109]，没有建立事先要求的 −0.005 非劣下界；平均 wall 增加 0.4111 ms，区间 [+0.2585, +0.5645]。本轮不替换旧 teacher，也没有从已打开的预测分箱再挑一个阈值宣称确认成功。

## 三、真实四模态任务的门已经通过

[media/REPORT.md](media/REPORT.md) 记录了从失败到新候选的全部路径，包括旧 tiny ASR 失败、并行 OOM、V2 观察器资格失败、两个旧接入失败及修复。新修正只使用公共输入 posterior 的 argmax；原 soft posterior 另外保留，目标标签不参与生成。音频选择的是固定 seed 23179 的单个输入头。

固定 ASR 组合在独立 300 个登记录音、147 位 speaker 上得到 **259/300 = 86.33%**，新输入头得到 **273/300 = 91.00%**，均通过原 85% 点门。两个单独 ASR 分别为 249/300、243/300，均未单独获得这项资格。录音只有 298 种唯一 WAV 字节，两组重复均在同一 speaker 内；两个资格终点共享同一 cohort，不是两次独立实验。组合 ASR 的描述性 speaker-bootstrap 95% 区间为约 [80.14%, 91.86%]，不能称其总体下界超过 85%。

正式确认使用冻结候选和 128 对新来源。下表统计的是**四个输出同时正确**，不是单独一个模态正确：

| 输入路线 | 严格成功 | 比例 |
|---|---:|---:|
| 图像 | 127/128 | 99.22% |
| 文字 | 128/128 | 100.00% |
| 音频 | 114/128 | 89.06% |
| 视频 | 117/128 | 91.41% |
| 音频 + 视频 | 125/128 | 97.66% |

105/128 来源对在五条路线全部成功。条件声音观察为 20/20、视频帧为 200/200，五个物理负例全部拒绝。实际文件 census 为 **512 个输入文件 + 2,560 个输出 codec 文件 = 3,072**；640 个 bundle 的文字、PNG、PCM 和 MP4 均真实产生，内容回读与四秒 presentation clock 检查全部通过。

正式媒体阶段耗时 329.215 秒，CPU 324.745 秒，峰值 RSS 901,165,056 字节。它复用 11 个已逐字节绑定的实际 PCM 事件观察，ASR 新调用数为零、缓存命中 1,308 次；冷 ASR 及新资格的 1,164.287 秒等成本单列。缓存不是新的独立观察，固定十条件声音函数也不是开放词汇语音能力。

## 四、联合训练执行成功，当前 entropic 目标未获得替代资格

[joint/REPORT.md](joint/REPORT.md) 与 [独立审计](joint/review/REPORT.md) 给出完整结果。六个模型采用相同配对初值、外生日程、320 步和 batch 4；core、speech、motion、audio input、video input 五组件均记录到真实梯度和参数变化。两目标使用同一个 0.005 保真正则，但风险变换和这个正则共同定义了实际优化问题，不能称为无正则 CE 的精确求解。

确认阶段使用 greedy 部署、实际物理 codec 和独立重新解码的观察；训练使用随机离散样本及 codec 前代理效用。固定三个 seed 的 **768 个 bundle、3,072 个输出文件**全部完成。统计单位为 **24 个实际连通 writer/speaker 簇**，而不是 768 个独立样本。

| entropic − mean | 差值 | 95% cluster 区间 | 原门 |
|---|---:|---|---|
| CE，γ = 2 | −0.006853 | [−0.014723, −0.001190] | 未通过 |
| 严格联合成功率 | −1.3021 个百分点 | [−3.3333, +0.5051] 个百分点 | 未通过 |

这项结果支持保留本轮 mean 基线，不能把五组件确实更新当作风险目标有效的证据。它也不否定所有风险敏感目标：本次只检验这些模型、代理效用、优化日程、正则和部署规则。缺少不继续训练的对照，因此无法由两组比较单独估计继续训练本身的收益。

完整确认子进程耗时 **574.254 秒**、CPU **661.772 秒**、峰值 RSS **1,405,755,392 字节**。1,536 个音频事件请求包含 60 次实际事件观察和 1,476 次缓存命中；一次事件观察运行两个固定 ASR 模型。输入准备、加载、核验和实际 codec 开销保留在完整进程中。固定 arm 顺序及缓存使成本比较只能作描述，不能当成随机化速度试验。

独立审计以不同的 histogram/math 算法重新计算全部主结果，最大差为 1.11e−16；核验通过，质量门仍然失败。没有重新训练、调整 γ、挑 seed 或追加确认来源。

## 五、原生执行已经落地，受约束最优性没有被证明

[native_h2/REPORT.md](native_h2/REPORT.md) 记录了两次旧 pilot 失败、另立的 400/400 旧开发、100-writer 新校准、1,000-writer 独立资格和正式执行。新资格的 pooled ID ECE 为 **0.015369**，覆盖率 0.6824，完全缺失输入误准入为 0/1,000，一侧 95% 上界为 0.00299125，原四项门均通过。它不保证每个动作或实际选择后的分布都已校准。

正式执行在同一准入机制下比较 NDU 和 correctness argmax。原生真实发出并执行决策，第二步绑定上一实际输出的公共状态和 outcome digest；私有真值评分在全部 owner 关闭后进行。数值误差相对原 teacher 最大约 5.86e−7；708 次决策、397 个 emitted outputs、54 个负例检查、4 个恢复检查均有原记录。

本次原生 H2 执行覆盖 text/image；media 与 joint 的四模态 codec 流程是独立实验，尚未证明四模态共同接入该 native 生命周期。

| 正式流上的 NDU − correctness | 观察差值 | 原 nominal writer-bootstrap 区间 |
|---|---:|---|
| 扣 .002／非 stop 动作后的 CE | +0.011367 | [−0.087290, +0.106950] |
| 严格成功率 | −1.5625 个百分点 | [−7.0313, +3.1250] 个百分点 |
| 公开请求耗时 | +5.6135 ms | [+2.6112, +9.3150] ms |

NDU 实际 selected correctness ECE 为 **0.057746**，baseline 为 0.092386，不能把较大的资格样本中的选后诊断直接继承到真实执行。这里测量的是立即输出正确率的选择后校准，不是 NDU moments 或动作价值差的校准。

这里还有三个必须明确的实现边界：

1. **原 Q 的备份没有包含新 owner 的未来准入和拒绝 −1 规则。** 在每一步给 unrestricted Q 加 mask，并不等于求解受这些约束的 Bellman 问题。实际可行集合改变了部分选择；这不能被宣称为负结果的唯一原因。
2. **owner 跨 writer 持续运行。** 神经状态没有按 writer 重置，不能把 64 位来源 writer 自然当成 64 个独立重置的策略试验。原区间完整保留，解释限定为固定已实现 ordered stream 下的名义重采样，不能单靠它作普适因果成本结论。H1 的同类边界也另有独立说明。
3. **projection 的身份接入与数值调制有区别。** 真实新内容经 frame→encoder 改变 H1；utility-derived modulator 的 digest 被绑定到 tick/journal，但本版 drive 固定，未证明它的数值进入 head 或在线 plasticity。没有把记录存在误称为调制收益。

资源核验覆盖全部 **3,540 个连续 candidate ticks**。四个有 tick 进程通过原汇总门，两个零 tick 恢复段为 N/A。一个 stop 候选的实际执行为 60,038 μs，超过 8,000 μs 单 tick 门，已经被原门拒绝。原 AUDIT 中把零 tick/null summary 当 false 的汇总值保留，另附精确分类和逐 journal 核验；没有修改门槛或隐去这次超限。

## 六、下一阶段真正剩余的研究问题

本轮不批准生产替换，授权保持 `deny_all`。已经关闭的工程问题包括实际 encoder/decoder、来源隔离与身份核验、动作提交与真实生成、codec/时间轴、原生加载与恢复、原始证据封存。以下结论仍需要新的候选与独立设计：

- 直接 NDU 动作差的条件估计和选后校准，尤其是未来噪声、备份误差与选择偏差。
- 将真实 owner 状态、可行集合、拒绝和随机成本写入未来备份，而不是只在最后选择时加 mask。
- 独立 owner-stream 或适当的顺序试验，分离状态延续、内容反馈与数值 NDU 调制的作用。
- 与实际输出效用一致、能在新来源上改善 CE 的联合风险训练目标。
- 能覆盖完整计算、生成和核验成本的廉价策略，以及超出十类构造任务的自然音视频和完整生产生命周期。

这些是尚未建立的研究和部署结论；本轮没有通过改门、隐藏失败、选结果后追加样本或伪造生产资格来把它们写成已通过。
