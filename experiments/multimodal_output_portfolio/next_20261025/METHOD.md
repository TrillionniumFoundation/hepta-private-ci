# 从多模态初值到动态输出选择：本轮实现的数学含义

本轮是在已有有限任务生成器上检验一种训练和推理方法。它确实运行编码、生成、条件价值预测、真实输出观察和 Hepta owner 生命周期；它不构成已经训练出通用全模态基础模型的证据。原 Hepta NDU 的协议类型、projection store 与 owner 准入规则保持原定义。以下 entropic certainty equivalent 是本研究选用的效用目标，不能反过来声称原产品所有 NDU 字段都等于这个统计量。

## 1. 输入产生初始状态，输出是受控生成过程

公共输入可以是像素及可靠性标记、字面文字请求、真实 PCM 的固定频谱表示，或实际时空像素。编码器把这些可见输入映射到生成初值。模型不能读取评分目标、尚未产生的生成分支、后验 oracle 或未来外部证据。

写作数学模型时，可以令状态为

\[
s_t=(h_t,z_t^{image},z_t^{text},b_t,\tau_t,\mathcal F_t),
\qquad s_0=E_\theta(x_{\rm public}),
\]

其中 \(b_t\) 是剩余计算预算，\(\tau_t\) 是 presentation clock，\(\mathcal F_t\) 表示已经到达的公共证据。实际代码使用离散的 latent/context、真实解码草稿和显式预算坐标；没有声称实现连续时间 SDE 或求解一般 HJB 方程。

有限动作包括停止、语义更新、图像更新、文字更新和跨模态耦合。选定动作后才抽取其未来随机性并执行生成。音频波形和视频运动由同一公共状态中的语义与图像状态驱动。动作是否可执行，还受 Hepta 准入、资源、状态和身份约束。

因此，Merton 问题在这里提供的是动态风险与资源选择的类比：预算像可耗用资源，不同生成过程提供不同、相关的任务收益，但生成动作通常离散、不可逆，质量不是可交易资产价格。当前实现没有把模态权重强行解释为一个金融投资比例，也没有套用常数投资组合的闭式解。

## 2. 目标与条件动作价值

对终端任务效用减去累计控制成本 \(R=U(Y)-C\)，本轮采用

\[
\operatorname{CE}_{\gamma}(R)
=-\frac1\gamma\log\mathbb E[e^{-\gamma R}],\qquad \gamma=2.
\]

固定成本口径和可行策略集合后，最大化 CE 等价于最小化指数 moment。预算不足、不可执行动作和信息不可用性属于约束；在实际测量里，离线搜索、部署控制、生成、核验、加载和整进程成本分别记录。把所有这些成本都转成同一种效用单位需要明确的价格假设，不能仅由一次 wall-time 测量得出。

条件 moment 控制器估计

\[
M_t(s,a)=\mathbb E[e^{-\gamma R}\mid s_t=s,a_t=a,\text{后续指定策略}],
\]

并在可行动作集合中选最小值。直接动作价值差模型则学习

\[
\Delta_t(s,a)=M_t(s,a)-M_t(s,\mathrm{stop}),
\qquad \Delta_t(s,\mathrm{stop})=0.
\]

这里负差值表示继续动作有利。它是有符号差值，不能经过仅输出正值的 softplus 再当作同一个模型。停止值必须为零，动作 mask 与剩余 horizon 必须一致。H1 的纯语义更新不改变立即交付的输出却增加成本，因此在本任务里受到严格支配；这个结论不自动适用于更长 horizon 或另一种生成器。

新 critic 使用完整公共特征，分别学习 H1/H2。H2 标签里的后续动作由另一个 source fold 的模型根据当时公共状态选择，再使用实际生成结果计分；不取同一棵已实现树中的事后最大收益作为可部署标签。模型选择只使用旧 development。新 writer 数据在候选、成本、对照和门槛冻结后才开放。

本轮的动作空间和 horizon 都有限。离线枚举提供的是这个空间、这批来源、这组实现随机分支下的内容控制上界；它不能证明任意大模型的全局最优性。

### 何时逐步决策才等于全局最优

若状态包含决策所需信息、终端效用为 \(U\)、每步成本为 \(c(s,a)\)，且转移分布已知，固定指数风险准则可写成乘法 Bellman 递推：

\[
V_T(s)=e^{-\gamma U(s)},\qquad
V_t(s)=\min\left\{e^{-\gamma U_{stop}(s)},\;
\min_{a\in\mathcal A_t(s)}e^{\gamma c(s,a)}
\mathbb E[V_{t+1}(s')\mid s,a]\right\}.
\]

若停止后的评分本身仍有未揭示随机性，第一项也必须使用对应的条件期望。这个递推需要正确的可行集合、终值、转移和条件价值；若编码器没有保留足够的信息，还需引入可更新的历史或 belief state。把一组输入编码成向量并不自动保证这些条件成立。

所以，在线每一步选择一个“预测 NDU 最大”的动作，并不单独证明全局最优。当前代码的价值头是有限来源上拟合的近似，H2 备份也只对应指定的交叉拟合后续策略；其误差、选择偏差和来源迁移必须实际测量。联合训练的四项平均效用与严格四模态成功是本任务的两个明确终点，尚不是任意用户偏好、跨模态互补和真实计算价格下的统一全局效用。

本轮原生执行进一步暴露了一个具体边界：新 owner 的准入、拒绝终值和持续神经状态没有进入旧 unrestricted teacher 的未来备份。因此逐步 mask 不是完整的受约束 Bellman 解。若 owner 状态会影响未来可行集合，它必须进入足够的控制状态或可更新的 belief；若实测成本随机，`exp(γc)` 必须留在条件期望内。现有数据没有单独识别这些近似各自造成多少质量损失。

## 3. 联合训练实际优化了什么

`joint/model.py` 把生成器、音频输入 CNN、视频输入网络、波形 decoder 和运动 decoder 放在同一个可训练模型中。生成器实际采样七个自回归 token 和两个语义类别，然后输出连续像素、波形与空间帧。训练代理效用是四个分量的等权平均：冻结图像 observer 的正确类概率、采样文字的严格正确性、实际波形相对教师波形的保真度，以及生成视频的语义和运动质量。

这个代理发生在物理 codec 量化之前。教师只有十种固定数字条件；波形保真度不等于自然语言可懂度，运动变换帧不等于自然视频。外部 ASR、视频文件读回和正式输出评分没有用于梯度或候选选择。

两个匹配训练目标为

\[
J_{\rm mean}=\mathbb E[-U]+0.005 A(\theta),
\]

\[
J_{\rm entropic}=\tfrac12\mathbb E[\exp(-2(U-0.75))]+0.005 A(\theta),
\]

其中 \(A\) 是两组共同使用的波形保真正则项。正则项会影响最优解，所以不能把整个目标叫作“无正则 CE 的精确最大化”。三组训练种子中，每对模型使用同一初始参数、数据与任务日程、噪声、学习率、步数和正则权重。

对实际离散样本 \(y\sim p_\theta\)，代码采用

\[
\nabla_\theta J
=\mathbb E[\nabla_\theta c_\theta(y)
 +(c_\theta(y)-b)\nabla_\theta\log p_\theta(y)]
 +0.005\nabla_\theta A,
\]

第一项保留连续路径梯度，第二项处理离散 token 与语义类别的 score-function 梯度；\(b\) 是与动作无关的固定常数。零前向值的 stop-gradient 修正只改变梯度，没有使用 straight-through 分类替代。训练同时运行解析二动作枚举契约来核对该梯度恒等式，并记录所有五个组件的实际梯度和参数身份变化。裁剪梯度和 Adam 是实际优化方法；没有全局最优收敛证明。

实际确认使用 greedy 部署、写出的文字/PNG/PCM/MP4、独立重新解码及观察，再计算四个实际正确性指示量和严格联合成功。这是有意声明的训练与评估差异。两组继续训练的比较可以检验这两个目标的差别；缺少不继续训练的对照时，不能据此估计继续训练本身的独立收益。

## 4. 动态反馈、计算成本与原生执行的证据边界

反馈实验让 fresh 和 stale 策略获得相同已到达生成结果和访问机会。两者保持当前 latent、相同第一动作与预算，区别是第二步价值预测是否使用当前实际解码草稿的内容特征。stale 仍有正常 latent 演化，因此该实验检验当前草稿内容的增量价值，不代表所有外部工具、历史记忆或在线学习的价值。

编译执行实验保留 teacher 函数，通过编译公共特征、CNN 和 head 降低开销。它不是新学到的蒸馏 actor。更便宜但质量下降的旧 actor 不能因为速度快而被准入；新的 signed critic 也必须单独通过完整质量与成本比较。

原生实验实际执行原始 owner、提交决策、生成媒体、独立观察、写入原 NDU projection store 并恢复 pending/committed 状态。它与“仅重放旧动作”有实质差别，但不自动证明 NDU 排序胜过同准入强对照，也不等于运行了完整生产 daemon 或获得生产模型身份与授权。

正式源码审查确认，owner 跨 writer 持续，不能将来源 writer 数自动当作独立重置的策略流数。原 native bootstrap 保留为条件于固定已实现顺序流的名义重采样。新内容确实通过 frame→encoder 进入 H1；utility-derived modulator 的 digest 被绑定，但固定 drive 没有将其数值送入预测 head 或在线 plasticity。二者的作用不能混写成已经证明的数值 NDU 调制。

## 5. 怎样解释通过与未通过

来源独立、执行正确、校准、排序质量、质量覆盖成本和生产可用性是不同的结论。每一项都需要自己的证据。资格通过的是它预先定义的统计总体；合并 ECE 不保证逐动作 ECE，也不保证策略选择后的 ECE。重复视图、多个生成随机数、动作枚举和训练种子不扩大独立 writer/speaker 数。

本轮统一保留原门槛和失败，不用结果触发样本追加，不把含零区间称为等价，也不把执行成功称为策略优越。完成某项实验能够回答研究问题；只有达到其预先规定的门槛，才可以作对应的正面声明。
