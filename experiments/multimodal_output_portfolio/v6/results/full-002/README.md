# full-002：条件生成修复后的独立完整对照

**真实联合生成已有效运行；本次结果仍不支持把风险感知动态推理作为优于强对照的默认方案。** NDU 训练在这三个 seed 的固定推理下改善平均 loss；加入动态控制后，future 平均 loss 又有所增加。完整内容控制没有稳定优于 allocation-only，额外搜索成本也没有被覆盖。所有已登记条件区间均包含零，不能据此发布总体优势结论。

本页只报告 [protocol.json](protocol.json) 对应的实际执行。源码冻结在干净提交 `b98961ceb71414490e1c6ae397cf635bca3093f4`；后续 owner 接入代码不追溯记入本次实验。协议 canonical SHA256 为 `d46eba91baaec2988756a5730f4be337b9f61cc904491447ce56374dc75c7af2`，完成摘要为 `baa995a3a6ad66d2376d4bd5e18e3f38c91255ebf41f6a5a88f6a6de131cd28a`。

## 2. 训练／推理 2×2

主表为 future、预算上限 128。质量先在每个 seed 内汇总，再对三个 seed 等权平均。CVaR90 是各 seed 最差 10% loss 的经验均值，属于描述性尾部统计。S 推理指 dev 调优固定序列，其初始化仍执行该模型的冻结内容 gate；推理轴识别后续动态控制的增量。

| 训练 / 推理           | 平均 joint loss ↓ | CVaR90 loss ↓ | 联合事实正确率 ↑ | 平均 wall ms ↓ | 实际工作单位 ↓ |
| --------------------- | ----------------: | ------------: | ---------------: | -------------: | -------------: |
| S / dev 固定（S/S）   |       0.216875931 |   0.625912455 |           46.11% |         27.552 |          9.583 |
| S / NDU 动态（S/N）   |       0.215090342 |   0.614041779 |           46.11% |         68.691 |         73.569 |
| NDU / dev 固定（N/S） |       0.199702005 |   0.583847549 |           50.00% |         26.690 |         10.250 |
| NDU / NDU 动态（N/N） |       0.205148527 |   0.578090908 |           48.33% |         62.334 |         74.000 |

平均 loss 的分解为：

- 固定推理下的训练效应 `N/S − S/S = −0.017173926`。三个 seed 分别改善约 0.022066、0.016151、0.013305。
- NDU 训练下的推理增量 `N/N − N/S = +0.005446522`。seed 17、29 恶化，seed 43 小幅改善。
- 监督训练下的推理增量 `S/N − S/S = −0.001785589`。
- 交互项 `(N/N − N/S) − (S/N − S/S) = +0.007232111`。
- 总差 `N/N − S/S = −0.011727405`；尾部总差为 −0.047821547。

因此，总差改善主要伴随训练轴，不能据此归因于风险感知动态推理。当前训练轴同时改变基础 surrogate 的风险聚合与真实输出计划 gate 的训练目标，这个 2×2 也不能单独识别二者贡献。

预算 64 下结论相近：S/S、S/N、N/S、N/N 的平均 loss 分别为 0.216875931、0.211891768、0.199702005、0.203752040。NDU 训练后的动态增量仍为 +0.004050035，交互项为 +0.009034198。

clean-retention/128 的 N/S 和 N/N 平均 loss 为 0.034659031、0.034419481；均值有约 0.000240 改善，CVaR90 却从 0.270512338 升至 0.292567754。clean-retention 是未训练的干净域，不能称为连续学习遗忘测试。完整逐 seed 分解见 [factorial.json](factorial.json)。

## 3. 强对照与共享语义控制消融

以下全部使用 NDU 训练、future/128，并使用相同预算上限。

| 推理策略            | 平均 loss ↓ |    CVaR90 ↓ | 联合事实正确率 ↑ | wall ms ↓ | 工作单位 ↓ |
| ------------------- | ----------: | ----------: | ---------------: | --------: | ---------: |
| 预设固定            | 0.201770960 | 0.577039654 |           48.89% |    27.306 |     11.250 |
| dev 调优固定        | 0.199702005 | 0.583847549 |           50.00% |    26.690 |     10.250 |
| hard top-1 MoE 路由 | 0.202641758 | 0.569960926 |           48.89% |    28.289 |     13.600 |
| 单步价值控制        | 0.202664065 | 0.580951610 |           48.89% |    38.024 |     28.883 |
| 风险中性动态        | 0.201968971 | 0.573995777 |           48.89% |    62.439 |     75.469 |
| 风险感知递归        | 0.205148527 | 0.578090908 |           48.33% |    62.334 |     74.000 |
| allocation-only     | 0.198806282 | 0.565893975 |           50.00% |    37.746 |     28.047 |

allocation-only 从 encoder 后初始化就绕过内容 gate，固定 image→text，随后只允许这两个模态更新，共享语义 `h` 保持原值；它并非仅在后续搜索中关闭 semantic/couple。完整方法相对它的平均 loss **增加 0.006342244**，CVaR90 增加 0.012196933。三个 seed 的平均差约为 +0.023465、+0.009213、−0.013651，方向并不一致。clean-retention/128 的平均差也为 +0.000596259，尾部差为 +0.044489589。

风险感知相对相同 forecast、场景和候选收费的风险中性控制，future/128 平均 loss 增加 0.003179556，CVaR90 增加 0.004095130。本次结果不支持完整内容控制或风险厌恶控制具有独立优势。逐行配对诊断见 [full-content-vs-allocation-01.json](full-content-vs-allocation-01.json)、[full-content-vs-allocation-02.json](full-content-vs-allocation-02.json) 与 [risk-aware-vs-neutral.json](risk-aware-vs-neutral.json)。

## 4. 控制确实改变生成，但预测质量仍有限

本轮 **QUERY 次数为零**。semantic/couple 的额外内部更新被实际执行；六个计划 gate 均有参数变化，command、semantic、couple 等训练模块均记录非零梯度。NDU future/128 中，风险感知与风险中性有 **40% 行对的原始输出字节不同**。首轮“风险项几乎不改变候选排序”的退化已不是本轮负结果的充分解释。

仍有可观察的学习限制：seed 43 的 NDU gate 在 future 的 60 个源中，58 个选择同一 semantic→couple 初始化，在 retention 的 30 个源中全部选择该计划。训练候选中均值最优与 entropic 最优计划的分歧只占 0–3.125%。实际更新和输入响应不能替代策略泛化证据。

forecast 的 source-pair OOF 效用 MAE 约为 0.372–0.421，而效用范围为 `[-1,1]`。预抽样 dev endpoint 的 90% 区间覆盖约为 0.844–0.906，但平均宽度约为 1.35–1.83。按风险感知选择后的 dev endpoint 覆盖约为 0.792–0.882，低于未经选择的诊断。这说明价值预测较粗、策略选择会改变所见误差分布；它是可能的失效解释，尚不是因果归因，也不是条件覆盖或自适应覆盖认证。六个模型的原始诊断位于 `conditional-forecasts-01.json` 至 `conditional-forecasts-06.json`。

全部输出具备必需的 text/image 文件且 caption 语法有效。N/N 的 clean future 联合事实正确率为 86.67%，clean-retention 为 90%；future 混合六层后的正确率仅 48.33%。`wrong_hint` 与 `missing_no_hint` 两层在主要三个对照中均为零。每层只有十个不同源 case，不能把层间差异当作同源输入干预效果。完整分层见 [corruption-outcomes.json](corruption-outcomes.json)。

Reward A 与 Audit B 使用不同训练源和不同权重；其保留源准确率分别为 95.7% 与 94.9%。两者仍来自同主机、同 OCR 架构，生成图像上的误差不保证等于保留源误差，不能称为外部真值认证。

## 5. 成本和有限搜索边界

风险感知 N/N future/128 的 wall 是 N/S 的 **2.336×**，实际工作单位为 74 对 10.25。相同预算上限 128 并不意味着相同消耗。没有得到足以覆盖额外搜索、候选状态前向和验证成本的质量收益。

全部 7,560 行的 wall 合计约 299.042 秒，CPU 合计约 515.213 秒；native adapter 另约 3.271 秒。861.013 秒全流程还包含基础训练、observer、计划枚举及学习、forecast 拟合和其他运行工作。正文中的逐行 wall 包含原始媒体落盘、回读及独立评分。工作单位只是预先声明的记账尺度，不是 FLOPs 或焦耳。每次启动 Python/Torch 的原生 owner 冷执行是另一成本范围，不能以这里的常驻 runner 延迟代替。

预算 64 的风险感知控制共 1,412 次搜索，全部记录为截断；预算 128 的 1,444 次搜索全部完成声明的有限树。新异方差 forecast 的两头计算收费提高，完整初次搜索需要 30.5 工作单位，预算 64 的初次配额仅 27.875。有限树完成只意味着给定有限候选与经验条件分布上的搜索完成，不证明一般 NDU FBSDE、无限策略空间或神经训练全局最优。

原生事后 evaluator 给出 893 次 active advice、54 次 abstain、133 次无唯一建议。active 中风险感知仅 30 次；allocation-only 为 349 次。54 次 abstain 的全部活动候选效用都为负。abstain 不完成必需的联合输出；事后已知结果上的建议也不是在线策略收益。所有 receipt 继续为 `DENY_ALL`、无生产授权。

## 6. 统计和事后风险效用诊断

全部 **32 个预先登记的条件 Hoeffding 区间均包含零**。这些区间按同源 case 配对、对固定三个模型取 seed 平均，依赖 case 独立抽样假设；它们不覆盖训练过程总体不确定性。经验 CVaR90 与每 seed 结果保留为描述性证据，不能挑选正面分组宣布成功。

另增加一个明确标记为事后的诊断：对每个固定模型在源 case 上的实际 `R=1−2×loss` 计算 `CE₂ = −log(mean(exp(−2R)))/2`，然后平均三个 seed。这是跨上下文的经验效用分布，不是控制器的条件分布，不替换主终点，且此处不扣工作成本。NDU future/128 的 dev 固定、风险中性、风险感知、allocation-only 分别为 **0.397433409、0.401376297、0.394657364、0.406525999**，方向也不支持风险感知控制胜出。独立脚本重算全部 168 个组，数值差为零，见 [posthoc-observed-risk.json](posthoc-observed-risk.json) 和 [independent-observed-risk.json](independent-observed-risk.json)。
