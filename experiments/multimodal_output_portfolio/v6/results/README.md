# v6 首轮完整实验、成本重放与基础能力修复证据

**首轮完整实验没有证明 NDU 优势：所有策略的联合事实正确率均为零。** 之后的完整成本重放保持全部原始输出不变，显著减少了重复完整性检查的开销。再之后，一个预先冻结、仅使用训练与验证源的指令条件修复，通过了事先规定的基础能力门槛。三类证据分别报告；验证集上的修复成功不能改写首轮负结果，也不能代替新的独立完整对照。

本目录保存可审查的 JSON 摘要与来源绑定；原始 checkpoint、媒体、逐行轨迹、运行日志及诊断脚本另有完整证据包。文件身份见 [manifest.json](manifest.json)。紧凑 JSON 与原始格式具有相同的 canonical SHA256，原始文件字节 SHA256 另列，不能混用。

## 2. 首轮 2×2 对照：没有得到有效的联合语义生成

下表为 future 源、预算上限 128；质量先按 seed 求均值，再对三个 seed 等权平均。CVaR90 是每个 seed 最差 10% loss 的经验均值，再跨 seed 平均。完整 wall 时间采用保持输出完全一致的重放结果，包含媒体落盘、回读及 audit 评分。

| 训练 / 推理        | 平均 joint loss ↓ | CVaR90 loss ↓ | 重放平均 wall ms ↓ |
| ------------------ | ----------------: | ------------: | -----------------: |
| S / dev 调优固定   |       0.730957295 |   0.894837343 |             22.685 |
| S / NDU 动态       |       0.724014685 |   0.900193522 |             63.979 |
| NDU / dev 调优固定 |       0.731176175 |   0.891833520 |             22.935 |
| NDU / NDU 动态     |       0.731172064 |   0.891852278 |             62.250 |

N/N−S/S 的 future 平均 loss 为 **+0.000214768**，clean-retention 为 **+0.004843294**，均为恶化。future CVaR90 差为 −0.002985065，但这不足以建立尾部优势：所有 32 个已登记条件对照区间都包含零，且只有三个训练 seed。该条件区间不涵盖训练 seed 总体不确定性。

全部 7,560 行的 caption 语法有效，文字和 PNG 均成功输出；然而 joint fact correct 为 **0**，跨模态数字对完全一致的行也为 **0**。完整媒体输出与语义正确是两种不同的指标。audit OCR 在自己的保留源上准确率为 94.9%，reward OCR 为 95.7%；这不是对生成图像的准确率保证。

### 强基线与内容控制消融

同一 future/128 范围，以下均为 NDU 训练：

| 策略            | 平均 loss ↓ |    CVaR90 ↓ | 重放 wall ms ↓ |
| --------------- | ----------: | ----------: | -------------: |
| 预设固定        | 0.731173034 | 0.891838396 |         23.396 |
| dev 调优固定    | 0.731176175 | 0.891833520 |         22.935 |
| hard top-1 路由 | 0.732288834 | 0.894712553 |         23.638 |
| 单步价值        | 0.731170205 | 0.891851622 |         32.649 |
| 风险中性动态    | 0.731172144 | 0.891852278 |         59.761 |
| 风险感知递归    | 0.731172064 | 0.891852278 |         62.250 |
| allocation-only | 0.732837064 | 0.897424014 |         34.321 |

完整方法相对 allocation-only 的 future 平均 loss 改善约 0.001665，主要来自 seed 29；clean-retention 平均 loss 反而增加约 0.000022，三个 seed 均未改善。不能据此断言共享语义控制产生了稳健收益。

本轮没有 QUERY 动作。NDU 动态策略在 future/128 的 72.78% episode 中执行额外状态更新，56.67% episode 执行额外 semantic/couple。因此内容控制确实被执行，失败不能简单归因于“只做查询”。初始化的三个 NDU gate 却分别对所有输入选择同一个计划；训练集两个噪声场景下，均值最优计划与 entropic 最优计划也没有分歧。实际梯度非零和有限训练目标改善，不等于学得输入相关的风险组合。

风险感知与风险中性在 178/180 个 NDU future/128 行对中输出字节相同。首版 forecast 在同一残差分层内使用平移分布；未触及 clipping 时，`CE(mu + error) = mu + CE(error)`，因此风险惩罚不能改变层内候选排序。这是一个具体的风险建模限制，不能用“recursive”命名替代风险效应证据。

future 的六个 corruption 层使用不同源 pair，每层只有十个 case。可以在同一层内做策略配对比较，不能把层间差异解释为给同一输入添加错误提示的因果效果。clean-retention 是保留干净域，不是经过连续学习后的遗忘实验。

## 3. 成本重放：优化有效，动态控制仍更贵

独立核验见 [independent-verification.json](replay-001/independent-verification.json)：

- 全部 7,560 个有序行对的动作、初始化计划、决策、调用数、终态、模型/forecast/observer 身份、指标和抽象工作量均一致。
- 重新计算了原始与重放两份目录中 30,240 个媒体文件的 SHA256；15,120 对输出字节一致。
- 全部 1,080 个 native recommendation/disposition 按 episode 比较一致。
- 每个新行都有 text/image/audio/video 四个固定槽位；text/image 为 complete，audio/video 为 unsupported。

优化把模型全量身份检查移到同步 episode 的入口与出口；窗口内仍逐次核验 forecast 和父状态。独立 backend 调用继续做完整检查。退出时仍存在的参数变更会阻止返回结果。该机制不支持并发写模型，也不证明能够发现恶意的“改后再恢复”操作。

| NDU 训练、future/128 | 原始 wall ms | 重放 wall ms | 原始 / 重放 |
| -------------------- | -----------: | -----------: | ----------: |
| dev 调优固定         |       34.197 |       22.935 |      1.491× |
| 风险中性动态         |      450.721 |       59.761 |      7.542× |
| 风险感知递归         |      454.334 |       62.250 |      7.299× |
| allocation-only      |      158.451 |       34.321 |      4.617× |

风险感知推理仍需固定 dev 策略的 **2.714×** wall 时间。两次完整运行发生于不同时间；这些是配对执行的描述性计时，并非随机化的独立硬件基准。重放没有重新训练，不能将 287.853 秒重放总时长与含训练的 1,517.092 秒原始全流程直接当作训练加速比。

预算 64 的风险感知控制共有 1,352 次 decision，其中 412 次搜索截断；预算 128 的 1,353 次 decision 均完成声明的有限树搜索。完成有限树不表示解决了无限策略空间的全局最优控制问题。功耗未测量，不能由工作单位或 wall 时间推出能耗。

原生 evaluator 返回 990 次 abstain、70 次 active advice、20 次 `ParetoSetRequiresSlowPath` 无建议。最后一种不是 abstain；两种动态 MPC 均未被选为建议。这里比较的是执行后已评分候选，全部保持 `DENY_ALL`、`production_authority=false`，不是在线 neuron 调度权。

## 4. 定位并修复基础生成缺陷

首轮负结果触发了诊断；具体定位和变体门槛仅使用训练源和 validation 的 pair 512–575，与 forecast 的 fit/calibration/dev 源 pair 0–255 分离。没有在 future、retention 或 Audit B 上比较、调优或筛选修复变体。Reward A 固定不变；首轮已经评估的源仍须从后续新实验中排除。

把原架构从 400 延长到 2,000 步后，clean 联合正确率从 0 提升至 S/N 各 3/64。S/N 能识别 60/64、61/64 个无序数字对，却只正确生成 25/64、30/64 个有序文字对；正确数字被反向输出 35/64、31/64 次。图像分别有 59/64、56/64 个重复数字对，而真值中只有三个。真实目标通过相同 PNG/文字评分通路得到 62/64 联合正确，说明主要失败在生成路径。

随后只登记一个联合变体：visual/fuse 的 Tanh 之前加 LayerNorm，通过公开 command token 的可学习 embedding 和 FiLM（固定 gain 0.5）保留指令条件。没有硬编码 keep/swap 置换，没有向 encode/step/decode 传 Target，也没有输出修补。其余 hidden、噪声、训练样本/动作/场景 schedule 与 2,000 步对照一致。

冻结规范 SHA256：`c337df34d918f0f16e4e9cb1333619459034f569a96eaa2f111a353ac105545a`。评估使用保存后重新加载的 checkpoint，完整文件、配置、模块源码和旧证据身份均在前后核验。

| 预先登记的门槛                      | 要求 |          S 实测 |        NDU 实测 |
| ----------------------------------- | ---: | --------------: | --------------: |
| clean 有序文字对正确率              | ≥80% |          93.75% |          93.75% |
| clean 图像数字对正确率              | ≥65% |          82.81% |          85.94% |
| clean 联合事实正确率                | ≥50% | 81.25%（52/64） | 84.38%（54/64） |
| 验证源加训练式损坏后的联合正确率    | ≥40% | 78.13%（50/64） | 84.38%（54/64） |
| 非平凡 command 翻转的文字反向响应率 | ≥80% |          98.36% |          96.72% |
| 非平凡 command 翻转的图像反向响应率 | ≥60% |          88.52% |          88.52% |

翻转测试排除了两个数字本就相等的三个 case，分母为 61。反向响应率衡量模型是否响应指令；两种指令都输出正确真值的比率另存原始摘要，不能把“会翻转”直接当作“都正确”。六项门槛分别适用于 S 和 NDU，全部通过。

这是一个 seed、一个已用于诊断的验证子集、一个联合架构变体。它不单独识别 LayerNorm 或 FiLM 的贡献，不证明 NDU 优于普通训练，也不产生新的 heldout 优势证据。后续完整对照必须在预先排除已评估源像素的新 case 上登记并运行，首轮原始负结果保留。

## 5. 数值正确性及证据边界

独立 Decimal oracle 最大价值差为 `2.1913580246879107e-16`；策略差在预先设定 `1e-11` 容差内，128 个问题全部完成且无失败。该证据针对有限 entropic 控制器，不能推导一般 NDU FBSDE、神经网络全局最优或实际效用预测正确。
