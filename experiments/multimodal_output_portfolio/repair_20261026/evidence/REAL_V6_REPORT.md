# 原 V6 上真实联合 prior：开发实验结果

**新的100类联合预测器确实完成训练，在预先固定的共同遮挡与公开关系任务上改善了联合概率的 log score；它没有全面击败强对照，也没有取得独立来源资格。** 本轮不改变任何历史结果或生产权限。

训练使用原 train 中2,000个不重复来源对，留出使用原 validation 中500个不重复来源对。像素身份与来源对不交叉；MNIST writer身份未提供，因此不能声称writer独立。原encoder及此前实验已经使用过这些历史来源，本轮始终属于开发留出，不是全新的确认。

每对来源有两个预先固定输入：clean；同时遮挡左右数字顶部20行，并公开提供两位数字之和模10。后者的关系是**显式构造的任务指令**，给予所有学习候选同等访问，不是从自然声音或图像中自动识别出的新证据。两个视图共执行5,000次实际encoder行。训练为固定17、29、43三个seed，每个seed各训练joint与factorized两个模型，250次全批Adam更新、相同NLL与L2系数；joint有6,756参数，factorized有6,804参数，接近但不是完全相同的容量或计算量。

在首次留出预测之前，六个模型及训练完成回执已经保存。两个模型家族也都保留了按公开模10关系作解析条件化的强对照；原冻结semantic head的factorized输出也完整保留。没有按结果换seed、改遮挡、改模型或追加留出来源。

## 完整主要结果

表内学习模型为三个固定seed的指标均值。NLL越低越好；准确率只评价100个语义代码的选择，没有本轮新decoder媒体生成。

| 输入与候选 | Joint NLL | 两位同时正确 |
|---|---:|---:|
| clean：原冻结factorized头 | 0.355373 | 91.00% |
| clean：新factorized | 0.687843 | 85.13% |
| clean：新joint | 0.587632 | 85.80% |
| 共同遮挡+公开关系：原冻结factorized头 | 5.792018 | 3.40% |
| 同任务：原冻结头+解析条件化 | 2.768492 | 37.60% |
| 同任务：新factorized | 2.458162 | 50.13% |
| 同任务：新joint | 1.014509 | 68.27% |
| 同任务：新factorized+解析条件化 | 1.357862 | **71.27%** |
| 同任务：新joint+解析条件化 | **0.966581** | 68.53% |

共同遮挡任务的joint−factorized平均NLL差为 **−1.443653**；以500来源对为单位、同时保留三个seed的名义95%开发bootstrap区间为 **[−1.620807,−1.268344]**。双方都解析条件化后的差为 **−0.391281**，相应区间 **[−0.540277,−0.250945]**。clean上的差为−0.100211，区间[−0.200484,−0.006890]。

这些是条件于固定历史面板和候选的描述性开发区间，没有确认性多比较门，也没有可证明的writer独立性。三个seed不是三次新的来源实验。

联合模型在共同遮挡任务上分给违反公开关系的代码的平均概率为约4.20%，factorized为约48.86%；解析条件化后两者都严格为0。未条件化joint的平均10-bin选后ECE为0.09160，factorized为0.14787。这些粗分箱诊断不是独立校准证书。

必须同时保留两个负面结果：原冻结头在clean上优于全部新训练候选；公开关系条件化后的factorized准确率高于joint。更好的联合概率log score不等于所有决策损失下都选择更准确，不能据此进行模型替换或宣称全局NDU优势。

## 成本、证据与边界

完整程序wall为15.420678秒、CPU为15.412692秒，峰值RSS 392,456 KiB。它包含来源重建、真实encoder、六个模型训练、全部留出预测与统计；共享主机环境不提供无竞争性能保证。模型数、更新数、参数数和真实时间分别保留，不能把近似参数匹配叫作严格同算力实验。

`REAL_V6_REGISTRATION.json`、`REAL_V6_RESULTS.json`保留冻结设计和全部14个预测分支的结果。完整模型、真实encoder特征、sealed predictions与独立评分目标保存在 `ndu-original-assets/evidence-real-v6-001`，其逐文件SHA256列于结果文件。`audit_real_v6.py`从保存的概率逐行独立以标量算法重算NLL、Brier、准确率和ECE，并核对完整来源census及字节身份；审计结果单列在`REAL_V6_AUDIT.json`。

本轮使“可以训练一个真正的联合prior”从接口推进到真实原模型输入上的运行和开发比较。它没有识别真实同speaker音频likelihood，没有执行新的音视频输出或原生owner，没有验证NDU反馈/在线plasticity收益，也没有在开放任务或独立新来源上证明优势。
