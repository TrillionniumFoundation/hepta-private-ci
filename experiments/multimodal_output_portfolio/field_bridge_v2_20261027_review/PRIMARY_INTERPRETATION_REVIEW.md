**V2 修复了 V1 的响应不可辨识和局部预测失败，但六项预注册主比较仍为 0/6 获得完整接受。普通训练 B−A 已取得双观察器支持的主任务增益；阻止其整体接受的是保留性非劣尚未确立。参数场相对强普通训练、原生状态相对同信息历史控制的增量价值，仍未确立。**

本稿解释已冻结的 [主结果](../field_bridge_v2_20261027/evidence/PRIMARY_RESULT.json)，原始路径为 `bridge_v2_primary/RESULT.json`，SHA256 为 `ae10b12185c64d366019f3b73c522e9d6b364523174864a9424a65ffafc547e2`。不改变协议、控制器、比较族、阈值或任何数据用途；不修改根 ledger。[独立算术重建](../field_bridge_v2_20261027/evidence/PRIMARY_INDEPENDENT_RESULTS_AUDIT.json)最大差为 `3.2439329000766293e−16`；[实际媒体审计](../field_bridge_v2_20261027/evidence/PRIMARY_INDEPENDENT_MEDIA_AUDIT.json)的特征及全部评分差为零，61,440 次原生 tick 精确重放。[恢复 parity](../field_bridge_v2_20261027/evidence/PRIMARY_RECOVERY_PARITY_AUDIT.json)通过 11,808 条原记录和 6,560 条原生回执的对应核验。协议见 [PRIMARY_PROTOCOL.json](../field_bridge_v2_20261027/PRIMARY_PROTOCOL.json)。

B 的两个保留区间分别为 `[−0.012566, +0.011074]` 和 `[−0.011205, +0.011743]`，均值接近零。G 和 K 的未通过区间上界也高于 −0.01。准确结论是这些区间尚不能排除超过预设容忍幅度的下降；本轮没有据此证明下降已经超过该幅度。

普通候选在开发集通过的是 clean 点估计规则；最终保留门槛要求新的样本上有校正区间保证。这是不同的证据强度。不能把开发门槛的通过当作最终非劣保证，也不能因 C/E 通过而 B/G 未通过，就宣称前者相对后者具有显著保持优势；本轮保留族比较的控制臂都是 A。

## 3. H7 的局部审计为何不能代替终点 rollout

原 H7 审计是实质进展：完整新优化器轨迹上的 pooled MSE 为 `3.00344e−5`，最强预定基线为 `4.64601e−5`，比率 0.6465；动作 regret 比率为 0.6158；相对拟合集选定固定动作的局部优势为 +0.00155466，完整轨迹配对 95% 区间 `[0.00119183, 0.00194834]`。三个原开发门槛均通过，不能因主评估没有增量价值而倒过来宣布该审计无效。证据为 `bridge_v2_bank/H7_GATE_RESULT.json`，SHA256 `d52c3727e7adb791172c5c76ca25f159062e489742f226bd6790161ed42186be`。

但它检验的是**同一训练响应面板、由预定探索策略到达的状态、下一八步块的硬价值排序**。最终 C 则让贪心策略连续控制 36 个块，然后在新图像对上评分。局部目标不是“此动作之后继续执行当前策略至 288 步”的 continuation value，审计状态分布也不是最终策略自身的到达分布。因此，单块排序、整段训练终点和跨任务样本泛化是三个不同问题。

这里还存在对原 B09 条款的明确偏离：原 closure criteria 要求 development 与 trajectory-audit 的源像素身份互不重叠，而 H7 fit/audit 共用响应面板及其图像标签，只分离优化器轨迹。预注册 H7 门槛确实通过，但“轨迹留出”不能替代“源像素留出”，也不能据此把原 B09 整体标记为已闭合。新 primary/retention 的源身份隔离、模型／策略冻结和访问边界部分已核验；轨迹审计源像素独立这一条仍未满足。

实际 H7 终段选择零倍率的块数为 28/36、15/36、29/36，非零 SGD 步分别为 64、168、56；普通方案每个模型执行 288 个非零更新，倍率由原开发集选为 0.25、0.25、1.0。零倍率仍执行梯度和探针，不能宣称因此节省训练计算。这里观察到的保守路径是解释线索，不是“保守造成最终差异”的因果证明。完整状态、预测／动作和计数已由独立训练审计及预定前两块重放核验。

[动量构造见证](MOMENTUM_WITNESS.md)还表明，固定参数、仅翻转动量方向时，H7 和 richer25 可完全相同，但后续值及最佳动作可以不同。这排除了包含这些构造状态的域上的强全局闭合；并未证明反向动量状态属于当前策略可达分布，也未否定可达分布上的实用近似。richer25 没有加入缺失的动量方向。J/K 的描述性终点也不能为特定七维场的唯一性或充分性背书；J 的两个观察器相对 C 排序不同，K 的保留门槛未通过。

## 4. E−G 的流程中介与 I 重置的限制

E 和 G 共享原生表示／读出搜索程序，但分别在各自 checkpoint 上重新拟合并选择读出。实际 seed17 是 E 的 pure native 对 G 的 raw16 hybrid；seed29 则反过来；seed43 两者都为 hybrid，但标准化和 ridge 参数不同。这些差异是预注册流程的一部分，E−G 合法比较“训练方法加相同下游拟合程序”的整体结果，不能被解释为共享同一组读出权重时的纯训练效应。C−B 在完全相同的固定部署动作下比较，提供更直接的训练增量检查。来源是各 `runtime/{seed}-{profile}/READOUTS.json` 的已冻结选择。

I 相对 E 改变了测试中的 `5,236/6,144` 次动作（85.22%）和保留中的 `1,315/1,536` 次动作（85.61%）。这证明状态干预影响当前读出，不证明记忆本身有收益：I 复用正常状态下拟合的头，输入分布被改变，没有独立拟合无记忆策略。E 在 seed29/43 选择了 raw16 hybrid，重置 native checkpoint 后仍保留原始两事件历史；因此 I 也没有移除全部历史信息。真正的已注册同信息参照是 F，而 E−F 未通过。

两次真实 `sparse_tick` 是有效的递归计算，但实验在每例重新初始化状态，只在两个自生成预览后作一次控制决定，没有外部新反馈、跨例持久学习或三因子塑性训练。原生状态是公共历史的确定性变换，可能贡献表示偏好和有限样本效率，不增加超出这些历史的观测信息。这里仍没有建立超越轻量历史的复杂度收益；工程 transport 改善不能代替 E−F。

## 5. 与 R45 的关系及建议 comments

R45 明确区分完整优化器状态、预先固定的观察映射、未来成本定义的价值、可实施的动作空间；并把可达投影残差、信息／策略损失、动作限制及系数／矩误差分别核算。论文自己区分可达分布上的实用低维近似与强全局闭合，也不把局部数值检查当成候选策略族上一致的误差界。[R45 主文，固定论文 pin](https://github.com/TrillionniumFoundation/ICLR-2027/blob/f8df0a6075f58f3ab9431a889b773cdf8d6e771d/revision_2026-09-26-r45/sections/r45_main.tex)。

本次连接的具体路径是：H7 在训练时间尺度上选择 LoRA 更新；更新后的生成器产生实际公开预览；Hepta 在模型参数冻结的推理时间尺度上压缩两次预览并选择后续输出动作。H7 没有直接变成 neuron state，native eligibility 也不是 SGD momentum。两层可以组合，但它们具有不同的状态、动作和价值定义。

因此，V2 最有价值的 comments 是：**“参数场是否能预测一个局部动作”与“该场驱动的完整策略是否改善目标”必须分别报告；本次前者通过，后者相对强普通训练尚未确立。** 这与 R45 的到达分布、信息和动作边界相容。本实验未估计其全部一致误差预算，没有求解／验证 Riccati、HJB、FBSDE 或标量 martingale 识别条件，不能把 H7 审计通过写成这些定理的实证认证。

精确的论文引用位置为主文标签 `sec:r45-framework`（完整优化器、`eq:r45-projection` 与 `eq:r45-forcing`）、`sec:r45-accounts`（`eq:r45-info-split`、`eq:r45-actuation`、`eq:r45-coefficient` 和 `eq:r45-value-budget`）。另外，[递归细节源](https://github.com/TrillionniumFoundation/ICLR-2027/blob/f8df0a6075f58f3ab9431a889b773cdf8d6e771d/revision_2026-09-26-r45/sections/r45_recursive_detail.tex)的 `eq:r45-riccati` 明确使用下一时点 continuation value，并区分单步 myopic 规则；H7 贪心八步控制不应被称作这项递归求解的复现。模块限制位于 `sec:r45-exact`／`thm:r45-exact`；标量层级边界位于 `sec:r45-hierarchy`／`eq:r45-hjb`／`tab:r45-dependencies`。

R45 新增的是冻结 GPT-2/Pythia 的受限非线性模块及精确完整词表聚合实例；本实验是 MNIST 构造的文本／图像生成器局部适配和两事件推理控制。两者的模型、动作度量、目标和时间尺度不同。当前负面或未决增量结果既不验证也不证伪整篇论文；它检验的是一条明确的工程连接。Hepta 的完整 stateful host、长期外界反馈和生产所有权尚未在本实验中检验，`DENY_ALL` 的边界保持不变。[当前递归范围审查](RECURRENCE_SCOPE_REVIEW.md)。

若另立下一轮研究，优先预注册三个可区分的问题：一是让局部价值目标与整段 continuation 对齐，并在独立的完整闭环开发轨迹上检查策略自身到达分布；二是在新的开发数据上研究保留约束／估计精度，随后用新保留样本验证，不能反复选择本轮 B/G/K 的阈值或样本；三是若主张 Hepta 的反馈优势，设计带新外界信息和后续合法决定的任务，并给予 current-only、完整历史及独立拟合 reset 控制相同机会。现有 D1 新审计条件因 H7 通过而未激活，不能在看过主结果后将其偷偷改成当前协议的补考。这些是下一份开发协议的待检验机制，不是本轮已经完成的修复。

## 6. 建议的精确 blocker 处置

保留原 closure criteria；区分“执行已完成”和“收益主张获支持”。下表是给 ledger owner 的建议，本稿没有修改 ledger。

| 编号 | 建议 status | 应写入的 resolution |
| --- | --- | --- |
| B01 | `closed_for_registered_development` | Pilot 响应／普通训练开发门槛及原 H7 分支响应门槛通过；限该 actuator 与面板。 |
| B02 | `closed_for_registered_local_trajectory_skill` | 冻结 G3/G4 及完整分支／预测先于结果的审计通过；不扩展成完整终段收益。 |
| B03 | `open` | B−A 双观察器主任务增益成立；B 的双观察器保留性非劣未确立，原完整条件尚未满足。 |
| B04 | `not_established` | C−B 与 E−G 均未获接受；pooled 点差负，校正区间含零；不宣称已证明劣势。 |
| B05 | `not_established` | D−A 仅 reward 通过，E−C 未通过双观察器增益；候选保留性通过不能补足增益条件。 |
| B06 | `not_established` | E−F 的校正区间与种子方向不支持稳定优势；不宣称两者等价。 |
| B07 | `partially_closed` | C/D/E/F/H/J 双观察器非劣通过；B/G/K 未确立；没有证实超过 −0.01 的损伤。 |
| B08 | 保持 `closed_for_transport_overhead` | 原生 parity 与 transport 工程问题已闭合；不升级为相对历史控制的效用或整体时延优势。 |
| B09 | `partially_closed` | 新 primary/retention 源身份隔离、冻结访问边界及 I/O 恢复核验部分已闭合；H7 fit/audit 共用响应面板，原条款要求的 development／trajectory-audit 源像素独立仍未满足。原 closure criteria 保持不变，也不声称全库未曝光或新 writer。 |

L01 定理级闭合与 L02 LLM 规模／生产集成继续为 `not_established`，它们是本轮的主张边界，不应临时变成一轮 MNIST 实验必须证明的新增任务。原 `eval/` 的 11,808 条完整记录已由恢复 parity 与相应新记录精确比对；它们属于同一冻结实验的中断重跑，不能并入样本量作为额外复制。

完整执行和完整证据可以闭环；没有通过的科学条件必须保持未通过。把这些条件改名为“全部科学 blocker 已成功关闭”，会丢失本轮最重要的结果。
