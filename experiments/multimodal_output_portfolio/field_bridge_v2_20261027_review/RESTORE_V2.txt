1. Obtain the source and authenticate the archive

Use a new source directory. Private repository authentication is required.

  git clone --depth 1 --filter=blob:none --no-checkout \
    --branch research/parameter-field-neuron-bridge-20261027 \
    https://github.com/TrillionniumFoundation/hepta-private-ci bridge_source
  git -C bridge_source fetch --depth 1 origin __AUDIT_SOURCE_COMMIT__
  git -C bridge_source sparse-checkout init --cone
  git -C bridge_source sparse-checkout set \
    experiments/multimodal_output_portfolio/field_bridge_20261027 \
    experiments/multimodal_output_portfolio/field_bridge_v2_20261027 \
    experiments/multimodal_output_portfolio/field_bridge_v2_20261027_review \
    experiments/multimodal_output_portfolio/v6
  git -C bridge_source checkout --detach __AUDIT_SOURCE_COMMIT__

Define paths to the downloaded immutable archive and its separately published
verification receipt. The receipt supplies archive bytes, archive SHA256 and
MANIFEST.json SHA256. An embedded manifest cannot authenticate itself.

  V2_SOURCE=/absolute/path/to/bridge_source
  V2_ARCHIVE=/absolute/path/to/hepta_field_bridge_v2_20261027_evidence.tar.gz
  V2_RECEIPT=/absolute/path/to/ARCHIVE_VERIFICATION.json

Verify every tar member and compression CRC without extracting a raw duplicate:

  PYTHONPATH="$V2_SOURCE" python3 -m \
    experiments.multimodal_output_portfolio.field_bridge_v2_20261027_review.evidence_archive \
    verify --archive "$V2_ARCHIVE" --receipt "$V2_RECEIPT" \
    --report /absolute/path/to/new_archive_check.json

The outer gzip CRC and every member's exact SHA256 must pass. Every scientific
gzip stream, including the recorded interrupted eval/ streams, is decompressed
to validate its CRC. The interruption did not corrupt their gzip containers;
the original incomplete scientific grid is still identified separately from
the complete eval_recovered/ cohort. No original evidence bytes are repaired.

One synthetic parser-test fixture deliberately lacks its eight-byte gzip
CRC32/ISIZE trailer: bridge_v2_review/primary-io-recovery-contracts-verified/
synthetic-original.jsonl.gz. Its original 125 bytes are preserved with SHA256
2b64c99c73215025f427f98950340755a0fd70d341ef7b25b55c759fe68db7e3.
EXPECTED_INVALID_GZIP.json and its manifest entry bind the exact path, bytes,
expected EOFError, producer source hash and successful original test receipt.
The verifier requires that expected failure and the original byte identity;
it grants no scientific gzip exemption. Creation checks all input gzip streams
before packing so any unregistered failure reports its member path immediately.

2. Selective restore or full restore into a NEW directory

The verifier can extract a selected dependency set while checking the ENTIRE
archive. It rejects duplicate/unsafe paths, symbolic links and existing output
directories. MANIFEST.json, RESTORE_V2.txt, SOURCE_PINS.json and the synthetic
fixture preservation receipt (when present) accompany every
selective restore. On a failed verification, its newly created restore directory
is removed; original archive and input evidence are never changed.

For a compact independent statistical check, restore only score rows, result
and completion metadata (patterns match whichever completed eval directory is
registered; the original interrupted attempt is preserved when present):

  V2_BUNDLE=/absolute/path/to/new_statistics_restore
  PYTHONPATH="$V2_SOURCE" python3 -m \
    experiments.multimodal_output_portfolio.field_bridge_v2_20261027_review.evidence_archive \
    verify --archive "$V2_ARCHIVE" --receipt "$V2_RECEIPT" \
    --extract-to "$V2_BUNDLE" \
    --select 'bridge_v2_primary/*/rows.jsonl.gz' \
    --select 'bridge_v2_primary/*/COMPLETE.json' \
    --select 'bridge_v2_primary/RESULT.json' \
    --select 'bridge_v2_primary/EVALUATION_COMPLETE.json' \
    --select 'verification/results_audit.json' \
    --report /absolute/path/to/new_selective_restore_check.json

For full byte/media/native audit, restore everything into a DIFFERENT new
directory after checking adequate free disk space:

  V2_BUNDLE=/absolute/path/to/new_full_restore
  PYTHONPATH="$V2_SOURCE" python3 -m \
    experiments.multimodal_output_portfolio.field_bridge_v2_20261027_review.evidence_archive \

Keep audit outputs outside restored training/ and runtime/: their complete
inventories are bound by PRETEST_FREEZE.json. Use a new report filename for each
audit; existing original reports must not be overwritten.

5. Preserved evidence and interpretation

The bundle includes all 18 pilot candidate records/checkpoints, H7 fit and audit
branch banks, all frozen predictors, inactive D1 enrichment, native/history/
hybrid/momentum diagnostics, source-identity reservations, contracts/replays,
final training states, all runtime heads and banks, and complete primary media,
rows, decisions, provenance and independent audits. Failed/null diagnostics
remain in the evidence. H7 passed its original gates, so D1 fresh audit was not
activated. A primary null result is not converted to success by archiving it.

If eval_recovered is registered in EVALUATION_COMPLETE.json, eval/ is retained
as an infrastructure-interrupted attempt. The recovered cohort uses unchanged
scientific files, models, readouts, source identities and random schedules;
recovery/parity receipts document the storage-only repair. It is not an extra
statistical replicate. Use only the registered completed directory for final
statistics, with the supported audit alias selected by completion metadata.

MANIFEST.json records each payload's path, length, mode and true SHA256. Its own
SHA256 is external to avoid a recursive self-hash. The external archive receipt
binds the whole compressed file. Same-host hashes and process chronology prove
internal consistency; they are not independent execution attestation.

The study remains a constructed historical MNIST text/image task conditional on
three recovered model seeds. It does not establish a global parameter-field
sufficiency theorem, LLM-scale benefit, unseen writers or production ownership.
Original V1 raw evidence is preserved separately and is not duplicated here.
