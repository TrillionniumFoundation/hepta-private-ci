# Actual neuron feedback, bound continuation values, and the retained tail failure

This directory extends the previous bounded research control experiments. It
uses the original `AgentdNeuronOwner`, numerical kernel, durable journal,
witness and native capability profile. Native authority remains `DENY_ALL`.
Research media delivery uses a separate, scoped host permission. No result here
grants production authority or qualifies a general multimodal foundation model.

The principal results are:

| Question | Actual result | Scope |
| --- | --- | --- |
| Can an actual delivered scalar change persistent neuron state, a later neural generation action, and external semantic reward? | Yes: strict success improves by 0.109375 and net utility by 0.191424 against the zero-feedback intervention, with positive paired 97.5% intervals. | 128 fresh source pairs, five matched arms; a finite digit-order preference task. |
| Does the predicted native future match real admission, expiry, refusal and cold continuation? | All realized trajectories match, with every forecast and recovery kernel charged. | Original binary, frozen readout and the specified generator. |
| Does native memory beat the same-information history or generic ten-state control? | No: actions and delivered bytes are identical. | The controls deliberately pay the same owner work; this does not establish lower cost than an optimized history implementation. |
| Can a changed generator silently reuse the old critic? | No: eight artifact changes are rejected without altering live owner state; valid guarded historical execution matches the original preflight. | Exact generator, decoder contract, runtime, readout, empirical law and pooling version. |
| Does a new public readback calibrator pass the original ECE and declared OOD gates? | Yes on one independent 1,024-pair qualification: ECE 0.008350 overall and 0.023705 on ID; OOD 0/600, one-sided 95% upper 0.00498044; nonzero coverage. | Both-inputs-missing declared OOD only; all rejected candidates remain in ECE. |
| Is the additional semantic loss-tail gate closed? | **No. Three incorrect commitments out of 424 ID cases exceed the frozen 0.004999 limit. Candidate promotion is refused.** | Selective coverage is 116/424; the heldout realized entropic moment also exceeds the prediction. |

## Original semantic feedback qualification

The generator is the previously selected seed-17 `joint_uniform` checkpoint,
SHA-256 `508931a0cb780d413bc39de83b8de91aeab68b33cfe1b384f176cb8e8f004ee6`.
It actually encodes public image/text observations, executes two learned
transitions, and decodes a PNG plus UTF-8 caption. The hidden preferred ordering
does not enter this interface. Missing pixels retain a zero mask; an available
class hint denotes the original source digit, not the hidden preference.

The external evaluator sends a scalar only after initial media delivery:

- `+1`: the actual caption expresses the preferred digit order and its relation.
- `-1`: it unambiguously expresses the opposite order and that order's relation.
- `0`: neither order is expressed unambiguously. This includes invalid or
  semantically incorrect text; unknown feedback is not treated as a negative
  order instruction.

Four prefix ticks precede delivery. Feedback enters tick five. The process
closes and exits; a new process recovers the original journal, witness and event
ledger. Two later ticks have zero new drive. The original ten-dimensional
eligibility state is read at tick seven. A proposed swap can run the real
generator only when owner expiry and remaining generation budget permit it.

The eleven-coefficient readout was fitted using actual historical candidate
outputs and 96 original-owner state paths. Same-information history and a
generic ten-dimensional recurrence were fitted as controls. The empirical
continuation law retains joint records of feedback, initial output and
alternative output; it does not multiply correlated observations as independent
evidence. Validation selects pooling strength eight. Exponential utility is
applied before averaging. This is a learned finite empirical law, not a supplied
oracle law of future qualification results.

Every episode pays for 50 original kernel executions: 16 actual API/branch
ticks, 24 forecast journal/ledger replay steps, and ten cold-recovery steps.
Numerical fees are 0.0001 per kernel, 0.01 per generation, 0.002 per delivery and
0.005 per refused proposal. These are task utility units, not measured currency
or energy. Python CPU, native child CPU, wall time, generation and readback are
also reported. The 128 separately rendered permutation-reference deliveries
are retained and costed outside the five arm totals.

Numeric minus zero has strict-success 97.5% interval `[0.046875, 0.171875]`, net
utility interval `[0.0923913, 0.2995098]`, and CE interval
`[0.0640209, 0.2223740]`. Nineteen actual correction decisions and final bundles
differ. Native numeric mean measured Python-plus-native CPU is 228.65 ms and
wall time 564.69 ms; this cost is not omitted from the record.

The zero intervention is `do(F=0)` through the frozen policy trained on genuine
unknown captions. It is a mechanism ablation, not a newly optimized blind
policy. Permuted feedback uses one fixed derangement across the test cohort;
its source-pair bootstrap is conditional on that realized donor graph and is
not an unconditional new-cohort/shuffle confidence interval. The primary
numeric-versus-zero comparison has 128 distinct source-pair units.

The original qualification contains 640 actual episodes, 32,000 kernels, 728
generations and 1,456 media files. The independent full native replay recovered
all 640 cold states and reopened 4,352 media files including historical and
reference deliveries. Maximum utility discrepancy is 5.96e-9 and maximum
forecast formula discrepancy is 2.0e-15. A separate peer independently reopened
the qualification outputs and reconstructed its scores and decisions.

Its early semantic diagnostics remain failures. Low point ECE did not establish
safe semantic acceptance. These diagnostics used wrong-semantic-output rate;
they are not the legacy native OOD acceptance FAR. The old diagnostic's 0.20
coverage threshold must not be described as the unchanged legacy 0.25 gate.
Its non-smooth ECE percentile bootstrap also has finite-sample bias; it is not a
production confidence certificate.

## Bound generator and continuation interface

`BoundCritic` verifies actual artifact bytes before predicting. It binds the
checkpoint, original binary, native readout, calibration proof, complete decoder
dependency contract, empirical joint fitting records, fitted control heads,
pooling selection and policy protocol. The new Gaussian latent actor developed
elsewhere in this work has a different generation distribution and cannot use
this critic without new fitting and validation.

Binding hardening was added after the first 640-episode qualification began.
That run's exact executed sources remain sealed. Eight stale-artifact rejection
tests preserve live owner status and durable bytes. A further three historical
episodes execute the guarded positive path: all forecasts, actions and actual
output bytes match the original preflight. These checks do not rerun the test
cohort or retroactively change which code produced it.

## Public readback calibration and the single new qualification

The later calibration task predicts strict correctness **after candidate
PNG/UTF-8 readback and the arrived scalar, before host confirmation and private
candidate grading**. It does not claim to forecast unseen candidate pixels.
The public reward recognizer supplies probabilities and embeddings; the heldout
audit recognizer supplies historical supervision and later private scoring.
The policy never receives the candidate's final private label or future feedback.

The first simple confidence selector and the first learned-head calibration
failed. Calibration 001 had adequate legacy-shaped metrics but zero entropic
commit coverage. It was explicitly retired into development. Refinement 002
keeps the fitted ridge-10 weights and intersects public head score at least
0.70 with minimum public digit probability at least 0.93. All grid outcomes and
retired failures are retained. The new calibration cohort has 256 ID plus 600
declared both-inputs-missing cases, with source hashes disjoint from head fitting,
head validation and the retired calibration. Its source pool is historical
generator training data; globally unseen-source calibration of the entire
generator is not established.

Offline calibration uses six actual native state paths to verify its frozen
action table. It does not claim a native process execution for each offline
calibration candidate. The later qualification performs an actual original
owner execution and cold recovery for every one of its 1,024 cases.

New qualification sources are 2,048 official test pixels, disjoint from the full
historical corpus, prior heldouts, earlier qualifications and all current
allocations. Images and labels are pinned, including the official label gzip
hash. ID and OOD corruption/preference/noise namespaces are distinct from every
development namespace and were frozen before outputs. This fixes the earlier
128-pair study's limitation of new pixels under matched corruption/noise patterns.

Five fixed probability categories cover every candidate: declared missing-input
OOD, unknown preference, caption inconsistency, selected public head, and other
known candidates. Jeffreys category means are fitted once. The legacy ten-bin
confidence-ppm ECE is computed both over the full cohort and over ID, including
all rejected candidates. Mask membership alone is not represented as a semantic
quality estimate: quality still comes from actual candidate outcomes and public
readback features. The declared OOD result says nothing about arbitrary unknown
OOD inputs.

Final host confirmation copies already generated bytes when the frozen rule
permits it. Abstention writes an explicit receipt. This does not erase initial
delivery, reopen an expired owner, authorize another generation, or change
native capabilities. A separate generation permit still strictly enforces
native expiry and the remaining generation budget.

does not replace it. The new run has 51,200 original kernel executions, 1,024
cold recoveries, 1,230 actual generations, 2,460 candidate media files, 232 final
confirmation media files and 610 refused neural proposals. All numerical future
states and actual generation admissions match. Execution costs total 80.03 s
Python CPU, 205.00 s native child CPU and 318.43 s wall; external private scoring
is separately recorded.

## Why low ECE did not close the loss tail

The three failures are qualification ID cases 45, 100 and 240. Case 45 receives
negative feedback and performs an actual later correction; cases 100 and 240
retain their initial candidates after positive feedback. All three have a valid
owner at expiry seven, correctly replayed persistent state and matching future
predictions. Their captions and relations are correct. The public recognizer is
confident, but the frozen audit recognizer disagrees on one generated image half
in each case. These are errors under the declared semantic scoring metric, not
a human image-meaning audit.

Historical selected calibration has 70/70 successes. Its deployed Jeffreys mean
is 0.99295775, whereas its one-sided 95% lower correctness bound is only
0.95810666. With gamma two, correct commitment utility 0.998, incorrect utility
-2.002 and abstention zero, commitment requires correctness above 0.98419706.
The deployed rule used the mean, not a conservative lower bound.

One incorrect commitment contributes `exp(6)`, approximately 403.43, times the
exponential term of one correct commitment. The predicted selected conditional
moment is 0.520956; the heldout 113/116 success realization has moment 1.550044.
Across the full cohort, predicted total moment is 0.988576 and actual moment
1.110088. ECE does not directly bound this conditional loss tail or weight errors
by exponential loss. The finite heldout realization is not a proof of the
population expected value, but the frozen additional gate demonstrably fails.

`admission_diagnose.py` is a read-only failure explanation. It does not use these
three examples to fit a new filter, alter a threshold, rerun qualification or
expand its cohort. `admission_promotion.py` requires the additional semantic-tail
gate as well as legacy metrics and independent audit. This candidate is refused;
native production authority stays `DENY_ALL`.

## Evidence and reproducibility

The raw root is `native_semantic_20261027` in the shared workspace. It contains
all actual inputs, original model/readout receipts, media, owner states, native
transcripts, source snapshots, full rows and failed attempts. Curated result,
seal, independent audit and test receipts are copied under `evidence/`; the
archive index binds every raw file. Do not infer success from a directory name.

Retained technical failures include two initial independent replay attempts
(the second captured `File exists` from reusing an audit scratch namespace) and
the source-allocation consumer's pre-inference schema error. The audit tool now
uses a unique scratch directory per episode; original owner behavior was not
relaxed. The source consumer reconstructs pinned exclusion sets rather than
mistaking the manifest's excluded-count field for a list. No qualification
model output was produced before that consumer fix.

Four semantic boundary tests, the 60-episode original preflight, eight negative
binding cases, three positive guarded historical executions and three actual
native admission preflight cases precede final repository formatting. Scientific
source snapshots preserve the executed versions. Separate peer receipts cover
natural speech, video and document output/statistical reconstruction, including
posthoc merchant alias sensitivity. The speech timing addendum distinguishes
actual transcript readback from a small metadata-reread asymmetry.

`PEER_TIMER_CORRECTION.json` independently verifies the subsequent common-timer
measurement: all 256 actual transcript and metadata files are reopened, all
original transcript bytes, encoder hashes and beam choices are unchanged, and
the 16-speaker cost intervals agree within 1.12e-16. Both the common core timer
and the metadata-inclusive timer retain the CPU/wall cost result. This is a
measurement correction on the same cohort and fixed policy, not a new quality
qualification; the cheaper fixed-greedy limitation remains.

The full control archive contains 49,898 registered files, 410,741,726 payload
bytes. `archive-restoration/002/RESTORE_RECEIPT.json` records writing, fsyncing,
closing, reopening and hashing every member through a unique temporary file;
the largest simultaneous payload is 38,299,568 bytes. The main archive hash
remains `37f4e8b887948031f30b64eef07733f5542241565fabd51bd1e62cd767b75c6d`.
The first restore attempt, which reused one temporary pathname, reopened a
28-byte caption as 896 bytes of witness data. Its actual file, source, log and
failure receipt remain under `archive-restoration/001/`; the exact filesystem
cause is not established. The original archive and that archive member still
matched their sealed hashes. The successful retry changes only audit temporary
filenames. These later restoration and peer-timer receipts supplement the
immutable main archive.

No end-to-end gradient through the native owner, general audio/video synthesis,
Hepta-specific superiority over sufficient history, semantic production grant,
or closure of the additional loss-tail blocker is established here.
