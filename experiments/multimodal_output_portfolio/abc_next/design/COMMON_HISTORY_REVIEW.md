# 共同公开历史真实诊断：执行结果与边界

**结论：真实生成、有限目标积分和独立 future 评价已完成。数据给出可继续改进公开条件价值的点估计信号，但没有建立统计显著的通用反馈增益。经验 oracle 的较大优势含有在线策略无法获得的私有目标和未来信息。旧 Q1 还暴露了一个可以直接闭合的结构性错误：在最后一步选择只改变 latent、不改变已输出内容的 semantic 动作。**

本报告对应一次预先冻结的 H1 运行，不涉及主实验新的 test 来源。结果不能外推为 H2、全模态或全局最优性证明。

## 3. 经验 oracle 信息分解

以下表格使用评价分支的**完整经验潜在结果表**计算，并以八条固定历史均匀混合的 CE 呈现。它们是同一表的可核查信息松弛值；包含样本取最大值的乐观性，不是总体最优性证书，也没有用于部署选择。

| 提供给选择器的信息 | Primary 经验混合 CE | Secondary 经验混合 CE |
|---|---:|---:|
| 只给当前完整公开历史，表内选最佳固定动作 | -0.536336 | -0.539083 |
| 额外给私有目标 | -0.487000 | -0.482501 |
| 额外给所有动作的未来潜在结果表 | -0.510537 | -0.511438 |
| 私有目标与全部未来结果都给出 | -0.395335 | -0.385950 |

Primary 中，后两种隐藏信息同时给出，相对于公开信息表内最优的差为 **+0.141001**；Secondary 为 **+0.153132**。这些差值不能作为在线策略可利用的收益。

Primary 的“只给目标”差为 +0.049336，“只给未来表”差为 +0.025799；两者相加仍小于共同信息差，交互项为 **+0.065867**。Secondary 交互项为 **+0.068906**。因此不能把目标优势和未来优势强行分成唯一的、可直接加总的两份。

公开信息表内最优与独立 fit lookup 也不同。Primary 公开信息经验混合最优为 -0.536336，fit lookup 在独立未来中为 -0.537490；不能把前者偷偷替换成后者的真实期望值。对真实条件最优值的注册同时界仍然宽：Primary 平均条件 CE 为 **[-0.586786, -0.040438]**，Secondary 为 **[-0.586786, -0.071733]**。lookup 平均条件 regret 的上界分别仍为 **0.611752**、**0.581620**，下界都是零。

这表示“有限真实诊断已经完成”与“已证明条件最优控制”是两个不同状态；后者没有成立。

## 4. 每条历史的动作和结构性错误

| 历史 | 公开 swap / 初始草稿序号 | 旧 Q1 动作 | fit lookup 动作 | Primary 旧 Q1 CE | Primary lookup CE |
|---|---|---|---|---:|---:|
| 0 | 0 / 0 | refine_image | stop | -0.487703 | -0.484756 |
| 1 | 0 / 1 | stop | stop | -0.459831 | -0.459831 |
| 2 | 0 / 2 | refine_semantic | refine_text | -0.674305 | -0.572529 |
| 3 | 0 / 3 | refine_semantic | stop | -0.555558 | -0.553558 |
| 4 | 1 / 0 | couple | couple | -0.549962 | -0.549962 |
| 5 | 1 / 1 | refine_image | stop | -0.537528 | -0.532605 |
| 6 | 1 / 2 | couple | refine_text | -0.573901 | -0.572131 |
| 7 | 1 / 3 | couple | couple | -0.562563 | -0.562563 |

在历史 2 和 3，旧 Q1 选了 H1 semantic。原 runtime 对该动作更新 latent、保留原始图像和文字，且扣 0.002；停止保留相同内容而不扣成本。因此对**每个私有目标和每个未来随机分支**，H1 semantic 都被 stop 严格支配。这不是依赖 64 个未来样本的统计推断。

只将这两次 semantic 替换为 stop，八条固定历史的平均条件 CE 就能机械增加 0.0005。这个观察用于暴露约束缺失，不把事后构造的新动作表冒充预先注册的主要策略。

主线在四个新 critic 候选及相应 one-shot 中统一加入了这个已知运行语义约束：Q1 的选择与 Q2 continuation backup 排除 semantic；one-shot 排除以 semantic 结束的计划；H2 的首步 semantic 仍可用于后续真实内容修正。旧 legacy 策略保持原状用于复验。

**这项结构性改善属于所有四个新候选共有的约束修正，不能归因于新增 90 维 sensor 特征。** 与更多新 fit 数据、来源交叉拟合一样，它需要通过 matched 673/32 与 763/32 等候选区别于 sensor 的独立作用。

## 5. 条件矩估计证据与限制

在 Primary 的五动作独立条件矩估计上，旧 Q1 的八历史平均 MSE 为 **0.814573**；最大单历史 MSE 为 **2.794203**。完整报告列出每个历史、每个动作的预测矩、实测矩、CE 误差和有限集合同时误差上界。

这不是旧 critic 在一般任务分布上的误差估计。旧 Q1 没有在这个特别注册的 32 对有限 prior 上训练；误差可能混合了条件价值拟合不足和目标分布变化。完全缺失的输入也不允许新 sensor 凭空恢复私有目标：它能改善草稿质量判断和停止／继续的价值估计，不能变成隐藏目标 oracle。

MSE 没有被转换成均匀误差证书。CE-Q 的 argmax 与正矩 Z 的 argmin、绝对／相对 Z 误差到 CE 误差的换算，见 [`DESIGN.md`](DESIGN.md) 第五节。现有有限模型理论保持其原有条件；本次没有将训练 MSE 当成全神经状态的最优性证明。

## 7. 主线实现的独立边界审查

对 `abc_next/value.py` 和 `compact_tree.py` 的只读审查确认：按来源对分折保留了全部视图、生成场景与节点的依赖；Q2 使用另一来源折的 Q1 对实际 child 的预测，没有把真实最优 grandchild 当 Bellman label；NPZ 保存的是实际 Bernoulli 位图和自回归 token，关闭 archive 后重新读取并比对每个原始输出 SHA。

审查发现并由主线修复两类边界问题：fit 入口现在绑定新来源区间、完整来源／视图／场景 census、计划顺序及 manifest 的逐对 source IDs；route 部署和训练最后一步后的模型均拒绝非有限值。公共 sensor 运行成本与 673 维候选的真实部署成本也需分别计量。

新增独立 [`value_boundary_tests.py`](../value_boundary_tests.py) 六项测试在 **0.872 秒全部通过**：

- 错区间、source pair 错位、重复／缺失行、计划重排在拟合前拒绝。
- spy fold head 遇到自己的训练来源即报错；实际通过，验证真正来源 OOF 和 Q2 中的 H1 支配约束。
- 四个候选同时剪除 H1 semantic，并保留 H2 semantic→couple 路线。
- route 的 NaN、Inf、零或负矩拒绝。
- 在 optimizer 最后一次更新后主动注入 NaN，不能返回可部署模型。
- 实际 NPZ 关闭再读的像素／token 完全一致；像素翻位、token 改写和非二值概率输入均拒绝。

这些是来源与执行边界测试，不代表新 critic 或新增 sensor 已通过独立性能评价。主线最终 test 仍须按自己的新协议冻结、执行和报告。
