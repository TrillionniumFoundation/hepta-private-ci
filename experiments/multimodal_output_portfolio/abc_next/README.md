## 实际实现的控制方式

图文生成器维持已有的实际 Bernoulli 像素与自回归 token 发射。新增公共 reader 读取公开输入与实际草稿；两个离线 outcome observer 不进入在线特征。条件值学习预测正值风险矩，按其预测值选择有限动作。来源交叉拟合的 H2 backup 使用另一 fold 的 Q1，实际未来的最佳结果没有作为在线特征输入控制器。

在这个有限时域原型中，训练与评价采用已声明的指数风险效用。终端净效用的确定性等价为

\[
\operatorname{CE}_{\gamma}(\pi)
=-\frac{1}{\gamma}\log E\!\left[e^{-\gamma(U-C)}\right],
\qquad \gamma=2.
\]

`C` 是各实验预声明的代理动作罚项；实测毫秒和 CPU 另行计量。随机动作成本下，不能把上式替换为 `CE(U) − E[C]`。本实现是有限动作、部分可观察状态下的近似条件值控制，没有声称求得一般 Merton 问题或全模态模型的全局最优解。

共同历史诊断还识别了一个确定性结构错误：H1 的 `refine_semantic` 不再发射输出，却支付成本，因而被 stop 严格支配。新四候选统一消除了这个末步动作；H2 首步语义修正仍合法。这个修正与新数据、交叉拟合、公共特征共同进入新方案，不能把整个更新包的增益归因于新增特征一个因素。

## 已完成的共同历史与原生结论

共同历史实验固定 8 条公开历史、32 个私有目标及独立 fit/evaluation futures。其经验混合 CE 中，目标与未来均可见的 oracle 比表内公开选择高 **0.141001**。这属于隐藏信息诊断，不是在线控制可取得的收益。公开 lookup 对旧 Q1 的平均条件 CE 点差为 **+0.014177**，同时差值区间仍跨零，因此没有据此宣称 lookup 的正期望收益已建立。

原生分支训练并校准的模型是**当前已生成输出的正确性预测头**。它不是旧 future-latent dynamics predictor 的修复。一次独立 verification 的 ID ECE 为 **0.024466055**，通过原点估计 0.03 门槛；描述性 95% 区间上端仍为 **0.0506751291**。完全缺失输入的 OOD false acceptance 为 **0/800**，仅支持该公开可识别缺失 profile。

原始 Rust 路径实际完成**分别创建的 1,600 个单 tick 上下文**及其 durable acknowledgement/checkpoint/eligibility 恢复。这些上下文复用 verification 输出，不增加独立资格 N。含 durable witness 的外侧 tick P95/P99 为 **676/1,425 μs**。但上游生成器与公共特征本身的 P95/P99 为 **8.8469/13.3409 ms**，完整生成不能继承 resident tick 的 3ms/8ms 资源资格。

实际同上下文 resolver、两个非零候选、原 `propose_v2`、持久注册和重开已经执行。产品 admission 在零 learning-ledger head 前置检查处返回 **`ArtifactBinding`**；后面的 DatasetSnapshot owner、签名与独立候选验收没有到达。研究 proposal 保持 **`RequiresIndependentAcceptance`、`DENY_ALL`、零已应用更新**。两个候选在已用于选择的 development 上的 Brier 均略差，也没有独立候选收益证据。

## 时序结果的范围

真实语音分支实际执行 **64 个冻结事实组合、256 个情境、1,280 条生成路径**。所有未来语音均经过真实 Piper 合成，已经提交的前缀不被改写；独立 Whisper 只在生成后读取实际 WAV，未参与策略拟合或固定对照选择。

共享语义修正相对同成本 clamp 的净 CE 差为 **+0.120281**，预注册名义 97.5% 区间 **[+0.078879, +0.162828]**。反馈对 fit 来源上仅按 Vosk 选定的 `fuse_slow` 固定策略的净 CE 差仅 **+0.003575**，同等级区间 **[−0.027772, +0.033416]**。反馈 exact 成功率的点差为 **−3.046875 个百分点**，描述性 95% 区间也跨零。共享语义机制获得支持，反馈的独立收益未建立。这里固定的是动作 gate；它选中 fuse 后，仍利用 later cue 和与反馈策略相同的公开 posterior 融合算子修改共享内容。

这 64 组来自一个模板族、一个 voice。五个 seed 是 critic 的拟合 seed，不是五个独立声学生成器。初始与后续 cue 在受控 owner 中预采样，随后按信息边界释放；当前有一个 action gate，不是外界实时采集或长时域多 gate 控制。固定模板、固定声学模型和学得的语义控制，也没有构成端到端文字／声学联合训练或 video/AV 同步。
