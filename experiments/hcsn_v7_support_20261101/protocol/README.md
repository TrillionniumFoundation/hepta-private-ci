# HCSN v7：内容保留与控制增量的协议草案

## 当前状态

`PROTOCOL_DRAFT.json` 的状态是 **`blocked_on_v6_assets`**，`frozen=false`、`confirmation_started=false`、`scientific_results_generated=false`。

这是在上一轮可见结论基础上形成的可落地设计，尚未恢复 v6 源码、权重和全部输入身份，尚未选定新的确认对象，也没有执行 v7 科学确认。JSON 中的空值都是运行阻断条件，不是可以自动猜测的默认值。当前可找到的更早 v3 研究线不能替代 v6 的模型或证据。

报告中已知的 v6 提交和 bundle SHA256 仅作为恢复线索保存。它们与恢复后实际核验的字段分开；不得把旧报告中的身份字符串称为本轮已经验证的对象。

当前支持模块的范围仅为合成单步合同夹具，动作是 STOP 或下一段 1 秒 READ；WAIT、完整多步规划、强制首音频的适配、已拟合强头和新确认均未实现。以下章节描述目标方案，不能写成支持模块已经完成了完整科学流程。

## 这轮要解决的具体问题

v6 的强前端能够识别，但持续核心及自适应路径没有保住质量。v7 首先保留共同强内容头和相同的可见内容缓存，让各核心承担后续观察价值的预测。该阶段可以检验异步读取和等待的收益，不直接声称 32 个状态标量已经学会保存全部语义内容。

必须防止一个容易被忽略的空比较：如果 STOP 预测和未来价值都完全由共同缓存决定，核心会被旁路。这时 D−B 接近零是设计的预期结果；继续调参迫使解析核胜出没有科学意义。因此本草案同时保留强 `cache_only_value` 外部基线，并明确核心在哪个接口可以影响动作。

## 最小可执行接口

1. **共同因果缓存**接受实际完成并被接受的事件，仅保存已观察 encoder 特征、模态级别、时序对齐所需信息及公开元数据。所有家族共用同样的字段、精度、容量与淘汰规则。
2. **共同强内容头**从该缓存产生最终预测。当前正确性的估计应校准到实际 0/1 正确率，不把未经校准的最大 softmax 当作当前任务价值。
3. **32 标量持续核心**接收相同可见快照，按已接受模态的窗口增量推进。三个家族均有相同架构和预算的语义读出，预测某个合法后续路径执行后，共同头在真实接受／超时规则下的最终正确性。
4. **共同价值控制器**将该预测与相同服务模型提供的时间、观察次数和截止风险组合。控制目标、枚举器、合法动作、deadline 和 STOP tie rule 全部相同。

语义读出的参数属于核心接口并进入参数量与成本。由此得到的 D−B 是“核心及匹配语义读出”在共同控制下的增量；若要进一步声称增量来自解析传播算子本身，仍需固定动作和信号替换证据。不同核心的裸隐状态坐标没有共同语义，不能直接送给同一个固定线性 critic 后把校准差异叫作动力学差异。

缓存增加了总容量。报告必须给出缓存、核心、encoder 和控制器的内存，不能只报 32 个状态标量或称整体仍是 256 字节。

重复事件的处理分层定义：当前缓存层明确拒绝重复 `event_id`，防止第二次内容或核心推进；未来拥有请求生命周期的调度层可以对重传作幂等忽略。该调度层尚未实现，不能称缓存已经幂等接受重复事件。

## 保持 (2\times2\)，增加强无核心基线

| 核心 | 共同轻量读取规则 | 共同价值控制 |
| --- | --- | --- |
| 验证选定的持久 GRU／输入条件 SSM | A | B |
| 解析核 | C | D |

同时保留强音频、共同头完整读取、验证集选定的强固定读取策略，以及使用相同缓存直接预测未来价值的 `cache_only_value`。直接 GRU 与 SSM 结果都保存，普通候选只在开发数据上选择。

主要核心比较仍是 D−B；B−A、D−C 和交互分别解释。名义状态预算与训练机会匹配，并公开实际参数数量、单纯形自由度和家族先验。无核心预测器不需要填充无用参数，但其全部实际拟合和执行成本必须记录。

## 校准与内容诊断的顺序

先检查共同强头经过缓存接口后是否逐前缀、逐合法顺序保持预测。然后分别测量表示、对齐、状态、读出与动作造成的质量变化，避免同一次修复改变全部层级而无法归因。

价值监督使用配对后续轨迹的真实 0/1 正确性，且遵守同样的超时、晚到观察和输出规则。不能把“目标终点全内容正确率”直接当成未必能按时取得该内容的实际正确率。语义读出只预测正确性；风险、时间和观察费用由控制器各扣一次，避免重复扣费。

优先采用独立的开发拟合、选择与校准角色，校准后冻结模型且不再把校准对象用于重训。若采用交叉拟合，应覆盖所有与标签相关的投影、对齐、内容头、核心和读出，并明确未折外的部分。不同折独立训练的隐状态可能发生置换，跨折校准应使用语义明确的输出，而非假定隐状态坐标一致。

旧 v6 确认结果已被看过，可以明确降格为开发材料；不能再次称为 v7 的未见确认。

## 质量门槛不因本轮设计改变而回写

协议保留已知 v6 条件：情绪点准确率至少 50%、绑定至少 75%；演员下界严格高于各自机会水平；精确记忆每 fit、每格至少 99%；相对强音频／绑定强参考最多 5 个百分点损失；D 对 B 的正确率及实际按时正确率非劣边界为 2 个百分点。恢复原协议后必须核对其精确实现。

这些参考必须在新的同一确认对象上重算。历史的 72.5% 或 85% 不是新对象上的配对参考。共同强头完整读取可以证明接口保留了质量，但不证明新核心独立学会了内容，也不能让 v6 的失败结果变为通过。

## 新确认对象与实际子集

确认清单需要原始录制 ID、成员身份和历史使用排除清单；目前都留空。已用录制的新裁剪、新前缀或新配对不能算独立新录制，合成随机种子也不能替代真实 AV 确认。

演员若复用，必须按新录制限定主张并保持整演员重采样。实际执行子集应在看到结果前确定，至少让每个演员覆盖多种情绪、每种情绪覆盖多个演员，优先使用平衡演员 × 情绪网格。不能重复 v6 一名演员只对应一种情绪的混杂设计。

样本量、训练种子和实际运行规模需在开发数据上做精度规划后冻结。增加 bootstrap 次数、复制配对对象或重复 fits，都不会增加独立演员数。

## 机制归因的准确边界

| 干预 | 本轮能直接识别的范围 | 不能替代的证明 |
| --- | --- | --- |
| 去掉外部服务风险惩罚 | 共同风险项如何改变观察和截止收益 | 解析内部首达风险通道的独立价值 |
| 保均值的相邻两点计数分布 | 可达事件计数分布形状的增量 | 完整内容分布对单点隐状态的普遍优势 |
| 将多次转移合并为一次 | 输入局部窗口中多次内容转移的作用 | 单独不应期、物理 reset map 或软件恢复 |

保留自由动作和原 D 固定动作两条轨迹，区分内容变化与动作中介。先在开发数据上量化多事件概率质量和任务敏感性；在几乎不会发生第二次事件的区间，零差异不能被写成一般机制定理。

真正的分布见证应来自声明模型或实际数据可达的历史，例如均值相同而可达分布不同且后续最佳动作不同。不能任意拼两个模型不可能产生的分布，并将方差或参数仅透露给解析方。若共同缓存已包含充分信息、普通模型也能利用它，就应如实保留没有增量的结论。

冻结模型消融只能说明该模型对通道的依赖；是否必要还需要另一个重新训练、能力匹配的对照。reset map 与 refractory time 要单独定义；固定事件时间的 reset 干预是受控直接效应，不能冒充自洽闭环总效应。

## 完整成本与实际执行

主要摊销规模保持 H=20，H=10,000 作为敏感性。共同缓存、对齐、当前／未来校准、语义读出训练、控制枚举、传播、IPC、实际请求的编码、启动和关闭都进入明确账目。开发失败、全家族搜索、原始素材取得和审计另列，嵌套分项不能重复加到外层完整进程。

正常运行的主要成本与故障注入条件分别报告；没有预定生产故障过程时，不声称正常 H=20 已覆盖生产的期望恢复费用。故障必须同时报告是否保住状态、恢复用时和按时任务质量。

NumPy64 与 Torch64 应先在同输入、模型时间和固定动作下核对数值，再比较实际执行。真实服务时间导致剩余预算不同可以改变自适应路径，不能直接归因于数值不一致。旧 float32 兼容失败保留。

同时进程族内存只有在 PID/proc 身份映射和已知子进程覆盖通过后才可报告；单进程峰值不能替代家族峰值。吞吐使用实际共同调度包络；设备能量不可直接观测时保留空值。

## 失败如何结束一个主张

- 不能恢复 v6：交付支持工具和阻断草案，不能写“v6 重跑／v7 已确认”。
- 强内容或自适应质量守门失败：保留全部比较为诊断，拒绝质量守门后的核心／经济性主张。
- 共同缓存使核心无额外信息：说明这一任务不需要该核心，不制造解析必须胜出的条件。
- 只看到 B−A、D−C：归因于价值控制，D−B 另下结论。
- 分布或多次事件在可达任务中缺乏支持：缩窄到所测范围，不把近零效应当普遍否定。
- 解析核输给最强可实施同信息对照：保留结果。研究问题可以被诚实的负结果回答，不必把“闭合”解释成必须获胜。
- 确认后改变模型、门槛或数据：建立新版本和新的独立确认；不回写旧通过状态。

## 使用本草案

先恢复并核验 `required_before_freeze` 的材料，再在新的支持目录中实现接口和开发诊断。填齐字段并不自动令协议冻结；必须保存候选、数据清单、统计方法和输出路径的实际提交与独立见证。当前 JSON 不能用于启动确认或宣称任何新实证结果。
