## 内容接口的作用与边界

`content_interface/content_interface.py` 仅保留已经完成并接受的观察。特征复制为不可变 binary64 元组；两模态的对齐身份、源时间窗口和维度必须一致才允许配对。共同缓存的载荷和 Python 对象图大小分别报告；32 标量只是核心额外状态，不能代表总内存。

STOP 价值使用共同内容头单独校准的正确性预测。各核心的语义读出预测同一头执行后续动作后的正确性，风险与费用由共同控制器扣除。这样可以避免将一种模型的最大分类概率与另一种模型的预期正确率直接相减。校准是否真实有效仍须开发数据验证，类型标签本身不是拟合证据。

契约测试证明：保持共同 STOP 头不变时，改变核心提供的后继价值可以改变动作；给核心与无核心参照相同预测时，二者选择相同。这只证明接口存在可检验的通路。真实拟合读出是否使用核心状态、是否优于强无核心参照，仍是待检验问题。

当前实现只有单步 STOP／下一段 1 秒 READ。WAIT、多步规划、强制首音频调度、核心传播、模型拟合与 v6 adapter 尚未实现。确认入口始终拒绝，不能通过设置一个元数据标志将夹具升级成科学实验。详情与 17 项原始测试凭证见该子目录。

## 内存观测的作用与边界

`memory_observer/` 区分 `/proc/self` 所在视图的 PID 与父进程取得的 namespace PID，并通过 namespace 链、父关系和 start ticks 绑定身份。RSS 读取前后复核身份，避免将 PID 复用或映射错误写成有效读数。

已登记进程集合与自动枚举进程族分开报告。完整族采样还需包括所有已知、预期存活的登记身份；受控探针核对父、子、孙的精确集合。前后枚举一致仍不是持续原子观测，短命后代和采样间峰值可能遗漏，RSS 求和也可能重复计入共享页。

当前运行环境缺少 children 元数据，完整族观测保持 `unavailable/null`。受控三进程集合成功并不能关闭完整部署内存守门。独立审查的原问题保存在 `protocol/MEMORY_OBSERVER_REVIEW.md`；修复后源码与最终探针的对应身份、保留的早期源码及凭证见 `memory_observer/HANDOFF.json`。

## 协议决策

共同强内容头先保护输出，各核心及匹配语义读出承担后续观察价值预测。保留 A/B/C/D，并增加使用同样缓存直接预测价值的强 `cache_only_value` 参照。如果共同缓存已使核心冗余，零增量就是应保留的结论。

质量门槛不因支撑代码通过而改变。强音频与绑定参考必须在新的同一确认对象上重算。新的裁剪、前缀或配对不能让已使用的录制变成独立新对象；v6 已曝光确认数据如需复用，只能明确作为开发材料。

当前风险消融针对外部服务截止风险；保均值计数干预针对事件数分布形状；合并多次转移不等于单独识别 reset map、不应期或软件恢复。这些范围在协议中分别声明，防止将一个干预解释成多个机制都成立。

完整执行仍以 H=20 为主要摊销规模，H=10,000 为敏感性。训练、校准、选择、传播、控制、缓存、通信、编码、启动、关闭和恢复均需相应账目。测试费用不属于候选模型经济性；外层完整 worker 与内层分项不能重复相加。

## 复核与重现

从本目录在 Linux 上运行下面的命令；输出目录必须是新目录，旧证据不会被覆盖：

```bash
python3 run_checks.py --out /tmp/hcsn-v7-contract-recheck
```

实际组装后的测试日志与完整 worker 凭证保存在 `validation/assembled001/`。内容接口 17 项、内存边界 19 项、基线核验 4 项，合计 **40 项通过**；三个完整 worker CPU 合计 0.517153 秒，顺序执行包络壁钟 1.439443 秒。这是独立组装复核的费用，不是模型运行费用。基线核验测试使用明确标注的临时合成 Git 仓库，并未伪造或重建 v6 提交。

独立组件早期测试和探针也保留，不能把重复检查当成新增模型样本。组件归档内容以展开文件、历史快照和原始凭证收录。初审后的只读复查见 `protocol/MEMORY_OBSERVER_REVIEW_FOLLOWUP.md`。`FORMATTING_STATUS.json` 记录仓库要求的最终 `just fmt` 能否执行；未执行的格式检查不记为通过。

恢复材料后，用只读核验器检查提交、协议以及所有 sources/inputs 的精确哈希：

```bash
python3 restore_check.py --repo /path/to/restored/hepta-hcsn --out /tmp/hcsn-v7-restored-baseline.json
```

若同时提供 bundle，可加入 `--v5-bundle` 和 `--v6-bundle`。任何已提供但缺失或身份不匹配的 bundle 都阻断通过。核验器不导入、解包、修改或覆盖仓库；通过只表示可继续开发，不授权或证明新的科学确认。
