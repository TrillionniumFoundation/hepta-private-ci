# R14：跟踪实际隐状态的 rollout 控制器修复

**修复已实现并真实运行；这次候选不具备可接受的收益与成本组合。** 普通核心的实际效用增量在两域均未排除零；HX 上修复与原 DP 完全同行为、同收益，却显著增加计算。本轮保留候选及所有负向证据，生产启用仍为 false。

## 1. 改动与确认身份

原共同控制器计算 Bayes 最优续行，但普通 SSM 实际有自己的 hidden state 和更新误差。新选择器对每个第一动作按 actor 当前分布及 fitted world 枚举后继，并在评分尾部调用原 actor 的真实 recurrent 更新和原 value 策略。普通核心与 HX 得到同一规则，分别记为 B′、D′；原 A/B/C/D 全部保留。

实际执行在每次收到新观察后重新评分。**这些评分是“强制第一动作＋原策略尾部”的值，不能称为新 receding 策略自己的 Qπ，也不构成真实世界收益单调改善保证。** 新规则从未接收 true world、评估器后验、未读符号或隐藏实际费用。

源码和协议先发布至 `57f2143f81b0432928c4dbd893410bd1b6c3afe2`。6 项行为测试通过后、生成新 tape 前冻结，`SOURCE_FREEZE.json` SHA256 为 `02bcbeb444bbebdde61c368def7b63bc39a1b2361b98e1eb0f86a3bfcc87cd68`。所有 24 个 checkpoint 和普通模型选择保持原样，8 个 fit 没有重新训练。

独立源审阅在冻结前修复了两项具体问题：诊断计算原本可能影响实际 planner 的 LRU 缓存，现移到实际计时结束后，用独立模型和缓存重放；汇总现先检查来源、每个 worker 的身份/退出码/原始 hash 和完整 clock 覆盖，并拒收带 FAILURE 的目录。审阅记录位于 `review/INDEPENDENT_SOURCE_REVIEW.json`。

实际确认使用新的固定随机 seed：8 fits × 2 domains × 128 paired tapes × 6 policies，共 **12,288 次真实执行**，分为 96 个独立、串行、单线程 worker。域中的公开间隔分别为 IID {0.15, 0.45, 1.05} 和 OOD {0.05, 0.75, 2.10}，每次任务 3 步、最多 2 次 READ。

## 3. 全部 27 个公开时钟的有限模型期望

另外 16 个独立 worker 对每个 fit/domain 穷举 3³=27 个时钟日程并等权平均。评估器独自推进 true-world 概率；每个未来分支都再次调用**实际**策略选择器，对 B′/D′ 也重新执行修复规则。因此这里计算的是新策略自身的真实有限模型期望，完整区分于用于选动作的 base-tail 评分。合计 **2,592 个 fit/domain/clock/policy root**，所有质量误差不超过 3.56e−15。

这项 secondary 积分掉了此有限模型的 latent、观察和公开时钟采样噪声。它限于冻结的 20 状态、3 步合成任务；它不是目标连续过程证明，也不是新内容任务、无限长度或自然模态能力证据。

## 5. 结论与复核入口

本轮可确认：新 selector 的评分真正保留 recurrent hidden 后继；真实 repaired 策略的前向执行与全时钟期望均已运行；true world 与 actor 严格分离；原四臂及所有成本保持。

本轮不能接受：普通修复的稳定效用增益；HX 修复的能力增量；完整成本正收益；主动 RESET 收益；生产替换。对 HX 继续使用原 DP 已有的同行为廉价路径，不把新候选误当新能力。任何进一步训练或控制设计应使用新的协议和独立样本，保留本轮失败证据。

完整结果：`evidence/confirmation_01/SUMMARY.json`、`PROCESS.json`、逐 worker 原始 JSONL、全部 clock 明细；独立审核见 `review/`；科学源码身份见 `SOURCE_FREEZE.json`、`SOURCE_PUBLICATION.json`。原始文件通过父级 `publication` 的独立 gzip 容器恢复，所有原始 bytes 和 member hash 保留。
