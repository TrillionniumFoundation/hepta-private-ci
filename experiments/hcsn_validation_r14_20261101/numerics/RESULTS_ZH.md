# R14：零不应期、初始边界原子和任意观测分段

## 本轮结论

新增完整分布实现 `ZeroDelayFlow`，在预先固定的四个过程案例、三个空间网格及
独立梯度案例上完成执行：**70/70 普通检查通过，2 条故意错误的等价检查保留失败。**
原始记录共 72 行，不能写成“72/72 等价通过”。

这一结果闭合的是固定系数、固定正 reset、零不应期的小范围数值验收；没有替换
内容学习、价值控制或部署路径，也没有据此改变 `D-B` 的科学结论。正不应期的
恢复年龄表示继续由 R13 单独覆盖。

## 1. 修补了什么

R13 的恢复年龄参考要求正不应期、正初始距离以及固定时间格。新模块补入零不应期
分支，完整状态包含各事件计数层的活动位置分布、上边界流失与累计期望事件数。
达到零边界后立即记数并返回正 reset；同一区间可以多次触发。初始位置恰在零
边界时，在 `t=0` 记一次事件并移至 reset，即使请求的时间长度为零也不漏记。

状态由固定有限生成元的矩阵指数推进，观察时间可以是任意非递减实数，不需要
对齐时间格。输出始终保留完整位置分布；没有在一次观察后重建平均膜电位。

计数层保留 `N=0,1,2,3` 和 `N>=4` 溢出层。溢出层仍继续复位，累计事件奖励
不会被截在四次。自复位测试还覆盖了物理位置不变、事件数继续增长的情况。

## 3. 任意时间分段与真正的梯度

四个中途观察时间固定为总时长的 `.137/.419/.733/.991`。所有十二组一次推进
与分段推进的完整状态 L1 差异不超过 `1.00132769e-12`，包括全部计数层、活动
分布、上壁流失与累计事件数。有限生成元的这一半群一致性与上一节连续误差是
两项不同证据；没有把二者合并成“连续误差已经为零”。

梯度案例为 `x=.413,mu=-.3,sigma=.8,H=1.17,reset=.813`，避开每个空间格的
插值结点。切线方程真正微分同一有限生成元，覆盖 `x,mu,sigma,H,reset` 五量。
独立 70 位连续求和给出的梯度为：

`[-1.2436307339, -.9103809110, 1.0433480901, .5901312045, -.7308404087]`。

对连续参考的最大绝对误差随网格为
`.0072617533 → .0036190167 → .0022407351`。最后一个量主要反映位置插值的
空间近似误差，不是自动微分/切线失效。中间网格的切线对两种中心差商步长
`1e-4/5e-5`，最大差异分别为 `1.69217496e-9/2.45112042e-9`。
64 项与 128 项高精度连续求和也通过固定的尾项差异检查。

对空间插值结点、初始边界原子，此实现不提供普通空间/重置导数；相关请求明确
拒绝。该结果不覆盖那些位置的单侧导数、更高阶导数或学习移动边界。

## 4. 保留的失败揭示了什么

两个负对照的失败行保存在 `FAILURES.json`，对应的损坏识别检查分别通过。

| 故意错误 | 实际后果 |
| --- | --- |
| 每个计数层仅保留活动质量和条件均值，丢弃完整分布 | 最终完整状态 L1 差异 `.1289666697`，期望事件数差异 `.0374191320` |
| 整段至多记一次事件，在末端才复位 | 记录 `.8536888242` 次，完整过程实际为 `1.3146622741` 次，少记 `.4609734499` 次 |

第一项在重建时保持了各层质量与条件均值，所以这不是单纯的概率质量丢失。
第二项说明首达概率与重复事件数不能互换。

另一个独立自复位对照令有限状态的每次触发都返回同一位置，事件计数应为
强度 `4`、时长 `.73` 的 Poisson 过程。实际期望次数 `2.9200000000000004`，
计数分布及期望的最大误差 `4.44089210e-16`；没有因为物理状态相同而漏记事件。
