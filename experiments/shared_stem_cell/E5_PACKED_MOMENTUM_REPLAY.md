# E5 sparse Packed Head Bank: exact momentum replay at clean restart

Draft/shadow only. This source implements an additional missing layer above the 24-run synthetic CPU SGD microbenchmark: persist the **entire 64/256/1024/4096-Cell packed FP32 weight bank**, the selected Cell indices and their **SGD momentum tensors**. It runs an uninterrupted reference and a checkpoint-after-K-steps/resume branch on the same synthetic Q24 feature and synthetic labels. It requires every weight, every momentum element and the loss sequence to match **bit for bit**. Nonactive Cell weights are hashed before and after every training phase.

Use `e5_packed_momentum_replay.py` module `exact_replay(logical=64,active=8,cut=2,total=4,checkpoint=...)`. The optional create-only checkpoint file uses exclusive creation, 0600 mode, fsync of file content and a checksum over canonical JSON with little-endian f32 tensor bytes. The replay reads back actual serialized tensors without pickle and validates complete shape/dtype/finite values. The Scope, generation and logical Cell count must match the supplied identity; altered payload bytes, stale generations, mismatched principal Scope, missing optimizer state and incorrect selected indices fail closed.

The local direct checkpoint implementation completed **12/12** isolated CPU unit/adversarial tests including actual PyTorch momentum, clean disk reopen, corruption, second-write refusal and cross-Scope/generation controls. The pushed GitHub implementation is a new source module and exact-HEAD Actions must independently pass; local equivalent tests do not automatically qualify hosted tests.

**Important:** a clean restart and byte-equal optimizer replay are **not** the same thing as unclean crash safety. This file does not provide directory fsync, a journal, cross-process exclusivity, current revocation, signed Worker-origin attestation, durable CAS, actual supervisor generation fences or crash fault injection. It also does not execute actual Granite/mmBERT/Gemma weights or test any learned task quality. Every output has `authority=DENY_ALL`, `production_promotion_permitted=false`, and `unclean_power_loss_or_wal_verified=false`. Do not install in a privileged runtime, select a Stem or merge to main without separate independent qualification and `blocking-ci`.
