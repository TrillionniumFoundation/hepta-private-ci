## Scope and evidence boundaries

The source of truth is the **original native byte ZIPs** emitted by a single
successful exact-SHA GitHub Actions run for the frozen DINOv2-small + Granite
Embedding 97M R2 + Ridge Bridge on original retrospective Beans leaf photos.
A report JSON alone, self-declared success counters or unsigned SHA-256 inside
a report is insufficient. This standalone pure-stdlib audit requires four
**externally SHA-256-pinned** source / withheld / producer / independent
readout ZIPs, and fails closed on missing ZIPs. The source ZIP may never contain
future targets, and the withheld ZIP may not be made available to model producer.

Checks include:

- Exact GitHub ZIP bytes and size bounds, duplicate ZIP members, traversal,
  symlinks, encryption, noncanonical JSON, nonfinite JSON and altered contents.
- Original immutable Beans train/test Parquet identity, source and withheld
  manifest linkage, 36 TRAIN and 24 retrospective TEST examples with disjoint
  image hashes, group IDs and case IDs, and the 12/8 original class quotas.
- **Every original selected photograph**'s SHA-256, case/question identity,
  TRAIN caption anchors, independently withheld TEST caption/class labels.
- Original pinned DINO revision + safetensors digest, exact 36/24 image
  forwards as recorded, real image-feature rows and normalized 384D values,
  pinned original Granite revision and TRAIN encoded feature/forward receipt.
- Exact Ridge fitting artifact, sealed future geometry and class predictions,
  all four arms including the nontrivial frozen DINO nearest-prototype baseline.
- Recalculate 24 heldout correctness values and paired rescued/harmed/both
  correct/both wrong independently of the original scorer and compare them
  exactly to the original independent class report. The separate #2202 second
  opinion supplies the additional descriptive Wilson/McNemar/Holm summary.

The success of this **archive consistency** audit, when it can be executed on
real original results, does **not** independently attest genuine model execution,
publisher authority, real-world causal benefit, user ground-truth adjudication,
future time windows, cost-matched hardware, OCR/text/native five-arm parity,
no negative transfer or production readiness. Synthetic archive unit tests
never constitute a natural-image model result.

## How to execute only after the physical source run finishes

Independently obtain all four ZIP byte artifacts from the **same successful**
original [#2189](https://github.com/TrillionniumFoundation/hepta-private-ci/pull/2189)
head SHA and record each ZIP's SHA-256 **before** passing it to the auditor.
Never derive a pin by trusting a JSON field inside the same ZIP. Then run:

```sh
python3 experiments/shared_stem_cell/e2_beans_original_zip_review.py \
  --source-zip natural-source.zip --source-sha256 "$SOURCE_ZIP_SHA" \
  --withheld-zip future-targets.zip --withheld-sha256 "$TARGET_ZIP_SHA" \
  --producer-zip sealed-physical.zip --producer-sha256 "$PRODUCER_ZIP_SHA" \
  --independent-zip original-independent-score.zip --independent-sha256 "$SCORE_ZIP_SHA" \
  --output new-original-archive-review.json
```

The four archive IDs and byte digests belong in a separate immutable exact-run
observation once the actual physical experiment has completed and an independent
source witness has validated its run ID, source SHA, and four artifact IDs.
**Do not install a favorable fixture as the official result.** If any original
ZIP is missing, cancelled, queued, or mismatched, produce no positive readout.
