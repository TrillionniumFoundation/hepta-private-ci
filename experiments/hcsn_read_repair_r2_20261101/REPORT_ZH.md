# 有偿原始事件 READ：逐查询恢复与价格边界

在冻结的本地原始事件服务契约下，缺失答案的逐查询恢复验收通过。置信度策略在四个主条件中，Flow、Diagonal 各三个冻结种子及普通参考均达到全部答案正确、全部四问正确、覆盖率 100%。独立的双缺失与顺序/取值变化条件由同一保守 `always_read` 策略达到相同质量。成功来自实际取得缺失原始事件并重放前缀，普通参考同样成功；这不构成解析核心独有优势，也不证明不读取缺失信息时可以准确预测。

## 冻结与实际执行

- 方法、候选发布于 `ae554e7d074497c460c950585fe61a5fa8225d69`；协议 SHA256 `e40bee32da4b114b90aae37ba34269f5592b2752f126ebe8f1b0f6f29d207b0c`，候选 SHA256 `8db46c0d207452815a76e48442ff0421c77f7884c3ba67d50e028b84123a0ae5`。确认后源代码未变。
- 每任务 64 个登记确认 episode，三个任务 × 六条件 × 四策略 × 七模型视图，共 504 行。四主条件为基础、单缺失、128 干扰、单缺失加 128 干扰；两次级条件为双缺失与写入顺序/取值变化。长短条件共享成对底层世界，模型视图共享已执行服务轨迹，不能当作新的独立样本。
- 仅通过开发普通参考的实际续行效用选择简单价格阈值，三个任务均选 0.16；置信阈值固定为 0.95。确认中不重新挑选。
- READ 请求只含已经收到的可见缺失槽位编号；响应是该槽位的真实 24 字段 WRITE 及原始时间。服务不返回标签、依赖或教师后验。首次取得该槽位收费并等待 0.1；缓存重复读取免费且不再等待。
- 取得旧 WRITE 后在原位置重建内部状态并实际执行因果神经重放，保持后续覆盖顺序，不改写已经发生的环境行为。服务等待计入当前回答时钟并从下一源间隔扣除；新帧到达时检查重叠，决策不窥视下一帧或其时钟。登记源间隔至少 0.25，单问至多两次读取共等待 0.2。

原先靠总体简单查询稀释错误的边界，现在在实际获取信息后逐查询恢复。读完后的成功不补证未读取场景的可靠性。次级条件的置信策略虽在本批样本也全部答对，未知顺序律中仍可能存在可观察前缀相同、隐藏写入不同的情形；因此仅资格化不依赖隐藏生成律的保守全读策略，没有按测试条件编号偷偷路由。

## 信息与价格的取舍

效用定义为每 episode 四问平均正确率减实际 READ 总费用。以下为单缺失确认条件、六个神经拟合的均值；费用与服务轨迹共享，不把六个模型视图当作六次独立收费。

| 任务 | 置信 READ | 不 READ | 简单价格阈值 |
| --- | ---: | ---: | ---: |
| mqar | 0.772188 | 0.798177 | 0.872109 |
| selective | 0.837813 | 0.828125 | 0.899219 |
| binding | 0.778750 | 0.792318 | 0.862552 |

置信 READ 的逐查询质量较高，但效用没有胜过简单价格阈值；MQAR、Binding 的混合价格效用也低于不读。普通参考的读取质量完全相同，未读取及简单阈值的神经读出误差与普通参考不同，完整分项见 ACCEPTANCE.json，不能混用均值。

| 价格条件 | 神经均值效用 | 该价格 episode 数 |

## 审计与成本

- 确认实际执行 4,608 次策略/世界服务会话，2,493 次付费原始槽位请求；六模型视图和普通参考复用这些匹配信息，没有重复计服务会话。
- 神经网络实际执行 2,292 个前向批次、49,506 条逐前缀序列、2,412,840 帧。缓存只复用逐字节相同且哈希绑定的 x/dt/observed 前缀；日志与输出索引保留。
- 独立服务前置审计：576 会话、2304 次查询重放、116,352 个源槽位/时间检查及 17 个反例均通过。独立记录审计核对全部 504 行、18 个条件及 18,432 个查询前缀查找，验证账单、时间、输入、logit 索引与指标；没有声称重新执行神经训练。
- 完整子进程外层计量：开发准备 CPU 4.912695 秒、墙钟 15.845623 秒；确认 CPU 87.712136 秒、墙钟 133.416212 秒。两段不重叠 CPU 合计 92.624831 秒，内部重放计时已包含。确认 wait4 单进程峰值 RSS 262,623,232 字节，不是同时全家族内存。
- 训练专用神经结构 smoke 的 body-only CPU 3.549323133 秒单列，不冒充完整外层计量。开发、审计、协议发布和历史训练总成本仍有未计量部分；能耗、GPU、外部服务产权与生产 SLA 未验收。

## 保留的边界

本轮闭合的是登记本地服务契约中的“付费取得缺失原始信息后逐查询恢复”问题。有限合成任务与显式类型先验、不读取时的歧义、未知生成律下的置信证书、外部服务所有权及成本优势、解析核心增量和整模型采用均未被此次成功替代。`all_blockers_closed=false`，`production_activation=false`。
