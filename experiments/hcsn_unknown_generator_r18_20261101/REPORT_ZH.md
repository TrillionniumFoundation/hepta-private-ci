# R18：在新生成器参数上回答真正不确定的内容

本轮补上 R17“所有接受答案都是点质量”的有限缺口：学习的普通 Markov 混合参照，在预先冻结的 **90% 选择性可靠性标准**下，通过了新生成器参数确认。它实际接受了 **148 个仍有分数不确定性的答案，错误 5 个**；按生成器整簇重采样的一侧 95% 错误率上界为 **5.97%**，低于原 **10%** 风险限。没有用更宽松风险目标替换原标准。

这是四地址、四值、声明生成器参数总体内的普通参照结果。它没有闭合任意未知规律、真实开放域跨模态绑定、解析核心 D−B 或生产采用条件。

## 冻结、信息边界与独立单位

执行源码在训练、校准和确认前发布于：

`fd5a2e0d515761252fd94cffe055cf931dc2dbda`

`SOURCE_FREEZE.json` 的 SHA256：

`bbd4a25a8b1f99f6f55e48dafdf8bfcc00e4a0b20f4f98d3373218f42951484d`

拟合后的全部模型、OOD 截断和选择性阈值，在打开确认世界前冻结并发布于：

`c43797d5cdc5b19ad7c55b825b83e7ba4b89abfb`

`POSTCALIBRATION_FREEZE.json` 的 SHA256：

`5d0df7a76d015a5b7c0b10a0a562d3e1f21fcd3a509aae882a05e1fba6a8fb77`

两个阶段均有逐文件远端回读收据。训练用 24 个生成器、每个 32 个完整公开 token 流。拟合函数只接收这些原始公开流和生成器分组，不接收生成器参数、owner 目标或缺测后隐藏内容。Markov 粒子混合与 pooled-iid 经验 Bayes 对照使用相同训练信息。

每个生成器独立抽取非均匀类别分布、持续率和覆盖键调度参数。新参数从**相同声明总体**的独立连续抽样获得，不是训练集出现过的离散参数身份，也不是任意新规律。负相关 rotor 规律另外列为明确失配面板。

内容流包含六个真实 WRITE，随机穿插 8 或 24 个 distractor；均匀独立擦去两、三或四个位置，不透露缺失事件类型。查询只带 alias，程序实际通过四个观察到的 raw bridge 映射地址。20/100 时间间隔保留在输入记录，但内容模型静态，**这些间隔不构成连续时间传播或学习型长程保留证据**。模型可读取完整公开前缀，也没有建立受限流式记忆优势。

## 校准选择没有使用确认集

OOD 截断由独立 128 个生成器提供；随后风险校准使用 **2,048 个独立生成器，每个只产生一个查询世界**。每个模型预先固定四个候选阈值，分别对全部接受答案和真正分数答案求 Clopper–Pearson 上界。两个模型 × 四个阈值 × 两种风险共 16 个边界，采用 family-error `.05` 的 Bonferroni 校正。

只有两种错误率上界均不超过 `.10`、且至少接受 20 个分数答案的候选才可选择。无候选通过时保留接近点质量的回退，并将不确定性门记为失败，不在确认后修阈值。

| 模型／阈值 | 分数答案数 | 错误 | 同时校正后分数风险上界 | 校准门 |
| --- | ---: | ---: | ---: | --- |
| Markov，.65 | 523 | 55 | 14.69% | 失败 |
| Markov，.75 | 500 | 44 | 12.82% | 失败 |
| Markov，.85 | 426 | 30 | 11.11% | 失败 |
| Markov，.95 | 283 | 11 | 8.16% | 通过并冻结 |
| pooled-iid，.85 | 124 | 4 | 10.29% | 失败 |
| pooled-iid，.95 | 23 | 0 | 22.18% | 失败 |

其余 pooled-iid 候选也失败；完整八候选均保存在 `calibration_01/CALIBRATION.json`。没有把 23 个零错误样本当作足够的 90% 可靠性证明。

## 锁定的新生成器确认

正式主确认是 **256 个新生成器 × 每个四个相关世界，共 1,024 个查询**。统计重采样单位为生成器，保留每个生成器全部四个世界；没有把同生成器的查询当独立样本。4096 次配对整簇重采样、种子和零分母处理均已预注册。Bootstrap 区间是经验统计证据，不冒称精确有限样本覆盖保证。

| 指标 | Markov 混合普通参照 | pooled-iid 普通对照 |
| --- | ---: | ---: |
| 尝试／意外失效 | 1,024 / 0 | 1,024 / 0 |
| 真实目标支持丢失 | 0 | 0 |
| 实际接受／覆盖 | 907 / 88.57% | 814 / 79.49% |
| 接受中的分数答案 | **148** | 0 |
| 分数答案错误 | **5 / 148，3.38%** | 无分数答案 |
| 分数错误率一侧 95% 整簇上界 | **5.97%** | 无法建立 |
| 全部接受答案错误 | 5 / 907，0.55% | 0 / 814 |
| 实际 READ | 212 | 301 |
| 选择性收益，已扣 READ 费 | **0.840488** | 0.737910 |
| 预注册有限不确定性门 | **通过** | 失败，保留回退 |

分数定义是最大预测概率严格低于 `1−1e−9`；接近点质量不称数学确定性。本轮不是靠统计总准确率掩盖不确定查询失败。

预测概率本身仍有局部失配，例如最大概率在 `.65–.75` 的 16 个查询，平均置信度约 71.9%，实际正确率 43.8%。这些查询没有通过冻结 `.95` 接受门。**选择性风险通过不等于整个概率域已校准。**可靠性分箱和全部预测都保留，未删除低置信度阴性结果。

## 同信息的普通模型增量与真实 READ

纯概率质量比较使用购买 READ **之前、相同公开前缀**的 Brier 分数，避免把不同购买信息造成的分数差冒称同信息模型贡献。

| 指标 | Markov | pooled-iid |
| --- | ---: | ---: |
| READ 前 Brier | 0.082369 | 0.124998 |
| READ 前 log loss | 0.168531 | 0.257032 |
| 执行自身 READ 策略后的 Brier | 0.050104 | 0.075624 |
| 执行自身 READ 策略后的 log loss | 0.103427 | 0.150742 |

同信息 READ 前 Brier 改善为 **0.042629**，配对生成器 95% 区间 **[0.032333, 0.054135]**；实际选择性收益改善为 **0.102578**，区间 **[0.078354, 0.127773]**。冻结的普通模型比较门通过。READ 后预测分别使用自身策略购买的信息，其 proper score 不单独解释为同信息增量。

READ 返回原缺失位置的真实 owner token，可能是 WRITE 或 distractor。完整联合后验在原因果位置条件化，不把旧 WRITE 当当前覆盖。对 Markov 的真实 READ 策略，与同世界、同前缀、同阈值不 READ 的配对收益差为 **+0.087559**，生成器 95% 区间 **[0.069634, 0.106079]**。动作费用和拒答均计入；这不是从模型估计动作价值直接宣称收益。

上述结果来自两个**普通**概率参照。它证明了一个可用的有限机制实验和后续网络训练目标，不证明解析神经核心优于强 GRU、SSM、Transformer 或同矩阵 HMM。

## 失配与 fail-closed 的边界

1. **真实未见规律 rotor**：128 个负相关内容世界中，Markov 拒绝 50 个查询，接受 78 个，接受错误 0；但收益 **0.589063**，低于 pooled-iid 的 **0.811719**。其中只有一个分数答案被接受，不能作新规律上的不确定性可靠性确认。Markov 的前缀 OOD 分数拒绝 39 个世界，其余拒答来自置信度门。此面板保留明确的跨规律退化，不能声称所有未知生成器都被识别或有效服务。
2. **公开 schema 损坏**：32 个输入在可见 token 中放入协议外类别标记，两个模型均在推理前拒绝，零 READ、零回答，整体质量 `null`。这是输入格式／支持负例；owner 原世界仍属四类，所以它不是一个连贯的新增类别世界，也不是未知标签泛化证明。

OOD 截断是经验拒绝器，不是对任意新规律的普适识别保证。超过四个缺测位置、非法 alias 和协议外 token 均应拒绝；不静默投影成合法输入。

## 核查、成本与交付

独立小范围参照从缺失 raw event 的完整字母表枚举，核对两、三、四缺测的后验、READ 后继、重试语义、动作排序和真实 alias 映射：**2,040 项，最大绝对差 1.33×10⁻¹⁵**。风险校准 raw、错误计数、16 个 CP 边界和阈值选择另由独立审计重算。确认 raw 和整簇统计见 [独立确认审计](../../tools/hcsn/four_stage_r18_20261101/independent_unknown_confirmation.json)，校准见 [独立校准审计](../../tools/hcsn/four_stage_r18_20261101/independent_unknown_calibration.json)。另外，独立 owner 程序重放全部 1,184 个世界与 555 次真实 READ，公开前缀、mask、alias、query、时钟、价格及 owner 目标均相同，见 `INDEPENDENT_OWNER_REPLAY.json`。这些核对范围不代替生产所有权资格。

完整外层子进程计量：准备阶段 **15.088784 CPU 秒**，确认及两个负例面板 **7.802415 CPU 秒**，两阶段共 **22.891199 CPU 秒**。分别墙钟为 15.098776 / 7.812207 秒；包含解释器、导入、拟合、全部校准候选、失败／拒绝尝试及最终输出。开发和独立审计另计，不宣称完整项目生命周期已重新计量。

这不是逐模型在线时延比较。减少付费 READ 不代表降低完整物理计算成本：Markov 使用更多粒子，本轮没有建立质量相同条件下的 CPU、GPU、吞吐或能耗优势。

## 仍未闭合

任意新生成规律、真实开放域多缺测和长距离跨模态绑定、学习型受限内容网络、解析核心同信息 D−B、完整生命周期成本采用门、连续动态传播、GPU／能耗与生产 Rust 所有权仍开放。原 HCSN 四阶段门不因这个新的有限参照通过而自动闭合。
