# 同过程传播准备优化：完整模型复测

基线为 PR #4548 的 `a793d55c23a7742378b081b162252da428a9fdb2`。本轮实现了一个仅对 addressed 模型启用的精确准备适配器，并完成开发和新种子的完整模型复测。**数值资格通过；稳定整模型速度门没有通过。**

适配器将 P/T 两组 FP64 稠密指数合并成一个批调用，以累积最大值实现相同的因果策略索引，并省去 addressed 读出不消费的 J/G 线性求解。所消费的初始律、P/T、边界 remap、模型权重和内容写入语义均逐项对照。它没有使用新的概率近似，也没有改变 CTMC 动力学。通用 ContentModel 还使用 J/G/b，不能使用这个 addressed 专用适配器。

两项原训练开发权重的来源和哈希见 `CHECKPOINT_PROVENANCE.json`。源码及协议在提交 `5ed625e9bf1328261be468b19ce859bfe5bb06bc` 远端冻结，协调器完成读回后才开放确认种子 971603；本目录保存独立先后顺序记录。没有按复测结果修改源、阈值或选取检查点。

## 数值与梯度

- 19/19 项独立消费契约及因果边界检查通过，覆盖缺测、全未观测、零时长、无 mark、完整模型参数梯度与上下文恢复。
- 两阶段合计 336 项 NumPy 独立物理组装 / SciPy expm 参照检查通过，最大矩阵绝对误差 2.977e-08。
- 开发与确认各 10 组完整模型比较，logits 和全部模型参数梯度最大记录差均为 0。这个有限样本结果不构成全部参数域的统一误差证明。
- 另以独立 SciPy 中心差分验证 10 项物理参数梯度，最大绝对误差 1.147e-08；它只覆盖声明的初始策略区间，不是通用梯度定理。

## 成本与结论

四个互不包含的外层子进程包络合计 **200.842181 CPU 秒**，包含解释器导入和输出写入；内部主体计时已经包含，不能再相加。开发与确认的外层 CPU 分别为 99.167081 / 94.987544 秒。并行壁钟不相加冒称用户等待。安装、开发、冻结、发布和历史训练存在未计量部分，完整生命周期成本仍为 null，GPU 与能耗也为 null。
