# 真实音视频编码：90 个任务的正式结果

**总体收益验收未通过。** 90/90 个任务完整有效；独立复算通过 5,412 项检查、核对 584 个输入文件且没有错误。八个预注册主要比较中，只有等训练 CPU 预算下 HCSN J/G 对 LIF 的比较通过。Transformer 在两个预算条件下的平均融合准确率均更高，当前 HCSN 参考实现也更慢。

这里报告的是新演员的 CREMA-D 音视频特征编码研究，不能代表全模态基础模型。训练、验证、测试分别为 16/6/8 个互斥演员及 384/144/192 个片段，全部 30 个演员在本轮之前未用于该研究。每模态使用 32×128 的低层特征，整段离线插值；分类为六类。两个编码器和共享分类头共同训练，目标包含融合及单模态交叉熵和配对对比项。算子使用真实片段时长，但本实验不是在线因果媒体解码器。

五种模型使用同一信息、同一开发学习率集合和同一种子计划；活动骨干参数为 35,540–35,908。开发集先锁定选择，再执行八个正式种子的固定 256 更新及等 60 训练 CPU 秒两组。10 个开发任务、40 个固定更新任务和 40 个等 CPU 任务均保留完整证据。两种学习率和短开发训练不构成充分的 SOTA 调优。

## 2. 八个预注册收益比较

表内差值均为 HCSN 减对照，单位为百分点。95% 区间来自 20,000 次演员×配对种子的交叉 bootstrap；校正下界是八项比较的单侧 Bonferroni 下界。通过还要求均值增益至少 2 个百分点，以及 Brier 不恶化超过 .01、10 箱 ECE 不恶化超过 .02。192 个片段不是 192 个独立演员样本。

| 预算 | 对照 | 准确率差 | 95% 区间 | 校正下界 | 校准保护 | 全部门槛 |
|---|---|---:|---:|---:|---|---|
| 256 更新 | 普通双门控 | +2.799 | [-2.018, +8.073] | -3.385 | 未通过 | 未通过 |
| 256 更新 | Transformer | -4.232 | [-9.180, +0.716] | -10.482 | 未通过 | 未通过 |
| 256 更新 | LIF SNN | +8.138 | [+3.516, +12.500] | +2.018 | 未通过 | 未通过 |
| 256 更新 | Mamba-1 | +7.943 | [+1.302, +15.169] | -0.456 | 未通过 | 未通过 |
| 60 CPU 秒 | 普通双门控 | +1.758 | [-1.758, +5.273] | -2.865 | 通过 | 未通过 |
| 60 CPU 秒 | Transformer | -3.711 | [-8.138, +0.911] | -9.245 | 通过 | 未通过 |
| 60 CPU 秒 | LIF SNN | +9.570 | [+4.622, +14.909] | +3.255 | 通过 | 通过 |
| 60 CPU 秒 | Mamba-1 | +5.859 | [+0.977, +11.003] | -0.456 | 通过 | 未通过 |

固定更新对 LIF 的准确率校正下界虽然为正，但 ECE 增加 .063744，超过原定 .02 容限，仍判未通过。等 CPU 对 LIF 的单项通过不能推广成优于全部 SNN、Transformer 或 Mamba。

快基线在等 CPU 组执行了更多更新，而验证仅在跨过 30 CPU 秒及结束时进行。它们在这一注册时序下出现明显的校准恶化；这项结果应限定为当前参考实现与选择计划，不能将它概括为充分调优后基线的上限。没有事后改学习率、选择周期或验收门槛。

## 3. 内容融合与检索的限制

HCSN 固定更新组的音频单模态准确率为 32.2917%，等 CPU 组为 32.9427%，均高于对应融合准确率。全测试池的 audio→video R@1 分别只有 .1953% 和 .4557%；Transformer 为 9.1146% 和 7.8776%。随机排名的参考概率为 1/192≈.5208%，只是均匀随机检索下的解析参照，不是另一个已训练基线或显著性检验。

上述结果没有显示跨模态协同。正常配对与错配之间的变化也不能单独证明协同，因为本模型采用后期平均 logits 融合。测试演员只有八人，数据域仅一个；不支持自然语言、图像、长视频或通用全模态能力的推断。
