# Opt-in fixed-model HX local equity research

**Not production integration. Not a general HX solver. Global status: NOT_CERTIFIED.**

This directory is an independently reviewed, reproducible research artifact for exactly

    r=1/20, delta=3/100, sigma=1/4, m=2, P=60, C=4,
    pi=1/4, alpha=3/5, xi=1, k=3/200.

Inputs are exact rationals, not the slightly different mathematical values represented by default binary64 parameter fields. The asset argument is a finite binary64 value interpreted exactly. The boundary is the exact smooth-fit root B*, not `hx.boundary()` rounded to float. Runtime accepts only the inward-rounded binary64 range corresponding to `0 < log(V/B*) <= 2^-19`; all other values are rejected.

The generated `fastpath.equity(asset)` has a uniform relative error bound `2^-49` under the stated CPython IEEE binary64 nearest-even, unchanged-rounding-mode premises. It uses no Arb, SciPy or transcendental calls at runtime. The proof includes root splitting, Taylor remainder, rounded coefficients and each arithmetic operation. Startup smoke probes do not attest arbitrary subsequent fenv changes. There is no parameter or boundary override.

This is **not delta=0 support**. The frozen model has delta=3/100. Separate zero-payout research requires an explicit E(V)/V→1 normalization; it is not bundled here. No other unreviewed research candidate, compiled callback, training code, production default, guard or CI configuration is changed.

## Reproduce locally

From this directory, in a small isolated environment (Python3.11+ CPython binary64, matching version recorded in EVIDENCE.json):

    python -m venv .research-venv
    .research-venv/bin/python -m pip install --index-url https://pypi.org/simple --only-binary=:all: -r requirements-research.txt
    .research-venv/bin/python -B verify_root.py
    .research-venv/bin/python -B precompute.py
    .research-venv/bin/python -B generate.py
    .research-venv/bin/python -B research_tests.py

Do not use `python -O`: proof generators contain assertions. No network is needed after the optional official dependency install. Do not commit the venv or generated bytecode. `verify_root.py` writes ROOT_PROOF.json; `precompute.py` rewrites COEFFICIENTS.json, whose timing field naturally varies; generator output must be byte-identical. `precompute.py --no-artifact` runs the proof without overwriting the receipt. Compare all non-timing certificate fields, not just an exit code. Missing python-flint is a dependency failure, not a skipped/passed test. The generated runtime itself requires only Python's standard library.

## What failed and what is fixed locally

At two of the original five near-boundary assets, raw binary64 A7 was negative even though the exact-root model has strictly positive equity. Two effects coexist: arithmetic cancellation and a nonzero boundary offset from substituting a floating B into an exact-root-specific expression. The local oracle distinguishes raw-vs-literal error, supplied-boundary shift, and binary64-parameter representation error. This candidate does not clip negatives or silently promise to emulate off-root A7. The saved negative raw observations remain in EVIDENCE.json.

The first proof draft's normal-intermediate discussion did not explicitly propagate previous rounding; independent review required the final rounded-endpoint induction now present. That correction did not shrink the chosen domain or loosen the error target. An unavailable `/usr/bin/time` attempt was recorded; bash's built-in time supplied process-wall measurements without dependency/security changes. Separate delta=0 wrong-bracket experiments are neither hidden passes nor included in this positive-payout artifact.

## Cost boundaries (observations, not performance guarantees)

Warm median fast call was0.227microseconds versus0.784milliseconds for the old per-call ball-validated wrapper. Mathematical precompute was2.392milliseconds and warm module load0.411milliseconds. Under that *already-loaded-dependency* charge, direct3-call workload had not recovered setup;4 calls had. This excludes fresh interpreter/FLINT imports and generation, so it is not a full-lifecycle four-call claim.

Fresh standalone processes measured approximately94ms proof recomputation,67ms generation,26ms fast first-call process, and66ms old ball first-call process. They are not cold-filesystem-cache benchmarks. A direct three-process proof+generation+fast workload cost0.175s for128 calls versus0.176s old cold wrapper (near noise, not robust superiority), and0.163s for256 versus0.267s old wrapper (one observed improvement). No universal cold crossover or energy/CPU/GPU advantage is certified. EVIDENCE.json preserves full warm batches and these cold accounting scopes. The dependency was already installed for prior research; install/build cost is explicitly excluded.
