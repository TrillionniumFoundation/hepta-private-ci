## Proven mathematical identities and a previously missing counterexample

For the simplified GBM one-shot option primitive with fixed rate, payout and volatility, put-call identity holds for *all* positive V,K:

`C(V;K)-P(V;K)=V-K`.  A fixed-parameter scalar state does not produce independent Call and Put degrees of freedom.

The free boundary is `b=K beta/(beta+1)` and `m=log(V/b)`. Each normalized signal `C/K`, `P/K`, `m` depends only on **one ratio V/K**. Their Jacobian with respect to `(V,K)` has rank at most 1 and a null direction `(V,K)`: scaling both positive variables equally does not change any of these normalized features. This fact persists even in the stopping region. The normalized three-channel proposal **cannot identify absolute common-mode activation reserve** without an additional nonhomogeneous or absolute-level signal. Raw C/P alone retain amplitude, but still satisfy exact parity. If K is contextual, `dm/dV=1/V` at fixed K does NOT guarantee nonzero total input gradient: when `V=a*x, K=x`, the normalized features all have zero gradient with respect to x. No false claim that `margin` solves every vanishing-gradient problem.

Call smooth-pasting yields `dC/dV=0` at the default boundary, but Put derivative is -1. Continuation-side `dC/dV=1-exp(-(beta+1)*m)`, `dP/dV=-exp(-(beta+1)*m)` and fixed-K margin `dm/dV=1/V`; the *joint* feature contains a gradient path only under the stated fixed-parameter assumptions. A guarded CPU float64 implementation suppresses unused stopping-region exponentials (avoids the `torch.where(0*inf)` reverse-mode NaN failure at large beta). This is not FP32/f64-all-domain certification.

## Independent first-passage probability (not Put value)

For frozen boundary `b`, log margin `m>0`, GBM log drift `nu = r-delta-sigma^2/2`, and finite horizon T:

`Q = Phi((-m-nu*T)/(sigma*sqrt(T))) + exp(-2*nu*m/sigma^2) Phi((-m+nu*T)/(sigma*sqrt(T)))`.

The implementation computes a stable log-normal-CDF reflection formula and compares it against an **independent inverse-Gaussian first-hit density quadrature** `m/[sigma sqrt(2*pi*t^3)] * exp(-(m+nu*t)^2/(2*sigma^2*t))` on `[0,T]`. 180 frozen, randomly sampled bounded physical cases: worst absolute difference **1.6331380692236053e-13**; quad's own estimated error is not a certified interval. At/below b it returns 1 and invalid/unbounded arguments are refused. This constant-boundary probability is not the endogenous financial default probability or a trained event-time gradient.
