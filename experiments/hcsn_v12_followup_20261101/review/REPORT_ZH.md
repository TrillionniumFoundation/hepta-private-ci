## 内核单任务资源 profile：尚待实际 CI 凭证

源码审阅支持一个明确受限的条件结论：若真实记录同时确认新 owned
parent 的 `pids.max=1`、`pids.peak=1`、零 pids 拒绝增量、no-swap、
一致 inode、前后零任务、唯一本 root wait4 正常退出、任务组完全 drain
和删除，可信 gated worker 的整个进程族仅有该单任务，可把 root 的
wait4 RSS highwater 用作该 profile 的族 RSS 峰值。它包括该进程出生／
gate／exec 启动开销；外层 meter、核验器和准备投入位于另一边界。

该条件不适用于任意多进程部署、外部迁移、物理唯一页或设备能量。
cgroup charge 峰值还受已存在库页／文件页的所有权及共享缓存影响，须
与 RSS 独立报告。两种预先固定顺序也不提供冷缓存或采用成本优势证明。

`audit_ci_singleton.py` 已准备为后续真实 CI artifact 复核精确 head、
源／输入 Git blob、40 个唯一模型／轮次、1,440 个完整案例及上述内核
条件。**当前此节尚无实际 CI 通过凭证，状态为待验收。** 本地只读共享
cgroup 不能替代该检验。未来只有真实运行及其完整原始记录均通过，才
能补充这个受限 profile 的结论。
