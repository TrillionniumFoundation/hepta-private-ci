# V12 独立审核：反馈 rollout 与保守默认回退

最终源码的数值、服务后继和守门算术检查通过。正式执行中没有动作通过
第二池置信门，132 条反馈策略轨迹的动作、访问和输出与 light **逐值相同**。
这证明声明范围内的默认回退行为得到保持，没有建立新的控制净收益。

## 正式执行与结果

独立原始审计通过 **92,584 项**：264 主运行、132 固定动作回放、1,056 个
强制输出、586 次 READ（212 次实际服务失败）。独立重算每次观察更新、
失败留存、收费、预算、STOP 后继、输出类别、计数到内容混合及整数奖励。

反馈控制共有 2,036 次实际决策：1,974 次第一池选择，其中 1,278 次直接
保持 light；696 次进入独立第二池，全部回退；另 62 次终止/预算回退。
零次接受偏离。审计显式检查所有 132 条反馈轨迹与 light 的完整动作、
访问和输出相等，并非仅核对它们各自的固定排程回放。

每组先在世界内平均历史拟合，再对六个独立世界做精确奖励块统计：

| 条件 | 普通反馈−light | 解析反馈−light | 同控制 D−B，95%世界区间 |
| --- | --- | --- | --- |
| 匹配 | 0 [0,0] | 0 [0,0] | +0.055667 [−0.039333,+0.217000] |
| 隐藏恢复期错配 | 0 [0,0] | 0 [0,0] | −0.005667 [−0.025000,+0.008000] |

GRU 和 SSM 各自的反馈−light 同样为零，交互项为零。D−B 不是反馈
带来的增量，两个区间均跨零。历史拟合不是独立世界；训练预算和结构先验
也不匹配，不能据此关闭严格解析核心准入。

## 独立检查及原始失败

最终守门数值检查 **1,696 项**，另有 **152 项**入口/真实前向检查，含
9 类非法种子/样本量/alpha 拒绝及六个真实 512 池开发前缀；其中五项实际
进入第二池。奖励差先保留整数单位，完整未来 READ 费包含在范围内。

初版向量化头在 45 个场景中有 21 个与原标量输出不一致。其 READ 数和
完整反馈动作/状态哈希一致，差异来自均匀内容的浮点 argmax，进而改变
正确计数和奖励。失败源码、记录与 CPU 均保留。修复仅让均匀行按唯一
公开状态调用原标量头，没有重新定义平局来改善结果。相同 45 场景、
**1,080 个根动作×样本分支**随后全部逐值匹配；最终 guard 版本再次完整
通过，原始服务失败/成功、refractory、WAIT/READ/STOP 与末 tick 均覆盖。

正式 campaign 的六项前向覆盖规则在执行前声明：两条件 world0，各取
analytic91103、GRU81101、SSM81101 的首个进入 validation 的决策；若没有
则取 tick0，不按奖励或 LCB 挑选。六项均实际进入第二池。按原公开前缀、
冻结 512/512 种子和权重重跑后，pool hash、整数奖励数组、全部守门字段
和动作完全相同。**这是同实现的有限前向回放，不是第二独立 planner，
也不是全 campaign 每条模拟未来的独立模型重演。**

共同动作补证的最新独立审计通过 **3,486 项**：120 个普通核心运行执行
解析反馈 D 的相同动作，实际观察、访问、预算和费用完全一致。480 个输出
中有 400 个概率向量和 25 个类别不同，说明固定实际动作后仍有内容预测
差异；它不证明完整机制必要性或反馈净优势。首份共同动作审计保留旧字段
标签；第二份只更正为 feedback schedule，样本和覆盖相同，费用都计入。

最终有效检查计数为 **97,918**（1,696+152+92,584+3,486），45 个场景/
1,080 分支和六项正式前向另列。复跑与旧版本不重复冒充新增覆盖。

## 数学范围与执行成本

详见 MATHEMATICAL_SCOPE.md。给定固定公开 prefix、冻结模型以及第一池
选中的单个动作，第二池 Hoeffding 门只保证声明模型内的根动作加 light
尾策略比较。预声明至多 2,640 次检验、alpha=0.05/2640，模型内全族界仍为
0.05。实际 696 次验证的 alpha spending 是事后计量，不能冒称更紧的全族
保证。该界不处理真实物理/服务校准偏差、未访问前缀或全任务改善。

完整主 campaign worker CPU 为 **554.426242 秒**。包含于其中的执行主体
诊断：feedback **518.736444 秒**，light **3.565973 秒**，比 **145.47 倍**；
输出和动作相同，主体额外 CPU **515.170471 秒**。这些内层计时不能再与
外层相加，也没有覆盖外层导入、世界生成及序列化。测量属于本 CPU 参考
实现，不能推断 GPU 或焦耳成本。

代码开发、写作等成本未完整计量；完整进程族内存、设备能量、历史准备与
预训练成本仍缺。保守回退消除了本次实际策略的偏离，也增加大量计算，
没有建立完整经济性、真实 AV、统一解析神经网络或生产采用资格。
