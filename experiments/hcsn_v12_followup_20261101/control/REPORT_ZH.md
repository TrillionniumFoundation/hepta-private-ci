# V12：真实反馈 rollout 与独立验证 fallback

本轮完成了反馈尾策略、独立选择/验证池与保守族置信门，并修复了一个真实的
批处理读出缺陷。**实际控制净收益仍未建立：所有 132 条反馈策略轨迹最终都
与 light 的动作、观察和输出逐值相同，却增加了约 515.170471 CPU 秒执行主体
成本。** 这些实现与检查不关闭原质量、解析核心或完整执行经济性准入。

## 实现、失败与修复

第一池固定 512 条模型未来，比较当前 STOP/WAIT/READ 后逐分支执行自适应
light 尾策略。成功 READ 更新该分支观察，失败保留观察；请求即收费并消耗
预算，下一 tick 交付先于输出和决策；STOP 继续全部强制输出。所有根动作
共享同一批模拟路径和服务随机数，但不共享分支观察。

第一池选定非 light 根动作后，只用另一个独立 512 池比较该固定动作与 light。
单侧 Hoeffding 下界严格正才偏离，否则 fallback。全 campaign 预声明最多
2,640 次验证，alpha=.05/2640；差值界 K=剩余输出数/4+剩余预算*.04。
两池均使用冻结拟合 q，真实执行保留原服务律。模型内置信不保证真实任务
总体改善，也不包含物理校准误差、拟合 q 误差、CPU 或设备能量。

首次独立标量对照发现 45 组中 21 组的 correct/reward 不同，动作和后继都相同。
原因是未读 uniform 内容的浮点 argmax 在批处理与原标量读出之间改变。
修复为仅对唯一 uniform 公开状态调用原标量头，保留原实现的具体数值；
没有人为将近似 uniform 强制设为数学 uniform。失败源码、原始结果和费用
保留在 `review/source001/`、`SCALAR_AUDIT_001.json`。最终源码完整复核
45 组/1,080 根分支样本的整数奖励、correct、READ 和反馈状态哈希，全部逐值一致。
另有一次审计命令 module 路径错误，无模型执行，失败日志及 CPU 保留。

## 冻结与实际执行

来源、旧权重/选择身份、12 个新世界（每条件6个）、两个 512 池、seed namespaces、
alpha 和 fallback 规则均在正式世界生成前冻结。全部 480 个 world/tick/pool
seed 不同；跨 core 复用是声明的 common random numbers，不用其他 core 的
验证结果选动作。五个历史普通 fit 的 GRU/SSM 两族与固定完整解析 fit91103
全部保留。训练信息和结构先验不匹配，不能当作严格架构准入。

正式完成 **264 次主运行、132 次同模型固定动作回放**；另独立冻结并执行
**120 次跨 core 共同解析动作运行**。主运行有 1,056 个输出、586 次 READ，
其中 212 次模拟服务失败，所有费用保留。

| 正式决策分类 | 数量 |
| --- | ---: |
| 第一池保留 light | 1,278 |
| 独立第二池验证后 fallback | 696 |
| 无未来输出或预算 | 62 |
| 实际偏离 light | **0** |

共 1,974 个选择池和 696 个独立验证池。实际 alpha spending 只作记录；
不把事后实际验证次数乘 alpha 冒称更紧的 familywise 保证，预声明模型内
全族 delta 仍为 .05。

## 实际收益与 CPU

全部 core、全部条件的反馈策略减 light 实际净奖励均为 **0**，所有 132 条
轨迹的动作、访问和输出逐值相同。这是登记世界内的执行事实，不是模型外
普适不劣保证。相同控制下的解析 D−B 为：

| 条件 | D−B | 95% 描述性世界区间 |
| --- | ---: | --- |
| 匹配 | +0.055667 | [−0.039333, +0.217000] |
| 隐藏恢复期错配 | −0.005667 | [−0.025000, +0.008000] |

两者均未建立严格正增益。每条件仅6个独立世界，先在世界内平均历史拟合再
成块重采样，模型拟合总体不确定性未覆盖。实际收益定义仍是四项输出正确率
减实际 READ 费用；没有将 CPU 秒或焦耳静默折成收益。

| 执行 CPU 范围 | 秒 |
| --- | ---: |
| 全主 fresh-worker 包络 | 554.426242 |
| 其中 light 执行主体（嵌套） | 3.565973 |
| 其中 feedback 执行主体（嵌套） | 518.736444 |
| feedback−light 执行主体增量 | **515.170471** |
| 独立共同动作补充 worker | 4.506393 |

主体约145.47倍是此 CPU 参考实现的嵌套诊断，未包含包络中的全部导入、生成
和序列化；不能再次加到 554.426242 秒，也不能当作部署或能量测量。
全部 **14 个互不重叠包络 worker 完整 CPU 合计 620.406604 秒**，包含失败、
修订和复核，详见 `COST_LEDGER.json`。开发/最初烟测的完整 CPU、历史准备/
预训练、完整进程族峰内存及可归因设备能量仍未知，所以这是完整项目成本下界。
