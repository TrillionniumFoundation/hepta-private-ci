# Registered GRID recording-group frontend study

This separate study uses historical public [GRID recordings](https://spandh.dcs.shef.ac.uk/gridcorpus/). It tests first-command bin/set classification and a constructed audio/video/text consistency task. It does not confirm the CREMA-D DFA/IOM model, newly recorded people, open-domain understanding, an analytic-neuron contribution, GPU performance or production adoption.

The registered speakers are training **1, 3, 4, 5, 6, 7**, development **8, 9**, and confirmation **10, 11, 12, 13**. Every speaker contributes the first 16 lexical bin and 16 set MPEG members. `COHORT_SELECTION.json` pins all 384 member names, roles, sizes, CRCs, offsets, archive sizes and ZIP-directory hashes. Class-bearing filenames are known source metadata. Speaker 2 was excluded after public example discovery; 32 speaker-1 training files and one training frame had already been inspected for source availability and crop geometry. No global historical human-identity or pretraining exclusion is claimed.

Selected source payloads total **161,257,472 bytes**. Acquisition requests only exact HTTP206 ranges, with at most three concurrent requests. It reuses verified speaker-1 files and namespaces every other speaker's cache. It never downloads complete 400MB archives. Original MPEGs remain reproducible external inputs and are excluded from evidence uploads.

`data_v2.py` is the qualified input entry point. `data.py` and `data_v1.py` are preserved acquisition/decoder prototypes; their decoder is excluded from qualification. V2 verifies published source and protocol, the complete registered member row, the role acquisition ledger and its full raw SHA256 before decoding. Development prefixes require the published candidate; confirmation acquisition and prefixes both require it. The independent synthetic guard audit passed 41 cases without opening actual media.

The physical observation is a fixed one-second prefix. Video uses 25 last-original frames, a fixed native96 square centered at (.50 width, .76 height), and an88 center crop. This is a disclosed training-geometry adaptation, not 68-landmark alignment or exact LRW preprocessing. Full-file decoding and possible codec frame reordering mean this is **offline PTS-bounded observation**, not qualified online one-second arrival latency. Audio is cropped before16k resampling. No full-recording normalization or duration feature enters either encoder.

`study.py` uses immutable official pretrained encoders and fixed mean/std descriptors:1536 audio features,1024 visual features, plus26 literal-command character features. Binary classifiers use fixed C=.1 and three actor folds; independent clean AT and AVT heads use C1. Only training data fit scalers or coefficients. All heads must be frozen and remotely read back before confirmation payloads. The zero in protocol filename `ENC0DERS.json` is retained as a byte-identical alias; `ENCODERS.json` is canonical.

The audio weights use the official TorchAudio Wav2Vec2 ASR base960h bundle, with MIT weight terms and separately BSD-licensed software. The visual weights originate from the [pinned author lipreading repository](https://github.com/mpc001/Lipreading_using_Temporal_Convolutional_Networks/tree/0cc99fab046bd959578f2baac52e654746da4825) under its noncommercial research/benchmark terms. Broader commercial/production permission is not established. GRID's official page states research availability; broader raw-media redistribution permission is not established here. `SOURCE_IDENTITY.json` and the encoder provenance files retain these distinctions. Third-party checkpoint files are not republished.

Use CPU Torch/TorchAudio2.6.0, NumPy, SciPy, Pillow and ffmpeg, with one thread per worker. Checkpoints are resolved relative to the repository parent, not a previous session path. Source/publication guards intentionally reject missing or altered dependencies. Use fresh output paths and the inherited complete-child meter; inner fit timers must not be added again. CPU time is not converted to joules, and all failed attempts remain part of the evidence. Four confirmation actors support only the registered group's bounded interpretation.

The completed confirmation outcome is negative: primary video80/128 (62.5%), temporal76/128 (59.375%); shared AT82.5521%, primary AVT77.8646%, temporal AVT75.5208%. Both original/family gates fail. All128 confirmation sources qualified, while the full64 development role remains HOLD because three speaker8 sources are shorter than one second.
