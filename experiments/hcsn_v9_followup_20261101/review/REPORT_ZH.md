## 服务风险与重新拟合：源码语义审阅

新任务明确给 READ 增加真实成功/失败服务过程。风险干预只把规划预测
成功率设为 1；实际服务 uniform、物理路径、请求收费和预算保持相同。
失败 READ 不更新观测，仍消耗一次预算并收费。策略接口没有接受实际
未来路径；真实标签只在强制输出的评分阶段读取。

原一读规划器输出 `net = expected_gain - fee`。在声明的独立服务混合
模型中，新风险调整为 `q * (net + fee) - fee`，与失败后继续保持当前
观测的语义一致。此公式并不使原规划器成为最优多步控制器。当前解析
重新拟合只估计漂移乘数，不是完整解析神经网络重新训练；普通两家族的
五个拟合来自 v8，不能重复算作本轮新拟合种子。

最终 `MECHANISM_AUDIT_WITH_FIXED_RISK.json` 完成 **104,767/104,767**
项独立检查，涵盖 24 个新世界、2,040 次主执行及 72 次固定风险回放。
全部已冻结源和历史权重、每世界 85 次主执行身份、真实服务成功/失败
后的观测、强制输出、计数分布到内容概率的独立矩阵传播、费用和净效用
均核对一致。固定 D 动作下，风险预测干预的概率、实际访问、动作和费用
逐值完全相同，支持这项干预只经控制路径发挥作用。

同一风险感知控制下，匹配条件的 D−B 为 **+0.0208333**；失配条件为
**−0.0283333**。因此不支持一般正向核心收益。另一个独立统计审阅器
以分数重算每条 `correct/4 - reads/25` 奖励：匹配条件的描述性世界块
bootstrap 区间下端严格为 **0**，不能把浮点残差 `1.85e-17` 当成正
下界。原浮点统计与精确补充均保留在 `mechanisms/review/`。本报告的
标准库审核只重算配对点估计，不宣称独立重证该 bootstrap 算法或解析
核本身的全域正确性。

## 前端资产与进程族成本的结论

资产检查器仍依赖原 v6 固定协议 SHA 和真实 sources/inputs 身份。
新手写排除清单不能代替历史所有者记录。目前 27 个必要字段均缺失，
输出保持 `HOLD`、`admitted_for_confirmation=false`。新增 owner-ledger
解析器只接受明确声明的结构；尚未恢复原包，不能宣称真实旧包一定使用
这一结构。未知布局必须经审查增加解析器，当前检查器会拒绝。

当前 cgroup 只读且共享，实际创建隔离组返回 EROFS。能力检查器没有
声称完成可运行的 cgroup 工作负载计量；完整进程族内存和设备焦耳仍为
null。真实短命叶子的单进程 highwater 已超过注册集合的采样峰值，给出
该采样值不足以代表完整峰值的实测反例。正常/收养两组 CPU 为不重叠
外层包络，内层 wait4 和拟合计时不得再次加总。

因此，当前通过的是明确范围内的实现与记录一致性。强前端、新独立 AV、
完整持续解析 AV 四格、解析核心净增益、完整解析神经消融重训、完整族
内存、可归因物理能耗及历史准备成本仍没有闭合。
