# 前端资产准入与本轮来源调查

本轮交付可执行的离线证据验证器，并对实际已取得材料运行。原 v6 强头、强音频、完整历史排除及真正新独立录制仍缺失，`OBSERVED_RESULT.json` 为 **FAIL**。旧 v3 的 48 个录制与 8 位演员只记录为历史材料。

`admission.py` 校验实际文件字节数、SHA256、可选 Git blob 身份、固定源提交及角色。原 v6 协议与头必须绑定既有 v6 提交。它拒绝空排除清单、仅 v3 的“完整”声明、遗漏已知 v3/v5/v6/v7/v8、缺失探索及失败运行对账；声明中出现的其他历史 campaign 也必须全部覆盖。已知集只是最低覆盖下界，不能用于声称穷尽历史。

独立性使用原始录制 ID、采集 session、原始媒体哈希和派生祖先检查。改名、重新编码、裁剪或重新切分不会获得独立身份；缺少采集记录或派生声明也不能通过。确认索引固定全部任务、case ID、录制和标签；两个头必须覆盖完全相同的全部 case，不能各挑容易子集或更换标签。确认索引、原协议、两个模型和原始分类输出绑定后，验证器分别复算 AV 与强音频在原任务质量门槛下的准确率，缺项保持拒绝。

这是**提交字节与身份合同**。离线验证器无法自行证明来源提交真实性、采集凭据真实性或外部历史清单确实完整；这些必须在可信恢复和独立核对中建立。合成测试中的 PASS 只说明合同可满足，没有恢复任何 v6 权重，没有生成或声称任何新真实 AV，也没有科学/生产通过结论。原 v6 协议未取得，因此本轮未凭空规定它的任务类别、独立样本数或质量阈值。
