# 持久状态核心：合成开发实验

本轮补上 v8 普通模型每次调用重置状态的实现缺口。GRU、SSM 和解析滤波器都跨观测 tick 保留状态，只在 episode 开始时复位；所有候选动作只使用已接受的观测和公开时间。**这不是持续真实 AV 或首达／复位模型验收。** 新任务是明确登记的二态连续时间 Markov 链，A、V 是两种带噪二元传感器的名称，不是音频、视频文件。

结果仍不足以证明解析核心的稳定净增益。在 256 个独立测试世界中，五个拟合种子分别训练 GRU 和 SSM，验证集选择普通模型后，D−B 平均为 **+0.00552344**，按拟合种子和世界双向重采样的 95% 区间为 **[−0.00268867, +0.01493521]**。一个种子的 D−B 为负，区间跨零。更强的同信息精确历史重算参照 H，与解析 D 的全部输出概率、动作和收益完全一致：**D−H=0，概率误差=0**。

## 冻结与训练

`results/development001/PLAN.json` 在模型拟合和测试世界产生前冻结了源码哈希、五个种子、训练与验证规模、训练预算、世界命名空间和所有费用。每个种子使用 384 个训练序列和 128 个独立验证序列，每序列 16 个真实观测 tick，随机 skip/A/V 缺测掩码相同。每个 tick 有 advance(dt) 和 post-event 两个监督位置，两个位置等权；skip 的零事件子步对两种模型的状态都是严格恒等。标签是该时刻的潜在类别，标签只进入监督损失，不进入状态输入。

两种普通模型都是 NumPy 完整 BPTT，宽度 16，100 个 epoch，包括 step-zero 在内的全部验证历史保留。每个种子的模型族和 epoch 只按验证 NLL 选择，测试前写入 `FROZEN_MODELS.json`。GRU 选中 epoch 28–47；SSM 选中 epoch 95–100，部分触及预算上限，因此**没有把它们标为已经资格化的强普通参照**。所有十个模型的权重、训练数据、验证数据和历史都保留。

解析和 H 使用已知生成律；普通模型由采样标签学习。虽然输入信息相同，解析模型具有正确物理先验，不能把有限预算学习差距解释成新的网络机制优势。H 每次从原始可见历史重算，使用同一已知律。它在本有限任务中给出充分的质量对照，但其历史内存和计算成本尚未与其他方法完成同预算采用验收。

## 实际运行与审计

- 256 个测试世界、6,144 次完整运行、98,304 个 tick 输出。raw 文件记录状态、当前概率、动作候选分数、实际动作、接受的观测、费用、正确性和奖励。
- 五项行为检查通过：独立有限差分梯度、前缀因果／标签扰动、跨 tick 持久与 episode 复位、零事件恒等、解析与原始历史重算等价；训练输入检查确认只有当时接受的事件。
- `audit.py` 独立重写 GRU/SSM 方程，不导入模型或 campaign 实现。它核对全部 6,144 个运行、98,304 个 tick 的状态与概率、动作、费用、奖励、验证选择和 D−B，最大独立递推误差 **0**；`AUDIT.json` 为通过。

各阶段互不重叠。阶段内部训练和执行计时已经包含，不能再相加。任务进程内部的 run 总计为 51.233897 CPU 秒／61.535462 墙钟秒；外层 wait4 数值还包括解释器启动和退出。上述三阶段合计任务 CPU **58.887843 秒**，连同计量器为 **66.971928 秒**。五项预冻结行为检查不在这三阶段之内。

成本凭证在相邻 `economics/results/persistent_prepare001`、`persistent_run001`、`persistent_audit001`。run 采样的非原子 RSS 和 PSS 总和峰值分别为 195,239,936 与 181,009,408 bytes；它们是采样观测，**不是完整进程族连续峰值**。cgroup 文件系统只读，设备能量计数器不可用，可归因能量及历史准备成本仍为 null。没有经济优势验收声明。

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m experiments.hcsn_v9_followup_20261101.persistent_core.campaign prepare --output /tmp/hcsn-persistent-replay
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m experiments.hcsn_v9_followup_20261101.persistent_core.campaign run --output /tmp/hcsn-persistent-replay
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python -m experiments.hcsn_v9_followup_20261101.persistent_core.audit /tmp/hcsn-persistent-replay
```

完整进程族 CPU／采样内存请用相邻 `economics/family_cost.py` 包裹执行，正式本轮 stdout、stderr 和原始采样均已保留。不同运行的计时、时间戳及压缩文件元数据可以变化；逻辑模型与世界通过冻结种子和源码身份复现。
