# HCSN 任务价值研究：完整注册矩阵分析

注册 168 个作业；完整性审计通过 168 个，失败或证据不完整 0 个。所有失败保留，未以失败作业替换成新种子。

## 执行后的核心判断

**训练与冻结实现通过了证据检查，但当前实验没有建立边界解析策略或双通道的独立任务收益，也没有建立对外部基线的等质量 CPU 成本优势。** 完整 value_dual 的 33 个作业中，五组参数在最后优化状态与验证选择 checkpoint 均有实际变化，平均梯度均为正；15 个冻结作业的目标组在两处均未变化，梯度为零。‘联合可训练’与‘该机制提高任务质量’是不同结论。

selective_copy 三个测试长度合计 45 个边界/通道主效应及交互准确率区间中，0 个排除零；CE 区间排除零的个数为 0。这支持‘此轮未检出净增益’，不证明所有任务上永远没有增益。

### 成本资格应如何理解

通过质量非劣及完整 worker CPU 比门槛的 3 项，实际涉及 1 组 worker 成本配对；其中相对 two_gates、Transformer、LIF 的资格数是 **0**。

- selective_copy / length32：value_dual 相对 freeze_boundary，CPU 比 0.621 [0.407, 0.947]；实际训练 CPU 最大相对差 21.420%。
- selective_copy / length64：value_dual 相对 freeze_boundary，CPU 比 0.621 [0.407, 0.947]；实际训练 CPU 最大相对差 21.420%。
- selective_copy / length128：value_dual 相对 freeze_boundary，CPU 比 0.621 [0.407, 0.947]；实际训练 CPU 最大相对差 21.420%。

三个长度可能使用同一组训练作业与同一次完整成本测量，因此不能把这些资格重复解释为独立成本复现。相对冻结边界的内部消融结果也不能转写为优于 Transformer/SNN 的经济性。全部区间仍为未校正多重比较的三 seed 名义区间。

## 判定规则与结论边界

所有 checkpoint 均由验证集交叉熵选择。分析不调参、不选择新的 checkpoint；审计重新核对预测、选择记录、源文件与 checkpoint 哈希。具体记录见 aggregate.json。

比较单位是相同 seed 的差值；三个 seed 的名义 95% t 区间使用 df=2、临界值 4.30265273。CE 比先对每个 seed 取 log，再计算区间并指数变换，同时保留均值之比。区间未做多重比较校正；3 个初始化重复无法代表新数据集、受试者或硬件的不确定性。

共 159 个预定成对条件/评测情形：21 个准确率差区间下界大于零，其中 3 个同时满足参数和实际训练 CPU 匹配；54 个满足质量非劣门槛；3 个还满足完整 worker CPU 比区间上界小于 1。不同长度及缺失情形分别计数，不能把这些数量当作独立重复的证据。
准确率区间分类：正 21，负 8，包含零 130，配对或 seed 不完整 0；另有 0 个注册比较没有可用配对，全部保留为不可判定。

质量非劣要求准确率差区间下界不低于 -0.02，CE 比区间上界及均值之比均不高于 1.05。只有通过质量非劣的配对，才允许在其具体条件下讨论测得的成本优势。简单点估计、低事件数、一次快运行或某个组件有梯度均不足以成立。

## 完整成本账本

有 receipt 的注册作业合计 child CPU 为 3641.947 秒；监控进程 CPU 另计 95.786 秒，不能再次把内层训练 CPU 加进全程数。
单个 worker 的最高峰值 RSS 为 408141824 字节；这不是所有并发 worker 的合计内存。已审计 checkpoint 共 15941921 字节，包含模型、优化器及复现实验状态。

receipt 不含此前环境安装、共享数据准备及未被 worker 回收的外部进程。推理计量是共享 CPU 主机上整段序列、batch=1、一次预热后五次重复；并非优化 KV-cache 服务，长输入通过重复首个测试输入构造。能耗未直接测量，未从 CPU 时间、事件数或本地 I/O 推造焦耳。

推理的 logical tensor 字节与按底层 storage 去重的字节均在 inference_summaries 中逐长度报告；null 表示该接口未提供缓存状态，不能当作零内存。返回状态不包括输入、输出 logits、反向传播图或所有临时分配，训练内存不由这些数字界定。

### 一次共享前端重建账目

独立完整进程计量：child CPU 16.484498 秒，wall 47.053765 秒，峰值 RSS 46735360 字节；其监控进程 CPU 另计 0.907154 秒。四个数据/归一化产物逐字节哈希与正式注册产物一致：True。

这一次流程从无原始媒体缓存开始，包含 48 个固定来源片段下载、ffprobe/ffmpeg、特征、因果前缀审计、仅训练集归一化、写盘与原始文件清理。它独立列账，未加到每个模型作业或每个比较上；此前旧 attempt 的 13.463 秒内部时钟保留，也不重复相加为‘完整研发成本’。包含审计的真实重建流程不等于最低生产前端成本，未测焦耳。证据为 frontend_cost001/IDENTITY_AND_COST.json 与 whole_process.json。

## 失败、完整性问题与未关闭问题

全部注册作业通过本次文件与数值一致性审计；此前独立数值验证中的失败日志仍保留。

学习到的局部奖励及Brownian边界不等于全序列任务最优解；8-bin有限流与连续参考存在数值差距。这里的结果不能自动推广到大规模多模态预训练、GPU吞吐、端侧能耗或真实神经形态硬件。只有满足报告中明示门槛的具体比较才支持相应范围的结论。
