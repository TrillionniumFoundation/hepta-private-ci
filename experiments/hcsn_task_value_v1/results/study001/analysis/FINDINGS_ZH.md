## 执行后的核心判断

**训练与冻结实现通过了证据检查，但当前实验没有建立边界解析策略或双通道的独立任务收益，也没有建立对外部基线的等质量 CPU 成本优势。** 完整 value_dual 的 33 个作业中，五组参数在最后优化状态与验证选择 checkpoint 均有实际变化，平均梯度均为正；15 个冻结作业的目标组在两处均未变化，梯度为零。‘联合可训练’与‘该机制提高任务质量’是不同结论。

selective_copy 三个测试长度合计 45 个边界/通道主效应及交互准确率区间中，0 个排除零；CE 区间排除零的个数为 0。这支持‘此轮未检出净增益’，不证明所有任务上永远没有增益。

| 任务/预算 | 对照 | 长度 | 准确率差及95%CI（百分点） | 参数最大差 | 训练CPU最大差 | 完整worker CPU比及95%CI |

| mqar / 15.0s | two_gates | length64 | 7.617 [2.107, 13.128] | 2.311% | 0.444% | 1.207 [1.064, 1.370] |

这几项比较整体架构的任务表现；它们没有单独隔离自由边界或双通道的贡献。训练 CPU 匹配也不等于完整 worker 成本匹配，完整 worker 还包括初始化、验证、checkpoint、测试与推理计量。

### 成本资格应如何理解

通过质量非劣及完整 worker CPU 比门槛的 3 项，实际涉及 1 组 worker 成本配对；其中相对 two_gates、Transformer、LIF 的资格数是 **0**。

- selective_copy / length32：value_dual 相对 freeze_boundary，CPU 比 0.621 [0.407, 0.947]；实际训练 CPU 最大相对差 21.420%。
- selective_copy / length64：value_dual 相对 freeze_boundary，CPU 比 0.621 [0.407, 0.947]；实际训练 CPU 最大相对差 21.420%。
- selective_copy / length128：value_dual 相对 freeze_boundary，CPU 比 0.621 [0.407, 0.947]；实际训练 CPU 最大相对差 21.420%。

三个长度可能使用同一组训练作业与同一次完整成本测量，因此不能把这些资格重复解释为独立成本复现。相对冻结边界的内部消融结果也不能转写为优于 Transformer/SNN 的经济性。全部区间仍为未校正多重比较的三 seed 名义区间。
