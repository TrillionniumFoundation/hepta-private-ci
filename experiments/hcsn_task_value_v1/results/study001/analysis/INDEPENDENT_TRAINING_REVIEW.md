# 联合训练、冻结实验与数学结论的独立复核

## 结论

**联合训练与冻结干预的实现证据成立；尚未建立自由边界或双通道机制的独立稳定性能优势。** 本次独立检查没有重新训练、修改模型或改动登记协议。读取既有对象与日志，按种子重建初始化，直接加载所有 90 个 HCSN 所选 checkpoint，逐张量复算变化。检查全部通过，详细数值、逐作业核对与证据 SHA-256 见同目录 `INDEPENDENT_TRAINING_REVIEW.json`。

168 项登记作业均有成功执行、完整摘要与计量记录。登记源码和作业文件身份一致；所选 checkpoint 的实际文件哈希一致；所选步骤对应日志中最低验证集交叉熵，持久化 selection 早于首次 test 访问。没有将本轮独立复核称为新的测试集实验。

## 五组确实参与联合训练

33 个 `value_dual` 作业中，每个作业的五组参数在最终日志和所选 checkpoint 均有变化。组内所有参数张量都发生了变化；独立复算的所选 checkpoint 变化张量数完全一致，双精度累计 L2 与原 float32 记录在声明容差内一致。

| 组 | 每作业变化张量数 | 最终训练 L2 范围 | 所选 checkpoint L2 范围 | 每作业平均梯度范数范围 |
| --- | ---: | ---: | ---: | ---: |
| content | 18/18 | 2.023–11.942 | 1.316–11.942 | 0.767–6.773 |
| dynamics | 4/4 | 0.242–1.355 | 0.128–1.355 | 9.57e-4–1.68e-2 |
| boundary | 3/3 | 0.210–1.495 | 0.142–1.495 | 6.47e-5–1.64e-3 |
| reset | 1/1 | 0.0263–0.355 | 0.0135–0.355 | 3.03e-5–5.76e-4 |
| refractory | 1/1 | 0.0216–0.227 | 0.0111–0.227 | 6.55e-5–1.81e-3 |

这是联合优化的实际证据。它不意味着每个组都带来性能收益，也不能由参数移动单独证明因果作用。最终训练模型没有另存完整 checkpoint，因此最终 L2 是训练源码产生的日志测量；所选 checkpoint 的 L2 和逐张量变化则已由本轮独立重建确认。

## 冻结与 stop-gradient 的语义

15 个冻结作业覆盖五组、每组三个种子。每个目标组的最终和所选 `changed=0`、`L2=0`、`trainable=0`，平均与峰值梯度均为零。独立 checkpoint 比较确认冻结张量与初始化 **逐位相同**；optimizer 中的活跃参数张量数量也正确。

三个 `stop_gradient_dual` 作业仍然学习 dynamics、boundary、reset 和 refractory。其实现只对解析边界输出 `b` 调用 `detach()`；系数仍能经有限值函数、概率流与物理门控等路径接收梯度。该结果符合控制定义。它不能被描述为“冻结全部边界参数”。同样，冻结 boundary 参数组不等于固定实际边界，后者还依赖活跃的漂移、波动率、折现、复位和不应期参数。[当前源测试](../../flow002/flow_audit.json)已直接区分这些情形。

## 梯度稳定性的实际范围

没有发现非有限训练损失、梯度日志或所选参数。33 个 `value_dual` 作业共 7,195 步，其中 5,021 步（69.7846%）触发全局范数 1 的裁剪；最高裁剪前全局范数为 231.22598，出现在 `cpu_delayed_recall_value_dual_w16_s31103`。因此合适的表述是“本次有参数边界和梯度裁剪的训练正常完成”。现有证据不支持“无需裁剪仍稳定”或“已解决长序列梯度消失”。

动力学和边界组的平均梯度均非零，但比 content 的原始组范数小。不同组的大小、参数尺度和参数化不同，这些比值仅用于描述，不能当作条件数或单参数敏感性。日志保存平均与峰值组范数，没有保存每一步每组的最小范数，因而不能排除局部或间歇性梯度消失。

## 数学与事件合同支持的主张

[数学合同](../../../CONTRACT.md)明确区分三个对象，复核未发现需要把它们合并解释的理由。

| 对象 | 已有支持 | 仍不能推出 |
| --- | --- | --- |
| 固定局部系数的一维 Brownian/Erlang 奖励合同 | 在规定条件下得到满足 value matching 与 smooth fit 的上边界；独立显式阶段空间 QVI 在最细网格上的值误差约 1.88e-6 | 该边界最优于实际八格神经流、未来分类损失或完整非平稳序列控制问题 |
| 神经有限概率流 | `J/G` 评价自身有限生成元下的既定策略；独立 dense solve、折现流和矩阵指数核对通过 | 八格近似已经得到连续模型的统一精度保证；所有状态与参数处都全局光滑 |
| 一般双细胞有限 QVI | 支持状态依赖奖励与复位核；重优化有限差分验证梯度，真实动作切换点报告左右导数差异 | 可直接扩展为大规模神经群体的联合连续自由边界最优解 |

当前源的八项 flow 测试支持分块与前缀因果性、缺失 payload 不变性、旧参数推进后再按当前边界重映射，以及未观察区间继续推进时保持恢复门控。四项接口测试支持首个零时差事件的信息通路、末端缺失 AV acquisition 的监督保留，以及已检查配置下不随序列长度增长的推理持久状态存储。

边界事件进入 Erlang 不应期；不应期中不能 FIRE，恢复后可以再次 FIRE。因此记录的 activity 是**可大于 1 的期望事件数**，并非首次过阈概率。复位核、不应期阶段、重复事件和瞬时边界重映射需要共同定义事件语义。阈值重映射、插值节点、upwind 切换与最优动作并列处依然有分段或单侧导数限制；去掉 0/1 阶跃并不自动消除所有非光滑性。

实现中的值不是金融 Call/Put 的原值，也未被证明是物理恢复力或恐慌力。网络还传递学习的 content、完整有限概率状态和局部系数，不能描述为“层间仅传递自由边界”。实际执行包含稠密概率传播与线性求解，事件计数不能直接换算为节能或硬件加速。

## 与最终统计汇总的关系

本轮只读现有 `aggregate.json`，没有重新读取或计算预测数组。159 个配对条件的名义准确率区间为 21 个正、8 个负、130 个含零；满足预算匹配的三个正条件都来自同一 MQAR、15 秒训练 CPU 对两门控比较的三个长度。所有 90 个 factorial 主效应/交互的 accuracy 与 CE 区间均包含零。登记的 whole-worker CPU 优势只出现在对 `freeze_boundary` 的内部比较，三个长度复用相同训练作业；没有外部基线的合格 CPU 优势。

三个种子的名义区间没有多重比较校正，长度条件不能计为独立重复，AV 也只是此前观察过的开发子集。故当前可交付的是**可复核的联合训练原型、局部数学闭合与事件合同，以及未确立独立机制收益的实证结果**。这些证据不足以宣称已经验证全模态大模型、通用 encoder 或相对 Transformer 的总体优势。
