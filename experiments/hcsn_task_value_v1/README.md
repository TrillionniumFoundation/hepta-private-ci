# Hepta Continuous Spiking Network：任务价值原型与完整实验

本目录实现受 He–Xiong *Rollover Risk and Credit Risk* 启发的连续自由边界网络：以可重复发放的概率流、局部任务价值和学习的内容状态进行监督训练。**168 项登记作业全部成功，六项科研门槛并未全部通过。** 已完成数学合同、低维 oracle 与联合训练核验；本轮没有建立解析边界或双通道的独立净收益，也没有建立相对外部基线的等质量 CPU 成本优势。

完整数据、区间与负结果见[最终报告](results/study001/analysis/RESULTS_ZH.md)、[机器可读汇总](results/study001/analysis/aggregate.json)及[独立训练复核](results/study001/analysis/INDEPENDENT_TRAINING_REVIEW.md)。本项目是小规模 CPU 研究原型，尚不足以支持全模态大模型、通用 encoder、新 SOTA、相变或硬件稀疏加速主张。

## 数学对象与事件语义

三个层级须分开解释：一维 Brownian 参考优化固定局部系数的奖励合同；神经模型在每个物理单元的 **8 个活跃格点、2 个 Erlang 阶段**上执行给定策略；双细胞有限 QVI 优化其有限联合状态上的 WAIT/FIRE 动作。后两者分别是自身策略评价与小型联合优化，不能直接替代连续参考或全序列任务最优解。

金融违约原本是吸收事件；重复神经发放必须显式加入复位与不应期，不能直接把违约概率反复当作脉冲。一般 oracle 支持状态依赖奖励和随机复位核，神经前向并不调用该联合优化器。固定策略隐式导数通过独立重优化有限差分核对；真实动作切换点报告左右导数差异，不将其伪装为普通导数。

活跃态满足 \(dX=\mu dt+\sigma dW\)，运行奖励为 \(ax\)，发放收益为 \(X-K\)，不应期结束后复位到 \(r\)。\(\rho\) 是折现率，\(\tau\) 是 Erlang 不应期均值。令

\[
D=(1+\rho\tau/m)^{-m},\quad
\kappa=\frac{\sqrt{\mu^2+2\rho\sigma^2}-\mu}{\sigma^2},\quad
U(x)=\frac{ax}{\rho}+\frac{a\mu}{\rho^2},\quad\beta=1-a/\rho.
\]

在 \(\beta>0\)、\(K_{\rm eff}>r\) 的上边界族内，

\[
K_{\rm eff}=\frac{K+U(0)-DU(r)}{\beta},\qquad
\kappa(b-K_{\rm eff})+De^{-\kappa(b-r)}-1=0,
\]

在延续区域 \(x<b\)，

\[
J(x)=U(x)+\frac{\beta}{\kappa}e^{\kappa(x-b)},\quad
G(x)=x-K+DJ(r),\quad J(b)=G(b),\ J'(b)=G'(b)=1.
\]

这里 \(J\) 是任务合同价值，\(G\) 是立即干预价值，**均不等于金融论文的 literal Call/Put，也不是概率或恢复/恐慌力**。实际神经算子求解 \((\rho I-Q)J=g+e(b-K)\)，评价自己的有限生成元；网络同时传递内容向量、概率状态、价值与边界特征。

[独立空间验证](results/oracle001/affine_20261031T014102544158Z.json)在 \(h=0.00625\) 时，验证网格 \([-8,3]\) 上的最大价值误差为 \(1.882\times10^{-6}\)；复位点价值的七参数梯度最大误差为 \(4.257\times10^{-4}\)。[当前流审计](results/flow002/flow_audit.json)的矩阵指数对照误差不超过 \(2.643\times10^{-11}\)，边界梯度对独立重求根有限差分误差不超过 \(6.639\times10^{-10}\)。这些数值只覆盖声明域，不能替八格模型提供统一连续精度保证。

\(dt\) 用秒表示：先按旧参数推进，再接收当前观察并重映射边界。缺失 payload 保持先前信号与参数，继续时间演化；末标签按最后有效 acquisition 保留。发放进入不应期，不应期内不能再次发放，恢复后可以重复发放。因此 `activity` 是期望事件数 \(E[N]\)，可以大于 1，不能当作首次过阈概率。复位插值、重映射和动作并列处仍可能只有分段或单侧导数。

## 联合训练与机制结果

三个种子为 31031、31067、31103。合成任务固定预算族训练 256 次更新，训练与验证序列长度均为 32；AV 固定预算族训练 64 次更新，使用完整片段。合成任务另有 15 秒训练 CPU 预算族。所有模型使用相同任务信息与监督目标，按验证集 CE 选择 checkpoint，再访问测试集；外部控制采用实际参数量近似匹配，不填充无用参数。两门控/LIF 按观察事件更新，首个 \(dt=0\) 事件也接收输入，真实时间仍作为共有特征。

content、dynamics、boundary、reset、refractory 五组均有非零梯度与实际更新。冻结目标组的最终及所选参数都逐位不变。`stop_gradient` 只断开解析边界输出的导数，其他物理路径仍可学习；冻结 boundary 参数组也不等于固定实际边界。

完整模型共 7,195 步，5,021 步（69.78%）触发全局范数 1 的梯度裁剪，最高裁剪前范数为 231.226。未发现非有限训练记录，但平均/峰值梯度不能排除逐步梯度消失，也不能证明无需裁剪的稳定性。

边界×通道实验共 45 个准确率主效应/交互区间，另有 45 个 CE 区间，**全部包含零**。例如正常长度下 value−fixed 准确率差为 0.543 个百分点，95% CI 为 [−0.534, 1.619]；dual−ordinary 为 0.152，[−2.216, 2.520]。当前没有隔离出机制净增益；这也不是所有未来任务永远无效的证明。

## 内容能力：实际结果

下表为宽度 16、固定更新预算的三种子平均准确率（%）；合成任务长度为 32，AV 使用完整片段。

| 任务 | HCSN value_dual | 两门控 | LIF | Transformer |
| --- | ---: | ---: | ---: | ---: |
| MQAR | 25.52 | 13.09 | 12.89 | 85.16 |
| selective copy | 25.52 | 12.43 | 11.85 | 41.21 |
| delayed recall | 36.46 | 10.68 | 13.80 | 100.00 |
| 真实异步 AV | 16.67 | 16.67 | 16.67 | 19.44 |

扩宽并非一致改善：delayed recall 宽度 8/16/32 的 HCSN 正常长度准确率为 39.32/36.46/80.73%。宽度 32 时，长度从 32 增至 128，HCSN 为 80.73%→73.18%，Transformer 为 100%→33.33%；宽度 16 的 MQAR 则为 25.52%→22.72% 与 85.16%→17.97%。这些条件性点估计须连同完整配对区间阅读，不能外推为普遍长上下文优势。

本轮 [Transformer 对照](../continuous_spiking_network/baseline.py)是 depth=1 的因果 SDPA 与前馈块，使用累计真实时间的固定 sin/cos 编码，没有学习式位置表越界。长度 64/128 的测试是仅用长度 32 训练与验证后的外推，并非专门训练或调优的长上下文 Transformer；未经对应消融，不能把下降归因于时间编码。

AV 来自 48 个真实解码片段，按原始音视频时间戳因果合并，完整片段有 201–462 个事件；内部 `length32` 仅是接口名称，不是截断长度。测试参与者与训练分离，但该小型 cohort 已被此前工作观察；模态删除是人为干预，并非实测传输故障。本轮未建立 AV 质量或缺失鲁棒性优势，详见[前端说明](ASYNC_AV.md)。

## CPU、内存与能耗

15 秒训练 CPU 匹配的 MQAR 中，HCSN 相对两门控在三个长度上增加约 7.62–8.14 个百分点；然而完整 worker CPU 比为 **1.207 [1.064, 1.370]**，训练预算匹配没有变成全程成本节省。相对外部两门控、LIF、Transformer，满足质量非劣且成本区间上界小于 1 的比较数为 **0**。

168 个 worker 合计 CPU 为 3641.947 秒，监控 CPU 另计 95.786 秒；最高单 worker RSS 为 389.23 MiB，不是并发总内存。宽度 16、batch=1 的 HCSN 持久状态在长度 32/64/128 均为 340 字节，但不含输入、输出、临时张量或反向图；Transformer 接口未返回缓存时记 `null`，不能当作零内存。

一次完整共享 AV 前端重建另计 CPU 16.484 秒、wall 47.054 秒，产物哈希与登记数据一致。不得重复相加内层训练时钟与完整 worker 成本。推理是共享 CPU 上整段序列测量，未实现优化 KV-cache 服务；没有 GPU/RAPL 焦耳读数，不能用事件数推导能耗。账目边界见 [ECONOMICS_SCOPE.md](ECONOMICS_SCOPE.md)。
