## 1. 状态、收益和时间

一个任务流最多包含三个分类任务。状态包含：当前任务已经读取的前缀长度 \(k\)、已观察到的状态 \(z\)、剩余时钟 \(h\)、包含当前任务在内的剩余任务数 \(m\)，以及公开读取价格 \(c\)。神经状态、任务队列、计费账本和剩余不应期也是可恢复状态。

| 动作或输出 | 语义 |
| --- | --- |
| READ | 实际调用一次 `backbone.step`，取得当前任务下一条观察，消耗一个任务时钟并支付 \(c\)；第一次读取也收费 |
| FIRE | 用当前预测对真实标签评分，获得 0 或 1；原生 owner 实际 STOP，当前 tensor iterator 终止 |
| RESET | 若队列未空且剩余期限足够，在两次 quiet tick 之后为下一张图像建立新 owner，并将神经状态重置 |
| 不应期 | 消耗任务期限；期间没有新观察、没有 model step、没有 owner tick。任务时钟不是 wall-clock sleep |
| 当前正确性价值 \(r_k(z)\) | 在声明的观察模型下，立即分类的成功概率；实际执行最终仍按 0/1 正确性评分 |
| 干预价值 \(G\) | 当前任务成功概率加上不应期后其他任务的真实期望收益 |
| 读取价值 \(C\) | 支付下一次实际读取价格后，获得新观察的期望续存价值 |
| \(J\) | 可行动作的最大价值；不是单独的“继续动作值” |

FIRE 本身没有额外任务时钟收费，但是只允许在正长度前缀上发生。任务队列有限，下一任务至少需要一次付费读取，故不存在零时间循环收取正确性奖励的问题。普通策略、价值策略、训练标签和原生执行均遵守同一动作可行域。

这里的 FIRE/RESET 是**任务层**的 owner 合同，不等同于每个内部压力神经元的首次发放。分布流单元的内部 own-policy 值和任务层分类 Bellman 值不因名称相同而相等。

## 2. 再生 Bellman 方程

令 \(F_m(h)\) 为尚未读取第一条观察的新任务价值，\(\gamma\) 为每个任务时钟的贴现，\(\tau\) 为任务层不应期。已观察状态的干预价值为

\[
G_m(h,k,z)=r_k(z)+
\mathbf 1\{m>1,\ h\geq\tau\}\gamma^\tau F_{m-1}(h-\tau).
\]

读取仍合法时，

\[
C_m(h,k,z)=-c+
\gamma\sum_{z'}P_k(z,z')J_m(h-1,k+1,z').
\]

因此

\[
J_m(h,k,z)=\max\{G_m(h,k,z),C_m(h,k,z)\}.
\]

没有剩余时钟或已读到任务最大长度时，只能 FIRE。新任务价值满足

\[
F_m(h)=\max\left\{0,-c+\gamma\sum_z\pi_1(z)J_m(h-1,1,z)\right\},\quad h>0,
\]

并有 \(F_m(0)=F_0(h)=0\)。零值表示拒绝开始一个不合算的新任务。在真实数据登记的价格范围内，会先检查所有可用期限和队列长度的拟合新任务价值均为正，之后每次开始实际任务都必须读取第一条观察。

未来项是重置之后剩余任务的价值：它随期限、队列、价格、不应期及后续任务分布改变，并在真实执行中由后续任务独立产生的正确性和读取账单核对。没有使用一个常数作为“未来奖励”。

READ/FIRE 的任务边界是 \(C-G=0\)。离散观察模型中的这个边界不自带连续空间的 smooth-pasting 定理；该有限 Bellman 问题也没有被包装成 He–Xiong 金融模型的直接复现。

## 3. 精确二元观测 oracle

隐藏任务标签独立服从 Bernoulli(1/2)。每条二元观察在给定标签后独立，正确可靠度为 \(\eta>1/2\)。前缀中 1 与 0 的数量差 \(s\) 是充分统计量，其后验为

\[
\Pr(Y=1\mid s)=\operatorname{sigmoid}\left(s\log\frac{\eta}{1-\eta}\right).
\]

由此得到精确的立即分类成功概率和下一观测转移概率。`task_value.py` 的表格动态规划使用上述充分统计量；独立参考则展开字面观测历史，用似然乘积求后验，不调用该表格求解器。另一个 Monte Carlo 实现实际生成隐藏标签与观察，只在 FIRE 时使用标签评分。

验证包括有限期限边界、队列终止、不应期、拒绝高价格任务、独立历史树、实际标签 Monte Carlo、总收益分解和价格敏感度。在局部最优动作不变化的参数点，价值对读取价格的导数应等于负的期望贴现读取次数。测试保留这个条件，不宣称跨策略切换点处处可微。

一个登记的因果执行 fixture 固定同一观察前缀、价格、噪声模型和剩余时钟，仅把剩余队列从一个任务改成三个任务。其后续任务价值改变当前 READ/FIRE 比较，并由固定原生 owner 消费两个连续分数。这个 fixture 属于低维精确问题的执行验证，不能当作 MNIST 内容成绩。

## 4. 真实数据模型、训练和公平比较

固定的 MNIST 骨干来自上一轮 free-dual 的 seed9101 选中检查点。它仍是 v1 的均值闭合网络，因此该执行研究的胜负不能归给新 v2 分布传播器。

每个观察前缀的 softmax 最大置信度先按 \(10^{-4}\) 量化，再根据 TRAIN 数据拟合的分位数映射为四个状态。TRAIN 前缀的真实正确性与下一状态频率用于拟合 \(r_k\) 与 \(P_k\)，固定伪计数为 5。空状态使用声明的前缀总体平滑分布，不读取验证或测试标签来拟合转移。

该置信度状态通常不是神经过程的充分统计量。它丢弃了完整 hidden state、类别和历史，因此 MNIST 的 Bellman 表只是**粗化 Markov 近似**。其价值校准、预测质量和净效用必须通过真实后续任务验证。

两种学习策略采用相同的五个输入：前缀长度、置信度状态、剩余期限、剩余任务数、公开价格。架构均为 `Linear(5,8) → tanh → Linear(8,2)`，有 66 个实际参与分数差的参数；初始化、全部 minibatch 序列、两组学习率、更新数和验证选点机会相同。

- 价值头回归 \([G,C]\)，并对 \(C-G\) 增加固定权重的回归项。
- 普通头从同一 teacher 蒸馏实际 Q24 READ/FIRE 动作。

这是相同架构下的**监督目标比较**，没有把损失函数差异藏进“纯双通道架构消融”。两个策略都根据真实 VAL 任务流收益选点，完整候选训练成本均收费。

此外保留直接表格 Bellman 策略，以及在 VAL 上按价格选择的固定/期限均分读取策略和置信度阈值策略。普通 schedule 不被强行收取不需要的 teacher 和 head 拟合费用。最强普通参考的族名称也在新测试访问之前由 VAL 锁定。

## 5. 新测试、实际执行和恢复

两个证据范围分开记录：

1. **128 个三任务流的反事实评分。** 完整前缀缓存全部实际计算并收费，策略只能按当前前缀查询缓存。它计算逻辑读取收益，不将缓存中的未查询项称为已省下的实际推理。
2. **前 16 个任务流的原生执行。** 三档价格和五个策略都逐步调用真实骨干与 owner。STOP 后的 tensor iterator 不再前进，后续任务建立新 owner 并重置神经状态。

分数经 `tanh` 与 Q24 进入原生 profile，KEEP 当且仅当量化分数大于零，零值 STOP。局部最大读取长度和全局期限强制 FIRE，属于公开合法性约束。每次量化、实际动作、终止拒绝和计费都有凭据。浮点/量化分歧只能是明确记录的舍入到零；缓存与实际 native 结果如有差异也会保留，而不会混合两种统计范围。

恢复 fixture 采用明确声明的固定8策略，分别在活动状态读完一次后，以及不应期只剩一次 quiet tick 时保存。外层程序让进程真正退出，再用新 Python 进程加载同一选中对象、队列、剩余期限、账本、剩余 quiet 和嵌套神经张量，接续原生 journal。完整语义轨迹与未中断 fixture 比较，包含实际输出、动作、native checkpoint、最终神经状态和收益；该工程 fixture 不计作选中策略的额外内容成绩。

## 6. 费用与结论范围

外层 `wait4` 计量整个训练/执行协调进程，包括导入、数据准备、teacher、所有候选、验证、测试缓存、实际 native 子进程以及恢复验证。各 phase 和 native 费用是其嵌套细项，不能重复相加。最终报告器/监督进程自身费用另行记录。

净收益敏感性使用明确的未来任务流寿命和每 CPU 秒的效用费率。一个口径按实际使用的方法组件分配一次性费用；另一个保守口径把整个新增研究活动费用都归给价值策略，并给普通策略免费的新设置成本作为有利下界。二者是场景计算，不是测量出来的美元或能耗。

科学上仍需区分：低维 oracle 正确、粗化模型校准、值回归头可训练、真实 owner 动作改变、内容收益、完整成本后收益。任何一项通过都不能替代其他项。将新分布流骨干接入通用执行器的附加 smoke/恢复实验会保留自己的身份，不能继承本轮冻结 v1 骨干的质量结论。
