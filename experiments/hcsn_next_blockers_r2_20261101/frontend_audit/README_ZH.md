开发源失败包括 8 帧至 0.28 秒、9 帧至 0.32 秒、5 帧至 0.16 秒的三个原始片段。它们按注册 CRC 与采集 SHA 验证为原字节，不能换样本、补帧、放宽前缀或仅用 61 个有效片段宣称通过。开发准确率及区间均缺失；不能写成 0%，也不能用训练 OOF 代填。确认按同一批已冻结候选单独执行一次，128/128 源合格并生成完整预测；没有依据开发故障改方法或换样本。确认组音频与文本各为 100%，两个视频候选仍未通过。主候选 AVT−AT 为 −4.6875 个百分点，原 95% 配对区间为 [−11.4583, +2.0833] 个百分点；次候选为 −7.03125 个百分点，97.5% family 配对区间为 [−11.1979, −4.4271] 个百分点。

GRID 训练集为六名说话人；开发集为两名；确认集为同一组四名说话人。两个候选使用相同确认组，不能把它们当成两份独立确认。97.5% 区间使用 `[0.0125, 0.9875]` 分位数，是两个候选的名义 Bonferroni 调整。四个确认说话人的 cluster bootstrap 只提供注册小组的描述性证据，不能保证总体覆盖率。官方预训练数据与这些人的身份是否重叠仍未知。

核验过程保留了以下修正链：

- 原视觉提取在训练片段 `1037_DFA_ANG_XX` 遇到 H.264 B 帧后按原协议停止。原源码、协议与失败日志保留；`REVIEW_REPAIR.json` 核验后续仅扩展为离线展示时间前缀。压缩参考帧的前视未测量，不能据此主张实时因果 1 秒输入。
- GRID `data_v2` 在读取前缀前检查完整注册记录、角色、源发布、候选发布、完整采集清单及原始字节 SHA。`REVIEW_GRID_V2.json` 的 41 个隔离合成用例通过；未启动实际解码器或网络请求。
- 初版 GRID 源码未保存九个外折参数。`REVIEW_GRID_RETENTION.json` 验证保留参数与优化器记录的修订未改变特征、目标、损失、优化参数、演员分折或评估算法。修订在拟合前发布，原特征库按精确 SHA 接纳。
- GRID V2 冻结文件继承的 `new_mpeg_payloads_acquired: 0` 不是 V2 冻结时的真实盘点；原冻结文件保留，主目录的 `PROVENANCE_ADDENDUM.json` 明确当时 V1 采集已运行，精确数量未知。
- `REVIEW_TERMINOLOGY_ADDENDUM.json` 澄清四个 CREMA 报告中较早的 `model_inference_performed: false`：未重新运行神经音视频编码器，但确实独立重算了冻结分类器及关系头。科学结果未变。

`audit_grid_results.py` 与 `audit_grid_family.py` 对完整确认特征与预测重算了原 95% 门与双方 97.5% family 区间；开发源失败没有生成这些质量报告。确认原主候选输出、clean AT 分数及音频/文本概率在 family 报告中逐字节相同，两个候选均报告，未选择有利结果替代原结果。

数值审计读取缓存特征、参数、预测与记录，不重新拟合或重新执行神经编码器。开发首个源失败另做了独立 ffprobe，未调用神经编码器；其外层 CPU 收据单列。训练目标仍是显式的有限词汇或句子分类与构造关系任务；没有解析核心、控制器、全球身份排除、开放域、GPU、能耗或生产采用的增量结论。

审计脚本采用独占写入保存报告，避免覆盖既有证据。复算应在单独工作副本中运行，并保留原报告。各脚本中的数据与报告路径均相对于仓库定位；需要相应缓存输入与已冻结的 Python 数值环境。
