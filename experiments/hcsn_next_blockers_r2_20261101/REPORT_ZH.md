# HCSN R2：全量后续验收

原始基线为 `a793d55c23a7742378b081b162252da428a9fdb2`，前轮追加证据为 `57df8353c103a31dca85ed95b5931bc349735324`。本轮在 2026-11-01 至 2026-11-02 执行。新增任务、先验、输入适配器和实现均另行冻结，原失败结果保留。

**当前结论：不能宣称所有 blocker 已闭合，也不启动生产采用。** 本轮补齐了受限生成律下的后验验收、真实有偿信息补全、有限联合状态的控制价值见证，以及完整模型的精确实现和 CPU/RSS 点测量。解析核心的质量增量、全工作负载稳定加速和完整硬件采用仍未获得合格证据。

缺失任务的多核心、多种子视图及长短序列配对共享底层世界，不能当作额外独立样本。原先无缺失四查询全对的结果没有被缺失拒答指标替换。

另有独立的精确律定理：仅接受点质量后验，在旧均匀单擦除 Selective 总体上可取得 100% 接受正确率和恰好 80% 的汇总已知覆盖。80% 是 pooled query 指标；逐 episode 平均覆盖只有 7/9，有限批次也没有 80% 裕度。这是数学构造，未更改已确认的四分之一哈希策略，也不是一次新模型确认。最终擦除歧义下，任何只用现有观测的预测最大正确率为 2/3；严格拒答会完全拒绝这一分支，补全信息的效果由真实 READ 单独验收。

## 已修复且保留原记录的问题

- 原始 CNN 新流水线曾把情绪标签误作 DFA/IOM 句子目标；错误缓存、源代码与中止训练保留为不合格结果，正确的 144/144 二分类目标在合格训练前修复。
- 预训练视频的原“无 B 帧”保护在第 145 个训练片段正确中止。原协议和 68.709255 CPU 秒失败记录保留；修订方案在拟合前重新冻结，明确限定离线呈现前缀，未取得在线因果性或一秒端到端时延资格。
- 分布任务早期事件计数扩展为 `int64` 并加溢出保护后才进入合格确认；旧源码与失败开发保留。
- 原顺序浮点差分曾产生约 5×10⁻¹⁹ 的交互假阳性。原摘要保留，独立分组配对纠正 `(D−C)−(B−A)` 恰为零；正式结论采用纠正摘要。
- READ 的非有限时间戳、分数载荷和到达重叠检查在冻结前修复；服务不返回答案、教师后验或隐藏状态，计费与等待有独立记录核验。
- GRID 前缀读取增加精确登记成员、整角色采集账本、SHA、路径及留出候选发布保护。V2 元数据里的零新增载荷字段为模板残留，实际边界以保留的采集收据和单独溯源补充说明为准；V1 在新增载荷前冻结，模型协议在特征提取与拟合前冻结。

## 独立复核与成本

原始数组、实际服务轨迹、策略 rollout、数值与梯度、冷启动工作进程均有独立记录复算。前端另行复核二分类目标、演员外折、只在拟合演员上计算的标准化、冻结权重和清洁 AT/AVT 比较。哈希清单涵盖成功、失败、日志、源码、输入身份与实际输出。

最终合并账的已计量、非嵌套完整外层 CPU 下界为 **2027.870251 秒**，其中科学组件 2013.757656 秒、根回归和有计量的独立审计 14.112595 秒。两套 GRID 共用的 479.628925 秒只计一次；这不是完整全轮生命周期成本。冷启动子工作进程、CPU 点测量工作进程及模型内部计时已经包含在外层包络中，不重复相加；并行阶段墙钟和不同时间的 RSS 峰值不相加。READ 费用为登记的符号服务成本，等待为模拟时钟，未代表货币、外网延迟或计算能耗。历史预训练、未完整计量的开发、审计、写作与发布保留未知值。CPU 秒不换算成焦耳。
