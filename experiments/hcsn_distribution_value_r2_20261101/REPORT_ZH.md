# R2：存活条件分布如何改变真实动作和结算收益

**新的有限识别服务任务中，状态—内容关联对实际动作与收益有正向作用；强普通完整分布参照完整复现了该收益，解析实现没有独立增量。** 原标量动态任务中 Flow 落后 Transformer 的结果继续有效。本轮完成一个前瞻登记的新机制见证，没有将它换写成原学习网络门槛通过。

## 1．新任务与可见信息

物理状态为三个活动格点及一个恢复状态，未知目标位Y在整个episode内固定。自然outage使最高活动状态进入恢复，恢复后回到低状态。实际Gillespie路径保留区间内的全部事件、复位及剩余时间。

- **READ**：实际推进0.15时间，支付费用，返回带噪目标位及是否发生outage；读取准确率依赖当前隐藏物理状态。
- **WAIT**：实际推进0.9时间，只返回是否发生outage。
- **RESET**：保留未知Y，把物理状态复位到低格点，实际推进0.25时间并收费。
- **STOP_0／STOP_1**：提交目标位，正确得1，错误得0。

最终效用扣除真实READ／RESET费用、时间费及实际重复outage费用。在线仅提供区间outage位；精确次数在终局结算中使用，不作为额外观察泄漏。确认中实际出现了单区间两次outage，按两次收费。Y、真实物理状态和真实转移率只用于环境执行和审阅记录，不进入候选或规划器。

两核心共同从完全相同的监督校准材料估计：上下文依赖的四种物理转移率、按状态标记的带噪READ可靠性，以及cue到初始联合分布的对应。这里确实开放了训练阶段的物理状态／转移监督；它与先前原始输入学习任务的信息边界不同。目标位与初始状态的校准样本按已登记比例分层平衡，三个模型没有独立的先验计数波动。

普通参照用通用uniformization保存完整经验联合分布，另一实现用稠密标记CTMC指数。它们共享同一拟合生成元、初始分布、读取似然、费用和控制代码。普通参照没有被降为均值模型，数学一致是预期结果。均值压缩与关联分解仅作为明确的机制干预。

## 2．冻结与实际执行

修正后的五个科学源文件、协议及三个候选锁于提交 `243c38c8eef6665ccf680991ed304d2d4b8956bf` 发布并读回，然后才打开确认。

三套独立物理校准样本分别使用种子211／337／499，每套含24个训练上下文、每上下文64条长度5的物理轨迹。六个确认上下文是相同参数函数族内的新特征抽样；这是未见上下文的检验，没有改变生成器家族。源代码、原始校准路径、计数、暴露时间、标签和全部拟合参数均保存。

每模型执行6上下文×8cue×4价格×64个episode、八种策略。共有 **12,288组共享世界随机种子、294,912条策略执行记录**；三模型与八策略采用配对随机世界，后者不是294,912个独立世界。训练/执行对照使用完整联合或乘积边缘的闭式经验MLE，再单独改变执行时是否保留关联；没有把它称为独立神经网络重训。

549项开发检查通过：普通完整／杀死／重复计数传播与SciPy增广指数的最大误差为 **6.77×10⁻¹⁵**，并核对概率质量、计数和匹配均值／边缘先验。规划是带明确舍入与tie容差的FP64有限期数值DP，不是对任意连续模型或无限期策略的精确证明。

## 4．关联和匹配均值见证

两个匹配均值先验具有相同物理均值1和目标位边缘0.5，但在0.9时间内的无outage概率相差 **0.0850–0.1649**。它们在本次价格集上的初始最优动作恰好相同，报告没有把概率差直接称为初始动作差。

另一对先验连物理边缘与Y边缘都相同，但关联方向相反。存活后Y=0的条件概率相差 **0.1746–0.5390**。这些条件量由候选的拟合模型计算，用于解释信息机制；真实生成器posterior没有提供给策略。

预登记的关联主检验限制在这两个关联cue，比较完整联合执行与每次决策前分解关联的执行。完整联合的实际效用增量为 **+0.1530243**，六上下文条件区间 **[0.1244015,0.1881958]**，三个独立物理拟合的点估计均为正。配对记录中有 **9,083条实际动作轨迹改变**。这支持本有限识别域中的关联机制门，主D−B依然为零。

## 5．保留的修正与成本边界

确认前的独立源审阅指出：初版实际事件计数使用uint8。原run001科学源码、候选、准备和单独开发探针保留；采用run002把计数扩为int64并显式拒绝容量溢出，再冻结并重做准备。run001没有打开登记确认。

原冻结汇总器把交互项按`D-C-B+A`逐次浮点相加，错误地产生约5×10⁻¹⁹及正向标记。已保存的普通／稠密实际结果完全相同。独立按原登记括号`(D-C)-(B-A)`逐条重算，**交互项严格为零，原正向标记无效**。原科学源和SUMMARY保持原样，修正仅在 `CORRECTED_SUMMARY.json` 与 `INTERACTION_CORRECTION.json` 中记录；不重跑模型、不改变样本或门槛。后续引用应使用修正汇总。

五个不重叠的外层子进程包络合计 **86.963778 CPU秒**，包括两个准备轮、开发探针、全部八策略确认以及交互项记录修正。确认本身为83.950197 CPU秒。内层策略计时已包含，不重复相加。独立审阅、源准备、部分汇总、打包及历史研究投入没有完整计量，故该数是明确范围内的已测成本，不是完整采用成本；设备焦耳、GPU与进程族同时峰值仍未知。

独立审阅重构训练计数与暴露时间、读取校准、先验样本、576个原始文件／4,608个arm-cell记录，核对全部294,912条执行的终止正确性、费用、动作时长和配对差分，并独立确认交互项修正。审阅成本保持未计量，没有用工具壁钟替代CPU。

本轮交付的可复核进展，是有限已识别任务中的分布／关联信息确实改变真实动作并改善登记结算收益，且普通完整分布参照同样做到。下一轮学习网络需消费这些条件信息并接受强普通模型、同控制、完整实际成本的检验；原标量负结果、真实音视频、连续自由边界和生产采用关卡仍保留。
