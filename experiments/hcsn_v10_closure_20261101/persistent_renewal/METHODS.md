# 原首达／复位过程的持续观测比较

本目录沿原 v2 的 `make_episode`、`generate_path` 和 `shared_calibration` 生成过程。`source_snapshot/EXTRACTION.json` 固定原文件哈希、AST 选取定义、行号和逐定义哈希；`physics.py` 仅补上显式 NumPy／SciPy 导入，不加载或伪装 torch。

过程保留逆高斯首达时间、复位间距、绝对恢复期、Bessel bridge 中途观测和五类内容的 Markov 转移。READ 一 tick 后到达，只揭示该时刻物理间距、恢复剩余时间和内容，不重置真实世界；预算三次；STOP 关闭后续感测；原四个输出 deadline 仍执行并计费。

GRU／SSM 在一次 episode 内跨 tick、跨 READ 保留隐藏状态。共同 16 维输入只有：本次 dt、READ 标记、是否已有 READ、最后一次已接受的间距／恢复剩余／五类内容、距该观测的时间、共同公开的四个物理估计参数、当前时间。初始间距公开，初始内容隐藏。未 READ 的当前间距或内容不进入输入；实际真值只在监督和评分时使用。

普通模型输出五类内容概率，不是替代计数分布标签拟合。共同 head 在 fresh READ 返回完美感测的 one-hot 内容，在首次 READ 前保持生成律的平稳均匀先验；隐藏态仍在推进，后续预测依赖核心。此 head 只适用于原完美感测有限任务，不能直接套用到不确定的真实 AV 识别。

每个拟合种子共用相同的随机缺测／读取序列、数据和 minibatch 顺序。GRU、SSM 及 latest-packet MLP 都分别拟合宽度 16、32；每种族只用独立验证 NLL 选择容量与 epoch，再在 GRU／SSM 中选普通核心。训练至少 80、最多 320 epoch，验证 40 epoch 未改善 1e-4 时早停。所有候选、验证历史和用尽预算记录保留；早停不是强模型资格证明。五个种子和世界命名空间在训练前登记；测试不参与选择。

A/B 为验证选择的普通持久核心，C/D 为解析 renewal 核心。A/C 共用原轻量阈值控制，B/D 共用原四粒子的“一次计划 READ”后续价值启发式。候选未来由共同估计律重新采样，控制器没有实际世界路径接口。每次假想 READ 克隆当前视图，推进自己的未来，不修改真实 hidden state 或重复消费实际输入。多个 deadline 的顺序缓存与 literal tick 重放逐值对照；解析动作值还与原 AST 提取的控制器作逐值对照。

两个无核心参照分别是：同样监督拟合的 latest-packet MLP，以及由可见 READ 历史重建最新充分 packet 后按同一解析律传播的 H。它们都有共同内容缓存；“无核心”不等于“无记忆”。在所声明的已知估计物理模型内，完美 READ 是 Markov 充分状态，因此 H 与解析 D 的质量应相同。历史可能有助于识别真实参数估计误差或隐藏恢复期；H 并未执行这些未知参数的完整 Bayes 推断，不能称为真实失配世界的 Bayes oracle。

H 仍使用解析 `renewal_counts` 算子；D−H=0 只针对持续隐藏状态的实现，不是移除解析算子的机制消融。MLP 才是不使用解析传播算子的学习参照。所有控制器的假想路径仍来自共同的估计生成模型。主要收益沿原定义为四次输出平均正确率减实际 READ 费用，CPU 单独完整记账，没有把 CPU 换算成货币效用或宣称完整经济收益。

本比较回答原有限合成过程中的实际控制与内容问题。它不含新独立录制、真实多模态识别、完整金融自由边界、开放域生成、生产 Rust 实现或可归因设备能量。解析模型具有正确函数形式先验；即使对有限训练预算出现正向差异，也不能单独支持架构采用或机制必要性。

`results/development001` 保留首次冻结和五项通过的前置检查。其后仅优化重复 forecast 工作，另在 `development002` 冻结，并增加第六项 literal tick 等价检查；首次尚未生成拟合或测试世界。两次前置阶段都由相邻经济性工具计量，不能丢掉首次准备费用。
