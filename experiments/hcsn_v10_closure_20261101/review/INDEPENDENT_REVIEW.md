## 截止合同：服务超时与输出违约已经分开

初审发现新服务返回 v10 `ReadResult`，旧 v8 executor 却严格检查另一类型，旧臂会在首次 READ 抛异常；作者在正式冻结前完成适配。新的 reserve executor 把服务等待截点提前，分别记录 head、序列化、sink 和 guard 的实际预算。输出是否违约仍由硬 deadline 后的真实 flush 完成时间决定，不能把服务 timeout 直接当最终输出 miss。

独立重构 144 次正常运行及两个实际压力运行的内容、费用、风险字段、输出时钟和迟到 drain：固定旧动作仅修复 reservation 后，逻辑净效用差为 `+0.5010375`，八个实际世界的描述差为 `+0.500879701`。正常 reserve 实际运行中服务仍可超时，但输出没有违约。新合同下显式 output-risk 完整与置零的逻辑差恰为 0，实际差约 `1.38e-5`，来自时长计费噪声，动作和内容概率一致。

这解释了 v9 的大风险溢价：相当部分来自等到硬截止才开始 flush 的执行合同，不是金融 Put 或解析核心的内容收益。两个慢 head/sink 压力例都超出预算并实际迟到，正确保留，不能声称任意 head、sink 或 OS 调度下的硬实时保证。`reserve_full−old_full` 的实际差仍为负，不能选择性只报告正向修复差。

## 原 renewal 持续状态：补齐了比较，尚未建立严格增量

基线轮和追加预算轮分别独立核验 1,632 次运行、34,272 个实际 tick 状态；隐藏状态误差为 0。核验覆盖实际 READ 信息边界、最新可见 packet、原解析 CDF/内容转移、四个强制输出及费用。保存的随机模拟候选值检查了决策一致性；完整四粒子假设规划器没有在本独立重构中全部重跑，其 clone 和优化等价由源码审阅及独立行为测试支持，不能把二者混称为同一检查。

追加预算只覆盖原验证状态确定的三个 SSM 未 plateau 候选。独立核对了另外 27 个候选 checkpoint 哈希、全部拟合数据哈希不变，前三百二十一项验证值逐项相同，新测试世界种子与旧轮无交集；运行时检查 epoch320 最佳权重完全一致的凭证也保留。这是追加的 validation-only 规则，不是原先预注册的 320 上限；全部重复前缀成本需要重新计入。

追加轮中，匹配和隐藏 refractory 不匹配两条件的 D−B 分别为 `+0.0226667`、`+0.0265`，其 95% 区间分别为 `[-0.0209167,0.0672542]`、`[-0.0205833,0.0765021]`，均跨零。D−MLP 区间也跨零。两轮 D 与精确原始历史参考 H 的动作和概率完全一致，D−H=0。原任务 READ 完美揭示内容、gap 与剩余 refractory；把共享估计参数当固定模型时，最新 packet 已包含该解析模型的充分状态，持久化实现本身不能证明该任务需要长期记忆。隐藏物理参数下普通模型可能利用额外历史估计，而当前精确 H 只重建最新 packet，也不能称为已资格化的最强无核心替代器。

### 固定大样本确认没有通过双主要比较

后续因区间过宽追加固定 384 个新世界，每条件 192 个，八片全部完成后才汇总。它是事后设计的独立有限世界确认，不是最初预注册，也没有保证功效。模型选择、全部 30 个候选 checkpoint、五个拟合种子均保持不变；独立核验新世界与原训练、验证、基线和追加轮排除集合无交集，以及预定 seed 命名空间、八片计划和全部 raw 哈希。

`CONFIRMATION_RECONSTRUCTION.json` 独立重构 13,056 次运行、274,176 个实际 tick 状态和 52,224 个强制输出；隐藏状态误差为 0，全部配对效应和 bootstrap 区间逐项重算一致。重采样单元是独立世界与五个拟合种子；同一解析 D/H 在五个 fit 中的重复不是新增独立样本。匹配条件的两项主要比较各用双侧 97.5% crossed bootstrap 区间，按事先冻结于该次确认计划的双比较 Bonferroni 描述口径，不能把它当小样本下精确覆盖保证。

独立输出另外保存 A/B/C/D/H/MLP 的准确率、实际 READ 数、READ 费、NLL 和 Brier，避免把更好概率校准与更好净收益混称。matched D−B 的准确率差为 +0.00651042，额外 READ 费为 +0.00041667，得到净差 +0.00609375；mismatch 准确率差为 −0.00130208，额外 READ 费为 +0.00275，得到净差 −0.00405208。两条件 D 的 NLL/Brier 都较 B 低，却不足以使已声明净效用主要比较通过；CPU 没有被擅自折进 READ 费效用。

该报告还有一项保留的审核元数据时序错误：运行期间审核者扩展了无关的 CI dispatcher，旧 driver 在报告结束时读取了新的磁盘自身哈希，而启动源码快照仍保留原 driver。原 JSON 不覆盖；`CONFIRMATION_IDENTITY_NOTICE.json` 单独绑定两份保留源码并说明差异仅为新增 CI 分支，confirmation 与状态重放 checker 未变。后续 driver 直接记录启动快照哈希。此处不能声称两个 driver 哈希原本一致，也不应因这项已披露的元数据错误重命名或丢弃科学数值结果。

## 联合重训：真实改变了动力学和内容，但表征优势依任务和指标而定

独立从参数、数据和矩阵幂重构 30,720 条预测、所有验证选择与联合参数变化，最大概率误差 `1.11e-16`。六个参数确实包括两个漂移/波动校准尺度和四个循环内容转移 logits，已超出只重训读出器的 v9 范围。single 干预严格只保留 N=0/1；学得的一步稠密转移可合法近似多事件边际，不能把这种替代能力称为暗中恢复实际多次事件。

重训 mean 消融相对完整模型 NLL 差为 `+0.00762049`，95% 区间跨零；single 差为 `+0.05892229`，区间为 `[0.04460392,0.07467599]`。完整模型比本轮普通 MLP 的 NLL 低 `0.03033581`，只支持这项已知有限模型族和有限替代器的比较。single 准确率略高于完整模型，不能说完整机制在所有指标上占优，更不能据此证明控制净效益或完整 AV 网络必要性。

一个 mean 拟合点的较大步长有限差分与解析梯度范数不一致，已由独立额外计量诊断澄清：某训练行的拟合均值为 `1.9999999188675452`，距离整数约 `8.11e-8`。步长 `1e-6` 跨过分段 knot；步长 `1e-8` 不跨时最大梯度为 `0.00043289816`，与解析值 `0.00043288914` 一致。这不是已发现的解析梯度实现错误；目标本来分段非光滑，正常 optimizer 停止也不是统一光滑性或 KKT 证书。

## 历史 AV 新候选：情绪线选中了初始化，绑定线有学习但增量为负

新的 latent renewal 是明确自定义的输入局部算子：前一状态决定有限区间 count 分布，复内容对按分布旋转，再吸收当前已接受 packet。它不是已识别的媒体物理律、完整金融模型或持续存活 gap 后验。初审指出 cap10 截尾再归一化缺少支持合同；作者在冻结前加入有限 dt∈[0,1] 和尾质量 guard。当前 source increment 只有 0/1，不能据此推广任意长时间推进。

独立重构 3,240 次历史运行、15,208 个 accepted 更新和 5,054 个决策读出器，隐藏状态最大误差 `7.63e-16`。初次审核有四个 direct 决策缺少完整当前 head packet。后续 `AV_INTERFACE_SUPPLEMENT.json` 已在单独计量阶段用发布的特征 NPZ 和字节绑定旧 V3/V8 接口重建这些实际接受前缀，再用独立 NumPy 新模型 reader 核对，四项均闭合。该部分明确复用了旧 head/前缀接口，不是另一套独立媒体 encoder；原 partial 报告没有覆盖或删除。

最重要的新失败是训练目标分布偏移。只读 train/validation 的事后诊断按原录制与演员聚合、折叠十条顺序，情绪线 masked 正率由训练 `0.88950617` 降至验证 `0.33858025`；用训练常数先验预测验证的 BCE 为 `1.49661650`，远差于 0.5 常数的 `0.69314718`。完整 3:3 端点训练准确率为 1，验证为 1/3。绑定线也由 `0.90046296` 降至 `0.70817901`，完整端点由 1 降至 3/4。这支持 in-sample 固定头正确性与新演员正确性存在偏移的诊断，不能单凭该描述计算断言全部训练失败的唯一因果机制。

情绪线 35 个模型中 34 个由验证集选中 epoch0，五个完整 renewal 都选初始化且 physics 变化为 0。final 权重训练过、单步梯度非零或运行了训练循环，都不能替代“所选模型获得有效联合学习”的证据。绑定线 35 个模型确有选中的训练，五个完整 renewal 的 physics 参数变化约 0.040–0.046；但共同内容 encoder/head 始终固定，不能说完整内容模型联合训练。

按原先验证选择的 B，情绪与绑定的描述 D−B 分别为 `−0.00249975`、`−0.01262371`。另加的 validation-motivated 常数0.5参考独立执行 72 次，原 B 没有被追溯替换；D−constant 分别为 `+0.0088305`、`−0.06329492`。常数运行的 66 个最终 head 端点与主 AV 交叉相同；六个主实验未到的绑定端点，也在后续接口补核中由实际 NPZ 及字节绑定旧 head 重建并逐值一致。该额外参考是事后历史描述，不能改称新的预注册独立确认。

## 成本与严格结论

外层 wait4 阶段账包含内层计量器的启动、导入和收据序列化，正式 prepare、数据、训练、执行、验证、独立审核及失败都应按各自独立子树计入一次。内层 CPU 只作诊断，不再相加。账本自身尾部收据需要单独说明；作者已采用外部加回，不能让自读取的账本假装天然包含自身尚未生成的收据。代码创作、早期检查、缺失历史工作和最终账本写出仍有明确边界，不是所有发展成本均已知。

闭合的四进程控制 fixture 中，逐进程最终 wait4 高水位记录覆盖了没有驻留采样的短命 48MiB 分配。完整固定进程库存下，`sup_t Σ RSS_i(t) ≤ Σ sup_t RSS_i(t) ≤ Σ H_i` 给出保守 RSS 和上界；共享页、继承最大值只会使上界更松。这是实际进展，但不能直接用于没有完整进程创建/回收库存的任意模型服务，也不是同时物理唯一内存峰值。本地 cgroup 只读与无可归因设备能量的能力记录保留。

### 两次真实 hosted kernel 峰值已完成限定资格

新增 hosted CI 已实际成功，不再是 queued 或静态方案。两次下载各自绑定 GitHub run、attempt、源 commit 与原始 artifact；根负责人另保留下载 digest/CRC 核验。本独立检查从 artifact 的 SOURCE_COMMIT、外部 API provenance 和 kernel receipt 核对对应身份、初始空组、exec 前门控入组、任务退出、后代清空、无 OOM 与 own-group 删除。

该实测闭合的是门控 exec 后这一次冻结有限联合评价及后代的 **cgroup memory-charge 峰值**。它包含归属本 group 的 kernel/page-cache 费用，既有共享库或 page cache 的 charge 可能属于先前进程；fork 前 wrapper 既有页也不因迁入自动归属本 group。因此不能改称全进程 RSS/PSS、冷缓存峰值或去重物理内存，更不代表全部训练、完整 AV 执行或生产服务峰值。进程族清空后仍有缓存 charge 也是这个口径的正常现象。所有归属和重放条件应与该 run 一起引用。

远端 checkout、pip、wrapper 和任务 CPU 没有被该 memory helper 完整计量，保持 unknown，不是零；本地独立 CI 审核阶段才进入本地 CPU 账。设备能量仍为 null。本轮首次获得真实任务专属 kernel 计量是实际进展，完整经济采用门仍 HOLD。

可闭合的限定项目是：新执行 reservation 合同与负压力例、原任务持续状态接口、有限联合重训、历史 AV 候选及失败定位、正式阶段 CPU 账、控制 fixture 的保守内存上界，以及两次冻结 joint 评价的专属 cgroup 峰值和数值等价。仍需真实资产或新证据的项目是：原 v6/强音频/完整排除与新录制，具有有效学习且优于强替代器的真实 AV 解析增量，完整多模态内容联合学习，以及部署层完整内存与能量采用门。没有把模型状态递推重放、历史弱头、合成过程点估计、单任务内存或 CPU 收据升级为这些验收。
