# 有限 renewal 模型的动力学与内容联合重新训练

这一轮把最终内容似然同时传回动力学概率和内容转移。拟合对象是可明确写出的有限首达/复位模型，范围比 v9 的冻结核读出器拟合扩大；它仍不是完整 AV 深网、金融自由边界网络或生产 Hepta 模型。

给定共同物理 packet，动力学为

\[
\nu_\alpha=\nu_{\rm packet}e^\alpha,\qquad
\sigma_\beta=\sigma_{\rm packet}e^\beta.
\]

内容转移由五类循环位移的四个独立 logits 参数化：

\[
T_\gamma=\sum_{j=0}^{4}\operatorname{softmax}(0,\gamma)_j S^j.
\]

最终输出使用

\[
\pi_{\alpha,\beta,\gamma}
=\sum_{n=0}^{23}p_{\alpha,\beta}(N=n)T_\gamma^n e_{c_0}.
\]

训练的六个参数包括两项动力学校准与四项内容转移权重。最终内容 NLL 对两组参数求导：首达 CDF 的解析导数负责动力学，逐次转移递推负责内容。测试通过独立有限差分核对这两条导数，并检查梯度非零、参数实际改变、概率质量及梯度质量守恒。

`original`、保均值两点计数分布、至多一次转移三个模型使用相同信息、参数容量、初始化种子、优化预算和验证选择，各自独立重新训练。另保留完整模型原参数直接执行两种消融的结果。

单转移消融始终满足 `N∈{0,1}`，最终输出只执行一次学得的 `T`。所有模型都允许同容量的稠密循环转移，所以单转移重训后的 `T` 可以近似原过程多次转移的边际内容分布。这属于明确允许的替代能力，不能据此声称它恢复了原事件次数，也不能仅凭退化声称完整机制普遍必要。

普通参照是同一六标量 packet 上的 `6→16 tanh→5 softmax` MLP，共 197 参数，容量大于六参数联合模型。两者都使用相同的已知类别平移对称性；MLP 训练输入不含事件数、真实动力学或未来内容。它是一个实际拟合的普通替代器，不能自动代表所有强普通模型。

数据标签来自独立 inverse-Gaussian 事件模拟与逐事件随机内容转移，生成器不调用解析 CDF。共同 packet 的漂移和波动率带有固定校准偏差；真实参数与实际事件数只保留作诊断。每个拟合种子使用 2048 训练、512 验证，五个新拟合种子共同评估 1024 个新留出世界。`train` 阶段只加载训练与验证文件，所有参数冻结后才由 `evaluate` 阶段加载留出文件。L2 按验证 NLL 选择，留出评分不用于调整预算或超参。

主指标为独立重训消融减完整联合模型的留出 NLL；同时保留普通 MLP、同参数执行期消融、准确率和 Brier。没有 READ 控制、服务风险或执行效用，因此这里不报告 `D−B` 或闭环净收益。

正式研究分成互斥计量阶段：`prepare` 固定计划与源码，`data` 生成资料，`train` 拟合并选取参数，`evaluate` 只读冻结参数输出与汇总。预检和独立原始记录审核另行计量。所有阶段通过相邻 `economics/stage_meter.py` 启动，不覆盖既有凭证。

当前计划与结果位于 `results/development001/`；独立审核、优化器停止条件、边界参数和费用应连同结果一起读取。优化器的 `success` 是软件停止状态，不能代替梯度门槛、全局最优或普通参照强度证明。设备能量、精确连续进程族内存及未恢复的历史成本仍按实际可测范围报告。

## 本轮实际结果

40/40 候选返回优化器正常停止状态，全部 15 个验证选中联合模型的动力学与内容参数均改变。动力学参数变化范数最小 `0.039596`，内容参数变化范数最小 `1.257851`，两个参数组的初始梯度均非零。动态尺度没有触及预设边界；部分内容 logits 在边界附近，对应稀疏转移拟合。`success` 包含 ftol 停止，不能据此声称全部达到同一梯度阈值或全局最优。

五个拟合种子、1024 个共同新留出世界、六个执行臂，共 30720 条概率预测。均值如下：

| 执行臂 | NLL | 准确率 | Brier |
|---|---:|---:|---:|
| joint_original | 1.019553 | 0.527344 | 0.541814 |
| same_weight_mean_two_point | 1.068246 | 0.518945 | 0.559486 |
| joint_mean_two_point | 1.027173 | 0.521094 | 0.544053 |
| same_weight_single_transition | 1.576065 | 0.523438 | 0.593760 |
| joint_single_transition | 1.078475 | 0.527539 | 0.554381 |
| ordinary_mlp | 1.049888 | 0.523047 | 0.550541 |

独立重训的保均值消融减完整模型 NLL 为 `+0.007620`，跨拟合/世界 bootstrap 95% 区间 `[-0.001382, +0.017089]`，区间包含零。单转移重训差为 `+0.058922`，区间 `[+0.044604, +0.074676]`。相对完整参数直接执行消融，独立联合重训的 NLL 分别改善 `0.041073` 与 `0.497590`。不能用执行期消融的较大损失替代重新训练后的实际比较。

完整模型减较大普通 MLP 的 NLL 为 `-0.030336`，区间 `[-0.043702, -0.016663]`。这项有限模型的似然结果支持当前结构与训练组合在该生成器上的贡献，范围包括正确模型族先验，不能外推为真实 AV、持续记忆网络或一般普通模型上的优势。单转移重训准确率 `0.527539` 还略高于完整模型 `0.527344`，因此没有全指标支配结论。

完整源码快照与 PLAN 的五项 Python 文件哈希一致，见 `SOURCE_FREEZE_CHECK.json`。正式执行的逐阶段日志、完整进程成本与独立审核凭证应和 `JOINT_REPORT.json` 一起读取；精确连续族内存、可归因设备能量和历史成本仍不作补值。

## 独立审核与计量

独立审核没有导入候选模型实现，重构全部 `30720` 条预测，最大概率差 `1.1102230246251565e-16`；重新检查验证集选取、保存参数、单转移支持和物理边界概率质量。独立有限差分结果保留在 `../review/JOINT_RECONSTRUCTION.json`。保均值两点干预在整数均值处非光滑，其中一个拟合点的有限差分与当前分支的解析梯度最大值不同；这些检查不构成统一光滑梯度、KKT 或全局优化证书。

验证、prepare、data、train、evaluate、独立审核六个互斥阶段的外层 CPU 合计 `36.226047` 秒，内层计时已包含，不能再相加。该边界包含每个受计量进程的启动、子孙进程、观察器及内部凭证写入；代码编写、工具传输、阶段启动器自身和最终阶段凭证写入、历史工作不在该数值内。完整收据链接列于 `JOINT_REPORT.json`，仍不等同全部历史准备成本或设备能耗。
