# 历史 AV 解析候选：已接入，未建立增量

本轮把一个可联合训练的 input-local renewal 状态算子接到历史 AV 的共同内容头和共同价值控制器。定义、信息边界和限制见 [METHODS.md](METHODS.md)。它是新定义的潜在归纳偏置，不能冒称恢复了 v6 模型、识别了媒体物理律或获得新独立录制。

两任务、五拟合种子、七模型族共 70 个候选；包括 GRU、SSM、完整已接受历史 MLP、解析 full，以及各自重新训练的保均值/单转移变体。所有种子与最终/选定权重保留。正式历史执行共 **3,240 次**，共同固定采集与价值控制均实际运行；同权重执行期消融另存，未混同重训。

B 是原冻结验证选择的普通模型族，未在看结果后替换。常数参考是训练/验证诊断激发的 **post-hoc** 补充，另有协议、72 次执行与费用账，不是新的预注册确认。

这些执行重复使用少量已暴露录制。历史 test 包含 12 个原音频录制、两个演员；绑定配对和五个拟合种子不增加独立录制数。不报告新确认置信区间，也不把 3,240 次运行当 3,240 个独立对象。

**学习是否被验证接受，必须单独判断。** 情绪任务 35 个模型有 34 个选中 epoch 0，包括全部五个 full-renewal 模型；这些选定动力学权重没有变化，不能用训练过 final 权重来宣称选中模型学到了有效解析动力学。绑定的 35 个模型选中非零 epoch，full-renewal 的物理映射确实改变，但其净效用仍未超过原 B 或廉价常数参照。

按原录制折叠十种采集顺序后，情绪训练集的 masked 正确性目标正率为 0.889506，验证集为 0.338580；训练常数先验在验证上的 BCE 为 1.496617，而 0.5 常数为 0.693147。共同头在训练完整端点正确率 1.0、验证 0.333333。该结果支持调查样本内共同头正确性目标的分布偏移，不能单独证明每个模型选择初始权重的因果原因。完整诊断位于 `review/TARGET_SHIFT_DIAGNOSTIC.json`。

六项修复后行为/独立数值检查通过，包括 SciPy 首达计数、梯度、均值保持、未来前缀与时间支持拒绝。首次测试失败及精确旧源保留在经济性目录。候选自己的审核重放全部 3,240 次运行，状态误差 0，最终共同头概率和费用一致；跨模块独立 NumPy 审核及其准确覆盖范围见相邻 `../review/`。

数据准备、70 模型拟合、执行、审核、失败测试及追加参考均有互斥计量阶段。source/service clock 是声明的逻辑时钟；实际测量是 CPU，不能冒称媒体解码、GPU 时延、设备能量或完整历史准备费用。完整内容编码器/共同头仍固定，本轮不等于完整 AV 网络端到端重训。

复现时先使用根 `publication/prepare_av_replay.py` 复制已发布的冻结输入集到新输出目录，再调用 `campaign train`、`campaign evaluate` 和 `audit`。源码要求可用 Torch/NumPy/SciPy；本轮只读 Torch 2.15.0+cpu 运行时不随研究复制。已有 frozen 结果不得覆盖。
