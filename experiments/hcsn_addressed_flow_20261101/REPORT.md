## 1. 算子：保证描述的是同一个过程

沿用行向量约定，概率满足 `p'(t)=p(t)Q`。事件标记矩阵 `R` 保留复位回原状态的自事件：这种事件可能不改变净状态，却仍应计入发放次数。存活过程使用 `Q0=Q-R`；因此 `p0 exp(t Q0) 1` 是尚未发生首个事件的概率，其补量是首达概率，而重复事件期望可以大于一。局部折现价值与首达变换使用相同的 Q、Q0、事件率和复位律。这些固定系数、固定策略量没有被称为任务级 Bellman 最优值。

原 174 项算子检查重新执行，**174/174 通过**。可选 Poisson 多项式加缩放平方实现的第二次开发审计 **202/202 通过**，独立参照包括 NumPy 组装、SciPy 矩阵指数、增广计数指数及 Frechet 导数。覆盖零时长、零事件、负漂移、不应期、自复位、重复事件、PGF 导数、批隔离及高率极限。

| 数值项目 | 最大记录绝对误差 |
|---|---:|
| 常规 FP64 转移对 SciPy | 1.788×10⁻¹³ |
| 常规 FP32 转移对 SciPy | 1.384×10⁻⁶ |
| 抽样 Frechet／时间梯度 | 6.033×10⁻⁹ |
| PGF 导数与重复事件计数 | 3.318×10⁻¹² |
| 高率计数 | 1.239×10⁻¹¹ |

截断上界是精确算术下的上界，明确排除浮点误差。连续反射扩散的首达时间参照还揭示了空间离散误差；不能把有限链的矩阵指数称为连续扩散的精确传播。初次审计的两个失败来自精度不一致的时间输入和不成立的逐网格单调误差断言，失败及修正依据均保留。

大批量内核反向传播有局部加速，但完整模型没有稳定获益。实际执行路径另核验 216 次调用、133,056 个矩阵，确实经过可选路径而非全部落回稠密算法。**默认仍保留稠密矩阵指数。** 详见[算子报告](operator_audit/FASTPATH_REPORT.md)和[原算子回归](results/operator_regression001/)。

第一版同等时长的静默等待保持接近满分，而干扰观测导致崩溃。因此进一步检查写入资格。第二版只允许原始类型声明为 WRITE 的事件写内容、BRIDGE 写关系；其他类型的写入率严格为零。合资格事件仍使用原学习门。原始输入、控制张量、状态演化和传输算法都保持一致。**这是两个核心共享的明确类型先验。** 占用归一化还可能抵消公共的事件衰减，不能把内容成绩自动归功于解析动力学。[结构说明](ADDRESSING.md)、[修订源码](typed_retention.py)

### 缺测没有被满分掩盖

第二版所有仍可从观测恢复的查询为 100%，但依赖已删除写入的查询表现很差。Flow 在 MQAR／Selective／Binding 中这类查询的准确率分别只有 **0.358%／0.048%／0.260%**，低于八分类均匀猜测的 12.5%。总体单查询准确率分别为 75.090%、83.114%、75.065%。

缺失信息不能凭空恢复，但这些错误也不能被称为 Bayes 最优；缺测训练、未知状态表达、置信度和拒答仍未获得合格证据。预注册的九条件质量门本来就不包含这种信息被删去的条件，报告没有在看到成绩后移动门槛。

三项基础 Flow−Diagonal 差均为零、bootstrap 区间退化为 [0,0]，只说明本次有限样本全部成功，不是总体等价或零风险证明。符号跨模态绑定也不能替代真实音视频理解。

## 4. 实际 READ/STOP 四格实验

两个版本分别运行普通核心／Flow × 轻量阈值／价值控制器四格。价值控制器从训练期实际 READ−STOP 续程收益拟合，共享同一组系数；轻量对照是在开发集选出的最佳固定价格阈值。确认时，模型先观察原始查询，再付费取得被删除的最后一次原始写入，随后重新查询；没有把计算出的正确答案作为输入。

控制器只使用首次查询时可见的概率、熵、已过时间和缺测信息。未来查询、未来时钟与标签不进入控制特征。这里的任务收益回归器与算子中的局部折现价值是两个明确区分的对象。

第一版 Flow 内的 value−lightweight 三任务增量的描述性 95% 区间均包含零。第二版重新冻结策略后，在新种子 118101 上确认：**两类控制器选择完全相同**，三任务的 value−lightweight 与交互项均为零。MQAR 的 Flow−普通核心效用差为 0.00008138，95% 区间 [0, 0.00032552]；另两任务为零。没有建立价值控制与解析核心的协同收益。

真实补读可以把四查询全对率恢复为 100%；强轻量价格门槛已经匹配该价值控制器。所有五种差分都保存，不能只挑一个正点估计。符号 READ 价格、CPU 成本和能耗是不同账目，离线计算两个续程的成本也不能当作线上控制器算术成本。[第一版控制](results/control001/)、[第二版控制](results/retention_control001/confirmation/SUMMARY.json)

## 7. 对后续主线的实际约束

本轮可保留的成果是共同的键值／关系寻址、严格写入资格、同过程算子契约、可核验冻结链和失败记录。普通寻址模型必须继续作为强参考。解析核若继续扩大投入，需要出现普通模型无法同成本匹配的分布或决策收益；当前时钟敏感性与内核局部加速不足以承担这个结论。

内容下一道门包括缺测下的不确定性与拒答、没有显式 WRITE／BRIDGE 标签的输入、扩展键数和未见任务分布。真实模态下一道门是有独立群体覆盖的有效视频信息及视频增量。只有这些质量门通过，才有依据把 GPU、吞吐、端到端尾时延和实测能耗纳入采用比较。
