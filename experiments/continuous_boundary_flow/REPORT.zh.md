# Hepta 价值边界、双通道与连续 flow：正式实验结果

## 结论与当前决策

**工程接入成立；三项预注册最小收益均未建立。** 当前证据支持保留现有 Hepta sparse neuron 主线，把价值边界、续行值、风险和 flow 保留为可消融的任务接口。尚不足以据此把现有内核整体替换为所谓 Continuous Spiking Network。

这并不证明三个想法普遍无效，也不是等价性结论。尤其双通道的均值方向为正，但独立种子之间仍有不确定性。下一轮应先检验策略训练与表示能力是否限制了这些输入的价值，再判断新的动态结构是否值得引入。

正式结果是 `study-002`：8 个独立训练/环境种子、9 个学习方法、4 个参考策略，每臂 2,048 个确认 episode，ID/OOD 各一半，共 **26,624 条轨迹**。主分析单位是 8 个 seed，不把同种子下的窗口或轨迹当作独立训练重复。所有方法共享公开状态、成本、绝对剩余期限、动力学信息、训练 teacher 和固定槽位的随机创新。

科学源码在训练前发布于 [5bbd4f2](https://github.com/TrillionniumFoundation/hepta-private-ci/commit/5bbd4f254f9331227e3b3acb048ae3e6a422ee4b)，模型选择封印在确认前发布于 [d7af4cb](https://github.com/TrillionniumFoundation/hepta-private-ci/commit/d7af4cba57bb7d5472c0794d4f09c31ec98e1787)。科学源、72 个已选学习模型和统计门槛在确认过程中保持不变。

## 三个问题的直接答案

净效用定义为物理任务效用减去 `1e-6 × 数值消息字节数`。CPU、求解与 JSON 线路成本另列，并未伪装成已计入该净效用的资源价格。下表为预注册的配对 seed Student-t 区间：各项 98.3333% 置信水平，三项 Bonferroni familywise 95%。通过要求为区间下限大于 **0.005** 且无稳定性失败。

| 主问题 | 比较 | 平均净效用差 | 同时置信区间 | 收益门槛 |
|---|---|---:|---|---|
| 价值边界是否优于直接学习边界？ | value_margin − learned_margin | −0.071980 | [−0.370054, 0.226093] | 未通过 |
| 风险/干预通道是否增加价值？ | value_dual − value_call | +0.048492 | [−0.031260, 0.128243] | 未通过 |
| 连续 flow 是否优于事件复位？ | value_dual − event_reset | −0.021073 | [−0.100581, 0.058435] | 未通过 |

三个比较的稳定性检查均通过，未过的是收益条件。双通道的描述性 bootstrap 95% 区间为 `[0.004003, 0.097633]`；它未经三项 family correction，且下限仍低于 0.005，不能替代预注册主判定。

双通道相对仅 C 的正向均值主要来自 OOD：OOD 增加约 0.1290，ID 减少约 0.0320。这个方向值得后续新协议研究，但不能在本轮改判。当前 sparse 和 dense 对照的总体均值都高于完整双通道 flow；两者相差很小，不能仅凭排序判断谁普遍更好。

DP 与完整双通道的总体差约 0.6246，OOD 差约 1.0548。一个合理的后续研究方向是先降低已知任务模型下的策略决策损失。DP 是离散任务的算法参考，直接执行时未经过原生神经消息链；其 CPU/通信数字不等于一个与 Hepta 完整部署成本匹配的产品实现。

## 实际实现了什么

有限期限维护任务在每个窗口选择等待、维护复位或停止。健康状态服从窗口内的 Brownian first-passage law；失败时按实际首达时刻记损失，窗口剩余时间不再生产，并在下个窗口复位。维护在窗口起点扣成本并复位。所有原始事件时刻、风险、动作、状态与收益均可重算。

任务分解满足 `Q_wait = C - P`。这里 C 包含生产和后续续行价值，P 是折现失败损失。自由边界来自同一任务的 Bellman 比较，是数值有限窗口干预边界。它不是完整 He–Xiong 金融均衡的重建，也没有声称满足连续时间最优停止的精确 smooth fit。

flow 与 event 的直接区别在新增 adapter 状态的更新：使用上一窗口的条件期望首达流，或实际 0/1 首达事件作反馈/复位。所有学习方法随后通过同一份原始 Rust sparse kernel 和 NDU。当前 sparse 对照不保留额外 adapter recurrence。这个比较没有把原生 neuron 全部改写为 Fokker–Planck PDE 或连续 ODE。

每个学习方法具有共同的冻结 encoder、原 width-20/top-k-4 sparse recurrence、**42 个拟合 head 标量**，每 seed 同样比较 12 个开发候选。直接边界另拟合 20 个系数；generic/dense 对照另有 42/78 个固定随机混合系数。应准确称为相同输入和可训练 head 预算的比较，不能声称总存储系数完全相等。

训练采用公共 DP teacher 的读出层拟合与开发集候选选择。没有完成全参数 GRU/LSTM 训练或 BPTT。完整链仍含 clip、Q24 量化、hard sparse selection 与离散 NDU 动作，不能据此声称已经建立端到端可微 SNN。

## 与当前 Hepta 的直接关联

全部 **205,470 个确认 neural tick** 确实执行了未修改的原 Rust kernel 与 NDU，并独立核对 activation、Q24 head score、动作、状态链和绝对期限输入。数学 adapter 仍是 Python research adapter，原始 neuron/NDU/Agentd 源绑定基线 `5898cd8…`。

科学主表采用持久进程中的纯内核路径。另选 96 条已存在的确认病例，经过真正的 Agentd owner、journal 与 witness，保存完整物理任务、6 维 adapter 状态、风险/事件、时钟、收益和 native checkpoint 后关闭进程再恢复：

| 工程验收 | 结果 |
|---|---:|
| 特征、activation、scores、真实动作与任务结果一致 | 96/96 |
| 真正冷恢复 | 96 |
| 冷恢复后继续运行 | 96 |
| STOP 后新 Tick 被拒绝且状态不变 | 10/10 |
| 意外验证失败 | 0 |
| 新增独立科学样本 | 0 |

这部分共 1,068 次真实 owner tick。含 replay/validation 为 1,644 次 kernel 和 1,356 次 NDU 调用。工程执行窗口另计 8.652527 CPU 秒；初始 raw shard 扫描不在该窗口内。

可直接保留的工程成果是 typed margin/risk/flow 接口、实际原生动作闭环、完整任务 checkpoint 与可独立重算的实验账本。它们支持以后更换训练目标、比较其他 cell，而无需先更换生产内核。研究 authority 保持 DENY_ALL，没有开启生产 admission。

## 风险校准与稳定性

风险是动作后、当前物理窗口内的首达概率，计算发生在事件之前。全部方法使用相同解析预测器，区别在所访问的状态与动作。因此 Brier/ECE 是访问分布下的校准描述，不能解释为某个 head 学会了更优秀的风险估计器。

完整双通道的 pooled-window Brier 为 0.016357，ECE 为 0.002427；event 为 0.016709 / 0.002461；native sparse 为 0.018322 / 0.002160。DP 为 0.010426 / 0.000251。始终停止没有风险暴露，校准指标未定义；始终维护的风险较低，但其 OOD 净效用为负，说明风险分数必须结合任务成本解释。完整 split 与 episode 等权指标均保留在 JSON 中。

确认轨迹未记录数值或执行稳定性失败。另有 8 个各 512 步的工程 case，在原始 native kernel 中完成 4,096 个主 tick 和 4,096 个参考 replay，逐项有界性与确定性检查通过。这是有界实现下的有限运行证据，不是无限时域 Lyapunov 稳定性、可微训练稳定性或生物脉冲动力学的证明。

## 计算与通信成本

有效科学运行共 864 次候选 head 拟合。已记录、互不重叠的阶段合计 **551.938007 CPU 秒**、**569.470172 wall-window 秒**，不是整个研发工作的端到端耗时。其中训练/开发 424.019355 CPU 秒，确认 rollout 95.925087 CPU 秒，序列化 19.249696 CPU 秒，余下为共享 setup。

| value_margin | 36.268 | 8.418 | 2.202 | 3.185 |

Rollout 包含环境模拟、adapter、native 处理与通信，受失败次数和终止时间影响，不是纯 neuron 算子耗时。native 进程 CPU 同样包含 JSON 协议与进程工作。各行最后一列是独立使用该方法时，覆盖全部 128 个确认 contexts、每个构建和求解一次的模型与 DP 总额归属口径；它不能再与实测共享总成本重复相加，也不能跨 arms 汇总为本次实际支出。

128 个确认 contexts 的实际共享模型构建为 3.041747 CPU 秒，DP 为 0.143614 秒。上述动态比较中的 native/generic/dense 也消费同样 DP-derived 信息，所以同样归属规划成本；固定/直接边界推理不读取 DP。

全科学运行实际 1,861,776 次 kernel、866,448 次 NDU 调用，完整 JSON 线路为 **1,675,421,482 bytes**。数值输入 payload 为 297,884,160 bytes，另列于完整协议流量。确认中的每个 neural tick 实际传输 20 个 i64 Q24 值，即 160 数值字节。这个实现没有给 event 机制假定不存在的 wire 压缩收益，也没有实现事件专用通信压缩。

**没有硬件能耗测量。** 稀疏事件、较少调用、闭式公式或较少数值字节均未被解释为能耗下降。有限门槛也没有建立 flow 的全资源成本优势。

## 数值误差诊断

对原来的 128 个 contexts 重算默认网格、细网格、扩大区域和独立 FD/CTMC 参考，未增加确认样本、重训或重跑策略。

| 数值比较 | 平均绝对初值差 | 最大绝对初值差 |
|---|---:|---:|
| 解析 128/4.8 相对默认 64/4.8 | 0.001564 | 0.012801 |
| 同 dx 的 192/7.2 相对 128/4.8 | 0.000000694 | 0.000027857 |
| 独立 FD240/7.2 相对默认 | 0.002488 | 0.036375 |

扩大上界的价值与边界影响很小，但网格/生成元离散差仍存在；默认 DP 是离散任务参考，不能当作连续时间精确真值。未在新网格重新评估学习策略，因此也没有跨网格策略优越性结论。

所有默认 DP 初值和边界均精确重现。原始记录总计 278,652 次决策状态访问，其中 `x≥3.6` 为 579 次、`x≥4.5` 为 69 次、最后 grid bin 为 36 次。它们不是连续路径最大值统计。独立 FD 有舍入量级负转移项，最小约 −7.52e−14，已原样记录。数值诊断另计 45.573553 CPU 秒，不计入原科学运行成本。

## 透明记录的两项修正

1. **确认前的期限公平性修订。** 最初 raw 输入给 `remaining / initial_horizon`，不能让所有 head 在 OOD 起点知道绝对期限。任何确认数据出现前已停止 study-001，改为共同的 `remaining / 16`，加入 3 项针对性回归验证，并发布新 source seal 后完整重训。任务、seed、候选数、输入宽度、teacher、主比较与门槛未改变。旧训练全部保留，其已完成回执下界为 129.344454 CPU 秒；未完成窗口没有完整成本回执，不隐瞒该缺口。
2. **成本负零的显式派生审计。** 原严格审计因 `completed_child_cpu_seconds` 的微小负值拒绝，这份拒绝仍在。原始账本不变。单独派生视图仅把 153 个位于 `[-1e-12,0)` 的该顶层字段改为 `0.0`；最大修正 1.77636e−15 秒，总调整 8.28222e−14 秒。其余 2,154 个输入文件字节一致，manifest 只改变成本 SHA。随后由完全未改的冻结审计代码通过全部检查。正确表述是“原始严格审计拒绝；透明成本派生视图通过”，不能把二者混为一份原始通过记录。

原始科学 manifest 为 `987423bd69b6213c3d306279e07bee91488cf0f161fafdd63bd8769e0f60ece5`；派生 manifest 为 `6c95e75fe1321a48bd16a4b246055027db6e3a78034d3db6031b4d8becf3675b`。工程验证始终绑定原 manifest，报告显式核查两者的 DERIVATION 链。既有 48 项定向验证和新增 3 项期限回归均有记录；没有在看到确认收益后改变任何模型、样本或主统计。

## 下一轮最值得做什么

建议下一轮以**减少从 DP 任务价值到真实 Hepta 动作的策略损失**为核心目标，继续使用当前内核与相同公开信息，预先注册新的独立确认样本：

- 比较当前 Q-value ridge readout 与相同 head 参数预算下的成本敏感 policy distillation，并保持相同 DP teacher 与模型选择预算。可以用 DP action regret 加权的分类/策略目标，避免只按拟合误差判断训练成功。
- 加入完整训练的普通连续/门控基线，明确总可训练参数、固定系数、输入和计算预算。当前固定 reservoir 对照不能回答对全参数 GRU/RNN 的优越性。
- 把在线规划与离线蒸馏分开：记录跨任务复用次数、边界求解成本和失配模型下的鲁棒性。当前 OOD 仍给出了真实模型参数，尚未检验未知 drift/volatility 或感知误差。
- 若新的训练方式下双通道仍显示可重复收益，再用新协议检验 flow 的额外动力学价值。不得给本轮追加 seed 直到显著。
