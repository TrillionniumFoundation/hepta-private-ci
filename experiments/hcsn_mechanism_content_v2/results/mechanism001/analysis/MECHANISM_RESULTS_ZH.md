# Hepta renewal 内容机制：正式结果与适用范围

**预注册主成功条件没有达到。** 在相同任务价值控制器下，解析核心相对 ordinary gated 核心的任务效用差 D−B 为 -0.003411 [-0.011146, +0.004376]。区间跨零；本轮不能宣称解析核心带来了稳定的任务效用增益，也没有做等价或非劣验收。

同时，解析分布确实进入了内容预测和实际 READ 时机；独立首达、复位、不应期与内容传播核验通过。局部解析求值相对同精度独立积分有明确的本次 CPU 成本优势。这两个结论与主效用结论分别成立。

## 1. 实验与计分合同

正式矩阵包含 3 个独立 ordinary 拟合 seed，每个 seed 在 matched 与隐藏不应期不匹配两种条件各运行 256 个共同世界。每种条件有 768 个 paired episodes；每 episode 有四个必答输出、最多三次 READ。主四臂之外还有三组预定干预，总计 10,752 个 arm-episodes、43,008 个输出预测。不能把这些输出数当成独立训练 seed 数。

A=ordinary gated＋lightweight；B=ordinary gated＋task-value；C=analytic＋lightweight；D=analytic＋task-value。ordinary 是 23,712 参数的前馈 gated residual 传播器，不是 SSM。解析核心没有可训练核心参数，使用已知 renewal 规律和双方共有的校准参数。双方共享观察包、内容转移矩阵与动作权限。

READ 在下一 tick 返回当前内容、物理 gap 和剩余不应期，不复位外部过程。STOP 停止后续读入和控制，但不能取消必答输出。任务效用为 `U=accuracy−0.04×READ次数`；CPU 没有被货币化。NLL 使用 `1e-12` 概率下限，出现零概率标签的消融因此报告的是裁剪 NLL。

区间由 10,000 次层级 bootstrap 得到：先重采样三个拟合 seed，再在抽中的 seed 内重采样 paired episodes。它们是三次拟合下的描述性 95% 区间。

## 4. 传播是否真实改变了内容与动作

在 matched 条件，D 与 B 的实际合法动作首次分歧发生于 172/768 个 episodes；内容概率在 768/768 个 episodes 出现差异。这两类首次分歧分别记录，没有用“内容不同”替代“动作实际不同”。

固定 analytic-lightweight 动作时序后，再比较内容传播：两组固定时序重放的实际动作差异均为零，且双方在同一可见状态下出现内容差异。

| 固定动作比较，matched | 准确率差 | NLL 差 | Brier 差 | READ 差 |
| --- | --- | --- | --- | --- |
| 解析−ordinary | +0.003255 [-0.000977, +0.007487] | -0.006646 [-0.010801, -0.002266] | -0.002280 [-0.003917, -0.000621] | +0.000000 [+0.000000, +0.000000] |
| 解析−保持最近内容 | +0.024740 [+0.012695, +0.037109] | -4.579875 [-5.103797, -3.996967] | -0.149320 [-0.175940, -0.121070] | +0.000000 [+0.000000, +0.000000] |

固定动作后，解析传播相对 ordinary 的 NLL/Brier 改善可以与观察策略变化区分；准确率差的区间仍跨零。相对保持最近内容的较弱消融，准确率提升的区间为正。后者证实事件后内容传播被任务消费，不构成对强普通核心的替代结论。保持最近内容会给错误标签赋零概率，因此其巨大 NLL 差依赖上述裁剪规则。

### Forecast-risk suppression 的含义

正常 D 与该干预在 767/768 个 episodes 的实际动作不同，首次动作差异的中位 tick 为 0。正常 D 相对该干预的准确率差为 +0.391276 [+0.366862, +0.415365]，READ 次数差为 +1.756510 [+1.720052, +1.791667]。

**tick 0 的影响包含 planner 中的假想 READ。** 干预将 READ 后的预测内容保持不变；这条规则也作用于 planner 推演的未来 READ 状态。因此即使真实世界还没有 READ，它已经能改变“现在读还是以后读”的估值。实际输出核心保持正常传播。这个结果说明指定的事件预测会改变控制行为，不是独立金融 Put 通道必要性的证明。

## 5. 384 个网格案例：完整分布、点压缩、复位和不应期

三个 cohort 各 128 个预定案例，每例 256 个独立 inverse-Gaussian 事件数与逐事件 Markov 内容标签，共 98,304 个独立标签。六种 variant 重用同一组标签；不将复用计作更多独立样本。

| Variant | 内容准确率 | 内容 NLL | 内容 Brier | 事件数 NLL | 平均 CPU/查询 |
| --- | ---: | ---: | ---: | ---: | ---: |
| analytic_full_distribution | 67.6381% | 0.742507 | 0.392215 | 0.527943 | 0.18086 ms |
| ordinary_gated | 67.2577% | 0.750802 | 0.395990 | 0.555621 | 0.40001 ms |
| matched_numerical_integral | 67.6381% | 0.742507 | 0.392215 | 0.527943 | 0.61650 ms |
| mean_count_point_collapse | 65.6647% | 2.213504 | 0.439402 | 6.619089 | 0.19029 ms |
| absorbing_no_repeat | 66.9912% | 2.592246 | 0.425368 | 5.434889 | 0.18496 ms |
| future_refractory_removed | 67.3828% | 0.749723 | 0.394199 | 0.630913 | 0.18428 ms |

点压缩先取得完整分布的事件数均值，再把它舍入成一个事件数，所以它甚至保留了正确模型给出的均值；其费用也包含这一步完整分布计算。它是信息压缩消融，不是成本更低的成熟普通网络。no-repeat 与 no-future-refractory 则是在同一真实世界上故意删去相应模型机制。

点压缩给实际内容标签赋零概率的比例为 5.8228%；no-repeat 为 7.3914%，所以对应 NLL 为裁剪评分。ordinary gated 是这里的强同信息对照，其内容 NLL 与完整解析分布的差远小于点压缩消融。

每个 cohort 还包含同均值、同方差、同校准参数但不同初态分布的两例。三组解析内容分布 L1 差分别为 0.016837, 0.039248, 0.038175。这说明该任务的前两矩并不充分，不意味着一般神经向量状态不能编码分布。

## 6. 同精度局部核成本

384/384 案例通过预定 `1e-8` 概率误差门槛；解析与独立密度积分的最大绝对差为 `4.404255e-13`。包含内容混合计算的平均 CPU 时间分别为 0.18086 ms 与 0.61650 ms，积分/解析比为 **3.409×**；wall 比为 3.403×。

解析侧平均 9.24 个 CDF 项；数值侧平均 476.33 次密度函数评估。这是不同类型的局部运算，不能称作减少了相同比例的 network updates。随机 variant 次序、公共 warmup 与重复次数均落盘。

这是对同一指定核、同精度输出的可支持成本结论。ordinary 的预测不完全相同，而主 D−B 区间跨零也不等于已通过非劣／等价验收，因此不能升级成“同质量全网络更快”的结论。

## 8. 本轮已回答与仍未回答的问题

- 已回答：重复首达、reset/refractory 与线性 Markov 内容传播的局部合同可实现，独立核验成立；传播会改变真实内容预测和合法动作。
- 已回答：预定任务价值控制器相对本轮轻量控制有收益；这种收益不能全部归给解析核心。
- 已回答：同精度局部解析核在本次 CPU 实现中比独立积分便宜；完整模型 worker 成本有一次性拟合账和可复核收据。
- 未确立：解析核心在同一任务价值控制器下的稳定效用增益、等价质量下的全网络成本优势，以及对任意普通门控／SSM 的优势。
- 未实现于该机制实验：任务最优自由边界学习、物理参数联合学习、原 He–Xiong 完整债股系统、自然多模态 encoder 改进及大模型规模优势。
