# V2：固定模型与阈值的新独立校准功效研究

V2 使用原 R20 的同一拟合模型和 OOD 截断，没有重新训练。`.95` 是在检查原失败校准后选择并披露的固定阈值；因此它不是未经选择的原 R20 结果。新源码、固定样本、模型身份与阈值在新世界前发布；原 54 边界合同继续记为失败，不与 V2 合并。原确认种子 `20011873` 保持未打开。

新校准种子为 `20021873`，固定混合总体 4,096、reverse 8,192、lag-two 32,768 个独立生成器，每个一个查询，共 **45,056 个新世界、135,168 个固定 `.95` 预测**。三个模型 × 三个校准层 × 全部／分数两种风险，共 **18 个 CP 边界**，delta=`.05/18`；每层仍须至少 20 个分数答案，且两种上界均不超过 `.10`。全部固定样本完成，没有提前成功停止、追加样本或更改阈值。

## 执行故障、修复和费用

第一次 V2 尝试在创建输出目录时因 `Errno28` 失败，尚未启动任何 stratum worker，也未产生任何 V2 世界；旧 outer 随后读取不存在的 worker 回执又失败。其精确 CPU／墙钟没有成功保存，保持 `null`，没有计为零。旧五个源码／协议文件及冻结、发布回执保存在 `launch_failure_v1`。

只针对执行边界修复了普通启动／I/O 异常：等待并回收已经启动的已知子进程；outer 在读取可选 worker 回执前取得 wait4 资源值；先将回执打印到标准输出，再尝试写磁盘。缺失 worker 回执记为未知和失败，不凭空补零。该修复重新发布、回读于 `62a621d83112212cb89f76474f5ea5f7a55fa9c6`，冻结 SHA 为 `1361aa3e25c5215723b7ff9acfd692d31e022bc0291c3250e6c2f1b4909114cc`，之后才重新执行新校准。模型、样本数、阈值和种子未变；没有统计样本被提前消费。该执行保护不声称覆盖协调进程 SIGKILL、任意 orphan 或完整断电。

实际成功运行 outer wait4 为 **484.824056 CPU 秒、638.331667 墙钟秒**，其中三个 worker 的 **483.825593 CPU 秒已包含一次**，不可重复相加。记录单进程最大 RSS 为 96,740 KiB，同时进程族峰值 RSS 未测定，保持 `null`。加上原 R20 准备，已知非重叠 CPU 下界为 **598.843511 秒**，另有首次启动失败的未知费用，以及开发／独立审计等未纳入完整包络的成本。没有完整项目生命周期、逐模型在线采用或 GPU／设备能量主张。

## 独立检查与下一阶段边界

独立流式审核核对全部 **45,056 个世界、135,168 个 owner 预测、176 个归档哈希、72 个计数和 18 个 CP 上界**，以不导入候选或 SciPy 风险函数的有限二项 log-CDF 二分参照重算，上界最大差 **4.39×10⁻¹⁵**。raw alias、mask、目标、实际 READ、费用、proper score 与真实目标支持均通过检查。结果与三条资格状态一致，见 `V2_INDEPENDENT_CALIBRATION_CHECK.json`。

只有在 root 再次冻结、发布并回读本次校准及附加覆盖规则后，才可打开新种子 `20031873` 的正式确认。其五个面板与固定样本功效、四世界生成器簇、五条政策、4,096 次分批簇重采样均在新校准前预先声明。正式确认结果不是本校准表；不得用本表替代正式泛化结果。未训练的 lag-two +2 结构变化仍独立验收，不能借用已知 family 校准。

`ADOPTION_COVERAGE.json` 的 3.125%=32/1024 是参考 R19 固定样本最低数量而新声明的采用覆盖子门，不是给 R19 追认一个通用率合同。它与 V2 原登记的数量／风险研究门分别显示，不改变后者。有限普通参照不提供解析核心 D−B、真实 AV、任意未知规律、完整模型采用或生产激活依据。
