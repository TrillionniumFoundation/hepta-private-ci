# R20 内容线：已知规律的有限可靠性修复成立，跨规律与采用资格仍未全部通过

本轮实现了学习一／二阶内容上下文和符号轨道的普通参照，并完成新的独立固定样本确认。已训练 reverse 与 lag-two 的新参数世界通过登记的风险／数量研究门；一个未训练的 lag-two +2 结构也通过。**未训练符号共轭面板失败；已知 lag-two 的可靠分数回答率只有 1.657%，没有通过另行冻结的 3.125% 采用覆盖子门。全部模型采用和生产激活仍为 false。**

这是一组有限六次 WRITE、四地址／四值、两至四个缺失 token 的普通概率参照；完整公开前缀、真实 alias 映射和最多一个付费 READ 对所有模型相同。它不建立解析神经核心 D−B、真实 AV、开放域绑定、独立多次训练或完整全模态模型的结论。

## 新确认的实际结果

原 R20 使用三个模型／三个阈值／三个校准层／两种风险的54边界合同，全部失败，原确认种子20011873保持未打开。后续 V2 没有重训或重拟合 OOD，而是在披露旧校准选定固定.95后，以新种子20021873执行45,056个预定独立校准世界、18个CP边界。只有 context 通过全部校准层；两个一阶模型因 lag-two 未通过。旧54门继续记为失败，没有合并补样。见 ORIGINAL_R20_REPORT_ZH.md、V2_CALIBRATION_REPORT_ZH.md。

在新校准、协议和审核器发布回读后，正式种子20031873完成 **86,016个新世界、21,504个独立生成器簇、430,080次政策执行**。每生成器四个相关世界，三个固定.95模型及两条保守参考政策共享同一世界。每面板4,096次整簇bootstrap，按64次一批、单坐标向量收缩执行，未物化大三维采样数组。全部预定样本完成，没有因中途结果改样本、阈值或政策。

因此4/5个 context 面板通过研究门，3/5通过覆盖／风险子门；五面板合取不通过。符号共轭面板153个分数回答中错17个，必须保留失败。单个新结构成功不外推为任意未知规律可靠性。区间是条件于一次冻结拟合的名义单面板经验bootstrap，不冒称精确有限样本或多面板同时95%保证。
