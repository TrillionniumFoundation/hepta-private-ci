# R22 有限内容模型与保守单次 READ

本轮修正普通内容模型与控制器。所有 R20 已看过的结果及五类生成律均属于开发资料；新参数世界只能检验这个明确有限的范围，不构成未知生成器、开放域视听绑定或解析核心贡献的证据。任意未知律可在同一公开前缀上分歧，因此有限模型集合不能提供任意律下的答案保证。

拟合仅使用已有的 48 组、每组 128 条完整公开训练流。新模型独立估计初始二元分布，并使用 Dirichlet 行后验预测积分，包含同质一阶、自由初始对的一阶、隔步二阶和完整二阶四个分量。组内留出选择分量权重；按生成器分组的交叉验证选择原始律与符号轨道律的共同混合系数。强一阶参照采用同样的初始对、积分、选择、轨道和控制方法。R20 的符号重标记门槛失败保留，但不能由有限样本差异推断总体等变性缺陷；独立检查验证了旧模型符号等变性。

七个科学行均使用开发资料事先选定的阈值 0.9。稳健行在两个固定成员下承诺同一个收据后决策规则，先分别计算每个成员下的总期望收益，再取最小值。此下包络只作为决策置信度；Brier 与对数评分使用明确指定的第一个、归一化后验预测分布。每项策略最多单独取得一次真实索引收据，单独支付费用。模型推断可共享公开前缀计算，收据与费用不跨策略复用。

校准固定 94,208 个独立生成器、每个一个世界：混合 4,096；反向 8,192；隔步 32,768；重标记隔步 32,768；跳二隔步 16,384。困难隔步分层使用较大固定样本以降低罕见回答计数造成的区间宽度，重标记层不再使用旧版的小样本规模。这个规模不能保证通过风险门。七个策略、五层、整体和分数回答两种风险合计 70 个一侧 Clopper–Pearson 上界，共享误差预算 0.05。每个策略必须在全部五层同时达到风险上界不超过 10%、至少 32 个分数回答且分数回答率至少 3.125%，无无效样本或支持丢失。主策略依次选择稳健上下文、上下文混合、上下文轨道中的第一个合格项；没有合格项则不打开新确认世界。不存在按新校准结果修补阈值、模型或样本数的步骤。

若有合格主策略，确认阶段再使用不同种子和参数的固定 94,208 个世界，按每生成器四个世界成簇；五层规模与校准相同。四个辅助可行参照在校准时自身合格则采用 0.9，否则采用事先固定的近点质量阈值。它们执行实际动作并支付自己的费用，不能借用其他策略的可靠性资格，零分数回答不能通过覆盖门。

确认逐层保留风险、覆盖、Brier 和付费效用独立门槛。Brier 必须相对于三个强科学参照同时达到配对生成器 bootstrap 改善区间下界不小于零；相对于四个可行策略的付费效用改善区间下界必须大于零。若强基线 Brier 更好，失败照实保留。4,096 次重采样按每批 64 次保存全部统计量，不构造三维巨大数组；区间是预先规定的逐面板经验区间，不宣称跨所有面板的精确联合置信。

新校准前先发布源代码、模型、完整传递依赖与独立复核程序；确认前再发布校准结果、主策略和控制策略。所有失败开发拟合与实际成本保留，重复存档不重复计算同一执行。输出上限 150 MB，最多四个固定 CPU 工作进程；普通启动、等待或磁盘异常必须保留已启动进程的成本并使总体资格失败，不宣称任意 SIGKILL 的成本闭合。完整全模态采用、解析核心归因、开放域任务、生产启用和四阶段全部闭合的结论始终为 false。
