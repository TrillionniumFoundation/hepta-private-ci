# R22 前置审阅：R20 的失败不等于符号等变实现失效

本审阅只读取既有 R20 源码、模型和正式结果；没有调用新的 world generator，也没有改变 R20 文件。R20 数据现在作为开发证据，下面的重新采样不能被当成新的确认。

## 已有等变性与总体运输

R20 的 `context_orbit` 和 `orbit_first_order` 都对24个值标签置换完整平均。在全部4,096个六值序列、24种置换及same/distinct两种键通道上，实际保存表的最大绝对差均为8.67e−19；最大相对差分别为6.38e−16、7.16e−16。未加轨道的 `first_order` 按设计不满足这一性质。

在理想声明总体中，pi~Dirichlet(.7,.7,.7,.7) 对标签置换不变；rho/q、键、擦除、distractor、查询和费用与值标签独立。对固定共轭sigma，lag-two的循环C变成sigma*C*sigma^-1，同时pi随标签推前。若预测及付费READ政策等变，则原lag-two与其共轭总体的风险、覆盖和效用相同。随机混合共轭（排除原循环）仍属于同一等变结构轨道，不是新循环类型。lag-two +2 的两个二循环则不与四循环共轭。

因此R20共轭面板的失败应保留，但不能直接称为发现了符号等变性bug或证明总体运输失效。置信度>=.95时接受标签唯一，通常的argmax标签平局不影响接受回答；仍需保留有限精度／阈值边界的操作核查。

从既有簇统计读取：lag-two为543个分数回答／35个错误，8,192个独立生成器；共轭面板153／17，2,048个生成器。错误分别发生在35／17个不同生成器中，每簇最多一个错误。仅作开发诊断的新独立簇bootstrap得到（共轭−原lag-two）风险差95%区间约[−0.00656,0.10359]，跨零。它不覆盖或推翻原登记失败门；低分数覆盖和小错误计数仍是实质验收限制。

## 有原则的模型修复方向

1. **共同修复初始两值头。** R20二阶模型以汇总全部五次转移得到的T1(x0,x1)开始。真实lag-two的x1从pi独立抽取，后续两条子链的边际又会随时间移动；汇总T1一般不是初始条件分布。使用共同的P(x0,x1)头，并令lag1／skip2／full2候选都从t=2开始，能避免把头修复误归因于二阶上下文。
2. **使用正确的行参数后验预测。** 固定训练后的Dirichlet行参数，积分同一测试序列内重复使用的行，而非把参数均值逐次相乘。六值序列只有四次头后转移，可精确编译全部4,096个概率；不需要采样或epsilon概率地板。
3. **加入有结构的skip2候选。** 真lag-two不依赖立即前一符号。skip2只需4行，full2需16行；后者在每组128条公开流下可能因不必要的自由度而高方差。让公开组内验证选择lag1／skip2／full2预测混合，强一阶参考必须共享修复后的头和同样的行不确定性处理。
4. **区分符号先验与上下文效应。** 完整S4平均把只含字面+1/−1方向的训练结构先验扩展到所有共轭四循环，因此相对未加轨道的参考可能损失已知方向信息。原context与orbit-first二者已经都加轨道，故它们之间reverse的Brier退化不能仅归因于轨道；初始化、参数方差和混合证据都是候选原因。raw/orbit的全局混合必须在公开验证上拟合，随后冻结，并以first/context×orbit/mixture四格分离两种改动。

这些是普通有限内容模型／控制的修复方向，不提供解析神经核心归因、任意未知规律或开放域跨模态结论。一次READ的不可识别性反例仍有效。任何扩大READ预算的研究都必须给全部参考相同机会、实际逐次扣费，且分开报告初始同信息概率质量与购买信息后的收益；更多READ造成的近点质量回答不自动修复分数回答覆盖。

## 可证伪条件

- 各完整六值预测表必须严格非负、总质量为1；带键耦合的编译表应满足4*sum(same)+12*sum(distinct)=1。
- 分组Dirichlet矩与逐步Polya预测应在全部4,096序列上吻合；不能添加多项式系数。
- 共轭后模型／READ行为若在远离阈值平局处变化，则应先修复操作等变性，不能把差异当作新能力。
- reverse的同信息Brier与实际效用要分别验收，不能用收益改善掩盖概率质量退化。
- 采用门须同时报告分数回答绝对数与占全部尝试的比例；新确认保持独立命名空间、原风险标准和完整成本。
