# Round 3：数学、事件、信息与验收合同

本轮建立在 Round 2 的已发布结果之上，旧源码、旧结果和原验收结论保持为研究基线。
研究对象是条件分布预测、整数事件通信及后续动作选择。它不是交易系统，也不把二元期权价格当作未经说明的概率。

## 1. 状态、条件信息与时间

核心状态满足注册的线性扩散模型：

\[
dX_t=b\,dt+\sqrt q\,dW_t,\qquad X_0\sim N(0,1).
\]

公开历史为实际取得的观察值、物理时间、观察方差、是否存在观察槽以及观察是否缺失。
数据中的未来潜在观察只有执行对应动作后才可取得。模型预测不接收终点真值、隐藏漂移标识或未来动作的观察值。
明确标记的 oracle 是已知参数线性参照，在 Student-t 条件下也不冒充非线性 Bayes 最优解。

给定历史 \(\mathcal F_t\)，滤波状态为 \((m_t,v_t)\)。核心传播为
\(m_{t+h}=m_t+bh,\ v_{t+h}=v_t+qh\)。这里的 \(h\) 是物理预测期限，不是通信包序号。
缺失观察只推进时间，不添加似然；同一时刻实际取得的两个传感器读数分别更新一次。

## 2. 三个终点事件与共享 call/put 核

对阈值 \(l\le u\)，输出顺序固定为 put、neutral、call：

\[
p_- = P(X_{t+h}\le l\mid\mathcal F_t),\quad
p_0 = P(l<X_{t+h}\le u\mid\mathcal F_t),\quad
p_+ = P(X_{t+h}>u\mid\mathcal F_t).
\]

非退化高斯下，令 \(z_a=(a-m)/\sqrt v\)，分别用稳定的 CDF、区间质量和尾概率计算
\((\Phi(z_l),\Phi(z_u)-\Phi(z_l),\Phi(-z_u))\)。实现对尾部和窄区间使用稳定表达式，不能以浮点 `1-CDF` 代替所有尾概率。
同阈值 call/put 互补；不同阈值必须保留中间质量。零方差按上述不等号处理阈值相等事件。
call 和 put 是同一条件分布上的两个事件方向，不需要训练两套相互矛盾的独立概率定律。

欧式现金二元期权在风险中性测度下还带有贴现因子；本实验在任务条件定律下直接预测事件概率，不引入利率贴现。
在对数正态金融模型中可通过对数状态转换得到相应形式；本轮实测状态是上述高斯扩散，而非声称所有隐状态服从 Black–Scholes。

| 名称 | 精确定义 | 本轮用途 |
| --- | --- | --- |
| 终点 put/call | 指定期限的终点阈值事件 | 概率预测和校准 |
| 首达 | 整段路径曾越过阈值 | 独立解析验证；不作为终点标签 |
| 中性 | 终点落在两个阈值之间 | 第三个互斥事件 |
| 静默 | 某通信通道没有非零计数 | 编码状态；不等于中性 |
| 缺失观察 | 槽存在但传感器值未取得 | 只传播，不加似然 |
| 正／负脉冲 | 均值或对数方差状态的有符号整数增量 | 通信；不表示 call/put 的真实结果 |
| 运行时置信与权限 | 原 Hepta 返回的独立控制字段 | 保持原研究权限，不能用事件概率替换 |

## 3. 事件状态、复位与动作证书

新编码器把训练所得滤波器的均值和对数方差增量转换为有符号整数计数。
每包携带版本、配置摘要、序号、时间、观察类型与精度；解码器只接受这些字节。
残差只存于编码器。预测与动作计算不读取连续后验或编码器残差。
误差反馈采用减去已发送增量的复位；`increment_only` 对照丢弃残差，并明确不具备同样的单步量化格保证。
动态精度变化必须显式重新表示整数状态，不能把分辨率不同的单位脉冲当成同一种成本。

动作值使用已注册的“预期终点平方误差＋实际任务费用”形式。
每个合法动作的值随当前方差单调，故可在解码方差区间两端得到值区间。
只有某动作的最坏端点严格小于其他动作的最好端点并覆盖数值余量时，才标记 `certified`。
若不能分离，则增加方差通信精度；达到最大精度仍不能分离时保留未认证记录。
证书保证在量化格内与同一拟合连续模型的动作一致，不保证环境真实最优。

事件计数、包数、序列化字节、精度重标定次数和端到端延迟分别记录。
这些数值不能自动换算成能耗、硬件吞吐或金钱。直接量化采用同一表示，作为统计等价的强对照。

## 4. 训练目标与数据隔离

五个新的训练种子固定为 607、701、809、907、1009。
基础模型每种子用 512 条训练轨迹、256 条开发轨迹；原 sparse 特征经原二进制实际执行，并拟合读出参数。
解析滤波器训练目标是多个阶段、多个期限上的复合条件高斯 NLL；这些测量共享轨迹，不当成独立样本。
事件编码器在 21 个预定配置中用开发集实际后续效用、NLL 和包字节选型，保留所有候选分数及回退情形。
这里没有声称通过硬脉冲的端到端离散梯度训练。

所有数据生成种子、选型规则、模型、12 个保留窗口的全部检查点和可执行源码在新的确认数据生成前冻结。
上一轮确认结果用于指出研究问题，不作为本轮拟合、开发集选择或确认轨迹。
新主实验固定 5 个种子 × 3 个定律 × 每组 384 条轨迹。
所有组完成后才形成总体结论，失败、等价和不显著结果全部保留。

## 5. 后续动作、交付与评分边界

主任务具有等待、修复、停止动作，观察带噪、状态隐藏、动作费用公开。
策略只能用已取得并回读的信息更新状态。每个初次／最终预测都实际写入数值文本及无损数值 PNG，再回读；数值 PNG 是传输工件，不是自然图像质量任务。
每个控制回合先完成最终交付，随后才读取该回合终点目标并计算
\(U=1-(\widehat X-X)^2-\text{paid costs}\)。
全量离线审计重新解码 PNG、重算成本及得分、重放冻结模型和原 sparse 二进制。
源代码中的读取顺序及文件时间记录不等于操作系统级私有目标内存隔离证明。

新的反馈任务额外提供一次付费等待观察，以解析期望净收益作为强基线。
运行时阈值概率的具体预测事件、修复幅度和等待价值在 `FEEDBACK_RUNTIME.md` 单独声明。
概率预测好坏、动作效用和记忆干预分别评估，不能把不同含义的概率混为一个神经元“置信度”。

## 6. 保留与校准的两种合同

原逐点保护头保留 \(\sup_x(\mathrm{NLL}_{new}-\mathrm{NLL}_{anchor})\le0.02\) 的明确适用域。
量化参数和最终类别质量是两个不同层次，保护不能从一个层次无条件传给另一个层次。
本轮新增经验校准头：六个训练参数、公开观察似然路由、开发集上 55 个强度／方差组合。
其旧开发集 NLL 差加 1.645 倍配对标准误的筛选仅是选择规则，不是总体置信保证或逐点数学保护。

新校准头为不同期限学习边际方差因子，属于边际预测校准层，不声称组成新的相容扩散半群。
它的 Q24 参数四舍五入版本不自动获得原保护头的性质，也不能继承另一个运行时模型的效用结果。
所有保留比较相对原始锚点进行；12 个窗口的结果不外推为无限任务或多年知识保留。

## 7. 预注册验收

主效用比较仍是 analytic 对 history、analytic 对 original sparse、新 event 对 analytic。
使用 4,000 次配对两层 bootstrap：先重采样训练种子，再重采样整条轨迹，三个主比较按 0.05/3 校正。
原优效门槛为区间下界超过 +0.01 且每种子的平均差为正。
事件非劣单列为同一校正区间下界大于 −0.01 且每种子平均差大于 −0.01；非劣通过不等于优效通过。

旧分布 NLL 允许增幅仍为 0.02，新漂移窗口 NLL 改善门槛为 0.005，并要求改善差的区间上界为负。
经验校准另列 ECE ≤0.04 与 95% 区间覆盖率落在 [0.92,0.98]，不以改名替代旧保留门槛。
Student-t(4) 平方损失缺乏有限四阶矩，相应 bootstrap 区间仅作描述，不主张总体覆盖保证。
同一轨迹的多个阶段、预测期限和模型输出均不扩大独立样本数。

## 8. 与已有理论的关系

[Deep Q-Learning on Hölder Spaces](https://arxiv.org/abs/2606.16846) 研究扩散 Bellman 目标的正则性与逼近复杂度。
解析事件核提供一个可精确计算并验证的扩散传播实例；该论文没有赋予这里的训练、脉冲复位或实用 DQN 更新通用收敛定理。
[Sigma Delta Quantized Networks](https://arxiv.org/abs/1611.02024) 已研究量化激活变化的通信。
因此，残差计数本身不作全新函数类声明；本轮单独检验动作证书、成本和可回放运行时是否带来可测收益。
