# Round 3：付费反馈、后续动作与实际运行时合同

本模块补充主任务的脉冲研究：旧轮的反馈实验只有修复／停止，本轮加入一次实际付费观测；旧轮的静默／复位对照混有修复幅度表示差异，本轮固定这一表示；旧轮的运行时验证与效用实验使用不同产物，本轮由同一 `FeedbackOwner` 的原生 Q24 输出驱动动作和最终交付。此前的证据和门槛保留。

## 1. 状态、信息与动作

每条轨迹有初始交付 \(A\sim N(0,1)\)、隐藏剩余误差 \(E\sim N(0,0.64)\)、目标 \(Y=A+E\)。误差在这段短任务内固定。第一传感器给出 \(S_1=Y+\eta_1\)，其公开方差从 \(\{0.04,0.36,1.44\}\) 抽取。第二传感器的公开方差从 \(\{0.04,0.16,0.64\}\) 抽取，噪声条件独立。修复成本为 \(c\in\{0.03,0.12,0.48\}\)，等待成本为 \(w\in\{0.01,0.04,0.12\}\)。成本和可用传感器方差在首次选择前实际写入 JSON 再回读。

初始输出和反馈残差 \(R_j=S_j-A\) 均以可逆数值 text/PNG 工件实际交付、回读。首次可选 stop、repair、wait。wait 扣除 \(w\) 后才调用第二观测获取函数，并追加残差与传感器方差；之后仅可 stop 或 repair。repair 扣除 \(c\)，交付 \(A+a\)；stop 保留 \(A\)。最终效用是

\[
U=1-(\widehat Y-Y)^2-c\mathbf1_{\rm repair}-w\mathbf1_{\rm wait}.
\]

这里的成本是任务实际扣除的效用单位。原生请求数、tick、CPU、墙钟、文件和字节另行记录，不能与效用单位相加，更不能称为美元或硬件能耗。

确认策略在独立 Python 子进程内只加载严格的 target-free `PUBLIC.npz`。评分进程在全部最终交付回读结束后计算目标损失。此结构限制正常代码路径的目标可见性；没有宣称同 UID 进程或文件系统之间存在敌对访问隔离。第二观测的取得次序由执行路径与回读收据验收，也没有宣称操作系统强制遮蔽尚未购买的传感器文件。

## 2. 概率到底预测什么

训练数据拟合误差方差 \(\alpha\) 与传感器尺度 \(s\)，均为正的监督 Gaussian 最大似然估计。给定已经获得的残差，后验为

\[
v=\left(\alpha^{-1}+\sum_j(s r_j)^{-1}\right)^{-1},\qquad
m=v\sum_j R_j/(s r_j).
\]

`gaussian` 使用该精度公式，`probit` 用独立稠密联合协方差条件化。二者具有相同信息和参数，属于表示等价对照。

typed 概率头输出同一终点误差分布在 \((-\sqrt c,\sqrt c]\) 周围的 put／区间／call 概率。原生路径的均值、方差及两个阈值都经过原生 Q24 输入量化，因此校准标签按**实际头的量化阈值**定义。终点尾部概率不等于某个给定修复动作的正收益概率，也不等于首达、缺失、通信静默或运行时授权置信度。

call 和 put 共享同一后验与解析核。三个输出构成一个分布。整数正负脉冲表示均值和 log 方差的通信增量，并不表示 call／put 事件已经发生。

## 3. 等待价值和修复价值

修复幅度 \(a=Q_{24}(m)\)，故期望修复收益为 \(2am-a^2-c\)。第二观测后、尚未见到其数值前，未来后验均值满足

\[
M'\mid\mathcal F\sim N\!\left(m,\frac{v^2}{v+s r_2}\right).
\]

直接参考策略的等待价值为 \(\mathbb E[(M'^2-c)_+] - w\)。两个 Gaussian 尾部的二阶矩给出解析式，独立 `scipy.integrate.quad` 检查涵盖 160 个事前固定案例；后验另与联合协方差求解比较。

此等待值使用未来连续最优修复近似，末端 Q24 修复量的舍入损失至多 \(1/(4\cdot2^{48})\)（在给定精确后验下）。实际 learned readout 的后续动作可能偏离该参考，所以其等待值明确属于共用的 plug-in 规划值，不能声称对 learned policy 是精确 Bellman Q。最终收益始终按实际后续选择和实际交付评分。

## 4. 可训练结构和对照

| arm | 决策表示 | 修复幅度来源 |
|---|---|---|
| gaussian | 精度公式后验、解析期望收益 | 精确后验均值的 Q24 舍入 |
| probit | 稠密 Gaussian 条件化、解析期望收益 | 同上 |
| event | 有残差的整数增量接收器、实际 typed Q24 后验、解析期望收益 | 实际原生 Q24 均值 |
| quantized | 同网格直接量化接收器、同实际 typed 后验 | 同上 |
| numeric | 标准化公开残差／方差／成本驱动原 sparse 的三个通道 | 同一 event 接收器和 typed Q24 均值 |
| analytic | 原生终点 put／区间／call 与成本驱动原 sparse 三通道 | 同上 |
| history | 相同公开充分信息的 63 维多项式／RBF | 同上 |
| zero | sparse 三通道输入置零 | 同上 |
| reset | 每通道第二个 tick 前清除 sparse 状态 | 同上 |

每个 sparse 通道运行原实现两个 tick，第二个 tick 没有新输入；读出 activation/eligibility 共 21 维，三个通道共 63 维。五个 learned arms 各自拟合 action-value MSE，三个 L2 值各运行 600 次真实梯度更新，再在开发集比较五个动作值偏置，共 15 个候选。保留每个候选权重、梯度、训练损失、开发集完整两阶段效用和实际参数变化。历史对照具有相同维数和选型机会。

zero/reset 只干预 sparse 决策表示；后验、修复幅度和等待规划通道仍然保留。各对照重新拟合自己的读出，所以这是有相同拟合预算的路径消融，并非固定所有其它参数的单次因果干预。它不代表删除了整个系统的所有反馈或记忆。

原 sparse 核没有重新训练。学习发生在方差参数和决策读出。事件编码的两个量化步长均事前固定为 \(2^{-12}\)，不进行硬脉冲反向传播。event 与同网格 quantized 的等价性必须公开报告。

## 5. 实际运行时、恢复和证据

`FeedbackOwner` 保存版本化计数编码器、独立解码器、序号、公开历史摘要、原生 checkpoint 和独立交付见证。策略读取重新打开的 decoder，再调用原生 typed 头；任何 encoder residual 都不直接输入策略。每个逻辑更新可以产生多个单位事件，单位事件数、包数、JSON 包字节分别计算。

每个 owner 最多 16 次更新，均值绝对值和方差不超过 8，方差严格正。确认常规轨迹至多两次更新；qualification 的重复、恢复与传播调用有独立注册用途。32 条新历史／seed、5 个 seed 共 160 条独立历史全部实际执行，每条包括两个条件状态。每 seed 两个新 Python 进程验证重复请求零新 tick、继续执行一个新 tick。还检查旧 CAS、变更重复、状态损坏、回滚、pending 后中断、native 已提交后的中断、丢失确认回执。

原生和 Python 见证不是跨 owner 原子事务；部分提交状态保留并停止推进。此反馈 profile **没有**旧知识密度保护证书，不继承另一保留 profile 的约束。原生仍然 confidence=0、abstain、DENY_ALL，不转移 Agentd 生产权限。

全量审计逐一打开 text/PNG/JSON，重建计数，调用原 native typed 与每个 sparse tick 重放，比较实际动作、成本、最终分数和持久状态见证。所有原始工件在逐成员 hash 校验后归档；归档完成后才删除本轮临时原始副本。

## 6. 预注册统计

训练 seeds 为 607、701、809、907、1009；各 512 train、256 development、384 confirmation。数据种子为 \(80{,}000{,}000+100s+\{1,2,3\}\)。runtime qualification 使用 \(90{,}000{,}000+s\)，与训练和效用确认数据分离。

主反馈对比为 event−gaussian、analytic−numeric、analytic−gaussian，使用相同的 seed／整轨迹两层配对 bootstrap（4000 次），三重比较 family alpha=.05。原 superiority 判据仍为调整后区间下端 >.01 且各 seed 均值 >0。event 的 .01 非劣诊断另列，要求下端 >−.01 且每个 seed 均值 >−.01；非劣通过不能改写为 superiority 通过。另列 analytic−history/zero/reset、event−quantized、gaussian−probit 的描述性比较。

校准度量使用首次条件状态的实际交付头，报告逐类 ECE、top-label ECE、Brier、95% Gaussian 覆盖和未裁剪事件 NLL；如真实事件被 Q24 概率赋零，报告次数并把均值记为 null（其理论值为正无穷），不能通过静默裁剪宣称有限损失。五个训练 seed 不展开为数千个独立训练重复。

本轮开发阶段曾因共享磁盘 ENOSPC 中断 seed701 的第一次训练。失败目录完整保存、逐成员校验归档，随后用同一事前种子重新运行；确认数据当时尚未生成。操作故障不改变科学门槛、种子或选型结果。
