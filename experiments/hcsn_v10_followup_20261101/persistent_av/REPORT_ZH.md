# 持续 AV 有限路径过滤器：模型、对照与验收边界

本轮实现一个**新登记的有限隐状态观察模型**，使概率状态真正跨每次已接受 A/V 观察传播与条件化。它不是原 He–Xiong 金融自由边界或 Brownian 首达／复位神经网络；原 v6 前端、独立新录制与完整解析神经核心准入不因本轮有限模型而闭合。

## 明确的拟合生成律

潜状态是训练数据新源窗口内容的 K-means 簇，K 只尝试 2 或 4。音频／视频分别使用按状态拟合的对角 Gaussian emission。转移生成元 Q 来自训练状态的平滑 off-diagonal 计数／停留时间率；这是明确的矩拟合方法，不是完整隐状态最大似然估计。初始混合使用训练首窗口状态占有率作为初始时刻先验，是模型假设。方差收缩只尝试 0.25 或 1.0；全部四个候选及验证似然保存，选择只使用历史验证数据。

每个前缀只条件化其新源窗的新增行均值：首窗包含源时间 0，后续为 `(prefix−1,prefix]`。重复累计前缀不重复计入旧观察。没有新行的窗口按无信息处理；未拟合缺失机制。隐藏簇不是情绪标签，过滤后验也不冒称实际任务正确概率或经过校准的现实不确定性。

实际状态保留 `p(z0,…,zt)`。全局源时间增加时，使用 `exp(Q)` 扩展末端路径；第二模态的同源窗口增加零时间，仍按其真实源窗口条件化对应路径坐标。因此 A3 后接晚到 V1 时更新的是 z1，不把 V1 错套到当前 z3。最多三个源秒、K≤4，路径分布最多 256 个质量项；没有把保留完整过去相关性的代价隐藏成 32 维神经态。

## 同律参照与普通模型

同 Q、同 emission、同先验与同读出权重同时运行普通 HMM 的独立 Poisson uniformization 传播。它与矩阵指数在该有限生成律下具有相同数学目标；若两者相同，只支持实现一致性，不能据此宣称矩阵指数或“解析”机制独有收益。

所有模型获得相同完整已接受六槽观察历史。每次 58 个标量包括 v9 公开的 41 维内容／前缀／源增量特征，以及新增源窗的 16 维均值和一个非空标志。新增信息同样提供给普通模型，不允许过滤器独占更详细观察。六槽之外还有六个存在 mask；未来槽为零。

新拟合四种模型：完整历史 MLP、持续 GRU、持续 SSM、历史＋路径分布 MLP。普通 recurrent 模型也可直接读取完整历史，以避免被压缩状态的信息损失人为削弱。读出参数量约四万；宽度预先固定，不进行无限架构扫描或追加调优。每个任务／种子／家族执行 100 次完整 AdamW 更新，目标均为相同冻结内容头在 16 个终点的实际正确性，最低历史验证 BCE 选权重，最后与选定权重全部保留。两个训练种子、两个任务，共 16 个 reader fit。

未来动作价值仍由共同目标的监督读出器估计，不是对金融任务 PDE 的闭式求解；离散簇、Q 的矩拟合及验证选择也不是端到端解析参数梯度训练。实际控制沿用相同的强制首音频、固定全采集／共同任务价值控制，保留普通与过滤器的完整四格描述。

## 执行与复现

正式准备与评估分开：`candidate prepare` 完成拟合、数据身份、所有候选及选定权重冻结；评估前先完成独立数值核查，再使用 **`root_precheck evaluate` 包装入口**。该入口在实际评估前后核验全部源、LAW、数据、adapter、输入及 reader 的字节封印。底层 `candidate evaluate` 只检查 precheck 状态，不应单独作为可复核正式评估入口。所有正式阶段由 v8 外层 worker CPU 计量，不将内部拟合定时重复相加。

```bash
PYTHONPATH=/tmp/hcsn-torch-runtime "$CODEX_PRIMARY_RUNTIME_PYTHON" \
  -m experiments.hcsn_v8_execution_20261101.economics.worker_cost \
  --out /tmp/v10-av-prepare-cost --timeout 1800 --sample-interval 0.2 -- \
  "$CODEX_PRIMARY_RUNTIME_PYTHON" \
  -m experiments.hcsn_v10_followup_20261101.persistent_av.candidate prepare \
  --output /tmp/v10-av-results
```

先使用同样外包络运行模块 `experiments.hcsn_v10_followup_20261101.persistent_av.root_precheck check --output /tmp/v10-av-results`。独立 precheck 对该精确冻结完成后，仍使用外包络执行该模块的 `evaluate --output /tmp/v10-av-results`，选择新的计费目录。没有相同字节封印的 precheck 通过记录，包装评估入口拒绝执行。

本次独立预检实际通过 2,948 项，覆盖全部 16 个拟合律候选、全部十种合法观察交错顺序、独立 DOP853 ODE 转移与显式完整路径枚举。最大绝对误差 `4.88498e-15`；晚到条件化错误轴的负对照在八个拟合律上被识别。该预检支持有限模型实现，而不验证其生成假设符合真实 AV 或具有 He–Xiong 资格。

实际准备外层 CPU 为 **100.210975 s**，保存全部 16 个 reader fit 与 16 个有限律候选。四个家族 reader 参数分别为 history 40,084、GRU 40,354、SSM 40,054、filter 40,144；近似参数预算并不等于相同训练工作或最强家族资格。两个情绪种子均选 K=2、shrink=1；绑定种子 91101 选 K=4，91103 选 K=2，shrink 均为 1。
