# V10 持续 AV 独立审阅与指定神经前向重放

审阅对象为 `persistent_av/candidate.py`、`root_precheck.py` 及其精确
冻结的 `results001/`。通过结论限于登记的有限隐状态模型和已暴露历史
录制；原前端、新独立样本、金融自由边界、解析神经网络与采用门仍开放。

## 源码与评估前核查

`PathFilter` 保留 `p(z0,…,zt)`。每次全局源时间增加只扩展末端轴；
晚到 V1 在全局 A3 之后条件化轴 z1。每个模态严格递增的前缀由继承的
缓存检查器控制；`new_window` 从实际已受 `time <= prefix` 限制的包中
选择首窗 `[0,1]`、后续 `(prefix−1,prefix]`，旧前缀没有重复作为新
证据。缺测窗只传播，未拟合缺测的概率机制。

所有家族都读取完整六槽、每槽 58 维的已接受历史和六个 mask；相同的
新增窗均值也提供给普通参考。过滤器额外的后验来自训练拟合 Q 和发射律。
聚类数和方差收缩由历史验证似然选择，读出器由相同历史验证目标选择。
这些明确的有限模型假设不等于真实录制过程的生成律资格。

根提供的评估前检查使用独立 DOP853 ODE 传播和显式路径全枚举，对
16 个律候选及每个律的十种合法音视频顺序执行 **2,948** 项检查；最大
差异为 `4.88498e-15`，八个律检出了故意把 V1 套到 z3 的错误。
实际评估命令使用 `root_precheck evaluate`，在前后验证 LAW、训练数组、
adapter、输入清单、权重和协议封印。直接调用 `candidate evaluate`
只检查 precheck 状态，不提供同样的完整封印验证。

## 标准库独立原始审核

`audit_path_records.py` 不导入 fitter、生产者、Torch、NumPy 或 SciPy。
它从封印的 Q、先验和发射参数，用另写的 Poisson 转移级数和对数域完整
路径枚举逐条重算实际接受历史的后验。

最终 `PATH_RECORD_AUDIT_FINAL.json` 完成 **37,601/37,601** 项检查：

- 720 次执行、3,346 次接受更新全部有唯一身份；过滤器有 1,298 次更新，
  其中 34 次条件化的源时间早于当前全局时间。
- 全路径质量、非负性、至多 256 项存储界、58 维同信息行、前缀与全局
  时间增量、完整状态摘要及冻结源和输入均一致。
- 独立路径后验与实际记录的最大差异为 **4.05231e-15**。
- 144 对矩阵指数／普通同律 HMM 的完整后验最大差异为 **8.32667e-16**；
  所有候选正确率、价格后分数和 STOP 增量的最大差异为 **2.22045e-16**。
  实际动作、选中计划、最终共同头概率与净效用逐值相同。
- 从候选分数独立重做严格 STOP 比较及计划字典序 tie 规则。观测到的最小
  正 winner margin 约 **5e-6**；未对未测试的任意近 tie 作保证。
- 相同最终音视频前缀的共同头概率逐值相同，所有实际逻辑费用和分组均值
  均重新计算。

| 历史价值策略配对效用差 | 情绪：12 个录制 | 绑定：24 个录制 |
| --- | ---: | ---: |
| Filter − 完整历史 MLP | +0.04437979 | −0.01375104 |
| Filter − GRU | +0.09250458 | −0.02145771 |
| Filter − SSM | +0.04333583 | +0.03312625 |

先在每个录制内平均两个拟合种子，再平均录制。差异主要集中在少数录制，
这是已暴露历史样本上的描述性配对点估计，没有总体或新录制确认含义。
同律 HMM 得到相同结果，因此这些数据不支持矩阵指数的独占收益。

追加全候选分数审核时，审核器自身先有两次失败：将固定策略记录误读为
含 `stop_score` 的价值记录，以及错误要求不同 episode 身份的内容指纹
跨实现完全相同。`source001/`、`source002/` 和两份失败包络完整保留。
最终固定策略比较计划／模式，各自内容指纹仍绑定自身的实际接受轨迹；
数值容差、全量样本和质量条件保持原值。初始基础审核记录也保留。

## 真实神经前向重放：独立列账

按根预先指定的每个 task×seed×family 的第一条 value/expm episode，
`replay_neural.py` 实际加载 16 份冻结权重，重做 **61 个 64 维隐藏态步骤**、
**175 个未来候选预测**、价格后的选择与最终共同头前向。总计
**765/765** 项检查通过，所有要求的隐藏态、候选预测和共同头概率均
逐值相同。记录在 `neural_replay001/`。

这一步明确复用生产者的模型架构和共同头实现，不属于独立架构实现或
独立训练验证；它提供实际运行冻结神经权重的重放证据，与前面的标准库
数值独审区分。

四份独立外层 CPU 包络分别为失败审核 0.482081、0.946707 秒，最终审核
0.966682 秒，指定神经重放 3.351789 秒，合计 **5.747259 秒**。
内层计时不再相加。最初未包络的基础审核、开发和文档成本没有计量，
因此此数不是完整研究总成本；完整族内存、物理能量及历史准备成本仍缺。

复现每次使用新输出名，并保留失败及成功记录：

```bash
python -m experiments.hcsn_v10_followup_20261101.review.audit_path_records \
  --directory experiments/hcsn_v10_followup_20261101/persistent_av/results001 \
  --out /tmp/new-v10-independent-path-audit.json
PYTHONPATH=/tmp/hcsn-torch-runtime "$CODEX_PRIMARY_RUNTIME_PYTHON" \
  -m experiments.hcsn_v10_followup_20261101.review.replay_neural \
  --directory experiments/hcsn_v10_followup_20261101/persistent_av/results001 \
  --out /tmp/new-v10-neural-replay
```

需要完整包络成本时，以继承的 v8 `economics.worker_cost` 包住命令；
其原始命令、成功状态和监督记录保留在本目录的 `cost_*` 中。
