# V10 独立审核

实现和执行记录通过本轮声明检查，但没有证明控制或解析核心净优势。
六个新世界/条件下，MPC 相对强轻量控制的平均收益差在两个核心均为负，
所有描述性区间都跨零；局部正 D−B 不能替代对轻量控制的比较。

| 隐藏恢复期错配 | −0.072667 [−0.207000,+0.019333] | −0.068333 [−0.283333,+0.098333] | +0.040333 [−0.019333,+0.115333] |

奖励先精确还原为 `correct_count/4 − READ_count/25`，每世界先平均五个
历史普通拟合，再对六个独立世界成块重采样。六个世界不是 396 个独立
重复，区间不包括拟合总体不确定性。原 one-READ 启发式的普通错配点估计
为 +0.000667（区间跨零），不能笼统称全部旧控制点估计为负。

独立数值检查 NUMERIC_AUDIT.json 通过 **5,529 项**。服务混合参照枚举
所有 2^R 成功模式，涵盖 0/1 成功率边界；对最新成功权重公式最大差
3.33e−16。合法采样包上，解析、GRU、SSM 批处理分别与逐包原接口一致
至 1.11e−16、1.33e−15、1.67e−15；这不是非法任意输入的通用 API 验收。

独立主记录检查 RAW_AUDIT_STATS.json 通过 **665,587 项**：396 个主运行、
132 个固定排程回放、1,584 个强制输出、1,018 次 READ，其中 443 次真实
服务失败。逐记录重算观察更新、失败留存、收费、输出类别、计数到内容
传播、预算、STOP 后继与固定动作执行。全部 **597,950** 个候选分数用
独立 2^R 服务模式枚举核对，最大差为零；**1,641** 个 MPC 决策的候选
集合、平局规则、选中排程和首动作均核对。

MC_FORWARD_AUDIT.json 单独冻结后，重放两个条件 world0/tick0 的解析、
GRU、SSM 六个实际 MC 前向。全部 64 条模拟后继对应的 base/read 均值、
每次 1,351 个候选排程/分数、选中动作一致，分数误差为零。
**这是按冻结种子调用同一实现的有限前向回放，不是第二独立 planner，
也不是完整运行全部模型前向的重放。** 主记录审计对其余 MC 均值仅核对
频数和下游算术，未独立重建每条模拟路径。

COMMON_ACTIONS_AUDIT.json 通过 **3,366 项**。120 个普通核心运行消费
解析 MPC 的相同动作；实际访问、观察、预算与费用完全相同。
480 个输出比较中，270 个概率向量、17 个预测类别不同，说明相同动作
后继下仍存在内容预测差异；这不证明整体解析网络必要性。

规划器没有实际隐藏 path/未读状态的入口。它接收当前合法观察、估计物理
参数、剩余预算和拟合服务概率，从共同已知模型模拟未来。该采样器具有
共同模型先验，不能算作普通神经模型自身学会的世界动态。READ 成功率与
潜在路径独立，因此失败保留原观察的条件语义成立。

候选只穷举开放环未来 READ 排程，再在每个真实 tick 重规划；未来候选
决策不按未来观察分支。加上 64 条 MC 的最大值选择误差，这不是精确
belief DP 或最优反馈控制。原始四输出分母、全部 READ 费用、同 deadline
先交付再输出、空排程 STOP 均保留。6 项前向一致性与正确的混合公式
不能消除该策略类或有限采样的限制。

四个正式审核 worker CPU 为：数值 3.393148 秒、主记录 18.179706 秒、
六项前向 4.264847 秒、共同动作 1.017481 秒，合计 **26.855182 秒**。
这些是独立审核运行费用，不能再与其内部计时相加；审核开发和写作等
额外成本未完整计量。没有完整内存、设备焦耳或采用经济性通过声明。
