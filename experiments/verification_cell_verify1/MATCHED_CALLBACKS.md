# Matched-study authenticator boundary

`analyze_matched` freezes detached copies of its admitted inputs before deriving
pair or observation references. Each design, label and cost authenticator sees
another disposable copy. A callback must return literal True without changing
values or replacing nested mutable containers, including equal-content copies.
Exceptions and truthy non-booleans do not authenticate evidence.

This protects scorer state from callback aliases; it supplies no evaluator,
trusted key, allocation authority or independence proof. The host must still
authenticate the separately frozen design and original label/cost receipts.
No analysis result grants execution or production authority.

The retained regression starts with one cluster and a diagnostic sign-flip
p-value of 0.5. An old callback could detach and mutate pair aliases, preserving
canonical manifest bytes while the scorer reported eight clusters, p=0.00390625
and an externally reviewable gate. The repair refuses that callback and keeps
the unmodified one-cluster result at 0.5. Regression fixtures add no real tasks.
