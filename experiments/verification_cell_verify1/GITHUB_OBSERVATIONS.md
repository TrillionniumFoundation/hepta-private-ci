their terminal outcomes. Preserve original API bytes and their SHA-256 in each
ordered capture envelope. The first supplied observation of every planned job
must be nonterminal; an omitted planned job cannot shrink the denominator.

metadata, not an authenticated clock or proof of public precommitment.

names, source identifiers and conclusions do not enter that projection. Provider
success gives a known false target-error label; failure/timed_out give true;
cancelled/skipped/neutral and other non-binary endings remain explicit UNKNOWN.
The target is this provider job's conclusion, not a business operation's truth.

The module checks supplied bytes and identities; it authenticates no provider,
trust key, evaluator custody, source independence or physical-cost completeness.
It creates no signed ShadowJournal label and performs no model fit, prediction,
network request or actor execution. A caller must preserve measured acquisition
cost or an explicit unknown; UTC timestamp differences are not a cost receipt.
