# 历史真实 AV 前端回接：内容保持成立，新确认门尚未通过

本目录将可恢复的 V3 原始拟合内容头接入 V7 不可变共同缓存，实际重放真实 CREMA-D 特征。来源提交为 `1dc975504276d9f7af3b28f0f7b1c2a79ef66d8d`。这项交付没有恢复失踪的 V5/V6，也没有把历史录制重新定义为独立新对象。

## 实际结果

- 两次完整开发重放各检查 **4,608** 个“任务、原分组、样本、音频前缀、视频前缀、接受顺序”组合。原头与缓存后原头的最大概率误差均为 **0**。
- 全量原始输出与归档选择模型的概率、标签和对象顺序精确一致。原有独立表格审计也重新通过。
- 所有 train/validation/旧 test 分组的绑定数据保持完整单模态输入边缘完全相同。
- 缓存最大 nominal binary64 payload 为 **8,448 bytes**；被检查的 Python 缓存对象图最大 **35,337 bytes**。这不是部署进程族内存。
- 最终增加的 9 个行为检查通过：未来内容隔离、输入复制、来源 ID 不进入预测、坏布局和未来时间拒绝、正确性校准的头身份约束，以及未来非法载荷不得拒绝当前读取。

原数据共有 **48 个录制、8 个历史演员**；从中构成 48 个六类情绪对象和 96 个同录制／异录制绑定对。4,608 是接口执行检查次数，不能当作独立样本数。

| 历史任务 | 原训练分组 | 原验证分组 | 已曝光旧 test |
|---|---:|---:|---:|
| 六类情绪 | 24/24 | 4/12 | 5/12 |
| 同录制来源绑定 | 48/48 | 18/24 | 13/24 |

这说明缓存接口保留了原头能够使用的内容；原头的跨演员质量仍不足。V3 情绪含 NEU，且绑定标签是同录制来源关系，不是 V6 的五类情绪／句子关系任务。因此 `content_quality_gate_passed=false`，不能转用这组数字关闭 V6/V7 前端门。

## 接口

`LegacyV3Head(task)` 校验原权重 SHA256，固定所有载入数组，然后通过 `classify(VisibleContent)` 执行原头。共同缓存保存每个模态在已接受前缀内的时间排序与 16 维特征；时间只用于因果选择和原事件排序，来源 ID、演员 ID、标签均不进入头特征。

`prepared_observation(...)` 只复制请求模态、已可用、已观察的源行。每个 packet 是完整前缀；缓存仅保留每模态最新 packet。共同缓存的显式预算包括这些历史行，不能把它称为 32 标量核心自行记住了全部内容。

原 V3 头直接使用原始前缀矩和交互。`aligned` 是声明的前缀均值，不是新的学习对齐；本适配器不声称已经恢复 V6 的共同投影或对齐参数。

`evaluate(VisibleContent)` 必须另行提供实际 0/1 正确性校准器，不把最大 softmax 直接充当经验正确率。`BinnedCorrectness.fit` 是供开发接线使用的固定五箱 beta 平滑校准器；调用方必须声明拟合材料、哈希和分组作用。接口存在和能运行，不等于已建立独立留出校准。

## 最后的因果修复与证据边界

第一版适配器在截取请求前缀之前验证整个预备数组的有限性。全部冻结历史数组都合法，因此其完整概率重放通过；但是未来 NaN 可以导致当前 READ 提前失败。修复将载荷有限性检查限制到真正选择的前缀内容。

`validation/CAUSAL_HARDENING.json` 对保留的修复前源码执行这个反例，确认原缺陷；同时逐一比较全部真实输入的 **864** 个模态前缀 packet，修复前后完全相等。最终 9 项边界检查由独立外层进程计量。完整 4,608 比较使用修复前、已冻结并保留的源码；864 个相同输入 packet 的比较明确给出此次有限性检查变更的覆盖范围，没有伪称随后又重跑过完整矩阵。

## 从完整仓库恢复

原源码和两个分片归档均已在父提交中；无需向本 PR 重复提交展开的历史 888 个成员。

```bash
python -m experiments.hcsn_v8_execution_20261101.frontend.recover_local
```

`RECOVERY_SPEC.json` 固定 16 个源码／来源元数据身份、两个归档清单身份。恢复器从当前完整 checkout 中读取这些路径，校验全部 27 个分片、两个压缩包和全部 888 个声明成员，写出前端需要的历史文件。任何后续修改的来源文件都会因哈希不匹配而拒绝，不会静默换用。默认目的地是仓库内 `recovered/v3`。

`validation/RECOVERY_VALIDATION.json` 保留实际独立恢复结果：**842 个落盘文件字节相同**，第二次同内容恢复成功。重复运行只接受完全相同的既存文件，不覆盖不同数据。恢复器不执行模型训练或科学确认。

## 重现

运行环境需可导入 NumPy、SciPy 和 PyTorch；历史 `data.py` 的合成任务导入路径需要 PyTorch，即使本适配器的预测本体仅使用 NumPy。原 V3 报告记录 Python 3.12、PyTorch 2.8 CPU。设置单线程环境后，从仓库根目录运行，并选择尚不存在的输出目录。

```bash
export OMP_NUM_THREADS=1
export OPENBLAS_NUM_THREADS=1
export MKL_NUM_THREADS=1
export PYTHONDONTWRITEBYTECODE=1

python -m unittest experiments.hcsn_v8_execution_20261101.frontend.test_legacy_v3 -v

python -m experiments.hcsn_v8_execution_20261101.economics.worker_cost \
  --out /new/output/parity_cost --timeout 300 --sample-interval 0.5 -- \
  python -m experiments.hcsn_v8_execution_20261101.frontend.replay \
  --output /new/output/parity
```

保留最初开发和随后计量复核的全部对照行、协议及失败范围。重放更多次不会增加演员或录制的独立性。
