## 源码审阅与拒绝路径

打包器把原始字节按不超过 400,000 bytes 切片，再以 `mtime=0` 的 gzip 包装；输入原本是 gzip／NPZ 时，内层字节不会被解压重写。恢复器先验证全部压缩分片的长度与 SHA256，然后按受限长度读取解码片段，检查每个片段的原始长度、SHA256 及最终拼接文件的总长度、SHA256。

路径校验拒绝绝对路径、空或点路径组件、父目录跳转和符号链接；目标路径受清单范围约束。开始安装前检查已有目标内容，发现不相同的文件即拒绝。已存在且身份相同的文件直接复用。

真实执行保留的四个负例分别证明：

| 负例 | 执行结果 |
| --- | --- |
| 目标已有不同字节 | 抛出 `FileExistsError`，原内容保持不变 |
| 目标祖先是符号链接 | 抛出 `ValueError`，链接目标未写入内容 |
| 清单原始路径包含 `../` | 抛出 `ValueError`，没有创建越界目标 |
| 分片首字节被改动 | SHA256 预检拒绝，未开始写出原始文件 |

### 原子性范围

**安装的原子性逐文件成立，不是整个包的事务。** 每个文件先在目标目录内写入临时文件，完成原始身份验证后以不覆盖已有名称的硬链接安装，随后删除临时名称。若后续文件的解码身份或完整原始身份失败，前面已经成功安装的文件可能保留；没有承诺整包回滚。

全部压缩分片身份在写入任何原始文件前预检，不等于全部解码原始文件在首个安装前已预检。源码声明的是受控本地目标，不保证能抵御恶意并发目录替换；本次也未测试断电持久性、任意并发写入或恶意无限资源输入。当前交付没有依赖这些额外保证。
