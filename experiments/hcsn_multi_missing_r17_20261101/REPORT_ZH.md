# R17：多缺测与生成器失配的有限内容参照

新增闭合的是一个明确有限的范围：四地址、八标签、两或三个任意缺测位置，在声明的有放回／无放回两个生成规律下，普通精确后验保留了合法支持，实际 READ 能按原事件位置条件化。它没有建立解析神经核心的独立贡献，也没有闭合任意未知生成器或开放域跨模态绑定。

## 源码身份与执行

正式打开新世界前，执行源码和协议已冻结并发布于
`bce93e1109163d4d87ca3656e3084fdeccb8da7b`。
`SOURCE_FREEZE.json` 的 SHA256 为
`ef9e12390670500e2bca33c1a1146c001cc0d1a7530b96179d78fb95174dc3b3`；
`SOURCE_PUBLICATION.json` 绑定完整回读验证。更早源码提交和冻结版本保留，不覆盖早先审计。

协议预先固定两个生成规律、三个任务标签、两种缺测数、每格 24 个世界，共 **288 个新世界、1,152 个 query**。每世界运行三个策略，合计 **864 次策略尝试**，没有按结果排除世界或重选价格。这里的 Binding 只执行完整公开的 alias→address 索引映射，不能解释为学习型语义或自然多模态绑定。

相对于 R16 的“环境选取一个真实 WRITE 擦除”，本轮改变了缺测机制：从全部 prelude 位置均匀独立选择两个或三个位置，缺失符号不透露 WRITE／distractor 类型。两者的结果不作直接架构收益比较。

## 后验、支持与实际 READ

`posterior.py` 对缺失 WRITE 的位置、合法地址及内容联合枚举，对缺失 distractor 的属性解析边缘化。它保留缺失事件和最终内容的相关性；不使用标签、owner 目标或未来信息填补输入。没有概率下限或支持修补。

在原位置取回的真实 READ 可能是 WRITE 或 distractor。观察后重新条件化，不把一个迟到的旧 WRITE 误当成现在新写入。重复相同 READ 返回完全相同的后验和证据；相同位置的矛盾重试被拒绝。

独立小世界审计先枚举完整生成规律，再按缺测分组，没有导入本后验实现。**96 个条件前缀、5,226 项核对**覆盖概率、完整前缀似然、READ 后继、READ 价值及重复／矛盾重试，最大绝对误差为 **1.61×10⁻¹⁵**。这不是连续算子、梯度或大规模学习的验证。

288 个正式世界中，已知真实规律的普通参照没有支持丢失或 READ 不可能错误：全部 **1,152 个 query 的真实目标后验均为正**。完整 owner 种子重放另外核对了目标、缺测 mask、公开 alias、实际 READ token 和价格，并从 raw 重算统计；三个篡改副本均被拒绝。见 `INDEPENDENT_AUDIT_V5.json` 和 `INDEPENDENT_RAW_AUDIT_V2.json`。

## 实测结果与阴性结果

| 真实生成规律 | 已知真实规律的普通后验准确率 | 实际 READ 世界数 | 平均置信度 | 平均净准确率效用 |
| --- | ---: | ---: | ---: | ---: |
| 无放回 | 84.55% | 65 / 144 | 84.01% | 0.810625 |
| 有放回 | 81.08% | 59 / 144 | 81.52% | 0.785486 |

净准确率效用为四个 query 的平均正确率减实际 READ 费用。有限样本的平均准确率和置信度接近，不能由此宣称未知规律下校准或总体等价。全部策略共用信息边界和价格；本轮不存在解析核心，也没有 D−B 架构结论。

**错误地固定无放回规律的对照，在真实有放回世界中有 71 / 144 次策略失效。**其中 56 次在公开前缀处被拒绝，另 15 次在实际 READ 到来后得到零似然；即使剩余有效尝试中，也有 **16 个 query 的真实目标被分配零概率**。该对照的整体质量和净效用保留为 `null`，不将成功子集的 77.40% 准确率作为整体性能。

“未知”策略只承认上述两个有限候选规律，遇到零似然可删除不相容候选。它要求候选规律对标签一致且每个候选概率均至少 0.8，才实际回答：

| 真实规律 | 实际回答 | 拒答 | 已回答错误 |
| --- | ---: | ---: | ---: |
| 无放回 | 444 / 576，77.08% | 132 | 0 |
| 有放回 | 447 / 576，77.60% | 129 | 0 |

**891 个被接受的 query 全部是概率恰好为 1 的点质量；没有任何仍带分数不确定性的 query 被接受。**因此这里的零错误只支持有限家族内返回已确定内容，不能闭合残余不确定性下的有效回答、任意未知生成器或通用拒答可靠性。两个不同的合法隐藏世界可产生相同公开前缀、不同目标；独立审计保存了这个两缺测不可识别见证。

冻结汇总中的未知策略 `mean_net_accuracy` 是对所有 query 强制 argmax 的诊断分数，包含实际拒答位置，不能作为实际执行效用。`SUPPLEMENTARY_METRICS.json` 保留同一 raw 的实际选择性收益：每 query 回答正确 +1、回答错误 −1、拒答 0，再减 READ 费；无放回为 **0.744306**，有放回为 **0.750764**。这是明确给定的有限任务收益，不能与不同奖励定义直接比较。

## 成本与证据

完整子进程外层 `wait4`：**1.774260 CPU 秒、1.883047 墙钟秒、峰值 RSS 35,112 KiB**。计量包括解释器、NumPy 导入、全部三个策略和失败尝试、实际获取及输出。它是整批普通参照验证成本，不能当作单个网络在线延迟、GPU 吞吐或能耗，也不包含前序开发与独立审计。审计各次内部 CPU 单列在审计收据，不能据此声称完整项目总成本已测量。

原始 `RAW.json` 为 2,926,389 字节。因单文件发布限制，以确定性 gzip 保存为 `verification_01/RAW.json.gz`（62,528 字节）；解压逐字节相同，原始 SHA256 为
`7b657481ab305feeee931028eb0028edb8041075930178d1f0bdf01cc9954c02`。
`RAW_COMPRESSION.json` 保存原始／压缩身份。独立 raw 审计可直接读取压缩文件；冻结执行器仍保持原样。

## 仍未闭合

任意未知或带偏差的生成器、缺失 alias 关系、学习型开放域长程跨模态绑定、解析核心相对强普通参照的独立收益、同质量完整生命周期成本、GPU／能耗及生产 Rust 所有权继续开放。本轮结果不能将这些项目改为通过。
