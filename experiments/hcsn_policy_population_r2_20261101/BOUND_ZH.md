# 只接受确定答案的精确生成律定理

存在一个仅依赖可见输入、无需学习或哈希抽样的构造策略：只在所有相容隐藏世界给出相同答案时接受，否则拒答。在既定 Selective 均匀单 WRITE 擦除律下，它的**人口接受正确率为 1，pooled 已观测最终目标覆盖率恰为 4/5，总查询覆盖率为 2/3**。普通精确解析器即可实现此构造。

这是新增数学命题及有限符号核查，没有实现或执行新策略，没有训练、抽取测试 episode 或新增经验确认。原四分之一哈希策略、已有 POPULATION.json、enumerate_policy.py、后验实现及全部实验结果均未修改。它不建立神经不确定性修复、解析核心增量或完整采用结论。

## 生成律与策略可见性

四个键的初始值是八类中的四个不同值；两个有序不同键取得两个不同且不与原值重复的新值；六次 WRITE 中均匀独立擦除一次；四个键各查询一次。时钟、查询顺序及显式 DISTRACTOR 不透露隐藏补全。任务类型及该有限生成律是公开共享先验。

策略只根据已到达的 x/dt/observed、可见键值、擦除槽所处阶段和当前查询键构造相容补全集合。若这个集合在当前键上的目标支持集只有一个值，就接受该值；否则拒答。标签、target_available、真实擦除内容、世界 ID、种子或未来输入均不进入策略；也没有来自先前预测的真值反馈。评分时才使用“该查询的最终 WRITE 是否仍可见”这个 availability 定义。

这等价于精确后验的点质量条件或可见状态解析中的 CERTAIN 分组。原拟合后验的 q 是严格介于 1/2 与 1 之间的值；改变对非点质量分支的接受规则并不需要重新拟合 q。但本文件只证明构造存在，并未替换冻结策略的接受掩码。

## 独立计数，不依赖总体公式

记 A 为擦掉初始 WRITE、但该键后来被可见更新覆盖；B 为擦掉初始 WRITE、该键没有后续更新；C 为擦掉最终更新 WRITE。给定任意两个更新键，六种均匀擦除身份中，A、B、C 分别各有两种，因此三类概率都为 1/3。

| 分支 | 类概率 | 每 episode 确定接受数 | 每 episode 最终 WRITE 仍可见的目标数 | 非确定查询的后验 |
| --- | ---: | ---: | ---: | --- |
| A：擦初始、后来覆盖 | 1/3 | 4 | 4 | 无；未知旧值已不影响目标 |
| B：擦初始、仍然需要 | 1/3 | 3 | 3 | 一个查询在三个剩余值间均匀 |
| C：擦最终更新 | 1/3 | 1 | 3 | 三个查询各以 2/3 保留旧值，三个新值各占 1/9 |

B 中，三个可见原值与两个可见新值已经排除五个值，因此隐藏原值有三个等权可能。C 中，四个原值和一个可见新值已知；隐藏更新键有三个等权可能，隐藏新值也有三个等权可能，共九个补全。对任一未见更新的查询键，六个补全保留其原值，另三个补全分别给出三个可能的新值。唯一已见更新的查询键在九个补全中答案相同。

独立符号核查固定原值为 0..3、新值为 4、5，穷尽 12 个有序更新键对和 6 种擦除身份，共 72 个结构历史、288 个查询位置。每个可见前缀重新枚举三个或九个相容补全，得到：

| 分支 | 结构历史数 | 查询数 | 确定接受数 | 可见最终目标数 |
| --- | ---: | ---: | ---: | ---: |
| A | 24 | 96 | 96 | 96 |
| B | 24 | 96 | 72 | 72 |
| C | 24 | 96 | 24 | 72 |
| 合计 | 72 | 288 | 192 | 240 |

所有确定接受均正确且对应可见最终目标；所有可见最终目标的 MAP 预测也正确。这个计数不是抽样。任意八类值的双射重命名保持支持集大小、确定性、availability 和 MAP 结论；原值加新值共有 8P6=20,160 个不同有序赋值。因此可提升至 1,451,520 个等权规范结构历史：总查询 5,806,080，确定接受 3,870,720，可见最终目标 4,838,400。独立的前序/查询排序及无关输入的乘数相消。

故每 episode 的期望确定接受数为 8/3，可见最终目标数为 10/3。由计数直接得到：

$$
P(\mathrm{correct}\mid\mathrm{accepted})=1,\qquad
\frac{E[\#(\mathrm{accepted}\land\mathrm{available})]}{E[\#\mathrm{available}]}=\frac45,\qquad
\frac{E[\#\mathrm{accepted}]}4=\frac23.
$$

MQAR、Binding 的单擦除会留下三个确定目标和一个五值均匀未知目标；同一构造的接受正确率为 1、pooled 已观测目标覆盖率为 1、总查询覆盖率为 3/4。非缺失条件四个答案全确定。以上均限于同一个显式类型与生成律契约。

## 两个不能省略的覆盖率边界

4/5 是 pooled 人口比值，与原 metrics 中 accepted[available].mean 的口径一致。它不是逐 episode 覆盖率的平均值；后者为：

$$
\frac13\left(1+1+\frac13\right)=\frac79<\frac45.
$$

4/5 也恰好位于门槛，没有有限样本裕度。某批次三类 episode 数为 nA、nB、nC 时，pooled 覆盖率为：

$$
\frac{4n_A+3n_B+n_C}{4n_A+3n_B+3n_C}\ge\frac45
\quad\Longleftrightarrow\quad
4n_A+3n_B\ge7n_C.
$$

并非每个有限批次都满足这个不等式。本定理不提供新批次的 80% 下置信界或通过保证。C 类歧义查询全部拒答，该分支的接受覆盖率为零，接受正确率没有定义；不能把空集合描述为逐分支可靠性验收通过。

从同一表还可独立重建已有 a 参数公式：若确定查询全接受、B 中的初始未知拒答，而对 C 中歧义查询以可见信息可测的比例 a 接受并预测旧值，则每 episode 额外接受 a 个查询，其中正确/available 各为 2a/3，因而：

$$
\mathrm{accepted\ correctness}=\frac{8+2a}{8+3a},\qquad
\mathrm{known\ coverage}=\frac{8+2a}{10}.
$$

a=0 给出本构造；总体接受正确率至少 95% 等价于 a≤8/17。无论 a 如何在可见状态间选择，非空歧义接受分支本身都不能从 2/3 变成 95%。

## 无额外信息的歧义上界

对 C 类任一歧义查询，在允许的全部可见观察条件下，目标后验的最大质量都是 2/3。任何仅依赖这些观察的预测，即使使用与隐藏补全条件独立的随机数，正确率都不超过最大后验质量。再对任何正概率的、仅由可见信息决定的接受子集平均，正确率仍不超过 2/3。选择哈希、置信门限或不同网络都不能在没有额外信息时突破这个界。

真实 READ 返回隐藏 WRITE 的键、值及原始时间，改变了可用信息，因此可以使这些补全收缩至同一个目标；它不与读取前的 2/3 上界矛盾。对 B 类的初始未知，同理上界为 1/3；MQAR/Binding 的初始未知上界为 1/5。

## 有限任务中的 READ 价格上界

对“四问平均正确率减单次 READ 实际费用 c”这个效用，一般质量提升最多为 1，所以一般净提升只能粗略界为 1−c。仅凭 c=0.64，不能断言任意模型、任意任务中的 READ 都亏损。

在本轮精确旧生成律、无拒答、以真正 Bayes MAP 为不读参考、真实单 READ 完全恢复唯一擦除 WRITE 的更窄条件下，完美信息的四问质量增益可以精确上界：

| 可见前缀类型 | 四问平均准确率的完美信息增益 |
| --- | ---: |
| Selective A | 0 |
| Selective B | (1−1/3)/4 = 1/6 |
| Selective C | 3(1−2/3)/4 = 1/4 |
| MQAR/Binding 单擦除 | (1−1/5)/4 = 1/5 |

公式为四个查询的 (1−最大后验质量) 之和除以 4。提前给予全部缺失信息比实际因果 READ 更宽松；已经发出的回答不能回写，只有后续查询时价值不会更大。一个缺失 WRITE 不意味着增益只能影响一个输出：C 类 READ 同时揭示哪个键发生更新，能解除三个查询的歧义。

因此，费用 0.64 相对于这个特定 Bayes 不读参考，Selective 净增益至多 −0.39，MQAR/Binding 至多 −0.44。这个较紧界不能直接套到可能同时误答多个已知查询的任意神经模型前后差上，也不是对其他控制任务、费用定义、奖励或全部策略的最优性证明。CPU、逻辑等待与能量也未进入这一符号价格计算。
