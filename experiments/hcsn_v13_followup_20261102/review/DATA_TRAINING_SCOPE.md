# V13 数据与训练协议：冻结前独立审阅

本文件覆盖 `joint_core` 与 `frontend` 的预冻结源码和实际 TRAIN-only
接口检查。没有读取正式 validation/test 标签，没有运行正式候选选择
或质量评价。后续训练和评价必须另留源码／候选远端冻结与真实执行凭证。
尚在实现的动态价值 adapter 不在这次源码准入结论内。

## 联合内容网络的数据与目标

`joint_core/data.py` 从旧 V3 历史真实 AV 的 TRAIN packet 形成六步、
55 维已接受观测。它包括两个模态的最新内容、新源窗均值、源时间增量、
前缀与模态标记；不含旧头概率、对象 ID 或标签。情绪 TRAIN 有 24 个
对象／240 条顺序，绑定 TRAIN 有 48 个音视频配对对象／480 条顺序。
绑定配对与每对象十种顺序是相关变换，不能记为新的独立录制群体。

新 class head 直接以真实六类情绪／二类来源绑定标签作六个前缀的平均
cross-entropy 联合训练。它不再把旧内容头的正确性当作分类标签，也不
复用旧 value head 的正确率目标。所有家族都可读取完整、未来槽为零的
六槽公共历史；持续家族另有自己的实际内容状态。

标准化只由 TRAIN 拟合，作用于 48 个内容坐标；七个时钟、前缀和事件
标记坐标保持原值。训练集跨前缀估计的离线统计属于已拟合模型参数，
不会在后续评价中以当前样本未来内容重新拟合。

## 预算、初始化和普通参照

预先声明两任务×六家族×三种子，共 36 个 fit。每个 fit 固定 128 次
AdamW 更新、batch 64、相同学习率与权重衰减，保存最后一步；没有按
validation/test 选择 checkpoint。每个任务／种子的独立 batch generator
在所有家族间相同，记录 minibatch 流 SHA；候选冻结器强制检查这点。
三种 HX／普通门分支还检查相同初始 state SHA。

| 家族 | 情绪参数数 | 绑定参数数 |
| --- | ---: | ---: |
| HX full／HX margin／ordinary gate | 31,430 | 31,170 |
| GRU | 32,550 | 32,290 |
| SSM | 29,382 | 29,122 |
| 完整历史 MLP | 21,958 | 21,698 |

三种同构门模型有相同已分配参数，但 margin 的四类零通道造成部分 gate
列没有有效输入，不能称相同有效表达容量。ordinary gate 使用相同资产、
边界／漂移归一化及重置结构，只把完整金融 bank 的前向替换为普通非线性
特征；其构造期共享的边界计算仍属于实际包络成本。

普通参考获得相同公共历史，具有明确可实施的 GRU／SSM／历史旁路。
这些是共同固定配方的强候选，尚不是每家族充分调参后的最强资格证明。
相同更新数不等于相同 CPU、样本独立性或严格参数／有效容量匹配。

## 已实际执行的 TRAIN-only 接口检查

`data_interface002/RESULT.json` 中 **407/407** 项通过；来源 SHA 固定
于同目录 PLAN。独立控制包括：

- 修改 TRAIN 标签和 ID 后，55 维输入逐值不变，目标标签实际改变。
- 从原始 TRAIN packet 独立重算十种合法顺序的新源窗，逐值相同；旧累计
  前缀不重复作为新源窗。全局增量、模态前缀及受保护坐标保持精确。
- 六种家族的实际逐步 `step + classify` 与完整 unroll 的各前缀结果
  逐值一致；改变未来内容不改变此前前缀的 class logits。
- 三个 HX／普通门家族在同种子下具有逐值相同的初始参数和缓冲区。
- 每任务用真实已标准化 TRAIN 批次执行临时 CE backward。asset encoder、
  content candidate、gate 和两层 reader 的梯度均有限且非零；实际一次
  optimizer step 改变 asset encoder。两个任务的 asset 梯度范数约为
  0.00232246、0.00514048，权重变化范数约为 0.0628977、0.0628736。

临时一步属于训练入口检查，不计作正式 36 个 fit，也不提供质量或泛化
结论。成功包络为 **4.671375 CPU 秒**。首次独立审核错误地在原 FP32
数组上求窗均值，而实际已声明的 packet 契约先复制成 FP64；它只在该项
拒绝，原源码、结果和 **4.872427 CPU 秒**失败包络保留。修正独立输入
转换后，仍要求逐值相同，没有修改作者源或数值阈值。

## 预训练音频的独立开发范围

`frontend` 绑定官方 Wav2Vec2 ASR 权重的精确 377,664,473 字节身份，
已实际执行模型前向和接受前缀控制。复用缓存对应 288 个历史 TRAIN FLV、
24 个演员；每个原媒体字节身份已验证，首条同步一秒 PCM 再解码／推理
后，前 1,536 维描述符与缓存逐位相同。

新的 emotion readout 只取最后隐藏层的均值／总体标准差，不使用缓存中
的 CTC logits、转录、原二类 sentence target 或 validation/test。
clip 顺序与 cohort 逐行对齐，六类 emotion 直接来自该 TRAIN cohort。
固定唯一 lambda=10：24 个 leave-one-actor-out fold 的均值、尺度和
ridge 参数都仅由其余 23 个演员拟合；各留出演员有 12 条、每类两条。
第 25 个全 TRAIN fit 单独保存。temperature=1 的 softmax 明确为未
校准描述量，不能当作经过校准的 STOP 正确率。

这套只用 TRAIN 的 OOF 开发可以在 root 远端 source freeze 后执行。
不得根据 OOF 结果追加调参，再把同一 OOF 当作新独立确认。ASR 表示的
288／24 演员数据也尚未接入当前 55 维 joint core；两条研究线不能互借
前端或核心验收结论。它不是原 v6 五类强头／语义绑定参考，也没有恢复
完整历史排除账本或建立新独立录制群体。

## 尚待正式执行的结论

目前可以准入固定金融律下资产编码、持久内容和新 class head 的实际
联合训练，以及预登记的 TRAIN-only actor-OOF。完整金融参数学习、任务
内生自由边界、连续区间首达／多次复位及质量净收益仍未证明。
新 class head 的动态 STOP／续行价值必须另行拟合和校准，精确绑定该头
及其状态；旧 value head／calibrator 不能沿用为新头的证据。正式评价
等待所有选定候选和对应数据／源码远端冻结。
