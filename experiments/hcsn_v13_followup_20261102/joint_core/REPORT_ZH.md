# V13：固定 HX 财务律的资产编码与内容联合训练

本轮补齐了实际内容学习、独立重训和训练×执行通道消融。**没有建立完整
解析核心或生产采用优势。** 所有结果是旧 V3 历史开发回放，不是新独立确认。

## 实际模型与信息边界

使用真实固定 HX 参数和原方程：Eq(12) 的内生财务边界、A7 equity、Eq(8)
债权价值、F 首达概率和 G 折现首达因子。FP64 Torch 端口对资产编码反传；
金融参数本身没有学习，F/G 也没有改名为独立 Put payoff。

八个可训练资产编码、32维持久内容状态和新分类读出由同一个六前缀 CE
目标共同训练。资产绝对单位锚独立保存，不随边界执行干预同比移动。神经
membrane 的有界编码、观测时点跨界 reset 及0.5源秒恢复期是明确新增的
神经映射；它不是论文原来的 post-default 法则，也不是完整连续区间内
first-passage、多次连续复位或任务自由边界学习。恢复后只推进剩余活动时间。

两个实际任务为六情绪分类和二类同录制源绑定。原 v6 未恢复材料的任务
等价性未知，不能把未经字节认证的“五类/语义绑定”叙述借作本轮规格。

TRAIN有24个情绪录制、48个绑定源对。每对象使用10个强制A1起始合法顺序、
每顺序6次实际接受；源对和顺序会共享原录制。共同55维输入只包含接受后的
缓存、新窗口、模态、prefix与源时钟，不含旧分类头概率、ID或标签。
所有家族共享完整六槽公开历史，标准化仅拟合TRAIN的连续特征，dt及事件
标志保持原值。

## 正式训练与重训消融

hx_full、hx_margin、ordinary_gate、GRU、SSM和history各使用三固定种子，
两任务共36个fit。每fit固定128次AdamW更新、batch64、lr=.003，只保存
最终候选，不按开发或测试结果挑checkpoint。共4,608次实际optimizer更新。
相同任务/种子的六家族minibatch流SHA一致；三个HX/gate臂初始state逐字节一致。

十八个HX/margin/ordinary-gate模型的每一步都记录到非零资产编码CE梯度，
并实际改变编码权重，说明并非只拟合一个冻结内容头外的reader。
训练记录合计905,015次reset-cell与649,287次恢复-cell事件。这是重复
minibatch中实际消费的cell事件，不能当作独立录制或连续首达样本数。

ordinary_gate跳过财务bank前向，但共同的固定law/边界/锚构造仍计入费用。
full/margin/gate分配参数相同；margin常零的bank列使有效表达能力不同，
不能将allocated参数数量相同写成完全容量匹配。GRU/SSM/history同样接受
相同历史与目标；更新次数相同也不等于CPU匹配。
