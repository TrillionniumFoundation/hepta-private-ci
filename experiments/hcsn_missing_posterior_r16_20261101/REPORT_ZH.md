# R16：缺测内容的共同因果后验与校准

## 本轮解决的问题

本轮接续 #4548，固定基线为
`a793d55c23a7742378b081b162252da428a9fdb2`。上一轮的 18 个冻结模型在
完整观测时能保留内容，但删除一条真实 WRITE 后，通常继续高置信度预测
已见过的值。本轮补上仅消费公开 raw prefix 的精确普通参照，并将同一个
校准层同时应用于 Flow 与 Diagonal。没有重新训练、选择权重或改写旧结果。

**本轮有限范围验收已通过：共同缺测后验、校准与拒答、真实补读后继均获得
冻结后新流证据。** 源码在
[`cf15dfe62476b0081c0d5d329671e345033794c7`](https://github.com/TrillionniumFoundation/hepta-private-ci/commit/cf15dfe62476b0081c0d5d329671e345033794c7)
发布并逐字回读后，才执行唯一的新流确认。源与 18 个 checkpoint 在运行
前后保持相同哈希。开发回放使用已经打开的种子 73117，仍单列保留。

这关闭了已知有限任务上的一个实际缺测处理 blocker。学习型缺测能力、
未知任务分布、解析核心净增量、全模态采用与生产神经元替换仍未闭合。

另一个新流中的 **1,536/1,536** 次实际符号 READ 均通过返回的原始 WRITE

token、执行后继和评分。两个实际后继的 raw 记录全部保留。

因此，这是两个核心共享的推断修复，**不是解析动力学的独有收益**。

## 必须先纠正的验收含义

MQAR／Binding 的四个初始值从八类中无放回抽取。看到另外三个值后，缺失
目标在五个剩余值上均匀，条件 Bayes 正确率是 **20%**。12.5% 只对应忽略
这些观测的边际均匀猜测。

Selective 还必须区分缺失的初始写入与后续覆盖。如果缺失的是最终覆盖，
原 token 的地址和值一起消失。另一个覆盖地址已知，而隐藏覆盖地址在其余
三键之间均匀。因此每个候选键的旧值概率仍为 `2/3`，三个未见新值各为
`1/9`。总体 Bayes 分类器会预测旧值，在评估者利用隐藏依赖信息划出的
“实际缺失目标”子集上却可以是 **0%**。这个子集不能单独承担校准验收。
完整推导和先验边界见 [INFERENCE_SCOPE.md](INFERENCE_SCOPE.md)。

## 冻结与未闭合范围

[CONFIRMATION_PROTOCOL.json](CONFIRMATION_PROTOCOL.json) 固定了：

- 每任务 1,024 个新世界，种子 990611；三个任务共 3,072 个独立世界。
- 原 18 个固定 checkpoint；不重训、不改变三组种子权重。
- 每任务 512 次真实 READ 后继，另用种子 990612。
- 每任务 128 个无缺测不变性对象，另用种子 990613。
- 12 项 proper-score 改善门，以 episode 为独立单位、在每个 episode 内平均
  三个固定 fit，再做 Bonferroni 调整的单侧 bootstrap 下界。
- 固定 0.9 拒答阈值；18 项按 episode 的精确二项可靠度下界；覆盖率另报。
- 48 个独立 latent 参照、完整源码和 18 权重前后哈希、全矩阵计数与失败保留。

源码清单绑定全部实际依赖；确认严格在远端冻结与回读之后运行，没有失败
后重随机化、训练、换阈值或修改算子。全部输出文件均低于仓库原有大小
限制，不需要新增例外。

本轮校准层直接采用公开生成器的强结构先验，并保存最多九个候选联合
世界。它为神经模型提供了一个可实施、信息透明的普通参照，也说明仍需
把这种不确定性处理学进模型或设计更通用的状态接口。当前结果不能关闭：

- 未知生成器／多个缺失／不同事件协议上的学习型校准和语义绑定；
- 内容任务在相同能力控制下的解析核心增量与强普通核心比较；
- 真实视频、音频与语言的独立信息贡献和长期跨模态绑定；
- 加速器、实测能耗、部署级通信恢复及生产 Rust 状态归属。

机器可读范围见 [BLOCKERS.json](BLOCKERS.json)。
