# Deployment activity supplement

This is an additive, prospective description of what the complete original
deployment traces can establish. It changes no recovery07 source, scientific
trajectory, original aggregate, statistical gate, or P0/P1 interpretation.
The pure reducers and synthetic fixtures do not grant permission to decode a
scientific artifact. A separately frozen adapter must first verify the actual
completed primary run and the immutable source and artifact bindings described
in `PROSPECTIVE_PLAN.json`. This directory has no scientific execution CLI.

## Registered observation population

| Stage | Whole population | Target field population | Observable state |
|---|---:|---:|---|
| B | 240 paths, 1,440 decisions | 48 paths, 288 decisions | Mutable adapter parameters, SGD state and physical state identities at every one of six boundaries; controller history separately |
| C | 32 paths, 192 decisions | 16 paths, 96 decisions | Complete training state at all six boundaries; parameter and optimizer components at terminal only |

B includes all three fixed seeds, sixteen schedules and five registered methods.
C includes both architectures, all eight evaluation seeds and both policies.
Comparisons use the original ordinary/baseline trajectory with the same seed,
schedule and architecture. No method, failed diagnostic or seed may be omitted
after inspection.

`audit_b(paths)` validates the complete B population and rechecks the action,
guard, rollback, continuation and original divergence summaries. It keeps
requested overrides, accepted overrides, candidate changes, committed changes,
paired physical differences and paired controller-history differences distinct.
The two recorded parameter/optimizer hash recipes are compared only within
themselves; their equality relations must agree. The original
`report_results.path_diagnostics` already reports first B parameter/optimizer
divergence. This supplement checks that mechanism more explicitly; it does not
claim a new experiment.

`terminal_components(record, path, digest)` accepts an already byte-verified and
safely decoded C checkpoint. The caller supplies the pinned original
`architecture_state.digest`. Parameters are selected through the stored
`parameter_names`, so a buffer is not silently counted as a parameter.
`audit_c(paths, components)` requires all 32 terminal records and the complete
trace population. Its input must join each original `COMPLETE.paths` inventory
row to the trace selected by that row's checkpoint identity. All shared fields
must agree. The two `first_legal_divergence_*` fields come from the completion
inventory: the original runner writes the compressed trace before adding them.
No unchecked dictionary overlay may conceal a conflicting identity or count.
A changed terminal component establishes terminal component
activity. Equal terminal components do not establish that intermediate
components never diverged. Intermediate whole-state differences are reported
with that limitation; their first clock is not relabeled as the first parameter
or optimizer divergence clock.

Both reducers return descriptive activity only. The status
`registered_inactive` refers to the recorded paired boundaries in its explicit
scope. Candidate changes that were rolled back, paid work, and controller
history may still exist. A paired difference after prior choices is not causal
credit for the current decision. Hash comparisons have their usual collision
assumption and do not replace verification of the underlying artifact bytes.

## What remains unobserved

The deployed process records the chosen action at each visited parent. It does
not execute every alternative action at that same parent. Consequently this
audit cannot compute deployment oracle regret or the chosen action's
counterfactual advantage over the current-parent baseline action. The guard
delta uses the registered reference panel; it is not that advantage.
Calibration-bank quantities and original endpoint policy contrasts remain
separate evidence. Activity does not establish benefit, a statistical success,
a certificate or adoption.

## Admission and costs

The prospective plan requires the exact primary completion, original source
closure and final raw manifest, all 17 primary archive identities and the
separate terminal delivery, plus the sealed postseal completion. Negative or
unknown scientific/cost conclusions are retained. A digest learned from the
unverified payload being opened is not an external pin.

A separate-host adapter must download actual immutable provider artifacts,
verify the downloaded ZIP and each selected member against the original byte
inventory, and reconstruct the final raw manifest without rewriting original
metadata. The original inode tuples describe the original host's independent
readback. They must never be claimed to reappear on another host. Source and
path relocation require an explicit mapping in the new replay receipt.

The adapter and actual diagnostic workflow remain to be frozen separately;
there is no completed diagnostic result in this directory. They must own real
wait4 measurement of download, verification, decompression, tensor decoding and
the reducer process. New costs are separately attributed and never added again
to inclusive original measurements. Startup, final serialization and delivery
outside a measured child remain explicit. Unknown preparation or historical
costs remain unknown.

## Synthetic validation

Run from a checkout containing this directory:

```sh
python -B -m unittest supplements.parameter_field_deployment_activity_20261031.test_activity -v
```

The fixtures exercise the full fixed populations, rejected and ineffective
accepted overrides, true paired component changes, controller-history-only
differences, C intermediate whole-state differences followed by terminal
equality, missing/duplicate paths, inconsistent baselines, nonfinite scores,
broken rollback/continuation, conflicting hash recipes and unbound checkpoints.
They use synthetic hash values and a fixture digest; they do not validate a
provider download, safe Torch decoding, the actual original numerical runtime,
or any scientific outcome.
