# R18 independent evidence plan

R17 closed bounded engineering and mathematical checks. It did not establish
the original core-utility or cost advantage, arbitrary-generator calibration,
natural cross-modal binding, full-model adoption, or production activation.
New R18 work must retain those distinctions and all original failed gates.

## Source and outcome discipline

Each module needs its own immutable source/protocol identity before opening
its new validation worlds. Preserve superseded implementations, unsuccessful
runs and their measured costs. A local development check is not retrospectively
converted into an independently frozen scientific confirmation. Bind runtime
imports, data-generation code, numerical constants and model selections, not
only the top-level runner. Read-only review changes no inherited experiment.

| Module | Concrete check before outcomes | What a passing result can close | What it cannot close |
| --- | --- | --- | --- |
| Planner fast path | Equal Bellman values, likelihood weights, fixed action/answer ties and anchored elapsed-time semantics against the frozen controller; preserve invalid branches and unsupported fallback | Correctness and measured cost of the optimized finite controller | HX-exclusive utility, the original anchored-versus-full cost gate, or full-model deployment advantage |
| Continuous task | Defined state/observation contract, stop/reset payoffs, recovery duration and its remaining-time successor; independent numerical method and predeclared refinement | The stated finite-horizon task solver and recovery mechanism in its measured error/mesh range | Full He–Xiong/reset PDE, neural learning, exact continuous first-passage execution, or arbitrary moving-boundary optimality |
| Unknown generator | Disjoint generator split, no target access in adaptation/control, mask mechanism and calibration unit explicit; separate fractional answers from point-mass answers | The stated observed-prefix adaptation/calibration procedure on its held-out generators | Distribution-free calibration over arbitrary unseen laws or learned natural multimodal binding |
| Native owner | Actual durable authority, model/owner identity, predecessor CAS, stale-owner behavior, pending-action persistence and external effect semantics | The implemented lifecycle at its tested native boundary | Product activation or external exactly-once effects from a synthetic local retry test |

## Planner audit

The R15/R16 controller optimizes only the current query's three remaining
slots. A speedup must preserve the public time/fee contract and that objective.
It must not drop a positive-likelihood branch, rescale probabilities, change
the tie rule, or compute a different horizon. Compare complete actual traces
and state values at declared checkpoints, while reporting floating-point state
hash changes separately. Numeric state comparisons at one checkpoint do not
qualify all intermediate state bytes.

Time model preparation, cold execution, cache reuse and full online work
separately; include serialization, restoration and failures. An implementation
comparison against the old slow controller does not replace the frozen
anchored-versus-full adoption comparison. The same-matrix ordinary HMM receives
any optimization that depends only on shared matrix/controller structure.
R17's equivalence proof still applies.

## Continuous task audit

A Gaussian-fold sampler generates exact reflected-Brownian endpoints at a
specified interval. A policy that observes only those endpoints is a
decision-mesh policy; it does not observe an unrecorded continuous boundary
crossing. Claims about continuous-time stopping need an explicit first-passage
method or a separately justified refinement limit.

For reset duration rho and remaining horizon t, the successor is evaluated at
t-rho, with every recovery charge and content-mode transition included. Reset
is unavailable for t<rho, while the t=rho case needs an explicit terminal
convention. Interpolation must be causal and preserve convex combinations.
If reset completion reveals the new mode, that observation must reach all
controllers in the same way.

An independently coded DCT method using the same finite-difference eigenvalues
is an independent algorithm for the same spatial discretization. It is not an
independent continuum-law reference. State which eigenvalues, boundary
conditions and spatial interpolation the reference actually uses. Mesh
refinement and complementarity residuals are numerical evidence, not certified
continuous boundary brackets. Where smooth fit is applicable, STOP contacts
match the stopping-payoff slope; spatially constant RESET obstacles match zero
slope. Do not select parameters or a useful mechanism after inspecting the
new validation outcomes.

## Unknown-generator audit

R17's conservative finite-family policy accepted 891 of 1,152 query decisions,
all with posterior maximum exactly one. Its zero accepted errors therefore did
not test useful fractional-confidence answers. R18 should explicitly count
fractional accepted predictions, their coverage, error and calibration, in
addition to resolved point-mass predictions and refusals.

Distinguish a newly held-out member of a declared family, a held-out generator
family, unknown sampling dependence and arbitrary unmodeled laws. No single
observed prefix identifies an arbitrary latent generator. The R17
nonidentifiability witness cannot be removed by relabeling a finite mixture as
an unknown-generator posterior. Adaptation may use permitted past raw
observations; evaluation labels and hidden future events remain scorer-only.
State the statistical unit: queries sharing a world or fitted model are not
new independent fitted models. A wrong-prior invalid run remains in the cost
and failure ledger, with whole-population quality null when required.

powercap/hwmon energy files in this executor. This describes exposed interfaces,
