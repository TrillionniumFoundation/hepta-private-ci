# R15 numerical implementation and recovery scope

This study separates financial valuation, finite CTMC construction, transition
preparation, and online probability propagation. They produce different outputs
and are not interchangeable timing baselines.

## Measured operations

`python -m tools.hcsn.addressed_decision_r15_20261101.numerics_study --output PATH`
records process CPU and wall time separately, including raw repeat totals.
Libraries are already imported. A cold transition means that no transition
result is cached, not a fresh operating-system process.

1. FullHX boundary construction with three forward tangents.
2. The eight-center financial equity, first-hit, discounted-hit and debt bank,
   including those tangents.
3. The actual FullHX-to-Law constructor. It currently performs inherited R12
   calculations, including financial values that R15 does not use as rewards.
4. Frozen matrix restoration from an already decoded payload. Export, JSON
   decoding, and disk access are excluded from this specific measurement.
5. A cold matrix exponential versus independent positive uniformization of the
   identical Q, at all six IID/OOD step durations.
6. Cached propagation of batches of 1 and 64 beliefs, including cache lookup.

The same-law comparison is only item 5, followed by item 6. A fast financial
closed-form value cannot substitute for a full 40-state transition. Conversely,
cached matrix propagation does not pay financial construction on every call.
Both preparation and reuse must be visible when reporting costs.

The reported array bytes count explicit float64 payloads. They do not measure
Python object overhead, scipy temporary allocations or process resident memory.
These are CPU-host measurements, with one BLAS thread when threadpoolctl is
available. No GPU, energy, native Rust or communication performance is inferred.

## Independent uniformization

For `rate = max(-diag(Q))`, the implementation forms

`P(t) = exp(-rate*t) sum_n ((rate*t)^n/n!) (I + Q/rate)^n`.

It uses a geometric bound on the remaining Poisson-series tail after the
successive ratios are below one. Intervals with Poisson mean above 16 are split
and composed. No matrix exponential is called by this implementation. No row
renormalization or probability clipping masks the approximation error. The
reported series bound excludes floating-point arithmetic error; direct errors
against scipy's expm are recorded separately.

`with_uniformization(law)` returns a Law-compatible object. Its mathematical
`identity` remains the original law identity, and `implementation_identity`
separately commits the numerical implementation and tolerance. Use
`method="uniformization"` in Planner and BeliefMemory. An explicit
`method="expm"` delegates to the original law. The world remains unchanged.

## A single recovery-shape intervention

`make_memoryless(law)` returns a frozen Law-compatible object with a new identity.
It preserves every active Q row, both emissions, content retention, reset
destination distribution, correctness reward, and all public prices. It changes
only the residence-time structure after natural absorption.

The original recovery consists of two exponential stages, each of rate
`2/recovery_mean`. Its total duration is Erlang-2. The intervention sends both
represented recovery phases directly to the same reset distribution at rate
`1/recovery_mean`. These recovery states are lumpable, and the total mean
duration from newly entered recovery is identical to the original mean.

The intervention does **not** preserve the conditional remaining lifetime of a
partly completed original recovery. Losing that age information is precisely the
factor being examined. It also does not preserve variance: Erlang-2 has variance
`mean^2/2`, while the exponential has variance `mean^2`.

Natural absorption still enters phase eight, and the natural-event mark remains
the active-to-recovery edge. First-hit and repeated-event-count methods therefore
use the correct changed generator with the same event definition. A restored
payload preserves the changed identity. The intervention does not repair,
resample, or reset the world's trajectory.

The development sensitivity study runs the same predetermined READ-at-step-1
and REFRESH-at-step-3 public histories through both models. It applies public
overwrites, ignores typed distractors, and reports observation log loss and
content prediction differences. This diagnostic neither fits models nor selects
confirmation outcomes. The root campaign separately measures the actual
memoryless arm under the same public information and action-cost interface.

Since the synthetic world is generated by the original Erlang model, better
agreement by that model is evidence conditional on that family. It is not by
itself proof that two-stage recovery is universally superior in real tasks.

## Incorrect endpoint shortcuts are negative controls only

Two audit-only approximations illustrate discarded post-hit evolution:

- Keeping only killed survival mass loses probability and is not the declared
  conservative regenerative process.
- Adding first-hit mass to recovery only at the end of a time window conserves
  mass, but ignores the time between the actual hit and the window endpoint.
  It fails the original semigroup and discards repeated events.

These approximations are excluded from main efficacy arms. The study reports
their errors as implementation counterexamples, not as strong ordinary cores.
