# 独立简化候选：C1 值场能否产生连续重复脉冲？

## 结论

在这组事先固定的参数和初值下，答案是可以：同一连续二维 ODE 在 γ=0.2 时回到稳定平衡，在 γ=0.8 时出现重复的风险高平台、反复穿越自由边界并自行返回。求解器没有事件触发、硬重置或离散 0/1 输出。四组嵌套步长支持该轨迹是收敛的数值现象。

这是一项独立的简化 perpetual 示例。它不是原 He–Xiong rollover 金融模型的神经元实现，没有修改冻结金融核或任何既有 gate，也不构成网络训练、任务质量、速度或能耗的优势证据。

## 算子与动力学

令 b=1，x=log(V/b)，α=1.7。续行侧 x>0 使用

F(x)=exp(−αx),
E(x)=exp(x)−1−[1−exp(−αx)]/α,
R(x)=2F(x)−F(x)².

默认侧 x≤0 使用 E=0、R=1。E 是此前 C1 示例的 equity-like 函数；R 是另行构造的风险 observable，并非原单轨迹 first-passage probability 或原 put。

在 x=0，续行侧 E=0、R=1，而且 E_x=R_x=0，故两者与默认侧的常数延拓 C1 拼接。这里把算子**值**直接代入

xdot = I − kE(x) − γR(x) + a,
adot = β[(γ+d)R(x) − a].

因此在固定的正参数下，二维向量场是全局 C1；这里没有把 −E_x 或 R_x 当作势能力来使用。若改为势能导数作为力，这份 C1 结论不能直接保证 ODE Jacobian 连续。

固定 k=0.1、β=0.1、d=0.1、V*=2，取

I=kE*−dR*=0.007197543363810573,
x*=log(2),
a*=(γ+d)R*.

两个 γ 使用同一形式的初值 x(0)=x*+0.05、a(0)=a*。时间是任意单位。

默认侧并不是吸收态：在 x≤0 内，a 趋近 γ+d，而 xdot 趋近 I+d=0.10719754336>0。延迟恢复变量因此能把轨迹自然带回续行侧，无需重置。

## 精确线性化

在平衡点，

E_x*=1.692213896663771,
R_x*=−0.7243829809597193,

J = [[−kE_x*−γR_x*, 1],
     [β(γ+d)R_x*, −β]].

因而

trace(J)=−kE_x*−γR_x*−β,
det(J)=β[kE_x*−dR_x*]=0.024165968776234906>0.

线性虚轴穿越候选为

γc=(kE_x*+β)/(−R_x*)=0.3716561497754841,

且 trace 对 γ 的导数为 −R_x*=0.7243829809597193>0。

| γ | trace | 特征值 | 局部结论 |
|---|---:|---|---|
| 0.2 | −0.1243447935 | −0.0621723967 ± 0.1424800402 i | 稳定焦点 |
| 0.8 | 0.3102849951 | 0.1551424976 ± 0.0098373894 i | 不稳定焦点 |

解析 Jacobian 与中心有限差分的最大绝对差分别为 1.64e−12、2.68e−11。虚轴横截是 Hopf 候选所需的线性条件；未计算第一 Lyapunov 系数、未证明局部分岔的非退化性或超/亚临界性，因此不声称严格 Hopf 定理。γ=0.8 也远离 γc，不能把其有限振幅轨迹当作已证明的局部 Hopf 分支。

## 实际固定步长轨迹

事先固定 RK4、总时长 800、统计窗口 [400,800]、步长 h∈{0.04,0.02,0.01,0.005}。求解器只在固定时间点计算 C1 右端；边界穿越时间是运行结束后从连续状态样本线性插值获得的读出，不反馈到积分器。

最细步长 h=0.005，每个 γ 为 160,000 步。

| 观测 | γ=0.2 | γ=0.8 |
|---|---:|---:|
| T=800 到平衡点距离 | 7.02e−14 | 1.45324 |
| 尾部 x 范围 | 0.693147180560 附近的舍入尺度变化 | [−2.4243424131,1.9198259716] |
| 尾部 V 范围 | 2 附近 | [0.0885363202,6.8197715321] |
| 尾部 R 范围 | 0.520839921266 附近 | [0.0750301371,1] |
| 尾部完整 R=1 平台 | 0 | 4 |
| 平均平台间隔 | 无 | 74.3084761764 |
| 平均平台宽度 | 无 | 47.9819593399 |

γ=0.8 在尾部还有一个尚未结束的平台；4 个完整间隔的标准差约 2.13e−7。以平均完整平台宽度除以周期，平台占比约 64.57%。这是明显的宽平台式、松弛振荡样活动，不能称为窄而稀疏的经典尖峰。这里只验证每个 γ 的一个初值，未证明周期轨道存在、唯一性、吸引域或任意输入驱动下的稳定性。

### 全时域步长收敛

相邻步长在共同时间网格上比较，范围覆盖 0≤t≤800。

| h → h/2 | γ=0.8 的最大绝对差 Δx | 最大绝对差 Δa | 最大绝对差 ΔR |
|---|---:|---:|---:|
| 0.04 → 0.02 | 2.08295e−7 | 2.52106e−8 | 9.74027e−8 |
| 0.02 → 0.01 | 1.36797e−8 | 1.80245e−9 | 7.95272e−9 |

γ=0.2 的差异已降至约 5e−14 的浮点舍入尺度，最后一次减半不再严格减小。边界拼接只要求 C1，故不把 RK4 在每次跨边界后的全局误差笼统宣称为四阶，也不把这些浮点差当成严格区间误差界。

## 对原构想的意义与限制

这项实验填补了一个具体可行性缺口：闭式、C1 拼接的两个 observable 加一个恢复变量，确实可以形成连续的重复边界穿越和脉冲样读出；不必先引入不可微的 0/1 阶跃或硬 reset。

同时，它暴露了实际代价：

- R 在默认平台内恒为 1，R 对 x 的局部梯度为零。整体状态仍能传播并恢复，但只依赖 R 的局部读出会失去该区间内的状态分辨率。
- 观察到的高平台占一个周期约 65%，并不天然稀疏；可微连续输出本身不保证少通信或低能耗。
- 闭式 observable 不等于闭式神经动力学。本示例仍使用数值积分，没有证明比传统 SNN、CfC、SSM 或 Transformer 更快。
- 没有端到端训练、内容记忆、跨神经元耦合、全模态 encoder、同 analytic-features baseline 或任务质量实验。
- 不能把本例结果用于替代冻结金融候选的数值准入、原任务确认集或质量约束 CPU gate。

## 文件和复现

运行：python dynamics_probe.py

PLAN.json 在首次轨迹执行前写入；RESULTS.json 包含两种 γ、全部四个步长、所有穿越时间、解析线性化和误差统计；CONTINUOUS_TRAJECTORIES.npz 保存 h=0.005 结果每 0.1 时间单位采样的 x/a/R（完整步长轨迹可由脚本确定性重算）；DYNAMICS.png 与 DYNAMICS.pdf 是科学图；RUN_LOG.txt 保存实际成功执行输出。MANIFEST.json 记录逐文件 SHA256。

实际进程退出码 0。积分和分析墙钟约 1.03 秒仅是运行日志，不是任何性能比较。图中平衡点与稳定轨迹、极限环样闭合轨迹、重复 R 平台和步长差均来自本次实际计算。
