# R13 传播层：实际修复、独立参照与认证边界

## 结论

R13 已实现可供训练、规划与原生执行共用的正性有限体积生成元：吸收端使用正确的半格距离，漂移使用平滑的指数拟合通量，上域按包含所有恢复/复位轮次的尾概率预算选择，复位分布的物理支撑及宽度保持固定。

这是一项可执行的有限模型修复。独立连续首达参照、更新方程以及全域嵌套细化都显示误差显著降低；默认 56 格仍不是连续扩散的精确解，也没有取得完整金融控制问题的连续最优保证。下面保留了一个默认网格选错动作的构造反例。认证门禁会阻止把有限参照结果转换成连续最优结论。

运行模型的 `api.py`、`finite_volume.py`、`bounds.py` 在正式拟合前交给根代理冻结；本目录后续只增加验证与理论文件，没有修改这三个文件。全部验证使用确定的物理参数与开发诊断，不生成或读取正式确认任务结果。

## 1. 运行接口和已经证明的部分

`make_grid()` 默认给出 56 个 active 单元、总状态数 116、上界 `13.064376419678013`。状态布局为每一内容类别的 `active[0:N], R1, R2`。`generator_torch(sigma, mu, reset_x, edges, recovery=.35, retention=.75)` 返回 `Q/prior/centers/reset/edges`；NumPy 接口同名同义。根模型用完整金融边界求 `reset_x`，该接口不重新拟合或替换金融公式。

证明及其条件见 [THEORY.md](THEORY.md)。主要结果如下。

| 项目 | 结果与适用范围 |
|---|---|
| 生成元 | 非对角项非负，行和为零；含两阶段恢复和内容转移的完整状态是有限 Markov 状态。 |
| 传播 | `exp(tQ)` 正性、质量守恒、满足半群关系，包含任意次复位及每次事件后的剩余时间。 |
| 吸收边界 | 第一中心到零的距离是半格；零漂移时杀死率为 `2D/h²`，修复 R12 的全格边界。 |
| 漂移导数 | 使用解析 Bernoulli 函数 `z/expm1(z)` 的稳定求值；不再在 `mu=0` 处进行 ReLU 分裂。 |
| 上域 | 对总时间 `T≤29.4`、`sigma≤.4`、`mu≤.04875`、复位/初始支撑 `[0,.8]`、恢复均值至少 `.35`，连续过程触及上界的概率不超过 `1e-4`。该界包含所有复位轮次。 |
| 有限指数 | 正性 uniformization 的 Poisson 尾项可按预算截断；该尾界与浮点累计误差分别处理。 |

`1e-4` 是连续过程上域修改的耦合界，不能替代 FV 空间误差界，也不是经过稀有观测条件化后的后验误差界。默认 `grid_certificate()` 仍显式返回 `fv_spatial_error_bound: null`。

## 2. 连续首达参照和网格误差

[FIRST_HIT.json](FIRST_HIT.json) 使用无上反射的 Brownian 首达解析式，覆盖三组波动率/漂移、三种初始均值、两种宽度、三个时间间隔，共 54 个场景。连续初始分布是固定支撑 `[0,.8]` 上的截断 Gaussian，跨网格通过 CDF 的实际 bin mass 对齐。Gaussian 160/320 阶积分最大差为 `7.79e-14`，并另用首达概率随初始位置单调的端点包络校验。

| 传播模型 | active 格数/细化 | 54 场景最大首达误差 | 平均绝对误差 |
|---|---:|---:|---:|
| R12 原上风率、上反射 `.8` | 8 | 0.34790819 | 0.07941878 |
| R12 原上风率、上反射 `.8` | 64 | 0.08158835 | 0.01523067 |
| R13 半格与扩域 | 56 | 0.01805555 | 0.00151064 |
| R13 每个单元二分 | 112 | 0.00413725 | 0.00036094 |
| R13 每个单元四分 | 224 | 0.00101823 | 0.00008949 |

后三行来自 [NESTED_REFINEMENT.json](NESTED_REFINEMENT.json)，上界和物理复位分布完全相同，细化发生在每一个单元。只缩小 `inner_step` 而固定尾部增长率 `1.2`，并不能保证所有远端单元宽度都趋零，因此另保留的近边界步长扫描没有被称为全域收敛证明。

最坏默认网格场景为 `sigma=.15, mu=.04875, initial_mean=.04, initial_sd=.03, dt=.05`。连续首达概率约 `0.26689155`，56 格给出 `0.24883600`。这表明短时间、靠近吸收端的窄分布仍需更细网格。表内最大误差只是这些确定场景的数值结果，不是整个参数空间的一致上界。

## 3. 独立完整 renewal 参照

[renewal_bounds.py](renewal_bounds.py) 从连续首达 CDF 出发，用更快/更慢的量化时钟包围每个 active duration 及两个 exponential recovery duration。正性卷积与 renewal resolvent 包含任意多轮复位；最快时钟的零时长循环原子也通过分母 `1−eta*h[0]` 保留。

通过普通和内容保留加权的累计事件数差，程序给出 active/R1/R2 与二元内容的六项联合概率包络。它保留了内容和恢复阶段的相关性，并没有把状态压成均值或一个恢复标志。

[RENEWAL.json](RENEWAL.json) 含 27 个参数/初值/时间场景，每个采用三档时钟与位置包络精度。最大联合概率区间宽度由 `0.15933` 降到 `0.08672`、再降到 `0.04537`；这是保守包络，不应描述成高精度完整后验。默认模型在一项较窄包络上超出约 `3.45e-5`，细化网格回到区间内，进一步说明 FV 空间误差仍存在。

在 `sigma=.3, mu=.015, reset_mean=.325, initial_mean=.04, initial_sd=.03, T=6` 时，至少完成两次复位的连续概率包络为 `[0.55809355, 0.56186825]`。忽略第二次及后续复位会遗漏实质概率质量。另用一个 active duration 恒为零的四状态 CTMC 对量化 renewal 公式进行独立核对，三档包络均包含 `expm` 的结果。

包络的数学证明以有效 CDF 上下界为前提。当前求值使用 float64、显式 `2e-13` padding 和普通卷积；没有执行 formal directed-rounding interval arithmetic。[CDF_ARITHMETIC.json](CDF_ARITHMETIC.json) 的 144 个高精度检查点最大绝对差为 `2.10e-16`，这是算术支持证据，不是所有输入的一致浮点误差证明。

## 4. 金融行动比较与保留的失败条件

行动检查使用完整金融收益/读取成本、R12 固定的六项内容证据及不可用符号，测试传播算子；它不是 SMS 正式确认结果。场景在 [VALIDATION_PROTOCOL.json](VALIDATION_PROTOCOL.json) 中先声明：72 个初始分布、内容概率及时间组合，`H=3, read_budget=2`。

56 格相对全域四分后的 224 格参照，72/72 动作一致，最大 action-Q 差 `0.00124451`。每个场景都满足 `gap > 2*finite_reference_difference + H*tau`，其中 `tau=1e-12`。112 格相对 224 格的最大 Q 差为 `0.00024441`。

继承的 R12 反例也被复现：`mean=.04, sd=.03, p(content0)=.875, dt=.05` 时，原 8 格选 READ、原 64 格选 ANSWER0。修正后的各档 SG 扩域网格都选 ANSWER0。**但默认 56 格对这一个窄 action-gap 见证仍不满足保守误差停止条件**；更细网格才满足。动作恰好一致，与已经取得充分误差证书，是不同结论。

每层 Bellman 节点都使用平局容差，因此相对精确有限模型最优值的累计损失最多为 `H*tau`，不能只在根节点加一次 `tau`。原始比较证据保持不变；全域细化及新增门禁采用累计预算重新检查。

## 5. 一个能实际选择 N 的有限范围连续误差预算

[observable_budget.py](observable_budget.py) 针对已经声明的首达观测量，利用解析位置包络 `[F_low,F_high]` 得到

`abs(F_finite − F_continuous) ≤ max(abs(F_finite − F_low), abs(F_finite − F_high))`。

这是观测量特定的后验误差界，数学上不依赖把两种网格的差冒充连续误差。[OBSERVABLE_BUDGET.json](OBSERVABLE_BUDGET.json) 记录的 54 个首达观测量最坏条件式界分别为：

| N | 条件式首达误差上界 |
|---:|---:|
| 56 | 0.01859089 |
| 112 | 0.00467259 |
| 224 | 0.00155357 |

请求 `0.002` 的误差预算时，程序选 224 格，并拒绝在 56 或 112 格停止。这里的条件仍包括解析 CDF 与矩阵运算准确，完整的机器区间证明尚未完成。

为展示实际行动后果，另构造一个**在查看诊断结果后设计的反例**，不将其计为预注册独立效果：SAFE 的收益为零，ADVANCE 的收益为 `.26 − 1{在 .05 前首达}`，使用上节最坏近边界参数。56 格选择 ADVANCE，但连续 ADVANCE 的 Q 包络为 `[-.00742689,-.00635693]`，所以实际应选 SAFE；该单次行动的损失包络为 `[.00635693,.00742689]`。224 格选择 SAFE，且在假定算术准确的数学预算下通过 `gap > 2*error` 条件。

这解释了为什么默认 56 格可以通过 72 个金融场景的有限参照检查，却仍不能宣称普遍连续最优。

## 6. 可执行认证门禁

[certification.py](certification.py) 提供 `certify()`，强制区分三个目标：

| 目标 | 允许的结论 |
|---|---|
| `computed_finite_reference` | 输入的有限 Q 向量范围内的行动结论；使用精确有理数比较这些二进制浮点数，不能据此允许连续最优 claim。 |
| `continuous_financial_task` | 必须同时提供统一 action-Q 误差和全部空间、公共状态空间/投影、域、观测条件化、收益、推断/参数、算术证据；缺一项即 `uncertified`。 |
| `continuous_declared_observable` | 仅限明确声明的窄观测量；同样不默认豁免未完成的机器算术证据。 |

全程策略保证还必须提供对所有策略/可达历史统一成立的 value discrepancy `D`，再输出 `2D + H*tau`。一个当前 belief 的 Q 差不能自动生成这个 `D`。

[CERTIFICATION_GATE.json](CERTIFICATION_GATE.json) 的实际检查结果如下。

| 检查对象 | 有限向量行动证书 | 连续金融行动证书 | 全程策略证书 |
|---|---:|---:|---:|
| 56 对 224，72 个场景 | 72 | 0 | 0 |
| 112 对 224，72 个场景 | 72 | 0 | 0 |

构造的 224 格首达行动通过了条件式数学 gap 检查，但严格门禁仍因没有正式算术误差证明而返回未认证。门禁中的假定 `D=.02` 合成检查只验证 `2D+H*tau` 公式实现，不是 R13 已证明该 `D` 的证据。
