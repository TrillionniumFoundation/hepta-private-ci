# Hepta neuron R13：统一有限模型、真实文本与可审计的准入结论

## 结论

R13 已完成实现、24 次正式训练、冻结后的真实文本确认和独立复算。训练、价值后继、原生批量推断和事件恢复现在使用同一个有限生成元。原三参数结构冗余、漂移零点梯度折点、数值并列行动差异、逐行原生开销和恢复合同缺口均得到实际处理。

**这不等于所有科学门槛通过。** 两域都通过注册的质量非劣与 unique deployment 成本验收，但质量增益均未通过；同模型通用 HMM 与 Hepta 的行动、效用完全相同。单字 FP32、完整连续金融 Q/策略误差证书、GPU 和自然时序内容任务仍没有准入证据。生产默认核心保持关闭。

本轮支持把 Hepta 保留为**可训练的结构化有限状态模块与显式事件执行器**。尚不能据此确认“完整金融核是一种优于强普通模型的默认神经元”。具体机器判定见 [ACCEPTANCE.json](ACCEPTANCE.json)，逐项处置见 [BLOCKERS_ZH.md](BLOCKERS_ZH.md)。

## 1. 实际运行了什么

采用 UCI SMS Spam Collection 的公开原始文本。官方数据说明明确指出其消息并非按时间排序，因此本实验没有把它冒充自然短信时间序列。归一化去重仅用于数据身份和分区；编码仍使用原始文本。5574 行得到 5159 个去重身份，没有冲突标签身份。

| 分区 | ham | spam | 用途 |
|---|---:|---:|---|
| encoder_train | 2233 | 338 | 训练共享词/二元词组哈希线性编码器 |
| core_train | 737 | 91 | 核心状态学习 |
| validation | 420 | 53 | 检查点和 GRU/SSM 选择 |
| confirmation | 1127 | 160 | 冻结后确认 |

分区由规范化文本 SHA256 决定，同一规范化文本不跨分区。整库会加载、规范化以去重；确认文本直到实际 READ 才编码，不参与训练、模型选择或后验似然重估。所有 actor 只收到相同的六档文本证据、恢复不可用标志、观测掩码和时间间隔。

编码器先训练后冻结，核心学习通过可微分有限模型进行。这是有监督内容学习与状态学习的分阶段组合，**没有声称梯度穿过离散文本分档实现联合端到端训练**。

每种核心每个种子使用 40 CPU 秒优化预算。共 8 个种子、3 个核心、24 次完整训练，完整子进程 CPU 总计 **1061.51464 s**，包含解释器、导入、数据准备、验证、序列化。共享文本前端的确定性同权重复拟合完整子进程 CPU 为 **2.48109 s**。确认进程完整 CPU 为 **22.231728 s**。

确认包含每域 4096 条长度12的序列，以及每域8192个配对决策情境，共16384个情境；每个情境分别执行7个arm。独立统计单位是每域8个训练种子的配对均值，不把 episode 数当作额外独立训练样本。

后验监督来自受控真物理生成元和训练语料的加0.5平滑名义似然。它是所有核心共享的因果训练目标，并非真实文本分布下已知的完整真后验。确认标签用于实际内容质量评分；名义后验CE/Brier只作诊断。结论以这个固定语料和受控过程为条件。

证据：[PROTOCOL.json](PROTOCOL.json)、[IMPLEMENTATION.md](IMPLEMENTATION.md)、[evidence/FREEZE.json](evidence/FREEZE.json)、[evidence/SUMMARY.json](evidence/SUMMARY.json)。原始逐例数据由证据归档恢复。

## 2. 设计已经怎样改变

### 统一状态与传播

状态是“内容类别 × 活跃位置/两阶段恢复”的联合分布，共116态。两类内容各有56个活跃位置和2个恢复阶段。完整HX解析模型提供边界和金融任务读价；在当前参数化中固定期限m=1.3，只学习sigma/liquidity。边界决定复位中心，漂移和扩散决定正的SG通量。复位分布物理支撑固定在[0,.8]，不会随计算域变大而改变。

同一个 Q_theta 对应：

- Torch `exp(dt Q)` 与 Bayes 更新中的可微分状态推进；
- 共同有限时域控制器的所有后继与观察分支；
- prepared Rust 的实际批量传播；
- Gillespie 原生事件轨迹中的触界、恢复和复位。

矩阵指数的精确性属于**有限CTMC**。从连续扩散到这个Q仍有空间离散和边界截断误差，不能把它们省掉。

训练参数有14个存储分量：2个物理raw参数与12个发射logit。两行softmax各有一个加常数自由度，所以不能据“14个参数”宣称14维全局统计识别性。GRU64和门控连续SSM64分别有26100和17204个参数；本轮约束的是相同优化CPU预算，并非参数量或状态内存完全相等。

### 复位和恢复成为执行合同

prepared model拥有不可变Q、版本和摘要，缓存按精确dt位模式绑定。事件更新先用旧Q推进至变更时间，再按残余单位指数风险或明确重采样策略接续；不沿用旧Q的目标状态或绝对事件时间。

posterior checkpoint与事件checkpoint具有各自明确schema。request包含dt、模型/观测身份、版本及预期checkpoint。错误版本、错误模型、伪装的Q24 journal、未经READ却提供的payload均拒绝。缓存满时拒绝不会推进posterior、时钟、序号或摘要；owner清空缓存后可原请求重试。

生产main当前的Q24接口没有同样的dt/checkpoint合同。R13只交付显式研究适配器，没有把旧journal错误地当成同一种状态，也没有自动激活生产默认。

## 5. 精度、梯度和原生开销

### 双FP32是单独后端

原81点加冻结后216个新点，最终双FP32候选297/297达到原值8e-7、Jacobian2e-5门槛；新点最大误差约5.75e-8/5.06e-7。单字FP32在新128/64/24组分别仅通过103/36/13个。

每个双FP32实数由两个32bit分量组成，有效载荷64bit；输入和输出为FP32，核内四则和超越函数用补偿FP32，不暗中使用FP64特殊函数。离线常数构造、参考解、日志读取与显式mixed诊断分别标明。它不是单字FP32内存节省。

CPU batch64前向/值+Jac：双FP32为23.7417/24.4406 s；mixed64为.1062/.1248 s。这个候选显著更慢。12步输出拟合的97.725%降损仅证明梯度可用于该优化诊断；R13确认仍使用FP64状态和金融桥，不能说整个神经元已在纯低精度完成训练。

### 实际拟合网格与输入量化补测

随后保持DS数学核冻结，在8个正式fit的56个位置上检查448点，独立80位参考分别对齐FP32代表输入和原FP64输入。对齐FP32代表输入时448/448通过；相对原FP64输入的总误差只有440/448通过，8个Jacobian超2e-5，最差3.5911e-5。失败出现在x约1.06/1.14的敏感导数，远端x>2的96点反而全部通过。这说明输入量化误差不能用“核内算得很准”替代。

另增明确命名的split64输入适配器：FP64仅用于入口hi/lo编码与范围检查，随后调用不变的两FP32数学核。事后复用归档参考检查448/448通过，最大值/Jac误差5.7424e-8/5.8355e-8；输入编码最大归一化误差1.6483e-15。两分量通常约48位有效精度，不是无损保留FP64的53位。完整值+Jac累计调用130.61 s。

这一适配器采用新的输入合同、仍有64bit有效载荷，属于事后财务后端修复检查，不替换旧448点失败，也不参与R13已冻结的任务确认。Jacobians近似的是连续HX公式在代表点的敏感度，不是round-to-FP32输入映射的数学导数。详细证据见[实际网格精度报告](verification/R13_GRID_PRECISION.md)及同目录split64附录。

### 参数和长链梯度

初值、真值、零漂移及两侧的raw→Q映射均为局部rank2；映射AD/FD最大误差1.09e-9。三种12/64/96步序列×三个参数位置，实际三个损失对全部14参数的双步长FD最大误差5.08e-10。零漂移两侧状态和梯度差随扰动缩小，没有旧ReLU折点。

这证明局部数值一致性与去除旧物理参数冗余；不证明从任意真实文本观测全局识别金融参数。训练的完整名义后验监督也必须计入这种校准解释。

### 原生精确二进制的性能

确认使用的.so SHA256为`19299f8802da6932f9a0e08025f265c38b855be8e9417b17f2c558115ef50ad2`。格式化后重新构建并重新验证，旧二进制结果未冒充新二进制证据。

默认116态、batch64、30步、含构造/三次P准备/在线的中位CPU：旧逐行路径1.04113 s，prepared dense .0252192 s，合法cached NumPy .00898089 s。因此相对旧路径快41.28倍，但相对强NumPy慢2.81倍。60个独立worker在同误差门槛全部通过；跨已测规模dense/NumPy为2.13–4.37。

上述结果是同Q多行批量测试。另已实测每个cell拥有不同sigma/liquidity和Q、每模型准备3个dt、执行8步的异质任务：

## 6. 连续误差和行动证书仍须分开

冻结网格的活跃计算域扩展到13.0644，近边界h=.025。在协议参数盒与总时间T≤29.4下，连续上域逃逸概率预算1e-4只控制上域截断、且在观测条件化之前，不能充当空间离散或后验误差界。

54个事先声明、用独立连续解析参照核对的场景：旧R12 N8最大误差.347908；新全域嵌套N56/112/224的最大误差分别.0180556/.00413725/.00101823。每个cell整体二分避免了只缩小近边界步长、远端网格却不收敛的漏洞。

72个预先列明的金融行动场景中，新N56与N224行动全部一致，并通过有限Q向量参照的gap充分条件。**这仍不是完整连续金融Q证明。** 查看诊断后构造、且不计入预注册确认的连续首达决策反例中，默认N56错误选择advance，连续模型损失包络约[.00635693,.00742689]；N224仅在这个首达观测量任务上、假定参考CDF与矩阵算术准确时满足数学gap条件；严格认证门禁仍因缺少正式算术误差证明而返回uncertified。这一反例保留，不因主确认漂亮而删除。

复位参照包含任意多次更新，不使用“只做一次reset”的快捷近似。例如一组真值附近参数T=6时，至少两次复位概率包络约[.558094,.561868]。

[certification.py](propagation/certification.py)已经实际执行。它区分有限Q参照、受限连续观测量和完整连续金融任务；连续任务缺少空间、条件化、payoff、参数/推断、共同状态空间或算术证据时返回uncertified。全程策略保证还须有对所有策略统一的误差D，不能拿单次Q差冒充；在相应假设下计入2D+H*tau。当前完整连续金融/全程策略证书均未通过。部分数值包络以准确CDF/矩阵算术为条件，尚未实施directed rounding。

## 7. 与两篇论文的关系和最终设计取舍

He–Xiong原论文的闭式边界、债务和权益表达可作为可微分参数化来源；R13沿用完整HX方程，再增加内容、恢复和神经元执行合同。这些新增机制不是原金融论文已经证明的神经网络结论。

Qi的Hölder工作研究连续控制Bellman目标在椭圆扩散条件下的正则性和逼近复杂度，明确不提供实际采样DQN训练收敛定理。R13应继续使用其“先分析传播与Bellman算子，再考虑逼近资源”的方法。吸收、复位、离散恢复相位和观测条件化不能无条件套入其全空间结论。短时间首达边界层与网格分辨率的压力，也说明不规则时间的优势必须连同误差预算衡量。

当前设计应保留统一Q、联合分布、因果读操作、版本化checkpoint和强普通/HMM参照；完整金融参数化作为可替换模块，按任务证据决定是否保留。CPU批量信念传播必须保留合法强NumPy路径；原生事件执行器承担显式事件与恢复语义。禁止把精度后端身份、有限模型范围或部署成本归因混在一起。

所有开发失败、前后格式化身份、新旧性能结果和本轮未通过项均归档。原始已存在结果不会被重跑覆盖。`restore_artifacts.py --verify-only`验证所有归档和确切native二进制分块；不加该选项可在干净检出中恢复缺失工件，遇到现有不同字节会拒绝覆盖。完整文件清单见TRAINING_ARCHIVES.json、EVIDENCE_ARCHIVES.json与native/BINARY_ARTIFACTS.json。
