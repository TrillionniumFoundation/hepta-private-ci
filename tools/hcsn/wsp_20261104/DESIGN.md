# 解析结构与 NDU：下一阶段的可实现设计边界

本文件区分已经实现的组件与尚未实现的设计推论。配套 native planner 只解固定特征二次问题；guard 只评估固定行。下面的完整图编译、全局策略综合和生产恢复均没有被本轮这两个工具自动完成。

## 1. 先绑定语义，再改变数值

Agent 需要的机制映射应绑定到实际可执行图：模型文件完整 SHA、tensor 名称、dtype/layout、归一化和单位、代码版本、输入来源，以及原参数到派生产物的依赖。静态参数名称不足以建立这个映射。

在当前 digital joint 中，renewal raw 参数导出为 generator 和 transition tables；NumPy 部署读取这些 tables。只改 raw JSON 而不重编译 tables 不会产生所声称的机制改变。更新必须同时验证原始参数、派生矩阵和执行图身份。

状态应包含影响未来条件分布的内容：时钟、剩余 budget、pending due 时点、已完成观察所属 tick 及对应可靠性、repair/cooldown，以及完整条件质量。当前 joint 采用 current-at-due 观测语义，必须按实际完成时点滤波，不能套用旧任务的静态 posterior。若隐藏状态把两个需要不同最优动作的历史映射为同一表示，任何只依赖该表示的末层都无法恢复丢失的区分。这是条件性结构推论，不能在没有表示碰撞证据时直接归因到某个 encoder。

只读源码核对还定位了一个明确的解析分支：renewal 的 forecast bank 第 7 项（零起始）就是模型自身在 deadline6 的正类概率，对应原始 85 维 head 输入的 `x[83]`。它由当前 mass33 加剩余公开 drive/duration 传播得到；只给 mass 而不指定时点和未来日程通常不够。按当前有限 CTMC、完整完成历史及给定 confusion，该模型后验可以直接计算，不必再次由 learned Belief 行拟合。

但现有 Belief 行作用于 `48-tanh hidden + bias`，并不直接读取原始 `x[83]`；其原训练目标是 teacher posterior，并非复制自身 bank。解析旁路需要改变执行图，不能把选择原输入第 83 项的 one-hot 行误写成已有 49 参数行的精确修补。85→48 的维度变化本身也不证明可达状态上发生了信息损失。模型自身的后验只有在初始分布、转移、emission/confusion 和时点语义均与验收 law 一致时才等于 Oracle；learned head 可能在补偿 core 偏差，结构一致性本身仍须接受任务价值检验。

REPAIR 动作修复的是 broken 传感器，CTMC boundary reset/recovery 是另一个机制。当前两个 refractory 状态的指数恢复不要求额外年龄状态；若改为非指数恢复、累计触边或曾经到达事件，则需要另行检查年龄、计数或事件标记。当前有限 CTMC 的充分状态论证不能自动外推到连续市场过程。

## 2. First-Passage、Reset 与 Call/Put 不能混用

对于 active-state 的 killed generator T、起始质量 alpha 和两个退出 rate 向量 r±：

\[
S(t)=\alpha e^{Tt}\mathbf1,\quad
F_\pm(t)=\int_0^t\alpha e^{Ts}r_\pm\,ds,
\quad S+F_++F_-=\alpha\mathbf1.
\]

此恒等式要求 `T1 + r+ + r− = 0`，即两条出口穷尽 active-state 的损失；只有初始 active 质量 `alpha1=1` 时右侧才为一。若起始已存在退出或 refractory 质量，必须另外保留该质量，不能把 active 子分布擅自归一化。

有 survival residual 时不能强迫两个 first-exit 概率相加为一。发生 reset 后的未来状态占用分布又是另一个对象；它包含重复退出、refractory 与重新注入。Generator 必须保持非负 off-diagonal、正确的行和，reset kernel 必须归一化，传播应保持质量和非负性。针对这些关系的检查应在真实定义下实施，不是强制任意两行权重相反。

对于同一随机变量和同一 horizon 的货币 payoff，

\[
\mathbb E[(X-K)^+]-\mathbb E[(K-X)^+]=\mathbb E[X]-K.
\]

若存在 discounting，必须在两边使用相同的计价规则。digital tail 概率、金融 Call/Put、上下首次到达概率三者不能共享一个不加区分的 complement 检查。严格大于与小于等于的 tie 质量也需要明确。

当前 V13 financial map 的金融参数未训练；它与学习到的 encoder、gate、rate、reset content、reader 是不同层次。R22 的九参数构造经三个摘要，Jacobian 秩至多三。未来自动规划应先在可识别商空间定位，不能把坐标方向数量或非零导数数量当作独立机制数。

## 3. 数学约束应缩小可行集，而不是替代任务目标

固定隐藏特征、样本权重非负且正则矩阵严格正定时，proximal weighted ridge 给出唯一二次目标最优解；它不保证 argmax 策略改进。NDU 应评价声明模型中的完整预期收益与成本，例如：

\[
Q^\pi(s,a)=-c(s,a)+\sum_{s'}P(s'\mid s,a)V^\pi(s'),
\qquad V^\pi(s)=Q^\pi(s,\pi(s)).
\]

终止收益由任务定义给出。状态、合法动作、观测迟延和失败概率都进入同一个有限环境；不能使用固定旧 continuation labels 代替变更策略后的完整计算。模型不确定或真实 decoder 未知时，所求只是声明模型下的值，不是现实世界真值。

一种可检验的下一步是：先对已知有限模型求最优动作，再检验冻结表示的参数能否实现该动作表。若动作 a 优于 b 的 logit/Q 是线性的，可以写成

\[
(w_a-w_b)^T\phi(s)\geq m,
\]

并加入 bias、固定 terminal 输出、范数／preservation 约束。有限动作表的实现问题可以成为 LP、QP 或带离散选择的优化问题。可行并不证明未枚举状态泛化；不可行可用具体矛盾或对偶证书说明继续训练同一参数块的限制。

本轮 TRAIN LP 就采用这一诊断路线，发现部分 terminal 排序根本不依赖可编辑 continuation 系数。该结论指导了后续 Belief 实验，避免继续增大同一 continuation 训练预算。它不自动授权把 teacher posterior 放进部署输入，也不自动保证 Belief 编辑在新任务上有益。

后续实际 Belief 实验已经完成：三个偏置修改消除六个已知 TRAIN 矛盾、保留其余 451 个符号，但新世界任务价值未提升，Belief-only 的验证接受数为零。这说明可实现性约束修复与价值提升是两个独立验收层；不能在第一层通过后跳过第二层。

随后独立冻结的三 bias 网格直接使用完整 TRAIN 任务价值，实际评价了五 fit 的全部 625 个候选。它给出声明的有限网格在数值目标上的最优选择，但新增候选相对当前 C 的原 VAL 门全部未通过；新测试的 V−C 两域区间也跨零。该实验将目标错位假说落实为可执行对照，结果没有建立增量效力，也没有实现连续权重空间的联合全局规划。

### 把全局价值与权重可实现性放进同一问题

对完全已知的有限状态／动作模型，令 `d0` 为初始状态分布，`0≤γ<1`，用折扣占用量 `x(s,a)=E[sum_t γ^t 1{S_t=s,A_t=a}]` 表示策略在各状态采取动作的折扣期望次数。它满足：

\[
\sum_a x(s,a)=d_0(s)+\gamma\sum_{s',a'}P(s\mid s',a')x(s',a'),
\qquad x(s,a)\geq0.
\]

有限 horizon 的无折扣任务也可以先把时间放进状态，写相应的逐层流守恒。任务目标是最大化 `sum x(s,a) r(s,a)`，其中 r 包括同一单位下的动作、等待和失败成本，而不是最小化旧 Q 标签的平方误差。在这里，验收环境的 P、r 固定且独立于被编辑权重；不能用候选自己预测的、更有利的环境 law 代替冻结的验收 law。

若要让某个可编辑线性头真正执行该策略，还需要动作选择变量 `z(s,a)`，约束每状态选一个动作、占用量只流向选中动作，并使选中动作的实际 Q 不小于其他合法动作。固定特征和固定 terminal Q 时，这些条件可以结合有界权重的 big-M 约束组成混合整数线性问题；L2 trust region 会引入锥约束。big-M 必须由真实参数／特征界导出，不可随意设一个大数。归一化 d0 且 γ<1 时，总折扣占用量有 1/(1−γ) 的上界；有限 horizon 也有时间长度上界。无折扣且没有终止或其他有限占用保证的模型，不能直接套用这样的有限上界。

动作约束还必须匹配真实 argmax 的 tie-breaking。只写非严格大小关系会允许规划器在相同 Q 值之间自由选一个高收益动作，但实际运行器可能固定选择列表首项。用正 margin 排除 ties 是一种保守办法，同时会缩小可行策略类；不能再把它的最优值称为整个无 margin 策略类的全局最优。

实数线性分数的 margin 或最优性也不自动覆盖 F32 参数 lowering 和前向舍入。部署前还需保守数值误差界或对实际执行的 argmax 作独立复核；有限个候选的数值实测不能替代整个可行权重类的舍入定理。

这条路线把“最优动作表不可被当前头表达”的问题纳入求解本身；还可对多个已声明场景共享同一组权重，并加入 preservation 约束。它可能返回具体可行参数、可核验的上下界，或者不可行证据。当前交付实现了固定动作表可实现性诊断、有限模型评价，以及上述三 bias 有限网格搜索，没有实现这个联合规划器。

其适用条件很严格。一起编辑 Belief 时，`1−2 sigmoid(logit)` 与 continuation Q 的比较一般不再线性；只在判断两个 terminal 动作的符号排序时，才可化成 logit 的线性符号约束。一起编辑状态编码器、rate 或 reset 时，模型内部特征和预测转移矩阵也会变化，但验收环境 law 不能随之改动。此时需要带误差证明的近似、非线性约束求解或新的外层搜索，不能继续声称原 LP 全局最优。混合整数求解的最坏复杂度和建模成本也可能超过梯度法。任何全局最优性都只针对已声明模型和范围，不能自动转化为未知 decoder 或真实市场中的全局价值。

## 4. 局部保留与因果定位

在单线性映射 W 上，若 K 的列是需要保留的输入，P 是其正交补投影，要使目标输入 k 的输出改变 delta，可考虑：

\[
\Delta W=\frac{\delta(Pk)^T}{k^TPk}.
\]

它在分母非零且数值条件合适时满足 DeltaW K=0、DeltaW k=delta；若 Pk 近零，应拒绝或报告与保留约束冲突。这是有限子空间的代数关系，不是全模型无副作用证明，也不是本轮已实现的新工具。

相关原始研究包括 [ROME](https://rome.baulab.info/)、[AlphaEdit](https://proceedings.iclr.cc/paper_files/paper/2025/hash/29c8c615b3187ee995029284702d3f43-Abstract-Conference.html)、[CrispEdit](https://proceedings.mlr.press/v306/ikram26a.html) 与 [BetaEdit](https://ijcai.org/proceedings/2026/508)。它们分别提供因果定位、保留子空间、低曲率能力约束及连续编辑干扰的相关思路；不能把这些名称都归为无梯度方法，也不能移除它们各自的激活数据、近似条件或实证范围。

## 5. 自主 Agent 的可审计决策循环

完整 Agent 应维护一个实验账本：问题与可证伪预测、源图身份、可编辑坐标、数据访问预算、候选产生过程、全部成本、独立验证、接受或拒绝、恢复验证。数学不可行、数据来源未闭合或目标错位时，停止该候选方向本身就是有价值的优化决定。

组合编辑必须比较当前 incumbent。先接受 C 后再提议 B，比较的是 `V(C+B)−V(C)`，同时用 C 的 SHA 绑定本次源，而不能一直比较 `V(C+B)−V(original)`。本轮冻结 2×2 实验里，C+B 对旧 base 全部过门，但新增 B 相对 C 没有通过同门的模型；旧收益可以掩盖新组件的无效。该经验应写入下一协议，不能事后改动旧协议并重贴成功标签。

已经实现：bounded numeric proposal、hash/byte-pinned artifact、实际线性 forward、明确的分数和输出约束、失败反向产物验证。尚待实现：原生完整图解释与派生编译、一般自动因果搜索、隔离的保留测试服务、跨取消／重启的持久结果 journal、生产模型切换及恢复协议。存在能力边界时不能用通用 shell 权限绕过它，再把操作称为已受原生语义约束。

下一阶段比较应使用同一初始 checkpoint、同一可见训练数据、同一未见测试、同一总资源上限，分别记录不编辑、仅外围解码/执行修复、随机或简单 bias、直接编辑、梯度更新，以及组合操作。保留所有失败尝试；测试数据不能反馈到下一候选。多轮适应性查询需要额外未见确认数据和明确的多比较处理。

解析 Belief 旁路的跟进审计给出了一个具体教训：`base_seed + fit*10000` 的编号在不同研究之间发生碰撞，64/320 日程与原研究另一 fit 重合。单次运行内部先冻结门、再生成测试，并不自动证明整个研究历史中从未见过这些日程。原结果和分母保留，另列勘误；不能换 seed 重跑后掩盖这次暴露。最后的 `analytic_belief_compile/` 实验已对冻结设计身份、fit、domain、用途做 hash 域分隔，并在任何 test 评分前按可用历史的日程内容去重；预先规定重复即停止而不重采样。其 320 日程与 1,616 个已知唯一历史日程均无重复，但原 formal confirmation 内容未取得，也不能证明未知外部历史没有重叠。

该编译研究把模型自身解析 bank 的 logit 拟合到原 49 参数 Belief 行，使用固定正则、固定半径和一个直接候选；它还用相同目标、相同起点和独立数值停点的 PGD 建立了可比较的局部基线。两者均达到共同 FW 门槛，真实参数序列化、精确范数和来源保持都通过，但任务价值区间仍跨零。更贴近自身解析输出时，TRAIN 相对 Oracle 的后验误差反而增加。因而“解析结构正确”“能编译成参数”“数值优化达到门槛”“对任务 law 的预测更准”“策略价值更高”必须继续作为独立验收项，不能相互替代。

\[
C_{total}=C_{acquire}+C_{features/activations}+C_{agent}
+C_{candidate}+C_{validation}+C_{failures/recovery}.
\]

只有任务价值与这个完整成本的联合证据支持结论时，才能说它比传统梯度路线更高效。当前较强的结论是：解析结构可以让一些局部问题直接求解，并让另一些方向提前得到不可行证据；这两者都能改善研究决策，但尚不是通用范式优越性的证明。
