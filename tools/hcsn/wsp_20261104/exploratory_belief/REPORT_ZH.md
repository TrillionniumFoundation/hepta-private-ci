# Hepta Neuron：受限 Belief 修复与精确有限域不可行证书

日期：2026-11-04。此项是独立的探索性跟进，原 study 的协议、结果和验收门未改动。新协议在新测试输出之前写入，seed 固定为 870140000；不是外部预注册实验。

## 结论

**实际修复了原 TRAIN 中六个终止动作符号矛盾，但没有取得可验收的任务收益。** Belief-only 的五个候选均未达到原验证集 +.005 门，因而被退回原参数。与原 Continuation 编辑组合后，IID/OOD 平均表现均低于仅做 Continuation 编辑，差值区间跨零。

另一个独立成果是：fit71 的有限线性系统不可行证书已从浮点残差检查升级为对已存储 IEEE 系数的精确有理数证明。这限制的是固定表示、固定 Belief 和给定改动范围，不是完整模型不可修复或连续数学定理。

## 4. fit71 的精确有限域证明

从原99个非零 witness 权重重建 y，未保存的微小权重按0处理，不重新优化或归一。所有 A、b、y、rho 均作为其 IEEE 二进制值对应的精确有理数。令 `r=Aᵀy`、`c=bᵀy`。对盒中任意点，若线性约束可行，则必须有 `c+rho*||r||1 >= 0`。

精确计算和向上舍入得到：

| margin | `c+rho*||r||1` 的向上舍入上界 |
| --- | ---: |
| 0 | **−.0005149002502248292241130588** |
| .001 | **−.001487468919277903441097118** |

因此两套有限系数系统不可行。残差不需要恰好为零，因为已将其最坏贡献精确纳入上界。Fraction 结果还用对齐的任意精度整数点积独立核对。

原材料没有单独保存 A,b；本次用原固定构造器及原数据重建后，将产生的 IEEE 系数冻结到新 NPZ。精确证明适用于这些序列化数值与声明的盒半径。它不证明修改 Belief 后仍不可行，也不证明未舍入实数问题、连续 law 或全局 NDU 不可行。
