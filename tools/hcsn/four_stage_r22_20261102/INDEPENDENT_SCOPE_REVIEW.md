# R22 跨组件只读范围审核

截至本审核快照，七个已完成组件的有限结论、保留失败与声明边界相符。
这不是新科学验收门，也不是全部阻塞项闭合。内容正式确认仍在运行；
本审核没有读取其部分结果，不推断最终质量、Brier、效用或成本结论。

独立逐条检查了七份原 ARTIFACT_MANIFEST 的 **1,973 条文件记录、
32,860,285 逻辑字节**，size 与 SHA256 全部相同。另核对全部运输分片、
压缩／原始归档校验、tar 内容对象、文件映射，以及既有 fresh roundtrip
目录的 **1,720 个 payload**，全部逐字节一致；没有运行求解器、模型、
参数抽样或归档写出。这些是记录数和逻辑字节，包含重复证据，不是独立
样本数或物理存储去重大小。各 manifest／source-freeze／归档身份见 JSON。

九参数构造的值／导数位置分别为 595×2001＝1,190,595 和再乘9＝
10,715,355；两个有限差分外推共21,430,710位置。价值通道的两个参照
合计2×(975＋9750)＝21,450位置，两个外推19,500位置。这些重复数值
位置不是额外独立任务世界。连续V2的1,564,944新方向／oracle导数位置
亦不能与旧诊断和重复工程位置合并为独立样本量。

G的非冗余论证只在共享理想精确公式层成立：局部调整principal保持
b，旧三个摘要及其理想值数组不变，而固定正log-distance下G随liquidity
严格递减。它不证明旧数组的九参数Jacobian也不变，不证明九维可识别，
也不证明两套不同边界近似的native FP64 b／Q bytes恒定。已有独立
NONREDUNDANCY评审与最终原文清楚保留了这一层次；没有数值见证冒充。

认证层保护的是checkpoint信封、见证请求／响应和单调tip绑定。
未改动的Rust LIVE owner/provider wire继续依赖受信任本机约定，不能
写成新获得密码学保护的LIVE协议。相同主机的独立进程不是独立主机故障
域；公开fixture密钥不是部署凭据。授权签名者给旧语义状态重新签发、
见证本身一起回滚、活动同UID写者和密钥泄露不在当前资格内。V1慢peer
首次工程发现于02:30:09完成，比审核器远端提交daf9f9ce于02:30:20早约
11秒；后来的冻结／复测不能追溯赋予该次发现远端前置冻结属性。

各原source-freeze与本地科学字节、publication绑定均已复核。另核对了
认证V1/V2各30项既有输入，以及连续V2全部184项legacy输入身份。
连续V2在c21de565前置发布源码和184个哈希，但V1新诊断raw bytes当时
