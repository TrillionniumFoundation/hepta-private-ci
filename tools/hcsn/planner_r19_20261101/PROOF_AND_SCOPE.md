# Owned-array forest: scope and arithmetic preservation

The only new implementation is a subclass of the frozen R18 Bellman forest. It changes allocation and validation scheduling inside two private helpers. The law, transition matrices, reward readouts, public-state owner, action tree, costs, action order, thresholds and checkpoint implementation are inherited.

`_project_many(full)` no longer concatenates all frames merely to validate them. Validation remains elementwise finiteness, the same negative allowance and the same last-axis row-sum predicate. It returns a C-contiguous array for each logical frame. **The C-layout requirement is essential:** R18's `p.copy()` materializes C order, while the broadcast joint can have non-C strides. Omitting that guarantee changed a prior-belief READ value by one last bit in a zero-price control. The failed candidate and its diagnostic are retained.

`_posteriors` creates a fresh joint array from a product; neither public beliefs nor emission arrays alias it. Its likelihood is a separately allocated reduction. Division therefore safely writes into that joint. Every nonpositive-likelihood row is subsequently replaced completely by the same prior as R18. All other rows have the same elementwise division operands as R18. Full projection then preserves R18's C layout before later matrix multiplication. Block projection retains the same original logical operand shapes and operations.

Descendants of `_forest` only read their incoming beliefs. Products and posterior joints allocate new arrays, and returned action-value arrays are separate from inputs. Removing a redundant full projection copy for an already-contiguous intermediate cannot expose writes into public owner state. Direct differential checks exercise read-only inputs and compare their byte identities afterward.

This reasoning concerns the inherited finite FP64 implementation and declared internal ownership contract. The numerical checks establish exact equality on the recorded fixtures and execution worlds. They do not prove arbitrary parameter-domain stability, cross-BLAS bit identity, continuous free-boundary correctness, a native Rust financial kernel or higher-order gradients.

Tracemalloc measures allocations originating during warmed executor calls, including transient arrays and returned execution records. It excludes already-resident law/cache/world storage and does not establish a per-arm process RSS reduction. The outer wait4 maximum RSS belongs to the complete common child, including data retention for all three variants.

Timing and allocation changes are shared planner optimizations available to the ordinary same-matrix HMM as well as HX. They provide no HX-exclusive D−B evidence. Each final deployment group executes 1,000 real owner episodes per variant, with half IID and half irregular-interval OOD worlds, and the inherited third-query (`query==2`) disk checkpoint/fsync/readback. Other query hashes are in-memory identities, not disk writes. See `ERRATA.json` for the frozen protocol wording error. These are engineering workload measurements at one frozen fitted model seed, not new independent training fits or real multimodal examples.
