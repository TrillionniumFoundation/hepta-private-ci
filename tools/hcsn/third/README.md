# HCSN 第三轮：原文准入、再生参考和新受控实验

## 结论与范围

本轮新增 **148 次实际神经网络训练**：48 次序列机制开发，100 次新样本冻结
encoder 对照；另有两次线性参考拟合及纯数值/证据检查。原有 495 次研究
训练及其失败结论保留，并通过隔离原版本的完整性重放。

数学实现和普通反向传播可以落地。本轮没有建立金融解析门相对同图普通
C1 门的独有质量收益，也没有建立等质量成本优势。新的记忆正则化约定改善
长程保持，却损害检索，因此没有通过事先约定的联合开发门。**30 次条件
确认没有执行；确认数据没有生成；完整混合 backbone 和扩大预训练没有启动。**

训练主线使用固定金融参数的完整 equity / 风险参考编译成数值 C1 核，
学习神经投影、边界坐标、时间常数和状态耦合。它仍是自定义连续状态递推。
本轮的连续概率再生模块提供独立参考；另一分布型研究分支已有的复位/
不应期机制没有被混入这 148 次训练的性能统计。

基线为 PR #4330 的 `1dd990bedee8a525093c1dd4008b2f00c2c5ff1c`。
原文是 [He 与 Xiong 的 Rollover Risk and Credit Risk](https://www.princeton.edu/~wxiong/papers/rollover.pdf)。
数学证据、科学验收和工程完整性分别记录；审计通过不会把负实验变成正结果。

## 1. 原文数值基础的两个修复

第一处是候选边界的准入。逐个金融参数落在原数值盒内，并不保证它们的组合
满足 equity 非负性。一个组合给出正边界 `22.2477116291049`，但
`x=log(V/Vb)=0.1` 的 equity 为 `-26.3685742093`。60位原始表达式、
独立 Green 积分和边界求根都确认了这个负值，因此它不是舍入噪声。

在 value matching / smooth pasting 边界，equity ODE 给出

\[
E_{xx}(0)=-\frac{2}{\sigma^2}
\left[\delta V_b-(1-\pi)C+\frac{\alpha V_b-P}{m}\right].
\]

方括号为正会使继续域紧邻边界的 equity 为负。新实现明确拒绝这些候选，
同时保留原始候选公式供审计，不截断负 equity 来掩盖问题。

512个角点加200个固定种子内部组合中，686个通过必要准入，24个负equity
候选被拒绝，另2个无正边界。NumPy/JAX的712个准入判断完全一致。
这既没有宣称论文公式错误，也没有证明所有被准入组合都满足全局停止不等式。

第二处是近可去奇点的数值消去。未放宽原容差，修复后边界交叉误差从
`5.743e-7` 降至 `1.313e-9`；九参数梯度的最大归一误差为 `4.630e-9`。
26个既有参数案例、五个自由边界BVP、四组债务PDE收敛及极限/导数检查
全部重跑通过，PDE阶数仍约二。详见 [解析报告](analytic/README.md)。

## 2. 连续再生参考与有限网格误差

对常漂移、常噪声、吸收零点、固定正复位距离，利用首达时间的距离可加性，
第k次发放的分布可写成距离 `x0+(k-1)xr` 的单次首达时间，加上k−1次等待。
确定等待直接平移时间；Erlang等待通过Gamma分布的一维积分得到。
这给出了独立于空间网格及矩阵指数的期望计数和不应期库存参考。

一个已记录配置的连续期望计数为 `4.2219866586`。八格有限过程给出
`3.9651669601`，相对误差 `-6.08291%`，同时仍保持概率守恒。
512格为 `4.2237826034`，误差约 `+0.04254%`；中间误差并非单调。

相同平均等待时间也不能使确定不应期与两阶段Erlang等价：在
`T=.45 < tau=.5` 的反例，确定等待的第二次发放概率为0，Erlang则为
`0.1993068535`。五参数解析积分梯度对有限差分最大归一误差为 `4.185e-10`。
详见 [连续概率参考](flow/README.md)，其范围不包含任意时变输入或移动边界。

## 3. 长记忆与检索之间的正则化取舍

归一化统计满足

\[
r=(1+\sum_t w_t)^{-1},\quad G=r\sum_t w_tk_tk_t^\top,\quad
H=r\sum_t w_tk_tv_t^\top.
\]

旧的读取 `(G+lambda I)^(-1)H` 等价于未归一化统计上的
`lambda(1+sum(w))` 正则。后续干扰写入即使与目标键正交，也会逐步收缩
目标读出。新的 `(G+lambda*r*I)^(-1)H` 保持未归一化正则固定。
这是一次明确的正则化约定变更；它同时改变训练梯度、参数适应和推理读出。

| FullHX，三个新开发种子均值 | 原fixed正则 | 新mass正则 | 新−原 |
| --- | ---: | ---: | ---: |
| 512步memory | 74.2839% | 100.0000% | +25.7161个百分点 |
| 512步retrieval | 99.6745% | 97.7214% | **−1.953125个百分点** |

128步FullHX主能力检查通过；不能用该结果替代512步检索约束。
普通C1、同Call sigmoid及纯记忆对照也出现相同取舍，无法把长记忆收益归给
金融函数形状。纯记忆fixed的memory128还保留了一个73.2422%的失败种子。

在看到开发结果之后进行的限定反事实进一步缩小了解释范围：保持fixed训练的
FullHX权重和整条状态轨迹，仅切到mass读取，retrieval512三种子均为100%；
保持mass训练的权重而改回fixed，均值只有34.57%。这说明本次失败涉及训练适应
和正则化的交互，不能只归因于mass公式的即时推理效果。该诊断使用已暴露的
开发样本，不修改失败门，也没有把训练/推理切换包装成新确认或可部署方案。

数值压力测试暴露了小残差不足以保障梯度的案例：原FP32求解adjoint误差
约0.00797，超过原0.005门槛。所有八分支统一采用FP64矩阵构造/求解后，
最大独立adjoint误差约`2.24e-8`。状态和学习参数仍为FP32，条件数乘状态
机器精度的风险另列，不能把求解修复解释成任意长序列的全精度稳定保证。

开发联合门唯一的质量失败为检索512退化。因此 [条件确认流程](confirmation/README.md)
保持未执行，未生成新确认数据，实际确认训练数为0。48个开发run、失败修订、调度变更、
恢复与完整独立重放见 [memory结果](memory/RESULTS.md)。

样本。PCA只拟合新train；文本删词和图像遮挡都在原始输入上执行，包含global
