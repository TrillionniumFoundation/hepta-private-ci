## 连续参考的推导与接口

安全距离过程为 dX=nu dt+sigma dW，零点吸收，每次发放后等待，再复位到固定正距离 xr；初始距离为 x0。漂移、噪声、复位位置和等待规律在整次观测内固定。无另一面反射墙。

由独立增量及强 Markov 性，第 k 次发放时间的分布等于：距离 x0+(k-1)xr 的单次首达时间，加上 k-1 个独立等待。确定等待给出常数 (k-1)tau；每次采用 m 阶 Erlang 等待则给出 Gamma(shape=(k-1)m, rate=m/tau)。因此第 k 次发放的 CDF 可由闭式单次首达 CDF 加一维积分得到。累加这些 CDF 即 E[N(T)]，不是“至少发放一次”的概率。

不应期质量按同一过程计算：对每个 k，累加“第 k 次已发放”的概率，减去“第 k 次发放后的等待已完成”的概率。等待区间不重叠，故活动质量与不应期质量相加为一。它不是把发放期望次数误当概率库存。

接口 `renewal_statistics(initial, reset, nu, sigma, refractory_mean, duration, law, stages, terms)` 返回累计期望次数、概率库存、各次发放 CDF、计数的参数梯度及尾项界。`law` 为 `deterministic` 或 `erlang`。梯度顺序是 nu、sigma、initial、reset、refractory_mean；对固定项数表达式在积分内解析求导。零等待的均值导数为右导数。

取任意 s>0，以 H_s(x) 为折现首达变换、D_s 为等待的 Laplace 变换，遗漏 K 项以后的累计计数满足

    tail <= exp(s*T) H_s(x0) [H_s(xr) D_s]^K / [1-H_s(xr) D_s].

实现取 s=1。尾项界是解析界；SciPy 自适应积分返回的误差只是数值误差估计。没有对完整时变网络或梯度尾项给出误差认证。

## 实测结果

运行 `OPENBLAS_NUM_THREADS=1 python third/flow/validate.py`（从 tools/hcsn）即可重算。无需 JAX、PyTorch、模型权重或下载数据。当前检查用时约 7.11 秒；具体环境、源摘要、参数和全部结果在 `results.json`。

基准为 x0=xr=0.7、nu=-0.7、sigma=0.5、Erlang 阶数2、平均等待0.4、T=6。连续参考累计期望次数 **4.221986658632017**，不应期质量 **0.285717178014656**。40项之后的计数尾界约 **5.27e-19**，积分累计误差估计约 **5.89e-12**。

| 活动格数 | 有限网格累计期望次数 | 相对连续参考的有符号误差 |
| --- | --- | --- |
| 8 | 3.965166960060 | -6.08291% |
| 16 | 4.151207016049 | -1.67645% |
| 32 | 4.212883894706 | -0.21560% |
| 64 | 4.226508104243 | +0.10709% |
| 128 | 4.226935120154 | +0.11721% |
| 256 | 4.225194478527 | +0.07598% |
| 512 | 4.223782603422 | +0.04254% |

这些格数共用安全距离上墙2.8，对应源模型 boundary=0.8、lower=-2 的区间宽度。**误差并非每次加细都单调下降**；边界、上风漂移和插值误差可能抵消。不能只展示看起来单调的子集。全部新网格案例保持非负、总质量误差小于2e-10；这仍不能抵消八格与连续过程的计数差异。

固定间距0.025，把安全距离上墙从1、1.5、2.8扩大到4，累计期望次数分别约为4.3859054、4.2355179、4.2271810、4.2271790。墙2.8与墙4之差约1.96e-6；与连续参考之间仍有约0.00519的空间离散差异。这将墙截断与空间离散影响分开，而没有把后者归给时间传播器。

### 确定等待与 Erlang 等待不可互换的最小反例

x0=xr=0.15、nu=-1、sigma=0.4、等待均值0.5，观测到T=0.45：

| 等待规律 | 第二次发放概率 | 累计期望次数 | 不应期质量 |
| --- | --- | --- | --- |
| 确定等待0.5 | 0 | 0.950866401499 | 0.950866401499 |
| 二阶段Erlang、均值0.5 | 0.199306853468 | 1.156272332591 | 0.782123508115 |

T小于确定等待时长，第二次发放在确定模型中不可能；Erlang 等待可以短于其均值，所以第二次发放概率严格为正。把两者仅因相同均值而互换，会在此例改变累计次数 **0.205405931092**。这不是 PR4255 的实现错误：它的合同已经明确声明采用 Erlang；此处给出独立定量反例以防后续混用。

### 梯度及剩余边界

两个负漂移配置（确定/Erlang）和一个正漂移Erlang配置中，五参数积分解析梯度与中心有限差分的最大归一误差为 **4.185e-10**。这是常参数期望统计的局部梯度核验，不是训练接口、网络长期梯度或事件样本路径梯度。

该模块没有验证移动边界、输入依赖漂移、多单元耦合或任务学习；这些应继续使用对应模型及其单独证据。新结果关闭的是“缺少独立连续再生参照及等待规律反例”的核验缺口，并没有消除已量化的粗网格误差，更没有建立 HCSN 的任务优势。
