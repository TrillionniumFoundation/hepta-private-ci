## 不修改失败与原始门槛

梯度检查保留两次失败的逐项结果与最差点见证，没有继续缩小步长直到通过；完整扰动数组未运输，逐标量复算需要确定性重跑。内容实验在任何确认前冻结模型、选择阈值和 OOD 阈值；reverse 与 lag2 不用于拟合或校准，未因失败修改模型或重开确认。所报分组 bootstrap 上界是注册的经验判断，不是分布无关的有限样本保证。成本实验保留数组存储次序改变造成的末位值差，最终候选恢复与 R18 相同的 C 连续布局；1,152 个直接值比较及原始执行记录支持精确行为一致。

成本冻结协议误写“所有查询边界 fsync”，独立审查发现实际继承实现只在第三次查询 `query==2` 写盘并恢复。原协议不修改，`ERRATA.json` 明确 `literal_all_query_fsync_requirement_met=false`。本轮成本结果仅适用于这个已有查询边界；暖态分配和串行 actor 吞吐的测量范围也单独声明，不当成每臂进程 RSS、完整部署吞吐或设备焦耳。
