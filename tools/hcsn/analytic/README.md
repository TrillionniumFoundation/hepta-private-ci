# He–Xiong (2012) 全模型解析复现与独立数值核验

本目录实现 **He & Xiong, “Rollover Risk and Credit Risk,” The Journal of Finance 67(2), 391–430 (2012)** 的债券价值式 (8)、首达函数式 (9)、内生违约边界式 (12)，以及附录股权价值式 (A7) 和其辅助函数 (A5)。这套实现保留有限债务期限、再融资损益、内生违约边界和流动性溢价；没有用永续简化算子替换原文全模型。

**本次运行全部验收通过。** 26 组参数的显式边界与独立积分求根最大差为 `2.672e-12`，股权价值最大差为 `8.509e-10`；独立债券 PDE 的网格误差呈约二阶收敛。结果证明本目录的金融解析基础在已测范围内数值一致，并不证明神经网络的性能或规模扩展优势。

## 3. 模型与完整公式对应

原文风险中性资产过程为

\[
dV_t=(r-\delta)V_t\,dt+\sigma V_t\,dW_t.
\]

债务按期限均匀滚动更新，总票息为 \(C\)，总本金为 \(P\)，初始期限为 \(m\)，每单位债务的票息与本金为 \(c=C/m\)、\(p=P/m\)。以下用 \(\lambda=\xi k\) 表示流动性溢价，\(R=r+\lambda\)，用 \(\pi\) 表示税收收益率；代码对应 `liquidity`、`tax`。

设 \(b=V_B\)、\(x=\log(V/b)\ge0\)，并定义

\[
a=\frac{r-\delta-\sigma^2/2}{\sigma^2},\quad
z=\sqrt{a^2+2r/\sigma^2},\quad
\widetilde z=\sqrt{a^2+2R/\sigma^2},\quad
\eta=z-a>1,\quad\gamma=z+a>0,\quad s=\sigma\sqrt m.
\]

为了简写，令

\[
q=p-c/R,\qquad Q=(1-\pi)C+(1-e^{-Rm})q.
\]

### 3.1 首达函数与债券价值：式 (8)、(9)

对 \(s_\tau=\sigma\sqrt\tau\)：

\[
F(x,\tau)=\Phi(-x/s_\tau-a s_\tau)
+e^{-2ax}\Phi(-x/s_\tau+a s_\tau),
\]

\[
G(x,\tau)=e^{(-a+\widetilde z)x}\Phi(-x/s_\tau-\widetilde z s_\tau)
+e^{(-a-\widetilde z)x}\Phi(-x/s_\tau+\widetilde z s_\tau).
\]

这里 \(F=\Pr(\tau_b\le\tau)\)，\(G=\mathbb E[e^{-R\tau_b}\mathbf1_{\tau_b\le\tau}]\)。因此 \(0\le G\le F\le1\)。债券价值为

\[
d(x,\tau;b)=c/R+e^{-R\tau}q[1-F(x,\tau)]
+(\alpha b/m-c/R)G(x,\tau).
\]

边界 \(d(0,\tau;b)=\alpha b/m\)，到期存续值 \(d(x,0;b)=p\) 对 \(x>0\) 成立。角点 \(x=\tau=0\) 按立即违约处理；这个角点本身存在不相容的初值/边值，因此 PDE 使用 Rannacher 启动。

### 3.2 显式违约边界：式 (12)

定义

\[
B(y)=\frac{\Phi(ys)-e^{(z^2-y^2)s^2/2}\Phi(-zs)}{z+y}.
\]

原文小写辅助函数在所需的 \(y=\pm a\) 上等于 \(e^{-Rm}B(y)\)。完整边界为

\[
b=\frac{Q/\eta+q e^{-Rm}[B(-a)+B(a)]+(c/R)[B(-\widetilde z)+B(\widetilde z)]}
{\delta/(\eta-1)+(\alpha/m)[B(-\widetilde z)+B(\widetilde z)]}.
\]

代码直接计算此式，没有用数值求根结果替换解析边界。数值参考单独从平滑贴合条件求根。

### 3.3 股权价值：式 (A5)、(A7)

定义完整的 A5 辅助函数

\[
\begin{aligned}
K(x;a,y,\beta)={}&[\Phi(ys)-e^{((\beta-a)^2-y^2)s^2/2}\Phi((\beta-a)s)]e^{-\beta x}\\
&+e^{((\beta-a)^2-y^2)s^2/2-\beta x}\Phi(-x/s+(\beta-a)s)\\
&-e^{-(a+y)x}\Phi(-x/s+ys).
\end{aligned}
\]

\(k(x;a,y,-\eta)\) 是将上式取 \(\beta=-\eta\) 后删除第一行所得的函数。再令

\[
A_x(y)=\frac{K(x;a,y,\gamma)+k(x;a,-y,-\eta)}{z-y}
+\frac{K(x;a,-y,\gamma)+k(x;a,y,-\eta)}{z+y}.
\]

则原文 A7 是

\[
\begin{aligned}
E(x)={}&b e^x-\frac{\delta b}{z\sigma^2}\frac{e^{-\gamma x}}{\gamma+1}\\
&-\frac{Q}{z\sigma^2}\left[\frac1\eta+\frac{1-e^{-\gamma x}}\gamma\right]\\
&+\frac{e^{-Rm}qA_x(a)-(\alpha b/m-c/R)A_x(\widetilde z)}{z\sigma^2}.
\end{aligned}
\]

`hx_precision.py` 直接写出以上 \(K,k,A\)；`hx_model.py` 对同一式子进行等价项合并以避免指数与尾概率相乘产生溢出。二者分别与数值 ODE 解比较。

股权 ODE 及边界为

\[
\tfrac12\sigma^2 E_{xx}+a\sigma^2E_x-rE
+\delta b e^x-(1-\pi)C+d(x,m;b)-p=0,
\qquad E(0)=E_x(0)=0.
\]

这里的 \(E_x(0)=0\) 与 \(E_V(b)=0\) 等价，因为 \(E_x=VE_V\)。

## 4. 数值稳定性：实际遇到的问题与修复

1. **零流动性导致的可去奇点。** 当 \(\lambda=0\) 时 \(\widetilde z=z\)，\(B(-z)\) 和 \(A_x(z)\) 字面表达式包含 \(0/0\)。实现使用真正极限，例如 \(B(-z)=s\phi(zs)-zs^2\Phi(-zs)\)。对极近的两点，用分子导数的积分表示除差，在极短区间上做八点 Gauss 积分；精确极点取 l’Hôpital 极限。没有设置人为流动性下限。

2. **指数溢出与正态尾下溢同时发生。** 实现通过 `log_ndtr`、`expm1` 和尾概率差计算 \(e^u\Phi(v)\)，避免先计算巨大指数再乘数值零。\(\eta,\gamma\) 用有理化根计算；\(\delta/(\eta-1)=\frac12\sigma^2(\gamma+1)\) 避免 \(\delta\to0^+\) 时的消差。

3. **股权边界处二重零的消差。** \(E(0)=E_x(0)=0\)，因此真实价值为 \(O(x^2)\)，而 A7 各项可能很大。`equity` 在 \(x<\min(10^{-4},10^{-3}\sigma\sqrt m)\) 使用从 ODE 推导出的四阶 Taylor 多项式。这是明确的局部数值近似，并非修改经济模型；`taylor_overlap_checks` 与 60 位精度原式核验接缝附近误差。五组重叠检查的公开接口最大误差为 `1.106e-9`。

4. **极短债务期限。** 在 \(m=10^{-8}\) 时，双精度 A7 的选点最大误差为 `4.601e-6`，且在极近边界处可能出现消差导致的微小负值。`m<1e-4` 时采用 60 位精度的原式和显式边界，再转为浮点输出。该分支不是适合直接大规模 GPU 训练的实现；后续需要专门的渐近展开、可微核或受控参数范围。

5. **独立积分也可能失败。** 未拆分的自适应积分曾在 \(m=10^{-6}\) 时错过极窄的边界层，将边界算为约 34.10；正确值是 102.74251657。参考积分现在按 \(s,4s,12s,|a|s^2+12s\) 拆分区间，并得到高精度原式和 BVP 的交叉支持。不能把任意数值参考自动视为真值。

6. **BVP 容差与网格过度细化。** \(m=0.01\) 下直接要求 `tol=1e-8` 曾在 \(x\approx0.0559\) 附近达到节点上限。参考求解器使用解析 Jacobian 和 `tol=1e-7`，再用独立的价值、边界、导数误差阈值验收。没有声称失败的更严格局部容差已收敛，也未放宽最终价值验收阈值。

## 5. 三条独立数值路径

**股权 Green 积分与未知边界求根。** 对线性 ODE 写出吸收 Green 核，只对衰减的债务部分积分；线性增长的现金流和常数成本单独解析处理。边界由 \(E_x(0;b)=0\) 的数值积分方程用 Brent 法求解，不使用式 (12)。此法不调用 A7。

**自由边界 BVP。** 将 \(b\) 作为未知参数，与 \(E,E_x\) 同时用 collocation 求解。三个条件为 \(E(0)=0\)、\(E_x(0)=0\)，以及远端渐近 Robin 条件。初值采用基于本金的粗猜测，没有用解析 \(E\) 或解析 \(b\) 作为初值。

**债券 PDE。** 独立离散 \(d_\tau=\frac12\sigma^2d_{xx}+a\sigma^2d_x-Rd+c\)，使用 Crank–Nicolson、四个半步隐式 Euler 启动和三档网格。该路径不使用闭式债券值作为内点源或初值。

独立性的范围应明确：股权 Green/BVP 使用式 (8) 作为债务强迫项，因此还需债券 PDE 单独核验式 (8)；这些并非三个完全不同经济模型。60/90 位原式计算是额外的数值审计，不计为独立 ODE 模型。

## 7. 对 HCSN 下一阶段的明确接口与限制

`HXModel` 输出 `boundary`、`equity(x)`、`first_hit(x,horizon)` 和 `debt(x)`，可作为完整金融模型的数值基准。这里的 \(x\) 始终是 \(\log(V/V_B)\)，不能直接当作未经换元的电压差使用；对物理电压或资产值的导数需要链式法则。

原文中的 \(E\) 可以作为具有平滑贴合的 call-like 通道。\(F,G\) 是首达概率与贴现首达概率，**原文没有给出另一个同时满足相同平滑贴合条件的独立 put 神经元算子**。一般 \(F(0)=1\) 且 \(F_x(0)\ne0\)，把违约区延成常数 1 不会自动成为 \(C^1\) 函数。\(E\) 在违约区延成 0 则是 \(C^1\)，通常不是 \(C^2\)。这会影响跨边界梯度的定义。

本目录实现的是稳态估值及参数到自由边界的映射。连续神经状态的恢复、再生、适应、刺激耦合和重置机制需要另行定义并验证。通过有限差分核验参数导数，不等于已经实现 PyTorch/JAX 自动微分；`mpmath` 极短期限分支尤其不能直接作为高速可微训练内核。

支持域明确要求 \(r,\delta,\sigma,m>0\)、\(\lambda\ge0\)、\(0\le\alpha,\pi\le1\)，且至少一种债务负债为正；无意义的非正边界会报错。精确的 \(\sigma=0\)、\(\delta=0\)、超出已测范围的组合、任意巨大 \(x\)、经济可行性和全局单调性没有被本次测试证明。代码没有擅自把回收值截断到本金；JSON 记录了 `recovery_exceeds_face`，当前测试均为 false。

原先简化 HCSN 算子保留在项目原位置用于消融，不应与本目录全模型混用。只有在后续神经动力学、同预算序列任务和冻结 encoder 实验提供实证后，才有依据判断完整 HCSN backbone 的训练价值。
