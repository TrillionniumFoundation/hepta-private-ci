# 新确认的独立数值复核

**16 个注册 fit 均成功；八项主效用门槛均未通过。** 每项 Bonferroni 校正区间都同时包含 0 和 +0.02，本轮没有确立相应机制的实际效用收益，也没有确立损害或等效。点估计不能替代注册判据。

## 核对范围与精度

冻结分析器和独立复算进程均返回 0。独立脚本没有导入 `analyze.py`、模型或任务模块，而是流式读取原始 episode，核对终止状态、真实 evaluator 标签、奖励减去全部已付成本的效用，以及完整世界配对和汇总。

- 153,600 个 episode、3,072 个不同 fit/world、808,200 次决策。
- 1,600 个 fit × split × candidate × controller 均值组，44,800 个汇总指标均值。
- 22,329 个 cohort 文件哈希；全部 16 个 STARTED 均引用同一已发布模型和 seal，且晚于确认启动记录。
- 1,596,143 次数值比较，**超出容差的不一致为 0**。最大绝对浮点差为 `2.2737367544323206e-13`；使用绝对容差 `1e-12`、相对容差 `1e-10`。这是声明容差内的复现，不是逐 bit 数值相等。

## 八项注册主对比

每项均使用 16 个独立 fit 的配对差，df=15；双侧 Bonferroni8 区间的 t 临界值为 3.177104299728672。收益门槛为区间下界严格大于 +0.02。

| 主对比 | IID 效用差及校正区间 | OOD 效用差及校正区间 | 门槛 |
|---|---:|---:|---|
| 终止结构：五个继承模型族 S0−F0 的平均 | +0.000714 [−0.062599, +0.064027] | +0.024647 [−0.017348, +0.066642] | 两域均未通过 |
| 访问状态监督：FPT S1−S0 | +0.018674 [−0.094521, +0.131868] | +0.055553 [−0.044684, +0.155791] | 两域均未通过 |
| 单次注入：FPT I1−S1 | +0.012137 [−0.084502, +0.108776] | −0.027786 [−0.106555, +0.050982] | 两域均未通过 |
| 解析增量：FPT S1−ordinary_bank S1 | +0.005993 [−0.098711, +0.110697] | −0.027474 [−0.128084, +0.073137] | 两域均未通过 |

F0=free_off，S0=structured_off，S1=structured_on，I1=impulse_on；全部主对比使用 value 控制器。新 accumulator 缺少 S0，不能将其 F0→S1 差值称为孤立的终止结构效应。确认规模的开发规划分别要求 47/72/76/328 个 fit；资源上限为 16，不能声称达到规划的 80% 功效。

## 实际成本与预算限制

| 注册工作进程范围 | 完整 OS wait4 CPU 秒 |
|---|---:|
| 正式训练 16 fit | 8,263.862734 |
| 新确认 16 fit | 2,352.672202 |
| 开发：3 个成功 fit 与保留的 3 个失败尝试 | 1,962.036354 |
| 以上 38 个进程合计 | **12,578.571290** |
| 冻结分析器，另列 | 30.714385 |
| 独立复算器，另列 | 28.159185 |

训练候选、诊断和模型执行时间是工作进程总量的内部拆分，不能重复相加。以上不是整个项目全部操作的总量；原生验证、保留信息探针、传输和恢复等由各自外层凭证另列。CPU 时间也不是并行墙钟总时长或硬件能耗。

**名义 16 CPU 秒面板没有实现严格相同的实际 CPU 时间。** 普通 bank、FPT 持续驱动、FPT 单次注入和 accumulator 的平均学习 CPU 分别为 16.030454、16.649731、16.967779、16.004882 秒；最大值分别为 16.077039、24.671916、29.936920、16.014454 秒。两个 FPT 候选的最大超额分别为 8.671916 和 13.936920 秒，必须随质量结果一起报告。

Bayes/fixed 路径在选择固定动作前还计算了未被固定控制器使用的 `oracle.q`，其 CPU 是未优化参考实现的执行成本。训练摊销、部署复用次数和能耗均未确定；没有完整成本优越性结论。
