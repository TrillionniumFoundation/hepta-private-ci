# 四项机制实验：冻结确认结果与边界

**本轮尚未建立可推广的效用或完整成本优势。八个主终点均未达到“调整后区间下界超过 +0.02”的验收标准。** 已确认的是终止输出约束、受控信息探针和独立有限动力学实现各自的性质；这些证据不能合并成六类模型全面通过或某一机制优越的结论。

源码、主终点及 384 个正式模型先冻结，再生成新的 IID/OOD 世界。每个 fit 各有 96 个 IID、96 个 OOD 世界，共 3,072 个 fit/world；24 个候选及 Bayes 参考分别执行 fixed/value，合计 153,600 次执行。**统计单位为 16 个独立 fit，不是执行次数或决策数。** 效用为终止奖励减实际读取、修复及时间成本；任务仍是合成内容经真实文件读取和冻结 FullHX 处理的有限任务。[协议](protocol.json)｜[模型封存](SEALED_MODEL_FREEZE.json)｜[来源复核](evidence/MODEL_PROVENANCE_REVIEW.json)

## 一、主确认结果

四个对比均使用 value 控制器：终止结构为原五家族 `structured_off − free_off` 等权平均；走访监督为 first-passage 的 `structured_on − structured_off`；输入机制为其 `impulse_on − structured_on`；解析增量为 `first_passage_bank − ordinary_bank`，两者均为 `structured_on`。

| 预先声明的对比 | IID 效用差［调整后区间］ | OOD 效用差［调整后区间］ |
| --- | ---: | ---: |
| 终止结构 | +0.000714［−0.062599，+0.064027］ | +0.024647［−0.017348，+0.066642］ |
| 走访状态监督 | +0.018674［−0.094521，+0.131868］ | +0.055553［−0.044684，+0.155791］ |
| 单次注入机制 | +0.012137［−0.084502，+0.108776］ | −0.027786［−0.106555，+0.050982］ |
| 解析增量 | +0.005993［−0.098711，+0.110697］ | −0.027474［−0.128084，+0.073137］ |

区间按独立 fit 的配对差使用 Student t，df=15，Bonferroni 校正八项，总体 α=.05，临界值 3.177104；仍依赖独立 fit 差值的 t 模型假设。八个区间都包含 0 和 +.02，因此既未确认实用收益，也不能据此证明有害、无效或等效。三次 DEV fit 给出的正态近似需求为 47、72、76、328 个 fit；预先声明的资源上限把正式样本限制为 16。标准差乘 1.25 只是启发式，不是方差置信上界，本轮不声称达到 80% 功效。[主分析](evidence/CONFIRMATION_ANALYSIS.json)｜[独立复算](evidence/CONFIRMATION_REVIEW.md)｜[样本规划](evidence/fit_planning.json)

## 二、终止结构、校准和实际控制

结构头只学习 WAIT、READ、REPAIR 和 belief logit，并展开为

\[
Q_{\mathrm{STOP}}=0,\qquad Q_{\mathrm{SUBMIT}_1}=2b_\theta-1,\qquad
Q_{\mathrm{SUBMIT}_0}=1-2b_\theta.
\]

正式执行中的结构残差为零，保证了相对于模型自身 belief 的终止排序；**它不保证 belief 正确、续行价值正确或实际效用提高。** 原五家族结构对比的 wrong-stop 点变化为 IID −.169、OOD −.273 次/百次执行，wrong-submit 为 +1.68、+1.42 次/百次执行。这里 wrong-stop 指选择 STOP 且拟合任务 oracle 的最优 Q>.02；wrong-submit 指提交且 oracle 最优 Q 与所选 Q 的差>.02。两者是教师 Q 遗憾诊断，不是直接按真实标签统计的分类错误。

下表均为 240 次更新、结构头并启用走访监督；数字是 16 个 fit 的等权均值，属于描述性面板。fixed/value 使用同一已训练模型。执行 CPU 含运行时初始化摊到本批世界、真实内容读取、状态推进、终止标签读取及评分；教师诊断另计，模型载入与共用准备留在整进程成本中。

## 三、记忆、持续输入与事件信息

持续驱动重复使用最后观察；单次注入在 READ 完成时注入，并同时中和后续区间 drift 与 bank 的未来 driver 特征。**其主对比是整个已声明输入机制的干预，无法单独归因于 drift。** accumulator 只汇总实际已读证据并显式保留时间；它的 `free_off → structured_on` 同时改变输出头和走访监督，不能充当第六家族的纯结构效应。

预先发布的拟合后探针覆盖 96 个模型、480 条记录：一次可靠度 .85 的观察、平衡类别、没有新 READ，各观察条件下分别传播后再混合。时间 3 的 cell 内最优分类准确率为：

| 家族 | 持续驱动 | 单次注入 |
| --- | ---: | ---: |
| ordinary bank | .827680 | .651175 |
| clocked bank | .833112 | .654180 |
| first-passage bank | .831129 | .654629 |

时间零时单次注入已携带观察，持续驱动尚未积累；长时间持续驱动又不断引入公开观察，不能把差异只解释为无输入时的记忆保持能力。在同一“最后区间发生新事件”的 first-passage 持续驱动条件群体中，最优准确率为：区间起始源状态 .820751、事件符号 .847322、拟合有符号 reset 后 .838841、强制相同 reset 后 .502631。相同 reset 仍可略高于 .5，因为事件选择改变了类别先验。源状态到符号增加的信息可以来自持续 driver；只对同一条件群体上的符号擦除/reset 映射施加数据处理约束。实际 head 仍能看到公开末次观察和时间，cell 内信息损失不等于整个策略的信息损失。此前初始化 cell 的探针与这些拟合参数结果分别保留。[拟合后信息报告](evidence/TRAINED_RETENTION_REVIEW.md)

这测量现有训练读出器，尚未独立训练最优 decoder；时间、任务标志、bank 特征及轨迹选择仍混杂，不能解释为事件/reset 的因果效用。[实际读出审计](evidence/ACTUAL_READOUT_REVIEW.md)

## 四、动力学语义验证与主任务分开

主效用实验沿用原 17 状态有限区间过程，每个区间至多一次新事件、区间末恢复。新增连续时间有限 CTMC 则独立处理首次事件、事件后的剩余时间、重复 renewal，以及 checkpoint 中的绝对待执行跳转时间、目标、RNG 和恢复状态。它不是精确 Brownian 过程，也未替换主任务的转移律。主任务效用、独立 CTMC 分布检验和原生恢复一致性分别验收，不能通过增加网格或直接移植物理参数而视为同一过程已验证。

预测检查在恒定未来输入 μ=.355、五个期限 .25/.75/1.5/3/6 下各采 12,000 条独立路径。reset-aware 六类别预测的最大校准差为 .0026–.0093，free Gaussian endpoint 为 .0757–.7733；期限 3 的六类别 Brier 为 .7883 对 1.2716。这是已声明 CTMC 真值下的语义对照，差异同时含离散传播和 reset/refractory，不能单独归因于 reset，也不是训练后预测器的外部校准；同转移律的通用 CTMC/HMM 可得到相同预测。[预测证据](evidence/forecast_comparison.json)｜[语义](RENEWAL_SEMANTICS.md)

封存后原生运行完成 16 fit×8 情形=128 条轨迹、384 个独立进程；60 条发生多次事件，共 226 个有符号事件。切点含 87 个 active、25 个下侧和 16 个上侧 refractory；完整运行与切开恢复的最终输出、checkpoint 和拼接事件轨迹逐字节一致。这支持所声明有限过程的恢复一致性，尚不包含生产 ACK owner、崩溃原子提交、跨架构确定性或任务效用迁移。[原生结果](evidence/NATIVE_CONFIRMATION_SUMMARY.json)

## 五、容量、预算与完整成本口径

## 六、后续只在开发阶段推进

1. 保留终止结构这一语义不变量，先改善 belief、续行 Q 与校准，再评价效用。
2. 用多轮最终策略走访替代单次中途快照，预先声明所选 Q 误差、margin 与效用的联合验收。
3. 拆开 impulse 的 drift/bank driver 因子、事件符号和 reset；补全六家族的输出头×走访监督对照。
4. 使用有界或可中断的采集/checkpoint，声明超支容差，实现可核验的实际 CPU 匹配。
5. 用开发阶段独立 fit 差值规划新样本数，再冻结新版本与新确认；本次确认继续只作为本次证据。
