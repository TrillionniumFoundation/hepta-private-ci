# R20：固定网格的真实动作平局、方向导数与求解器修复

本轮实现并验证了一个此前缺失的合同：固定网格障碍问题在真实动作平局
处的单侧方向导数。它还找到了并修复了浮点平局下策略标签循环、正确
数值解却不能退出的实际求解器缺陷。**非恒定任务的严格有限步差分门
仍失败，完整金融／神经梯度没有闭合。**

基线为 `ede941c81edaf246486c88725a8a921bf70279ec`。V1 源码与协议
先发布到 `ce6d07d5f1e4210e8c1ade9846dd4e5cd89038ce`；保留失败后，
只有混合互补求解器的退出条件发生修复。V2 在
`d0acb8d41a9b7682d22f606998c4e04fe4093e6c` 另行冻结，使用完全相同
方向名册、差分步长和验收阈值重新验证。这是修复后的同名册工程复核，
不冒称新的独立样本，也不追认 V1 通过。全部 V1 源码另存 `source_v1/`。

## 实际改变

对 `min(v-o,Av-b)=0`，严格 WAIT 行满足 `A z=db-dA v`，严格障碍
行满足 `z=do`，真正双活跃的平局行满足

`min(z-do,Az-(db-dA v))=0`。

R20 求解这个混合互补系统。STOP／RESET 障碍及新恢复动作准入时刻
的 max 平局都采用两条方向斜率的最大值。每次调用返回一个方向的响应，
不把这些非线性响应拼成一个处处有效的普通 Jacobian。正恢复滞后保证
后继已计算，准入左极限继续使用此前左后继，右 RESET 使用右后继。
独立数学审阅给出 M-matrix 唯一性及实数算术中的残差比较界。

V1 在对立奖励方向的真实准入平局上发生 256 次策略标签循环；终止时
实际混合残差只有 `2.7756e-17`。V2 对全部适用约束检查残差后退出：
强制等式、强制接触和双活跃 min 行都计入，稳定标签但残差过大则拒绝。
这个修复没有放宽原 `1e-10` 代数验收门，也没有再缩小差分步长。
`V1_CYCLE_DIAGNOSTIC_NOTES.md` 和独立 `V2_SOLVER_REVIEW.md` 记录
具体缺陷、修复和误差边界；浮点残差不是区间算术证书。

## 单列的非恒定任务挑战仍失败

在冻结前另登记三个新非恒定配置：sigma／重置位置分别为
`.82/.57`、`1.17/.73`、`1.53/.91`。每个配置对全部 13 个系数同时
尝试正、负单位方向，固定网格 `.2/.02`，单侧步长固定为 `1e-4`、
`3e-5`，严格比较门仍为 `1e-6`。每条尝试都保留。

V1 与 V2 都完成 **78/78** 个方向。V2 只有 **30/78** 案例同时通过
两个步长及原值一致性；单项差分为 **71/156** 通过。最大有限步导数
差为 **1.27111918**，因此该门保持失败。这三个配置中 13/13 个系数
都产生了非零响应，弥补恒定域的“算子方向一阶静默”观察范围，但它们
并未通过通用梯度资格。有限扰动跨动作分支、非线性截断误差及数值
分类需要分别研究；这里没有把每项失败都归因于局部导数公式错误。

浮点分类没有报告未决行，不代表已经获得向外舍入的精确分支证书。
`generic_math_qualification=false` 始终明确保留。R19 原门及其更小
步长补充的失败也由输入哈希和实际 `passed=false` 绑定，完全不变。
