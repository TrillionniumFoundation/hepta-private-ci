# 可证明的编辑子问题与尚未证明的策略能力

本文件给出从现有模型结构直接推导的设计判断。它不增加新的实验样本、显著性检验或成功候选。实测依据始终是冻结的 [RESULTS.json](ndu_policy/execution_r1/run/RESULTS.json)。

## 1. 原始权重不能独自确定语义坐标

考虑 `f(x) = W2 tanh(W1 x + b1) + b2`。对任意隐藏单元置换矩阵 P，

```text
W1' = P W1, b1' = P b1, W2' = W2 P^-1
```

给出完全相同的函数。利用 tanh 的奇函数性质，符号翻转与置换也能构成等价参数化。因而“第 k 个 neuron 表示什么”不是脱离结构、输入坐标与 decoder 后唯一可识别的事实。对于带 ReLU 的相应网络，还存在正尺度重参数化。

这不是说 Agent 无法理解权重，而是说明它应提出可检验的机制假设：指定网络结构、输入/状态 schema、张量轴、观测完成顺序与输出解释，再定位可干预的参数块，并以执行后的行为证伪假设。一个未绑定单位和事件的权重向量不能自动获得 First-Passage 或 Call/Put 语义。

本轮 C、D、G、DQ、DB 保持解析 core 不变，P 只替换 terminal posterior，J 则把完整未来决策接到同一自身 law。J 的主要收益门通过，不能由此推断某个内部物理参数已经被纠正。J−P 没有预定主要检验；不能在看到表格后另立一项成功资格。

## 2. 代理误差与 argmax 价值之间缺少单调关系

以下只是数学反例，不是实测 Hepta 数据。假设同一状态下真正的两个动作值是 `[0.501, 0.500]`。估计 `[1.501, 1.500]` 有很大的共同偏移，却选对动作；估计 `[0.499, 0.500]` 的均方误差小得多，却选错动作。MSE 的下降本身不能作为策略收益的接受门。

在一个已声明、有限期限、完全包含合法动作与费用的模型中，若所有相关状态动作满足

\[
\|\widehat Q-Q^*\|_\infty\le\varepsilon,
\]

并且每次用同一合法性与 tie 规则选择 greedy 动作，则每一步相对最优动作的 Q regret 至多 `2 epsilon`。最多 H 次决策时，标准逐步分解得到模型内价值损失至多 `2 H epsilon`。这里要求的是覆盖相关状态动作的统一误差；平均 TRAIN MSE 不提供这个条件。

更强的动作保持条件是：某状态最优与次优动作间隔大于 `2 epsilon`。这可以直接指导编译验收，把动作边际和近 tie 状态单列。精确 tie 必须保留约定的第一个合法最大值；不能为了让 native migration 通过而增加数值宽容的 tie 规则。

这些界只相对指定 law 的 `Q*`。自身 law 与实际环境的差异、未观察状态、真实 CPU 经济成本和执行失败没有被该推导消除。当前记录的 KKT 残差也不是统一 Q 误差的严格上界。

## 3. 参数范数可以约束输出，但通常不足以保持策略

本轮隐藏层为 48 维 tanh。附加常数 bias feature 后，理想实数语义下

\[
\|\tilde h(s)\|_2\le\sqrt{48+1}=7.
\]

因此一个 continuation 行的编辑满足

\[
|\Delta Q_j(s)|\le7\|\Delta\theta_j\|_2.
\]

Belief 使用 sigmoid，导数上界为 `1/4`，两个 terminal reward 为 `±(2p−1)`，所以其改变可界为

\[
|\Delta Q_{\rm terminal}(s)|\le3.5\|\Delta\theta_{\rm belief}\|_2.
\]

这些是固定表示、理想算术下的保守界，不是本次完整程序的已执行证书。实际写入、参数量化、隐藏层计算和输出舍入需要另加误差分析。Rust 的精确 F32 改变量判定只证明指定半径内的参数可行性；它不会自动证明动作保持。

即使半径判定精确，如果任务的动作边际很小，允许的输出变化仍能改变读数、等待、修复与停止，从而改变未来访问分布和费用。真实收益 gate 必须覆盖整个策略轨迹。

## 4. 下一种编译目标应回答的具体问题

当前结果排除了“把本次同一 MSE 问题求得更精确，就已经证明任务改善”的叙事；D 与 G 都达到各自冻结的数值停止门，任务价值都失败。它没有排除其他可行参数或不同的代理目标。

后续值得检验的、尚未执行的方向包括：在固定完整 TRAIN 状态上显式保持 teacher 的合法动作边际；对策略会访问的状态和 costly mistakes 赋予可解释权重；在量化后的实际 decoder 下验证 Belief 与 continuation 的交叉不等式；或扩展表示/保留结构 planner，避免把完整程序硬压进原头部。

这些必须另立候选与协议，使用未用于选择的新场景；不能把当前 TEST 再叫作新 holdout。若一个参数类被严格不可行证书排除，才可停止该类的等价训练搜索。当前有限状态 MSE 解和五 fit 结果没有给出任意头部的普遍不可行证明。

### 策略空间的全局解不是权重空间的全局解

对声明的有限 DAG，可用状态动作 occupancy `d(s,a)` 写出流量守恒：

\[
\sum_a d(s,a)=d_0(s)+\sum_{u,b}d(u,b)P(s\mid u,b),\qquad d(s,a)\ge0.
\]

最大化 `sum d(s,a) r(s,a)` 是线性规划；有限期限 Bellman 递归是这个已知模型决策问题的另一种求解方式。它允许各状态自由选择合法动作，没有要求所有选择能由同一个神经参数向量实现。

若要求部署原神经头，还必须加入：占用正质量的被选动作满足实际 `argmax f_theta(s)`，包括合法性、精确 tie 规则和同一组参数在所有状态间的共享。固定特征、纯线性分数及已知有限参数界可以用离散动作变量与有界条件不等式表达部分约束；当前 terminal reward 又含 sigmoid，仍需非线性处理或有证书的分段界。这不再是上述简单策略 LP，也不能由一个低 MSE 的 ridge 解自动满足。

因此，“用 NDU 全局目标规划权重”可被形式化，但一般会付出离散搜索、表示验证和环境模型误差的成本。本轮没有执行这个完整混合优化问题，也没有证明其比梯度训练便宜。当前可独立验收的是局部凸子问题、精确参数预算、有限模型策略及最后的任务价值门；把这些边界显式化，比在接口中写一个未经证明的 global-optimal 标志更有用。

## 5. 当前原生子系统的清晰边界

Agent 负责读取已授权的模型与执行语义、提出机制和编辑目标。Rust 接口负责有界数值规划、实际参数身份/范数检查、隔离候选、实际 forward 与保留门、持久化意图及明确的失败恢复。这个职责划分使 Agent 的判断可以被执行结果否决。

原生 Bellman 接口只解调用方提交的有限 DAG。checkpoint 与世界到 DAG 的语义绑定仍由公开的导出和独立桥接验收完成，不能把 `checkpoint_verified=false` 改名成 Rust 已读取并理解任意 checkpoint。guard 的恢复也限于隔离工件；研究候选被保留不代表已安装或成为真实交易的效力来源。
