# 独立实验审查：序列与冻结 encoder

审查日期：2026-10-30。审查范围为 `benchmarks/` 的 v1/v2 模型、数据生成、训练、评估与结果，以及 `encoder/` 的冻结 MiniLM 特征准备、分类 Head 和结果。仅阅读实验文件、重解析已有数据，并执行初始化、边界导数和三个更新步骤的定位探针；没有重跑完整训练，也没有修改他人实验代码。本文件记录发现时的状态；修复后的元数据以主代理最终提交为准。

## 结论

没有发现使现有分类准确率失效的直接 train/test 数据泄漏。数据来源、句子级标签、训练集拟合 PCA、validation 选择 checkpoint 的实现与所述小型实验基本一致。实验证据支持这些新增神经模型可以通过普通离散 BPTT 训练，尚不支持解析门控优于普通 sigmoid 门控，也不支持推进完整语言/多模态 backbone 的优势主张。

现存训练时间字段不适合速度排名：首次更新之后仍可发生 JIT 编译，且不同 run 是否命中缓存不一致。保留原始时间并统一标明这一限制即可，无需为此重跑训练。

## 数据、标签与预处理核验

使用缓存的三个 SST parquet 文件独立读取 `ptb_tree`，并将解析结果与保存的 manifest 对照。原始行数为 train 8544、validation 1101、test 2210；仅去掉中性根标签后，二分类候选数分别为 6920、872、1821。实验选中的 1600/400/800 条分别为 800/800、200/200、400/400 的正负平衡子集。

- 选择记录中的原始行号、标签和归一化文本摘要与重新解析结果全部一致，没有空文本。
- 对全部 11855 棵树另做递归 PTB 叶子解析；仅有 3 条训练句子的原始字符串空白表现不同，归一化后相同，且这 3 条均不在选中子集中。没有发现标签或文本语义解析差异。
- 每个所选 split 内归一化文本唯一；三个所选 split 的两两摘要交集为零。这不构成近重复或预训练污染审计。
- PCA 的均值、协方差、主成分和尺度只从训练特征拟合，没有使用 test 特征或标签；所有 Head 共用同一特征文件。训练函数只接收 train/validation，checkpoint 仅按 validation loss 选择。
- 特征文件训练前后 SHA 相同：`970c2c56442dc7deaa0e1db98f78b12ab0254a5fae2d45923852055252286a8a`。
- 缓存 NPZ 中三个 split 的标签逐项匹配 manifest，差异均为零；所有缓存特征均为有限数。
- 原始 encoder 预训练数据与 SST 的交集未审查。准确措辞是“Head 训练的 holdout”，不是 encoder 从未见过数据。

这应称为**来自官方句子 split 的平衡二分类 SST 子集**，不直接等同完整 SST-2 标准成绩。

48-token 截断影响 train 的 36/1600 条、validation 的 12/400 条和 test 的 21/800 条。12 个局部块中平均完全为空的块数分别为 5.44875、5.3625、5.22125。Head 没有接收对应的 padding mask；空块经过 PCA 后是固定向量，所有动态层仍推进 13 个等间隔步骤。这对所有 Head 一致，但限定了序列动力学的解释：它是固定分块特征处理实验，尚非保留原 token 时间/有效长度的序列 encoder。

## BPTT、边界与“解析算子”的验收范围

实际 JAX 0.4.38 实现中，HCSN 与匹配 sigmoid 在边界均满足 `q(0)=0.5`、`q'(0)=0.5`。未发现边界自动微分取零的错误。`jax.lax.scan` 贯穿整个有限序列，没有 detach 或截断 BPTT，梯度通过离散更新传播。另有 dynamics 模块对独立离散梯度和有限差分的验证结果。

这些训练代码中的 Call/Put 是有界 C1 启发算子，boundary 是学习参数，v2 还依赖当前输入与记忆。每个时间步没有求解原论文的最优违约自由边界；冻结门的指数更新也不是完整非线性 ODE 的精确流。因此，当前训练验收是**新增离散神经模型的可微性与任务表现**，不能替代原论文有限期限价值公式、最优边界及其隐式导数的单独验证。

序列任务未见目标标签泄露到无关输入：memory 的信息来自首个带标记符号，retrieval 来自存储 key/value 与最后 query；irregular 的目标按连续时间指数衰减定义。后者本身偏向相应时间常数归纳偏置，应限制为该合成分布的结果。

## 已观察结果及升级条件

冻结 encoder 的 v1 test 五种子均值为 HCSN 74.70%、sigmoid 74.225%、GRU 75.175%、Transformer 74.525%，线性参考 77.25%。HCSN 对 sigmoid 的逐种子平均差为 +0.475 个百分点、样本标准差 0.899 个百分点，未建立稳定增益。

v2 frozen 的 HCSN 为 76.05%，sigmoid 为 76.575%；HCSN 对 sigmoid 平均差为 -0.525 个百分点、样本标准差 1.459 个百分点。v2 相对 v1 的变化还包含 residual memory 等设计，不应归因于解析门控。所有种子共用同一文本 test 集；种子标准差只描述训练随机性，不能当作总体泛化置信区间。

当前可接受的验收是：代码与数据可追溯，模型可以训练，已记录正反例，普通 q 门控消融没有显示 HCSN 的可靠优势。完整 backbone 的升级条件仍未满足。下一轮若开展，应先固定设计与目标指标，用新 holdout 做完整通道/记忆/边界消融，并对有竞争力的基线做相称调优；只有出现可靠质量优势后，才值得专门重做端到端成本测量。
