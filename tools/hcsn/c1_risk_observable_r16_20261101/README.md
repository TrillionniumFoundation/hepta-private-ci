# 独立候选算子审阅：R = 2F − F² 的跨边界一阶光滑性

状态：数学候选；未改冻结金融核、原门槛或确认结果。本文不是原 put / default 概率公式的重新命名。

## 1. 精确命题

设 theta 属于开集 U⊂R^m，b:U→R 为 C1；续行域为 D+={(V,theta):V>b(theta)}，default 域为 D-={V≤b(theta)}。设 F+ 在 D+ 内为联合 C1，连续延拓至界面，且

\[
F^+(b(\theta),\theta)=1.
\]

要求每个界面点附近的全部一阶偏导数局部有界。一个更强、容易核查的充分条件是 F+ 联合 C1 至续行域闭包，并具有有限连续的一侧梯度。“在每个内点导数有限”不是上述条件。

定义

\[
R(V,\theta)=
\begin{cases}
2F^+(V,\theta)-F^+(V,\theta)^2,&V>b(\theta),\\
1,&V\le b(\theta).
\end{cases}
\]

则 R 在每个满足条件的界面邻域内联合 C1；界面的完整梯度为零。若这些条件在整个考虑域内成立，且续行域内没有其他奇点，则 R 在该域内 C1。这个局部拼接结论不能覆盖未满足假设的参数端点或其他模式切换。

## 2. 严格一阶证明

令 x=V−b(theta)。局部有界的 F_V 与值匹配给出

\[
1-F^+(V,\theta)
=-\int_{b(\theta)}^{V}F_V^+(u,\theta)\,du=O(x),
\]

其中常数可在固定界面点的小邻域内一致选择。对界面点 z0=(b(theta0),theta0) 的扰动 h，b 为 C1 意味着 x(z0+h)=O(||h||)。因此在续行侧

\[
R(z_0+h)-R(z_0)=-(1-F^+(z_0+h))^2
=O(\|h\|^2)=o(\|h\|).
\]

default 侧该差恒为零。故 R 在界面处具有 Fréchet 导数 DR(z0)=0。

续行侧的链式法则给出

\[
R_V=2(1-F^+)F_V^+,\qquad
R_{\theta_j}=2(1-F^+)F_{\theta_j}^+.
\]

这里 F_theta 是固定 V 时的完整导数，包含通过 b(theta) 及其他模型参数产生的依赖；不得擅自 stop-gradient 自由边界。因为 F+→1 且全部一阶导数局部有界，以上偏导数趋于零，与 default 侧及界面处的零梯度连续匹配。证毕。

需要的核心是二阶消失的值差与趋零的完整梯度。F+ 本身不必跨界面 C1。反例也说明边界正则性不能省略：取 b=0、F+(x)=1−sqrt(x)，0<x<1。它在每个正内点 C1、连续趋于1；然而 R+=1−x，与 default 常数1拼接后有斜率−1/0的折角。

## 3. Equity 的条件

设 E+ 联合 C1 至边界，满足所有 theta 下的 value matching 与 smooth pasting：

\[
E^+(b(\theta),\theta)=0,\qquad E_V^+(b(\theta),\theta)=0.
\]

沿边界对参数求导：

\[
0=\partial_{\theta_j}E^+(b(\theta),\theta)
 =E_V^+\,b_{\theta_j}+E_{\theta_j}^+,
\]

故 E_theta_j+=0。把 E 扩展为 default 侧恒等于0，其一阶梯度同样连续拼接为零，得到联合 C1。

仅逐 theta 满足 E_V(b,theta)=0 不足以保证联合 C1。例如 x>0 时取 E(x,theta)=x²h(theta/x³)，其中 h 是光滑紧支撑函数、h'非零。每条固定 theta 的 V 方向满足零值/零斜率，但 E_theta=h'(theta/x³)/x 沿某些趋近路径发散。必须核查联合参数正则性和边界分支 b(theta) 的可微性。

## 4. 原 PDE 如何改变

为避免时间符号混淆，令 T 为剩余时间，固定参数下的扩散生成元为

\[
\mathcal L=\mu(V)\partial_V+\tfrac12 a(V)\partial_{VV}.
\]

若原首次触及概率满足 F_T=LF，则

\[
(\partial_T-\mathcal L)R
 =a(V)(F_V)^2.
\]

GBM 情形 a(V)=sigma²V²。原因是 h'(F)=2(1−F)、h''(F)=−2，生成元含有二阶链式项。R 因而满足一个新增梯度平方源项的方程，不再满足原线性首次触及 PDE。

一般地，若

\[
(\partial_T-\mathcal L+q)F=g,
\]

则

\[
(\partial_T-\mathcal L+q)R
=2(1-F)g+qF^2+a(V)(F_V)^2.
\]

若改用日历时间 backward operator D=partial_t+L，且 (D−q)F=g，则符号变为

\[
(D-q)R=2(1-F)g-qF^2-a(V)(F_V)^2.
\]

在 F<1、F属于[0,1]的续行区，可用 F=1−sqrt(1−R) 写出

\[
(\partial_T-\mathcal L)R
=\frac{a(V)(R_V)^2}{4(1-R)}.
\]

该表达式在 R=1 形式上为0/0；不能因此声称得到边界上无奇异性的常规 PDE。若 F_V 有一侧有限极限，原 a(F_V)² 形式有相应的一侧极限。

通常 R 仅 C1，不是 C2：

\[
R_{VV}(b^+)=-2(F_V(b^+))^2,
\]

而 default 侧二阶导数为0（假设所需一侧二阶导存在）。全域 C1 不意味着可把 default 区与续行区当作同一个未修改的经典二阶 PDE 问题。

## 5. 对语义和训练的实际代价

- 若 0≤F≤1，则 F≤R≤1。续行区 R 对 F 单调，但这是一个新的风险观测变换。
- 若 F 是未折现的真实首达概率，R 可解释为两条条件独立、同分布复制轨迹中至少一条首达的概率。它不是同一条原轨迹的首达概率；折现首次触及价值不能自动套用这个概率解释。
- 在非退化情况下，设 x=V−b、F=1+c(theta)x+o(x)，则 R=1−c(theta)²x²+o(x²)。风险对状态/参数的一阶梯度在阈值处消失；smooth-pasted equity 的一阶梯度也消失。
- 在 default 区，两个观测通道都对这些输入/参数给零梯度。若损失只经这两个输出反传，可能形成局部无梯度区域；增加状态/安全裕度旁路可改变这种情况，但那是额外架构设计。
- 逆变换 dF/dR=1/[2sqrt(1−R)] 在 R→1 时病态，有限精度下压缩近阈值差异也是代价。
- 对有限期限首达概率，T=0 的初始条件 F(V>b,0)=0 与边界值1在角点不相容；本变换不会修复该不连续。sigma→0 的确定性阈值极限也不由此证明覆盖。
- 硬事件、随机首达采样、离散重置、top-k、分支切换、非光滑 b(theta) 求解和其他网络操作仍需独立分析。连续 C1 观测不等于真实脉冲、稀疏执行、低能耗、训练更快或多模态大模型性能更优。

### 观测值作为动力学项，与势能导数作为力，必须区别

若直接用 E、R 的值构造 ODE 右端，例如 \(\dot z=A(z,\theta)+B(z,\theta)E+C(z,\theta)R\)，且 A、B、C 及其余组合均为 C1，则该局部右端可为 C1。这里只能推出相应的局部正则性；全局存在、全局 Lipschitz 性仍须单独验证。

若把 E、R 当势能，改用 \(-\partial_V E\) 或 \(\partial_V R\) 作为力，那么 ODE Jacobian 会涉及 \(E_{VV},R_{VV},E_{V\theta},R_{V\theta}\)。E、R 为 C1 只保证这些力连续，不保证力场 C1，更不保证所需的全部二阶导存在或连续。通常的二阶导跳跃正是反例。本审阅不构造 C2 模型，也不改原金融核。

对于具有期限 T 的折现首达/Laplace 通道，若 \((\partial_T-\mathcal L+q)F=0\)，则精确得到
\[
(\partial_T-\mathcal L+q)R=qF^2+a(V)(F_V)^2.
\]
这里 T 明确表示剩余时间；不能与日历时间 backward 方程的符号混用。

## 6. 独立验证范围

附带纯 Python 文件只验证一个有实际首达意义的解析样例：

\[
F=(b/V)^\alpha,\quad
\mu=\tfrac12\sigma^2(\alpha+1),\quad V>b>0,\ \alpha>0.
\]

这是该 GBM 在正对数漂移下的无限期下穿概率，满足 LF=0。示例 equity 取 E=V−b+(b/alpha)(F−1)，仅用来展示值匹配/光滑粘贴的拼接；不冒充冻结金融核的原 equity 公式。

检查包括联合(V,b,alpha)解析梯度与差分、边界两侧的梯度衰减，以及 LR=−sigma²V²(F_V)²。浮点演示支持实现理解，严格结论来自上面的证明；不替代原数值、质量或成本验收。
