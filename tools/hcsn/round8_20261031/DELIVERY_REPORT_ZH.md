## 2. 事件动力学：修复、独立参照和收敛

## 4. 解析状态：有功能，但未证明脉冲架构不可替代

固定已知模型中，观测历史可压缩为两个充分统计量：

\[
A=\sum_i\Delta y_i/s_i^2,\qquad B=\sum_i\Delta t_i/s_i^2.
\]

它们确定三个可能漂移的后验，再用相同 Brownian 首达核计算未来事件风险。所有方法看到相同的因果观测、时长、传感器噪声和未来查询参数；没有模型获得私有漂移标签。

原 12 个训练检查点、四个 regime 共 8,192 条确认数据全部恢复。本轮独立 NumPy 公式重放 13 个预测器共 106,496 次预测，最大输出差 `1.23581e-6`，所有保护动作一致。独立审阅核对了 GRU 权重分块、reset gate、hidden bias 和长度 mask，没有发现标签进入推理。

解析滤波器与普通 exact filter 的风险 MSE 都接近浮点误差，保护动作 regret 为零。普通 GRU、充分统计量 MLP 和 memoryless MLP 的误差较大，说明历史与正确的概率传播具有任务功能；但普通两个累积量配合同一解析核已构成同信息的等价实现。因此这里没有满足“普通实现无法以更低成本实现相同结果”的强条件，也不能据此断言解析核本身没有价值。

成本边界已单独复核：原 PyTorch 摊销表在四个 regime 使用同一 IID 服务计时，是统一计价情景；训练/teacher 生成可独立核对，未逐项保存的加载时间只作为原测量的正残差保留。本轮新增四 regime 的 NumPy 后端独立计时另列，不改写原 PyTorch 数据，也不当作新训练结果。

逐场景新增 3,796 条计时记录。当前 NumPy 后端下，GRU 的长历史单查询 CPU 为 695.431 微秒，IID 为 280.001 微秒，相差 2.484 倍；这直接说明统一 IID 计价不能代表全部场景的实际工作。解析滤波器与普通 exact filter 的计时接近，排序随场景及 batch/scalar 负载改变，没有普遍成本优胜结论。该计时没有与历史 PyTorch 结果做同硬件速度比较。

详见 [任务与成本范围](state_task/README.md)、[逐场景 NumPy 成本](state_task/NUMPY_COST_REPORT.md) 及 [已审阅重放回执](state_task/evidence/RECOVERY_REPLAY_REVIEWED_20261031.json)。

## 6. 边界与复位后的算子理论

对完整状态和合法动作，定义折现周期核

\[
Q_a(x,A)=E_x[e^{-\rho C}1\{X_C\in A,C<\infty\}\mid a],
\qquad TV=\sup_a(g_a+Q_aV).
\]

当奖励有界、可测性/选择成立，并且**所有合法动作统一满足** `sup Q_a(x,S) <= beta < 1`，才有 sup-norm 收缩、唯一有界固定点和误差控制。若每个非终止周期均有强制 Erlang 恢复、均值统一不低于 `r0>0`，可取 `beta <= (1+rho*r0)^(-1)`。仅 FIRE 有恢复、零时间 WAIT、恢复均值可趋零或无折现，都不能自动沿用该证明。

对候选值函数，若数值残差为 `delta`、奖励误差为 `eta`、cemetery 扩充后的核 TV 误差为 `epsilon`，可得到

\[
\|V-\widehat V\|_\infty
\le\frac{\delta+\eta+2\epsilon\|\widehat V\|_\infty}{1-\beta}.
\]

高维部分分别列明条件独立乘积误差、共享潜变量/相关噪声的依赖误差、有限生成元扰动、有限期限传播、动作间隙、预算合法性和复位正则性。单个 cell 的首达边缘准确，不足以控制联合事件。没有把其他论文的 Hölder-space 假设默认为本模型已经满足。

详见 [killed/reset 理论](event_dynamics/THEORY.md) 和 [高维近似及失效条件](event_dynamics/HIGH_DIMENSIONAL.md)。
