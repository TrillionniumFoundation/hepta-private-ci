# v4 独立审查：来源、数学界、成本与确认性结果

本审查由未编写 v4 模型的独立代理执行。审查仅新增本报告及 `independent_audit.py/json`，没有修改冻结模型、训练协议、原始结果或 checkpoint，也没有执行训练或选择新 checkpoint。

**最终状态：静态检查及350组独立重放全部通过；FullHX 的预声明联合质量目标未通过。检索目标达成，但一个 memory 种子在128步低于95%。工程核对通过不代表性能目标达成。**

## 1. 冻结设计与标签隔离

`freeze.json` 覆盖19项源码、协议与固定算子表。独立检查时，其摘要全部与磁盘内容一致。冻结流程要求开发实验及状态/梯度验证完成，拒绝覆盖既有 freeze 或 confirmation results；开发阶段只构造训练和验证集。该来源链支持“开发后冻结、随后确认”的执行记录，不应被描述为外部注册或第三方时间戳认证。

模型接口只接收参数、`x`、`dt` 和模型类型；标签不进入预测函数。所有16个输入坐标和 `log(1+dt)` 通过通用可学习稠密投影进入 key、value、write 和边界。源码没有根据任务名、marker 列、键编号或答案坐标手写路由。数据中的标记与键值内容是所有模型获得的同一输入，目标由历史输入定义，这是任务本身。

前缀扫描覆盖 `0..T-2`。最后一个 token 提供 query，读取前缀的 Gram/cross 统计量，不写入这些统计量。最后 token 仍会更新快慢神经状态并参与 current residual，因此“最后 query 只读”准确地指**关联记忆统计量只读**，并不指全部神经状态不变。

独立实验在四个 ridge 变体中改变最后 token 和其时间间隔，得到 `G/H/r` 最大差异全部严格为0；带神经动力学的三个变体仍产生快慢状态和 logits 的变化。该实现满足声明的 sequence-to-one 接口，不能据此推导逐 token 自回归生成的成本。

## 2. 数据隔离与预算

独立重建了130份新确认/挑战数据集，发现：

- 新数据集之间完整 SHA 重复数为0。
- 与 v3 训练/验证/测试/挑战及 v4 开发数据的完整 SHA 重用数为0。
- v4 验证、测试、挑战的精确 `(x,dt)` 输入，与全部 v3/v4 开发/v4 确认训练输入的交集为0。
- v4 各验证、测试、挑战之间的精确输入交集为0。

同一个 task/seed 的数据在七种模型间刻意复用，这是配对控制。短符号训练任务的有限样本空间允许训练集内部重复，本审查没有把这种重复误报为测试泄漏。新的随机种子并未改变任务生成机制，所以这些结果仍是同一合成任务家族内的检验。

冻结预算为每个模型600次更新、batch32、19,200次样本呈现，训练长度8/16/32循环，每种长度2048个样本，学习率0.003。checkpoint 只按每50步的 validation loss 最小值选择。数据与更新次数匹配，参数量约匹配；状态容量、FLOPs、编译成本与能耗不匹配。独立重放已对全部105个 checkpoint 核验这些记录、参数量及逻辑状态数。

## 3. 归一化 Gram 与 ridge 界成立的范围

记累计写入质量为 \(S_t=\sum_{i\le t}w_i\)，其中 \(0\le w_i\le1\)。递推确实满足

\[
r_t=(1+S_t)^{-1},\quad
G_t=\frac{\sum_iw_i k_i k_i^\top}{1+S_t},\quad
H_t=\frac{\sum_iw_i k_i v_i^\top}{1+S_t}.
\]

由于 \(\|k_i\|_2\le1\)，且 value 每个坐标的绝对值不超过1，精确算术下 \(G\succeq0\)、\(\operatorname{tr}G\le1\)，并且 **H 每一列**的二范数不超过1。这不意味着整个 H 的 Frobenius 范数或 value 的二范数不超过1。

对 \(A=\tfrac12(G+G^\top)+0.01I\)，特征值在 \([0.01,1.01]\)，故 \(\kappa_2(A)\le101\)；每个读出坐标的保守绝对界为100。这些数学界正确。对称化消除舍入不对称，但不能单凭该操作保证有限精度矩阵仍严格 PSD，因此需要数值检查。

还能利用 G/H 的共同来源，将读出界收紧至5。对第 j 个 value 坐标，令 \(t_j=\sum_iw_i v_{ij}^2/(1+S_t)\le1\)。联合二阶矩阵为 PSD，故 \(h_jh_j^\top\preceq t_jG\preceq G\)。于是

\[
|q^\top A^{-1}h_j|^2
\le q^\top A^{-1}GA^{-1}q
\le\max_{g\in[0,1]}\frac{g}{(g+\lambda)^2}
=\frac1{4\lambda},
\]

从而 \(|R_j|\le1/(2\sqrt{0.01})=5\)。原先的100界依然有效但较松。这个收紧只使用既有模型的矩结构，没有修改模型、数值阈值或实验协议；独立 JSON 保留执行时记录的保守证书。

独立2048步 FP32 递推与 NumPy float64 直接加权求和比较，最大绝对误差为 **3.2075e-8**。本次样本最小 Gram 特征值0.01798、最大 trace0.39669、最大 H 列范数0.02120；写门为0时三个统计状态均逐位不变。这些样本检查与定理一致，但不是覆盖所有数值输入的证明。

归一化后的固定 ridge 具有明确代价：

\[
q^\top(G_t+\lambda I)^{-1}H_t
=q^\top\!\left(\sum_iw_i k_i k_i^\top+\lambda(1+S_t)I\right)^{-1}
\sum_iw_i k_i v_i^\top.
\]

在未归一化表述中，有效正则项随总写入质量增大。旧的稀少关联可能被稀释；有限条件数并不保证任意长度保持、无限内容容量或良好的长期 BPTT。快慢状态的界也不约束所有可训练投影的范数。

## 4. 原始 FP32 压力测试失败的诊断

`stress_solve_results.json` 的8例中有2例不满足原定 FP32 有限差分阈值，原文件及其 `passed=false` 保留：在差分步长 `2e-5` 下，最大归一误差为 **0.0045192**，超过0.003；FP64 四例均通过，FP32 solve 残差仍小于4.72e-8。

独立审查没有放宽该阈值，而是直接推导矩阵求解的 adjoint。令 \(B=A^{-1}H\)、\(R=q^\top B\)，对 \(L=\|R\|_2^2\)，有

\[
\nabla_H L=2(A^{-\top}q)R,\qquad
\nabla_G L=\operatorname{sym}(-\nabla_H L\,B^\top).
\]

NumPy float64 闭式公式与 JAX FP32 全矩阵梯度的最大归一误差为 **2.5359e-6**，低于独立预设的 `2e-5` 阈值。完整保留 `2e-3/5e-4/1e-4/2e-5` 的差分步长扫描；较大步长 `2e-3` 下误差不超过2.15e-4，而缩小到 `2e-5` 后误差增大。

这一组证据支持“FP32 小步长差分的相消误差”解释，未发现 solve adjoint 实现错误。原始有限差分检查依然记录为失败；不能把独立 adjoint 通过改写成原测试也通过。

v4 带神经动力学的状态是 v3 的 **2.179倍**；memory-only 是 **2.450倍**。状态数不含参数、优化器、临时激活与编译器开销，也不是实测峰值内存。

固定算子表有两个必须分开的口径：运行时 FP32 数组 **131,128字节**；源 NPZ 解包后的 FP64 数组 **262,256字节**。冻结 runner 的 `fixed_operator_bytes` 实际记录后者。该字段未修改，解释时必须使用正确口径；不能把源数组字节数称作实际 FP32 表占用。

每个 prefix token 的统计更新是 \(O(K^2+Kh)\)，另外还有 \(O(h^2)\) 的 value 投影及神经动力学。最终一次 \(K=16\) solve 为 \(O(K^3+K^2h)\)。本实验每段序列只 solve 一次，逐 token 查询将反复支付读出成本。推理的统计状态长度固定；普通 BPTT 的激活存储仍随序列长度增加。

## 6. 如何区分记忆结构收益与金融算子收益

v3 训练和标准 heldout 检索均只有4个关联项；32/64/128改变的是间隔长度。v3 HCSN 的四项 Test128 为 **88.652%**，同图 sigmoid **88.574%**，memory-only **88.145%**，full-HX **88.613%**；同预算未修改 v2 为 **50.586%**。这些数值说明关联记忆改造有明显增量，却没有建立金融门形状的独有优势。8项是另行冻结的容量挑战，不能与四项测试混为一谈。

`benchmarks/data.py` 的检索任务从固定8种键中无放回抽取4种，每个 value 属于4个类别；8项挑战使用全部8种键。新种子改变配对值、位置与干扰，但并不引入新键词表。这个任务没有同键覆盖、冲突关联、按时间选择不同版本或任意新词表。因此“检索目标通过”应限定为这一任务，不等同于通用长上下文检索解决。

v4 改为更大统计状态和正则化回归读出，机制不是 He–Xiong 股权解析解推导出的记忆。v4 的 HCSN 与 sigmoid 为同图、同初始参数对照，仅风险门形状不同；full-HX 同时改变 call/risk 数值形状。memory-only 删除快慢状态但为匹配参数使用不同宽度，因此其归因也必须保留容量与宽度差别。若 memory-only 已实现检索收益，不能把该收益全记在金融算子上。

## 7. 确认性重放与判定

## 9. 审查结论与保留事项

**工程证据链通过；FullHX 预声明联合质量门未通过。** 检索子任务得到有效修复，金融门不是该修复的必要条件；长期初始符号保持、金融算子独有收益、同质量成本优势与完整 backbone 的扩展仍没有被本轮建立。

原始确认结果、挑战失败、原 FP32 有限差分失败、固定表字节勘误、所有 checkpoint 及独立解析梯度补证均保留。本轮不追加 v5、不改门槛、不按测试结果重新挑 checkpoint；后续研究需要另行声明协议和未触碰的数据。

主要机器证据为 `independent_audit.json`：`static_passed=true`、`replay_pending=false`、`replay.passed=true`，同时 `replay.primary_full_hx_targets_passed=false`。训练来源摘要为 `41068832208cdcaa1ac8e1eae9d145a1dd0884fb70c5296d9095aeee8208a2a1`，挑战来源摘要为 `bebc4f31dc8fad6a5d54a5bf59b4c5717fa6929ed37bf0193759ba86210b0f34`。
