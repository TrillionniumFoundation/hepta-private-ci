# 完整 HX 算子 Head：冻结消融与独立审计

## 结果

本目录已完成 **7 个预先固定的分支 × 5 个种子 × 2 套真实冻结 encoder 数据，共 70 次训练**。独立审计从 70 个保存的 checkpoint 重新计算验证、干净测试与原始输入扰动测试的全部指标，并对真实代码分支做有限差分梯度及查找表依赖检查；全部通过。

**完整金融公式来源的算子可以接入普通反向传播，但当前两套实验没有证明其风险形状或完整动力学组合优于普通门控记忆。** AG News 上完整模型与保留同一 Call 的 sigmoid 对照相近，普通 memory-only 均值更高；CIFAR-10 上完整模型也没有稳定超过这两个对照。删除残差记忆或动态边界会降低部分干净测试分数，但这些是固定宽度的组件删除，参数数目随之减少，不能把所有差异都归为该组件的独立因果收益。

这些是独立文本、图像探针，不是配对多模态或完整 backbone。数据、原始输入扰动和预训练重叠的范围见 `../encoder/README.md`。本轮完整模型结果不得与“全模态大模型已获优势”混为一谈。

## 1. 完整算子确实进入了训练图

`models.py` 直接调用 `next.full_kernel.full_gates`。其 Call 来自完整 A7 equity 的有界归一化；风险通道来自明确作过近边界 C1 修改与镜像延拓的 first-hit risk。运行时使用 float32 Hermite 表及连续尾部扩展，因此它是经过独立误差检查的完整公式数值编译核，**不是运行时精确闭式表达式，也不是原文 put 价格的原样复用**。

固定表来源和误差检查保留在 `../full_kernel/`。这里额外检查实际依赖：分别改变 Call 或风险的表系数，观察相同短序列的输出是否改变。结果与各分支定义一致：

| 分支 | 依赖 Call 表 | 依赖风险表 | 实际删除或替换 |
| --- | --- | --- | --- |
| full | 是 | 是 | 完整神经递推 |
| full_sigmoid | 是 | 否 | 仅将 q 替换成 sigmoid(2z) |
| no_call | 否 | 是 | Call 恢复增益置零；写入形状换普通 C1 函数 |
| no_recovery | 是 | 是 | 删除慢恢复状态更新及其读出 |
| static_boundary | 是 | 是 | 删除输入及残差记忆对边界坐标的影响 |
| no_memory | 是 | 是 | 删除残差记忆写入、候选投影与记忆反馈 |
| memory_only | 否 | 否 | 普通 sigmoid 读门、普通 C1 写门、残差记忆；删除金融门与快慢状态 |

普通 C1 写门为 `relu(s)^2 / (1 + relu(s)^2)`。memory-only 在长度为 1 的序列上只读到初始零记忆，实际输出等于输出偏置；此检查验证了其读旧记忆、随后才写入当前 token 的约定。

完整风险门在边界的斜率与 `sigmoid(2z)` 不同，本实验没有斜率匹配。因而 full 与 full_sigmoid 隔离的是这两种完整函数形状在相同神经结构中的差别，不能将结果解释为对所有 sigmoid 参数化的结论。

### 金融参数固定，可训练的是神经参数

固定金融参数为 r=0.08、delta=0.02、sigma=0.23、alpha=0.6、tax=0.27、liquidity=0.01、maturity=1、coupon=6.39、principal=61.68。它们及离线求解的金融边界只用于生成表，未加入 Adam 参数树；70 个 checkpoint 均核对这一点。

神经参数中的 `boundary` 是每个神经单元学习的坐标，`call` 是学习的神经增益。它们不是重新求解金融自由边界或对上述金融参数做隐式微分。层间学习边界坐标也不等于金融停止问题随网络时间演化的精确解。

共享表有 **32,782 个固定标量，float32 数值总大小 131,128 字节**，与可训练参数分开报告。源 NPZ 保存 float64 数值，未压缩数值总大小 262,256 字节。固定常数由所有单元共享；该数值总量不代表编译后实际驻留内存，编译器可能删除某些分支未用的常数。

## 2. 训练协议、宽度与状态预算

协议为 `protocol.json`，每个结果文件嵌入同一内容，审计比对一致。两个数据集均是 2,000 训练、500 验证、1,000 测试，输入为冻结 encoder 与仅训练数据拟合 PCA 后的 `17×64` 特征。所有分支均运行种子 0–4、300 次 Adam 更新、batch 32、学习率 0.003、梯度裁剪 1；每 50 次更新按干净验证交叉熵选择 checkpoint。测试没有传入训练器。模型运行顺序仅按预定 seed 旋转。

full 和 full_sigmoid 精确参数匹配；其他删除分支保留相同宽度，因此是**宽度匹配，非参数匹配**。下表状态数是每个样本有效持续状态的标量数，不是整个训练时的激活/优化器内存；源代码为统一 scan 仍可携带不更新的零占位量。

| 分支 | AG 参数 / 状态，宽度 26 | CIFAR 参数 / 状态，宽度 25 |
| --- | ---: | ---: |
| full | 6,114 / 78 | 6,010 / 75 |
| full_sigmoid | 6,114 / 78 | 6,010 / 75 |
| no_call | 6,088 / 78 | 5,985 / 75 |
| no_recovery | 6,036 / 52 | 5,935 / 50 |
| static_boundary | 4,398 / 78 | 4,360 / 75 |
| no_memory | 4,398 / 52 | 4,360 / 50 |
| memory_only | 3,540 / 26 | 3,560 / 25 |

这些是组件删除组，不是遍历所有组件组合的完整析因设计，不能估计所有交互项。memory-only 同时删除多个结构，主要用于检验“整套金融动力学是否比更简单的普通门控记忆必要”。

## 3. 所有测试分数

数值是准确率百分比，`±` 为 5 个训练种子的样本标准差，单位为百分点。五个种子共享相同测试样本。

| 分支 | AG 干净 | AG 原始删词 | CIFAR 干净 | CIFAR 原始遮挡 |
| --- | ---: | ---: | ---: | ---: |
| full | 83.96 ± 0.57 | 83.22 ± 0.64 | 76.36 ± 1.14 | 41.96 ± 1.25 |
| full_sigmoid | 83.84 ± 0.64 | 83.06 ± 0.48 | 76.52 ± 1.11 | 42.72 ± 1.14 |
| no_call | 84.02 ± 0.67 | 83.08 ± 0.71 | 75.60 ± 1.10 | 42.16 ± 1.15 |
| no_recovery | 83.80 ± 0.52 | 83.14 ± 0.88 | 77.46 ± 1.10 | 41.82 ± 1.75 |
| static_boundary | 83.16 ± 0.57 | 82.50 ± 0.66 | 73.96 ± 1.21 | 41.80 ± 1.95 |
| no_memory | 82.86 ± 1.12 | 82.22 ± 0.33 | 69.32 ± 1.76 | 40.64 ± 0.87 |
| memory_only | 85.06 ± 0.40 | 84.42 ± 0.26 | 76.76 ± 0.79 | 42.92 ± 0.97 |

正文不根据这些测试分数再选择新超参数、删除失败种子或改变模型。CIFAR 去掉恢复支路后干净均值提高，但遮挡均值未提高，不能宣称该恢复机制在所有任务都无用。删除记忆的 CIFAR 干净均值下降约 7.04 个百分点，但同时减少约 1,650 个参数；它支持继续研究记忆路径的必要性，尚未区分记忆机制与额外容量的贡献。

### 配对 seed 与样本分析

审计在重放 checkpoint 和读取逐样本差异前固定了以下方法；当时 AG 聚合分数已经可见，所以它是**描述性的后续分析，不是测试盲统计预注册**。

对 full−full_sigmoid、full−memory_only 两个固定比较，在每种数据与扰动条件各做 5,000 次 bootstrap。每次有放回抽取 5 个训练种子，再按原类别分层有放回抽取 1,000 个测试样本；同一对模型使用完全相同的种子与样本索引。报告百分位 95% 区间，基准 RNG seed 为 `2026103008`，各条件使用记录在 JSON 的后续 seed。

| 比较 | 条件 | 配对均值差 pp | seed + 样本 95% 区间 pp |
| --- | --- | ---: | ---: |
| full−full_sigmoid | AG 干净 | +0.12 | [−0.74, +0.98] |
| full−full_sigmoid | AG 删词 | +0.16 | [−1.00, +1.30] |
| full−full_sigmoid | CIFAR 干净 | −0.16 | [−1.64, +1.24] |
| full−full_sigmoid | CIFAR 遮挡 | −0.76 | [−2.68, +1.02] |
| full−memory_only | AG 干净 | −1.10 | [−2.26, +0.02] |
| full−memory_only | AG 删词 | −1.20 | [−2.42, −0.04] |
| full−memory_only | CIFAR 干净 | −0.40 | [−2.00, +1.18] |
| full−memory_only | CIFAR 遮挡 | −0.96 | [−3.02, +1.10] |

所有 full−full_sigmoid 区间跨过 0。full−memory_only 的均值均为负；AG 删词的未校正区间略低于 0，但本分析有 8 个条件比较、只有 5 个训练种子，并未多重校正，因此不把这单项当作确认性显著发现。JSON 也保留仅对种子重采样的区间；两类区间差异表明，仅报训练种子的波动会遗漏测试样本不确定性。此分析仍未覆盖 encoder 预训练、数据 split 选择、超参数搜索或分布漂移的不确定性。

## 4. 独立审计实际执行了什么

`audit_heads.py` 在两个训练结果均 `complete=True` 且训练进程退出后运行，CPU affinity 4–5。没有重新训练，也没有改动训练器、模型或冻结协议。

- **70/70 checkpoint 重放：**验证、干净测试、原始扰动测试，共 210 组预测。用独立 NumPy softmax/交叉熵/Brier/ECE 计算复核保存指标；AG 最大绝对差 `1.943e-16`，CIFAR `4.441e-16`。
- **70/70 存储预测：**干净测试 1,000 个类别预测逐项精确相同。
- **协议与证据：**原训练源码、特征、表、checkpoint 哈希一致；特征与 encoder manifest 一致；训练前后特征哈希一致。
- **参数与结构：**每个分支的参数键、全部形状、float32 dtype、有限性、参数计数与有效状态计数一致；金融参数不在训练树内。
- **checkpoint 选择：**保存的 best step 等于验证历史交叉熵最小的检查点，实际重放的验证指标也一致；每次训练均为 300 次更新、无额外预热更新。
- **真实分支梯度：**每个分支各用 2 个样本、4 个不等正时间间隔、输入维 3、宽度 4，做一次随机方向参数 BPTT 与两种步长的中央有限差分。使用实际运行 float32 表值提升至 float64，隔离浮点差分舍入；没有代理梯度。
- **真实表依赖：**对 Call/risk 表分别做固定系数干预，验证上表的使用/不使用关系，不只是检查函数名或 import。

7 个分支的梯度均有限。有限差分步长 `1e-4` 的最坏绝对误差为 `1.277e-8`；步长 `3e-5` 为 `1.146e-9`。这是一项有意义的短 BPTT 路径检查，不证明任意长度训练无梯度消失、不证明全局优化，也不替代 `full_kernel` 中独立的公式与插值误差检查。

完整审计耗时 47.65 秒，结果保留在 `audit_results.json`。结果的路径哈希均以 `hcsn_research/` 根目录为基准；新增审计脚本没有反向加入已经完成的训练源码快照。

## 5. 完整核的真实端到端成本

`measure_pipeline.py` 新增了 full、full_sigmoid、memory_only 各 seed 0 的实际原始输入测量，共 2 套数据 × 3 个模型 × 50 个输入 = **300 次**，每个模型另做 3 个预热输入。用同一冻结测试 manifest 的前 50 条；编码器、输入处理与 PCA 路径复用经核对的真实流水线。

计时包含文本 tokenizer 或 PNG 解码/resize、完整 encoder、局部/全局汇聚、PCA、CPU 张量转换与 Head logits。表读取、模型/参数加载、JIT 编译及分类指标不计入在线延迟并另列；所有 NPZ 数组都在计时前完整读入，不存在逐次读取系数的问题。原始特征的前 8 条与缓存最大绝对差为 0；300 次实际流水线类别预测均与对应保存预测相同。

| Head | AG 中位 / p95 ms | CIFAR 中位 / p95 ms |
| --- | ---: | ---: |
| full | 19.303 / 22.675 | 11.783 / 14.772 |
| full_sigmoid | 18.645 / 23.659 | 13.108 / 15.740 |
| memory_only | 20.069 / 23.302 | 13.619 / 15.097 |

不能将该表读成金融核具有加速优势：例如 CIFAR 的 encoder 中位时间在三个顺序测量段分别为 8.535、9.462、10.033 ms，足以改变整条流水线的排序；对应 Head 部分为 0.903、0.892、0.794 ms。AG 的 Head 部分也随系统调度变化。这里是共享 CPU、每组仅 50 次、不同时间块的参考测量，没有隔离硬件争用，也没有同质量或能耗匹配。

完整 35 次 Head 实验墙钟时间分别为 AG 208.52 秒、CIFAR 221.65 秒，包含编译、训练、验证、测试、保存与 Head 延迟检查。它们还需加上此前共享 encoder 准备成本，而不应只报神经 Head：AG 75.485 秒、CIFAR 48.986 秒，PCA 另为 0.555、2.140 秒。编码器准备可在所有这些 Head 之间共享，不能把它既省略也重复按每个 Head 加一次。

训练器将编译、执行、主机批处理与验证分开记录；执行总时间包含第一个编译后冷 dispatch，不冒称纯 warm 训练时间。此处的测量关闭了“完整核只报 Head 开销”的缺口，未建立等质量扩展成本曲线。

## 6. 复现与文件

先按 `../encoder/README.md` 下载固定公开数据/权重、准备两个特征缓存。依赖使用项目 `requirements-cpu.txt` 与 `next/encoder/requirements-extra.txt`。以下在 `hcsn_research/` 根目录执行：

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 taskset -c 4-5 python -B next/ablation/run_heads.py ag_news --features /tmp/hcsn-next-encoder-assets/ag_news_features.npz
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 taskset -c 4-5 python -B next/ablation/run_heads.py cifar10 --features /tmp/hcsn-next-encoder-assets/cifar10_features.npz
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 taskset -c 4-5 python -B next/ablation/audit_heads.py
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 taskset -c 4-5 python -B next/ablation/measure_pipeline.py
```

审计要求两套训练结果完整，因此不能对中途写入的结果提前运行。如果只复核已发布 checkpoint，跳过前两条；原始权重、数据和特征缓存仍需按固定来源重新生成。CPU 编号需在其他机器选择有效值，并记录其对性能条件的改变。

`ag_news_results.json`、`cifar10_results.json` 是原训练证据；对应 checkpoint 保存在各自 `_checkpoints/` 目录；`audit_results.json` 是独立重放、结构、梯度与配对统计证据；`pipeline_latency.json` 是新增的完整核原始输入测量。源码、协议及原始训练证据在本次审计中均未修改。

尚未获得的证据包括：金融参数端到端学习、普通门控的斜率/尺度匹配完整搜索、组件参数容量匹配、配对多模态任务、真实长程异步事件输入、完整 backbone 预训练与等质量规模成本曲线。它们不能被本轮可微性与复核通过替代。
