# 独立解释审查：五阶段验收、剩余命题与 backbone 决策

## 决定

**当前可以验收的是一套可复核、可用普通反向传播训练的连续值神经模块，以及固定金融模板的 C1/FP32 实现；完整语言或全模态 backbone 的扩展条件尚未满足，结论为 NO-GO。**

本轮已经关闭多项具体工程缺口：完整公式来源的算子进入实际训练图，固定参数模板可稳定以 FP32 求值和对神经状态求导，真实文本与图像共享 encoder 实验完成，原始输入扰动重新编码，参数消融与 checkpoint 复核落地，计时剔除了已发现的重复编译或重复读取问题。它们不自动构成金融曲线优于普通门控、任意长度稳定记忆、真正的生理脉冲、配对多模态一致性或大模型同质量成本优势。

原先的 160 次实验与其中的失败记录保留原样，新的结果只增加证据。不能用后来某个实现通过，倒写旧原式 FP32 检查、旧训练计时或旧泛化结果为通过。[历史完整报告](../RESULTS.md)

### 审查时间范围与计数

本报告依据已经完成的 `full_kernel`、`sequence`、`encoder`、`ablation`，以及 v4 `ridge` 已经写入的记录。首次读取 v4 主结果时有 **68/105** 条记录、`complete=false`；随后追加只读核对时，已是 **105/105、`complete=true`**，memory 与 retrieval 均有全部五种子。本报告写作结束时，挑战和完整独立重放仍在进行。这里记录审查时点，最终执行状态以 [RESULTS.md](RESULTS.md) 和各目录最终审计为准；本报告不为尚未写入的实验填分数。

本轮主矩阵规划为 335 次神经训练：v3 序列 120、独立冻结 encoder 基线 40、完整 HX Head 消融 70、v4 确认矩阵 105；另有 4 次 v4 开发训练和 2 次确定性线性拟合。原先 160 次、当前新增主矩阵、开发训练、线性拟合、数值检查与 checkpoint 重放应分别计数。最终完成总数应在所有完成标记和重放通过后核对，不提前写成已完成。[v4 协议](ridge/protocol.json) [开发协议与记录](ridge/development_results.json)

## 2. “完整金融公式可训练”必须拆开解释

### 2.1 固定模板的状态梯度：可以验收

固定金融参数先在 float64 计算原文 Eq.12 的最优边界与 A7 股权价值，再生成共享查找表。Call 由完整股权作有界归一化，风险通道对首达函数增加局部 C1 拼接及危险侧镜像延拓。运行时对输入状态、神经权重和神经边界偏移求导，不需要硬阶跃的代理梯度。

14 个参数模板的 FP32 归一化门值最大误差为 `1.808e-7`，状态导数最大归一化误差为 `4.901e-4`，均在先声明标准内。这个结果支持固定完整模板进入神经训练；它不是任意九维金融参数空间的验证，也不是逐步精确计算原闭式金融金额。[核验证](full_kernel/validation_results.json) [接缝检查](full_kernel/join_results.json)

70 个训练 checkpoint 已独立重放；另外，七种实际代码分支在宽度 4 的初始化参数和固定短序列上进行表干预：full 的输出依赖两张表，full_sigmoid 不依赖风险表，no_call 不依赖 Call 表，memory-only 对两者都无依赖。七个分支的短 BPTT 方向有限差分检查均通过；步长 `3e-5` 的最坏绝对误差约 `1.146e-9`。表干预与有限差分的覆盖范围是这些明确的小型路径，不是对 70 个训练 checkpoint 各做一次全参数有限差分。[Head 审计](ablation/audit_results.json)

### 2.2 九个金融参数的总导数：不同的对象

历史 float64 JAX 实现直接对完整金融方程求导，固定 V 下的金融九参数总导数包含金融最优边界移动。这条证据与当前查找表状态梯度不能互换。[原式 JAX 报告](../analytic/JAX_REPORT.md)

新表在训练前已经计算完，优化器参数树没有 r、delta、sigma、alpha、tax、liquidity、maturity、coupon、principal。神经参数中虽然有名为 `boundary`、`call` 的字段，但分别代表神经坐标和神经增益。它们不是原金融问题重新求解的最优边界或债务结构。[固定参数元数据](full_kernel/baseline_table.json) [实际模型](ablation/models.py)

因此不能写“原九参数金融模型的 FP32 自动微分问题全部解决”。原式 FP32 失败记录应继续保留；当前完成的是固定模板的神经使用。若以后将表中每个系数当作自由权重训练，它也不再自动等价于九参数金融族，需另证明 value matching、smooth pasting 与参数一致性。

### 2.3 原文 F/G 不等于第二个满足同样贴合条件的 put

原文股权 E 的边界条件不能直接搬给 F/G。F 是首达概率、G 是贴现首达项；原 F 在违约区直接常数延拓存在一阶导跳跃。当前 C1 风险门是新增设计；边界层内不再是未经修改的原违约概率，违约后的镜像再生侧也不是金融最优停止问题给出的继续演化。

应称“完整金融模型派生的双通道神经算子”，并同时说明风险修改、归一化、查找表与尾部近似。不能因存在完整原式来源，就把所有新增神经行为说成论文的解析结论。[风险构造说明](full_kernel/README.md)

## 3. 神经边界、连续时间与 spiking 的实际语义

### 3.1 学习边界坐标不等于在线求解最优停止自由边界

完整 Head 中的边界坐标由偏置、输入投影和记忆反馈组成；static_boundary 删除输入与记忆反馈，但仍学习偏置。它是可微的神经参数化。金融 Eq.12 的边界在表编译时固定，运行时没有根据当前输入、网络状态与新优化目标反复解自由边界问题。[Head 更新代码](ablation/models.py) [模板编译代码](full_kernel/tables.py)

当前输出还包括快慢状态、残差记忆或关联读取，并非只把一个金融 Vb 标量在多层间传递。严格的 boundary-only 深层通信、其信息容量及相对于一般连续状态传递的收益，没有在这些实验中独立验证。[v3 模型](sequence/models.py) [v4 模型](ridge/models.py)

### 3.2 当前是时间感知的可微离散事件更新

fast/slow 使用 `exp(-dt/tau)` 泄漏，并把当步非线性门控与驱动冻结后更新。这对冻结驱动的线性泄漏项是精确的，但不是整个耦合非线性 ODE 的精确解析时间流。

槽记忆的写入权重 w 按 token/事件应用；ridge 的累计 Gram/cross 统计也按写入事件更新。输入可包含 `log1p(dt)`，所以门有学习时间信息的能力，但 w 没有被结构性地构造成 `1-exp(-rate*dt)` 这样的时间增量。一般不能保证 dt 趋近零时记忆写入也趋零，更不能保证把一次事件拆成两次后结果不变。

例如在固定候选 v、固定写入门 w 的局部情形，一次写入为 `(1-w)m+w*v`，两次为 `(1-w)^2*m + (1-(1-w)^2)*v`，通常不同。ridge 把相同事件写两次也会改变累计写入质量以及固定 ridge 下的读取。作为事件模型，两个事件改变状态是合理的；这一例子只说明不能直接把同一实现解释为对持续输入任意拆步都不变的连续流。学习到的 dt 依赖可能在某些数据上近似补偿，但实现没有保证时间半群关系 `Phi(t+s)=Phi(t)∘Phi(s)`。

v4 最后一个 token 特殊地查询 prefix 的 G/H/r 而不写入它们；该 query 仍更新快慢状态和当前残差。其语义是 sequence-to-one 读出协议，不是已验证的每 token 自回归解码器。[更新定义](ridge/models.py) [实际 query 不写入检查](ridge/independent_audit.json)

因此可以报告“连续值状态、时间间隔感知和普通 BPTT”，不能报告“整个网络已获得原论文解析解的精确连续流”“任意拆步不变”或“已验证的连续时间语言解码效率”。本审查没有为这些尚未建立的性质新增测试。

### 3.3 C1、阈值、相变与脉冲不能相互代替

C1 说明函数和一阶导的连接性质。它可以让普通反向传播通过边界，却不自动产生全或无发放、绝对不应期、可靠的尖峰时刻编码、滞后或吸引子分岔。穿过 z=0 也不自动等于动力学相变：相变命题需给出控制参数、状态/吸引子变化及可重复的判定。

连续模型当然可以产生脉冲或振荡，但需要自己的动力学证据。历史简化模型中确有部分周期轨迹，也有平台、稳态及长程梯度放大/衰减；不能把其中一个现象推广到所有新完整核或所有训练参数。[动力学报告](../dynamics/README.md)

当前普通关闭写门确有一片值和一阶导为零的区域，但是否实际学会关闭须看权重。v3 已训练 memory 模型的诊断发现，20 个模型中真正对全部四类 filler 关闭全局写门的数量为零。128 步任务成功主要可以通过地址分离等机制实现，不等于严格无限期保持。[v3 写入诊断与解释](sequence/README.md)

所有 SNN 与 HCSN 目前都在 dense CPU 上运行。去除 0/1 不可微门并不自动保留传统事件稀疏计算的硬件优势，也不构成生物神经元真实性验证。

## 4. 实证门槛：已记录反例不能被均值或未完成 seed 消除

### 4.1 v3 改善成立，泛化边界也成立

在新的 600 更新、8/16/32 课程下，v3 HCSN、sigmoid、full-HX 的初始符号 memory 到 128 步均为 100%。同预算未修改 v2 的 128 步均值为 64.922%，说明新记忆结构有实际增量；GRU 在同预算下也显著改善，所以旧 300 步结果不代表架构能力上限。

v3 检索到 128 步均值约 88.6%，没有达到预定 90% 目标；更长 memory_512 的 full-HX 均值约 64.77%、最差种子 26.56%，8 个关联项检索 full-HX 均值约 76.25%，Transformer 参考约 99.14%。这些是不同容量/干扰条件，不能把四项、128 步成功改述为任意长上下文或任意内容容量已解决。[v3 完整结果与挑战](sequence/README.md)

### 4.2 v4 主模型的每 seed memory 门槛已有明确失败

v4 在确认测试前规定，主模型 full_hx 在每个 seed 与每个长度的 memory 准确率均需至少 95%。已经保存的 **memory、seed 2、length 128 为 0.9384765625，即 93.84765625%**。这个单个已观测反例已足以使“每 seed、每长度至少 95%”这一合取条件为假；不能用五种子均值约 98.77% 替换它。

其他训练或挑战的好坏不会删除这个已经固定 checkpoint 的反例。若以后修改结构、优化器、预算或选择规则，应另立新协议与未触碰 holdout，保留此失败。full_hx 检索的五个已记录 seed 在 32/64/128 均为 100%，同 ridge 的简化 HCSN、sigmoid、纯记忆也都达到该分数。这是有价值的窄任务结果；105 次训练全部执行完成，不等于所有主要标准、容量挑战或所有尺度均通过。[v4 冻结门槛](ridge/protocol.json) [已落盘主结果](ridge/results.json)

四次开发训练的 validation 均为 100%，只能说明开发 sanity 目标成立；它没有保证独立确认 seed 的 memory 门槛，也不是测试集选择依据。[开发记录](ridge/development_results.json)

### 4.3 SPD、梯度检查与任务准确率是不同层次

v4 的归一化统计在精确算术中满足 `r=1/(1+sum(w))`，G 是有界 PSD 的加权和，固定 ridge=0.01 使读取矩阵有严格正下界。这解决了定义与条件数控制的具体问题，却不阻止旧事件贡献随总写入质量稀释，也不证明内容一定可恢复或长程 BPTT 一致良态。

保留的 `stress_solve_results.json` 中，小步长 FP32 有限差分曾未过预定阈值。后续独立 float64 解析伴随参考把同例 FP32 梯度最大归一化误差定位为约 `2.536e-6`，在其预定 `2e-5` 内；完整步长扫描复现小步长相消问题。应同时保留原失败与新诊断，不能把原记录改为通过，也不能仅据差分相消断言 AD 必然错误。[原压力记录](ridge/stress_solve_results.json) [独立伴随诊断](ridge/independent_audit.json)

这些数值实现证据与主模型 memory 准确率未达门槛并不矛盾。一个实现正确的模型仍可泛化失败。

## 5. 共享 encoder 已执行，金融算子独有收益没有建立

新实验使用 AG News + MiniLM 与 CIFAR-10 + MobileNetV2，各为 2,000/500/1,000 的 train/validation/test；PCA 仅训练集拟合。原始删词和原图遮挡先于 encoder，局部与全局特征全部重算，没有保留干净 global 特征通路。40 次基线、70 次完整核 Head 与对应 checkpoint 复核已完成。[新 encoder 报告](encoder/README.md) [完整核报告](ablation/README.md)

| 固定比较 | AG 干净 | AG 删词 | CIFAR 干净 | CIFAR 遮挡 |
| --- | ---: | ---: | ---: | ---: |
| full 准确率 | 83.96% | 83.22% | 76.36% | 41.96% |
| 同 Call 的 full_sigmoid | 83.84% | 83.06% | 76.52% | 42.72% |

full−full_sigmoid 的四个配对 seed+样本 bootstrap 区间全部跨 0；full−memory-only 的均值四项均为负。AG 删词相对 memory-only 的区间略低于 0，但该分析只有五个 seed、八项未多重校正比较，而且方法固定时 AG 聚合分数已经可见，应作为描述性后续分析。它既没有证明金融门稳定更好，也没有证明未来所有金融门与普通门等价。[逐项配对结果](ablation/audit_results.json)

full_sigmoid 保留同一 Call、相同可训练参数和神经结构，仅换风险 q；但 sigmoid 在边界斜率与新 q 不同，没有做斜率匹配。组件删除保留宽度、减少参数，是另一层公平范围。报告这些限制是为了正确限定归因，不能事后将它们作为删去不利结果的理由。

两个独立模态各自有效的编码与分类流程，不等于共享跨模态表示、真实配对融合、缺模态推理或多模态一致性验证。预训练数据历史重叠也未审计；“新 holdout”只相对于本项目的 Head 实验。

## 6. 参数、状态、FLOPs 与全系统成本

### 可训练参数相近，不代表资源相同

v4 full_hx 约 6,217 个可训练参数、1,373 个逻辑持续状态标量；GRU 约 6,257 个参数、37 个状态。v3 动态版本有 630 个状态。参数预算相近时，记忆容量与每步运算已经明显不同。Transformer 的状态字段为 null 表示此处未用同一循环状态口径统计，不表示没有内存成本。[独立资源检查](ridge/independent_audit.json)

ridge 还含 K=16 的统计更新与最终矩阵求解：prefix 更新约 O(K²+Kh)，学习的 value 投影另有 O(h²)，最终 solve 约 O(K³+K²h)。只在末尾 query 做一次 solve 的分类协议不能替代逐 token 语言解码成本测量。

固定金融表也不是零资源。实际 FP32 数值缓冲区为 131,128 字节；原 NPZ 数组是 float64，数值总量 262,256 字节，文件本身为 253,216 字节。v4 原 `fixed_operator_bytes` 字段记录的是源 float64 数组，已有单独资源勘误；原训练结果不覆写。[资源勘误](ridge/resource_accounting.json)

### 已补上真实流水线计时，但没有同质量成本曲线

完整核 Head 已做固定 seed 0、每组 50 条原始输入、包含真实 encoder 的实际测量：full 的 AG 中位延迟 19.303 ms、CIFAR 11.783 ms；参数、表、JIT 在计时前加载/编译，原始输入处理与推理成本保留。[完整核流水线](ablation/pipeline_latency.json)

不同模型时间块的 encoder 本身波动足以改变总延迟排序，例如 CIFAR 三组 encoder 中位值为 8.535、9.462、10.033 ms。不能将这种共享 CPU 单次块测量解释为金融核具有显著加速。此前线性参考重复 NPZ 读取的计时问题已有独立修正，并保留原脚本与原 JSON。[线性计时修正](encoder/pipeline_latency_linear_corrected.json)

一次共享特征准备的 encoder 成本约为 AG 75.485 秒、CIFAR 48.986 秒，PCA 另为 0.555、2.140 秒。多 Head 可以分摊该准备成本，但全系统报告不能将其删去。训练器现区分预编译、优化器执行、验证和主机处理，优化器执行仍包含第一次编译后的冷 dispatch。

尚无同质量、不同模型规模/数据规模的成本曲线，也没有 GPU、大规模内存/通信或能耗测量。dense CPU 上的 LIF 与 HCSN 比较不能支持神经形态硬件能效结论。当前只能验收成本口径与参考测量，不能验收“训练全模态大模型比 Transformer 更便宜”。

## 7. 对“直到所有 blocker 闭合”的处理

可以明确宣布已处理并验证的工程事项：固定金融模板 FP32/C1 实现、完整核进入真实训练、输入扰动路径、有限差分与 checkpoint 复核、源码/数据哈希、计时错误的修正与历史保留。

仍应标为**证据未支持**的事项：主模型每 seed 的稳定长记忆门槛、金融风险形状的稳定独有收益、完整金融动力学组合优于普通门控记忆、任意长/大容量检索、普遍梯度稳定、相变与生理 spiking 的强解释。

仍应标为**未执行**的事项：完整金融九参数的低精度端到端训练、严格 boundary-only 深层通信验证、配对多模态/音频、完整语言与多模态 backbone、同质量规模成本与能耗曲线。v4 尚未完成部分的最终计数、挑战与重放也不能先填 pass。

研究任务可以通过可复核的否定或范围受限结论完成；“全部障碍已经消失”是更强的科学主张，当前没有证据支持。不能不断改目标、删失败 seed、将每 seed 条件改成均值，或把独立单模态包装成全模态，来制造闭合。

## 8. Go / No-Go

| 决策对象 | 判断 | 理由 |
| --- | --- | --- |
| 发布本轮代码、数据来源、checkpoint、失败与审计 | GO | 证据可复核；可区分实现通过、实证未支持和未执行。 |
| 把固定完整模板作为可微连续值模块继续做限定研究 | GO | FP32 模板、真实神经参数 BPTT 与小任务训练已有实证；结论限于声明域。 |
| 宣称 Hepta 已证明新的通用 spiking/自由边界相变机制 | NO-GO | C1 与时间感知更新不足以替代动力学、生理和连续流证据。 |
| 宣称金融算子已稳定优于普通门控或 Transformer | NO-GO | 同图对照未建立风险形状收益；容量、时间范围、模型预算与任务不同，负结果仍在。 |
| 启动以“上述条件已经成立”为依据的完整 backbone 预训练 | NO-GO | 主质量门槛已有反例，encoder 归因未成立，配对多模态与同质量成本未执行。 |

NO-GO 的依据是当前质量、归因和外推证据，硬件资源只是后续执行约束。未来若另立新假设、预算和独立 holdout，可以继续研究；那属于新的实验，不改变本轮已经保存的验收与失败。
