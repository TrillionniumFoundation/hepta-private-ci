# HCSN 完整算子与受控实验：本轮研究结论

## 结论

本轮把“完整金融解析曲线能否进入可微神经网络”推进到了实际训练和独立重放：固定金融参数的完整股权及 C1 风险通道可以稳定参与 float32 BPTT；新的关联记忆在四项检索上达到五种子、32/64/128 步全部 100%。然而，**完整核的逐种子记忆标准仍有失败，金融算子相对普通门控的稳定独有收益仍未建立。完整语言 / 多模态 backbone 预训练的条件没有成立。**

因此，本轮不能给出“全部 blocker 已闭合”的验收结论。工程可实现性、有限任务能力和研究优越性分别判定。失败的种子、原始低精度测试、修正前计时与资源口径均保留；不会以平均值代替逐种子门槛，也不会把后续独立补证写成原失败测试已经通过。

## 2. 完整金融公式怎样成为可训练算子

原始来源为 [He & Xiong (2012), Rollover Risk and Credit Risk, Journal of Finance](https://www.princeton.edu/~wxiong/papers/rollover.pdf)。完整边界与价值式、独立积分 / BVP / PDE 参照在上一轮 `analytic/` 中保存；本轮继续使用该原式参照，没有用简化模型替换 A7。

### 2.1 Call 延拓与明确新增的风险通道

记 s=σ√m，x=log(V/V_B)，危险坐标 z=−x/s。将完整股权归一化：

\[
a(z)=\begin{cases}
E(-sz)/(E(-sz)+V_B),&z<0,\\
0,&z\ge 0.
\end{cases}
\]

原股权满足边界值及一阶导为零，因而这一延拓具备 C1 接合条件。原首达函数 F 的边界导数一般不为零，直接延拓不能提供第二个自动 smooth-pasting 的“put 神经元”。本轮明确增加边界层设计，而不把它归称为论文原有结论。

设 ε=0.02s，L=1−F(ε)，k=−εF′(ε)/L，t=x/ε。在边界层内定义

\[
\widetilde F(x)=1-L(3-k)t^2-L(k-2)t^3.
\]

它在零点取值1、一阶导为0，在 ε 与原 F 的值、导数相接。编译时检查 0≤k≤3，使该层保持单调及有界。层外保留原 F，再定义

\[
q(z)=\begin{cases}
\tfrac12\widetilde F(s|z|),&z<0,\\
1-\tfrac12\widetilde F(s|z|),&z\ge0.
\end{cases}
\]

因此 q(0)=1/2、q′(0)=0；Call 的值和导数在边界均为0。危险侧的镜像和局部拼接属于新神经模型，不是原违约后的金融过程。14 个案例中，对原概率 F 的最大有意改变为0.00503985，对 q 的影响为其一半；这种模型修改与数值近似误差分开报告。

### 2.2 稳定的 float32 实现及其限度

完整公式在 float64 中编译为共享节点三次 Hermite 表；运行时使用 float32 分段多项式及匹配值 / 导数的有界尾部。每个通道4097个节点。没有使用 surrogate、STE 或自定义伪梯度；区间查找后的实际 C1 多项式直接参与自动微分。

| 检查 | 实测结果 |
| --- | ---: |
| 14 案例 float32 最大归一化值误差 | 1.8084×10⁻⁷ |
| 最大状态导数误差 / max(1,参照导数绝对值) | 4.9009×10⁻⁴ |
| 160 步、4 单元 BPTT 参数差分最大误差，float64 | 2.09×10⁻¹⁰ |
| 同一检查，float32 | 7.20×10⁻⁵ |
| 共享 float32 算子数组 | 131,128 bytes |

边界、拼接点、表尾、极大输入、区间导数极值和单调性另有检查。修复过 `minimum/clip` 在精确接缝上的半导数及独立浮点系数接缝问题，原错误的机制已记录。当前验证属于声明的14案例和数值容差，并非任意金融参数的统一误差定理。

**金融九参数在表中固定。** 可训练的是神经投影、边界偏置、时间常数、记忆及读出权重。固定模板本身可以是有效网络设计，但不能据此宣布九个金融参数的 float32 端到端梯度已解决。原 `analytic/jax_hx.py` 的 float64 参数梯度与原 float32 失败保持原状。

## 3. 从八槽记忆到正则化关联记忆

### 3.1 v3 的提升及其失败

v3 使用八个有界槽、学习的共享 key/query 寻址、普通 C1 关闭写门，以及可选的快慢神经元。没有根据任务名称、marker 列或答案手写路由。未修改的 v2 在同一新数据、600更新和长度课程下重新训练，分离预算变化与结构变化。

五种子平均准确率：

| 模型 | Memory128 | 四项 Retrieval128 | Memory512 挑战 | 八项 Retrieval128 挑战 |
| --- | ---: | ---: | ---: | ---: |
| 未修改 v2，同新预算 | 64.92% | 50.59% | 39.22% | 42.46% |
| v3 简化 HCSN | 100.00% | 88.65% | 64.38% | 76.09% |
| v3 同图 sigmoid | 100.00% | 88.57% | 64.38% | 76.21% |
| v3 完整 HX | 100.00% | 88.61% | 64.77% | 76.25% |
| 同协议 Transformer | 93.71% | 99.73% | 79.77% | 99.14% |

完整核已真实进入序列训练，但未解决 v3 的90%检索门槛。20个 memory 模型的写门诊断中，没有一个对全部 filler 严格关闭全局写入；模型主要依赖地址隔离。softmax 槽地址仍有非零泄漏，因此128步成功不能证明任意时距保持。更长和更多关联项的挑战实际暴露了这一限制。

### 3.2 v4 的方法、数学界与代价

为避免有限 softmax 槽碰撞，v4 使用16维学习 key、归一化 Gram 矩阵 G、关联统计 H 及逆累计写入质量 r。写权重 w∈[0,1]，key 范数≤1，value 各坐标在[−1,1]：

\[
r^+=\frac{r}{1+wr},\quad \alpha=wr^+,\qquad
G^+=(1-\alpha)G+\alpha kk^\top,\quad
H^+=(1-\alpha)H+\alpha kv^\top.
\]

最后一个 query 读取前缀统计：

\[
\mathrm{read}=k_q^\top(G+0.01I)^{-1}H.
\]

query 不写回统计量；神经快慢状态仍可响应 query。全部输入坐标经通用投影学习。训练和确认数据与 v3、v4开发数据分离。

零初态与凸更新保证 G⪰0、trace(G)≤1、H 每列范数≤1，因而条件数 κ(G+0.01I)≤101。利用 G/H 来自共同加权二阶矩的性质，还可将每个读取坐标的界收紧至1/(2√0.01)=5。独立审查核实了这些性质。界限保障数值结构，不保障分类质量或长期 BPTT 的统一条件数。

代价也增加：v4 完整核逻辑持久状态1373个标量，v3为630，约2.18倍。每个最终 query 多一个16维求解。当前只在序列末尾求解一次，不能把它当作逐token语言解码成本。可微内容寻址已有长期先例，例如 [Neural Turing Machines](https://arxiv.org/abs/1410.5401)；不能把增加关联记忆本身当成金融类比的独创性证明。

新确认集五种子、训练长度8/16/32；主要目标事先固定为 memory 在**每个种子、每个32/64/128长度**≥95%，retrieval对应≥90%。

| --- | ---: | ---: | ---: |
| 完整 HX + ridge | 98.77% | **93.85%** | 100.00% |
| 简化 HCSN + ridge | 99.43% | 97.17% | 100.00% |
| sigmoid + ridge | 98.57% | 92.87% | 100.00% |
| 纯 ridge 记忆 | 77.25% | 25.39% | 100.00% |
| GRU | 100.00% | 100.00% | 39.34% |

四种 ridge 变体的检索在五种子×32/64/128三个长度均达到100%。任务从固定8种键中无放回取4项，值有4类；新测试改变位置、值和干扰，不包含新键词表、同键覆盖、冲突或时间版本检索。这是该限定任务的检索修复，普通 sigmoid 和纯记忆同时成功，不能把结果归因于金融函数。完整核 memory seed2 的128步准确率93.84765625%已使主要标准失败；平均98.77%不能覆盖这个失败。

纯 ridge 记忆也出现明显长度下降。归一化统计中，旧项相对于不断增加的写入质量缩小，而固定正则保持不变；持续写入及神经内容耦合是需要研究的机制。当前诊断不能将所有下降唯一归因于某一项。没有按确认测试结果修改 ridge、筛种子或调整门槛。

## 4. 新 encoder 及完整算子消融

### 4.1 新数据与真实原始输入缺失

使用 AG News + 冻结 MiniLM，以及 CIFAR-10 + 冻结 MobileNetV2。各自2000训练、500验证、1000测试；原始train/test分离，精确内容哈希跨split交集为零。PCA只在训练特征拟合，16个局部块加1个全局块，统一成17×64维表示。公共来源、固定revision、数据行号和SHA均随manifest保存。

文本测试先删除原始单词，图像测试先在原32×32图像中央遮挡16×16区域，再完整重跑encoder和全部表示。没有留下未经扰动的全局特征。两个实验的dt均为1，它们是独立文本分类与图像分类，不是配对多模态、音频、真实异步事件或全模态训练。

### 4.2 完整核不是仅挂名接入

70个完整核消融checkpoint均完成指标与预测重放。另在七种实际代码分支、宽度4的初始化参数和2个样本×4个token上，表干预验证了计算依赖：full依赖Call和risk；full_sigmoid只依赖Call；no_call只依赖risk；memory_only两者均不依赖。该七分支的实际递推短BPTT随机方向差分均通过，float64差分步长3e−5时最坏误差1.146×10⁻⁹。这不是对70个训练checkpoint逐个做表依赖干预。

五种子平均准确率：

| 分支 | AG 干净 | AG 原始删词 | CIFAR 干净 | CIFAR 原始遮挡 |
| --- | ---: | ---: | ---: | ---: |
| 完整 HX | 83.96% | 83.22% | 76.36% | 41.96% |
| 同图 sigmoid，保留完整 Call | 83.84% | 83.06% | 76.52% | 42.72% |
| 去 Call | 84.02% | 83.08% | 75.60% | 42.16% |
| 去慢恢复 | 83.80% | 83.14% | 77.46% | 41.82% |
| 静态边界 | 83.16% | 82.50% | 73.96% | 41.80% |
| 去残差记忆 | 82.86% | 82.22% | 69.32% | 40.64% |
| 普通门控纯记忆 | 85.06% | 84.42% | 76.76% | 42.92% |

完整核与full_sigmoid参数精确匹配；它们的边界斜率不匹配。删除组件保持宽度，实际参数更少，所以不能将所有表行解释成单因素等参数因果效应。线性参考分别只有260/650个参数，使用不同优化器，是检查动态层必要性的参考。

对 full−full_sigmoid 的配对 seed/样本描述性 bootstrap，95%区间为：AG干净+0.12pp [−0.74,+0.98]，AG删词+0.16pp [−1.00,+1.30]，CIFAR干净−0.16pp [−1.64,+1.24]，遮挡−0.76pp [−2.68,+1.02]。这些后续分析未作多重校正，不用于模型选择。当前结果没有支持金融风险形状的稳定优势。

去残差记忆、静态边界的下降提示相应结构在这些设置中有用；普通门控记忆同时有竞争力，且去慢恢复在图像干净测试上高于完整模型。不能因为某个部件在某个任务有收益，就宣称整个金融类比具有独有优势。

## 5. 成本、重放和修正

新训练器按实际形状预编译，使用强dtype，校验优化器签名，没有丢弃的预热训练更新。回归夹具与旧训练器的相同4个更新参数逐项差为0。编译、优化器执行、验证、主机取样、纯logits预测和原始流水线分开记录。首次AOT执行仍含冷dispatch，不称为纯warm时间。

完整核原始输入到logits实测：固定seed0、每种模型同50条输入、包含tokenizer或图像解码/resize、真实encoder、池化/PCA及Head。AG完整核中位19.303ms，CIFAR中位11.783ms。300个完整核/控制流水线预测全部与对应存储预测一致。不同测量时段的encoder耗时足以改变排序，不能将小差异解释成金融核加速、等质量成本优势或能耗优势。

独立重放覆盖全部正式checkpoint；详细记录分别在各目录的audit文件。encoder40个神经checkpoint的四项指标最大差为0；完整核消融70个的独立NumPy指标复算最大差4.44×10⁻¹⁶；v3共120个test32回放差为0。v4的105组test32回放差为0；独立210组test64/test128最大差4.44×10⁻¹⁶，140组挑战最大差8.88×10⁻¹⁶，准确率均精确一致。校验哈希、数据隔离及checkpoint一致性，不将训练集分数当测试结果。

保留两项真实勘误。原线性流水线每次重复读取NPZ参数，修正脚本将数组在计时前物化，实际重测100次；旧脚本和记录保持不变。v4原字段fixed_operator_bytes统计了源float64数组262256bytes，运行float32实际131128bytes；另有资源勘误，没有重写原runner或成绩。

v4近条件数101的solve压力检查共有8个精度×尺度组合，其中2个失败，均为float32、小步长2e−5差分超过原0.003标准：float32为2/4失败，float64为0/4失败。原失败保留。独立float64闭式adjoint对比的最大误差2.536×10⁻⁶、较大差分步长的误差显著下降，支持原偏差主要来自差分分辨率。两份结论分别报告，不修改原容差。

## 6. 验收判断及完整 backbone 决策

| 阶段 | 可以验收 | 尚不能验收 |
| --- | --- | --- |
| 解析基础 | 原式复现保留；固定模板C1通道、float32状态梯度和完整核训练 | 任意九维金融参数的float32训练；把新风险通道称作原文put |
| 神经元动力学 | 已定义更新的有限状态/梯度检查、正时间间隔更新、受控训练 | 任意长期梯度稳定、生理真实性、整体非线性ODE精确流、boundary-only深层通信 |
| 小型序列 | 四项检索修复；大量配对控制、独立新holdout、挑战失败完整保留 | 完整核逐种子记忆标准、无界长度 / 容量、跨所有任务的统一优势 |
| 共享 encoder | 新文本和真实图像、冻结encoder、原始输入扰动、组件消融 | 可归因于金融算子的稳定收益、配对多模态与真实连续事件流 |
| 完整 backbone | 有可复用代码、协议、保存的checkpoint和失败判据 | 本轮未启动；无同质量规模成本曲线、GPU / 能耗或全模态预训练证据 |

当前结论是：**可作为可微动态层继续研究，尚不足以把完整金融核选为新大模型 backbone。** 这一决定来自验收证据，不能通过扩大训练规模自动消除。修复后的内容寻址能力也不构成金融算子创新性的证明。

后续若重开实验，需另设未触碰的开发 / 确认集，针对泄漏与归一化质量稀释提出明确机制，并在同图普通门控和纯记忆控制下检验；不能反复挑选当前测试种子直到通过。若最终优势来自一般记忆模块，应按一般记忆架构报告其贡献。完整backbone阶段仍以可重复、可归因的质量收益及同质量成本证据为进入条件。

## 7. 关键语义边界

原金融模型解决的是估值与最优停止；其解析解不是神经时间动力学的解析解。当前输入依赖boundary是神经坐标偏移，金融V_B在模板编译时固定。神经层读出还包含快慢状态和记忆，未验证“只通过原文V_B传递信息”的深层网络。

指数项精确处理的是一步冻结驱动下的线性泄漏。槽和ridge写入按事件进行，w虽能通过log(1+dt)学习时间信息，却未被构造成dt半群增量；一般dt趋零时仍可写记忆，拆成两个相同事件可改变状态。因此当前BPTT是已实现离散更新的真实梯度，不是整体非线性连续流的精确梯度。

C1使一阶反向传播可用，但不自动产生脉冲极限环、相变或稀疏事件执行。单元有界不蕴含Jacobian乘积有界，新增memory状态也有真实资源成本。HCSN是本研究原型名称，这些未完成主张均保持单独标注。
