# 完整金融公式的 C1 神经通道与 float32 编译核

## 本轮解决了什么

本目录实现并验证了一个可以直接放进 JAX `lax.scan` 的完整模型派生算子：Call 的模板值来自 He–Xiong 全部有限期限股权公式 A7；风险来自 Eq. (9) 的首达函数，并明确增加一个局部 C1 拼接和神经危险侧延拓。金融公式先在 float64 编译，运行时使用 float32 的共享节点三次 Hermite 插值。**14 个已声明参数案例、两种运行精度、状态梯度、边界和尾部、极端输入及短 BPTT 全部通过预先列出的标准。**

这关闭的是“固定金融参数的完整曲线能否以 C1、稳定 float32 形式参与神经状态训练”这一实现问题。**没有关闭任意九维金融参数的 float32 端到端训练问题**：金融参数在每个模板中固定；本核可微的是输入状态、神经阈值／边界偏移和使用它的神经权重。原目录 `analytic/jax_hx.py` 的低精度失败原样保留，仍可使用其 float64 原式进行金融参数研究。

风险通道是新增神经设计，不是原论文已经给出的独立 put，也不再是边界层内未经修改的违约概率。表查值是受控数值近似，不宣称运行时逐次精确求解闭式 A7 或最优停止问题。

## 1. 坐标、Call 与风险

令 s=σ√m，危险坐标为

\[
z=\frac{\log(V_B/V)}s,\qquad x=\log(V/V_B)=-sz.
\]

z=0 为神经边界，z<0 为金融延续区。原式边界 V_B 在编译时按 Eq. (12) 计算，完整 A7 股权归一化为

\[
a(z)=\begin{cases}E(-sz)/(E(-sz)+V_B),&z<0,\\0,&z\ge0.\end{cases}
\]

股权 E(0)=E′(0)=0，因此这个延拓为 C1，并在非负股权条件下落在 [0,1]。本次编译检查了非负性，没有将失败值直接截断成零来冒充原式。

### 风险的明确局部修改

设原 Eq. (9) 首达函数为 F(x)，期限取 m。F(0)=1，但 F′(0)一般非零，直接常数延拓不能 C1。固定拼接宽度

\[
\epsilon=0.02s.
\]

记 L=1−F(ε)>0、k=−εF′(ε)/L，t=x/ε。在 0≤x≤ε 定义

\[
\widetilde F(x)=1-A t^2-B t^3,\qquad
A=L(3-k),\quad B=L(k-2).
\]

在 x≥ε 仍取原 F。这样有

\[
\widetilde F(0)=1,\quad\widetilde F'(0)=0,\quad
\widetilde F(\epsilon)=F(\epsilon),\quad
\widetilde F'(\epsilon)=F'(\epsilon).
\]

若 0≤k≤3，则 2A≥0、2A+3B=kL≥0，所以 t(2A+3Bt)≥0；拼接严格保持非增并位于 [F(ε),1]。编译器对该条件逐模板检查，不满足就报错。当前 14 个案例全部满足。

最后定义神经风险门：

\[
q(z)=\begin{cases}\tfrac12\widetilde F(s|z|),&z<0,\\
1-\tfrac12\widetilde F(s|z|),&z\ge0.\end{cases}
\]

于是 q(0)=1/2，左右导数均为零，q∈[0,1] 且单调非减。默认侧的镜像是为神经再生相位新增的定义；金融模型本身在违约时终止，没有这一神经恢复分支。当前 q′(0)=0，与旧简化 q′(0)=1/2 不同，这个变化在后续模型比较中应明确。

14 案例中，拼接对**原概率 F** 的最大有意改变为 **0.00503985**；对 q 的影响是它的一半。此数与插值误差单列，不能把这种建模偏差藏在浮点精度误差里。

## 2. float32 稳定化的具体方法

`tables.py` 使用未修改的 NumPy/mpmath 金融参考计算模板。Call 在 t=log(1+x/s) 坐标上采样，风险在 u=x/s 坐标上采样，每个通道 4097 个节点。单调 PCHIP 给出内部斜率，Call 在原点的斜率强制使用原模型正确值零；风险首节点使用原 F 的解析斜率。

运行时 `kernel.py` 从模板取得**相邻区间共享的节点值和斜率**，使用增量形式的 Hermite 基。共享端点使对应实数插值函数 C1；增量形式避免近乎相等的 O(1) 值在求导时严重消差。没有 surrogate、STE 或 custom JVP/VJP。`floor` 仅用于定位区间；共享节点的两侧导数一致，实际可微对象是连续分段多项式。

模板保留幂基系数以兼容离线编译，但运行时使用其共享节点信息，不独立求值舍入后的两侧幂基多项式。FP32 舍入残差仍在证据中量化，并不声称计算机浮点运算具有无限精度连续性。

### 超出表范围

Call 表到物理对数距离 x=8；风险表到 u=max(16,2|as|+12)。超界时采用值和一阶导数匹配的指数尾：

\[
a(x)=1-(1-a_L)e^{-k_a(x-L)},\quad k_a=a'_L/(1-a_L),
\]

\[
F(u)=F_Ue^{-k_F(u-U)},\quad k_F=-F'_U/F_U.
\]

这是有界尾部数值近似，不是以硬 clip 截断原曲线。尾部与原式的差异包含在 x/s 最远至 120 的数值比较中；±10³、±10⁶、±10³⁰ 另做有界／有限值压力测试。

**发现并修复的真实接缝错误：** `clip` / `minimum` 在恰好界点的 AD 约定可能给出半导数。例如风险 z=−0.02 曾返回 0.236632，而两侧正确值约 0.473265。现在用严格不等式 `where`，在接缝选中 identity 分支，保留复合 C1 函数正确的导数。Call 表尾也修复了相同问题。

## 3. 实际验证

标准在 `protocol.json` 中于全量检查前固定：归一化输出绝对误差≤5e−6；状态导数误差除以 max(1,|参考导数|) 后≤5e−4；有界性容差1e−6。它们是神经归一化函数的标准，**不是给旧原始金融金额测试降低门槛**。测试包含上一轮受控 JAX 域的全部14案例，每例约18000个值位置和2800个导数位置，原点、窄拼接层、普通区间及尾部均有专门采样。

| 检查 | float64 编译表运行 | float32 编译表运行 |
| --- | ---: | ---: |
| q/a 最大值误差 | 5.200e−8 | **1.808e−7** |
| 状态导数最大归一化误差 | 4.901e−4 | **4.901e−4** |
| 边界 q,a | 0.5, 0 | 0.5, 0 |
| 边界 q′,a′ | 0, 0 | 0, 0 |
| 14 案例通过数 | 14/14 | 14/14 |
| 160 步、4 单元 BPTT 的参数有限差分最大误差 | 2.090e−10 | 7.196e−5 |

两种精度的状态导数最大误差几乎相同，表明其主要来自插值近似，而非 float32 消差。原式参照沿用已独立核验的完整 A7，并用原始 JAX float64 核计算状态参考导数。

`check_joins.py` 额外直接测试 z=0、±0.02、风险尾部、Call 尾部的精确位置与两侧。最大邻域导数变化为 1.689e−4，其中包含有限距离下真实曲率变化，不应当作导数跳跃。对每个三次区间，还计算其二次导函数在端点和内部极值点的符号，而非仅用随机采样宣称单调。

float64 各 Call 区间最小导数为零，风险区间最大导数为 −1.94e−61，满足所需符号。FP32 转换后风险尾部的最大正舍入残差约 1.67e−43；原始结果保留，没有把这种次正规数级残差写成严格的实数不等式证明。

## 4. 训练调用

在 `hcsn_research/` 为 Python 导入根目录时：

```python
import numpy as np
import jax.numpy as jnp
from next.full_kernel import as_jax_table, full_gates

table = as_jax_table(dict(np.load("next/full_kernel/baseline_table.npz")), jnp.float32)
q, a = full_gates(z, table)  # z supports arbitrary batch/time/unit shapes
```

`z` 已是标准化危险坐标；**不要在外部再次乘 s**。表应在训练开始前构造或加载一次，作为共享固定常量，而不是每个时间步重建，也不能把表加入优化器来宣称九个财务参数已经端到端训练。

默认表含原文基准金融参数。NPZ SHA-256：

`c77e407162061c06a9a34c5822b8751ebb2a71b1a5ff2a584c60e6b6ec63e764`

float64 数组总大小262256字节；转换成float32后131128字节，约128 KiB。这是固定缓冲区成本，应计入资源测量，不能只报告神经可训练参数数。多个神经单元可共享同一份表。
