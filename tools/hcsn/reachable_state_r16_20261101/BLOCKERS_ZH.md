## 1. 内容与寻址：合成绑定合同通过

固定 8 个拟合、3 个域、每拟合/域 128 个 episode，合计 3,072 个 episode、73,728 个目标；三个普通模型和 oracle 共输出 294,912 个预测。选择集选出的普通 cosine 记忆，在 IID、长时距、噪声干扰域的准确率分别为 `1 / 1 / 0.9993489583`。以拟合为独立单位的三个 Bonferroni 单侧下界分别为 `1 / 1 / 0.9988892795`，超过注册的 `0.90` 门槛。源码和模型先后冻结，确认不接触训练/选择 key。

这里学习的是合成组合 key 的 B→A 线性绑定。QUERY 只暴露 `kind/feature/dt`，真实 keyID 不参与普通模型路由。ridge 与 gated-delta 是明确保留的普通对照；精确地址 oracle 单列其特权信息。长时距域不含隐藏内容漂移，故不能据其通过宣称学习了长期动态保持。全正确域的 t 区间标准误为零也不是总体零错误证明。没有 HX 内容臂，也没有训练完整 GRU 或现代 SSM。

**继续闭合所需：** 在预先固定的真实或更广内容任务中，共享学习地址和内容接口，保留强普通检索/递归对照、完全隔离的 key 与域，计入全部训练/搜索/检索成本，再测试与 HX 动态控制结合后的净收益。不能用本内容准入门替代 D−B。

证据：[内容报告](content/REPORT_ZH.md)、[正式汇总](content/run_confirm_01/SUMMARY.json)、[独立确认审计](content/INDEPENDENT_CONFIRMATION_AUDIT.json)。

## 2. 联合分布与压缩：支持修复有效，净成本门失败

四个预注册动力学族全部保留。在扩展的连续时间公开日程上，`hx`、`phase_inhomogeneous`、`reset_mixture` 找到正概率历史对：数值边缘一致，联合后验不同，最优答案为 `[1,2]`；等权历史混合的最佳共同答案相对完整历史条件答案的损失分别为 `0.0004842071 / 0.0002200372 / 0.0000869221`。`free_drift` 没有严格答案分歧，结果保留为 false。四族内容边缘残差至多约 `3.45e-15`；这是 float64 数值见证，未升级为区间认证的精确连续证明。其时距扩展了 R15 原离散日程，证明的是条件最优答案有差，不是控制时机必有差。普通公开历史跟踪器完全等价。

新的 block2/4/5 投影保存相位边缘、块内内容边缘及当前 READ/REFRESH 似然。支持保持证明与数值拒绝路径分开：可表示的正支持不删去，不可表示的正支持下溢明确拒绝，不加 epsilon。原均值投影把合法 erasure 从 `0.1` 变为 `0` 的反例保留；新投影在此例仍为 `0.1`。因此不能把“替换压缩形式”写成“原均值压缩已验证”。

主确认 1,024 个共享世界，三压缩方式 × 两域 × 净收益/正确率的 12 个非劣下界都通过。但原 block2/4/5 在线 CPU 是 full D 的约 `4.32–7.47` 倍，所有压缩成本门失败。新冻结 fast 实现再用 namespace 18 的 512 个新世界确认：旧/新完整查询字段等价，fast/old 在线 CPU 为 `0.353609 / 0.359490`，工程速度门通过；fast/full D 为 `1.571268 / 1.555032`，含冷准备与 checkpoint 的 1,000 次使用比为 `1.564578 / 1.545647`，相对 full 的成本门仍失败。

**继续闭合所需：** 在合法支持上实现实际降维的传播和规划，保留 old/full 同 Q 控制、异常路径及所有失败尝试；以新的冻结确认同时满足质量与全成本门。有限质量非劣不等于正向质量增益。18/26/30 个编码浮点数也不等于当前 owner/规划器只使用这些状态：执行仍 lift 到 40 状态。

证据：[可达见证](results/REACHABLE_WITNESSES.json)、[支持证明](results/COMPRESSION_PROOF.md)、[压缩验证](results/COMPRESSION_VALIDATION.json)、[主确认](results/CONFIRMATION_SUMMARY.json)、[fast 报告](results/FAST_REPORT_ZH.md)、[fast 独立审计](fast_run_01/INDEPENDENT_AUDIT.json)。

## 3. 边界与价值控制：有限全观测最优性通过

新的维护任务有共同的 STOP/RUN/RESET、共同公开状态、已知 Q 和有限时域。它与 R15 隐藏内容任务分别声明。固定核后的“选择阈值 − 固定阈值”收益为 IID `+0.1238479004`、OOD `+0.1406901855`；“有限 DP − 选择阈值”为 `+0.0783083496 / +0.0935546875`。四个 Holm 校正 p 均为 `0.03125`，均通过有限 profile 门。

Bellman 反向归纳只证明注册的 40 状态、12 步、三动作、所选有限 reset 核的最优性。ordinary_same_q_dp 在全部 4,096 个基础 episode 上逐轨迹等价。该对照证明普通 DP 可获得相同收益。

**继续闭合所需：** 把固定/学习/自由边界置于同一个部分观测内容任务和连续控制问题，证明或数值认证相应 PDE/QVI 的收敛与最优性，保留同信息、同动作和同成本的普通控制器。当前不宣称连续自由边界最优性。

证据：[控制协议](control/PROTOCOL.json)、[有限最优性推导](control/README.md)、[训练清单](control/run_01/TRAINING.json)、[正式对照](control/run_01/CONFIRMATION.json)。

## 5. 再生：真实干预与有限选择已实现

RESET 确实从指定 recovery 核采样新 owner 状态、支付费用，再传播干预后的状态；它区别于只购买观察的 R15 REFRESH。核、恢复阶段及阈值时机使用互相隔离的训练/选择/确认命名空间，保留所有候选及其 CPU。

核单独选择及联合 reset 相对固定基线的描述性收益相同，为 IID `+0.3473764648`、OOD `+0.4452963867`。recovery-only 两域均为零，不能宣称恢复阶段选择已带来独立收益。这些机制对照是描述性的，不加入四个主要收益检验的结论。

**继续闭合所需：** 让 reset 核、恢复状态和时机在共同的部分观测内容任务中学习，并验证跨动力学与代价变化的稳定收益。有限候选搜索不能概括为通用神经 reset 学习。

## 6. HX 核心：原主门不能被辅助结果补过

主确认保留完整 2×2。D−B 在 IID 为 `−0.0005600586`，OOD 为 `+0.0001173503`；两域 Holm p 均为 `1`，两域均未通过原 `mean ≥0.01`、正的 t 区间下界及显著性门。D 与显式同矩阵普通 HMM 在全部 1,024 个世界查询轨迹相同。

更关键的是，8 个继承选择中有 6 个 B 已经是精确同 Q HMM。只剩 2 个拟合可能有非零 D−B；注册的双侧符号翻转检验最小可能 p 为 `0.5`。增加这些拟合的 episode 数不能使原显著性门通过。这个结论在读取新确认结果之前由算子等价推得，不是事后剔除失败拟合的依据。

**继续闭合所需：** 将“HX 参数估计/归纳偏置”、“联合状态表示”和“数值实现成本”拆成可识别的、新冻结问题；保留同 Q 等价对照，不删掉它来制造优势。需要跨动力学与真实内容、重新独立拟合的强普通比较及完整净收益证据。

证据：[可识别性结果](results/IDENTIFIABILITY.json)、[问题分解](MODEL_IDENTIFICATION.md)、[主确认汇总](results/CONFIRMATION_SUMMARY.json)、[主原始数据独立审计](results/INDEPENDENT_MAIN_AUDIT.json)。

## 7. 数值与生产：限定持续精度闭合，完整生产开放

固定边界、零漂移、常扩散、下端吸收/上端反射子问题的最细网格概率 L1 加首达误差为 `6.063371981e-5`，观察到空间约二阶、隐式 Euler 时间约一阶。未包含完整 HX 再生、移动边界及控制耦合。

pure-Q24 的整数质量、结构支持、误差账与受信恢复合同通过，但严格 1% 证书在正式种子 `163201/163203` 只完成 `22/33` 条事件，第 `23/34` 条明确拒绝。上界 2 的诊断执行不能替代该合同；首次 support-floor 失败原件继续保存。

独立的新 hybrid profile 保持同一 `167772/2^24` 上限。正式种子 `163211/163213` 各完成 549 条事件，回退 20/19 次；**每条 tape 的全部 549 个事件最终都付出 80 位区间重放/审计成本**。在第 274 条退出并另进程恢复，逐事件计数、支持位、误差账、时钟/游标、最终 native checkpoint 与完整区间缓存均一致。它认证准备后的整数权重有限模型；对原 float64 的小误差是另一项描述性比较。

**继续闭合所需：** 完整连续 HX PDE 收敛；原生价值规划器和真实 owner 的端到端状态恢复；长期历史和缓存增长界；实际能耗/网络及完整资源净收益。checksum 仅检测受信 snapshot 的损坏/混用，不提供授权或防回滚。本 profile 仍保留完整公开 tape。
