# R16：合成跨视图内容绑定的冻结确认

## 结论与交付范围

**本轮已经把“显式给定地址”推进到一个实际学习的跨视图 key 绑定接口，并在全新 key 上完成确认。** 预先选定的普通 cosine 检索，在 IID、长间隔、噪声加干扰三个域的正确率分别为 **100%、100%、99.934896%**；原协议的三个同时质量门通过。这个结果提供了可用的普通内容基线，不能记成 HX 或解析动力学的增益。

任务仍是合成的组合属性编码：256 个 key 来自四个四分类属性，两种未知正交变换产生 A/B 两个视图。它不是自然语言、真实音频或图像语义理解。每个 fit 的 96 个训练 key、64 个 selection key、96 个 confirmation key 互不重叠；各属性值仍来自同一预定词表，因此这里验证的是**未见组合 key**，不是未见语义概念。

本专项独立于 R15 每地址 40 状态动力学，尚未把此学习接口接入 HX/普通核心的完整二乘二。不能用本专项通过替代主实验 D−B、双通道收益或真实内容泛化的验收。

## 1. 学习接口与实际行为

训练只观察成对的 A/B 视图，学习线性映射

\[
W_\lambda=(B_{train}^{\mathsf T}B_{train}+\lambda I)^{-1}
B_{train}^{\mathsf T}A_{train}.
\]

每个 key 产生六组噪声配对，训练共 576 对。另 384 对 selection 视图只用于选择预先登记的三个正则化候选，没有重新拟合权重。实际 query 只含 `kind`、16 维原始 `feature` 和 `dt`，没有真实 key id、正确槽位置或目标内容。模型把 B 视图乘以所学 W，再访问自己从公开 WRITE 建立的内容状态。[源码](models.py)、[任务接口](task.py)。

三个普通候选共享这个 encoder：

- **cosine 槽检索**：通过学得的 key 相似度检索/覆盖，槽位总数有界。
- **ridge 槽检索**：对相同槽内容做正则化重构；矩阵求解缓存在 WRITE 后，查询没有重复做无必要求解。
- **gated delta 记忆**：在线残差更新的门控线性关联递归，预设步长、衰减与更新次数经 selection 选择。它不是经 BPTT 充分训练的 GRU 或现代 selective SSM。

每个 episode 有八个内容槽、八类值、24 次 query、重复查询、五次真正改变内容的 overwrite，以及明确标为 DISTRACTOR 的事件。所有核心都能按公开类型忽略干扰，未学习未知干扰识别。内容只在公开 WRITE 时改变，没有隐藏漂移。长间隔把 dt 乘以十，所以无衰减槽检索的时间稳定性不构成连续动力学优势。

额外保留确切地址 oracle：它只利用公开 WRITE 值，但额外获得 owner 的真实 key id。这是信息更强的上界，与三个普通模型分列。

## 3. 确认结果

| 候选 | IID 正确率 | 长间隔正确率 | 噪声/干扰正确率 |
| --- | ---: | ---: | ---: |
| 冻结主普通候选：cosine | 1.000000 | 1.000000 | 0.999349 |
| ridge | 0.999105 | 0.998983 | 0.971761 |
| gated delta | 0.866821 | 0.862386 | 0.832316 |
| 确切地址 oracle，上界 | 1.000000 | 1.000000 | 1.000000 |

主普通候选三域的同时单侧 Student-t 下界为 1、1、0.998889，均严格高于预登记 .90。统计独立单位为 **八个 fit**；24 个 query 先在 episode 内平均，128 个 episode 再在 fit 内平均。三域采用 Bonferroni family alpha=.05，df=7，临界 t=2.6418596705。[原协议](PROTOCOL.json)、[正式统计](run_confirm_01/SUMMARY.json)。

每个 episode 共享的固定 WRITE/QUERY 费用为 .05，即每 query 平均 .002083333。主候选净效用为 .997916667、.997916667、.997265625。此处费用来自强制公开操作，不含可选收费观察；本专项不证明自适应 value 控制的收益。

这些结果给出了一个明显强于当前 gated delta 候选的普通内容基线。后续解析核心必须与这个已能完成内容任务的基线比较，不能只使用约 83%–87% 的 gated delta 作为普通核心上限。三类模型存储量并不严格相同，因此这里也没有作同容量的架构优越性声明。

### 完美样本不等于未知总体零错误

两个域的全部 fit 正确率均为 1，原协议的 t 标准误因此为零。这个数值结果不能写成未知总体永远无误。另做了明确标为**确认后探索性**、不改变主门的保守诊断：对每个 fit/域，把整个 24-query episode 全部答对视为一个二项事件，在 24 个 profile 上作 Bonferroni 单侧精确下界。最小下界为 **.896203**。它约束的是整个 episode 全对，条件为这八个冻结模型及各域的 iid episode 生成器；不约束新的 fit 或开放域语义。它既不是原 query 正确率门，也没有用来挽救或改写任何门。[探索性诊断](EXPLORATORY_DIAGNOSTICS.json)。
