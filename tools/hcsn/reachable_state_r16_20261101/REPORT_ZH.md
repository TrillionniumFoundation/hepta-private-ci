## 3. 联合分布：可达见证成立，范围需保持准确

R15 先前见证并未完成可达性。本轮保持既有动力学和发射，使用公开 WRITE 后的 REFRESH／READ 历史 `(1,2)` 与 `(2,1)`。标签对称性使两条历史的相位边缘及历史概率相同；连续求根找到内容边缘也相同的合法时刻。两条历史概率为正、联合后验不同，并用独立 uniformization 再核对。

这是 float64 数值见证：四族的最大相位边缘残差约 `5.55e-17`、最大内容边缘残差不超过 `3.45e-15`。保存的 uniformization 尾界只认证 Poisson 截断部分，不包括全部浮点与求根误差；本轮没有给出区间认证的连续存在性证明。

|---|---|---:|
| hx | 是 | 0.0004842071 |
| free_drift | 否，保留零结果 | 0 |
| phase_inhomogeneous | 是 | 0.0002200372 |

这说明在该连续时刻查询协议内，仅保存两个边缘可能丢失未来决策所需信息。它没有证明原离散查询日程里的 READ／WAIT 时机差异，也没有把条件见证转为总体平均净收益。保存同样历史和联合状态的普通 HMM 得到相同收益。实际实现仍是 40 状态追踪器，尚无“一位摘要即可替代”的测得优化。

## 4. 支持保持压缩：支持合同验证通过，经济性未关闭

新增 block2／block4／block5 投影保留每个 phase 质量及组内 content 质量：

`C(p)[i,c] = phase_mass[i] × group_content_mass[group(i),c] / group_mass[group(i)]`。

它保持所有原有正概率坐标仍为正；可能增加支持，因而这里的“支持保持”指不删除原支持，而非支持集合严格相等。它保留当前 R15 READ／REFRESH 发射概率。若正概率乘积在浮点下溢成零，显式拒绝精度，不能加 epsilon 后继续。已存回归用例中，旧均值投影把合法 erasure 的概率由 0.1 变成 0，本轮投影保留 0.1。

正确性验证每个模式覆盖 556 个 belief，最大不变量误差 `4.44e-16`；32 个原模型世界产生 576 次合法观测，其中 37 次 erasure，1,728 项支持／恢复检查均通过。正式主确认的 12 个同时非劣界也全部通过。

| 编码形式 | 每地址编码数组字节 | IID 在线 CPU／完整 D | OOD 在线 CPU／完整 D |
|---|---:|---:|---:|
| 完整状态 | 320 | 1.00 | 1.00 |
| 原 block2 | 144 | 4.32 | 4.40 |
| 原 block4 | 208 | 6.33 | 6.51 |
| 原 block5 | 240 | 7.24 | 7.47 |

压缩行的 144／208／240 字节是可保存的紧凑编码数组，不是当前 owner 的实际常驻内存。当前实现仍保存每地址 320 字节的 40 维浮点状态，规划和传播也使用完整 40 状态；本轮没有测得在线内存下降，投影反而增加 CPU。

随后冻结向量化的快速 block2。旧档案工程重放核对 663,552 对投影结果，最大差 `5.55e-17`，并核对原行动／回答。新命名空间的 512 世界正式确认中，旧版和快速版的查询语义一致，四个质量非劣界通过；快速版／旧版在线 CPU 为 IID 0.35361、OOD 0.35949，即减少约 64%。

但快速版／完整 D 仍为 **1.57127／1.55503**；含准备、检查点与 1,000 次使用的比值为 **1.56458／1.54565**。工程修复门通过，完整状态净成本门失败。当前证据支持保留正确投影作为研究工具，尚不支持把它替换成默认生产路径。

依据：[投影证明](results/COMPRESSION_PROOF.md)、[正确性](results/COMPRESSION_VALIDATION.json)、[快速版报告](results/FAST_REPORT_ZH.md)、[新样本结果](fast_run_01/SUMMARY.json)、[独立审计](fast_run_01/INDEPENDENT_AUDIT.json)。

## 6. 边界、RESET 与恢复学习

单独建立全观测 40 状态有限维护 MDP。所有策略看到相同信息，具备 RUN／RESET／STOP 相同行动能力，支付相同费用；RESET 真正重置 owner 状态再继续演化。R15 的 REFRESH 仍然只是观测，不被重新解释成 RESET。

## 7. value／risk：真实费用补齐，独立收益仍失败

使用 R15 全部八组冻结权重，四个特征臂都是 STOP、READ 后 STOP、REFRESH 后 STOP 三种行动能力；没有新增动作或重新训练。特征按需计算：只有 value_risk 支付首次命中风险的冷启动增广矩阵指数和在线特征；其他臂不计算未使用风险，也不把算出来的风险成本隐藏在公共缓存里。

正式 1,024 世界、4,096 臂 episode、24,576 查询：

| 净收益差 | IID | OOD |
|---|---:|---:|
| value_risk−stop_value | +0.00012012 | +0.00046143 |

四个 t95 区间都跨零，Holm p 都为 1，也没有达到注册的 0.001 最小增益，故联合门失败。风险臂相对普通双通道的实际特征 CPU 为 **2.49／2.23 倍**，完整 warm owner 为 **1.113／1.074 倍**；冷启动加 1,000 次使用为 **1.111／1.072 倍**。历史拟合成本单独保留，不能把冻结权重当作免费，也不能把异机历史计时直接混入当前机器总成本。

## 8. 数值与完整过滤状态恢复

### 8.1 固定边界 PDE

使用零漂移常系数 Brownian 子问题，区间 `[0,0.8]`，下端吸收、上端反射。以独立谱展开作为参考，空间 16→256 格、四种时距；最细最大 L1 约 `6.06337e-5`，末两级空间约二阶，隐式 Euler 时间约一阶。早期参考尾界修复前的开发结果保留。

该结论覆盖固定边界子问题；完整 HX 的漂移、再生、自由边界和控制 PDE 仍待验证。

### 8.2 纯整数 Q24 与诚实拒绝

Native Rust 内核使用总和为 `2^24` 的整数概率计数和独立结构支持位；小于一个计数的正尾概率可以量化为零，但不能删除结构支持。精度证书不够时拒绝，不能添加 epsilon 或强制接收。模型绑定、校验和、支持、误差账、整数时钟及游标进入可信检查点。

首版“每个正支持至少一个计数”实现最大 L1 为 `1.44765e-4`，未过原 `1e-4` 门，失败源码和轨迹保留。支持位图版在正式两条长诊断轨迹中最大 L1 为约 `1.78e-5／1.91e-5`，Rust／Python 每轨迹 88,000 个概率计数、合计 176,000 个计数及对应支持／证书一致。但在原 1% 证书预算下分别只接受 22／33 条事件，于第 23／34 条拒绝。允许通用 L1 上界 2 的长诊断轨迹不能冒充原合同完成。

## 9. 成本、复现和证据完整性

本轮区分外层完整子进程 CPU、其内部函数计时、单个 actor 在线计时、冷准备与检查点、历史异机拟合、选择评估及失败尝试。嵌套计时不重复相加，未量到的启动／导入／GPU／网络／能耗不填零。完整账见 [RESEARCH_COST_LEDGER.json](results/RESEARCH_COST_LEDGER.json)。

主确认完整子进程 CPU 为 403.835366 秒，其中函数体 395.749232213 秒是嵌套分项。压缩优化确认完整子进程 CPU 为 64.113695 秒。内容训练加确认完整子进程为 27.484839 秒；双通道确认 workers 为 44.974841 秒、独立统计进程 2.663331 秒。控制只测得训练 0.738031771 秒与确认 2.299238360 秒函数体，记为下界。数值各次尝试测得 CPU 下界 45.838639815 秒包含单次 hybrid full 的成本，不再重复相加。

当前运行环境只读检查没有暴露 powercap 能量文件，也没有 nvidia-smi；没有测得焦耳、部署网络流量或吞吐。CPU 秒不能换算成能耗结论。证据见 [RUNTIME_MEASUREMENT_AVAILABILITY.json](results/RUNTIME_MEASUREMENT_AVAILABILITY.json)。

主 128 个 gzip 原始档案直接发布。内容／控制／双通道／快速压缩共 232 个原始档案保存为分片 tar.gz，索引记录原路径、字节、SHA-256 和 Git blob 身份，打包前后逐字验证。每片不超过 480,000 字节。数值正式和开发证据遵循各自 PUBLICATION_FILES 清单；失败尝试保留，重复开发目录由显式记录去重。还原命令、哈希检查和独立审计入口都在 REPRODUCE 中。

所有科研结果均是 standalone 执行与指定审计结果；未运行或宣称完整 Codex/Rust 工作区 CI、生产部署或上线验收。发布只保留研究分支和 draft PR。

## 10. 未闭合项的实际出口

后续应以能产生可区分结果的合同开展工作：把学习寻址接到同一个隐藏内容 owner，保留最强普通模型并共同计费；为低维压缩推导可闭合的推进／观测算子，或报告必要的近似误差与净成本；让 reset 核、恢复阶段和边界在部分观测及跨族任务中联合学习；给连续再生／自由边界 PDE 独立参考和网格收敛；把原生规划器、完整生产状态、授权、防回滚接入实际 owner，并在具备计量和网络环境的部署上验收。

这些都是当前尚缺的证据，不因有限 profile 的通过自动成立。尤其是，同 Q 普通模型与 HX 的可观测等价性不会被“多跑一次”解除。R16 因此保留核心门失败、双通道收益失败和压缩经济性失败，并把已经可复现的子结论作为后续工作的约束。
