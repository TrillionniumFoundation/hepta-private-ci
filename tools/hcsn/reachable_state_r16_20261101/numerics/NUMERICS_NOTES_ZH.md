本目录把两个有限问题做成了可执行验证：固定边界扩散的网格/时间收敛，以及 R15 同一有限算子的 Rust Q24 过滤、公开写入和四地址状态恢复。完整 HX 连续自由边界、原生价值规划器、生产 owner 接入、能耗与网络恢复仍在本目录的验收范围之外。

冻结基线为 `74144a3f5d5c77c953ecdc4708d3d90b56b67d3c`；原 R15 科学源码和结果不修改。`PUBLISH_MANIFEST.json` 列出本轮八个拟发布文件的 SHA-256 和 Git blob 身份。`LOCAL_DEVELOPMENT_FREEZE.json` 只说明额外开发轨迹生成前的本地冻结，**不构成远端预注册**。正式 seed `163201/163203` 必须等 root 发布、读回并返回源码提交后才运行。

## 1. 固定边界 PDE 的独立参照

研究的方程是

\[
  \partial_t u=D\partial_{xx}u,\qquad u(t,0)=0,\qquad
  \partial_xu(t,L)=0,
\]

其中 `D=0.045`、`L=0.8`、初始点 `x0=0.3`。这只覆盖零漂移、固定吸收/反射边界的子问题。与 R12 相同形式的半网格吸收面扩散率接受检验；再生、内容翻转、移动边界和控制均未放进该 PDE。

独立连续参照使用特征函数展开：令

\[
 k_j=(j+1/2)\pi/L,\quad
 u(t,x\mid x_0)=\frac{2}{L}\sum_{j\ge0}
   \sin(k_jx_0)\sin(k_jx)e^{-Dk_j^2t}.
\]

每个网格格子的参照质量直接积分该展开；存活质量为

\[
 S(t)=\frac{2}{L}\sum_{j\ge0}\frac{\sin(k_jx_0)}{k_j}e^{-Dk_j^2t}.
\]

首达概率是 `1-S(t)`。截断尾部用几何包络界记录，浮点下溢也保留一个正上界；1024 与 2048 项展开另行比较。该参照不导入有限网格生成器。

有限体积生成器在内点使用相邻速率 `D/h²`，下边界吸收速率 `2D/h²`，上边界反射。初始点在两相邻中心间线性分配。空间检验使用有限矩阵半群，时间检验固定 128 格并使用隐式 Euler，因此可以分开观察空间与时间误差。

`results/PDE_CONVERGENCE.json` 的实际结果：

- 16、32、64、128、256 格，四个时距 `0.15/0.45/1.05/2.10`。
- 256 格的最大“活跃分布 L1 + 首达概率误差”为 `6.063371981335831e-5`。
- 最后两级空间收敛阶为 `1.9986` 至 `2.0009`。
- 隐式 Euler 末两级时间阶约 `0.99773`、`0.99887`。
- 非负性、独立级数稳定性和预先写入执行脚本的误差门槛均通过。

这些数值结果没有证明完整 HX 再生模型的连续收敛，也没有证明连续策略最优性。

## 2. Q24 的概率与支持分别记录

`q24_core.rs`、`q24_main.rs` 和 checkpoint 路径的概率算术没有浮点类型。每个地址有 40 个非负 `u32` 计数，总和严格为

\[
 M=2^{24}=16,777,216.
\]

乘积、归一化及误差计算使用 `u128`；时钟使用整数微秒 tick。模型准备在 Python 中完成：R15 双精度矩阵被转成 `2^80` 尺度的非负整数权重，原生程序随后自行量化，准备误差单独记录。

**概率计数与结构支持不是同一个对象。** 一个正但很小的概率可以舍入为零计数，其支持位仍然为真。正时距转移支持由正生成器边的布尔传递闭包提供，零时距使用恒等关系。普通转移取支持并集，Bayes 取状态与发射支持交集，公开 WRITE 对相同相位取支持并集。这些操作保存有限模型中可能状态的集合。

若某次观测的 Q24 计数似然为零：

- 若结构支持交集为空，返回 `impossible observation`。
- 若结构支持交集非空，返回 `precision required: positive observation below Q24 resolution`。

第二种情况需要更高精度或精确重放。本轮没有实现该回退，也不会给出编造的后验。旧 R15 的无效均值消融保持原结果；这里的位图既不修改该结果，也不把零似然隐藏起来。

## 3. 误差界与拒绝规则

整数权重 `w_i` 的总和记为 `W`。最大余数分配产生计数 `q_i`，准确的整数误差半径是

\[
  r=\left\lceil\frac{\sum_i|q_iW-Mw_i|}{W}\right\rceil,
\]

因此对应的 L1 误差不超过 `r/M`。原生程序计算这个整数表达式，不用浮点估计它。

若当前误差界为 `e`，转移每行的量化 L1 误差最大为 `r_T`，传播后的再次量化误差为 `r_A`，则由随机矩阵的 L1 非扩张性有

\[
 e_{\rm next}\le e+r_T+r_A.
\]

Bayes 更新使用发射误差上界 `r_E`。近似未归一化观测质量为 `\hat Z>0` 时，由归一化映射的三角不等式有

\[
 e_{\rm posterior}\le
 \frac{2(e+r_E)}{\hat Z}+r_A.
\]

代码以整数向上取整实现，并将最大 L1 界限制在概率距离的通用上界 2。上界到达 2 只意味着认证已经没有辨别力，绝不表示误差很小。公开 WRITE 是确定性映射，不增加 L1 上界。所有会超出指定精度预算的更新在修改地址、时钟、操作计数之前拒绝。

该数学误差界针对整数权重定义的准备后有限模型。原 R15 双精度模型到该 fixture 的转换误差另行测量，本轮最大行 L1 为 `2.0336315786387144e-15`。独立双精度比较使用的 `1e-12` 松弛只用于这次有限轨迹的浮点核验，不是任意历史长度的总误差证明。

长诊断轨迹使用上界 2，以观察计数误差；另一个独立执行使用 `167772/M`（略小于 1%）的严格门槛。严格执行会在证书过宽时拒绝，实际拒绝位置必须披露。**诊断轨迹能跑完不等于整个轨迹都获得了 1% 精度认证。**

## 4. 保留首次失败

首版试图强制所有正概率至少占一个 Q24 计数。549 个因果事件后，最大双精度参照 L1 误差达到 `1.4476539484950985e-4`，没有通过 `1e-4` 门槛。源码、模型、事件、完整压缩轨迹和 CPU 收据保存在 `results/development_support_floor_01/`，其中 `SOURCE.tar.gz` 可恢复失败版本。

改为支持位图后，原开发 seed 的最大误差降为 `1.652492035863518e-5`。另外两个开发 seed `161102719/161102733` 分别得到 `1.2272990852179342e-5`、`2.0646600225850903e-5`。这三次均是开发结果，不是独立统计确认，也没有调宽原误差门槛。

每个完整轨迹有 549 次操作，连同初态检查 2,200 个地址状态、88,000 个概率计数。独立 Python 整数实现逐项检查计数、位图与误差界；浮点内容 argmax 一致仅作描述，不等于整个价值规划器动作一致。10 项 Rust 测试覆盖稀有合法观测、结构零、溢出、原子拒绝和恢复错误。

## 5. 恢复保证及其边界

checkpoint 保存四地址计数、支持位、累积误差界、整数时钟、已完成操作计数与模型文件 SHA-256。文件写入后同步，再原子重命名；Unix 路径另同步目录。恢复要求 schema、长度、模型字节身份、校验和、维度及概率合同全部满足。

独立 Python `hashlib` 检查原生 SHA-256 与文件字段。中点退出后新进程恢复，余下每一步和最终 checkpoint 必须与不中断执行逐字节一致。在受信 snapshot 的恢复模型下，误差账完整保留，因此正常重启不会获得新的精度预算；攻击者重算校验和或回滚旧 snapshot 不在本合同内。

这是一份**过滤内存**的恢复合同。它不保存待执行规划树、完整业务 owner 状态或网络交互，也不提供签名、授权、防回滚协议和生产部署资格。SHA-256 在这里检测损坏并绑定模型，不构成对恶意写入者的认证。
