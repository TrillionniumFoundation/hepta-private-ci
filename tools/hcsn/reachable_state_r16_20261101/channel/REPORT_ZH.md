# R16：value/risk 的实际特征成本与同能力确认

## 结论

**本轮已经拆掉 R15 中“四种特征策略都共同 eager 计算 risk”的成本混淆；冻结 value/risk 策略仍未建立稳定独立收益。** 两个域、两个参照的四项预登记检验均未通过，Holm p 均为 1。value/risk 的实际特征 CPU 约为普通双特征的 **2.49 倍、2.23 倍**；包含真实 owner 执行的暖运行 CPU 约高 **11.28%、7.36%**。这些成本比是当前实现的描述性计量，不是部署时延显著性结论。

本研究只复用 R15 已训练的一次动作 controller。它回答的是这四组旧权重和当前任务中的真实特征收益/费用，不能说明所有风险特征无用，也不能替代完整价值控制、金融双通道或连续自由边界的研究。

## 1. 什么保持相同，什么实际改变

八组拟合 HX 法则和四组 learned weights 均从基线 `74144a3f5d5c77c953ecdc4708d3d90b56b67d3c` 的 R15 原始 training 文件完整复用。没有重新训练、重选策略或使用新确认对象选择参数。[协议](PROTOCOL.json)、[精确源码/输入摘要](SOURCE_FREEZE.json)。

四臂始终有相同动作能力：在 query 起点选择 STOP，或执行一次 READ/REFRESH 后 STOP。所有臂使用相同公开 typed 地址、固定截止时刻、观察核、世界与费用。没有把弱一次动作策略同三槽精确 planner 混比。特征 provider 只拿到当前条件分布、公开时间与价格；目标只在动作和答案提交后由 owner 取得。

唯一机制改动是计算实际需要的特征：

| 策略 | 特征维数 | 实际执行的额外算子 |
| --- | ---: | --- |
| state/confidence | 8 | 无终点 value、无首达 risk |
| STOP value | 9 | 终点预测正确率 |
| value/risk | 10 | 终点预测正确率＋自然首达概率 |
| ordinary dual | 10 | 置信度平方＋phase 均值的 logistic 变换 |

这里 value 不是金融股权价值，risk 不是一条自动产生恢复运动的力。它们都是同一可用后验的派生统计量。每个臂独立恢复空缓存法则；公共传播矩阵库对四臂同样计费，只有 value/risk 构造三个所需首达增广矩阵指数。首个 expm、复用后的矩阵运算、权重应用以及真实后续行为均计入相应账户。[按需特征](features.py)、[显式注入的执行器](execution.py)。

## 2. 冻结、等价和执行完整性

新源码/输入冻结提交为 **`df19a18ae4984bcc3a23e0bfe1f7f048ce905fa5`**，在远端发布且逐字读回之后才开启 namespace 17。manifest 绑定 23 个源码/输入文件，包括八份原 training archive。

冻结前独立开发 namespace 917 共跑 128 个臂 episode、768 个 query。新 owner 与原 R15 的完整 query 记录相等，实际特征向量逐位误差为 0；state/confidence 与普通双特征没有创建 risk 缓存，也没有调用 STOP-value 算子。没有改写 R15 或 monkeypatch 全局函数。[开发等价检查](DEVELOPMENT_EQUIVALENCE.json)。

正式确认完成 **8 fit × 2 域 × 64 worlds = 1,024 个共享世界**，四臂共 4,096 个 episode、24,576 个 query 预测。16/16 worker 成功；128 个原始 archive 全保留，最大 101,216 bytes，低于仓库单个二进制 512,000-byte 限额。数据包含完整 owner 路径、公开 prefix、实际特征、动作、答案、真值、费用和时间；未筛选成功子集。[正式统计](run_confirm_01/SUMMARY.json)、[完整进程回执](run_confirm_01/PROCESS_RECEIPTS.json)。

独立确认审计从公开 WRITE 重建四地址 belief，另行使用矩阵指数计算 value/risk，重放 6,566 个实际观察 token，并重算全部动作、答案、四项检验与冷热成本。**4,440,938 项比较通过，最大数值差约 2.53×10⁻¹⁴**；只有 value/risk 的 6,144 次在线首达调用被确认，其他臂为零。[独立审计](INDEPENDENT_CONFIRMATION_AUDIT.json)。

## 3. 四项独立收益检验

| 预登记效用对比 | IID 均值与 t95 区间 | OOD 均值与 t95 区间 |
| --- | --- | --- |
| value/risk − STOP value | +0.000120 [−0.000437, +0.000678] | +0.000461 [−0.000721, +0.001644] |
| value/risk − ordinary dual | +0.000537 [−0.000340, +0.001415] | +0.000467 [−0.000718, +0.001651] |

四个均值均为小正数，区间均跨零。统计单位是八个配对 fit；每个 fit 先平均其 64 个 world，每个 world 先平均六次 query。每项穷举 256 个符号配置，再对两个对比×两个域共四项作 Holm 校正，调整后 p 都为 1。

原协议要求四项同时满足：均值至少 .001、t95 下界大于零、Holm p<.05。**四项均未通过，整体收益门为 false。** 不使用动作翻转、单个正 fit 或其他成本复用点挽救主门。

| 策略 | IID 正确率 | IID 扣费效用 | OOD 正确率 | OOD 扣费效用 |
| --- | ---: | ---: | ---: | ---: |
| state/confidence | .923828 | .909538 | .918945 | .899110 |
| STOP value | .923828 | .909575 | .918945 | .899206 |
| value/risk | .924154 | .909695 | .919596 | .899668 |
| ordinary dual | .923503 | .909158 | .918945 | .899201 |

这批四种旧 learned 策略都没有选择 READ，实际形成 STOP/REFRESH 决策。相对 STOP value，加入 risk 在 IID/OOD 各改变 16/41 个首动作，答案各改变 1/4 次；相对普通双特征则改变 17/31 个首动作、2/4 个答案，每域分母为 3,072 query。轨迹分叉后的比较不等同相同 public prefix 上的局部因果效应；这些计数仅是预设描述性证据。[动作与成本细节](run_confirm_01/DESCRIPTIVE_DETAILS.json)。

## 4. 真实冷/暖成本

每个臂的冷账户包括原输入 decode、法则恢复和公共传播库；value/risk 再承担首达库。其三个首达增广 expm 的平均 CPU 为 IID **0.625 ms**、OOD **0.670 ms**。其他三个臂没有这项矩阵库，只有计时函数本身的小开销。正式阶段共 48 个首达库矩阵及 6,144 次真实 risk 特征调用，均由 value/risk 支付。

| 策略 | IID 暖特征 CPU/query | OOD 暖特征 CPU/query | IID 暖 owner CPU/episode | OOD 暖 owner CPU/episode |
| --- | ---: | ---: | ---: | ---: |
| state/confidence | 37.16 μs | 34.45 μs | 2.717 ms | 2.586 ms |
| STOP value | 50.81 μs | 46.52 μs | 2.832 ms | 2.716 ms |
| value/risk | 101.06 μs | 87.58 μs | 3.085 ms | 2.887 ms |
| ordinary dual | 40.59 μs | 39.20 μs | 2.772 ms | 2.689 ms |

把真实冷准备加上 1,000 次暖 episode，value/risk/ordinary-dual 比为 **1.110643、1.072480**。这只是当前函数范围的复用账户：包含共同的审计快照与 checkpoint 哈希开销，尚未把部署导入、生产通信、能耗或历史全部学习费用转换到同一成本尺度；不能称为完整生命周期经济性。

正式确认的 16 个完整子进程合计 **44.974841 CPU 秒**，包含各进程导入及最终写出；统计子进程另外 **2.663331 CPU 秒**。这些外层账户已经包含内层特征、owner、准备和 archive I/O，不能再次加总。

另保留原 R15 的历史训练函数 CPU **25.714871 秒**，其中 learned-controller 部分 **2.021036 秒** 已包含在前者中。它们来自原主机和原函数范围，没有被解释成当前主机重新训练的时间，也没有因为重用权重而变为免费知识。实验没有测量能耗、网络或完整生产 owner 恢复。

## 5. 这次推进关闭了什么

实际特征计算不再被 eager 的公共 risk 工作掩盖；四个策略的动作范围、公开信息、旧训练和原始成本都有明确身份；真实首个 expm、暖复用、全部 owner 费用及失败规则已经进入可复核代码和证据。

**稳定的 value/risk 独立效用收益仍未关闭。** 当前控制器只在固定 STOP 训练前缀上学过一次动作收益，当前 OOD 只改变时间间隔。需要更充分训练、在部署 prefix 上校准、相同更强控制能力及真实内容任务，才能扩大结论。增加计算费用而只有当前近零且不稳定的收益，不足以获得生产采用资格。
