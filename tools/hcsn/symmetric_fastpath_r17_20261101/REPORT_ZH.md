# R17：对称有限生成矩阵快路径与完整执行成本

本轮建立了不改模型身份的有限矩阵加速候选，完成同源码工程重放。算子和行为一致性通过；**实际整段执行没有建立10% CPU优势，解析核心独立收益与生产资格仍未闭合**。

## 冻结身份与数学机制

源码在远端 `8e62cf1a57d2b07c9f9207e1bb01b0e909bfed54` 回读核验后执行；41个输入身份由 SOURCE_MANIFEST.json 约束。保留原八份拟合及金融核，未重新训练。`Q`、发射矩阵、奖励、参数、operator identity 与 model identity 原样保留。

十个物理相位×四个内容的生成矩阵先接受逐块位级对称性检查，再用20×20 Metzler上三角提升计算跨内容质量，避免相近指数矩阵相减；不裁剪、不加概率地板、不重新归一化。证明及适用条件见 PROOF_AND_SCOPE.md。

16个HX/同矩阵普通HMM和3个free模型符合快路径；5个free模型因内容对角项约一个浮点舍入差而被严格拒绝，显式走原稠密实现。没有把近似对称当作精确对称。

## 失败保留与成本边界

第一轮24模型全部数值/ODE比较通过，但验收代码错误地要求每个free矩阵都必须走快路径，违背已写明的回退合同；因此门失败并在campaign前停止，原源码、结果、5.096156 CPU秒保存在attempt_01。第二版只修正该资格判断，启动时因create-only文件已存在而拒绝，未启动子进程；重复输出来源未确定，未归因于其他任务。第三版显式改用results_v2，并让行为门和子进程失败返回非零。数值、状态和动作阈值未变。

第三版第一轮campaign遇到磁盘满，四份完整fit档及第五份空文件、错误日志、12.918543 CPU秒全部保留。清理后，在新隔离checkout用完全相同源码/协议/样本命名空间完成重放，输出位于replay_01/results_v2。这是工程重放，不是额外独立样本。

完整重放外层子进程CPU **16.395342秒**；连同已计量失败尝试，互不重叠子进程CPU下界 **34.410041秒**。内部准备和execute秒数不重复相加。父监督器、发布、旧训练及部分启动检查未完整计量，因此不是研究全生命周期总成本；无GPU或焦耳读数。

## 判定

`finite_operator_gate=true`、`exact_behavior_gate=true`、`query2_checkpoint_numeric_gate=true`。完整原始矩阵、成对执行、检查点、失败、收据和冻结身份可复核。

`all_project_blockers_closed=false`，`production_activation=false`。该优化同样适用于同矩阵普通HMM，不能支持解析核心独占收益；连续自由边界、未知生成器、真实多模态、GPU/能耗及生产所有权仍需各自证据。
