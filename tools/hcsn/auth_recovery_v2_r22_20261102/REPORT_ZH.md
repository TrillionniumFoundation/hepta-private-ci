# R22 V2：双向绝对截止时间与认证恢复

V1的独立工程反例暴露了逐次socket读取超时可被慢速未认证连接无限延长的问题。V1源码、成功的完整性检查以及失败反例均保留。第一次V1慢速反例在独立审核源码远端发布前约11秒完成；它是工程发现，没有前置远端冻结属性。

V2独立建目录，修复服务端请求和客户端响应两个方向：单次frame只设一个monotonic截止时间，每次recv使用剩余预算，滴字节不会延长截止时间；请求和响应包含换行最多8192字节。服务端读取预算1秒、客户端响应读取预算3秒，响应写出也有超时。连接建立和发送的预算另行计算，不能把单次响应frame的3秒写成整个API端到端硬实时上限。
