4. Required boundaries for the final report

A. Fixed maturity is a model convention, not recovery of maturity from data. Conditional on fixed emissions, R13 flow's three physical coordinates have rank two; after fixing maturity and removing two emission row-shift gauges, the twelve-dimensional joint local raw-law derivative has full rank at the declared point/design. Discrete bit-label permutation remains and requires labeled training outcomes. None of this is global identification, finite-sample recovery, or continuum identification.

B. The equal-flow/different-fee witness is a statement about R13's financial payoff/read-cost mapping. R14 deliberately supplies public synthetic task prices (READ .03, RESET .025, elapsed-time .01) and terminal current-bit correctness. It does not learn or identify the original financial fees. Equal flow alone does not justify an inferred task-cost model.

C. R14 RESET repairs an external sensor while preserving the physical/content state and consuming a full interval. It is separate from natural first-passage absorption/recovery and from resetting internal memory. Every baseline has the same maintenance permission. A useful maintenance witness is not proof that intrinsic neuron reset is necessary for semantics.

D. The learning objective is frozen actual-policy evaluation supervision: 0.1 posterior CE plus 20 weighted Q-pi projection error. A true-net-Qpi softmax with temperature .1 determines fixed action weights. Per-action state-independent fees cancel from an unweighted normalized-belief Q-error; these fixed net-value weights retain fee effects in the priority. This is not a policy gradient, exact policy optimization, or a guaranteed improvement in realized task utility.

E. The common planner identity must match across A/B/C/D within a fit. The final HX core's fitted dynamics can differ from the common planner, intentionally. A final-matrix generic HMM must still reproduce D's filtering/actions with the same planner; equality blocks any HX-exclusive filtering interpretation. Any positive D-B would remain conditional on the chosen ordinary candidate and this finite synthetic family.

F. The OOD split changes time intervals only. It is not a new physical family, new semantic contents, a multilayer language model, or long-term memory evidence. Financial pure FP32, native Rust ownership and deployment economy stay outside admission.
