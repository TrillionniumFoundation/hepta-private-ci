# Hepta neuron R12：统一模型的完成证据与设计结论

## 1. 结论

本轮已经完成并执行了一个研究实现：完整 He–Xiong 金融核、有限首达／恢复过程、内容分布学习、公共价值控制器和 Rust 原生执行共享同一模型。八个种子、三种核心共 24 次正式拟合，全部参数与源身份先于新确认数据发布。

**本轮结果支持继续研究联合分布状态与可验证传播；没有支持把完整金融核升级为 Hepta 的默认基础 neuron。** 最重要的确认量 D−B 在 IID 为 +0.002965，在 OOD 为 −0.005578，均未通过预先规定的增益条件。保守 CPU 成本准入也未通过。

还有四项直接改变设计的发现：

1. 内容与恢复阶段的相关性确实能改变后续最佳动作，单独保留边缘分布仍可能丢失决策信息。
2. 本轮内容动力学只识别 sigma 和边界两个独立方向，不能分别识别 liquidity 与 maturity；金融参数不能仅因有梯度就全部设为自由参数。
3. 当前有限网格误差足以改变实际动作，精确计算矩阵指数不能消除建模离散误差。
4. 同模型 HMM 与原生分布核心之间的少量答题差异来自约 1e−15 的浮点并列值，不能作为 HX 独有收益。确认后新增的数值修复候选不替换原确认结果。

独立复核完成 944 项检查：逐 episode 重放全部 16×8 个执行臂，重算 16×5 组序列输出，独立枚举符号翻转与 Holm，并核对读取、成本和冻结哈希。五处原生／HMM 动作差异均为两个答案数值并列，最大答案 Q 差为 6.67e−16。序列中 901 次两种实现的 argmax 差异也全部位于不超过 2.95e−15 的内容概率差内；后验校准一致不意味着有限精度下裸 argmax 的标签一定一致。

独立 `tie_resolution/` 候选统一采用绝对容差 1e−12，选择距最大 Q 不超过容差的最小动作索引，并返回被选动作的实际 Q。它已统一上述五处终止选择，但保留了容差边界两侧仍可翻转的反例。若动作 Q 的统一误差有界 epsilon，单步真实 regret 至多 `2*epsilon + tol`；后验误差不能未经传播分析直接代替这个 epsilon。此候选没有进入原确认，也未用已看过的数据重新宣称增益。

## 3. 现在统一的究竟是什么

每个 cell 的有限状态是二元内容与十个阶段的联合分布：八个 active 距离格、两个恢复阶段，共 20 个状态。恢复完成时以概率 0.75 保留内容，否则重新抽取公平 bit，因此有效同 bit 概率为 0.875。reset 距离以 `log(90/b_HX)` 为中心，固定物理标准差为 0.1。

完整金融核仍来自原 R11：自由边界 b、股权 E、首达 F、贴现首达 G、债券价值 debt，以及完整 5×10 一阶 Jacobian。桥接没有采用几何替代梯度。九个金融参数中只有 sigma、liquidity、maturity 在本轮训练；其余固定。

统一传播为

\[
p_{t+\Delta}^{-}=p_t\exp(\Delta Q_\theta),\qquad
p_{t+\Delta}(i)=\frac{p_{t+\Delta}^{-}(i)\ell_\phi(y\mid i)}
{\sum_jp_{t+\Delta}^{-}(j)\ell_\phi(y\mid j)}.
\]

训练的状态推进和后验监督使用这一 Q；规划对同一 Q 的所有潜在读取结果做加权；在线 C/D 调用 Rust 对同一 Q 做 uniformization；事件 CLI 对同一 Q 做 Gillespie 采样。内容改变、反复首达、两阶段恢复及复位均已写入 Q，没有在执行器外额外丢弃概率质量。

这里的“精确”限于有限 CTMC：矩阵指数、uniformization 和事件采样对应同一个有限模型。它不是原连续扩散首达的闭式精确传播。上界 0.8 的反射、有限网格和再生规则均是明确的扩展。

金融量的实际作用也必须分开：sigma 与边界进入内容动力学；E/debt 进入声明的任务收益与读取成本；F/G 保留为完整核输出与连续诊断。本轮没有证明五个金融输出各自具有独立任务贡献，也没有证明金融自由边界就是任务的最优停止边界。

### 内容确实参与了训练，但任务范围有限

输入是六个原始传感符号、一个恢复不可用符号、实际时间间隔及缺测标志。训练学习两类内容的符号似然和物理参数，损失包含完整联合后验交叉熵与内容标签损失。教师只由同一条因果观测历史构造；运行时不暴露隐藏内容、阶段、教师后验或未读取的 token。

这是二类合成内容任务。它不是文本理解、真实多模态内容学习或开放域推理的证据。

## 5. 哪些分布机制确实改变了动作

### 联合分布有必要，普通均值风险读出不够

实际模型的 3,192 次构造比较中，factorization 保留内容和阶段的全部边缘分布，却改变 52 次动作。最大见证的联合状态为：0.9 质量位于内容 0、距离 0.05，0.1 位于内容 1、距离 0.65。两种表示的内容概率和距离均值 0.11 相同；完整状态选择 READ，完整模型价值 0.9139904090；factorized 状态选择 ANSWER0，价值 0.9028047786，一次动作损失 0.0111856303。

另一个纯距离均值压缩目录的 1,764 次比较没有发现动作变化。该零结果也保留，不能把所有可能的信息损失都说成当前任务的实际需求。

### 恢复与金融量必须经动作验收

128 个固定开发 episode 中，去掉 equity bonus 没有改变动作或 utility；改为常数读取成本改变 9 条轨迹。恢复均值错设为 0.05 或 1.0 也改变实际读取和不可用读数。

单个开发样本中有些错设看起来更好，但独立精确策略树期望给出：去 equity bonus 效应为零；常数读取成本及恢复 0.05 均比完整模型低 5.6594e−5；恢复 1.0 低 3.20323e−4。样本中的偶然正差不能作为正确机制的反证或错设优越性的证据。

### 解析边缘化减少了一个明确来源的动作噪声

16 个实际因果 belief，mc32、64 次重复中，采样根节点 READ 后继观测与精确边缘化的动作分歧率为 4.6875%，排序分歧率 1.3346%，在同模型精确 Q 下的平均动作损失为 0.000376303，最大为 0.0164633。这只覆盖该一步观测边缘化；后续条件价值仍精确，不是 DQN 训练收敛证据。

## 6. 数值结果迫使设计继续分层

### FP64 梯度链已检验，参数可识别性未自动成立

完整 HX→boundary→reset→Q→矩阵指数→多步 Bayes→内容损失的中心差分误差，在 12 步、64 步和近边界 48 步场景分别为 3.525e−11、6.128e−11、3.755e−11。检查包括物理参数和观测 logits。金融桥接本身近边界的参数与状态导数最大缩放误差为 1.857e−8。

但 Q 对三个物理参数的 Jacobian 第三奇异值约 3.6e−11 至 1.1e−10，前两个方向约为 13–16 与 1.2–1.5：内容过程只有两个独立物理方向。实际拟合把边界恢复到约 65、sigma 恢复到约 0.30，却没有把 liquidity/maturity 分别恢复到真值。后续应固定其中一个参数、改用可识别坐标，或增加独立金融／任务价值校准目标。

upwind 分裂还有真正的 kink：mu=0 对应 sigma≈0.34641016，处于允许训练箱内。此处单侧导数不同。局部一阶梯度验证不能扩展为全域 C1 或二阶 AD 保证。

### 完整纯 FP32 仍未准入

候选通过股权 ODE 的 Green 积分等价式、`expm1`、稳定差商和 FP32 成对归约修复大项相消；没有改原 R11 源码或放宽阈值。

| 算法 | 失败导向固定箱内点 | 最大值误差 | 最大 Jacobian 缩放误差 |
|---|---:|---:|---:|
| 原 FP32 | 2/32 通过 | 0.0162873 | 61.8149 |
| 候选 FP32 | 20/32 通过 | 2.07109e−6 | 5.22242e−4 |
| 原 mixed32，内部 FP64 | 32/32 通过 | 4.41371e−8 | 6.88321e−8 |
| 候选 FP64 | 32/32 通过 | 2.4834e−15 | 2.49767e−12 |

原最坏点已降到约 1.3e−5 的 Jacobian 误差并通过，但冻结后的 33 点接缝检查中 FP32 仅 3/33，通过不了全域门槛。4096 次完整值/Jac 标量 CPU 执行，候选约 34.03/30.63 秒，原 mixed 约 10.59/13.23 秒。精度改善没有形成成本优势。所有失败与开发版本均已保留。

### 连续误差足以改变最佳动作

同一有限反射域连续参考下，当前 N8/N16/N32 首达最大误差为 0.286815/0.174220/0.097476。首格半格吸收修正候选降为 0.146659/0.028757/0.006371；该候选未混入已冻结训练。上界截断本身也会产生误差：一个长时例中有限域首达 0.756253，无上界首达 0.474939，不能靠加密同一有限域网格消除。

342 个同物理初始 law 场景中，N8/N16/N32 相对 N64 有 7/4/2 次动作分歧。明确例子：位置 0.04、宽度 0.03、内容 0 概率 0.875、dt=0.05，N8 选择 READ，N64 选择 ANSWER0；在 N64 有限模型下的动作损失为 0.0203203。N64 仍不是连续真值，但这个反例已经否定“局部核精确所以动作不受近似影响”的推断。

## 7. 原生执行与恢复的完成范围

当前冻结源码和二进制组合已经重新执行一般模型 67/67、实际完整金融参数化 Q 的 68/68 检查，原始回执为 `native/evidence/audit_frozen`、`contract_frozen`。不同历史组合的证据单独保留。

一般模型相对独立 SciPy expm 的最大误差为 3.186e−14，质量误差 8.693e−14；实际 Q 加七种观察的最大误差为 1.704e−14。传播没有通过末尾归一化掩盖失去的概率质量。

同一实际 Q 一次推进 dt=256，Rust 真实执行 1993 次跳变、51 次首达、50 次恢复阶段转换、50 次复位，其中 8 次切换内容。64 时间后退出进程，再由新进程推进 192，逐事件时间、节点、类型和最终 checkpoint 字节完全相同。pending 事件时刻、目标及 PRNG 一起保存；没有在恢复时重新抽样。

这是固定 Q 的研究 CLI。中途更新 Q 的剩余 hazard 迁移、生产运行时接入、GPU 和能源计费尚未完成。原生热执行也没有胜过合法缓存的矩阵传播：256 个同质 20 维 cell、dt=2.1 时，独立单线程测得 native 批 CPU 中位数约 4.230 ms，缓存矩阵约 0.235 ms；缓存准备成本另列。

## 8. 理论与两篇论文的关系

He–Xiong 给出债券、股权和内生违约边界的解析结构；原模型违约是清算终点。这里的恢复、重复首达和内容保留是新增机制，不能由原金融模型直接推出神经网络最优性。

Hölder 论文研究的是连续随机控制中 Bellman 目标的正则性与逼近复杂度，明确区分算子层面结论和实际采样 DQN 收敛。当前实现先建立了有限模型可证明的部分：

1. 行生成元 Q 的非负跳率和零行和给出正性、质量守恒与半群。
2. 固定模型的贴现 Bellman 算子是 gamma 收缩；本轮无贴现有限时域只使用非扩张与后向归纳。
3. 保留恢复阶段使状态 Markov；将阶段合并一般失去这一性质。
4. Bayes 更新需要正证据，若证据有下界 eta、似然有上界 L，TV 误差可被 L/eta 放大；小先验误差不能无条件推出小后验误差。
5. 若转移 TV、阶段奖励和终值的统一误差分别是 epsilon_P、epsilon_r、epsilon_g，则 H 步模型价值误差界为

\[
D_H\le\epsilon_g+H\epsilon_r+
[RH(H-1)+2GH]\epsilon_P.
\]

在相应统一 critic 误差条件下，部署 regret 至多 `2 D_H + 2 sum_t epsilon_fit,t`，再加动作求解误差。样本平均误差不能直接代入这个统一界。

吸收／复位边界的连续正则性、退化内容方向、状态—动作逼近秩、模型学习误差、优化误差和实际 SGD/DQN 收敛尚未合并为定理。没有把有限矩阵的光滑性冒称为上述全部条件已经满足。

原始来源：

- He & Xiong (2012), [Rollover Risk and Credit Risk](https://www.princeton.edu/~wxiong/papers/rollover.pdf)。
- Qi (2026), [Deep Q-Learning on Hölder Spaces](https://proceedings.mlr.press/v336/qi26a.html)。

## 9. 对 Hepta neuron 的设计决定

| 层次 | 本轮落实或应保留的设计 | 尚需通过的具体条件 |
|---|---|---|
| 状态合同 | 内容×活动／恢复的联合分布；首达、占用、事件计数分开 | 更大内容状态的压缩仍保留行动所需相关性 |
| 传播合同 | 训练、规划、Rust 传播和事件共用同一 Q 与恢复规则 | 连续域近似误差、模型更新后的恢复迁移 |
| 金融参数 | 保留完整核作受约束结构先验和价值标定候选 | 以可识别方向决定自由参数；独立证据证明 E/debt 的必要性 |
| 控制 | 公共价值控制器保留，普通核心始终参加 2×2 | 新真实任务中 D−B 或预设非劣成本条件通过 |
| 数值 | FP64／已验证 mixed 路径为可用研究基线；纯32候选独立 | 全域精度、接缝梯度、动作稳定性与同误差成本 |
| 决策接口 | 增加所有核心共享的数值并列动作规则候选 | 新源身份下重新冻结、独立新确认；不替换原结果 |
| 原生系统 | 已有独立 Rust 传播、事件和 durable recovery | 生产 owner 集成、真实负载、GPU／规模与能源测量 |

本轮可以关闭“是否能把这些机制接成一个可训练、可执行的有限模型”这一工程问题。不能关闭“金融结构是否值得成为新基础网络核心”这一科学问题；本次最关键的确认比较给出了未通过结论。后续优先级应由不可识别方向、连续误差造成的实际动作损失、真实内容任务和完整成本决定，而不是继续堆叠金融读出。
