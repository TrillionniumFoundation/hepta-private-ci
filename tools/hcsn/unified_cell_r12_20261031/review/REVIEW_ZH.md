# R12 冻结确认结果的独立审计

## 结论

本审计确认冻结身份、数据与计分重放、读取约束以及预注册统计计算一致。**本轮主质量增益与保守成本验收均未通过，IID 与 OOD 都不能报告成功。** 这不是未运行实验：24 个独立训练进程的产物、8 个配对种子在两个域的确认结果均已生成和核对。

D 与相同拟合模型的 generic HMM 在数学上使用同一个有限状态贝叶斯滤波算子。确认记录中的 5 个不同动作全部是两个终止答案的浮点平局：最大绝对 Q 值间隙仅 `6.661338147750939e-16`。它们解释了全部 D−HMM 收益差，不能当作 HX 独有能力。序列评估的 901 个标签差异也都在数值平局附近，最大类别概率间隙为 `2.942091015256665e-15`。

本目录只新增审计材料；冻结源码、训练产物、原生库、`CONFIRMATION.json` 和 `SUMMARY.json` 均未改写。所有重放都是确认后的诊断，不是新的独立确认。修复平局规则必须保留原结果，并在独立候选或下一轮预注册中实施。

## 2. 八个配对种子、样本与普通模型选择

种子为 `121101, 121103, 121107, 121109, 121113, 121117, 121119, 121123`。每个种子分别训练 HX distribution、GRU、continuous diagonal SSM 三个核心。同种子三者的训练和验证数据哈希相同；跨种子训练、验证哈希各有 8 个不同值。16 份确认序列的数据哈希均不同，而且由声明的种子、真实模型、时间间隔重新生成后逐一匹配。

每个域每种子有 192 条长度 12 的确认序列，以及 128 个控制 episode。每个控制臂总计每域 1,024 个 episode；统计的独立单位仍是 **8 个配对拟合种子**。不能把 episode、时间步或多个臂作为额外独立重复。

8 个种子的普通核心都按冻结前验证 posterior CE 选择了 GRU。保留的 SSM 结果没有被隐藏。参数数量分别为 15、5,844、3,444；这是等每核心 CPU 预算的比较，不是等参数量或等结构先验的比较。各拟合的 20 秒 CPU 预算越界为 0.00754–0.02916 秒，符合实现按完整操作结束计时的范围。

## 4. 真正的 READ 访问和计分

审计重新运行全部 16 行 × 8 臂的环境路径，采用记录中的动作，不重新训练、不重新选择核心。重新生成的获取 token、终止时用于计分的隐藏状态、正确性和效用全部匹配。

每次 `READ` 才调用 `EvidenceWorld.read()` 并从当前隐藏状态的发射分布物化 token；`WAIT` 只推进状态；`ANSWER` 立即结束。预先生成的是配对随机数，不是提供给 actor 的未读取 token。输入估计器的只有时间间隔、实际 token 和可用掩码；隐藏相位与标签仅用于生成世界及计分。

全部臂满足：记录的 `read_calls` 等于动作矩阵中 READ 的数量；token 获取位置恰好对应 READ；每个 episode 不超过两次读取；每个 episode 恰有一个终止回答；恢复读取次数等于 token 6 的数量。计划器对七种假设 token 求期望时使用的是模型似然，不读取未来真实 token。

这是对合成环境中真实 API 调用和因果数据流的验证。没有真实传感器、文件检索或远程服务访问，因此不能由此量化物理设备能耗、网络成本或真实内容任务上的节省。主控制任务通过有限 CTMC 转移抽样终点；原生 Gillespie 的实际跳变/复位见证是另一项独立机制验证，不能把 belief 占用或 endpoint 抽样称为观测到的脉冲次数。

## 5. D/HMM 平局诊断

冻结 `control/controller.py::_result` 直接使用 `np.argmax(qvalues, axis=1)`；`evaluation.py::sequence_score` 的类别判定也直接调用 `argmax`。文档所称“最低动作索引打破平局”只对浮点数完全相等生效。概率理论上的平局经不同的矩阵指数或累加路径计算后，可能相差几个 ulp。

以下 episode 索引从零开始，全部在第 3 个决策时刻即 `step=2` 出现不同回答。完整逐步 joint belief、已读历史、Q 值和冻结身份在 `raw.json::ties`。

| seed / domain / episode | 历史 | dt | D 的 Q0−Q1 | HMM 的 Q0−Q1 | D / HMM 动作 |
| --- | --- | ---: | ---: | ---: | --- |
| 121113 / OOD / 69 | READ(token 6), WAIT | 0.05 | +1.1102230e−16 | −2.2204460e−16 | ANSWER0 / ANSWER1 |
| 121117 / IID / 50 | READ(6), READ(6) | 0.45 | 0 | −2.2204460e−16 | ANSWER0 / ANSWER1 |
| 121117 / IID / 123 | READ(6), READ(6) | 0.45 | 0 | −2.2204460e−16 | ANSWER0 / ANSWER1 |
| 121123 / IID / 34 | READ(6), READ(6) | 0.15 | 0 | −2.7755576e−16 | ANSWER0 / ANSWER1 |
| 121123 / IID / 124 | READ(6), READ(6) | 0.45 | 0 | −6.6613381e−16 | ANSWER0 / ANSWER1 |

这里的精确数学模型有内容交换对称性：初始内容先验各为一半，两个内容类使用同样的相位动力学，恢复标记 token 6 不区分内容，WAIT 保持该对称性。只看到这些历史时，两个答案的精确期望收益相等。所有差异均在终止动作出现，之前获取信息与时间推进相同。

IID 四处的实际效用差为 `+1, −1, +1, +1`，在 1,024 个 episode 上合为 `+0.001953125`；OOD 一处为 `+1`，合为 `+0.0009765625`。这精确解释了汇总中的 D−HMM 均值。不是由更多信息或更好的动态模型得到的优势。

序列确认中，HX Torch 实现与 generic HMM 的类别 argmax 不同共 901 个时间步：IID 468、OOD 433；全部两类别概率间隙不超过 `2.942091015256665e-15`。因此相同 CE/Brier 附近的小 accuracy 差不能用作能力排名。

还必须区分两种精度证据：主序列 `generic_hmm_torch_parity_max` 比较的是 Torch distribution 与 SciPy/NumPy HMM，其最大值约 `1.33e-15`；主 episode 的 D 实际调用 Rust，而 HMM 使用 NumPy。五个诊断终点的 native/HMM 最大 belief 差为 `1.3322676295501878e-14`，出现在包含 WAIT 的 OOD 轨迹。Rust 未强制归一化泊松截尾后的质量，这个差值不应被错误写成所有运行路径都只有 `1e-15` 误差。

## 6. 两个主成本口径

设 `T_HX` 为 HX 拟合加数据准备，`T_G` 为选中 GRU 拟合加准备，`I_D/I_B` 为每 episode 的已测在线 CPU，摊销数 `M=1000`。

- `actual_unique`：D 为 `I_D + T_HX/M`；B 为 `I_B + (T_G+T_HX)/M`。D 的 encoder 与共同模型校准复用同一拟合。
- `equal_shared_charge`：D 为 `I_D + 2*T_HX/M`；B 仍为 `I_B + (T_G+T_HX)/M`。它有意再次给 D 计入共同校准，以免将复用收益误当核心算子加速。主验收采用这一保守口径。

| --- | ---: | ---: |
| B，两个口径相同 | 40.140971 ms | 40.139366 ms |
| D，actual unique | 20.115186 ms | 20.112356 ms |
| D，equal shared charge | 40.160718 ms | 40.157888 ms |
| D/B，actual unique | 0.501113590 | 0.501063106 |
| D/B，保守口径 | 1.000491941 | 1.000461422 |
| 主成本验收，要求非劣且比例 ≤ 0.90 | 未通过 | 未通过 |

单独的已测在线 CPU 为：IID B `0.066438 ms`、D `0.069654 ms`；OOD B `0.064833 ms`、D `0.066824 ms`。单次小规模 CPU 计时不能支持性能分布或硬件泛化结论，此处也没有测到 D 的在线加速。actual unique 的约一半成本来自训练复用的分摊差别，不能叙述为 Rust 传播快一倍。

## 8. 容易超出证据的解释

1. **完整 HX 核与通用 CTMC 算子需要分开。** 现有桥接确实调用完整 HX 五输出及十输入 Jacobian；有限传播和观测更新与相同 Q/发射模型的通用 HMM 等价。原生独立实现、可训练性与模型归纳先验可以作为工程成果，不能因此声称发现 HX 独有的滤波代数。
2. **有限模型的精确性不等于连续首达过程的精确性。** 这里有 8 个 active 网格、2 个恢复相位、2 个内容类和上边界截断；`exp(Q*dt)` 对这个 20 维 CTMC 的精确半群，与原始连续 He–Xiong 首达模型的精确解不是同一声明。恢复、复位和内容保留是本项目声明的扩展。
3. **完整五输出并未都作为独立训练特征辨识。** `DistributionCell.prepare(prices=False)` 中训练状态转移依赖 sigma 和 full-HX boundary；liquidity/maturity 对 Q 的作用经同一个边界标量。导出时 equity/debt 进入任务收益/成本，F/G 作为核输出保留。这不证明每个物理参数可独立识别，也不意味着完整 HX 解秩为一。若要辨识这些参数，需要额外观测或训练目标。
4. **这是已知生成族的合成任务。** 真实世界和候选使用同一 HX 参数化族，teacher 后验只在训练目标及评分中出现，结构先验强于普通循环核心。此处 OOD 改变的是时间间隔集合；内容发射、生成模型族和真实物理参数没有变成另一个域。当前结果不证明真实文本、开放域内容、金融预测或通用语言能力。
5. **Hölder/DQN 理论未由此验证。** 本轮是共同的有限时域模型规划，不是运行 deep Q-learning 后证明其收敛；不能把有限 CTMC 的解析传播、训练损失下降或小概率差与函数空间 RL 理论互相替代。
6. **确认后数值消歧不是新确认。** 容差内确定性平局规则可作为后续候选，并用这些轨迹验证机制修复，但不能用修复后的同一批已看见样本替换原始确认、重选阈值或重新宣布成功。

以上限制中，平局消歧是明确的数值可重复性修复候选；其余为成本和科学解释范围。没有发现需要通过修改冻结文件才能使原始数值汇总自洽的问题。原始质量、成本未过的结论应保持。
