# 确认后数值修复候选：在容差内统一动作选择

## 结论与范围

本目录提供 `resolve_action(qvalues, tol=1e-12)` 与 `wrapped_plan(...)`。它们只处理原规划器已经计算出的 Q 值：在距最大有限 Q 不超过 `tol` 的动作中，选动作编号最小者，并返回所选动作本身的 Q 值。默认动作顺序沿用原控制器：`ANSWER0=0, ANSWER1=1, WAIT=2, READ=3`。

独立审查记录的 **5 处正式 D/HMM 动作差异，应用该候选后均统一为 ANSWER0**。这 5 个 episode 的全部 15 个已记录步骤中，两个实现的候选动作均一致。这里仅解析已记录的 Q 数组，没有生成新 episode、重跑确认实验、重新计算正式效用或替换任何冻结结果。本目录是 **post-confirmation numerical repair candidate**，不构成质量提升或显著性结果。[实际 Q 证据](ACTUAL_Q_PAIRS.json) 保留原动作与候选动作两列。

原 `control/controller.py` 的 SHA256 在检查前后均为：

`910c8f0033b10a93aa56640231514a57525f1e6cf262ebff0d0d0d3dbc839c99`

本候选未接入冻结训练、模型或确认流程。它也没有改变 HX 计算精度或扩展此前 FP32 的资格结论。

## 选择规则和接口

对可用动作集合 `A`、输入 Q 数组 `q`，规则为：

\[
M=\max_{a\in A}q_a,\qquad
\widehat a=\min\{a\in A:M-q_a\leq\tau\},\quad\tau=10^{-12}.
\]

这是一个绝对容差，与本次约为 1 的任务收益量级相对应。它不随 Q 的单位自动缩放。动作索引的顺序是策略定义的一部分；这里的确定性偏好是容差内选最小编号。

`resolve_action` 支持一维动作向量，返回 Python `int`；支持二维批量数组，返回 `int64` 动作向量。`-inf` 表示不可用动作。拒绝 NaN、`+inf`、无有限动作的行、空动作维、不支持的维度、布尔／复数／字符串／object 数组，以及负数、非有限、布尔或非实数标量容差。允许 `(0, actions)` 空批量。输入数组不被修改。

选择比较针对转换后的 FP64 表示值。它没有声称恢复输入转换前丢失的精度，也没有把选择层的 FP64 转换称为纯低精度算子。在极少见的浮点边界上，直接计算 `M-q` 会把严格大于容差的真实差值舍入为等于容差；代码用 TwoSum 的余项修正这个边界。例如 `q=[-5e-324, 1e-12]` 的普通相减得到 `1e-12`，但这两个已表示数的精确差值严格大于容差，因此候选正确选择动作 1。[边界证据](STABILITY_LIMIT.json)

`wrapped_plan` 原样调用冻结 `plan`，保留它的 Q 矩阵，然后执行上述选择。`PlanResult.value` 是 `qvalues[row, selected_action]`，可能小于原来的最大值；不会选较低 Q 后仍把最大 Q 报作该动作的价值。候选只改变返回的根动作，原 Bellman 递归及其最优后续价值保持原样。

## 能够证明的期望 Q 损失界

以下是直接推导，不是由这 5 个 episode 估计的统计结果。假设真实 Q 为 `Q`，输入近似 Q 为 `Qhat`，两者可用动作集合相同，且对所有可用动作都有

\[
|\widehat Q(a)-Q(a)|\leq\varepsilon.
\]

候选满足 `max Qhat - Qhat(selected) ≤ tol`。若 `a*` 是真实 Q 的最大动作，则

\[
\begin{aligned}
Q(a^*)-Q(\widehat a)
&\leq \varepsilon+\widehat Q(a^*)-\widehat Q(\widehat a)+\varepsilon\\
&\leq 2\varepsilon+\tau.
\end{aligned}
\]

固定的 512 行人工扰动检查取 `epsilon=0.001`，观察到最大真实 Q 损失 `0.0017855277401466196`，低于 `0.002000000001`。该检查用于核验实现与符号；一般界由上述推导成立。

这里的 `epsilon` 必须是所有可用动作的 Q 误差界，不能直接用某个 posterior 分量的 `1e-15` 差异替代。该界针对一次选择与原 Q 定义下的后续行为。若每一步重新规划并再次应用容差，累计策略损失需要单独分析，不能把一次的 `tol` 宣称为整个 rollout 的总损失界。一次具体样本中，两种几乎等概率的 ANSWER 仍可能相差一个完整正确奖励；小期望 Q 差不限制该次实际奖励差。因此不把这 5 个数值动作修复转换为新的正式效用结论。

## 确定性规则的稳定性边界

容差不能使所有任意接近的 Q 数组永远得到同一动作。已保存的反例为：

```text
q1 = [0.0, 1e-12]                    -> 0
q2 = [0.0, 1.0000000000000002e-12]    -> 1
max |q1-q2| = 2.0194839173657902e-28
```

它们刚好位于容差边界两侧。若两组 Q 的最大误差为 `delta`，各动作“距本组最大 Q 的差值”变化最多为 `2*delta`。因此，同一可用动作集合下，若所有原差值距容差阈值的距离严格大于 `2*delta`，则可接受动作集合一致，最小索引也一致。

五处正式末步记录满足这个充分条件：最大的跨实现 Q 差为 `2.4424906541753444e-15`，所检查的最小阈值余量为 `9.998889776975375e-13`。这是这些输入的局部数值稳定性证据，不是对所有后续状态的统一保证。[稳定性记录](STABILITY_LIMIT.json)
