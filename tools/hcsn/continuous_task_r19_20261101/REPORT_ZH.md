# R19：跳变感知的有限网格任务梯度

本轮在冻结的 R18 连续任务上实现了 13 个平滑系数的活动分支切线，
同时保留每个恢复准入时刻的左极限、右值及各自梯度。正式登记的
全数组有限差分验收 **未通过**，不能据此关闭“完整参数梯度”。

原研究提交为 `b25601c9bae257ffb651c8f9354fc380d8333f38`。
源码、协议、推导和独立审核器先发布到远端
`d9bfd93d86a985dc603cce8b0c4ade6102cb7696`，再执行正式核验。
`SOURCE_FREEZE.json` 绑定 7 个本轮文件；10 个读取的 R18 输入文件
逐个与原 Git blob 和字节数一致。此前局部工程探针和旧审核器源码保留。

覆盖的系数为扩散率、WAIT 与恢复费用、重置位置、两种模式各自的
重置费与保留率、两个奖励基数与幅度、共同奖励斜率。恢复后继带完整
剩余时间和模式转移。重置位置的导数包括线性插值的直接斜率；终点奖励
和 STOP 障碍也携带导数。准入左极限只能使用前一准入时刻的左后继，
新右 RESET 则使用右后继，防止新可行动作的导数向此前等待区间泄漏。

| 正式核验项目 | 实际结果 |
| --- | --- |
| 登记覆盖 | 3 个扩散/重置位置配置 × 2 个网格 × 13 个系数 × 2 个差分步长 |
| 全数组比较 | 156 条记录，1,919,112 个标量位置 |
| 原求解器数值一致性 | 6 组数组，最大绝对差 `5.5511e-16`，通过 `2e-12` 门槛 |
| 不含检测到分支切换的记录 | 144 条，最大缩放差 `1.5543e-9` |
| 含检测到分支切换的记录 | 12 条，均未通过 `1e-6` 全数组门槛 |
| 全部尝试的最大缩放差 | `0.01010018`；原全数组门槛失败 |
| 每个系数至少一个稳定通过配置 | 13/13；独立辅助覆盖条件通过 |
| 非零数值跳变与非零梯度跳变 | 两个网格均实际出现 |
| 拒绝合同 | 7 个不支持坐标、3 个插值结点/端点，10/10 拒绝 |

12 条失败都伴随有限扰动下的活动分支变化，这与局部活动分支切线的
适用限制一致。这里未建立全部误差逐点来自该变化的归因证明，也没有
把这些记录排除、改阈值或归入通过。每个方向、每个步长的左/右分支
变化数以及包括准入日期在内的误差均在 `CONFIRMATION.json`。
`passed=false` 和正式进程退出码 1 完整保留。

独立记录审核器 `record_check.py` 重算记录数、阈值、覆盖和汇总，
并验证全部冻结文件及结果哈希，与原失败结论一致。正式结果保存的是
每个坐标/步长的误差最大值和分支计数，没有保存各次完整扰动数组；
记录审核不能仅凭汇总重算每个标量差分。完整数值复核需要按冻结的
确定性源码重新执行；不把记录审核称为原始数组独立重放。

补充工程诊断将旧 R18 四坐标切线直接用于新跳变求解器，最大绝对
差分别为 sigma `0.0028210`、WAIT 费用 `0.0205655`、模式 0 重置费
`0.0425230`、模式 0 保留率 `0.0039113`，最大差发生在准入时刻。
原 R18 已明确没有资格化该组合；这项诊断说明本轮处理的是具体缺口，
不改变旧结果的适用范围，也不是新增登记通过条件。

正式审核器子进程实际用户加系统 CPU 为 **19.450417 秒**，壁钟
**23.099773 秒**，单进程最大 RSS 为 **56,048 KiB**。
该外层 CPU 已包含审核器报告的内部 18.365091 秒，不能重复相加。
编译、开发、早期探针、集成和全项目成本不在该数字内；能耗未测量。
工程探针自己的内部 CPU 和日志另存，不冒称完整开发资源总账。

仍开放：动作切换处的方向/半光滑导数合同、移动恢复时间与期限、空间
边界与网格的导数、连续极限梯度、完整金融/神经模型梯度、解析核心
独立净收益、真实跨模态内容、GPU/能耗及生产准入。该实现是 Python
研究模块；`all_blockers_closed=false`，`production_activation=false`。

## 前瞻补充：更小的扰动仍保留失败

在完整保存上述失败后，新协议与独立源码审阅先发布到
`b1e5d3f95b6bb756363fe43f0d8ede86a20ffc41`。11 个文件的冻结清单
同时绑定原失败结果。补充不改变模型源码、配置、网格或误差门槛，
仅预先登记差分步长 `1e-7` 与 `3e-8`，重新尝试相同 156 条记录。

结果为 **155/156 通过，补充全数组门仍未通过**。155 条稳定分支
记录的最大缩放差为 `1.4248e-7`。唯一失败是默认扩散率、细网格的
WAIT 费用在 `h=1e-7` 时发生一次分支变化，缩放差 `0.0009083483`；
最大差位置为时间索引 19、模式 1、空间索引 25。其实际正负扰动值
为 `0.14982134327496657`、`0.14982134717050916`，中央差分
`-0.019477712914772738`，活动分支切线 `-0.020386061259301962`。
同一坐标在登记的 `h=3e-8` 时稳定且通过；这不覆盖此前失败，也
不证明在动作切换处存在唯一导数。

补充记录保存每一条最大误差位置的原始正负值、切线值及完整数组的
哈希。独立标准库审核逐条重算这 156 个数值见证、覆盖、冻结身份和
两次失败状态；完整数组哈希只能在重新执行时复核，不冒称数组已归档。
正式原门与补充门均保持 `false`。

补充外层子进程 CPU 为 **19.868542 秒**，壁钟 **23.419458 秒**，
最大 RSS 为 **56,352 KiB**；CPU 亲和性 0–5、BLAS 线程数 1。
