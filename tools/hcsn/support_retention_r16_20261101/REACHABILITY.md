# 可达联合状态与真实后续收益：有限开发证据

## 本轮结论

本模块把 R15 的人工 joint 见证转成了一个**明确定义的新受控环境中的真实观察后验**，并完成全部预定后续动作评估。它没有证明这些后验由原 R15 的 WRITE 历史产生，也没有完成正式训练确认。

48 个预定场景、96 个关系符号 prefix 中，完整后验相对两个边缘的乘积，有 12 个 prefix 的实际策略期望收益差超过 `1e-6`。全部场景等权平均差为 **0.0004146016694**，最小 0，最大 **0.007614317206**。所有强制首动作都执行其各自后续，而不是仅比较预测 Q 或动作是否翻转。

**同生成元普通 HMM 与“公开构造上下文＋一个关系位”的参考策略，与完整后验逐棵策略树相同。** 因而本轮只说明当前 factorized 投影会丢失小量可用关系信息；没有建立必须存储完整四十维后验，也没有建立 HX 独占收益。上述收益均小于先前归一化效用 `0.01` 的实用门槛；本开发实验没有新增通过门或改变旧门槛。

## 1. 可达性构造

每个场景有公开的两个 phase、两个 content 类与两个边缘质量。二维子块基准为

\[
B=\begin{pmatrix}a\\1-a\end{pmatrix}(b,1-b),\qquad
\Delta=c\begin{pmatrix}1&-1\\-1&1\end{pmatrix},
\]

其中 `c = .9 * min(B)`。在完整 `10 × 4` 空间加入预先规定的 `1e-6` 均匀背景质量，然后按 `1-1e-6` 缩放基准子块和运输方向。背景是该新世界的初始分布定义，不是对失效后验加 epsilon，也没有修改旧 R15 mean 对照。

定义 `p+ = p0 + delta`、`p- = p0 - delta`。运输方向行列和均为零，所以两者 phase 边缘和 content 边缘相同；由于振幅小于最小子块质量，全部状态概率严格为正。

Owner 首先真正抽样 `Z0 ~ p0`，随后从公开关系发射核抽样符号：

\[
E(+\mid z)=\frac{p_+(z)}{2p_0(z)},\qquad
E(-\mid z)=\frac{p_-(z)}{2p_0(z)}.
\]

两列均合法且和为一，两个符号的边际概率各为二分之一。Bayes 公式立即给出 `P(Z0=z | O=+) = p+(z)` 及负号版本。因此两个 joint 都由实际 owner 观察到达，而不是运行后直接替换 belief。48 个场景全部保留，没有按未来真值、动作差或收益筛选方向。

固定构造为 phase 对 `(0,8), (7,9), (2,5)`，content 对 `(0,1), (1,3)`，边缘质量对 `(.3,.7), (.7,.85)`，每槽时长 `.3,.8`，价格倍数 `.5,4`。三个方向族包含 active–recovery 与 active–active 关联。本轮没有声称覆盖全部方向或所有原始输入历史。

## 2. 同一 prefix 的真实后续

沿用 R15 `Law` 的 40 状态生成元、READ 与 REFRESH 发射及终点内容评分。每次 query 有两个时间槽，评分始终在同一终点。STOP 提前提交后，世界仍继续到终点；WAIT 无观察；READ 耗一槽并获取真实 noisy 内容或 erasure；REFRESH 耗两槽并购买更准确的新观察。

每个 prefix、每个模型完整评估四种强制首动作 `STOP/WAIT/READ/REFRESH`。后续动作由各模型在相同公开成本、规划深度和同一 `Planner` 下选择。factorized 模型在传播与观察后按原合同重新投影；其收益则在真实完整 owner 分布下计算。

独立 evaluator 为固定策略树计算每个真实起点状态的收益向量。STOP 用终点内容概率；其他动作先计算各真实 observation 后继，再按 emission 和 transition 求和，扣除真实费用和耗时成本。该计算不使用模型预测的 Q 代替实际执行收益。full 策略的全部 384 个强制首动作期望值与共享规划器输出最大差为 **2.78e-15**。

Owner 转移另用正 uniformization 计算，Poisson 剩余质量界小于 `2e-15`；与原 `expm` 最大误差 **8.05e-16**。这是有限 CTMC 的离散时点精确法的数值比较，不是连续空间扩散证明。抽样时仅把最后一个 CDF 端点设为一，先要求随机行残差低于 `2e-12`；该微小浮点处置没有用于改变 belief 支持。

## 3. 配对世界与结果

每个场景固定 512 个 owner 世界，共 **24,576** 个。先采初始 latent、关系符号、两个后继状态，再生成每个合法时间／质量的观察噪声。所有政策共享这组真实轨迹与观察机会。模型策略只读取关系符号与实际购买的 token；终点内容只进入 scorer。

每个场景保存完整初始/后继状态、关系符号、各观察机会、每个强制首动作的提交答案、总费用和完整策略树。`reachable_raw_audit.json` 独立从保存的状态、预测与费用重算了 **768** 个模型 × prefix × 首动作抽样收益及全部配对差；48 个原始文件身份全部匹配。

| 项目 | 本轮记录 |
|---|---:|
| Bayes 后验与构造的最大绝对误差 | 5.55e-16 |
| 两个后验边缘最大差 | 1.11e-16 |
| 完整／factorized 首动作不同的 prefix | 6 / 96 |
| 完整实际策略期望收益差超过 1e-6 | 12 / 96 |
| 全场景等权期望效用差 | 0.0004146016694 |
| 最大单 prefix 期望效用差 | 0.007614317206 |
| 配对抽样平均效用差 | 0.0001319864909 |
| 配对样本描述性标准误 | 0.0005580855216 |
| 同 Q HMM／公开上下文关系位与 full | 全部策略树一致 |

抽样标准误仅描述这批独立 owner 抽样的 Monte Carlo 波动；不是训练 fit 的置信区间，也不构成架构泛化显著性检验。正的期望差由有限场景全枚举给出；抽样结果与其一致但不单独建立稳定的经验收益。

## 4. 强普通参考与信息边界

给定公开场景上下文，只需记住一个关系符号就可重建初始后验。参考实现通过公开 `p0`、公开发射表和这个位执行 Bayes 解码，随后使用普通同 Q HMM。所有强制动作与后续分支的树都与 full 一致。这排除了“两个边缘不足，所以完整分布存储必需”的推断。

本参考只证明**当前单次关系观察的初始信息可压缩为一个位＋公开上下文**。之后仍采用完整模型运算；它不是对任意数量关系观察、公开覆盖或长时间后验族的低秩闭包，也没有测得在线成本优势。公开场景参数、发射映射、解码和策略树准备也不能在以后成本账中视为免费。

## 5. 冻结、失败保留与成本

在抽样前单独写出 `reachable_protocol.json`。首次运行在场景零的参考校验处停止：将数学上的 `p0 +/- delta` 与浮点 Bayes 结果按 `2e-16` 比较过严。原源码、协议和失败原因保存在 `reachable_attempt1_failure.json`；未产生任何完整场景文件。该失败阶段没有完整 CPU receipt，明确记为未知，不能当零。

随后只把普通关系位参考改为与公开 Bayes 相同的运算顺序；场景、种子、预算、动作、费用和科学判断不变。`reachable_protocol_v2.json` 再次单独冻结源码后才执行新运行。该协议 SHA256 为 `c641e3716109c22860bab6766f9797d756dd2d7a6991c405960f4a7d6bce3e36`。冻结发生在本地，不能声称运行前已公开发布。

成功运行记录 **1.694138 process CPU 秒、3.814279 wall 秒**，包含 owner 构造、全部动作规划、普通参考重算、抽样及原始文件写入，不包括解释器启动／导入、最后汇总写入、首次失败和额外审计。它不是完整研究成本，也不是一次在线决策成本。最大本轮 JSON 文件约 212 KB。

本模块的运行前窄 manifest 绑定 `reachable_joint.py`、R15 `law.py` 和 `planner.py`；它没有单独绑定其传递依赖。补充的 `reachable_dependency_reference_audit.json` 因而明确登记为**运行后**依赖绑定：保存 R12 Cell／协议、R11 kernel 的当前哈希及完整 Q／发射／收益模型导出，再用独立 `scipy.linalg.expm` 逐项复算保存的 **768** 个强制动作策略树期望值，最大差 **2.44e-15**。其主体 CPU 为 0.182123 秒。总发布的源码 manifest 应包含这些继承依赖；不得将补充回执倒写成运行前完整依赖冻结。

从仓库根目录运行。已打开输入只属于回归；请使用新输出文件名。程序按 create-only 规则拒绝覆盖已有证据。

```sh
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 MKL_NUM_THREADS=1 python -B -m tools.hcsn.support_retention_r16_20261101.reachable_joint --protocol tools/hcsn/support_retention_r16_20261101/results/reachable_protocol_v2.json --output tools/hcsn/support_retention_r16_20261101/results/reachable_replay.json
```

源或模型文件哈希变化会使冻结验证拒绝。新场景或参数必须另行登记。此模块保持 `confirmation=false`、`full_distribution_necessity_established=false`、`hx_exclusive_gain_established=false`；它补齐有限开发环境的可达性与实际后续收益证据，尚未关闭主研究的能力、成本和生产采用门。
