# R16：支持保持、锚定时间推进与完整成本确认

## 1. 本轮完成了什么

本轮在冻结 R15 的八组拟合模型上，完成新的 **2,048 个 owner 世界、十个候选、20,480 次执行尝试**。新增压缩表示保持 active/recovery 与 content 的联合质量；锚定版本在没有新观察时保留真实经过的时间，避免因人为切分时间而重复丢弃相位信息。独立有限算子核查、支持核查、时间切分与恢复核查通过；锚定候选在 IID/OOD 的效用与正确率共四个指标上，通过预注册的 `0.01` 非劣界。

持久数字状态由四地址完整表示的 **1,288 B 降到 296 B，减少 77.02%**。这一结果限于概率质量和时钟数组。完整模型、缓存、临时四十维传播、规划分支、Python 对象和磁盘序列化另计。

**解析核心的原收益门仍未通过；锚定候选的保质 CPU 成本门也未通过。整体 blocker 尚未全部闭合，生产激活保持关闭。** 机器结果见 [SUMMARY.json](results/SUMMARY.json)，逐项状态见 [BLOCKERS.json](BLOCKERS.json)。

| 用户验收阶段 | 本轮实际证据 | 结论范围与未完成部分 |
|---|---|---|
| 算子与传播 | 有限 CTMC 的质量、首达、存活、重复事件与独立 ODE；时间导数；支持证明 | 已通过所列有限 profile；不替代连续空间误差、完整金融参数梯度或 FP32 验收 |
| 连续动态任务 | 不规则间隔、无观察时间切分、真实 erasure、WRITE 与磁盘状态恢复 | 锚定推进通过；逐步投影候选保留明确失败；冷进程及 pending-action 恢复未验收 |
| 内容任务 | 四个给定地址、六次查询、覆盖与干扰；新关系观察构造及真实后续动作 | 有限 typed 内容与关系机制证据成立；学习语义寻址、跨模态长距离绑定仍未证明 |
| 全模态模型 | 同世界、同机会、同控制能力下的质量、执行时延及完整候选 CPU 账 | 原核心收益及成本门失败；真实全模态、GPU、能耗与生产能力仍 open |

`e8a167247efacfed7463ad1cc86e1457d8833d850d9be3cc349de19cfd9f3f8a`

确认固定八组旧拟合，每组在 IID/OOD 各运行 128 个新世界。统计独立单位仍是 **八个 fit**，不是 2,048 个世界或大量相关 query。本轮未重新训练模型、重新选择普通对照或改变旧固定控制程序。普通候选保留自由率 CTMC、同矩阵 HMM 及原验证选择；金融参数族的结构先验差异仍存在。IID/OOD 沿用已声明的时间间隔族，不称全参数族外推。

所有候选共享相同初始公开事件、owner 路径、动作接口、观察机会、费用与固定 deadline；其购买的观察历史随自身动作而不同。提前 STOP 后，世界仍推进到共同评分时刻。真实 erasure 是观察到恢复状态的符号；缺测没有符号，两者分开处理。控制器只优化当前 query 的三个时间槽，不声称跨全部未来查询的全局最优性。完整合同见 [PROTOCOL.json](PROTOCOL.json)。

## 3. 压缩与时间推进的修复

### 支持保持

将四十维分布收集为八个 `active/recovery × content` 质量，组内相位用明确的均匀形状重建。设收集与展开核分别为 `C`、`R`，则 `RC = I_8`。在精确算术中：

\[
p_z>0\ \Longrightarrow\ (pCR)_z>0.
\]

R15 的 READ、REFRESH 及内容奖励在同一分组内不随 phase 改变，所以即时压缩前后的观察概率与内容奖励相同。共同非负转移、合法 Bayes 更新和公共 WRITE 都保持支持包含关系。旧 index-mean 会删除恢复质量；新增候选不通过 epsilon、概率裁剪或更改旧对照来掩盖这一问题。

该证明不表示压缩后的后验、动作价值和概率校准完全相同。它明确丢弃组内相位形状；实现对无法以 FP64 保留的极小正支持报错。证明及数值范围见 [SUPPORT_PROOF.md](SUPPORT_PROOF.md)。

### 时间切分

逐步投影版本使用 `K(t) = R exp(tQ) C`。它通常不满足 `K(s)K(t)=K(s+t)`。本轮最大缺陷为 **0.03175808584**，因此该负对照的时间切分门明确失败。

锚定版本保存每地址的八个质量和上次真实观察／WRITE 时间。没有观察时仅推进公共时钟；需要读取状态时从锚点计算 `zR exp(elapsed Q)`，只在真实信息到达或 WRITE 时重新压缩。共同规划器也只在未来真实观察后投影，WAIT 不重复投影。它是**带经过时间的压缩过滤器**，不是八状态 CTMC。

最终独立算子审计同时检查观察前分布、观察后分布和压缩状态，锚定时间切分最大误差 **6.21725e-15**。早先审计版本及补充说明均保留；主入口是 [operator_development_v3.json](results/operator_development_v3.json)。

### 有限算子与恢复结果

独立 DOP853 参照直接积分完整／killed 生成元及事件奖励方程，不调用项目传播或事件积分函数。范围为三组参数、四十个基初态及八个时长。

| 核查项 | 最大绝对误差／结果 |
|---|---:|
| 转移矩阵对独立 ODE | 2.00922e-11 |
| 首达概率对独立 ODE | 2.68460e-10 |
| 重复事件期望对独立 ODE | 3.64055e-10 |
| 概率质量 | 1.04361e-14 |
| 首达＋存活等于一 | 1.67844e-12 |
| 时间导数 | 4.08136e-10 |
| 完整分布半群 | 6.10623e-16 |
| 丢失正支持／合法观察 | 0／0 |

每次正式 episode 在第三次 query 完成后执行真实 JSON 写盘、flush、fsync、读取与恢复。全部臂使用相同边界；恢复前后状态及后续行为检查通过。**同一进程继续保留 law 和 transition cache**，没有 pending action。这不等于冷进程生产 owner 恢复。代码及测试见 [compression.py](compression.py)、[execution.py](execution.py)、[test_compression.py](test_compression.py) 与 [test_execution.py](test_execution.py)。

## 5. 锚定表示的质量、存储与成本

### 质量非劣通过，不等于精确无损

预先冻结的主比较为 Anchored−D。四项单侧 98.75% Student-t 下界共同控制 family alpha `.05`，各自须严格高于 `−.01`。

| 指标 | IID 平均差 | IID 下界 | OOD 平均差 | OOD 下界 |
|---|---:|---:|---:|---:|
| 净效用 | −0.001327026 | −0.005317283 | −0.003152458 | −0.006999653 |
| 正确率 | −0.000651042 | −0.004416062 | −0.002766927 | −0.006686984 |

四项均通过原非劣界。平均质量差仍为负；不能写成完全保持精度或证明更高收益。

### 数字状态降低，CPU 门未通过

完整表示的四地址 belief 加公共时钟共 **1,288 B**；锚定表示为质量 **256 B**、每地址锚点时钟 **32 B**、公共时钟 **8 B**，合计 **296 B**。减少 **77.02%** 是持久数字状态结果，不是总 RSS、整个模型内存或能耗降幅。

| 成本指标 | IID | OOD |
|---|---:|---:|
| Anchored／D 在线 CPU | 0.992488 | 1.049554 |
| 1,000 次复用完整账 CPU 比 | 0.998161 | 1.012110 |
| 预注册成本门 | ≤0.90 | ≤0.90 |

两个成本条件都未达到要求，**保质成本门失败**。成本账包含全部候选与失败尝试，不能只以 296 B 或单次更快的测量作采用结论。

执行时延原始记录也保留。D／Anchored 的平均 episode wall time 在 IID 为 **19.881／19.224 ms**，在 OOD 为 **18.293／19.495 ms**。按同一执行区间时长取倒数，分别为 **50.30／52.02** 和 **54.67／51.29 episode/s**；这是所测 `execute` 区间的串行完成率，不包括所有外部准备，也不代表持续服务、GPU 或全模态吞吐。

### 费用、失败与资源账分开

全部十臂均尝试全部世界。旧 `mean` 共 **21 / 2,048** 次失效，失败 CPU **0.434264172 秒**；按冻结规则，mean 在两个域的最终质量结果均为 **null**。其他九臂各 **2,048 / 2,048** 有效。原始失败、成功记录与计算成本均保存，没有成功子集质量估计。

Linux 外层 `wait4` 对十六个子进程记录的完整确认 CPU 为 **313.038601 秒**，包含解释器、导入、全部执行和最终输出；继承的八个 R15 训练外层进程 CPU 为 **30.111223 秒**。每个替代部署的复用账采用：

\[
I=\text{原完整训练进程 CPU}+\text{本轮两域全部候选确认进程 CPU},
\]
\[
C_a(N)=I+\text{候选模型准备 CPU}+N\times\text{候选平均在线 CPU}.
\]

共同搜索投资分别计入每种替代部署，不把两个替代部署总数再相加。 原训练数值继承其已保存的外层收据，本轮没有在当前主机重新训练；复用曲线是这些已记录成本的摊销，不声称同一硬件上的全生命周期重测。模型准备、在线工作、失败和全部 worker 成本见 [PROCESS_SUMMARY.json](results/PROCESS_SUMMARY.json) 及每 fit/domain 收据。

开发、机制试验及独立审计成本另外列示，不称完整项目总成本。Raw 审计内部 CPU 为先行 **0.311842525 秒**、完整 v1 **6.678017389 秒**、完整 v2 **5.610567155 秒**，这些内部计时不覆盖其解释器启动与所有最终保存。也不能把首次机制试验未记录的失败 CPU 当作零。

[ENVIRONMENT.json](ENVIRONMENT.json) 记录本次为 Linux；未发现 CUDA 设备或 powercap 能耗文件。没有 GPU、焦耳、真实网络或全模态 encoder 的完整资源测量，不能从 CPU 秒推断能耗。

## 6. 可达联合关系：新增有限开发证据

另一个预声明的受控世界先从 `p0` 抽样真实 latent，再由公开关系 emission 抽样正／负符号；Bayes 后验为两种同边缘、不同 joint。它完成 **48 场景、96 prefix、24,576 个 owner 世界**及所有强制首动作的真实后续收益评估。

完整 joint 相对 factorized 的全场景平均期望收益差为 **+0.000414602**，最大单 prefix 差 **0.007614317**。普通同 Q HMM 和“公开上下文＋一个关系位”的参考与 full 的完整策略树一致。因此它只证明当前 factorized 投影会丢失少量可用关系信息，**不证明四十维状态必要，不证明 HX 独占收益**。

这是新受控环境的 development，不是原 R15 WRITE 历史的可达性证明，也不是正式 fit 确认。背景质量是新世界初始分布的定义，没有修补旧 mean。首次运行的浮点校验失败、未知失败 CPU、本地窄源码冻结和运行后补充依赖核对均保留。详见 [REACHABILITY.md](REACHABILITY.md)、[reachable_v2_results.json](results/reachable_v2_results.json) 及其中原始场景文件。

## 7. 独立审计与可复核性

独立 raw 审计没有导入实验 executor、planner、world 或 summarizer。它从保存的 owner 路径重新计算公开 schedule、指纹、目标、keyed token、费用和效用，再从 raw 重算 fit 均值、CI、sign-flip、Holm、非劣、全局 invalid 与成本加总。

最终 [INDEPENDENT_RAW_AUDIT_V2.json](results/INDEPENDENT_RAW_AUDIT_V2.json) 覆盖 **64 个 raw archives、2,308,644 项检查、990,696 次数值比较**，最大差 **2.220446049250313e-16**，零不一致。它还拒绝四种内存副本损坏：target、fee、token、owner identity。第一版审计的尾部行完整性检查缺口已补，原审计源码快照和原收据保存在 [INDEPENDENT_RAW_AUDIT_REVIEW.json](results/INDEPENDENT_RAW_AUDIT_REVIEW.json)。

这是独立记录和统计核对，不是对全部规划最优性、内部时钟状态或 CPU 仪器的独立重演；相应源码及有针对性的行为测试另行审阅。统计函数的 t 分位数曾用 50 位 mpmath regularized-beta 反演独立验证，见 [review_root_statistics.json](results/review_root_statistics.json) 和 [review_root_statistics_v2.json](results/review_root_statistics_v2.json)。

## 8. 复现与剩余 blocker

复现命令见 [README.md](README.md)。对已发布结果执行独立审计不需要重新打开 owner 世界。重跑实验应在冻结源码的独立 worktree 中进行，复制交付头的 `PUBLICATION.json`；所有证据采用 create-only 写入，不能覆盖旧 results。同源码、同 namespace 的重放属于可重复性验证，不能称新的科学确认。

本轮仍未完成的采用条件包括：原 `D−B` 实用收益、完整成本 CPU 优势、学习型语义寻址、真实跨模态长距离绑定、连续自由边界与全时域控制、生产 Rust ownership／pending-action 恢复，以及 GPU、能耗和生产通信验证。支持保持、锚定时间推进与有限质量非劣可以保留为具体成果；它们不能把这些开放项自动改为通过。
