# MemoryCell: exact five-archive causal research decision

This lab is deliberately **not** a new model runner, new memory system, or
production acceptance issuer. It independently replays five immutable GitHub
Actions artifacts, including real program-worker execution, before summarizing
Reader capacity, nonparametric organization, parameter-memory eligibility and
lifecycle constraints.

Frozen archive artifact IDs: source `11669174727`, SmolLM2-1.7B
`11674486085`, Qwen2.5-3B `11674741321`, 40+72 full RAG
`11696514149`, independent replay `11696898778`. Exact outer SHA-256s
are enforced in code and checked again by the reproduction scripts.

Execute from the repository root with the five original ZIPs:

```sh
PYTHONPATH=scripts/memory_cell python3 scripts/memory_cell/real_memory_five_archive_gate.py \
  source.zip smol.zip qwen.zip strong.zip replay.zip new-audit.json
```

This checks **208 actual model-generated answers** (48 per reader and 40+72
additional Qwen RAG calls), all 48 matched Reader source/input pairs, and
re-executes 24 original controlled program-worker invocations from the
published frozen worker source. No generated answer, citation or task score
is changed. These are **authored development tasks**, not independently sampled
future work, and the publisher support graph has not been independently human
adjudicated as sufficient and necessary.

The observations support three separate diagnoses:
- Reader **capacity**: SmolLM2-1.7B organized 3/8 versus Qwen2.5-3B
  organized 8/8 on matched source bytes; this gain is not parameter memory.
- **Nonparametric** memory: Qwen hybrid 3/8 versus entity/time projection 8/8
  on the same reader; further graph organization adds **0** correct tasks
  but saves 573 input tokens in the complete 72-evaluation experiment.
- **Lesion confounding**: four of eight omitted-premise contexts also omit
  the answer literal. This does not establish independent premise necessity.

Admission remains closed. No matched knowledge-module or learned-policy
advantage over the strong same-reader RAG baseline has been demonstrated on
independent future data. Human oracle sufficiency, long-term retention,
multi-node revocation recovery and complete extraction+index+training+
query+maintenance+storage costs remain unmeasured or uncertified. Retaining
raw evidence and the measured model weight footprint must not be omitted
from economic analyses. No source/model reviewed here may be promoted by
the audit alone.
