# PFT 第二轮：实际闭合结果、负结果和仍需真实输入的门

本轮把第一轮的几个工程缺口推进到了真实设备、真实 SmallHCSN、外部候选封存、独立测试和新进程复用。新增研究使用 PFT 独立身份；没有重跑或改名消耗已有 E1–E6 预算，没有把两个设备、工程身份或合成数据当成两位真人。

**双机解析读出层训练已经实跑并通过复核。168 个公平配置的受约束端到端 BP 实验已经完成，结果为混合收益，部分核心比较没有优势。真实 A→独立 B→原生采用→新任务再次使用仍未获得必要原件与运行时资格。**

## 1. 本轮闭合了什么

| 原缺口 | 本轮实际证据 | 结论范围 |
| --- | --- | --- |
| 只有 loopback 或控制器转发 | 两台实机通过既有 USB4/SSH 直接交换；12 组基础协议及 12 组真实 HCSN 统计量协议 | 固定、受信的两个节点；没有中心统计量转发 |
| 掉线恢复仅为模拟 | 每组真实 `exit(17)`，新 PID 恢复原检查点并完成求解 | 原贡献身份、逐帧字节、错版本拒绝和重复幂等均复核 |
| 统计量尚未由真实 HCSN 产生 | 两端各自运行冻结物理源码、生成非 IID 训练特征，重构原 provider 文件并核 SHA | 固定物理模型上的读出更新，不能推广为全场闭式更新 |
| 原 HCSN 跨宽度起点、后端和预算不同 | 8/16/32/64 单元、三个初始化 seed、同 dense/float64、固定预注册的 168 配置 | 全部实际完成 96 次更新；无失败、无预算截断；不声称收敛 |
| 缺少测试开放前的外部候选封存 | 两个研究分别先发布完整候选 Git seal，再调用 evaluator 生成测试 | 测试目标未进入训练或 backward boundary |
| 只证明参数能重新加载 | 12 个新进程冷加载真实 HCSN 更新模型并重放 24 个已开放测试分区 | 预测逐元素一致、物理参数原值不变；研究文件模型复用 |
| 原生撤销与冷恢复缺少组合实跑 | 原 Agentd owner/runtime 的一个新组合测试实际通过，1 次 dispatch、1 次 nonce 消费 | 工程角色与模型 fixture；不能替代真实模型或真实 B |
| 原始证据无法审计或单文件超限 | 完整统计量、模型、预测、历史、检查点、帧及逐字节清单；每个 Git blob 小于 512000 B | 不修改 size policy 或 allowlist，保留失败与低分 |
| 主分支清空首页后 readiness 仍要求首页导航 | 仅移除空首页的 discovery-link 要求，保留四个内部入口；完整 docs 验证和既有 11 项测试通过 | 原授权、资格与 source gate 不变；不代表全仓 CI 通过 |

下述数字均可由本目录的原件重算。完整度审计与有利科学结论分开：程序运行成功不等于所有模型超过质量阈值，工程测试成功不等于真人闭环完成。

## 2. 真正接通的双机训练

### 2.1 协议与故障恢复

基础协议的 12 组实验覆盖维度 8/16/32/64 和三个 seed，独立 NumPy 集中解的最大相对 action 误差为 `7.700594136418377e-16`。12 次真实中断恢复全部成功，两端原候选 hash 相同。其应用层双向数据为 6,925,364 字节，supervisor 总墙钟为 16.2619 秒。原先任意 TCP 端口的连接失败记录仍保留，后来使用已有认证 SSH 的直接 USB4 路径解决可达性；未改变防火墙。

真实 SmallHCSN 研究又执行了 12 组：8/16/32/64 个单元对应 21/41/81/161 个读出差分参数。统一准备阶段从两种节点分布各生成 32 个公开无标签 calibration 样本，固定并下发同一坐标；随后两台设备各自生成 128 个本地训练样本。每个节点自行计算并交换 `G=XᵀX`、`b=Xᵀ(y-Xw₀)`，随后各自求解 `(ΣG+0.01I)a=Σb`，安装 `w₀+a`。物理递归、QVI 相关计算和初始模型来源都由同一源码 capsule 固定。

33 项逐 case 审计全部通过，含双方候选原内容、action、parent+action 关系、原 provider 原件重构、精确帧散列、字节守恒、新 PID 和原检查点恢复。最大独立集中解相对误差为 `1.2580727370995353e-10`，最大相对正规方程残差为 `5.821676675447782e-14`，均低于预设容差。应用层双向数据总量为 **40,042,839 字节**，supervisor 耗时 **42.4656 秒**。审计在普通 Python 和 `python -O` 下均通过。

来源：[基础双机结果](p2p_closure_v2/results/pft2_direct_peer_ssh.json)、[真实 HCSN 预测试审计](p2p_closure_v2/results/pft2_real_hcsn_pretest_audit.json)、[完整通信证据](p2p_closure_v2/ACTUAL_HOOK.md)。

### 2.2 冻结后的泛化与冷启动

真实 HCSN 读出研究先在 Git `e725f22b5c9806fb1ebb33845085195926a993b4` 发布 12 个候选，再生成独立测试。每个 seed 有两个来源、各 128 个测试样本。以下为三个 seed 的均值：

| 单元数 | 父模型准确率 | 跨机解析更新后 |
| ---: | ---: | ---: |
| 8 | 46.35% | 74.35% |
| 16 | 50.52% | 81.90% |
| 32 | 51.82% | 85.81% |
| 64 | 52.34% | 87.11% |

同一 seed 的测试输入跨宽度复用，共 768 个不同测试样本，不能把 3072 次评估当成 3072 个独立样本。候选安装后的真实模型预测与线性坐标预测最大差为 `2.2160051571518125e-12`。之后每个模型都在新进程中从保存文件加载：12 个不同 PID、24 个测试分区，预测差精确为 0，目标、坐标预测和非读出参数全部一致。

来源：[真实模型方案与范围](actual_p2p_v2/README.md)、[逐 case 测试](actual_p2p_v2/evaluation/RESULT.json)、[冷启动原件](p2p_closure_v2/evidence/cold_replay_v1/RESULT.json)。

这项正结果证明实际 HCSN 表示上的一类可合并二次权重更新可以在两台设备完成，并形成可复用模型。它没有证明统计量隐私、任意陌生节点准入、恶意节点容错或大规模广域网训练。

## 3. 168 配置的受约束端到端训练

### 3.1 公平性修复和外部冻结

正式矩阵为 144 个主配置：4 个宽度 × 3 个初始化 seed × 2 个读出特征库 × 3 种消息通道 × 2 种循环权重条件；另有 24 个嵌套标签量配置。所有宽度使用 dense/float64、同一物理源码和明确的固定训练预算。开发集选择包括已做有监督 ridge 拟合的 step0，所有运行仍实际完成 96 次 BP 更新。

正式 v2 协议在 Git `221c4fb6a6ece0fba3d0052a66c9beeca7d1dcd3` 发布并读回后才开始训练。168 个最终候选在 Git `7dfd1deb8b70867a7875ef1fc99cd1a6b20f4953` 发布；随后首次开放测试。旧 `FORMAL_PROTOCOL.json` 是保留的 v1，正式训练使用 `FORMAL_PROTOCOL_v2.json`，两者不能混用。

独立审计核对了 5 份研究源码、25 份物理源码、provenance、测试数据，以及 168 组的 candidate、训练 RESULT、HISTORY 和测试预测，共 672 份逐臂原件。190 个无损包的 981 个成员也与留存原件逐字节匹配；总归档 19,180,320 字节，最大单包 228,124 字节。

来源：[正式方案和完整解释](actual_hcsn_v2/README.md)、[候选 seal](actual_hcsn_v2/GLOBAL_CANDIDATE_SEAL.json)、[训练汇总](actual_hcsn_v2/TRAINING_SUMMARY.json)、[原件独立审计](adoption_closure_v2/receipts/HCSN_V2_ARTIFACT_BYTES_AUDIT.json)。

### 3.2 主要比较与负结果

在 full message、循环权重可学习的预定子组中，三个初始化 seed 的测试均值为：

| 单元数 | value/risk 特征库 | 等维 tanh 特征库 |
| ---: | ---: | ---: |
| 8 | 79.95% | 82.29% |
| 16 | 88.28% | 89.84% |
| 32 | 90.10% | 82.29% |
| 64 | 85.42% | 76.56% |

全主矩阵的配对描述如下：

| 比较 | 平均测试准确率差 | 具体限制 |
| --- | ---: | --- |
| value/risk − 等维 tanh | +1.931 个百分点 | 72 对，46 胜、4 平、22 负；不是所有宽度/配置获益 |
| 学习循环权重 − 固定循环权重 | −0.087 个百分点 | 72 对，29 胜、7 平、36 负；没有稳定正收益 |
| dev 选中的 BP 候选 − 初始 standardized ridge | −0.206 个百分点 | 主组 144 条，范围 −11.719 至 +9.375 个百分点 |
| standardized ridge − raw ridge，同数值 λ | +20.226 个百分点 | 去重后 72 个初始表示；改变了坐标中的正则度量 |

测试前预设的 85% 经验准确率门由 **68/168** 个配置达到，其中主矩阵 **67/144**。不能把它写成所有配置达标或独立成功率。47 个候选选择 step0；36 个候选选择预算末端 step96。64 单元的 18 个循环权重可学习主配置全部选择 step0，不能以最后一步的参数变化冒充最终采纳的能力更新。

来源：[最终描述性汇总](actual_hcsn_v2/FINAL_SUMMARY.json)、[逐组分析](actual_hcsn_v2/ANALYSIS.json)。

### 3.3 必须保留的解释边界

**这是岭回归初始化之后、固定拓扑下的受约束端到端 BP。** `raw_boundary` 没有参与训练；fixed 组还冻结循环权重。连接 mask/topology 不学习，`full` 指消息通道，tanh 指 HCSN 内部的等维特征库。它不是从随机读出头开始的全参数 BP，也没有普通 RNN/Transformer 的同预算完整对照。

step0 已消耗训练标签、特征生成和求解成本；它不是未训练模型。即使最终选 step0，96 步 BP 的实际成本也保留。所有配置共用固定 train/dev/test 数据，只有三个初始化 seed；72 对或 168 条不是独立重复次数，本文不据此声称显著性。

标准化的解释尤其要谨慎。令原坐标权重为 W、特征尺度为 D，同数值 λ 的 raw 与 standardized 头分别惩罚 `λ||W||²` 和 `λ||DW||²`，代码没有保持原正则度量的矩阵补偿。两者都中心化并使用未惩罚截距。+20.226 个百分点因此包含尺度、正则偏好和数值条件的共同变化，不能全部归因于浮点稳定性。后续 BP 优化最终步交叉熵，也不是相同平方 ridge 目标的另一个求解器。

16/32/64 的样本曲线指嵌套训练标签数；仍另用共享 64 个开发标签和此前诊断/调参。该曲线在这一固定合成任务中提供描述性证据，不能直接换算真实任务的总标注效率。此前 PFT 的 Riccati 规划探针仍是独立控制问题，本轮没有将其嵌入 HCSN 后证明完整任务规划收益。

## 4. 原生采用链：已做的工程工作与真实缺口

新增私有输入契约可依次进入 `frozen_waiting_b`、`evaluation_ready`、`first_use_ready`、`repeat_use_ready`。它允许在 B 尚未出现时固定 A、候选和旧能力集；后续只能追加一步，不能更换候选、改写旧前缀、跳过阶段或把相同原字节重命名成新任务。结构和散列检查始终不发行真人授权。

原生组合测试在固定源码 `fe249567feae227a362d354c1df3499a2995af40` 上实际通过了 1 项指定测试，另外 867 项未选择。它实际调用原 Agentd owner/runtime，验证一次工程采用、丢弃 actor 后冷重开、原 CURRENT/journal/witness 的读取，以及实时撤销后读回和再次冷恢复被拒绝。实际控制 dispatch 与 nonce 消费均只有一次；原请求读回不能算新任务再次使用。编译缺资源与宏导入的先前失败全部保留，没有修改原 Cargo.lock、依赖 revision 或授权规则。

当前原生声明适配器只接受已审计 ELF 的 `--help`、`--print-statement`。本轮实际完成当前 CLI 的 `--locked` 构建，并实跑 train、evaluate_only、request_consumer_run、report_consumer_outcome 四类声明，全部退出 0。固定来源的保护性原 turn verifier 仍为 `ORIGINAL_TURN_VERIFIER_REQUIRED`，原 owner-intake 路径不可用；普通运行时 main/CLI 的真实 stage owner、Circuit provider 和 Root lane 装配也没有因此自动完成。声明渲染成功不授予这些权限。

**下列真实门仍未闭合：**

| 门 | 必须新增的真实证据或能力 |
| --- | --- |
| 原始授权 | 原站点能绑定原 Core turn、当前队列/checkpoint、精确 scope 和撤销状态的原生 verifier/issuer |
| 独立用户迁移 | A 的授权成功经验、登记机构证明的不同 B、候选冻结后才到达的 B 新任务与冻结 keep 集；B 答案留在评估侧 |
| 原生实际采用与复用 | 原 owner 采用同一冻结模型，对 B 的实际任务完成交付，并在另一项新任务中再次使用；需要时有合法的新授权前进绑定 |

历史公共 A、两个机器账户、工程角色签名和文件模型冷复用分别具有自己的证据范围，不能补齐这三道门。详见 [接入契约、源码审计及原生结果](adoption_closure_v2/README.md)。

## 5. 成本、数值和 CI

168 个训练运行以四个单线程进程并行完成，训练总子进程 CPU 为 **3587.52 秒（59.79 CPU 分钟）**，campaign 墙钟为 **995.18 秒（16.59 分钟）**，包含宿主共享带来的争用。独立测试 launcher 另耗 **320.04 秒墙钟、317.74 秒 CPU**。初始化、特征和求解、优化、开发集、序列化等逐臂阶段在原件中独立记录；不能用选中的早期 step 截短实耗成本。

真实双机 HCSN 读出研究另外记录了环境准备 490.24 秒、公共坐标 11.19 秒、两端准备 22.52/29.37 秒、网络协议 42.47 秒、独立测试 49.38 秒及冷复现 33.16 秒。两端并行阶段和通信等待不能直接相加。38.12 分钟仅是环境任务创建至独立测试完成的实际观察窗口，包含控制等待和并行工作，并且不包含之后冷复现和归档。没有据此宣称同质量系统加速，也没有测量功耗。

概率质量最大误差为 `2.220446049250313e-14`，signed mark excess 为 0。训练前的小规模有限差分与缓存等价检查支持相应实现路径；它们不是全参数、全状态空间的形式化证明。

仓库本轮修复的 CI 问题只涉及清空首页后的 readiness 导航要求。完整 development docs verifier、既有 11 项语义测试和官方 `just fmt` 均通过。formatter 配置默认排除 qualification Python，故不把该命令写成所有研究 Python 文件的格式合格证。全仓 Rust/Bazel/平台 CI 的独立状态须以 GitHub 当前检查为准，不能继承为本研究通过。

来源：[成本与参数分析](actual_hcsn_v2/ANALYSIS.json)、[双机成本口径](actual_p2p_v2/SUMMARY.json)、[导航修复验证](ci_navigation_v2/VERIFICATION.json)。

## 6. 对最初参数场问题的实际回答

第一轮的零空间对照已经给出只知端点时的不可识别实例；本轮没有增加足以消除一般神经网络参数对称性、欠定性和模型错配的信息。把终点写成 FBSDE 的边界条件，仍需要给定或识别动力学、代价、噪声和观测算子，不能凭边界记号直接唯一恢复大模型全部权重。原始结果见 [PFT1](results/pft1.json)。

本轮新增的实证支持较具体的路径：固定真实 HCSN 的物理表示和共同坐标后，分布式充分统计量可以解出同一个二次读出更新，两个节点能够完成真实中断恢复，并得到在新输入上有效、冷启动后可复用的模型。把这一机制扩展到可学习的非线性动力学、任务级 PFT 规划、完整大模型及独立真人迁移，各自仍需要相应的新增证据。
