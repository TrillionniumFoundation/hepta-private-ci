# PFT 六组实验：执行、负结果与资格边界

这套研究从“端点能否确定参数、统计量能否去中心化求解”推进到可重复的实证。
编号为 **PFT1–PFT6**，独立于仓库已有 E1–E6 自动化；旧实验的身份、预算和证据不变。

**核心矩阵已经实跑。结果支持特定线性问题的可识别性及充分统计量聚合，尚未建立 Hepta 解析结构、学习连接或端到端 PFT 训练的普遍优势。**
真实跨用户 A→B 与生产运行时采用仍需要真实授权数据及采用证据。

## 执行范围

| 实验 | 本轮执行 | 结论边界 |
|---|---|---|
| PFT1 | 4 宽度 × 3 seed × 3 条件 × 5 观测方式，180 行 | 已知外部激励的线性状态系统，不是 LLM 权重反演 |
| PFT2 | 12 组非 IID 聚合；另 12 组四进程 TCP 与退出恢复 | 同父模型、同坐标、同二次目标；多宿主结果单独归档 |
| PFT3 | 8/16/32/64 单元，108 次结构拟合 | 新 NumPy 循环研究模型；使用 BPTT，固定律 F/G 只是特征 |
| PFT4 | 额外 12 次固定连接拟合、60 行对照、12 个冻结父模型置换 | 通信依赖与架构优越性分别判断；LQ 是独立机制探针 |
| PFT5 | 24 个有利/冲突合成 case，四种泄漏或篡改负例 | B 标签只在候选冻结后的独立 evaluator 中读取；真实 A→B 未达成 |
| PFT6 | 120 行五方法、等预算/同质量成本比较 | 真实本地计算计时；原矩阵的网络、能耗及 Hepta runtime 采用未测 |

完整源码、逐 case 收据、失败结果、冻结候选和合成数据均保留。大体积原始证据以无损 archive 提交；manifest 列出每个原始文件的 SHA256。

## 主要发现

### 1. 增加可观测方向，而不只是增加初态数量

PFT1 的模型是 `s[t+1] = 0.7*s[t] + W*q[t]`，未知参数是 `n*n` 的 W。
`q` 是已知外部激励，W 非奇异；本轮没有同时识别未知递归动力学或扩散。

| 精确线性条件 | 留出终点相对误差均值 |
|---|---:|
| 单初态单终点 | 0.9643 |
| 多初态、有限终点 | 0.9057 |
| 完整中间轨迹 | 1.30e-14 |
| 与轨迹相同观测数量的独立终点 | 9.33e-15 |

仅改变响应初态、固定外部激励的负对照仍为 rank 1。12/12 个零空间构造保持训练终点不变，同时改变留出预测。
完整轨迹在测量噪声下误差为 0.1411，在非线性模型错配下为 **1.6795**。满秩不保证错配模型的泛化。

### 2. 可以合并二次目标，不能任意平均局部权重

共享父模型及坐标基时，每端提交 `G_i = K_i.T @ K_i`、`b_i = K_i.T @ residual_i`；全局 ridge 只加一次。
集中解与聚合解的最大相对差为 **2.60e-15**。直接平均局部权重在 12/12 个分布变化测试上更差。

四个真实 Python 进程通过 loopback TCP 各自交换、汇总并求解。每组一个节点在持久化贡献后真实 `exit(17)`，随后以新 PID 从账本恢复。
12/12 组恢复通过，每组四节点最终候选 hash 相同；相对集中解的最大差为 **1.85e-15**。

去重针对声明的贡献标识，不提供一人一次、Sybil 抵抗或跨身份内容去重。
hash 不证明统计量由诚实数据产生，也不提供隐私。loopback 数据不等同于 WAN 证据。

### 3. 解析结构的收益尚未出现稳定证据

每组 512 train / 128 validation / 1024 test。任务等待晚到的第二个 bit，再对早期与晚期 bit 分类。
测试改变线索噪声分布、晚到时间支持及初态方差；目标不进入前向计算。
新信息到达前准确率均值 **50.07%**。

| 结构 | 边界 | 平均测试准确率 |
|---|---|---:|
| Boundary F/G | 固定 / 可学习 / QVI prior | 96.09% / 96.93% / 93.55% |
| Signed flow | 固定 | 99.06% |
| Both F/G + flow | 固定 / 可学习 / QVI prior | 94.24% / 96.36% / 95.55% |
| 等维普通特征 + flow | 固定 | 98.58% |

64 单元 Both 固定边界的一次训练只有 **50.59%**，完整保留。
同宽度、同消息维度和相同更新次数不等同于相同墙钟预算；每行都报告参数数量与耗时。
可学习边界增加 `width` 个可训练参数。

`qvi_prior` 来自一个明确的 81 状态有限链 reset Bellman VI；Bellman residual 为 0，转移质量误差 1.11e-16。
该问题的成本是状态平方、reset 费用和终端平方，不是分类损失。
其阈值 0.5 恰与验证选择的固定阈值相同，未建立 QVI 优于学习阈值。

### 4. 连接被使用，与学习连接更优是两个问题

| 单元数 | 学习连接 | 固定连接 | 普通等维循环模型 |
|---:|---:|---:|---:|
| 8 | 93.91% | 90.14% | 96.22% |
| 16 | 99.64% | 99.35% | 99.09% |
| 32 | 99.87% | 99.90% | 99.54% |
| 64 | 83.53% | 100.00% | 99.48% |

12 个选中父模型先严格恢复同一权重及预测 hash，再置换同轨迹中的 sender 身份，保持两个通道配对。
平均准确率由 94.24% 降到 53.11%，但也保留置换反而改善的种子。
原跨样本 shuffle 属于另一种关联破坏对照，未与 sender 置换混称。

独立 LQ 探针保留 PFT 的物理更新尺度 `h*sqrt(h)`。
固定反馈、单步 greedy、有限时域 Riccati 的平均成本为 **1.19761 / 26.20476 / 1.16202**。
这是已知延迟控制系统的结果；不代表完整 HCSN 网络已由 PFT 获得同等收益。

### 5. 冻结后的 B 测试可以拒绝不良迁移

训练只读取 A、keep_train、父模型及评估数据的 hash 承诺；B 的路径与答案不进入 trainer manifest。
随后冻结候选，再由独立 evaluator 核对候选 hash 并首次读取 B 的标签。

| 合成条件 | 通过 | B 相对 MSE 改善中位数 |
|---|---:|---:|
| 共享真值、新旧子空间分离 | 12/12 | 99.24% |
| A/B 目标冲突、新旧子空间重叠 | 0/12 | -127.85%（变差） |

向 trainer 注入 B、冻结后改评估 manifest、复制训练内容但改 ID、冻结后篡改候选：四类负例全部拒绝。
这属于进程与代码路径隔离，不是对恶意代码的 OS 安全隔离；精确内容去重不证明语义独立。
所有 actor 均为 synthetic，真实门槛保持 `BLOCKED_NO_REAL_CROSS_USER_DATA`。

### 6. 同质量比较削弱了表面的加速倍数

主要比较固定相同表示和读出目标下的 readout BP、ridge、RLS。
rank-two 双因子读出 adapter 和 full BP 的参数范围不同，作为附加对照。
dev 早停及最终独立 test 均要求 MSE <= 0.0008。

| 方法 | 质量通过 | 本地端到端时间中位数 |
|---|---:|---:|
| Readout BP | 12/12 | 2.211 ms |
| Ridge | 12/12 | 1.567 ms |
| RLS | 12/12 | 4.250 ms |
| Rank-two adapter BP | 9/12 | 3.193 ms |
| Full BP | 10/12 | 3.014 ms |

配对 BP/ridge 时间比中位数 **1.450×**，范围 **0.843–1.802×**，有 ridge 更慢的 case。
BP/RLS 比中位数 0.546×，RLS 在这 12 个 case 全部更慢。未以失败方法的短耗时声称加速。
等预算结果也保存，但不以其约 50 倍差距替代公平的同质量比较。

计时包括加载、特征、诊断、求解、验证、序列化、读回与本地模拟采用。
数据生成和进程启动不计入单 case 小计；OS page cache 未清空；这是毫秒级微基准，未证明稳定系统加速。
PFT6 的测试数组在加载阶段已进入进程，但不用于训练或早停；其隔离弱于 PFT5。
原矩阵 `remote_transfer_s`、能耗均为 null，Hepta runtime adoption 为 false。另行跨宿主探针不能补成这一完整成本链的采用证据。

## 复跑与核验

冻结本轮环境是 Python 3.12.14、NumPy 2.3.5、SciPy 1.17.0。其他环境重跑应作为新证据，不继承原 hash。

```bash
python3 -m pip install -r requirements.txt
python3 run_suite.py --profile full --output /absolute/new/output
python3 run_suite.py --profile smoke --output /absolute/new/smoke-output
```

输出目录必须全新。完整 runner 顺序执行九条命令，先保存源 hash 和配置，再产生各项结果；不以科学结果有利作为程序通过条件。

若已下载原始 archive，可在新目录解包，并审计原始候选字节：

```bash
mkdir /absolute/new/evidence-view
tar -xzf evidence/raw_evidence.tar.gz -C /absolute/new/evidence-view
python3 verify_receipts.py --results /absolute/new/evidence-view/results
```

核验覆盖 24 个冻结 PFT5 候选和 120 个 PFT6 候选、源 hash、匹配数据、因果性、真实 TCP 退出恢复收据、负例拒绝。
ridge 与 RLS 候选的最大相对差为 **4.33e-14**。禁止 `python -O` 关闭断言后运行验收。

这是探索性研究矩阵。PFT5 的评估 hash 承诺先于拟合，不等同于整个项目在任何探索之前完成了外部预注册。
只有三个种子，没有声称统计显著性或普遍优势。smoke 回放、父模型恢复均不计为额外独立样本。
