# Post-publication LIF clock correction on the retinal event association test

The published LIF baseline advanced its membrane and adaptation with exp(-2/tau) at each 1 ms retinal input step, carrying over parameters from cortical data sampled in 2 ms bins. Replace exactly the two exponent numerators by 1. Retain the same physical time constants (membrane 4+4*(unit mod 6) ms, adaptation 25+15*(unit mod 4) ms), one-step effective refractory equation, readout columns, adaptation gain, soft reset, drive, temperature and threshold. The original points and conclusions remain available. This sensitivity analysis is post hoc; the earlier results are public. The corrected arm's cold scores have not yet been computed. No retraining or reselection of another arm is authorized for this correction.

Use the input spike files and assignment function from the original study, unique 5,000–9,997 ms retinal intervals, train odd trials 1–43, development 45–55, and score odd 57–75 only after freezing the corrected fit. Compute normalization from all 10,000 bins of training trials alone, and retain the same six causal filters. Train four candidates, the Cartesian product of input scale (0.6,1.3) and ridge (0.01,0.0001). Select the earliest lowest pooled development BCE candidate. Freeze input, code, readout, normalization, candidate and source hashes before opening the cold trial files in the fitting process. Cold application occurs in a separate process. As compatibility verification, the identical corrected kernel instantiated with the legacy dt=2 and the previously stored legacy coefficients must reproduce the old cold LIF probabilities, without fitting the old arm. Verify event labels, trial IDs, timestamps and order against the previously published cold NPZ; directly compare the new LIF to every previously sealed arm using their original predictions.

Use mean log loss per repeat as the main measure. Report paired whole-repeat bootstrap (ten repeats, 6,000 resamples and seed 30588), pooled log loss, Brier, calibration, training-rate reference and per-repeat differences. Publish actual full code, all four development fits, selected coefficients and complete corrected cold predictions. This is one recording, sampled in the last ten unique-input trial segments. Comparisons against prior methods are paired to the identical events.
