# Prospective external Git diagnostic: immutable implementation package

The prospective precommit and implementation V1, V2, V3 files are copied byte for byte. V3 removes unnecessary future-annotations imports; V2 permits byte-identical Git-object role aliases and rejects contradictory aliases. All new-cohort model calls were zero at the V3 seal. This package does not contain a new model result or a production qualification. SHADOW_ONLY / DENY_ALL / NO_GO remain in force.

The source archives retain every consumed original commit, root tree and license object as raw bytes, their original source/command receipts, and the primary calibration metadata. Archive headers are normalized; member bytes are unchanged and hashed in PUBLICATION_MANIFEST.json. The initial Zed license failure remains separate from its successful same-pair recapture.

Complete bare Git download stores are omitted because they also contain unconsumed subtree objects. A read-only object store can be reconstructed without network from each receipt's original_objects and root_license_objects: initialize a fresh bare repository, run git hash-object -w --stdin -t <recorded kind, or blob for license> with each exact raw member, and require the returned ID to equal recorded git_sha1. Then independently verify git cat-file -t and git cat-file <kind> bytes. Do not execute repository code or hooks. These reconstructed stores are derived replay artifacts, not new external captures. The frozen scoring code is bound to the original captured stores, with replace objects and lazy fetch disabled. No new-cohort model scoring has run.

The frozen projection records the original absolute execution paths. This package does not silently rewrite those paths or their hashes. Full runner replay requires the captured layout or a separately disclosed relocation receipt; raw Git identity and projection inspection do not require the original download pack.

The inherited Memory source is identified by commit 2f8c5678d19713ed4d532768f245a4810b139377 and per-file hashes in the three immutable identity files. Its hundreds of unchanged modules are not copied again here. No model weights, Python runtime, training data, obsolete projection outputs, or running original-evaluation files are included. Original Memory 112 execution and this future-source profile are distinct experiments.

Code was frozen after the prospective source window opened, before any new-cohort model output. The additional five-point lexical retrieval calibration search is explicitly disclosed and is not claimed to have been fully preregistered. Repository families are proxies; committer dates are not independent creation attestations. Git metadata projections do not establish independent semantic citation adjudication or production suitability.
