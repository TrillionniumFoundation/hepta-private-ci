## Locked official text-score component

The official [VizWiz example API archive](https://vizwiz.cs.colorado.edu/VizWiz_final/vqa_data/API.zip)
was accessed with exact bounded ranges and archive member CRC verification.
Archive ETag is `"b100d2d-5f706f9ea99e6"`, size 185,601,325 bytes. Only the
required original scoring member and bounded ZIP metadata were read. The whole
archive hash is not claimed. The 11,856-byte `vqaEval.py` member SHA-256 is
`d26ef7ac2db06351444c3531f8d95fd9c454423fbcb9fd5dd984f12281146694`.

The component `vizwiz.official-20230316.text-accuracy-prefix.v1` extracts the
original `VQAEval` accuracy statements through its unique top-level
`self.setAccuracy(...)` call. It retains the original normalization and ten-answer
leave-one-out scoring; it does not normalize gold strings beyond the upstream
implementation. Scores use the official two-decimal percentage convention.
Caption and unanswerability metrics are excluded. The adapter contains no copied
upstream scoring source and does not infer a redistribution license for it.

The native Python 3.12.3 component AST SHA-256 is
`108e3bbd265990fcae19b0e89fba85e83784dc7082d28199fbe35625b92da16e`.
The exact original source bytes and Python version remain part of the lock.

For each of the 90 existing human reference answers, the extracted component's
text accuracy matched the complete same-version `VQAEval` class. In this
conformance run the full class used an empty caption adapter that asserted text
accuracy had already completed before it was called. All 90 comparisons passed.
These reference-derived probes are **software conformance, not model predictions
or model performance**. No independent training repeats were executed.

An offline terminal-prediction interface now requires exact external hashes and
the complete selected case roster. It rejects unfinished, missing, duplicate,
extra, and privileged-field predictions before opening references. The output
retains whether predictions are captured model outputs, reference probes, or
synthetic test fixtures. Self-declared terminal flags and hashes do not establish
generator custody or erase past exposure. Online actor/critic projections exclude
gold; process and filesystem isolation remain unverified.

The new component is a prospective development diagnostic. It does not replace an
ongoing pilot's predeclared primary metric or qualify image-edit quality, five
task families, independent confirmation, or an independent human review panel.
The [VizWiz VQA page](https://vizwiz.org/tasks-and-datasets/vqa/) states that its
VQA evaluation servers were deprecated in April 2026 and that test annotations
were released for self-evaluation. The [offline service page](https://vizwiz.org/offline-benchmarking-service/)
also describes the April 2026 shutdown for tasks outside the remaining workshop
challenges. This work does not claim a currently independent hidden VQA service.
