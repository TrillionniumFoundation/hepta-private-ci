# GPT editing under a new anonymous weight representation

One frozen GPT program correctly transferred the previously established
late-quote sign rule to three anonymous views of real checkpoint weights.
Its decoded native edits and final score bytes exactly match the canonical
compiler. This is a successful use of supplied mathematical semantics, unit
identities and weight values; it is not independent circuit discovery.

## What was hidden and what was supplied

The editor had the known mechanism and a label-free packet containing affine
weights, signed-feature readout weights and a precise task contract. Each view
used new unit and feature permutations, anonymous tensor/unit names, a sign
gauge and signed affine feature units. The head's unit order was independently
permuted, so matching array positions was insufficient. The physical price
coordinate could have a negative scale and nonzero translation.

The editor did not read the host seed mapping, generator, inputs, labels or
new test outcomes. Its one program and one explicit candidate were sealed at
`2026-11-28T11:12:02.932501+00:00`; the host then sealed decoded candidates
before generating 40 new contexts/80 swapped-price queries in [-4,4].

The program aligns units by ID, forms each signed-head contrast, and sets
`A_quote' = -sign(contrast * quote_scale) * abs(A_quote)`. It compensates the
derived view bias by `-delta_A * quote_translation`, keeping the native bias
fixed. The native host decodes only the four allowed price-coordinate words;
every other parameter/header byte stays equal to the parent. The program
abstains when the declared contract is unsupported or every usable path is zero.
Strict ordering still requires a live physical coefficient and sufficient F32
resolution; the nonpositive derivative alone does not ensure either.

The transformed tensors are a weight-program view of the final affine map,
not an unreported persistent native graph rewrite. All endpoints below use the
complete source-bound native graph with its explicitly declared final-tick
mark bridge.
