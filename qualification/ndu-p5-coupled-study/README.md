# P5: Nonlinear coupled binary FBSDE with independent Newton control

**Research-only / no model authority / DENY_ALL.** This is a *full-tree discrete*
FBSDE with nonlinear drift/terminal conditions and two-sided forward/backward
coupling. It is not an empirical reasoning system, pretrained Encoder, natural
multimodal capability, or a numerical proof for a general continuous-time FBSDE.

## Registered law and admissibility

Each discrete step has the same independent symmetric increment
`epsilon_{k+1} in {-1,+1}` conditioned on public prefix information:

```
X_(k+1) = X_k + a*h*Y_k + sigma*sqrt(h)*epsilon_(k+1)
Y_k = [E(Y_(k+1)|F_k) + h*beta*tanh(X_k)]/(1+h*lambda)
Y_T = tanh(X_T)
Z_k = (Y_(k+1,+)-Y_(k+1,-))/(2*sqrt(h))
Sigma_k = h; B_k = h Z_k.
```

The pilot's **sufficient discrete map contraction**
`q=a*T*(1+beta*T) < 0.95` admits the full joint fixed-point iteration;
otherwise fail closed before refining a local mesh. Every candidate uses the
SAME whole-tree terminal goal. The error surrogate `||Y-F(Y)||/(1-q)` is a
bound for the ideal *discrete exact-arithmetic* map if its contraction
assumptions hold. Python float operations are **not outward-enclosed error
certificates**. No Brownian-motion strong convergence, PDE result, semantic
truth, stochastic-coefficient identification, or utility improvement follows.

Every candidate is rechecked against the original global map and both
signs of each stochastic edge; `Z Sigma = B`, terminal condition and
conditional drift are independently validated. The deliberately incorrect
branch resets a terminal field at the interior level, often leaving the
last terminal residual *exactly zero* even though whole-tree residual is
large; it is always rejected. Stochastic time is **not Transformer layer depth**.

## Three independent-cost controls

- **Picard:** direct bounded fixed-point iterations of the globally coupled
  map over all public prefixes, no learned parameters.
- **Independent Newton:** separate prefix-indexed implementation of the same
  forward/backward law; central algorithm does not call the independent
  implementation. Finite-difference Jacobian with dense pivoted linear solve,
  all actual map calls charged. Restricted to <=5 steps.
- **Cheap noncoupled BSDE:** when `a=0`, one backward conditional recursion is
  enough. It must match Picard numerically; expensive FBSDE solving cannot
  claim a gain on this model family.

Predeclared factorial: `a in {0,.25,.6,.85,1.1}`, steps `{3,4,5,6}` and
`X0 in {-.6,0,.7}` = **60 distinct profiles**, 48 supported and 12 rejected
at the *global discrete* contraction gate. Each successful profile also checks
one deliberately wrong-reset path. 36 cases have a separate dense Newton
reference, and 12 noncoupled cases have a cheap direct reference.

The protocol, computations and independent audit are **separate create-only
files generated by separate processes**. The independent evaluator replays
all 60 slots, verifies source identity/operation counters, recomputes full
residuals from raw vectors and reruns the alternate Newton solver where
supported. Actual CPU/wall observations are retained but are self-observed;
there is no independent physical-time attestation.
