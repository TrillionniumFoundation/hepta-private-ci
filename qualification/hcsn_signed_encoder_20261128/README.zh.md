# 有方向的价格反馈能否改善六层视听文本编码器

在完整 CREMA-D 的 4,984 条训练、1,147 条开发及 1,311 条留出片段上，四个模型共享六层编码器、边界传递、金融价格读出和 BP。差异仅在上一拍的价格或状态是否以及如何改变本拍相对边界漂移。提示词表有 72 个候选。固定一遍为同一顺序的 312 次优化，覆盖全部训练片段。各模型三个初值，汇报留出 16 位演员的结果。

| 漂移反馈 | 一遍 NLL | 一遍 top-1 | 60 秒 NLL | 60 秒 top-1 |
|---|---:|---:|---:|---:|
| 有符号金融反馈 | 3.94498 | 7.679% | 3.62176 | 11.848% |
| 可反号金融增益 | 3.94445 | 7.704% | 3.72269 | 11.238% |
| 非金融状态反馈 | 3.88275 | 7.907% | 3.61168 | 12.103% |
| 去掉漂移反馈 | 4.02151 | 7.551% | 3.70242 | 10.628% |

有符号反馈用上一拍的股权通道把存活群体均值拉回复位距离，并用损失通道推动向吸收边界的漂移。非金融对照用质量加权距离和不应期质量驱动同样的有方向反馈。金融控制与可正可负控制有完全相同的起始预测，初始增益导数一致。实测六层初始增益梯度的最大差为 1.86×10⁻⁹。

同一遍的 paired NLL 差以“有符号模型减对照”计。对去力为 −0.07653（95% 演员 bootstrap 区间 −0.12162 至 −0.03603），对非金融为 +0.06223（+0.04377 至 +0.08250），对可反号为 +0.00053（−0.00123 至 +0.00221）。60 秒的对应差为 −0.08065（−0.12977 至 −0.03358）、+0.01008（−0.05299 至 +0.07764）、−0.10093（−0.20545 至 +0.00326）。全部六项同时占优的预注册判据未通过。区间条件于固定的三个种子，以演员配对重采样，没有作多重比较校正。

原始运行中所有模型均用单线程优化。两个种子后续模型的进程亲和掩码被环境放宽，第三个种子在 60 秒活动墙钟内仅获得 23.5 至 31.3 秒进程 CPU。准时截取的原始数值描述这台机器当时的优化表现。据此注册了逐步检查亲和掩码、轮换同一核上四种方法，并同时记录墙钟和进程 CPU 的复现。

24 个权重均已从磁盘重新构建模型并对开发与留出数组逐元素冷重放。全部 4,247,424 个 FP32 分数逐位一致。另一实现独立用 NumPy FP64 从存档权重重建完整六层前向及全部提示，只用 PyTorch 读权重，标准库 erfc 计算 GELU。独立复算与原分数最大绝对差 1.606×10⁻⁵，最大概率质量偏差 1.746×10⁻⁷。58,992 个 argmax 中 58,991 个相同，去力模型一个样本的前两名原始分差为 1.907×10⁻⁶。各端点结果明细在 independent 目录。

GPU 机制检查经 HeptaRuntime 请求私有 Kaggle T4。原云实例启动后第 82 行的 CUDA 可用性断言失败，回收了原始标准输出和资源。本研究所报告的训练与评分均来自有完整数据的 CPU。四路结果支持可微实现、定向反馈对比和去力消融，未显示金融反馈比非金融反馈具有稳定的分类或负对数似然优势。
