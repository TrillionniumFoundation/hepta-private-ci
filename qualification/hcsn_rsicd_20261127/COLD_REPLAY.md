# Engineering replay of exact short-panel selections

After inspecting the short results, replay the already selected development roster from cached, digest-verified raw files, in fresh processes on one thread. This is a cost and cross-check measurement on previously seen results, not a new independent scientific confirmation. Measure full elapsed wall from before Python interpreter startup to exit. Run 12 s HCSN, CCA and 12/60 s conventional endpoints for the three original seeds. Direct search reconstructs all four registered configurations. Conventional search restarts both paired learning rates and runs the exact sequence of completed dev-checkpoint step counts that were eligible on the original clock; the replay clock can differ, and overshooting original ineligible attempts is not necessary to reconstruct the eligible roster. Retain elapsed for every stage: verifying source files, decoding, fitting common representations, building a physical price table if needed, complete model fit/selection, loading selected weights and cold scoring. Record the final per-query rank arrays versus the immutable original. Original raw network transfer is outside each cached-input replay. This audit measures achieved cold costs on the observed common gallery. A claim of same useful quality against stronger long-run models requires the separate higher-budget comparison.
