# 前向构造后物理 BP 的 2 分钟曲线

三个父种子先按开发集封存了当期状态，再冷测 964 幅遥感图片与对应原作者说明。初始网络是原短期开发选中的宽度 12、岭参数 0.1 的字面双价格编码器。每种子最多 120 累计活跃墙钟秒，种子在同一核上轮转，等待其他种子的时间单列。

三种子均值 R@1 为 1.1238%。相对同一冻结解析初值的配对差为 +0.0346 个百分点，条件于这份图库的 95% 配对区间为 [-0.4668, +0.5014]。各做法共用先前已经检验的图库。本时点的发布覆盖物理网络和其冻结父模型。常规深度对照须等三个种子的相应预算都达到后再独立比较。

归档含 12 个文件。逐个从所有在预算内实际完成的开发候选重选，所有入选权重 SHA 和逐例严格检索指标均匹配。按 manifest.json 顺序连接 2 段、解开 XZ 及 ZIP，可得到全部当期选择、三份完整权重、每个项目的双向排名与资源回执。
