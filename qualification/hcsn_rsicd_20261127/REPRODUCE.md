# Reproduce from original materials

The immutable parent has the neural operators at qualification/hcsn_continuous_20261127/paired_catalog and its companion core directory. Use a working checkout including these sources. Python 3.12, torch 2.8.0+cpu, NumPy 2.3.5, SciPy 1.17.0, scikit-learn 1.8, Pillow and pyarrow 20 executed the reported panels. Point RSICD_RAW at an empty raw data directory and HCSN_CATALOG_DATA at a separate empty working data directory. HCSN_REFERENCE can override the relative paired_catalog location. Use the desired Python executable in PYTHON and pin the process to one available CPU with OPENBLAS_NUM_THREADS, OMP_NUM_THREADS and MKL_NUM_THREADS set to 1.

Run python fetch.py with the raw directory as its only argument. Run python prepare.py and bash run.sh. The latter runs all budgets including the extended six total hours of neural optimization across three seeds. To obtain the 12/60 s panel only, run study.py fit short METHOD SEED for every listed family and seed, then study.py seal short and study.py confirm short. The fixed algorithms and source data are reproducible. Wall-based candidate eligibility can vary between hosts. For exact replay of all original eligible candidates, populate the reported short_evidence archive and run cold_replay.py with RSICD_ORIGINAL_SHORT pointing at original short receipts including cold_ranks.npz. Subsequent verification independently reconstructs rankings from the original selectors and candidate states. Temporary source data and intermediate model tensors can require 1 GiB or more.

For the conditional warm-initialization follow-up, run warm.py fit METHOD SEED for each of warm, marginal and all three seeds. Then execute warm.py seal and warm.py confirm. The core width and both derivative paths remain the same across these two methods. For a category audit, unpack the verified public annotation classes.rar into RSICD_RAW/classes with a RAR reader, yielding 31 official class text files. Run official_categories.py after confirming the original short panel.

The chunked inference evidence does not distribute source photographs. To verify an existing evidence package before refitting, run python verify.py DIRECTORY. Concatenate the sorted partNNN.bin files. For delivery_encoding=xz decompress the XZ stream to recover the original ZIP. For identity or an absent encoding the concatenation is already the ZIP. The package manifest cryptographically identifies the ZIP and each contained member. The JSON map in the archive records the unique selected state for each method, seed and budget.
