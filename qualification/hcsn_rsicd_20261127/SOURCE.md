# Caption source check before fitting

The Arrow repack adds or varies wording. Every one of the 10,921 image names belongs to the same official split and has at least one normalized caption in common with the authors' file. Only 2,010 entire caption sets are identical. Use only the authors' original captions in constructing pairs; receive pixels from the byte-pinned Arrow files. This source correction was made after preprocessing initially stopped on the first image and before any model fit or ranking. The authors' revision is fc33b4555e4baa4d2f05ff0449479c89da2eeac2. Download with the immutable links and validate fingerprints in prepare.py. Manually prototyped HTTP downloads used 29.94 s in parallel for the three Arrow shards; prior network exploration is not part of that clock.
