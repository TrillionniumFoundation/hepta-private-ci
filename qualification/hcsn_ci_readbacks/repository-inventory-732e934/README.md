# 初始全仓审计快照

默认分支固定在 732e934ba496d90fbe042b8d41d479ef901643e5。初审递归读取 9,843 个 Git 树条目，逐个读取并核对 8,665 个跟踪文件的 Git blob，共 97,364,825 字节。归档保留原审计报告、逐文件内容分类和哈希、当时的 7,925 个分支头，以及按 HCSN 标题检索到的 535 个 PR。分支头清单是分页枚举的时间切片，逐文件扫描的对象是这个固定默认分支。后续科学和原生资格分别绑定各自的研究提交。

下载并解开 inventory.zip 后可以打开 HTML 查看原审计及其附录。在此目录运行 `python verify.py` 可复核整个归档、四个成员的哈希、路径唯一性和计数。另有本地仓库包含该固定提交的所有对象时，运行 `python verify.py --repo /path/to/checkout` 会从 Git 对象数据库重新读取并计算每个原文件的哈希。
