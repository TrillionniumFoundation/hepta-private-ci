## 复核

先检出上列 c12 固定源。e327 与 c12 在这些输入和生产者凭据上的 Git blob 相同。下列命令校验当前目录的字节、来源树、原始故障和逐项记录。

```sh
python3 verify_ownership42.py --repo /path/to/hepta-private-ci
```

如需逐项重新运行 rustfmt，使用官方 x86_64-unknown-linux-gnu 发行版（对应 SHA-256 记录于 ownership42.json）。验证程序拒绝工具版本或二进制摘要不符的输入。

```sh
python3 verify_ownership42.py --repo /path/to/hepta-private-ci \
  --rustfmt 1.88.0=/path/to/1.88.0/bin/rustfmt \
  --rustfmt 1.95.0=/path/to/1.95.0/bin/rustfmt \
  --rustfmt 1.96.0=/path/to/1.96.0/bin/rustfmt \
  --rustfmt nightly-2026-07-21=/path/to/nightly-2026-07-21/bin/rustfmt
```

原始 1.95、1.88 和 nightly 发行物分别按 Rust 官方通道清单的 xz_sha256 检查。复算使用各自的 rustfmt、同版 rustc 共享库以及源树的原 rustfmt 配置。为只检查绑定文件，显式禁用子模块递归。这是对绑定源码的独立检查，各档案原先的整 crate 格式门与测试门保留各自的执行范围。
