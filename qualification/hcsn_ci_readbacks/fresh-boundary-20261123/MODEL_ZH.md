# 从内生违约边界到连续放电算子

He 和 Xiong 的出发点是资产状态、连续产生的净收益，以及持有人何时停止继续承担展期损失。原文式（11）对权益价值求解，债务滚动收益进入方程的源项。在违约点，有限责任给出权益价值为零，最优停止给出一阶导数为零。作者用拉普拉斯变换求得权益和内生边界。把期限内首次触及的概率叫作“put 通道”是神经模型的设计选择，原文并未把违约概率和普通看跌期权价格等同。[He 与 Xiong，Journal of Finance 2012，第 400–401 页和附录 A](https://www.princeton.edu/~wxiong/papers/rollover.pdf)

| 金融模型中的对象 | Hepta 中有可检验含义的对应物 |
| --- | --- |
| 资产状态和展期净收益 | 连续状态 $x$、维持激活的任务收益与代价，二者共同决定是否继续积累信息 |
| 权益值和内生违约边界 | 继续运行的价值 $U(x)$ 与由停止或干预收益决定的边界 $b$ |
| 首次违约及其概率 | $\tau_b=\inf\{t:X_t\leq b\}$，给定观察窗内的首触概率或折现事件强度 |
| 违约后的处置 | 放电、不应期和重置核，需要神经模型另外规定 |
| 信用损失与融资反馈 | 可选择如何把一次放电映射为下层输入。信号的强度、符号和学习目标需在任务上验证 |

复发放电使边界条件发生了实质变化。若放电要付 $k$，在固定不应期 $d$ 后从 $x_r$ 重新开始，贴合条件是 $U(b)=-k+e^{-\rho d}U(x_r)$。若右侧不随当前状态变化，平滑贴合给出 $U'(b)=0$。只有真正终止且无终值时才直接得到原金融模型的零边界值。所以恢复力、首触风险、重置三者各有不同的物理或任务含义。金融权益的绝对数值和货币量纲并不能直接指定膜电流。

在平稳、常系数、固定物理参数的单元里，$b$ 对同一单元的不同输入状态可取同一个数。单传 $b$ 不能区分这些状态。可传入下一层的是当下状态与阈值的距离 $x-b$、固定时窗内的连续首触质量、事件通量，或按任务重新计算的边界。对连续状态、首触核和内生根，若根简单且活跃分支稳定，可通过 $F(b,\theta)=0$ 得到 $\partial_\theta b=-F_\theta/F_b$。在分支切换、硬 argmax 决策、精确事件时刻或重复根处，仍要分别指定训练目标和梯度。没有一般结论能从一次平滑贴合直接推出任意深度、多边界、反复重置网络全局可微。

传统 SNN 也可以使用梯度训练。代理梯度为硬阈值指定平滑的反向导数，EventProp 在满足事件条件的 LIF 网络上用跳跃条件传播精确梯度。Hepta 的可检验差异在于它能传递连续首触概率、保留不确定性，并让任务代价参与确定边界。这些性质是否带来更好的效用、稀疏执行或训练时间，需要在相同数据、功耗或时间预算内测量。[代理梯度](https://ieeexplore.ieee.org/abstract/document/8891809/) · [EventProp 原论文](https://www.nature.com/articles/s41598-021-91786-z)

有一个可直接编辑的内部参数。若外部明确给定目标边界，放电成本在边界方程中线性出现，移项即可求出；再改连接偏置，可精确补偿一个指定初态上的受方输入。在同一两细胞实验上，直接编辑和 BP 均通过 10⁻⁷ 的目标与保持门槛，含三个额外初态验证的五次整轮中位数分别为 0.10950 和 0.20087 秒。额外初态的连续输出最大变动 0.004372。这限定了结论需要的监督信息与保持范围。更广泛的训练研究还要回答从真实任务反馈识别目标边界的成本。[实验前协议、全部计时与独立核对](../qvi-conditional-edit-20261123/README_ZH.md)
