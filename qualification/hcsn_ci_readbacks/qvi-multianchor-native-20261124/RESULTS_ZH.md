# QVI 多 anchor 原生权重编辑：结果与边界

## 完成内容

在原公开两神经元科学 fixture 上，完成可执行的 Rust 条件解析编辑、带范数限制的多 anchor 判定、直接参数编译、重开验证和失败回滚。新增原图已有二维投影的编辑支持后，两个 anchor 的 49 项输出可同时保持在约 5e-16；原两坐标常数 bias 的不可达结论仍成立。

所有严格未来初态保持门仍未通过。本轮的工程成果是可执行的 edit/no-edit 接口和明确的容量证据，没有把局部解或较小误差当成完整模型能力闭合。

验证用 257 个区间 [0.6,1.4] 的等分中点及 64 个区间 [1.4,2.4] 的等分中点；321 个连续值初态均未用于求参。它们是未见初态有限验证，不是新任务来源，也不等同每个实数初态上的证明。

同支持条件 BP 与原生法使用同一解析成本反演、同一矩阵、同一平方误差和 box。联合 BP 还优化成本；其损失是边界误差平方加 fit-anchor 接收初态均方误差，有限优化可能牺牲目标边界。BP 使用固定 L-BFGS-B 上限，无超参搜索。

## 严格不可行证据与适用范围

固定解析目标后，接收初态对三个现有读出参数是线性的。Rust 返回的保守 dual 下界经 Fraction 对全部输入浮点数的精确有理值独立验证：3/5/9 anchor 的接收初态最大误差分别至少约 0.0006275067、0.0011981504、0.0011159896（原 0.1 box）。

补充的事后静态代数未使用任何未见初态、未更新候选、未做优化：

- 3 anchor 的唯一无界解需要投影改动约 [0.5781753,1.2514919]，严格超出原 box。
- 5 anchor 的精确左零空间证书给出无界接收初态残差下界 0.0005249472672624197。
- 9 anchor 的精确左零空间证书给出无界下界 0.00015596932166664045。

后两项说明即便解除幅度 box，这三个系数也不能精确匹配对应记录矩阵的全部目标。它们证明的是记录 FP64 矩阵的线性接收初态子问题，**不是 49 维非线性输出的全局不可行定理，也不是整个 Hepta Neuron 的容量上限**。完整 49 输出另由原冻结 Torch 算子实际验收。

## 浮点写回与回滚

首次 attempt001 在 checkpoint 重开比较时失败：原 Python fixture 的 tuple 经 JSON 成为 list，严格对象比较失败。保留源码、日志、输入及 run receipt；仅统一 JSON 容器类型后运行 attempt002，没有改数值或科学协议。

attempt002 进一步发现原始 base+delta 的 F64 合成会把边缘 0.1 变成 0.10000000000000003。原 harness 的 1e-15 容差不能代替协议原 box，因此 attempt002 不是最终参数资格。其原始结果完整保留。

新增 Rust compiler 向父权重方向移动必要的 representable ULP，并用向外界验证真实参数差不超过原 0.1；零编辑保留包括负零在内的原位模式。修正说明在重放前提交 c4f1630cb856d0e6d23294a39cb2153fbc1e9ce0。

attempt003 不重新求参：只改 11 个实际数值发生浮点边界修正的候选，重放其 3,585 个 fit/未见 forward panel；19 个完全相同候选复用已绑定摘要的原验收 receipt。120 个重开参数差由 Fraction 精确验证全部在原 box 内。

最终 30 条事务中，8 条在隔离 checkpoint store 实际写入、重开后因未见保持失败回滚，22 条在采纳前拒绝，0 条提交。全部最终 live checkpoint SHA-256 与原始一致。拒绝产生的诊断候选仍保留，未改成 KEEP 来掩盖失败。

## 资源与独立复核

主数值作业 attempt002 的内部墙钟 44.8537 秒，进程峰值 RSS 274,460,672 字节，CPU 单线程。包含启动的 wrapper 墙钟 46.9201 秒。修正重放没有优化器调用，wrapper 墙钟 19.0241 秒；首次失败 wrapper 4.7208 秒，三次进程累计约 70.6649 秒，不含审阅/构建。

同支持条件 BP 的三次 solver 中位数比较中，原生/BP 比值在 1/2/3/5/9 anchor 上约 1.345/1.224/0.684/0.757/0.790。简单欠定情形中原生进程开销更高；完整耗时由 49 输出验证主导，不声称获得同等比例的端到端加速。原生求参没有梯度调用；主比较所有 BP warm+timed 共 684 次梯度求值，均低于固定预算，没有 GPU 或远端训练。

独立 stdlib 方程验证 9,630 个 panel，接收初态最大差 2.22e-16，接收末端不应期概率最大差 6.66e-16；所有五个向外数值证书通过精确有理复核，box-LS KKT 最大违反 1.65e-17。独立标量复核没有重新推导全部 49 项，不能把这两个标量的精度泛称 49 项独立验证。

Rust planner 五项、compiler 三项数值测试通过；作者 Rust 文件已 rustfmt。该资格属于 standalone 科学子程序，不是整个 Cargo workspace/HeptaRuntime 产品 CI 通过。没有变更依赖 manifest、Cargo/Bazel 锁、原 CI 门或并行 HCSN/HIA head。

## 对实际 WSP 的意义

本轮闭合了可执行条件编辑、有限多 anchor 判定、明确不可达返回、严格浮点参数编译和隔离回滚这些工程环节。现有三个读出系数的不足由明确矩阵证据定位，可以在继续训练前拒绝此类不可能的精确保持要求。

尚未闭合的仍是全局保持、真实任务或交易净收益、由外部收益自动推出目标边界、AI 自主电路定位以及 HeptaRuntime 产品集成。当前结果支持受限数学子程序，不能声称已替代大模型训练或实现了通用 REA。
