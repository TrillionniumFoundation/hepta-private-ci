# Editing both hidden layers of a frozen speech classifier

This registration extends the public 7dcce236 AudioMNIST study. Its physical model was trained on real FSDD waveforms; the only edited matrix in the original experiment was the second 12×12 matrix. Both the acoustic-input matrix (16×12) and the receiver matrix (12×12) are editable here. The ten-class head, normalization, temporal recurrence and the two nonlinearity banks are fixed within each parent. Full network evaluation after every write propagates sender changes into the receiver. We will perform all six parent experiments (271,577,911; literal / smooth).

**Data and confirmation.** Reuse the published 2,100-example FSDD parent split (actual post-deduplication size from data.json), old calibration/development/test splits, four AudioMNIST adaptation speakers and four development speakers, repetitions 0–11. Preserve exact physical parents. For the matched smooth control replace the four tabulated scalar fields with smooth saturation functions matched in value and first derivative at the operating point; preserve interpolation grid, recurrence, 16/12/12 widths, initialization, parent data, head fitting and application costs. Parent results on FSDD will document the changed baseline. All editing uses old held-out-from-parent calibration anchors and the new calibration labels, never old or new test labels. The 52 AudioMNIST speakers outside the eight designated fit/development speakers are split by alternating sorted speaker ID into A, B (26 each). Evaluate A only on previously unused repetitions 12–15 (1,040 recordings before exact PCM dedup), and B on repetitions 16–19 (1,040 recordings). These are fresh waveform instances. Speaker IDs occurred in earlier work; do not call the population a new source. FSDD old test uses existing held-out repetitions 0–4; report known-split retention. PCM hash dedup against existing calibration, dev and retained test records. Neither A nor B will guide any candidate fitting; no success threshold changes after A. B provides a separately sealed replication of exactly the same choices.

**Methods.** Use a shared per-digit balanced subset of 120 new and 120 old calibration utterances (fixed RNG 17319) for all active methods. All select on the complete old and new development splits. Keep old score logits as the distillation target and one-hot targets on new labels, giving domains equal weight. (a) KEEP. (b) Forward-only damped least squares on centered, finite output responses to joint hidden-layer perturbations. Use 12 directions per construction round, six input-matrix and six receiver-matrix directions, streamed through both layers. Old/new input covariance can select directions without labels. Solve a positive ridge system, evaluate actual network candidates at three trust fractions .25/.5/1, and relinearize at the best support-loss point. (c) Receiver-only forward secants, same 12 directions. (d) Same-position full Adam on both matrices with exact loss BP. (e) Same-position rank-3 LoRA on each matrix trained by BP; evaluate merged weights. (f) Independently rerun two-layer editor after rotating every new calibration label by +1 mod 10. (g) Flattened acoustic ridge correction on frozen parent logits; an external additive baseline, with the same support observations, using three ridge strengths. Record full physical ranks, masks and changes. All adaptive methods may select KEEP. Use three BP rates .003/.015/.05 round-robin, joint loss, batch size 48 balanced, a validation point every four updates in each stream (plus first step). Active-arm budgets 3,15,60 single-thread process CPU seconds, counting development selection; seize the latest completed candidate before each budget and charge any overshoot separately. The early/medium/late models are nested within each one training trajectory. All time-to-quality claims charge the complete corresponding validation search at its rung, both-stage cold prediction, common waveform preparation and parent construction; report both cold and reusable-parent clocks and CPU vs elapsed where measurable. Quality targets are evaluated on the actual independent runs; late-rung accuracy need not increase.

**Frozen decision.** At each rung select the highest new development accuracy among candidates with old degradation <=2 percentage points and new improvement >=2 points vs the corresponding unedited parent. Break ties by old accuracy, then smaller mean squared residual on new dev. KEEP otherwise. Strong success requires all three literal parents on both external speaker panels to gain at least two new points over KEEP with at most two points loss on the retained old test, plus aggregate lower speaker-paired 95% interval vs KEEP >0 on each panel. For a time advantage require this same gate for exact BP as well, at least 20% lower median matched total time for the editor, and external quality noninferiority to BP with margin two points on both panels (paired speaker intervals). To support a special physical advantage require positive lower paired bound vs smooth two-layer editor on external accuracy and shared retention success; differences in unedited parents will be disclosed. Strong internal-specific attribution requires the outcome also beat KEEP and assess both receiver-only and acoustic ridge. Report all arms, seeds, full accuracy, logits and ranks, tail slopes/validation choices and cold clocks. Run an independent cold scorer after freezing candidates and source hashes. A negative result, missed time target or missing evidence leaves the corresponding original blocker open.
