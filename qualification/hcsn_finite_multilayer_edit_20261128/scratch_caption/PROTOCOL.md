# No-pretraining causal image captioning with local forward fits at every writable site

The parent-editing trial retains 11.1 million pretrained weights apart from two selected sites. This independent trial instead starts every model from random weights, consumes decoded RGB and human-written word sequences, and fits every writable matrix without a task-loss backward pass in the primary arm. It uses the same original Flickr8k benchmark as the separate transfer study; this registration and all selection rules precede opening any held-out Flickr caption losses for either study. The two experiments share image identities and cannot count as independent replications. COCO 2017 validation supplies a separately sourced external image/caption panel.

## Data and reporting

Process all images of the original Flickr8k train, development and test lists, retaining up to five original human captions per image. Split by image and deduplicate native RGB and resized pixel hashes across splits. Use only training captions to construct up to 4,092 most frequent lexical tokens plus four fixed control tokens. Lowercase alphanumerics; preserve sentence order. Predict up to sixteen words, and EOS when the sentence fits. Record actual vocabulary size and all OOV/token counts. Select up to 160 source-development images for candidate selection by fixed filename SHA order (all of their captions); keep all source test images for the cold panel. For external COCO, take the first 768 eligible official validation image IDs in fixed SHA order after deduplication, with up to five human captions. Capture official archive hashes and caption/image counts. Grounding checks cyclically shift the source photographs among different images while leaving all captions fixed. Confidence intervals resample whole images, keeping their captions and tokens together. Include a predeclared subset of target lexical tokens equal to individual non-stopword tokens in COCO's official object-category names. Report its exact support and an interval, and exclude EOS and UNK from that specific analysis.

## Shared causal model

Three temporal layers, each containing h=512 populations. Causal inputs are the image's raw 8×8 RGB patches projected by a trainable affine map, followed by the prior caption tokens through a trainable input table. The true image representation is also available as a persistent fixed spatial mean context at each text step. A fixed positional encoding is shared by all mechanisms. Project each successive layer with one trainable affine map from its input to 512 drives. Each HCSN stage emits the log boundary, equity, debt-loss, and finite-horizon crossing statistic; carry the physical model's causal price feedback and history. The final h×4 features predict the next token via one trainable affine readout plus a fixed source unigram prior. Record all tensor dimensions and counts. Use random seeds 173,311,619. The matched smooth network uses the same width, interpolation, memory and trainable sizes. The attention comparator is a three-layer causal Transformer, width 512, with an independent output head, raw-image patch encoder, same context/positions, pretrained-weight count zero, and explicit parameter count. Its architecture may have a modest parameter-count difference.

## Training and selection

The primary forward projector determines the visual input matrix by a regularized local solve from true image patches to a randomized joint patch/observed-caption target. Determine input token vectors by sufficient statistics of one-hot prior tokens and their true next-word targets. For each successive physical layer use randomized projections of its incoming signal and observed next-word labels as a supervised local preactivation target, in the sense of Forward Projection Eqs. 1–2 (O'Shea et al., 2026). Fit each affine map using ridge. A boundary-aware variant forward-inverts the attainable log threshold and subtracts the causal price feedback along target trajectories before solving. At inference the network receives only pixels and prefixes. Fit the final word readout by ridge to centered, class-frequency-scaled one-hot residuals, with fixed prior and a one-dimensional calibration selected on development. All active parameter tensors, including image and token input maps, layer weights and large output matrix, must change from their own initial states for an all-site update claim. Report tensor-level changes and eligible token row coverage. This algorithm uses supervision and multiple layerwise scans. No layer may consume future words, labels, or a pretrained feature extractor at test time.

Compare full exact end-to-end AdamW BP on identical literal and smooth architectures, frozen-random features with only the readout fitted, the causal Transformer trained by full BP, and a training-only backoff bigram plus unigram language model. Include unchanged random checkpoints at each budget. Evaluate nested caps of 60, 300, and 1,200 single-core process-CPU seconds per arm, counting preprocessing of features within a run, local fits, gradient steps, validation and calibration. Include source data acquisition and measured held-out evaluation in cold matched-time. Train-time subset prefixes for forward fits contain up to 32, 128, 512, 2,048 and the full number of training images in stable training-only order; each includes all available captions. Process fitting in bounded batches, discard a candidate not completed by a rung. Choose minimum dev token NLL, then earlier measured clock. All budgets and controls share the image/caption labelling and causal targets. Fingerprint sources, all learned states and selections before opening held-out outcomes. Save host and runtime identity, step counts, data visits, training/NLP mask statistics, wall/CPU and parameter footprints.

## Gates

1. A trained local model must improve both full-token and known-lexical NLL by at least 0.10 nats versus unigram on Flickr and at least 0.05 on COCO for every seed, with positive paired image 95% lower bounds on gains. Its Flickr NLL must beat frozen random features and bigram with positive paired bounds. Report each component separately so that a language-only gain is visible.
2. To establish visual conditioning, the matched image must improve NLL over a fixed derangement by at least 0.005 nats/token on *both* corpora for each seed, with positive paired bounds. Include image-wise caption means, held-out top-1/top-5 next-word accuracy and category-word results. Publish deterministic greedy captions on fixed initial source and external test image IDs as inspectable generation, separately from teacher-forced quality.
3. For same-quality speed, both direct training and matched full BP must pass gates 1–2. Direct training must be noninferior to BP within 0.03 nats on both corpora (paired upper bounds) and use at least 20% less median measured end-to-end wall time at the first passing rung. Report warm compute and acquisition-including ratios and comparisons with the Transformer. If one method fails to reach the common quality target, no time-to-quality speedup is estimable. If smooth ties or exceeds the literal law, no special financial-law advantage follows.

The 32×32 images, finite vocabulary, three conditional sources and finite single-core budgets limit conclusions. This is a direct check on causal raw image/text modeling and full local training, distinct from pretrained editing, all-modality foundation pretraining and billion-scale evaluation.
