# Frozen experiment for cross-domain raw image and text parameter editing

This is an acquisition using the Flickr8k original image, token and official split lists. A source-trained next-word model reads a 32×32 RGB image and its genuine human caption prefix. Its source is RSICD, its fixed vocabulary has 850 entries. All six hidden temporal layers, width 416 and 16 populations are retained. One predictor contains 11,101,984 coefficients. Physical and value/tangent-matched smooth models use the same width and sites. The edit sites are (i) the *one shared* 850×416 table used for inputs and outputs and (ii) the 416×80 physical feature projection inside the final temporal layer. There is no full-network fit under this protocol.

## Population and masking

Use author train/development/test image splits and all original unique RGB images retained by a SHA256 duplicate check in train, validation, test order. One human sentence per image is chosen by smallest SHA256 of filename plus normalized caption. Load images as RGB, resize to 32×32 with bilinear interpolation, report all token frequencies, lexical out-of-vocabulary fraction, EOS and truncation, and publish image identities, source ZIP CRCs and input hashes. The source training vocabulary, maximum 16 words and next-token masking stay fixed. Use deterministic SHA ordering of image names to retain at most 1,024 train images, 192 dev images and all valid test images. Original RSICD old-domain retention uses its fixed 964-image held-out set. For old train replay use the first 512 SHA-ordered train examples, old validation the original source-selected 128 images. Record any image digest overlap, excluding matching pairs. Report cold means token-weighted and image-weighted. Pair confidence intervals resample images (10,000 draws), never individual token positions.

## Parent identity

Three independent source initialization seeds 109, 271 and 463 per architecture are intended. For each architecture and seed, freeze the lowest original-source dev-NLL checkpoint with original CPU acquisition trace at most 300 s, using only its pre-existing original time/selection records. Require checksum agreement with the original record. Where an existing parent is absent, resume/reproduce the original source-only fit on the original data, seed, law, architecture and optimizer. Publish distinct seed results and full measured parent/setup/image download, preparation and inference costs. Do not pool partial seeds with full results. Comparisons across image records conditional on fitted parents cannot establish population uncertainty over architectures.

## Updates and control arms

KEEP reproduces the unchanged model. TIED outputs a regularized normal-equation update of the real shared word table built from final features, token prediction residuals and old activations. JOINT additionally constructs an update of the final physical feature projection from the same residual projected through the frozen-at-step readout, followed by a regularized local input-feature solve. Both proposal sites update actual trainable coefficients for the true next full forward. JOINT-FLOW uses the two site proposals as a small basis, measures the end-to-end output response to finite parameter displacements, solves a damped two-dimensional cross-entropy quadratic, and re-evaluates true predictions on support before retaining a step. Arm BP applies reverse-mode Adam to both exact sites. LORA applies reverse-mode Adam to rank-8 factor pairs at both exact sites, with shared input/output word weights. UNIGRAM changes only an extra vocabulary offset fitted from new-support counts. WRONG repeats JOINT-FLOW with mismatched real target sentences. These genuinely local edits are initialized from a BP-trained source parent. None constitute BP-free pretraining.

## Budgets, selection and end points

Run nested 15, 60 and 240 single-core process-CPU second ceilings per arm, rotating order by seed and architecture. Count fitting, feature collection, solves and dev evaluation. Record wall and CPU independently. A candidate may be selected only after its dev evaluation finishes within budget. Always allow KEEP. Use the lowest new dev token NLL among visited candidates whose old dev NLL increases by at most 0.03 nats. Exact ties favor the earliest visited candidate. Fingerprint all selected weights, protocol, code, parents and data before opening old and new cold test outcomes. Input preparation and frozen parent creation are separately recorded and charged in end-to-end comparisons.

Multiplicative speed claims require the compound gate on all three literal parents. New test NLL must improve by at least 0.05 nats per token, known-word NLL (target id≥4) must improve by at least 0.03, old-domain NLL must increase by no more than 0.03, and both paired new improvement lower CI bounds must be positive. New gain also must exceed the UNIGRAM offset control, and JOINT-FLOW must be noninferior to both full and low-rank same-site BP within 0.02 nats across paired image CIs. Compare first eligible measured total time including acquisition, preparation, actual fit/development and cold scoring, with a ≥20% reduction to claim an actual time advantage. Report separately end-to-end with and without already-owned parent and identical common data acquisition. If BP does not meet the quality gate, no timing speedup is estimable. Test the real image contribution by cyclically shifting pixels among distinct images with captions unchanged. Require shifted NLL minus matched NLL ≥0.01 including a positive paired CI to claim image-conditioned improvement. Report full verbatim failures including an unchanged model chosen by dev. Neither the 850-token source vocabulary nor a single image size permits a claim about an all-modality foundation model.
