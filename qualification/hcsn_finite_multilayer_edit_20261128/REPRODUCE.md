# Reproduce the two-layer speech transfer experiments

The original source is the parent directory hcsn_independent_audiomnist_20261127 at 7dcce23693ad3d8a06283c41acd6715fcdee3990. Follow its REPRODUCE.md for the FSDD/AudioMNIST source revisions, parent waveform panels and physical law table. Only NumPy and SciPy are required for the study here. Set OPENBLAS_NUM_THREADS, OMP_NUM_THREADS and MKL_NUM_THREADS to 1. The 7dcce236 model evidence contains parent_271.npz, parent_577.npz and parent_911.npz; generate these with the original fit procedure or restore the parent's evidence. The new program refits the same parent and checks numerical equality prior to using the restored exact weights.

1. Create a readable Git clone or bare object store for AudioMNIST at 630d7dab4c040882834de6fa21baf9a60372accd, with origin pointing to soerenab/AudioMNIST. Run fresh_data.py GIT_DIR FIT_DATA/sources.tsv FRESH. It fetches only registered waveform blobs, validates Git identities, deduplicates PCM, and extracts ordered features.
2. Download the official TensorFlow Speech Commands V2 restricted test archive named in SPEECH_COMMANDS_SOURCE.json (SHA-256 cc2a00c1147c2254e9be3fa0f779d8c17421dc349b86366567a8edfa9acd51df). Run third_corpus.py ARCHIVE FIT_DATA/sources.tsv FRESH/waveforms.tsv FRESH. Source test labels are restored from the explicitly encoded category in each filename; the network has a ten-digit vocabulary, and this is a subset of the 12-class task.
3. For each seed 271,577,911 and law literal,smooth run fit_model.py --data FIT_DATA --archive PARENT_MODELS --law LAW.npz --work MODELS --seed SEED --arch LAWNAME. Run sensitivity.py --data FIT_DATA --law LAW.npz --models MODELS --seed SEED --arch LAWNAME after its base parent is available. Fit selection uses process CPU timers. A machine or library which runs more candidate updates at the same budget can produce different weights; cold replay of stored weights is the fixed scientific observation.
4. Freeze all selected weights, every search trace, code and input SHA before cold prediction by invoking seal.py MODELS SOURCE_DIR FIT_DATA LAW.npz FRESH SEAL.json. A second independent interpolation implementation scores them with confirm.py MODELS FIT_DATA LAW.npz FRESH SEAL.json COLD. score.py MODELS FIT_DATA FRESH COLD RESULTS computes all paired speaker effects and quality gates.
5. The archive restoration script and archive manifest preserve the fitted source, selected models, test inputs and cold outputs. A separate score-only bundle allows comparison without refitting. The data preparation clock excludes network transfer and covers local waveform reading, feature extraction and writing. The full cold clock adds parent fitting, fit-example setup, retained selection time and cold prediction. A reconstruction clock measures the new full program on the current machine using all restored files. It differs from the sum of original independently measured components if OS load or hardware differs.

The Fisher/Gauss–Newton update consumes the external target residual and an explicit end-to-end forward response matrix. It uses local derivatives of the entire network. The finite-answer secant method uses output differences under perturbed weights. Neither method claims to infer useful hidden weights from an endpoint without downstream information.
