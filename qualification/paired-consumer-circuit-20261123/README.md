# Subsequent local Circuit execution

The participant-owner commands and two signed statements use the same interface as the [single-Cell study](../paired-consumer-use-20261123/README.md). A Circuit enrollment uses its own complete request and selected Circuit manifest. The owner opens the protected admission and locally evaluates the frozen pair before producing the subsequent request statement.

The registered profile `hepta-local-routed-circuit-v1` accepts a new visible task. Its frozen router extracts prompt features and chooses a registered graph. `LocalCells` loads the original Cell manifests and tensor files. On a connected graph it passes the first answer as a tool message to the second Cell. The second generation supplies the delivered bytes. For readback the owner reruns the route selection, reconstructs the visible input for each hop, reopens each slot's own tokenizer, decodes its actual output IDs, and links the final bytes to B's original operation and outcome. The research study records local execution and B's response. [Circuit forward and readback](../../scripts/cell_experiments/online_v4/circuit_bundle.py) · [Subsequent-use consumer](../../scripts/cell_experiments/paired_consumer_run.py)

A subsequent task must be fresh against the registered selection/retention tasks, both routers' training inputs and the Cell exposure records. For a normal trained Cell, retain its original `paired_source_exposure` catalogue. The archived synthetic adapter format also has an original single-SGD-step `TRAINING.json`. Before the new paired freeze, the fixture binds the canonical hash of each original record by Cell ID in the bundle's `consumer_cell_training_receipts`. The owner verifies the file, its manifest and its input IDs. For this fixture the source Cell and router trained on `train`, and the reader trained separately on `1`. Counting only router exposures would miss the reader's training input. The registered historical panel also includes `keep` and `later`. Foundation-model pretraining exposures are outside these source records. [Training input readback](../../scripts/cell_experiments/paired_consumer_circuit.py)

The existing enrolled source-training command on #7029 calls `coding_sft.verify_model(parent, root)` and fits a coding model. A human Circuit run needs an original enrolled source completion, retention result and participant grant over that same Circuit. A prior grant for an individual Cell has a different candidate digest. [Source training](../../scripts/cell_experiments/paired_source_train.py) · [Enrolled people binding](../../scripts/cell_experiments/paired_people.py)

The engineering fixture fits the two actual local LoRA adapters and routes a later input through the original frozen graph. Four known inputs are rejected before generation; changes to the router decision, relay, output tokens or slot digest fail readback. Both person identities and the source delivery are explicitly fictional. [Fixture and controls](../../scripts/cell_experiments/test_paired_consumer_circuit.py)

The independent verifier reloads the original tensor bytes and recomputes each greedy output for the archived small GPT-2 model with NumPy. It first checks the zero residual-block weights which permit the reduced calculation, then applies token and position embeddings, final layer normalization, the language-model head and the saved LoRA matrices. It also checks original inputs, fitted router decisions, the two-step message sequence, installed model artifacts, the original admission and the fictional statement binding. Run `PYTHONPATH=scripts python qualification/paired-consumer-circuit-20261123/verify.py ARCHIVE.zip` from the repository root.

## Hosted result

The registered new input `train later` had initial token IDs `[4, 5]`. The frozen router selected the connected graph. The source generated token `7` (UTF-8 `1`). The reader received `[4, 5, 0, 0, 0, 7]`, including the tool-observation serialization and the source's exact answer. Its actual output was also token `7`. The NumPy readback reproduced all ten primitive generations across the original two-arm selection and this subsequent use. The engineering participant fixture reported acceptance. The run records zero live participants and zero payments.
