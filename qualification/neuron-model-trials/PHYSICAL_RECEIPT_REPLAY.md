# Offline replay of archived physical Laya smoke (diagnostic only)

`run-38095795540/` contains six small JSON receipts plus a manifest for the
three real CPU model forwards from GitHub Actions run
[38095795540](https://github.com/TrillionniumFoundation/hepta-private-ci/actions/runs/38095795540).
The full weights are **not** retained in Git. Running this verifier does **not**
download weights, execute a model, or issue a qualification or promotion grant.

From the repository root:

```bash
python3 scripts/hepta_neuron_physical_receipt_verify.py \
  --directory "$(pwd)/qualification/neuron-model-trials/physical-smoke-receipts/run-38095795540" \
  --catalog qualification/neuron-model-trials/upstream-weights.lock.json \
  --expected-run-id 38095795540 \
  --expected-source-sha 5b542e100368f2e1aefeba6de7a156e19af27282 \
  --expected-manifest-sha256 93665176c9f42d7489ea4509217aa58d452a87ee33c5051066e027122f20448e \
  --output /absolute/new/diagnostic-receipt-replay.json
```

An operator who has independently retained the **raw** SHA-256 of the original
`manifest.json` can also supply `--expected-manifest-sha256 HEX` to detect a
later replacement of the manifest. **The manifest's self-reported GitHub Actions
artifact SHA is not an independently authenticated signature.** The verifier
checks stored file sizes, raw SHA-256 bytes, pinned upstream weights/revision,
SDK identity, matched model identity/parameter counts, denied effect flags,
and single synthetic observation shape. This is only self-consistency and
cannot prove the statements were generated by a trusted host.

The test workflow replays these checked-in diagnostic receipts and fails closed
on malformed or swapped files. It intentionally does **not** label single
synthetic CPU latencies as comparable p95/p99 or claim task efficacy. Next
qualification requires approved real Hepta data, an independent evaluator,
separately elapsed future windows, NDU gains, real worker/Checkpoint roundtrip,
rollback/fence and an independently signed target-host measurement bundle.
