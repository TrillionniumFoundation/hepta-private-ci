# Two-host relay of one frozen Circuit

Use the authored subsequent task and complete locally fitted Circuit from #7042. Source bytes, selected bundle and task are pinned before dispatch in `run.py`. The historical outputs are used only after the two jobs complete. No user records or privately operated hardware participate.

1. An Ubuntu 24.04 GitHub-hosted job recomputes the frozen route, extracts only the source slot's tensor inventory, and cold-generates the first answer. It publishes the raw UTF-8 bytes and an envelope as a same-run GitHub artifact. The envelope binds the workflow run/attempt/commit, task, operation, graph, router, both slot manifests, source observation and actual answer.
2. A separate Ubuntu 22.04 hosted job is allowed to start after the source job. It downloads the exact artifact ID received from the dependency, checks the separately transferred envelope digest, original frozen identities, different boot identities and answer size/digest. Two separate processes cold-load the same reader in fixed order. The connected arm receives the source output through the original tool-message serializer. The removed-edge arm receives the original task only. The two conditions share an identical first-slot generation.
3. Reopen both jobs' original observations and the historical single-host reference after generation. Compare the rendered inputs, token IDs, outputs, graph and selected model digests. Recompute the greedy result from the actual tensor bytes for source, connected reader and removed-edge reader. Retain success, failure or disagreement.

Record job identities, OS image, CPU model, hash of each kernel boot ID, preflight, cold-load, model-generation and action-step times. Use GitHub's run and job timelines for queue and dependency delays. Separately count raw answer bytes, envelope bytes and on-platform artifact ZIP bytes. Download-step elapsed time includes client/action/verification overhead. Measure clock gaps across jobs with GitHub timestamps or mark observed cross-VM wall-clock differences as approximate. This single event establishes no network percentile or steady-state throughput. Physical host allocation, peer discovery, payment, independent people and production adoption stay outside the evidence.
