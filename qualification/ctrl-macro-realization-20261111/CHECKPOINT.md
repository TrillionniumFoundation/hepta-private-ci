policy execution. External byte identity, current dependency context, macro
semantics, implementation identity, numeric arrays, source partitions, observed
denominators, probability labels and calibration ranks are checked together.

a trained content model nor evidence from a real receipt corpus.

locally before formatting (21/21, zero skips). This stage contains only the
parser and its six-method suite; the fitter is delivered in the next stage.
Full physical costs and actual execution remain separate measurements.
