# Original learning / independent NextUse: byte-custody precheck (HOLD-only)

Run `python3 -m unittest discover -s qualification/learning-original-custody -p 'test_*.py'` and `python3 qualification/learning-original-custody/audit.py /authorized/manifest.json`.

This is an **offline integrity and inventory precheck**, not a source of truth, cryptographic verifier, evaluator, owner/holdout grant, selection authorization, or economic qualification. It can say `integrity=PASS` only for the **provided files**; `status` is always `HOLD`. A different credential chain, actor ID, controller or signing key does **not** prove different human/organization control. In particular, the `operator_custody` map is **self-reported**, not independently attested. Declared costs are not proven complete against a provider's original invoice/attempt inventory. File bytes must be obtained from the original authorized owners and authenticated by those owners' existing signature/current-trust and rollback-frontier rules, *outside* this checker. Never promote a production model based on this result.

Expected manifest (`schema: hepta-original-learning-custody-precheck-v1`): pinned 40-hex `source_head`, common `operation_id`, distinct `source_task_id` and `next_task_id`, immutable 64-hex `baseline_bundle` and `selected_bundle`, `decision` (`adopt` for changed version, `no_update` for unchanged), `operator_custody` (`trainer`, `evaluator`, `holdout`), all eight named `original_receipts` (`experience`, `dataset`, `training`, `evaluation`, `selection`, `published_current`, `final_use`, `next_use`). Each receipt is `{file, sha256, operation_id, task_id, bundle_sha256}`; files are regular, local, at most 64 MiB, rooted in the manifest directory, not symlinks, with distinct paths/digests. Stages except `next_use` bind source task; the latter binds a **different ordinary task**; publication/final/next use bind the selected immutable bundle. The self-declared `admitted_attempt_ids` must match `attempts`, each with exact `id`, `state` (completed/failed/cancelled/pending/unknown) and nonnegative finite decimal-string `cost_usd`, including failed and cancelled attempts. Pending/Unknown are *not* success.

The synthetic unit tests exercise only rejection and accounting logic and cannot be counted as real customers, external operator custody, independent holdout, real Q24 training, Root cold recovery, statistically significant net benefit, or authenticated receipts. External owner trust, original data rights / deletion frontier, signed one-time holdout admission, genuine Selection, CURRENT/FinalUse, Root restart and future NextUse, actual all-in opportunity cost and randomized prospective retention/benefit remain independent gates.

This tool is deliberately in a new qualification-only directory to avoid changing #5627 / #5735 Q24 native sources, #5720 delivery/recovery, daemon blocking CI, Rustfmt or RustSec. Its `PASS` must never be mapped to product `Eligible` or `Closed`.
