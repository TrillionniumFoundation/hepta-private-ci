- `data.py`: two local official TRAIN files only; fixed publisher MD5, SHA256,
  strict IDX, complete row/group identities and original weights. Fixed noise,
  FIT/SELECT/SCREEN groups and512 FIT policy groups; no dataset/network fallback.
- `model.py` / `autodiff.py`:65,562 content parameters,291 actor parameters,
  all13 shared sequences, cached J features and full feedback gradients. T
  changes text probabilities, I changes continuous pixels, J updates both.
  Internal FP64, actual output float32. Adam checkpoints include moments/clocks.
- Stable conditional fixed-K risk uses log1p/expm1 and non-target probability
  complement in the logit VJP. Exact clip endpoints have derivative zero by
  declared convention; central differences are used only at smooth points.
- Feedback posterior VJP uses the pairwise softmax identity to preserve tiny
  near-certain-class derivatives. At ten classes it costs300 scalar operations
  per row plus a100-element temporary; that work is included in actual CPU/RSS.
- `transport.py`: actual UTF8 JSON bytes through existing text/RGB payload
  contracts; three RGB planes identical. Offline scoring uses decoded words
  and float32 pixels, not a hidden tensor or auxiliary sampled-risk score.

  standalone method1800s,2GiB RSS/retention,150s shared,450s/seed build,

  unused SCREEN quota is not transferred into content. Supervisor receipts

## Actual entry and once-only control

From `qualification/joint-generation`, with BLAS/OMP/MKL threads all1:

```bash
python -m fashion_research.launch --smoke
python -m fashion_research.run --freeze
```

Smoke imports the real entry dependencies without allocating a model, opening
data, writing outputs or creating a measurement marker. Freeze binds the full
Python source list, protocol, license and existing contracts to hashes. A freeze
can be made once; data is not needed to freeze the reviewed source.

Only after valid local TRAIN files are supplied and the frozen source is checked:

```bash
python -m fashion_research.launch --data /LOCAL/TRAIN --out runs/fashion-D-preprobe-d1
```

no downloader. Cheap source/local-file preflight precedes an atomic global
`D-PROBE-OPENED.json`; all measured intake occurs after that latch. Missing
files/smoke/known403 create no latch. Once measured work begins, every source,
