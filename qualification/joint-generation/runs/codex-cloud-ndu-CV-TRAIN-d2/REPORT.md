## Interpretation and bounded next direction

The fixed CE CV mathematics and earlier static-point variance reductions remain
valid evidence. Here its historical cache construction, live reference pullback
and correction consumed real budget, leaving roughly half as many useful updates.
This is a concrete complete-budget failure, not proof of a numerical failure,
nor a causal decomposition of staleness versus fewer updates: the study was not
designed to isolate those two effects. No variance inference is made by treating
successive, changing training states as repeated samples at one parameter point.

If the parent continues this direction, the smallest code-level hypothesis is
an **exact fused encoder pullback for the same fixed CV**, not a new coefficient
or utility. Because current and reference gradients use the same x_B,

`x_B.T @ d_current − .2*x_B.T @ d_reference`
`= x_B.T @ (d_current − .2*d_reference)`.

Then add the same fixed full-reference mean. This could remove a duplicate
encoder GEMM while preserving the pre-clip corrected gradient; head pullbacks,
mean/cache cost, checks and their CPU still must be paid. Low/full folding must
remain exact. First falsification would be single-step full-vector/Adam mismatch
or no end-to-end CPU saving after gathering/corrections; even an exact faster
kernel would still need a separately frozen full-budget study to establish
training improvement. It is only a proposed implementation hypothesis here;
no fused kernel or additional training was executed.

This result does not reopen r1/r2/failed CORE c1, reset any formal alpha or support
open-world multimodal/AV claims. The large independent confirmation remains
unexecuted. There is no permission/resource blocker; this fixed candidate's
complete-budget TRAIN improvement screen is a substantive negative result.
