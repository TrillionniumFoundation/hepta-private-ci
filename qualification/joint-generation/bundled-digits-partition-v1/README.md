# Bundled digits: one non-training partition attempt

This is a source-and-redacted-evidence package, not a standalone dataset, runnable benchmark or model result. It does not automatically execute anything. No training, model inference, selection/final evaluation, Fashion, all-FIT or strict256 result is included or authorized.

The exact real candidate source freeze and all ten of its bound files are copied unchanged into runtime/, alongside its independent SOURCE review. The two aggregate receipts in runtime/RUN_ONCE/ describe the already consumed single local attempt. This retained RUN_ONCE path must not be deleted to enable a retry. Do not invoke run_once.py or worker.py from this publication. Publication is not a new execution admission.

INPUTS.json pins an absolute local scikit-learn 1.8.0 data path, its exact compressed hash/size, and documentary paths/hashes. Those paths depend on the original execution environment. This package supplies none of those installed data/documentary inputs. Missing paths do not authorize arbitrary substitution, downloads, relocated sources, fallback loaders, relaxed parser limits or another attempt. The shared benchmark lock and trusted interpreter environment likewise are not bundled.

## Included evidence and scope

- runtime/FREEZE.json binds the ten original source/document files byte-for-byte. Source-only PLAN/CAPACITY descriptions are preserved historical pre-execution text, not rewritten as results.
- runtime/INDEPENDENT_SOURCE_REVIEW.json is the real manager source review.
- runtime/PRIOR_INDEPENDENT_SOURCE_REVIEW.json and PRIOR_INDEPENDENT_SAVED_REVIEW.json preserve earlier synthetic review records; PRIOR_REAL_G1_ADMISSION_NEXT.md preserves the earlier admission proposal. These historical references are evidence, not a complete copy of the prior synthetic candidate or its outputs. Original earlier candidates remain preserved separately. Their referenced paths may not resolve in this intentionally selective publication.
- runtime/RUN_ONCE/RESULT.json and WAIT4_RECEIPT.json contain documentary source identity, attribution, aggregate partition counts, TRAIN-only class coverage, fixed outcome category, process accounting and whole-file hash/size bindings. They contain no sample rows, heldout labels, per-group identifiers or source-row mappings. Inventory keys identify files, not samples.
- runtime/INDEPENDENT_SAVED_REVIEW.json records an independently reconstructed saved-artifact PASS for the single non-training attempt. runtime/SAVED_FINDINGS.md is its reviewed author summary. This source-and-evidence package still requires a publication-scope audit before any authorized remote write.

All files under private_manager are excluded, including TRAIN/records.jsonl, management/selection.jsonl, management/final.jsonl, management/manifest.json, PUBLIC_RECEIPT.json and COMPLETE.json. No raw gzip, decoded data, sample, image, label list or private manifest body is included. Whole-file hashes in receipts are bindings only: the omitted private files cannot be reconstructed or verified from this publication alone.

## Observed result and limits

The frozen manager's terminal receipt reports one child, normal exit, complete reap and partition groups TRAIN1096, selection324, final377. These are aggregate partition sizes, not heldout class coverage or predictive performance. Completion depends on the original private COMPLETE marker and exact artifact verification; a public complete=true field alone is insufficient. The independent saved review confirms the exact five private payloads plus completion marker and aggregate receipts; those private files remain excluded here.

The manager necessarily read all records and labels for schema, duplicate/conflict checks and grouping. Management verification and reconstruction create additional declared exposure. This is cooperative local workflow discipline, not OS isolation, cryptographic privacy or an administrator-proof seal. Child wait4 CPU is whole child lifetime; parent timing excludes a nonzero unknown serialization/write/teardown tail. Review/tool costs are additional. External supervisor-death behavior was not experimentally qualified.
