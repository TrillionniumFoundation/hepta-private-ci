# Finite digits TRAIN proposal, design v2

Status: DESIGN ONLY. The next possible admission is implementation plus a separately frozen finite synthetic workload ONLY. Every TRAIN-export/Q/T/S/F budget here remains an unapproved proposal. No implementation, imports of model/dataset packages, data access, training, scoring, or execution is authorized. HOLD_NEW_TRAIN remains in force. This is a new proposal, not evidence of feasibility or results. Separate source freeze, independent review and explicit admissions are required. All Fashion/all-FIT/strict256 holds remain unchanged. The proposed512-update new-domain training is not the old256-step recovery qualification and grants no exception to its limit.

## Evidence and scope
The public real-partition saved review reports 1,797 unique image groups: TRAIN 1,096, selection 324, final 377; no exact duplicates. TRAIN per-class groups are [111,109,120,103,99,108,111,115,104,116]. Counts are not evidence of statistical power. This design read public source/documentation/reviews and RESULT/WAIT4 only, never raw data or private_manager contents. Existing manager and saved reviewer exposure to all data is declared in their reports.

Source: Alpaydin and Kaynak (1998), Optical Recognition of Handwritten Digits, DOI https://doi.org/10.24432/C50P49; https://archive.ics.uci.edu/dataset/80/optical+recognition+of+handwritten+digits ; CC BY 4.0 https://creativecommons.org/licenses/by/4.0/ . It is the scikit-learn bundled original public UCI TEST subset, newly locally repartitioned, not original untouched TEST. No writer IDs or writer-independent inference. Later derivatives must retain attribution and disclose scaling, corruption, repartitioning and fitted reconstruction. No externally downloaded source identity was established.

The sole mechanistic question is whether a one-way predicted-class-probability connection helps reconstruct corrupted digits while also emitting one of ten fixed words. There is no loop, iteration, adaptive controller or general multimodal capability. Every arm is a finite static function. A win against listed static controls does not establish superiority over a static function class.

## Four fixed arms, no architecture search
All tensors and arithmetic are float32 except explicitly specified host-side generation and statistical analysis. Row-vector notation below; every affine has bias. No normalization, dropout, residual paths, pretrained weights or extra losses.

A, class-conditioned reconstruction: h=ReLU(x W1+b1), width128; z=h Wc+bc, width10; p=softmax(z); r=ReLU(concat(h,1*p) Wr+br), width128; reconstruction=sigmoid(r Wi+bi), width64. Word=argmax(z), smallest digit on ties.
B, connection-disabled ablation: exactly A, except concat(h,0*p). p and its multiplication are still computed. All dense forward/backward operations and allocated tensors remain in the graph, including explicit zero-valued gradient matrix products. No graph compiler, sparse optimization, constant folding or short circuit. Even though Wr conditioning columns cannot learn from this connection, they remain allocated and optimizer updates are performed. This tests the connection, not equally useful capacity.
C, static joint control: h=ReLU(x W1+b1), width128; u=ReLU(h Ws+bs), width138; o=u Wo+bo, width74. First10 outputs are logits; remaining64 are sigmoid reconstruction. L, linear descriptive baseline: o=x WL+bL, width74; first10 outputs are logits, remaining64 sigmoid reconstruction. No hidden layer, conditioning or pretrained weights. WL has64*74 weights and74 biases, totaling4,810 parameters;4,736 forward dense MACs and14,208 forward-plus-backward MACs per example. L receives the same seeds, initialization rule, batches, loss and optimizer, but different tensor shapes and no byte-identical initialization claim. L is mandatory descriptive reporting, never a selectable replacement or extra inferential contrast.

C uses all its capacity for a shared joint representation and predicts class after the second hidden layer. It receives no class labels at inference.

A/B parameter count: (64*128+128)+(128*10+10)+(138*128+128)+(128*64+64)=35,658. C: (64*128+128)+(128*138+138)+(138*74+74)=36,408. Per-arm parameter ceiling36,408 also applies to L. L uses less capacity; no dummy padding. C gets 750 extra parameters (2.10%) and a deeper classifier, deliberately favoring a credible static control. No equality-of-parameters claim across A/B/C; exact A/B equality only. Adam moments: two slots per parameter, plus gradients and one parameter copy, before activations. A/B/C have two hidden affine/ReLU stages in the reconstruction path. A has an extra classifier/softmax path. Architecture is frozen, not increased after results.

Dense forward MACs per example excluding biases/activations: A/B=35,328; C=36,068. Generic dense backward computes input and weight gradients for every affine, including first-layer input gradients and zero paths: 2*forward MACs; forward+backward A/B=105,984, C=108,204. Optimizer, clipping, nonlinearities, reductions, host generation, validation and serialization are additional; these formulas are not a CPU guarantee. Record measured compute, allocations and operator counts. If implementation cannot retain the stipulated B operations, reject the implementation before admission, not quietly call budgets matched.

## Exact initialization and finite optimization
Qualification seed only: 701. Confirmatory seeds, all mandatory: 17011,29009,41011. Qualification models never enter confirmation. L uses tensor name WL and its own shape under the same initializer rule. For each seed, A/B every tensor is byte-identical at initialization; C shares byte-identical W1/b1. Other C tensors use distinct tensor names. Weight entries are independent uniform[-sqrt(6/(fan_in+fan_out)),+sqrt(...)], host binary64 then one float32 rounding; evaluate b=sqrt(6/(fan_in+fan_out)), then t=(2*u)-1, then w=b*t with an individual binary64 rounding at each operation and no fused multiply-add; all biases zero. SHA256 stream below uses purpose `init`, seed and tensor name with flat C-order entry index. No initializer is allowed to inspect data.

Loss per example = cross-entropy(z,label) + mean64((reconstruction-clean)^2), unit coefficients. Targets clean=raw_integer/16, exact float32. A gradients flow through softmax to class head and encoder; no stop-gradient. B the zero mask removes that route only. C both heads train its shared trunk. Loss is mean over batch; no class reweighting, augmentation beyond frozen noise, weight decay or early stopping.

Adam: learning rate0.001, beta1=0.9, beta2=0.999, epsilon1e-8 added outside sqrt; zero moments, bias correction with step starting1, no AMSGrad, no clipping, float32 moments/updates, no scheduler. Qualification: exactly64 updates per arm. Confirmation: exactly512 fresh updates per arm per seed. Batch size64, including a last partial batch of8 at each epoch end (1,096=17*64+8); do not pad, duplicate or drop. Updates consume cyclic epochs until fixed limit. Stable group order is lexicographic group digest. Each epoch sort groups by (SHA256 canonical key purpose=`order`, stage, seed, epoch, group_digest),group_digest). Thus A/B/C/L receive identical batches and corruptions within a seed. Every admitted arm runs once, sequentially, in A,B,C,L order per ascending seed. No restart from an intermediate checkpoint, optimizer fallback, rerun or repair after real execution.

## Corruption, PRNG and singleton serialization
Prior draft required exact corruption seeds before G1, but the actual G1 freeze did not specify them. This design explicitly documents that timing deviation: exact model streams are fixed now AFTER aggregate-only partition qualification, BEFORE any TRAIN sample or heldout outcome is read by model developers. It does not retrospectively claim a pre-G1 freeze.

v2 changes BOTH initialization and Gaussian-noise uniform definitions before any model execution: use the top52 bits plus exact binary64 half-unit, producing strictly open-(0,1) midpoints. The v1 top53-bit expression could round to1. All key seed integers remain unchanged; domain tag is versioned to v2. Bootstrap continues to use raw64-bit integers.

No implicit library random generator. Canonical key is compact ASCII JSON array, separators comma/colon, no spaces/newline, ensure_ascii=true, fields ["digits-train-design-v2", purpose, stage, seed, epoch_or_draw, group_digest_or_tensor_name, counter]. stage is `qualification`, `confirmation`, `selection`, or `final`; seed integer, epoch/draw/counter nonnegative integers; digest lowercase hex string. SHA256(key UTF-8), first8 bytes big-endian unsigned k; uniform=((k>>12)+0.5)/2^52. For independent uniforms use counters2j and2j+1. Box-Muller g2j=sqrt(-2 ln u0)*cos(2*pi*u1), g2j+1=sqrt(-2 ln u0)*sin(2*pi*u1), pi=0x1.921fb54442d18p+1. Compute using pinned host binary64 libm, then clean+0.25*g in binary64, clip[0,1], round once float32. Floating transcendental identity is only promised on the exact later-frozen runtime and fixture outputs, not all platforms. Init uses purpose init, stage confirmation or qualification, epoch0, tensorname, counter=flat entry; uniform mapped to Xavier bounds. Ordering uses entire SHA256 digest and purpose order, counter0. No stochastic library calls.

TRAIN epoch supplies epoch_or_draw; fixed sample/seed/epoch gives a single noise realization regardless of arm or batch placement. Heldouts have exactly4 draws (0..3), seed0, purpose noise, distinct selection/final stages, paired across all arms AND all model seeds. No corruption search or reuse of TRAIN streams. Qualification and confirmation TRAIN corruption stages are separate. Duplicates, if source changes, cause identity failure rather than changing grouping.

All evaluation and qualification API diagnostics use the SAME singleton path: 64 clipped float32 values encoded as exact 256-byte little-endian IEEE754 payload, decoded once to shape(1,64). Reject nonfinite, wrong size or out-of-range values. Outputs are ASCII JSON with keys `digit_word` then `image`; digit_word maps 0..9 to zero,one,two,three,four,five,six,seven,eight,nine; image is 64 C-order float32 values, each encoded as an 8-character lowercase hex representation of its four little-endian bytes. No probabilities or true label are output. Evaluation decodes image bytes back to float32 and scores only these returned values. It must not score a higher-precision or batched reference instead. Batched TRAIN computation is allowed; qualification checks singleton API/reference equivalence on 16 fixed TRAIN groups, but no batched-only endpoint can enter selection/final.

## Finite phases and data boundaries
Q: four 64-update qualification runs, seed701, TRAIN only. Check fixed shapes, finite losses/gradients/parameters, exact A/B initial binding, masked gradient behavior, singleton bitwise equivalence to the same singleton reference, operator counts and complete receipts. No threshold on TRAIN predictive quality, no selecting a model, no optimizer/architecture tuning. Failure or ceiling breach stops this protocol. Report TRAIN diagnostics as feasibility only, never evidence of generalization. Q also includes the exact intervention below; it can establish only local numerical sensitivity, not semantic class use or improved denoising. Q does not authorize confirmation automatically.
T: separately admit twelve confirmation runs (4arms*3seeds),512 updates each. Final step only is retained for inference; no checkpoint selection. All twelve must complete exactly. Any failure stops the route; retain all partial costs. No extension if slow or weak.
S: separately admit one isolated selection worker, 12models*324groups*4draws=15,552 singleton calls, with frozen checkpoint hashes. There is exactly one candidate per arm/seed and no hyperparameter grid. This is a finite preregistered screening gate, not a chance to choose favorable seeds. Compute group/seed-averaged metrics for all four arms. Stop if ANY arm accuracy<0.50 or MSE>0.10, or if ALL arms accuracy>=0.99 AND MSE<=0.01 (saturation). Otherwise retain ALL twelve checkpoints unchanged. L is scored and reported, but neither its quality nor comparisons with L affect this screen. All ANY/ALL arm thresholds in this paragraph refer ONLY to A/B/C. Report selection results descriptively, never pool them with final. Gate does not require positive A contrasts, so negative findings are not censored by design. Separate final permission still required.
F: one isolated final worker,12*377*4=18,096 singleton calls. Every model, every group and every draw is mandatory; no partial scoring success. No reevaluation after exposure, no new seed, no relaxed threshold, no task revision on saturation, negative or inconclusive results. Missing/nonfinite output stops claim. Metrics may be reported for an aborted incomplete run as explicitly incomplete, never silently exclude failures.

Models/developers receive ONLY a separately authorized TRAIN export bound to the public TRAIN whole-file hash. They never traverse private_manager, raw source, management manifest, selection or final. Future manager exports exactly that TRAIN artifact and no other content; this still requires a named authorized actor and admission. S/F managers may read only their own split and bound checkpoints under separate authorization, returning aggregate results/intervals and receipts, not samples/labels/group identifiers. Local separation is cooperative access discipline, not cryptographic or administrator-proof isolation. No permission changes are proposed.

## Fixed final estimands and claim rules
For each group g, arm a, seed s, draw d, error=1[word!=label], image loss=mean64 squared error, joint=error+image loss. Average equally over4 draws then3 seeds, then equally over377 unique groups. Do not treat draws/seeds as extra independent images. Conditional class-correct MSE is descriptive only, pooled numerator/denominator with zero-denominator NA. Report per-seed component/joint means as well as averages; no seed exclusions or best-seed claims.

A/B measures the total effect of enabling the connection during BOTH optimization and inference; gradient routing, learned parameters and direct conditioning are not disentangled. The Q interventions hold a checkpoint fixed and do not remove this training confounding. A probability vector may carry non-class information, so neither contrast nor intervention identifies semantic class-content use.

Primary contrast A-B joint improvement D=joint_B-joint_A. Competitive contrast A-C similarly. For each contrast also form harm E=error_A-error_control and M=MSE_A-MSE_control. Meaningful superiority margin D>0.01; component noninferiority E<0.01 (one percentage point) and M<0.002 in normalized pixel squared units. These margins are fixed pragmatic utility choices, not externally validated clinical/economic thresholds.

All group lists for scoring/bootstrap use ascending lowercase group-digest lexicographic order, never filesystem order. Decode output float32 exactly then promote to host IEEE754 binary64. For each image, accumulate squared errors sequentially in pixel index0..63 then divide64; no float32 metric sums. Average draws0..3 sequentially, seeds17011,29009,41011 sequentially, then groups in that lexicographic order. Differences are formed per group from those arm means. Bootstrap means sum sampled group differences in sampled-index sequence then divide377; all endpoint/statistical operations binary64, no reassociation, vectorized nondeterministic reduction or parallel aggregation. Accuracy counts are integers before division. These conventions also apply to descriptive L and selection with324 groups.

Intervals: paired cluster bootstrap of image groups, 10,000 resamples of size377 with replacement, retaining entire3seed*4draw block for each sampled group. Generate uniform indices by SHA256 canonical keys purpose bootstrap, stage final, seed0, epoch_or_draw=replicate, group_digest_or_tensor_name="groups", counter=index/rejection-attempt encoded by counter=index*1000+attempt; use first8-byte integer k, reject k >= floor(2^64/377)*377, use k mod377, at most1000 attempts else fail. Resamples shared for all endpoints/contrasts. Sort 10,000 bootstrap means. Six one-sided endpoints use Bonferroni alpha=0.05/6: lower order index82 (zero-based) for D, upper index9916 for E/M. This percentile bootstrap is an approximate finite-group uncertainty procedure, not an exact coverage guarantee, and ignores unknown writer clustering. Fixed-seed-ensemble inference only: three seeds do not establish generalization over all training randomness.

Claim benefit from the total training-plus-inference connection intervention A-B only if D lower>0.01, E upper<0.01, M upper<0.002, AND each of the three seed-specific D point estimates>0. Claim superiority to this particular C only if its analogous three criteria and all seed-specific D>0 also hold. Full positive conclusion needs all six simultaneous criteria. Otherwise report precisely which failed and negative/inconclusive findings; do not reinterpret a joint gain hiding component harm. No inferential claim from selection or Q. No universal static-class, writer-independent or general-multimodal claim, regardless of significance.

## Fixed Q sensitivity diagnostic (not a benefit test)
At each final Q checkpoint, take exactly the first16 lexicographically ordered TRAIN groups and their qualification-noise epoch0 inputs, already used for API/reference checks. For A and B only, preserve weights and the exact h and p of the ordinary singleton pass. Substitute (i) uniform p_j=float32(0.1), all10 entries, and (ii) cyclic p'_j=p_((j+1) mod10). No true label enters either replacement. Run each modified full singleton forward once; the encoder must reproduce h byte-exactly, with no update or RNG draw. The replacement takes effect immediately before the unchanged mask. Count full forwards, even though h is conceptually fixed; no cache discount. Ordinary output is reused from the existing diagnostic. Thus A/B each have16 API+16reference+16uniform+16cyclic=64 forwards; C/L each32; total192 Q diagnostic forwards. No additional intervention at T/S/F.

For each intervention/arm record aggregate maximum absolute pixel difference across16*64 returned float32 pixels (promoted to binary64), mean squared change with the same pixel/group reduction order, and count of groups whose maximum difference exceeds1e-7. B must return every output image byte-identically under BOTH replacements; any difference fails Q as a mask/serialization defect. A sensitivity is detected for an intervention only if at least one group's maximum difference is strictly greater than1e-7. If neither does, report 'no detected output sensitivity at the fixed Q probes'; do not fail engineering Q solely for that result, add probes, retune, or claim demonstrated conditioning use. Report exact zero separately from nonzero changes at or below threshold. A sensitivity does not establish better reconstruction, semantic class information, or later checkpoint sensitivity. It is descriptive only and cannot change T/S/F criteria.
