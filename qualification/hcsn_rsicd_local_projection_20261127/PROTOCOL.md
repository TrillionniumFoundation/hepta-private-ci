# Prospective local forward construction inside the literal RSICD captioner

This is an extension to the independent RSICD nine-/ten-million-scale grouped free-boundary captioning panel, not a new external corpus. Register before fitting a local model or opening a held-out score in either panel. The base panel's training code is still being written. Publish an implementation annex with its exact source hashes, modules, fit coefficients, data bytes and common initialization/cost rules before starting any formal local solves. Use its unmodified literal forward application and official train/dev/test IDs. One canonical author caption per 32×32 RGB image, no pretrained tokenizer, feature backbone, language model or learned external targets. The same previously used RSICD gallery has 6,311 training images, 742 published validation images (use base-selected 128 for ranking) and 964 final images. The corpus is reused for research. Use full held-out source image as statistical unit, not separate caption tokens.

Use the base seed initialization, teacher-forcing masks and minibatch stream for seeds 109, 271, 463 and batch size 8. The exact benchmark has a 416-D, six-block residual stack, genuine four-live-bin plus one refractory He–Xiong price/transport state, grouped continuous boundary wire, trainable row-decoded 8×8 RGB patches and a tied word input/output dictionary. Preserve the price function, transitions, layer count, tensor widths, decoder tying and causal inference. Financial parameters and mass tables are physical constants. Preserve residual identities, normalization constants and any scalar/state parameter for which the training features do not identify a well-defined direct local regression; count and enumerate omissions. A solved matrix will not be called freely optimized at full rank when only a low-rank update was fitted.

Construct supervised local targets from causal incoming features and independent fixed random projections of the genuine next-token identity on supervised text positions. Every lexical target is available during fitting only. Supply each training image's tokens with a code for its own caption's bag of eligible target words; this is a training target, not an inference input. For nonlinear layers use a Forward Projection adaptation of sign(projected local input) plus sign(projected task identifier), followed by an explicit regularized least-squares update. Use centered/variance matched local residuals, bounded blend magnitude and positive regularization. Write at least one hidden matrix in each of six blocks and register exactly which additional physical input/output maps have locally identifiable targets. Include the actual patch sampler in the local matrix fit. The final direct dictionary fit shares input and output weights in the model. A new input embedding can alter its own design matrix, so evaluate each completed updated dictionary by running the entire unmodified literal network forward again. Finite statistics may support only a rank-limited update; save rank, design counts, dimensions, actual eigenvalue/condition diagnostics, factor degrees of freedom, pre/post hashes, number of changed scalar coordinates and per-layer norm. Track unused embedding rows and fixed physical/coefficient tensors separately. No gradient, autograd optimizer or BP teacher may be used in any forward arm.

Five positive-cost constructions/controls use identical seeds and data stream. (1) Local supervised hidden construction plus tied dictionary fit. (2) Same hidden solves after permuting targets among training examples, with the final tied solve still trained on true targets. (3) Label-free random feature hidden construction with the same shapes before the true tied solve. (4) Tie-preserving dictionary-only fit with all other parameters exactly fixed; the resulting input representation changes through the shared tensor. (5) Frozen literal features with a separate fitted linear probe, whose independent readout explicitly breaks weight tying and adds parameters. Also record the complete unmodified random literal at zero training cost. Compare with the independent panel's exact literal BP, and optionally its SDPA at the same budget where ready. Do not count a second fixed readout as a newly trained physical network.

Use 4, 16, 48 and, when feasible, 128 minibatches of the same seed-specific prefix as the base BP arm. Each fresh prefix fit starts from the same seed and charges all preceding local construction/validation/serialization to the run. The 4/16 prefix comparisons align the exact sampled images and token occurrences; report feature passes separately, since corresponding procedures read their prefixes differently. Fixed wall budgets 60, 180, 300 seconds per method×seed on a single CPU thread using cores 2 or 4 when free, with exact process CPU also recorded. A candidate counts only after the entire dev128 score and durable model/recipe are complete at the budget. A candidate late for a prefix stays late. Record all attempted constructions, all completed models, best dev token NLL per prefix, timings, exposure counts and peak RSS. Use at most one pre-specified regularization/blend schedule per arm, with no search on cold scores. If all candidates end earlier, charge actual completed work. Include feature/data build and selected cold load/inference for time-to-quality comparisons, treating shared upstream prep equally for BP. Use the base panel's thresholds 4.5, 4.0, 3.5, 3.0 nats, and report censoring. Numerical time ratios require an attained common specified quality in all three seeds. Keep measured wall, process CPU, observed checkpoints and common token count distinct.

Seal candidate identities, weights or bit-verified recipes, selected histories, inputs and code publicly within the private research repository before first external score in this extension. Use the base EOS and padding policy, per-image matched NLL sums, target counts and cyclically shifted-image NLL sums on all 964 test images. Count ties explicitly when measuring matched-image preference. Pair models by source image and seed, bootstrap 4,000 or more paired complete images, add two-way resampling of the three seeds as sensitivity. Primary at 300 s: local supervised full minus literal BP and local minus tie-only on normal-image token NLL, plus local shifted minus matched NLL. Report interval, seed values, true sequence count and fraction of images preferring their match. Additional arms/prefixes are descriptive. A +0.05-nat upper confidence bound is a prespecified local noninferiority margin; symmetric equivalence additionally requires the lower endpoint at least −0.05. No interpretation as generative foundation-model equivalence. Archive all original per-image outputs, masks/counters, random initialization and learned factors/parameters, demonstrate exact independent prediction replay from the published recipe, and account for actual effective degrees of freedom plus every untouched parameter family.
