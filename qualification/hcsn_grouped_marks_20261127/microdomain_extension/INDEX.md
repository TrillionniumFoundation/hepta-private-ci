# 独立微通道、相关性与放电时间研究索引

这组实验把阈值首达从单条扩散路径推广到同一时刻开始的多条路径。发生第一次触壁时，所有路径一起复位。金融价值通道仍使用原来的单路径股权特征。如下结论分别绑定到具体可观测量、复位约定和数据。

| 问题 | 可核验结论 | 证据 |
|---|---|---|
| 一个时间步能发送什么？ | $n$ 条条件独立路径的首击概率为 $1-S^n$，下一步期望安全距离为 $mS^{n-1}+r(1-S^n)$。停止边界的延拓至少 $C^{n-1}$，$n=1$ 恢复原算子。使用期望值继续递推属于一阶矩闭合。 | [单步公式、PyTorch 与核验](README.md) |
| 一段时间内可以发几次？ | 再生过程按每次联合复位重新开始。在有限不应期下可逐次夹逼期望脉冲数。固定内容每次全量写入时，接收门等于至少一次首击概率。每次仅写入比例 $g$ 时，接收门为 $E[1-(1-g)^N]$。240 万条独立模拟轨迹核验了有限窗算法。 | [公式、上下界及两个复位尺度](REGENERATIVE_EVENTS.md) |
| 零漂移能持续发放吗？ | 单路径及两条独立路径平均等待时间发散。独立路径达到3条时均值有限，达到5条时方差也有限。任何严格向外漂移配合有限条独立路径，最终均会永久逃逸。工程源参数下，8条路径在逃逸前预期仍可发放约9,930次。 | [长期率、误差与适用前提](TONIC_AND_CORRELATION.md) |
| 两条路径有相关噪声时如何？ | 两路径高斯噪声相关系数 $\rho<0$ 时，零漂移首击的精确均值为 $-x_1x_2/(\rho\sigma_1\sigma_2)$。$\rho\ge0$ 时均值发散。白化后的楔形开角给出尾指数 $\pi/[2\arccos(-\rho)]$。 | [停止鞅推导与独立扇形求解](TONIC_AND_CORRELATION.md) |
| 哪些参数写入可以省去反向传播？ | 对已给定的局部目标与冻结键，零漂移单步首击概率可反算本金和预激活。原正漂移版本可单调求根。对固定绝对复位水平、零漂移有限均值模型，还可以直接反算指定长期放电率。155个局部频率目标的最大标量误差 $1.78\times10^{-14}$。未保护的键出现了实测变化。 | [单步解析反解](README.md) · [有漂移反解](FINITE_DRIFT.md) · [稳态率反解](TONIC_RATE_EDIT.md) · [局部求解时间](LOCAL_TIMING_RESULT.md) |
| 改算子能改善既有图文模型吗？ | 三套原 Flickr 权重在256张开发图像上进行了9种冻结替换。单、双和四路径平均损失分别为2.942679、2.942731、2.942862。两种多通道相对单通道的配对区间均包含零。 | [真实图文开发对照](FROZEN_RESULT.md) |
| 实测神经元是否偏好多路径？ | 真实 Allen 恒流刺激的36细胞中，使用训练和开发数据锁定的主比较是四路径对单路径逆高斯。未见细胞的对数似然增益为−2.808 nats/s，95%区间[−6.127,+1.205]；已见细胞留出电流的增益为+1.655，[−8.585,+14.440]。3,066项原始时刻对照独立复算一致。适应性敏感性分析同样未达到两端点优势标准。 | [生理结果、逐扫证据与复算](allen_isi/RESULTS.md) |

Allen 试验比较了首击之后的间期密度和末尾右删失生存率。单独的金融股权读出、物理噪声相关系数和长期相变均未由这一数据检验识别。局部目标写入的计时与整个模型从语料训练到相同外部质量分别有独立实验口径。
