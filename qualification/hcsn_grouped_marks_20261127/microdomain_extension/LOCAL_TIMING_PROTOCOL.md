# Timing a frozen-key local write at equal achieved risk tolerance

Use one shared CPU thread with PyTorch float64. Compare three ways to find the preactivation required for a known reachable local release probability in the two-path zero-drift model. The methods are the closed inverse-normal expression, bracketed bisection, and a bracketed Newton method whose actual derivative is computed with PyTorch reverse-mode autograd. All use the same frozen keys, positive diagonal covariance, original preactivations, full nonlinear boundary map and final minimum-cost weight-row write. Use independent rows of 64 weights in batch sizes 1 and 1,024. A batch of 1,024 represents 1,024 different rows, one edit apiece. There are no coupled edits to a common row.

Generate keys, initial weights, diagonal variances and target drives deterministically with seed 20261127129 plus batch size. Sample target drives uniformly in [−1.4,0.45] and generate exact feasible local probabilities. Both iterative solvers start with bracket [−8,8] and must attain maximum absolute probability error 1e−11 over every row. Newton starts at zero, falls back to midpoint on a small derivative or a proposal outside the bracket, and stops once the full batch qualifies. Bisection also stops at the first qualifying iteration. Every method must return post-write probability errors within 1.01e−11 and numeric costs consistent with the closed solution. Warm all three methods three times, then run 31 rounds in seeded randomized method order. Report all raw elapsed times, medians, 10th/90th percentiles, solve iterations, maximum errors and timing ratios. The timed operation includes target inversion, the same weight-row update and a final error calculation; frozen-key/covariance preparation is shared. Measurements exclude network representation learning, cost of collecting an empirical covariance, dataset preparation and global model validation. They give local solver costs on this runtime.
