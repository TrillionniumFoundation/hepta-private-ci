## Likelihood and comparisons

Condition on the first observed spike of a sweep. Score the density of each subsequent observed interval and the survival probability of the right-censored interval from the last spike to pulse end. A sweep with exactly one spike contributes its survival term. A zero-spike sweep has no observable conditional waiting interval and is counted in cohort coverage only. Do not use first-spike latency as a renewal wait. Assert all event times are strictly increasing and lie inside the measured pulse. Preserve a genuine support failure if any observed event interval falls inside a model's absolute refractory time. No cell is excluded based on comparative performance.

For integer path count n in {1,2,4,8}, the single path has a unit-mean inverse Gaussian waiting time U with positive shape k. Conditional independence within one interval gives the normalized density n f(U) S(U)^(n−1) and survival S(U)^n for the earliest event. Each observed spike resets the group and starts a common absolute dead time. Apply the common time scale tau(I) = exp(a + b tanh(I/200 pA)). Units of tau are seconds. For the model with adaptation include c times (previous spike time / pulse duration minus 0.5) in log tau. The previous spike time is observed before the next wait starts. A parameter group is shared across all cells and currents, with no cell embeddings, per-cell intercepts, test calibration, or fitted rate offset. Parameterize the time scale directly. Finite-interval fits under this model do not separately identify microscopic reset distance and noise scale.

Compare a single-path inverse Gaussian (n=1), a gamma waiting law, a lognormal waiting law, and an exponential law with the same common dead time. The latter uses unit-mean exponential noise. All remaining families use positive shape and unit mean before the common time scale. Shape, time-scale intercept and current slope are the same number of continuous degrees of freedom for each multichannel IG, single-path IG, gamma, and lognormal. A learnable adaptation coefficient costs one extra degree of freedom in each family. Fit using SciPy L-BFGS-B, bounded a in [-6.5,0], b in [-2,2], log shape in [-3.5,5], and adaptation coefficient c in [-2,2]. Use three deterministic starts with the same initial timescale 35ms, slope −0.5 and log shape −1.4, 0, 1.6 (one start for the exponential); adaptation starts at zero. The unit-mean lognormal uses geometric parameter sigma = sqrt(1/k), so increasing k consistently reduces dispersion. Cap at 450 optimizer iterations. Rank finite converged or otherwise explicit finished candidates by achieved objective, track optimizer exits and costs, and refuse a missing finite fit.
