# Memory Cell V6：语义寻址与结构收益验证

## 结论

**自然语言入口未通过资格门，自适应结构的独立收益也未得到证明。** 本次交付包含可运行的有限任务路由器、冻结模型、确定性对照、真实结构变更及其接受/拒绝记录，以及负面结果的完整证据。它不构成通用智能、生产 Cell 自组织或端到端原生 agent 的验证。

独立留出集的 120 条有效请求中，V6 正确接受 12 条，V5 正确接受 9 条；两者均大量拒绝有效输入。强确定性解析器正确接受 89 条，但同时错误接受 2 条有效任务和 8/60 条分布外请求。三者均未满足预先冻结的“正确覆盖率至少 80%，分布外误接受率至多 5%”要求。[原始汇总](evidence/independent-held-v1/results/SUMMARY.json)

在绕过自然语言入口、直接提供任务 ID 的有界结构实验中，系统确实发现了三个新算术程序，并进行了分裂、合并、重连、回退和持久化。最终保留旧任务 48/48、新任务 24/24，但接收相同程序与信息的静态表也达到 72/72，状态更小、总算子调用更少。因此，“节点发生变化”不能充当“自适应结构带来净收益”的证据。[结构结果](evidence/oracle-adaptive-v1.1/RESULTS.json)

## 实现与公开开发诊断

本次候选是训练语料词特征、手工有限语义 cue 特征及二者组合的线性路由器。系数由训练数据拟合，cue 编码本身由人类可读规则实现。**没有使用预训练语义向量、神经编码器下载、教师模型调用或蒸馏**，因此本实验不能替代这些后续方案之间的比较。[训练实现](train.py) · [特征编码](compact_features.py) · [语义 cue](semantic_cues.py)

## 固定单 Cell 与多 Cell 控制

固定同一编码器、同一参数、每请求一次编码和七个稀疏点积，仅将七个标签 head 分配给 1、2、7 个 Cell。三种布局均为公开 development 63/72 正确接受、0/72 分布外误接受，预测完全一致。15 次交错重复得到的中位 dispatch 时间分别为 26.809、26.851、27.210 微秒。该时间不含特征编码，不是分布式运行时成本。[拓扑协议](STRUCTURE_PROTOCOL.json) · [完整结果](evidence/STRUCTURE_RESULTS.json)

两个多 Cell 候选均没有达到预设的能力增益门，因此实际采用次数为零。系数清零后正确接受为零；循环重分配标签 head 后，正确接受为零、错误接受 51/72、分布外误接受 31/72，说明现有参数与标签绑定确实影响输出。它不证明重新划分相同 head 会产生新能力。

同一语言决策接入固定 CO2 数值任务后，参数图正确 63/72，移除边降到 12/72，打乱边为 21/72，oracle 语义入口为 72/72；强 exact codec/planner 在相同语言决策下同为 63/72。这里只包含六种数值操作在固定日期上的重复语言表达，不是 72 个独立数值问题。该控制验证了已有边和参数被实际使用，没有证明参数网络优于强确定性组合。

## 真正的有界分裂、合并与重组

进一步固定 11 个已有 typed 算子、最多三跳、四个不可变 exact codec、最多 24 个 Cell/独立程序、16 KiB 结构元数据、12,000 次算子调用和最多 16 个变更候选。新任务为 `min3`、`sum3`、`mean2`；任务 ID 由 oracle 明确提供，**绕过了已经失败的自然语言入口**。[自适应协议](ADAPTIVE_PROTOCOL.json)

程序发现对每个新任务枚举 14 条真实可执行路径，按发现日期上的数值及有序 provenance 反馈选取程序，未消费目标路径标签。相同已发现程序也提供给独立构造的静态 interned program/binding table，以免把获得更多信息误记为结构收益。

14 个实际变更候选包含超预算分裂、不兼容旧任务合并、等价合并、各新任务 specialist、跨域复制、破坏性合并、等价程序重组及错误重连。9 个接受、5 个拒绝，拒绝原因包括资源门、旧能力保留和效用未改善。每个候选及其评价、前后摘要、迁移字节、检查点均持久化；最终状态从磁盘重新加载后评价。[全部候选与收据](evidence/oracle-adaptive-v1.1/)

| 口径 | 自适应结构 v1.1 | 相同信息的静态表 |
| --- | ---: | ---: |
| 旧任务最终正确 | 48/48 | 48/48 |
| 新任务最终正确 | 24/24 | 24/24 |
| 最终 Cell / 独立程序数 | 9 | 9 |
| 最终结构元数据 | 1,467 B | 891 B |
| 最终服务算子调用 | 192 | 192 |
| 计入发现后的总算子调用 | 3,266 | 1,128 |
| 接受状态迁移字节 | 16,200 B | 未采用变更序列；静态表构造后保留 |

两臂共享的固定资产为 24,377 B，不能省略后将上述元数据解释成完整系统大小。自适应从初始 24 个域内旧任务 Cell 收敛到 9 个共享程序，保留了有限旧能力并完成新任务；静态表在相同信息下仍更小、更便宜。其结论是**有限程序发现和变更管线可运行，结构独立价值尚未建立**。静态臂没有相同的在线突变历史，也没有产生每步旧能力风险；相应额外评价成本正是动态变更需要承担的成本，不能从总账中删除。

## 复核与运行

从基线提交的完整工作树应用本目录；V5 源码与数值资产继续由基线提供。V6 不包含对 V5 的修改。训练/参考推理环境为 Python 3.12.14、NumPy 2.3.5、SciPy 1.17.0、scikit-learn 1.8.0；标准库模型服务不需要后三者。

先执行纯文件与已有输出审计，不重新训练、不修改证据：

```bash
python3 qualification/memory-cell-v6/audit_evidence.py
```

验证服务输出时使用新输出路径；这里的输入已经公开，不再是新的留出测试：

```bash
python3 qualification/memory-cell-v6/native_router.py \
  --model qualification/memory-cell-v6/evidence/development-v6c/combined-lr-c1.0/model.json \
  --sha256 9107b8e9cc4f823cd227a43be04fe50c7ac07663c33623cbb5b71272eb69ac94 \
  < qualification/memory-cell-v6/evidence/independent-held-v1/results/serving_requests.jsonl \
  > /tmp/hepta-cell-v6-reproduction.jsonl
```

`evidence/independent-held-v1/evaluate_frozen.py` 是原始评估器的逐字副本，保留当时绝对路径，因此不要在其他机器直接运行并覆盖已有结果。可在新的本地副本中仅替换 `ROOT/CELL/HELD/OUT` 路径，或用以上服务命令产生新输出后比较 `accepted_intent`；时延字段随机器变化。

结构和训练脚本需令 `PYTHONPATH` 包含 `qualification/memory-cell-v5`，并将输出写入新目录。既有 `FREEZE.json`、模型、协议和证据保持原样。`DELIVERY_MANIFEST.json` 列出新增目录中除自身外的所有文件字节数和 SHA-256，可在迁移后核对。

## 对下一阶段的约束

目前不能把该自然语言路由接为自动生产入口；下一次语义改进应在新训练/开发资料上比较更适合的编码器或教师方案，冻结后使用新的人类或业务表达留出集。结构实验继续独立于执行器更换，保留静态同信息对照和全部成本；只有在持续新任务下取得可复现的净收益、保留旧能力且通过可信语言入口后，才具备升级结构结论的证据。
