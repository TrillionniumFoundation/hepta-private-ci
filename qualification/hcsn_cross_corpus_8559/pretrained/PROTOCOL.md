# Frozen pretrained Transformer comparison on the two previously opened galleries

This prospective addendum evaluates the publicly released OpenAI CLIP ViT-B/32 on the first experiment's locked RSICD test and UCM photo-caption galleries. It does not touch any of the new four-corpus experiment's NWPU or Sydney observations. Earlier HCSN, CCA and matched Transformer scores on the first two galleries are known. The CLIP checkpoint has not been scored in this work at registration.

Use one published, unmodified model with no additional optimization or checkpoint selection. Use each locked photo's normalized first human caption as a single natural-language query. Report two image conditions for the same model: native source JPEG/PNG bytes decoded at their original dimensions, and the exact cached 32×32 raw RGB given to all first-study encoders. Apply standard CLIP four-channel-free RGB bicubic shortest-edge resize, center crop to 224, and published channel normalization. Use the checkpoint's tokenizer and its model-supported context length. Pilot I/O may be run on training-only rows. Retain normalized hidden vectors and photo IDs with hashes.

Use the first study's two-direction concordance, exact and caption-equivalent Recall@1, randomized image permutation, either tower fixed and lexical 25-peers. Compare external UCM CLIP against literal and CCA in exactly the common galleries with paired normalized-caption cluster resampling conditional on the observed reference set. Record trained parameter and input counts, elapsed and CPU time for acquisition, setup, both inference resolutions, scoring and reconstruction. Prior CLIP pretraining time and data overlap are unknown for purposes of this experiment. The separately reported resolution and prior-data advantage should not be attributed to the Transformer mixer; equal from-scratch comparisons remain in the main study.
