# Cross-corpus optical image–caption grounding from scratch

This study asks whether repeated free-boundary transport improves image–text correspondence *after changing the corpus* at equal updates and limited training time. Source training and selection use only RSICD photographs and original-author descriptions. External evaluation uses all available UCM-caption photographs and their first listed human caption. No UCM result is used to choose a deployment. The earlier within-corpus catalog and caption-generation comparisons use different splits and outcomes.

## Data and independence

Use the existing RSICD author-matched, deduplicated pixel/filename correspondence, verified against its pinned pixel digest, with 32×32 RGB images and up to five true descriptions. Use original UCM bytes from train/validation/test together as an external gallery; extract 32×32 RGB by area downsampling. Use only a source-train word vocabulary (maximum 2,048, max 24 words). Within the three ordered groups source train, source development and external gallery, process stable photo names lexicographically. Remove exact RGB collisions and images within Hamming distance four under an eight-way dihedral 64-bit perceptual hash of any accepted predecessor. Hashes on 32×32 raw RGB (standard grayscale DCT sign excluding DC from the median). This is a near-duplicate screen with no geographic-independence guarantee. Source official test is a parallel report-only gallery; screen it against source train/development, not against the other report-only gallery. Use the first human caption per photograph for evaluation and deterministic per-iteration alternation among author descriptions for training. Report vocabulary coverage, photo counts, digest, exact shared captions and exclusions. Hold the two report-only galleries sealed until every architecture/seed candidate is fixed.

## Learners and costs

Two-layer width 64, four-group, four-live-atom literal He–Xiong population transport and delayed equity/loss plus explicit interlayer boundaries from the checked RSICD full-stack law. Smooth uses shared transport and an equal-parameter local smooth price law. Attention uses two standard causal scaled dot-product attention blocks at the same width; common residual feed-forwards, embedding dimension, normalized contrastive criterion, trainable image patch and word frontends. Each raw image becomes four consecutive groups of image patches; words are grouped into four chronological tokens. Common trainable readouts pool all four intervals, with separate image/text embeddings. Each trial uses AdamW lr .001, weight decay .01, one CPU thread, batches of 32, gradient clipping 1, the same initial shared parameters and the same data stream for a given seed. Seeds 371, 719, 1123. At steps 32/128/512 select best source-dev correspondence; also record the latest validation result available at cumulative training incl. source validation time budgets 10/40/120 process CPU seconds, and cost of first feasible candidate including dataset prep, model setup, source validation and cold scoring. Training stops after step 512 for all arms. A calibrated linear paired projection (whitened two-view ridge covariance with source-selected rank/regularization on train-only image color/patch moments + bag of source word IDs) is a conventional fast baseline. No UCM fine-tuning. Track whole processes separately. No claims about full multimodal LLM pretraining.

## Outcomes and advance decision

Primary is external-image-weighted bidirectional probability that the paired score exceeds a mismatched score (ties half), each direction averaged per image. Ignore false-negative matches sharing a normalized first caption. Report exact-photo R@1, caption-equivalence R@1, paired score gap, separate image→text and text→image, labels permuted and one modality replaced by a constant. Report 2,000 paired bootstrap resamples over normalized-caption clusters after averaging seeds, conditional on the realized gallery. To claim a specific HCSN contribution require the lower 95% confidence bound for literal minus smooth AND literal minus attention to exceed zero and require chance-level results under shuffling. Interpret component contributions without a study-wide superiority claim if these conditions fail. To claim accelerated matched quality report first observed checkpoint and source-selected deployment at an external concordance >=.60 for all three seeds; absent attainment remains unobserved. This descriptive clock includes endpoints available on our discrete grid; report any effects of different optimization throughput. No target search or replacement of unfavorable baselines.
