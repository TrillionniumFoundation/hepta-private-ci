# A real image–language encoder with an exclusive scalar-boundary interface

The earlier residual encoder showed functional sensitivity to its equity channel and little task-level sensitivity to its lower-to-upper wire in an already-opened UCM gallery. Register a redesigned architecture in response. This is iterative on UCM. A new, independently constituted RSITMD test gallery will be opened only after all values, seeds and deployments have been locked. This study never accesses Sydney or its model predictions.

Train only on the original first study's 6,308 RSICD photographs with their author captions and the verified input.npz. Select by original 742 source development rows. Every inter-layer data-dependent bit must be carried exclusively by four chronological positions × eight scalar values; upper code receives that tensor only. Image and text use the same lower and upper operators with separately learned raw pixel/word frontends and normalized final 32-D readouts. The literal lower and upper operators use the previously validated 4-live-bin first-passage law, delayed reinjection, two independent indexed prices and endogenous normalized boundary mark log(B(P)/B0)=log(1+kappa*u). Reset and leak constants remain fixed. There is no hidden residual across the declared port. A matched smooth operator uses the identical transport, price ranges/normalization, parameter shapes and mark projection with the existing tangent-matched price functions. The independent bottleneck Transformer uses causal multi-head dot-product attention and projects each of four lower positions to the same eight bounded values. Upper decoding still sees only the wire.

Test literal, smooth and attention using both FP32 wire values (1,024 nominal bits per sample) and exactly eight-bit uniform codes (256 bits per sample). All variants use the same static normalized mark interval; quantized variants use straight-through gradients at training, and must reproduce inference after actual uint8 serialize/decode. Nominal transport width, code count, measured test entropy and parameter counts are reported. Neither quantization nor a matched channel count grants an energy or effective entropy equivalence. The unquantized experiment uses ordinary automatic differentiation. Each of 18 arms (three fixed seeds 4171, 6817, 9203; three architectures and two formats) sees identical seeded ordered batches within a seed.
