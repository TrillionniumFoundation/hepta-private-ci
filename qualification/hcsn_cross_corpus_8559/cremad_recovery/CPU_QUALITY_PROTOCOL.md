# Independent billion-parameter CPU quality panel during unrelated accelerator use

The original Radeon time-to-quality experiment continues under its original device and budget. It is physically occupied by a pre-existing external compute workload. This separate panel measures whether the real full-width model progresses past its earlier single-step proof. Use the verified 7,442-clip original array (4984/1147/1311) and identical 72 text candidates, 4096 width, six trained temporal layers, 32 groups, 256-D joint readout, seed 137, batch 16 and from-scratch AdamW .0001 with .01 decay and gradient clipping at one. Evaluate literal, matched smooth, hard LIF and SDPA in that fixed order. Use one low-priority CPU core 12, FP32 parameters/optimizer, CPU bfloat16 autocast and no GPU operations. Record actual per-step times, gradient-tensor counts and memory. No GPU timings are inferred from CPU.

Evaluate at source-only steps 0/4/16 on a fixed 112-row development panel (the first 8 rows per development actor sorted by SHA256 of 'crema-cpu-quality-8559|' + media identifier). Also evaluate all 1,147 development clips at step 16. Preserve step-4 and step-16 parameters and development logits. A 0.05-nat reduction in the fixed-panel NLL from initialization for the literal model is the predeclared descriptive quality criterion; preserve the actual continuous change if missed. On the 16 held actors, score only the source-selected step (4 or 16) and only after all four models have completed both fits and their file identities have been sealed. Preserve predictions and each modality’s within-actor derangement. The four single-seed arms are a preliminary quality check distinct from the full three-seed GPU comparison. Physical memory headroom is verified before launching. CPU computation yields between fitted minibatches or evaluation batches while the higher-priority original accelerator comparison is executing; accumulate active computation and paused wall time separately. There is no weight sharing across arms.
