# Finite augmented-selector interval — HOLD

This separately frozen candidate stacks on
[#6329](https://github.com/TrillionniumFoundation/hepta-private-ci/pull/6329)
and closes one narrow small-fixture arithmetic gap. It uses the exact signed
non-substochastic interval primitive to encode a finite active state with:

- a nonreturning upper accumulator;
- lower-hit and occupation accumulators; and
- an independently discounted active copy with discounted lower-hit and
  occupation accumulators.

The fixed positive and signed-mirror fixtures run at duration 0.5. Exact
rational enclosures must uniquely round every one of the seven outputs to a
binary64 value. Zero duration must preserve only the two initial active
amplitudes exactly.
