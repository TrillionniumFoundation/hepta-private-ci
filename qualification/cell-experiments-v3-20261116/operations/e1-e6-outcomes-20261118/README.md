### A concrete message-interference observation

Read-only comparison of all original learned/drop-answer pairs proves that
five are effective interventions. Their tasks, routes, contracts, first
requests, first answer bytes and token IDs match. In the second request, only
the relayed answer field differs; feedback, initial messages, model parameter
hashes and generation configuration match. Four old A tasks change from a
failed to a successful last step when that field is removed. The fifth,
`A-colon-repair`, fails both ways. `A-counter` has a feedback-only route, so
its answer ablation is an explicit noop and both last steps fail.

This paired intervention identifies harmful answer relay on four tasks for
this fixed candidate and protocol. The raw outputs include excess escaping
and invalid test patches. It does not establish a general property of Circuit
communication, an independent-task improvement or a net collaboration gain.
Both arms still select the same five successful A answers.

A-only search costs are included: six graph candidates on six A tasks use
72 model calls before any B evaluation. FF, TF with feedback only, and TF with
no relay tie at 5/6. The predeclared tie-break selects FF. TT and CC are extra
controls, not silently added to the selection pool after B is seen.
Those search/fit costs are additional to the learned route's evaluations;
equal two-call task caps do not make its end-to-end cost equal to a
predeclared FF control.
