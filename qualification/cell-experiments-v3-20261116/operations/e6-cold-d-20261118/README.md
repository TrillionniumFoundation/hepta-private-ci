# E6 distinct cold-process D controls

The 21-test macOS run uses an explicitly authored predictor fixture. It includes a real cold subprocess, both model decisions, exact original-request binding, refusal of stripped D/changed-record retries, and D receipt retention. Source hashes and the complete test log are retained here.

These controls qualify only engineering execution and accounting behavior. Independent source/control evidence, native owner adoption, FinalUse, full physical cost and settlement remain unqualified. Actual D tasks must be frozen with the upstream experiment; old training receipts cannot be rebound to a later plan.
