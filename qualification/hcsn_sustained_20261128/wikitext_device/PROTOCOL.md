# Prespecified WikiText-2 physical streaming extrapolation

Evaluate the pre-existing seed-887 validation-selected HX and SDPA word models from the private 12-epoch study in PR #7280. No fitting. Each has 1,144,579 trainable weights, width 32, two blocks and the same normalized 33,278-word head. Verify both weight byte hashes and the official test-token array hash. The source uses absolute position embeddings of length 128, 128 filter powers and non-overlapping training contexts. First reproduce the official complete 245,568 target scores at exactly that window and compare the streaming outputs against the existing dense model.

For windows 256, 512, 1,024 and 2,048, make a new inference convention: use the original 128 positional vectors cyclically, carry the HX causal exponential update across block boundaries, and preserve all previous SDPA keys and values to the requested capacity. Each outer window restarts both models. Evaluate the same complete target stream under each convention. Include identical per-128-target block totals for paired uncertainty; use contiguous groups of 4,096 tokens for descriptive paired resampling. The interventions combine different position semantics outside training and longer state retention. They cannot establish that the original train-time models support arbitrary long positions or that a model was trained with long contexts.

For numerical verification, compare strict-128 cached hidden vectors with the unmodified original model and compare arbitrary chunk sizes / singleton appends on the same extended sequence. Verify exact full-support greedy words from the hierarchical word probabilities against an independent construction on selected states. At short and extrapolated lengths (128, 512, 2,048), measure real full-prefix conditioning and 16 genuinely autoregressive continuations at batch one. Measure both arms, interleave them in reversed orders over four repeats, synchronize at timing boundaries, and distinguish receipt of the last input from generation of the next word. Report carried state and KV bytes separately from allocated device memory and readout scratch. Full-distribution greedy decoding must include rare words under their conditional distribution and cannot be replaced by picking the largest root class.
