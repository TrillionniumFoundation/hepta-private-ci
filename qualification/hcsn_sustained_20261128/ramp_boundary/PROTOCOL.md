# Continuous motion of the boundary within each time interval

The existing physical network holds each new boundary fixed after an instantaneous jump. Add log-linear motion from the previous boundary to the new one during the interval. Keep the previous law, neural drive, reset timing, monetary observations and port, and preserve the default behavior for existing models. Write both dense and FFT implementations on the existing population constructors. For constant physical log drift μ, volatility σ, interval length h and log-boundary increment b−b_prev, the continuously moving absorbing problem is exactly the fixed-barrier problem for log margin with drift μ−(b−b_prev)/h. Conditional survival and endpoint mass live in the new log-margin coordinates. Predictive probes use the terminal boundary held fixed over their separately named horizon.

Validate full tensor values and gradients of two-layer networks for jump/continuous modes and dense/FFT for multiple widths, grids, input sequences and seeds. Check flow plus surviving mass equals initial mass, and check fixed-boundary special cases. Independently test first passage and endpoint probabilities by Brownian-bridge sampling under a moving barrier. Track the finite sampling error. Check convergence when a fixed linear ramp is split into two half-steps on increasingly fine grids. One-tick refractory and mid-bin projection are distinct modelling approximations and must not be silently changed in the semigroup check.

Re-use the registered Optical Digits 0/1 task for a paired engineering test. Use seeds 314, 159 and 271, K=12, two layers of width 3, the priced port, cached quotes, one CPU thread in FP64, batch 8 and AdamW lr .016/decay .001. Compare the old jump, log-linear ramp and ramp with learnable physical gain initialized at .15. Their endpoints receive the same inputs and output heads. Take 64 updates with development checks at 0,8,16,32,64. Freeze each model's best development NLL and final weights across all nine cells before looking at any of the 73 previously studied clips held out from fitting. Report all seeds, raw scores, accuracy, timings, bounded interpretation and a paired-by-sample bootstrap. The comparison is a feasibility and small-task sensitivity test; it cannot identify the physiological motion law or establish general encoding superiority.
