# A boundary that moves continuously between sampled inputs

For the opt-in `boundary_path="linear_log"` path, the physical boundary moves from $B_0$ to $B_1$ according to $B(s)=B_0\exp[s\log(B_1/B_0)/h]$ within a time interval of length $h$. The log margin then has constant relative drift $\mu-\log(B_1/B_0)/h$. Applying the existing killed diffusion to the starting margin with this relative drift computes the continuously moving boundary's exact first-passage probability for the interval, conditional on the chosen physical dynamics. Surviving bins are expressed relative to the ending boundary. The endpoint financial quotes use the ending contract. Subsequent probes retain their own fixed-boundary forecast convention. The `step` path remains the default for existing models.

For example, the initial log margin 0.131818 and a boundary log increment 0.19 give immediate absorption probability 1 under a boundary jump. A continuous movement over 0.25 time units gives 0.787404 under the same starting margin and price-law volatility. On a fixed boundary, the two CPU FP64 implementations agree to 1.05e−16 in the comparison. Both produce continuous population messages, with different temporal assumptions.

The dense moving-boundary path integrates the reflected Gaussian terms in log space to avoid magnifying roundoff at large relative drift. Its source-atom blocks bound the size of each working tensor. The FFT path uses its fast convolution in the well-conditioned region and falls back to the stable contraction when an inward drift would amplify roundoff. A finite grid still relocates surviving mass to representative points, and the neural refractory mechanism still lasts one tick.

Twenty independent checks used 524,288 Brownian bridges per case, sampling both whether a continuous path hit and its end bin. Maximum absolute endpoint-bin discrepancy was 0.00145 and maximum analytic mass error was 2.23e−16. In a no-reset first-passage semigroup test, splitting a given continuous ramp into two half intervals introduced an absolute flux discrepancy of 0.003839 at 32 bins, 0.000231 at 128 and 0.00001444 at 512. Across eight two-layer network configurations, dense and adaptive FFT output/gradient discrepancies were below 1.0e−15/7.1e−15. An independent directional difference for the full input graph was within 1.1e−11. See [native verification](verified.json) and [checks](check.py).

On the registered small Optical Digits 0/1 sensitivity test, all nine cells finished 64 updates. The three-seed mean held NLL and balanced accuracy were 0.07116/99.55% for instantaneous jumps, 0.06249/100% for continuously moving log boundary and 0.08444/98.20% when the latter also learned an input-driven physical drift. The paired held-example interval for continuous minus jump NLL was −0.00867 [−0.01229,−0.00541]. Adding the learned physical gain gave +0.01329 [−0.02450,+0.07642] relative to jumps. The same 73 held examples were used in previous engineering trials. Training times were 1.10–1.27 s, 1.63–1.65 s, and 1.99–2.21 s respectively.
