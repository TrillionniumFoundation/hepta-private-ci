# Device observations for HCSN head editing

The native panel uses the original FP32 seed-137 HCSN output head, real clip features of the 1,708 source-training examples participating in the first three sentence edits, the same 200 protected anchors and 72 prompts, all 1,147 development clips and 1,311 held clips. Upstream HCSN features are materialized before launching this panel. The two methods receive the same original keys. Direct BetaEdit adapter writes visit each new minibatch once. The strong BP control performs 128 cumulative cross-entropy gradient iterations per stage. Both apply the previously fixed 0.25 parent-relative deployment gain. This benchmark begins at tensor handoff, excluding upstream feature generation, software installation and pretraining. Fresh full-process timings with feature generation appear in the parent chapter.

On the ai395 physical AMD Radeon 8060S Graphics, PyTorch reported ROCm and an actual device dot product equaled 140. FP32 held logits differed from the native CPU calculation by at most 1.15e−5 for either method. The methods both met the joint gate in both repetitions on both devices. In the first GPU process placement, direct and BP tensor-handoff-to-end times were 1.829/1.657 s. In a reversed-order repeat with libraries warm they were 0.0780/0.8547 s. On one CPU thread they were 0.0284/1.3226 s in first order and 0.0228/0.8555 s in reverse order. Single-seed device timing with two repetitions does not isolate startup or hardware scheduling effects. It does establish real GPU matrix solves, gradient optimization and validation on the same complete original stage-three panel.

The standalone private cloud panel is separately identified. It takes a deterministic stratified subset of the same subject's frozen-head features, with 108 training, 144 development and 144 held clips, all 200 anchors and all 72 text keys. The input is FP16-packed and expanded to FP32 before evaluation. The 190,301-byte cloud program includes only required head data and experiment code. It is a device-path and transfer experiment. The compact native CPU and 8060S runs completed and both methods missed the joint gate; a speed ratio at matched quality is unavailable for the compact panel. The cloud request is independently identified as `hcsn-9de7-matched-beta-device-v1`. A real device arithmetic check, observed PyTorch build and verified runtime result are required to count a remote execution as GPU.
