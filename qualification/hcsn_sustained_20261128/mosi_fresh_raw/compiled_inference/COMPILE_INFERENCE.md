# CPU inference on the frozen MOSI cohort

This analysis was arranged after examining the new MOSI training and cold summaries and observing different inference times. Fixed all-stream forward HCSN and Transformer at width 64, seeds 413, 677 and 941, original 180-second validation winners. Use the original 686 utterances, existing 64-example batching and final 46-example batch, one physical host with one CPU thread per process. Both arms receive identical eager and fullgraph CPU Inductor treatment.

Compare a new process for each architecture and execution backend. Measure first complete output with the architecture's compiler cache initially empty, and record model loading, wrapper construction and first execution separately. Change only weights between seeds. Verify the eager predictions against the original stored vectors, and require mean absolute compiled error at most 0.0001, maximum at most 0.001 and zero sign-label flips for the numerical gate. Record nine warm full-dataset sweeps per seed, their medians, process-to-first-output latency, exact saved predictions and estimated complete sweeps needed to amortize compilation relative to eager. Bound each architecture/backend child at 600 seconds and retain the relevant failure if compilation does not complete. Existing feature preparation, foundation feature acquisition, network transfer and the training studies each have separate clocks.
