# A fresh, limited MOSI replication if the original selected files remain unavailable

The 2026-11-27 MOSI branch ends with a selection seal. Its public tree contains the original code, financial table and hashes of the original results. Neither the weight archive nor the fit-history files were present in that pinned tree when this document was drafted. This document reserves a *new* experiment on the already studied public cohort. It is written before the newly reconstructed arrays are scored and before the recoverable-weight comparisons are known. Any later historical object that verifies against the old seal is reported in a separate historical-object table.

Use the pinned original raw source, train/development/test tensors, model sources, financial table, original fixed video folds, model designs, seeds, losses and candidate-level CPU budget. Require exact restored checksums first. The fresh panel comprises four 64-unit, three-layer physical arms (supervised all-stream forward, matched text-only forward, matched audio-plus-vision-only forward and shuffled hidden labels); physical frozen-hidden readout; the 64-wide ReLU forward control; 64-setting physical full BP, attention BP and text-only attention BP; and raw all/text/AV ridge controls. The matched AV physical arm uses the unchanged original FP-H trainer on the same normalized arrays with only text coordinates zeroed and preserves all original IDs and responses. Include all seeds 413, 677 and 941, the original CPU rungs 15/60/180 s, and all actual commits/sampler/candidate timings. The model-width setting 64 corresponds to the original 48-wide, two-block attention control. Cost is observed separately by mode; new wall times cannot substitute for historical ones. Save all new fit receipts, state files and hashes. The main target is lower video-equal MAE. Pairing, uncertainty, clipping and the equivalence margin are retained from the original prospective protocol. Report full-vs-text and intact vs deleted or independently deranged audiovisual channels, plus low-cost ridge comparators.

Before scoring any new candidate outside train/development, write a fresh selection seal with every enrolled fit hash, checkpoint hash, code identity and selected rung/checkpoint. Reuse a candidate from the byte-reconstruction work only if it was made from the same train/development inputs and predeclared code, with all fit observations saved, and enrollment was specified before its external evaluation. Keep historical-object matching separate and disclose any prior observation of the same public cohort. Score the new seal separately on all 686 confirmation utterances from 31 original videos, using all three seeds and the original three derangements per modality. Count unseen and censored rungs explicitly. Publish raw prediction vectors, per-video scores, hierarchical paired clusters, fusion vs text-only and raw notes. No output from a new fit is an observation on the missing old checkpoint. The inputs are pretrained/extracted (BERT/audio/vision) and this is neither raw multimodal foundation training nor a general speed or locality theorem.
