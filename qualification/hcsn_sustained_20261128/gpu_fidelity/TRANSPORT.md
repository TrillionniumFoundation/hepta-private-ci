# Private input capabilities on the installed HeptaRuntime routes

The 58,831,581-byte prepared original archive reached the private ROG staging directory from the original ai395 host through preconfigured SSH with strict host-key checking and batch authentication. Both ends produced SHA-256 `18423277257e2e487521d83a8c116bc7cf5599411f4ff769e569bd849beae6ad`. This verifies operator-to-operator transport. The archived accelerator features come from twelve 28×28 grayscale frames and twelve 64-band audio vectors per clip. They are already a derived representation of the original synchronized public media.

* `hepta-compute plan --help` accepts one code source and named outputs. The installed Colab profile limits its code source to 262,144 bytes. A 58.8 MB NPZ cannot be transported intact this way. Private data on an operator host is absent from fresh Colab filesystems.
* `hepta-colab-account ALIAS run --help` has bind, submit, inspect-key, run, status, cancel, read and fetch. On a provision-key bound session, the release dispatcher's allowed commands are submit, run, status, cancel, read, fetch and inspect-key. The installation `20261109-scoped-profiles-v6-absence-4920/account_launcher.py` lines 46–61 specifies those operations. Its lines 89–104 check the exact account, profile fingerprint, session, kernel and endpoint. A write of an arbitrary input file is absent from this interface.
* The pinned underlying vendor CLI `colab upload --session NAME LOCAL_PATH REMOTE_PATH` performs a Jupyter Contents PUT. Its CLI takes `--config` to select stored sessions. The managed adapter saves the runtime proxy token and endpoint into the existing account-level SDK session store (`manage_colab.py` lines 386–407). Directly selecting that store and going outside the task-scoped dispatcher would change the access path. The study did not read or export that store or use a global/default credential. The fact that Google's general client can upload a file does not establish a managed input receipt for this private task.
* `hepta-kaggle-account ALIAS batch submit --help` exposes `--dataset-source`, `--kernel-source`, `--model-source`, and `--competition-source` for existing Kaggle assets. `hepta-compute`'s ordinary private route forwards task code, timeout and accelerator. The configured account adapter has no dataset-create or dataset-upload command. No project-identified existing Kaggle asset containing the exact archive was supplied or found. Kaggle notebook ownership and actual device assignment are independent prerequisites.
* The new trial retrieves only fixed public release media and the public pinned FFmpeg wheel when necessary. It verifies the original clip LFS pointer and then the prepared tensor hashes. This permits a test of fresh full-resolution inputs without private corpus export, account secrets in the cloud, or any change to a signed adapter.
