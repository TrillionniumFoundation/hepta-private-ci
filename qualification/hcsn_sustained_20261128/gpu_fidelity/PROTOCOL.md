# Private Colab validation of original CREMA-D features from public pinned media

The primary endpoint is equality of raw tensor bytes to the existing prepared CREMA-D corpus (SHA-256 `18423277257e2e487521d83a8c116bc7cf5599411f4ff769e569bd849beae6ad`). The frozen 58,831,581-byte prepared archive is staged on a private operator host. The accelerator job receives its checksums, speaker split, fixed 72 prompts and model source in an authenticated private source file. It retrieves public media from the authors’ pinned release `1658cd342dff90010aa843eaeebd53610a08b1dc`, checks each reconstructed Git LFS pointer against the release tree, and invokes the original FFmpeg binary and preprocessing transform. No account keys are supplied to the cloud program. Only verification and scores return.

Five nested tiers use training/development/test counts 24/8/16, 96/24/48, 384/96/192, 1,152/240/384 and the entire 4,984/1,147/1,311 corpus. Within each split, records are selected from the original row order by deterministic permutations with seeds 280911, 280912 and 280913. A tier qualifies only if original clip identifiers, image tensors and acoustic tensors all match their precomputed SHA-256 hashes. All 48 initial clips have separate SHA-256 references for each modality. The privately retained reference includes original raw array hashes for all 7,442 clips. Failed requests, exact counts and nonmatching arrays remain reportable outcomes.

One private Colab GPU attempt allows 600 seconds. Public ingress gets up to 365 seconds after program entry, using at most eight worker threads. If the initial tier qualifies, all four archived six-layer width-96 encoders run on the largest fully verified tier. One seed (137), common full-fidelity data, 12 steps, batch 24, AdamW 0.0003, original contrastive loss and fixed 72 prompts define the secondary endpoint. Every qualified held-out item is scored for each arm. The run verifies a real CUDA T4 and synchronized hardware timing. The fixed-update endpoint illustrates feasibility conditional on the exact tier, and cannot establish a longer fixed-clock or multiseed comparison.
