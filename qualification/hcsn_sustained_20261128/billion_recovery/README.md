# Four completed billion-parameter CPU fits and cold CREMA-D evaluations

This recovery brings together the four one-thread CPU fits at seed 137, their selected checkpoints, development panels, cold logits and the original final scorer output. Six width-4096 temporal blocks consume twelve grayscale 28×28 frames and twelve 64-band acoustic vectors per clip. The shared model maps audiovisual input and each of 72 text prompts into unit 256-dimensional vectors and scores the 12-script × 6-instruction gallery with a scaled dot product. The three physical-model arms have 1,016,475,200 trainable parameters each and the causal SDPA arm has 1,011,757,056. The literal and smooth mixers use 32 groups with four live atoms and one refractory coordinate. A matched hard LIF arm uses a surrogate derivative. This is a limited closed-gallery audiovisual/text encoder comparison. [Encoder](original/scripts/encoder.py) · [Temporal blocks](original/scripts/hcsn_temporal.py)

All four arms completed 16 AdamW updates of batch size 16 under CPU BF16 autocast, starting from their seeded initializations. There were 256 presentations and 249 distinct training clips, sampled with replacement. The sealed 112-clip development panel supplies eight clips from each of 14 development actors. The stage selected the lower panel NLL of steps 4 and 16 for each arm before scoring 1,311 clips from 16 held-out actors. Train/development/held-out totals were 4,984/1,147/1,311 clips and 61/14/16 distinct actors. Conditional on these four fitted models, the literal-minus-SDPA difference on aligned held actors was −0.001023 nats (paired actor-bootstrap 95% interval −0.001284 to −0.000744). The joint top-1 difference was zero. The differences in literal-versus-smooth and literal-versus-LIF NLL both have intervals spanning zero. Swapping only video actually lowered literal NLL by 0.000186 on average, whereas swapping only audio increased it by 0.000699. These small differences need to be read alongside absolute retrieval performance. The four arms shared a single initial seed, and presentations were a small fraction of the available corpus.
