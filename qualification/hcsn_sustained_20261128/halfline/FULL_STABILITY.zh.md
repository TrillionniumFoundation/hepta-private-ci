# 两个外侧稳态的完整频谱与局部稳定性

同一恒定输入和相同的即时有符号反馈下，两个外侧正再生平稳分布在固定总质量的加权全变差范数中局部指数稳定。中间平稳分布有正实线性增长模态。结论针对含吸收、连续时间复位和定长不应期的无限半轴模型。两个外侧根的区间与单位时间发放率见 [稳态公式](README.zh.md)。

## 开环谱与不可观测方向

取 $1<\beta<\min(u_\mathrm{low}/D,u_\mathrm{high}/D)$，例如 $\beta=1.1$。在活跃半轴上设权重 $W(x)=e^{\beta x}$，在不应期的剩余时间区间上取 $W=1$。考虑总质量为零的有限带权有符号测度，或其中由活跃与不应期密度组成的闭子空间。股权最多按 $e^x$ 增长，所以所有反馈观测在此空间有界。漂移变化的一阶输入是 $(p'_u,0)$，它在同一空间内且总质量为零。

对恒定 $u$，开环再生过程在零质量子空间有指数混合。给出适用标准加权 Harris 定理的细节。对固定 $t_0>d$，未触壁路径的终态权重期望至多为 $e^{-\beta(u-D\beta)t_0}W(x)$，这是无吸收布朗指数矩。到壁后经过的每一段活跃过程从 $a$ 重启，在 $t_0$ 内重启次数至多为 $1+t_0/d$。有限时间布朗最大值有有限指数矩，故已经触壁的路径对终态权重贡献有与初始位置无关的常数界。从不应期出发也有同一类常数界。这给出一步几何漂移。任意有界初始活跃集合 $0<x\le R$ 中的路径，在一个指定的有限时窗内有一致正的触壁概率，下界可取从 $R$ 出发的首达概率。选时窗和骨架时长，使触壁、等待 $d$ 后，到骨架终点仍有统一正的剩余时间。从复位 $a$ 到一个固定正区间的吸收转移密度在剩余时间的紧区间上有正下界。不应期起点可直接完成首次复位。故各权重下水平集满足骨架链的小集条件。由加权 Harris 定理及有限时间权重界，存在 $C,\gamma>0$ 使零质量开环演化 $T(t)$ 满足 $\|T(t)\|_W\le Ce^{-\gamma t}$。[Hairer 与 Mattingly, *Yet Another Look at Harris’ Ergodic Theorem for Markov Chains*](https://doi.org/10.1007/978-3-0348-0021-1_7)

完整线性化是这个开环加上有界秩一反馈 $b\otimes f_*$，其中 $b=(p'_u,0)$。若 $\Re s\ge0$，开环在固定质量空间已有预解算子；完整系统出现谱的充要条件为 $1-H(s)=0$，其中 $H(s)=\langle f_*,(s-A)^{-1}b\rangle$。因此所有完全不改变价格观测的模态均受开环混合界控制。按此空间计算，$H(0)=1-S'(u)$，可由微分归一化稳态方程得到。

## 从有限插值到整个虚轴

写 $k=2s/(u+\sqrt{u^2+4Ds})$、$t=(u+\sqrt{u^2+4Ds})/(2D)$、$\lambda=u/D$、$N=a+du$。选择平方根实部为正的支。设 $J_k(l,h)=\int_l^h e^{-ky}f_*(y)dy$。这些矩由实股权 ODE 的部分积分公式以及两项正态 CDF 直接延拓。令 $V_s$ 为不应期延迟的开环贴现值。用 $-u+D\lambda=0$ 化简两个矩，有

$$
 H(s)=\frac{\lambda}{Ns}
 \big[J_\lambda(0,\infty)-e^{\lambda a}J_\lambda(a,\infty)
       +D(V'_s(a)-V'_s(0))\big].
$$

$V_s$ 的吸收项用两个指数解，复位分母为 $1-e^{-sd-ka}$。该式也给出零点附近的可去延拓；复位分母在零点的一阶系数是 $d+a/u>0$，归一化扰动消去常数模。对每个外侧根都把代表 $u$ 的验证区间再收紧到约 $2\times10^{-33}$。

将 $[0,30]$ 分片，用 28 阶 Chebyshev–Lobatto 插值。对每一片，外切的参数 2 Bernstein 椭圆有独立的模长上界 $M$。由解析延拓的 Chebyshev 系数界以及 Lobatto 混叠，整个实片的余项不超过 $4M/2^{28}$。每个节点用 MPFR/MPFI 向外舍入计算复正态 CDF。将 $\exp(-z^2 t^2/2)$ 的 Taylor 多项式在 $t\in[0,1]$ 积分，第 $n$ 阶后的余量至多为

$$
 |z| e^{b} b^{n+1}/\{\sqrt{2\pi}(n+1)!(2n+3)\},\qquad b=|z|^2/2 .
$$

输入转换的半径用复导数模长上界另计。离散余弦变换本身使用区间运算。如果实部插值多项式的系数是 $c_j$，则 $\Re H\le \sup c_0+\sum_{j>0}\sup|c_j|+4M/2^{28}$。所有相邻小区间共享同一个精确二进制端点。这里的最大值覆盖节点之间的全部频率。

椭圆上的 $M$ 使用在实半轴对支付函数的上界，不取复高斯函数的插值作假设。对本组合约，$0\le L(y)\le A-\mathcal R$，其中 $\mathcal R=\alpha B/m-c/q$、$A=e^{-qm}(p-c/q)$，由 $e^{-qm}F\le G\le F$ 可验。股权现金流是 $\delta B e^y+C_0-L(y)$，其中 $C_0<0$，由贴现和有限责任得 $0\le E(y)\le B e^y$。因此存在显式 $c_j\ge0$ 使 $|f_*(y)|\le c_0+c_1y+c_2e^y$。把这些指数和线性项分别对 Green 核及其起点导数积分，即得椭圆上、复位分母避零后的 $M$。第一片另用围绕零的小圆上的上界与最大值原理；用 $sd+ka=s[d+2a/(u+\sqrt{u^2+4Ds})]$ 和指数余项界证明圆盘内复位分母的唯一零点为原点。所有比较、系数和余项见 [计算程序](frequency.py)。

## 从谱排除到演化稳定性

令 $h(t)=\langle f_*,T(t)b\rangle$，开环混合使它指数衰减，而且 $H=\mathcal Lh$。存在一个窄的左移条带 $\Re s\ge-\epsilon$，其中 $1-H$ 一致避零。确实，在有限的紧频段内由连续性得到；对于充分大的 $|s|$，用同一高频不等式并把 $|e^{-sd}|$ 的上界换成 $e^{\epsilon d}$ 即可。取 $\epsilon<\gamma$。在这个条带上 $H=O(1/|s|)$。反馈卷积预解的变换为 $H/(1-H)=H+H^2/(1-H)$，后项沿左移竖线绝对可积。由 Laplace 反演和移线，其时域核为 $h(t)+O(e^{-\epsilon t})$。开环、有时域指数界的反馈卷积与变参数公式一起给出零质量线性演化的算子指数衰减。这一步保障了未被单个数值模态检验覆盖的任意小分布扰动。

同一模型也能从线性结论得到非线性局部稳定性。固定有限时间块，先把向内速率相对稳态的变化看作确定的有界函数 $b(t)$。在恒漂移的参考轨迹上，用仅在活跃时段累计的布朗随机积分做 Girsanov 漂移变换；吸收、复位与确定性等待依旧是同一条样本路径上的规则。对时间块上的终态/中间态带权期望，指数鞅在 $\|b\|_\infty$ 的一阶展开有一致 $O(\|b\|_\infty^2)$ 余量。理由是随机积分的二次变差至多为 $T\|b\|_\infty^2/\sigma^2$，而参考终态 $W$ 的任意有限次幂期望在有限块内均以对应的初始 $W(x)$ 次幂为界。Cauchy–Schwarz 后，其带权变化至多为 $C_TW(x)\sqrt T\|b\|_\infty$。也可在不应期起点使用这个界，彼时活动积分先为零。以上界同时对所有中间时点成立。

稳态附近的活跃质量有正下界，两种价格聚合也严格为正，故群体均值、截正后的双曲正切以及反馈都是关于分布有界线性读数的光滑函数。在短时间块上，$b\mapsto$ 由受控轨迹分布算出的反馈映射因前述 $\sqrt T$ 因子成为压缩映射。这给出局部唯一演化及其对初始分布的一阶可微性；可在带权有符号扰动上作局部延拓，再限制到概率分布。把相邻短块合成，可对任意固定有限块得到相同可微性。漂移变化的一阶 Duhamel 源在稳态是 $p'_u\delta u$，所以块映射在稳态的导数正是此前分析的完整线性化。选择一个足够长的块，使该导数在零质量子空间的算子范数小于 1，由一阶展开得到稳态邻域内的逐块收缩，再用有限块一致上界得到连续时间局部指数稳定。这里没有给出吸引域的大小或实际膜电位的物理时间标度。

```sh
python enclose.py
python enclose_growth.py
python sharp_roots.py
cc -std=c11 -O2 -shared -fPIC cdf_point.c -Wl,-l:libmpfi.so.0 -Wl,-l:libmpfr.so.6 -o cdf_point.so
python tail.py
python frequency.py 0 0 16 proof_low.json
python frequency.py 2 0 16 proof_high.json
python independent.py ../resolvent/closed_form.py
```
