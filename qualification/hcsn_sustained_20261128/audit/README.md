## Completed billion-parameter comparison recovered from the original host

The Git branch stopped at an early development checkpoint. The original CPU campaign subsequently completed 16 updates, 256 training presentations and a held-actor cold test on 1,311 clips with 72 target prompts. At the single fitted seed, HCSN, LIF and scaled-dot-product attention each chose the correct prompt on 16 clips (1.2204%). The slope-matched smooth control chose 18 (1.3730%). The HCSN and attention held-out NLLs were 4.275644 and 4.276667. Mean NLL for a uniform 72-class prediction is 4.276666. The paired HCSN-minus-attention NLL difference had a conditional 95% actor-bootstrap interval from −0.001284 to −0.000744. Joint top-1 accuracy was equal. The active wall-clock durations for HCSN and attention were 634.19 and 488.72 seconds respectively. This run measured billion-parameter training and inference at a very small training budget.

We independently rescored all 1,510,272 stored finite logits across four input permutations and four arms. We verified common clip order, labels, 16 held actors, individual archive hashes and the training/evaluation seal. A separate standard-library reader recomputed every mean NLL and joint accuracy with maximum absolute difference 8.88e−16 from the original host summary in the accompanying CREMA-D evidence. The recount is in `cremad_independent_recount.json`. The host's earlier checkpoint replay verified 8,064 development logits byte for byte after restoring 4,066,268,811 bytes of model state. The full multimodal pretraining, life-cycle energy and cross-data equal-quality cost claims remain open.
