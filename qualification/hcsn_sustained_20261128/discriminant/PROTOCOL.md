# From-scratch six-layer direct writes with a discriminant shared gallery

The earlier post-hoc calibration established that the original random-target ridge write can change ranking while yielding poorly calibrated probabilities. This follow-up changes the objective used by the direct method and keeps the original 72-prompt encoder, raw width-96 weights, same seven writable matrices, actor splits, seeds 137/311/557 and scores. The previously observed CREMA-D cohort is explicitly reused. This is exploratory.

At each hidden read, evaluate both modalities through the current stage, form class centroids of the provisional last-position residual for the complete observed batch, and solve one ridge system to move each example halfway toward its class centroid. This requires alignment labels during training and uses no downstream adjoint. Use the exact original ridge regularizer. The shuffle control assigns a common permutation of the hidden targets' labels to the paired examples. The head-only control leaves all six reads at initialization. At the final layer fit a shared Fisher projection using the observed pooled within-class and between-class scatter of audiovisual and text features, shrink within scatter by 0.05 times its trace per coordinate, and keep at most classes minus one discriminants with positive eigenvalues. Embed those row vectors in the first rows of the original 256×96 output matrix; all methods use the original cosine score and 72 text encodings. This rule requires labeled examples of the gallery classes during training.

Use exactly two fixed prefix lengths, 16 or 128 minibatches of 16, using the original sample-index generator. In the comparator, train the same seven matrices by the original contrastive AdamW update at those prefixes. Each independently initialized control reconstructs all work from the same inputs. The primary endpoint is raw 72-way held-actor NLL. A secondary endpoint fits the same temperature in [0,4] and adds the training-class log-prior, as in the prior calibration. That common prior is learned from the entire training label set and declared in advance for this analysis. Development selection over the two prefix lengths uses only the corresponding form of development NLL. Freeze candidate weight hashes, selected prefixes and all temperatures before opening this study's 1,311 held examples. Report raw and secondary top-1, actor-paired intervals, and all three seeds' joint development/held gate at 4.1. Include preparation, fit, development, calibration and cold scoring in the charged per-method times; train-to-common-quality requires individual seed agreements. Hyperparameters, label-dependent target design, this cohort's prior use, and frozen non-written weights delimit the claim.
