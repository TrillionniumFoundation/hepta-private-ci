# What can a finite set of boundary queries tell the next layer?

This study fixes the live mass to one and the current free boundary to the same known value in every trial. The unknown state is the probability vector on the current grid. Refractory mass is zero. This lets a counterexample in the live population answer an identifiability question without assumptions on the hidden state. General initial populations are admitted. A specific dataset or reset process may visit a smaller set.

The grid is the repository's uniform log-margin grid on [0.015, 1.30] with 12, 32 or 64 atoms. Set sigma = 0.23, mu = 0.08 - 0.02 - sigma²/2 and step length 0.25, matching the published-law population defaults. For log-margin x and duration t, define h(x,t) as the exact frozen-boundary first-passage probability. h = 1 at and below contact. For positive x it is Phi((-x-mu*t)/(sigma*sqrt(t))) + exp(-2*mu*x/sigma²)*Phi((-x+mu*t)/(sigma*sqrt(t))). A known exogenous change s shifts all log margins, so g_i = h(x_i+s,0.25) is the next-step target. A negative s moves live mass toward contact.

For each grid size compare five port budgets: the constant boundary alone (zero population queries), the single h(x,0.25), the existing four horizons (0.08, 0.125, 0.5, 3), eight logarithmically spaced horizons between 0.04 and 6, or the same existing four plus four horizon-0.25 probes at shifts −0.20, −0.10, 0.10 and 0.20. Targets use shifts −0.175, −0.075, 0.075 and 0.175. Evaluate exact observations and independent per-coordinate errors bounded by 0.0001 or 0.001. The fixed set of queries can be known at both endpoints; data-dependent query selection would require its own communication accounting.

Let Q map a live population p to its probe values. The receiver sees y = Qp+e with |e_j| ≤ ε and predicts gᵀp. The exact minimax absolute error over all probability vectors and allowed noise, including nonlinear decoders, is

    R = min_(c,a) ||g - c1 - Qᵀa||∞ + ε||a||₁
      = (1/2) max_(p+,p-) gᵀ(p+−p-)
        subject to p+,p- in the probability simplex and ||Q(p+−p-)||∞ ≤ 2ε.

The upper bound follows by using c+aᵀy. For the lower bound the two allowed observation boxes intersect at the midpoint, while their true targets differ by gᵀ(p+−p-). The equality follows by ordinary finite linear-program duality. More explicitly, dual variables u,v from the positive/negative approximation inequalities satisfy 1ᵀu=1ᵀv, 1ᵀ(u+v)=1 and ||Q(u−v)||∞≤ε, giving p+=2u, p-=2v. Unused mass in a dual solution with the equivalent weak mass inequality can be restored to both distributions at the same atom. The actual upper and lower witnesses determine how close each numerical solution is. If ε=0, an exact global predictor exists precisely when g belongs to the span of the constant and the probe rows. If ε>0, large coefficient norms amplify sensor noise.

Archive the affine coefficients and both probability vectors for every cell (180 pairs of problems). Check witness feasibility, duality, CPU special functions, and a tensor-device implementation of the exact first-passage formula. For each grid/port combination use 8,192 deterministic synthetic probability vectors drawn from Dirichlet distributions with common shape 0.3 and verify the observed error against the bound, including the worst allowed noise sign for each state. Each endpoint records the accelerator queried inside the runtime. The linear programs run on the CPU; in the cloud, the independent witness and population replay run on CUDA. This synthetic test measures information loss for a specified port and next-step query, without making speed, learned-accuracy or reachable-state claims for an encoder.
