# A reachable-state counterexample for the stock HCSN free-boundary port

Two actual histories of the single-unit stock `BoundaryPopulation` start from the same reset, emit precisely the same current log boundary, and have different flux on the next common input. The construction requires neither arbitrary simplex states nor changes in network parameters between histories.

Use the stock step-boundary implementation, `dt=0.25`, volatility 0.23, its original reset and equity/credit prices, and 32 transport atoms. Set the input sender weight to one, its bias to zero, and the recurrent and financial feedback weights to zero. These are permissible fixed weights. Enumerate all six-frame histories on {-0.55, 0, +0.55}, append 0 to each, and start each from the standard reset. In control history 546, the six inputs are (+,−,+,−,+,−). In history 548 they are (+,−,+,−,+,+). The common seventh input sets both emitted log boundaries to exactly zero. Given the same eighth input +0.77, their next emitted first-passage fractions are 0.3321584241303591 and 0.11317150183609612. Half the gap is **0.1094934611471315**. Any memoryless decoder of the common boundary alone incurs absolute error at least this large for one of the two histories. A receiving layer with its own recurrent history can distinguish past messages, so the result is scoped to decoding from the current port.

### What extra measurements buy on the reachable dictionary

For each port vector, assume an independently bounded deterministic perturbation of each transmitted coordinate by at most ε in its stock numerical units. Two histories may produce the same received vector exactly when their Chebyshev distance is at most 2ε. The worst-case absolute error of the optimal unrestricted decoder on this finite dictionary equals half the largest target gap over those pairs. The lower bound follows from the two histories; at any received vector, returning the midpoint of the largest and smallest compatible targets attains the upper bound. The convex ensemble columns below allow a population to be a mixture of these reachable single-history populations. At a fixed common boundary, its original message components and next hit are linear in the mixture. An affine fit with deterministic-noise penalty gives an upper bound; a pair of indistinguishable sparse mixtures attains its lower bound. Mixtures need not each be reachable from one shared control history.

These values use the same unselected +0.77 eighth input. All 120 combinations cover transport resolutions 12 and 32, each of four fixed future inputs, five ports, and ε = 0, .0001 and .001. Infinite-precision flux uniquely indexes the 729 trajectories in these finite panels. At ε=.001, 31,188 pairs of 32-atom trajectories collide through the scalar flux, compared with 341 through the priced coordinates and 318 through the seven-dimensional port. Bounds depend on coordinate scaling, the finite history family and additive error. The continuous-network architecture sends the constant common boundary as well when configured for the priced or augmented ports; adding its identical value has no effect here. These measurements do not estimate learned task accuracy or imply a necessity theorem for all possible state encodings.

### Reproduce

Run `generate.py` beside the pinned `population.py` and `he_xiong.py` using Torch and NumPy. The original generated arrays are in [reachable.npz](reachable.npz), SHA-256 `53d2a42d920ce141d5d7c59d16aa1e239b9b2ca25279063989b92c2c4ce2221a`. Use `reachable_bounds.py` with SciPy HiGHS to enumerate pure-state overlaps and compute both mixture certificates. Run `reachable_replay.py ../../resolvent` in this directory using only NumPy and SciPy and the independent contract resolvent; it computes boundaries, first passages, binned killed transitions, prices and trajectories again from the controls. On both grids it reconstructed the stock final states within 1.35e−15, financial and passage messages within 1.74e−14, all next-flow targets within 8.33e−16, and every finite-dictionary radius within 2.78e−16. Its largest independently recomputed gap between feasible mixture lower and upper bounds was 9.13e−10.
