# Autoregressive image captioning from a pure six-layer HCSN temporal backbone

The pre-existing full-stack RSICD protocol used teacher-forced next-token scores and image permutation. This new, separately identifiable trial measures actual unprompted caption generation. Preserve the pinned full-stack architecture, vocabulary, matched training image-caption selection and image split. Use the original raw-RGB 32×32 pixels, 6,311 training images, the original deterministic 128-item development subset drawn from 742, and 964 test images. Match the public natural-language references for each test filename using the original-author corpus. Record the reference counts and duplicate reference rate.

From random initializations 109, 271 and 463 fit the 11,101,984-parameter literal He–Xiong, smooth-price and LIF controls and the 10,860,512-parameter native causal-SDPA network. In all twelve cells the six mixers use the named operation at all six layers, and the tied output head uses no extra attention decoder. Reuse the original FP32 batch-eight cross-entropy on real caption tokens, source training image sampler, AdamW lr .0005, weight decay .01, clipping at one. Record at least 60, 300 and 900 actual optimization wall seconds per cell, excluding validation, file I/O and initialization from the gate but reporting those costs separately. Use at most two new one-thread native CPU workers on the operator with the verified original pixels. Report actual process CPU seconds, updates, token exposures and unique training images. Persist optimizer state and seed sequence. Select lowest teacher-forced NLL on the prescribed development subset from the three saved states, breaking ties by earlier active-time gate. Seal all twelve selections and their 900-second endpoints before first evaluation of test labels or scoring of generated captions. The trial is separate from any ultimately recovered earlier 300-second checkpoint.

Generate each held caption from its image and BOS only. At each step take the argmax over the entire original 850-word vocabulary, masking only PAD and BOS, stop at EOS or at the 16-word training horizon, keep emitted UNK literally. No beam search or tuning using test text. Score every generated caption against all original human references tied to that image, using corpus unsmoothed BLEU-4, multi-reference ROUGE-L (beta 1.2), CIDEr-D with four n-gram orders and Gaussian length penalty sigma 6. Tokenize captions as the source's lowercased alphanumeric word runs. Report number of distinct generated captions, fraction hitting length cap, empty output, distinct n-grams, and a cyclic within-test negative image pairing. Pair generation metrics by image across the three data-aligned seeds, using 4,000 bootstrap samples for per-image CIDEr-D and ROUGE-L. Conditional on this domain, fixed images, chosen seeds and tokenization. Teacher-forced NLL on 11,756 real tokens accompanies free generation. Two cheap baselines provide most frequent source training caption and nearest source training thumbnail caption (4×4×3 spatial averages, train-standardized Euclidean distance). Report original reference duplication and distinguish scoring overlap from human judgments. The corpus is a natural-language remote-sensing domain, and the experiment does not train a universal language or multimodal foundation model.
