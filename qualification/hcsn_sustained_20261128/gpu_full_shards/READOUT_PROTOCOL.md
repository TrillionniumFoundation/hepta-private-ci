# Pooled readout selection

For each model and seed, standardize the 256 embeddings by the population mean and standard deviation of the 4,984 training rows, with a standard-deviation floor of 0.000001. Center the target by its training mean. Fit an intercept and a ridge map with squared loss. The regularization grid for the averaged covariance is 0.0001, 0.001, 0.01, 0.1, 1 and 10. The score multipliers are 1, 4, 16, 64 and 128. Minimize development cross-entropy with row-major grid order as the deterministic tiebreak. Export all selected maps and their hashes before computing held scores. Use all splits' original 72 fixed labels and highest-score top-1. The prompt target is each clip's reference row from the original frozen 72×256 prompt matrix. Use a raw dot product of the ridge-predicted vector and each candidate prompt before the selected multiplier. The unfitted audiovisual–text score uses the original encoder's factor of 12. The raw-input Gaussian projection has only the class readout. The six-volume feature encoder is never trained on labels.

The stored full original feature tensors allow an independent per-coordinate hash check. For the pooled ensemble summaries, average each seed's per-row losses, then aggregate rows. Also report individual seed metrics and paired actor bootstrap intervals for literal-minus-smooth, literal-minus-LIF, literal-minus-SDPA and literal-minus-raw. Cluster bootstrap uses seed 66541 and 4,000 resamplings of the 16 original held speakers. The means and intervals describe this population split and the fixed seeds.
