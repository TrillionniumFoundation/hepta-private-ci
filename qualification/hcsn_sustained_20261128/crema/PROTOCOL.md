Use the six-layer AVText encoder, financial table, raw prepared clip arrays, fixed actor splits and prompt gallery from the parent CREMA-D experiment. This independent CPU study tests whether sustained training changes the near-chance short-budget outcome and whether predictions require the explicit cross-layer boundary wire. The original billion-parameter GPU queue retains its own separate experimental identity. The current study has six width-96 layers with sixteen four-atom populations on the physical arms, or native causal scaled dot-product attention. There is an ordinary residual stream in every arm.

Use the literal financial cell, matched smooth-price cell, hard LIF with the original surrogate backward, and causal attention. Use seeds 137, 311 and 557 and a separate deterministic train-index generator shared across arms for each seed. Train all weights from random initialization with the original symmetric multi-positive contrastive objective, batch 16, AdamW at 0.0003, decay 0.01, gradient norm limit 1. Use a single Torch CPU thread and FP32. Evaluate at 16 and 128 updates and after 20, 240, 1000 and 3150 s of actual optimization per cell. If a cell has yet to reach its fixed-update milestone when the terminal clock expires, retain the observed comparison as unavailable for that milestone.
