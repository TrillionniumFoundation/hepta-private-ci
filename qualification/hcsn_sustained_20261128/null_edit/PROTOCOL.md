# Applying the AlphaEdit null-space constraint to an existing audiovisual HCSN

This is a controlled factual-relabeling study on a previously trained HCSN. It tests the explicit null-space projection from AlphaEdit on the original shared 256×96 head. It does not reproduce AlphaEdit's LLM localization or optimized target-value pipeline. Use all three previously sealed and cold-scored same-site BP parents chosen by minimum original development NLL in the first finite width-96 study. Do not use any still-unsealed sustained-training checkpoint. The experiment uses the previously studied CREMA-D actor splits. Fix the edit before any new scoring: for the first transcript (DFA, label indices 0 through 5), change the requested emotion to the next one cyclically; the other 66 prompt assignments keep their original authority. This is a deliberately synthetic knowledge update. Read actor-disjoint development and held subsets only after all candidate matrices are fitted and hash-sealed, with no candidate selection.

Use every available training clip of the edited transcript. Target each audiovisual feature's projected vector toward its newly assigned parent text direction, scaling it to the example's original projected norm. Keep all seventy-two training-independent gallery text keys as protected exemplars. Protect them alone, or add exactly 8 or 32 random retained-task audiovisual training anchors (fixed NumPy seed 47000+parent_seed). Determine the nullspace of the stacked protected keys in FP64 using an SVD rank tolerance of 1e−7 relative to the largest singular value. Solve the ridge problem in the reduced basis with λ equal to 0.01 times the mean diagonal of the full edited-key Gram matrix, and write the result in the original FP32 head. Retain the zero-update outcome if protected keys span the entire input. Reference methods are unchanged parent, unconstrained ridge using the identical edited targets, and 16 FP32 AdamW steps on the same supervised regression target plus protected-vector mean squared error with equal weight, lr 0.001. The latter uses the same shared matrix and 8 protected audiovisual anchors. Report end-to-end costs for key acquisition, fit and new scoring separately. The 16-step choice is fixed, not a time-to-equal-quality benchmark.

On held actors report edited-subset and retained-subset 72-way NLL and top-1, raw projection drift on protected keys, generalization of preservation to untouched held prompts/AV, actual numerical rank and null dimension, and changes in text gallery and clip predictions. Pair differences against unchanged parent by actor and training seed. Also report the predeclared within-six-emotion score for edited clips as diagnostic. Static function agreement on a finite subset of protected feature vectors does not imply preservation of every unobserved activation. The parent is weak on the gallery task and the synthetic cycle changes its labels; conclusions are limited accordingly.
