## Immediate executable order

1. The original deployment owner identifies the existing descriptor paths and supplies the pre-held process capability to the existing read-only `diagnose-native` entry. The current bounded evidence has not authenticated these MEM-specific descriptors.
2. The original embedding recovers the canonical writer and installs the authenticated source adapter. The normal environment startup leaves both writer and episodic ingress absent; the adapter is still a real deployment integration input, not a JSON file that an import request may select.
3. Reconcile the namespace through the ordinary import client, then use the existing native inference entry with the original final-use authority and retained request identity. Capture actual model exposure for a future memory off/on comparison.
4. Recover the same canonical/effect state under an authorized successor generation, then reconcile pending original effects against the registered destination. This is the uncompleted owner/effect milestone.
