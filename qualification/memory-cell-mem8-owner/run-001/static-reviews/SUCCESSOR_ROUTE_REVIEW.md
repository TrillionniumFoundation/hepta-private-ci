## 3. The intervention surface is not yet one end-to-end experiment

The Python prototype already offers `off`, `retrieval_off`, `association_off`, `delivery_off` and the four retained strategies. Its receipt reports actual call paths. It freezes the source allowlist and verifies selected records, authority, generation and revocation frontier again after ranking and before constructing the delivered context. That last-read point is an in-call linearization boundary; it does not fence a later external effect. [Python implementation](https://github.com/TrillionniumFoundation/hepta-private-ci/blob/66f570a77c60aac8d33e6cbeac8dfd120ef1d867/scripts/ndu_real_runtime/episodic_retrieval.py)

The native driver currently exposes an optional context query. `None` withholds that explicit owner-context path; `Some(query)` performs retrieval and attaches the returned snapshot. It does not expose separate native controls for retrieving-and-withholding delivery, pinning an external association head, or selecting the Python exact-KV/BM25/uniform/ICL support. Its durable source payload digest includes the query option, prompt, owner socket and timeout. [Native admission and replay identity](https://github.com/TrillionniumFoundation/hepta-private-ci/blob/0c32926cfec58d986477fc72ba3a4787ab75fde9/codex-rs/hepta-infer-worker-host/src/native_run_control.rs)

The following are concrete engineering increments before a causal real-successor comparison:

| Required contrast | Existing partial mechanism | Increment needed at the real actor boundary |
| --- | --- | --- |
| Memory off/on | Optional native context query; F2 disables alternate implicit memory paths | Register an explicit intervention in the durable request identity. Give both arms the same authorized predecessor history and fresh successor input; ensure off cannot resume predecessor conversation/KV or read another memory path. |
| Retrieval off/on | Python receipt can show store view without retrieval; native query `None` skips the whole explicit path | A host-owned read policy with a real retrieval-call receipt and fixed store/current frontier. Preserve model/tool/budget parity and distinguish whole-path memory-off from retrieval-off. |
| Delivery off/on | Python can retrieve/rank while omitting actor content | Native support for retrieving the same support but withholding the AdditionalContext attachment, with the intervention bound into the source admission/payload identity. Record both retrieved support and actual attached bytes; do not infer consumption from a retrieval receipt. |
| Association off/on | Optional actual Python head callback; absent head is explicitly `unavailable` | Pin a real head/version and invoke it over the identical eligible support. Its output may rank admitted records, not mint source authority. Keep final current-source/owner revalidation on the actual selected set. |
| Exact KV, BM25/RAG, ordinary ICL, uniform replay | All four exist in the Python read strategy surface | Map each strategy's admitted support into the actual native owner-checked context path under the same history and byte/token budget. Do not paste unauthenticated Python text into the actor as if it were a canonical snapshot. |

The fixed public selector already has a precise working-state profile hash, but the native cognitive retrieval/ranker is a different selection boundary. Holding the working-state selector constant does not prove the native episodic selector is constant. The new protocol needs to name and freeze both applicable boundaries. The current native context limit is four items, while ordinary ICL/history budgets must be explicitly matched; a larger ICL context cannot be assumed from the current API. [Fixed-public plan](https://github.com/TrillionniumFoundation/hepta-private-ci/blob/66f570a77c60aac8d33e6cbeac8dfd120ef1d867/scripts/ndu_real_runtime/candidate_retention_public_plan.py) · [Native context constraints](https://github.com/TrillionniumFoundation/hepta-private-ci/blob/0c32926cfec58d986477fc72ba3a4787ab75fde9/codex-rs/hepta-agentd/src/cognitive_context.rs)

For exact KV, keys must be available to the actor rather than evaluator answer identifiers. The prototype's `uniform_replay` is uniform record sampling at read time, not optimizer/training replay. Ordinary ICL must receive the same authorized experience and charged context budget. A missing association head remains unavailable. These are already explicit requirements of the [MEM6 protocol](https://github.com/TrillionniumFoundation/hepta-private-ci/blob/66f570a77c60aac8d33e6cbeac8dfd120ef1d867/qualification/memory-cell-mem6/PROTOCOL.md); they are not new measured outcomes.

## 5. Minimum real-task registration after the path gate

Freeze ordered predecessor/successor sequences with the same model, prompts, permitted tools, seeds, initial effects, history, memory budget, schedule and independent graders across arms. Preserve all planned pairs and original request IDs. The source families should cover current-fact replacement, explicit withdrawal, dependency propagation, cross-document support, similar wording requiring different source-specific procedures, distractors, wrong-source lookalikes and unanswerable/abstention cases. Each family must have a rubric that depends on predecessor information rather than repeating the already solved prompt with its answer.

Register one primary memory on/off comparison with the selector held fixed, then mechanism ablations using the same source cohorts. Keep exact KV, BM25/RAG, ordinary ICL and uniform experience sampling as predeclared baselines. The old-state and revocation controls must use the current authoritative frontier; restoring a file is not permission to restore a withdrawn fact. Each failed admission, timeout, unknown ACK, no-op and bypass stays in the original denominator and evidence ledger. Actual terminal success and complete attributable intervention evidence are separate fields.

For inference, the existing working-state helper averages paired differences within source and weights sources equally. It hardcodes the `current_only`/`bounded` working-state contrast, uses a 20,000-draw role-stratified bootstrap and a 95% one-sided bound. It cannot be reused unchanged to certify the four prospective E baseline comparisons. The existing E protocol specifies 98.75% one-sided bounds for those four comparisons, with preregistered adjustment and source-level replication. Prepare a new exact analysis plan before the new references/outcomes are accessed, rather than changing the existing helper's modes or thresholds after the fact. [Working-state inference](https://github.com/TrillionniumFoundation/hepta-private-ci/blob/66f570a77c60aac8d33e6cbeac8dfd120ef1d867/scripts/ndu_real_runtime/candidate_retention_inference.py) · [E acceptance](https://github.com/TrillionniumFoundation/hepta-private-ci/blob/66f570a77c60aac8d33e6cbeac8dfd120ef1d867/qualification/memory-cell-mem6/ACCEPTANCE.json)

## 6. Inputs still needed for a deployed-owner successor run

The exact host route requires the existing Agentd identity, spawn generation, home/run layout and retained `AgentdProductionWriterHost`, including its live production authority lease, original verifier and exact current cut. The episodic source adapter must independently observe the full current namespace, actual fact bytes/metadata and withdrawal evidence and return typed admission; no default deployment implementation was located. The native caller additionally needs its existing final-use issuer binding/journal and any actual effect owner's preserved state. The sibling `OWNER_BINDINGS_REVIEW.md` records the inspected metadata and the limits of that inspection.

A reachable llama endpoint or generic secrets account does not establish any of these memory-owner bindings. The private fixture makes the joined code path testable without substituting itself for the original deployment. Keep the milestones separate: source review/replay, zero-model native controls, actual synthetic provider context use, registered unseen successor benefit, and original-owner/trust/effect cold recovery.
