# Distinct crossed-execution receipts

Linux research wrapper for an explicitly registered NEW train/dev run.
Before output creation it binds registration/config bytes, the nine source
files, runner bytes and both original DESIGN and new EXECUTION registrations.
The child imports isolated source copies with one BLAS thread. Create-only
start/terminal receipts preserve argv/env, process identity, child/wrapper
exits, source drift/read errors, logs, RESULT hash and checkpoint inventory.
Fit outcomes are not parsed. Timeout termination affects only the new session.

The scoped package passed 118 tests. Six wrapper cases include actual tiny
8-fit fixtures with unrelated seeds, identity/config rejection, launch failure,
source drift/missing files and timeout-exit races. Child success cannot hide
outer SOURCE_CHANGED failure. Linux-only cases are skipped on other systems.
just fmt/Ruff passed with unchanged tested ASTs; original final test log is
compressed beside the source/validation receipts. Earlier unpublished 116-test
validation preceded the source-drift/timeout corrections and is not added to
the final denominator. No formal 189-fit campaign has started in this stage.

CPU spans and cumulative child RSS high-water are separate; final receipt
serialization/fsync, energy and currency are not complete physical costs.
Caller commit declarations are not remote authentication; file fsync is not
atomic publication or power-loss durability. Missing originals remain missing,
old confirmation stays sealed, and qualification stays HOLD.
