# 三模态实验的适用范围

每个片段使用同一份公开的 MMSA 对齐输入，文本为 768 维 BERT 表示，声学为 5 维，视觉为 20 维。每个坐标按训练集标准化，三个模态按维数平衡，然后将一段话压缩为六个按词序排列的时间组。组长随话语而变，资料不提供本实验可用的统一物理步长。声音与画面中的高频结构只有在原提取器和六组汇总保留时才会影响结果。

物理单元使用有限价格表的双线性插值。内部状态保存上一时刻边界、下一步的条件均值近似及由权益和定价损失生成的反馈。前两层向外传递已标准化的对数相对边界，最后一层给出边界、权益、定价损失与限期首达概率。定价表还含下一步均值供内部状态传播。O’Shea 与 Rajendran 的前向投影规则为每个真实隐藏矩阵构造局部最小二乘目标，最终再单独拟合情感读出。所有 FP 候选均在推断模式或显式线性代数下写入隐藏层和读出。原定价库构造对象时还计算了基点上的两个标量导数，这两个导数没有进入定价表生成或三模态隐藏参数求解。独立梯度核验与 BP 对照均调用了自动微分。

相同宽度下，对应 FP 与 BP 物理网络的权重形状完全相同。前向构造每次写入隐藏矩阵后，用完整训练特征估计该层的固定均值与方差；物理 BP 与冻结随机特征用预定的 192 个训练片段进行初始化校准。两组普适对照还有两个差异。ReLU 末层每个单元只有一个读出通道，物理模型有四个。Transformer 对六组输入双向注意，真实参数数分别公布。所有可学习权重均从随机值或零监督的随机投影起步；BP 与 FP 使用同一训练与开发分组，且有各自登记的学习率或岭惩罚候选。

正式外部终点为 31 个完整源视频各自的绝对误差均值，再对视频等权平均。普通按片段合并的绝对误差、相关系数和剔除零标签的正负分类正确率另列。不同片段可能来自同一人同一视频，分层自助法成对重抽整段源视频及随机种子，共 10,000 次。三个初始种子限制了对训练随机性的推断精度，确定性原始特征岭回归的三个种子给出同一解。登记的单侧 +0.05 上界在统计学上是非劣条件；同时给出整个区间是否落在 ±0.05 内，便于严格阅读。三个尺度上九个单模态错配的同时区间采用 Bonferroni 调整，其他带区间的分项按探索性逐项理解。屏蔽输入和跨视频交换衡量当前预测函数对已提取表征的依赖，强行错配也会改变输入联合分布。单次研究没有干预原始视频和人类感知。

15、60、180 三档为每个方法与种子的累计单线程 CPU 预算。按开发损失封存后才评价外部结果。首次观察到三种子全都达到目标的预算档是离散的；时间包含共享特征预处理的完整开销、拟合进程启动、优化与开发选择、所有选中模型的保存、冷测加载与完整预测。预算截点之间的选择耗时使用下一次完整评估发生时刻给出保守上界。并行负载使实际秒数有波动，原始记录同时保留 CPU 和墙钟。额外报告一次性从出版公式生成价格表所需的实测时间。已发布的 BERT 和音视频特征提取、分发下载的耗时无法由该实验测得。冷测干预、证据存档及审计开销另列。

Rahman 等人在 ACL 2020 的同一 MOSI 对照中报告按片段 MAE，固定 BERT 表征的 MulT 为 0.861，微调文字 BERT 为 0.739，MAG-BERT 为 0.712。Yu 等人在 AAAI 2021 同一规模的切分上重新训练 MAG-BERT 得 0.731，Self-MM 得 0.713。两篇工作采用各自的特征和优化条件，适合与本实验的片段 MAE 比较质量量级。本研究的同预算墙钟比较只使用本机记录。[ACL 原文](https://aclanthology.org/2020.acl-main.214.pdf) · [AAAI 原文](https://cdn.aaai.org/ojs/17289/17289-13-20783-1-2-20210518.pdf) · [前向投影原文](https://doi.org/10.1038/s41467-026-69161-1)
