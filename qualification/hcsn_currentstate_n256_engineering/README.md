# N256 sparse-operator resource pre-admission

**RED_RESOURCE_CAP_HOLD / HOLD_NO_NUMERICAL_EXECUTION / all_closed=false.**

This independent stage consumes the exact new-export-only N256 input bundle and
the #6294 symbolic roster identity. It materializes the sparse CTMC/block
operator topology solely to bind dimensions, nonzeros, packet lineage and
resource lower bounds. It does not propagate state, call a matrix exponential,
run a numeric oracle or serializer, invoke Torch/backward/optimizer, or train.

The N128 raw caps are comparison controls, not an amended N256 allocation.
Exceeding them is a retained negative result. No threshold is raised and no
large-grid qualification is issued. A future numerical stage still requires an
N256-specific workspace/RSS bound, full-state serializer and independent oracle,
durable host+cgroup headroom and a frozen calendar.
