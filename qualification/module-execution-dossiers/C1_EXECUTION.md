# C1 product-host and cross-process acceptance contract

Scope: `C1-PROMPTED-MEMORY-RETRIEVAL-RANK` under existing package/DAG requirements. This specifies a native harness and its expected observations; it does not claim that a new product host or CLI already exists.

## 1. Three distinct modes

`reference` uses deterministic analytic oracles and labels all outcomes synthetic. `product_fixture` uses the actual app-server/agentd path, real owner persistence and authenticated fixture identities in an isolated test deployment. `product_observed` additionally binds the real selected model/device and independently observed task outcomes. A report cannot upgrade its mode because its numeric metric is good.

The initial task is a bounded read-only retrieval/report action. It records authorized internal ledger/artifact writes, but zero Memory/KG source mutations and zero external tool/provider/physical effects in the deterministic reference mode. Real model use in a later mode is explicitly granted and measured, not hidden behind a zero-effect claim.

## 2. Frozen harness profile

The owner must supply exact source/tree, build target, executable digest, existing or newly implemented host entrypoint, argv/configuration digest, OS/architecture, process generation, body/objective/artifact tuple, store descriptors, fixture dataset, port bindings and observer/evaluator/selector identities. The adapter manifest states which are real and which are fixtures.

Do not assume imaginary command-line switches. A native harness maps this profile to actual exported APIs and executable entrypoints and compiles that mapping. Missing product caller/store/identity yields `integration_binding_required`, not a passing fixture substituted for deployment.

Expected source reuse includes deterministic NDU exports, native DurableLedger, native artifact payload/registry storage, CognitiveStore semantic parity with the new durable owner adapter, and the selected Neuron profile/journal when enabled. Python analytic references never become the product ledger or a second model spine.

## 3. End-to-end trace

The request compiles to immutable objective IR. Cognitive owner ports provide a coherent scoped snapshot. Retrieval records the complete bounded generator-relative legal candidate set and any preassignment truncation. A preregistered selector chooses an arm and logs its actual probability before the outcome is known. NDU and neural advice remain bounded and advisory.

Prompt selection includes no-intervention. Context compilation binds exact sources, tokenizer/template/tool schema, placement, costs and omissions. The actual Codex request assembly revalidates current revocations and emits a matching delivery observation; compile-only is not exposure. The report remains read-only in the task domain.

The observer independently records task success, stale/citation/contradiction outcomes, costs and finality. Learning owner appends/syncs events and acknowledgement anchors. Reopen the native ledger in another process. Freeze an eligible dataset with current exclusions. Train a bounded candidate, evaluate on disjoint data, store immutable bytes and registry events, and obtain a separately issued selection decision.

Drain the first process. Start a distinct process generation with the exact selected artifact tuple. Demonstrate changed behavior on the reserved engineering probe set and match its loaded artifact digest. Then request a compatible, non-revoked rollback and start another generation. The predecessor behavior must return on the same engineering probes, while current revocations and accepted history remain intact.

## 4. Engineering probe dataset

Use named synthetic fixtures that cannot be confused with future-calendar efficacy: a fresh supported fact, an expired source, a high-risk contradiction pair, an unauthorized principal's otherwise identical query, a mandatory-provenance budget overflow, and a source revoked between ranking and delivery. Exact expected dispositions are supported read, stale rejection, abstain/slow path, scope denial, insufficient_context and stale/revoked attachment denial.

The changed-behavior probe includes two legal ranking policies with different deterministic ordering on an otherwise fixed scoped candidate set. It proves loading/behavior change, not that either policy is better. Its expected old/new/rollback outputs are frozen by the independent harness before candidate code runs.

## 5. Fault injection and invariants

Inject failures before/after decision append, actual context delivery, outcome observation, ledger sync, witness publication, dataset freeze, artifact byte sync, registry publication, selection consumption, process exit and reload. Corrupt a candidate payload; lose an acknowledgement; race a stale writer; delay/correct an outcome; revoke training ancestry; restore an old backup.

An unacknowledged committed event remains reconcilable by its original identity. An orphan artifact never becomes selected. Unknown outcomes remain pending/censored. Failed anchored recovery cannot retry unanchored. A new process cannot mix the old encoder with a new checkpoint or restore a revoked artifact. Source writes and terminal effects are independently counted, not self-reported by the evaluated policy.

## 6. Evidence output

Produce distinct exact-candidate receipts for contract compilation, storage round-trip, actual product callsites, delivery, independent outcome, dataset eligibility, training, evaluation, artifact creation, new-process load, behavior change and rollback. Include all eighteen dossier fields. General logs contain safe IDs/digests and bounded metrics, not raw secrets or unrestricted model payloads.

The harness reports missing stages individually. It never averages a failed authority/deletion/rollback gate into a passing utility score. Current full source-head and deterministic merge CI are necessary but do not replace this trace.

## 7. Transition to real learning

After engineering composition passes, use `LEARNING_EXPERIMENT.md` for independently preregistered future windows, old-task retention, subgroup/OOD support and mechanism ablations. Synthetic dates in a fixture do not count as elapsed future time. Resource/model identity is frozen or explicitly stratified; improvements caused only by buying a larger model are not attributed to NDU or neural mechanisms.
