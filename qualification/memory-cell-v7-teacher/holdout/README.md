# V7 独立代理编写的合成留出集

本目录由 `/root/semantic_holdout_v7` 独立编写，用于六操作路由的下一次冻结比较。它不是人类标注集、真实用户对话或生产业务样本，不证明开放域语言理解能力。

## 输入与标签隔离

`requests.jsonl` 共 180 行，每行严格只有 `utterance`、`series_name`、`date`。这三个字段是唯一允许交给候选的输入。

`labels.jsonl` 只供评价器读取，使用 `index` 和完整 `request_sha256` 绑定请求；`expected_intent`、`family`、`family_item` 和 `id` 都不得进入模型输入或路由器。不要根据预期标签重新排列请求。原顺序已经用固定种子打乱。

| 操作 | 请求语义 | 条数 |
| --- | --- | ---: |
| `at` | 指定月 t 的已记录数值 | 20 |
| `previous` | t 的前一个日历月的已记录数值 | 20 |
| `change` | t 的值减 t−1 的值，保留符号 | 20 |
| `mean3` | t−2、t−1、t 的等权算术平均 | 20 |
| `range3` | 上述三个月的最大值减最小值 | 20 |
| `peak3` | 上述三个月的最大数值 | 20 |
| `__reject__` | 其他方向、窗口、地址、统计量、输出形状、复合结果、推断、修改或跨序列请求 | 60 |

60 个拒绝样本分为 12 个审核类别，每类 5 条。标签按照请求操作而非偶然数值相等判断：例如单元素窗口的最大值仍是契约外操作。

## 结论边界

这是一名代理同时编写输入与标签的有限英文合成测试，尚无独立人类标注审核。精确去重不保证语义独立，手写改述可能仍与公开训练材料共享句法和词汇。指定的序列和日期只用于输入契约，不是生产数据回放；本目录不评价数值执行、持久化、权限或工具恢复。
