## Executable contract

`assess_episode(plan, episode, evidence_loader, observation_verifier=None)`
requires authenticated observations for timeline, isolation, memory, provider
and costs. All bind one case; memory and costs also bind both reader sessions.
There is no default trusted verifier.

A exits before the new C processes start. The same frozen actor, public selector
profile, public_rule mode, selector source/configuration, query/key, retrieval
bounds and public C task are checked. Raw launcher receipts must bind full
stdout/bootstrap/actor-output/stderr bytes, sealed input transport, nonreused
sessions/processes, empty initial private state and distinct host/child namespaces.
Memory-off has exactly zero context bytes; on-context must match actual retained
bytes. Return status, exit code and monotonic timing must be consistent.

The current handoff supports **one physical request per arm**. The physical body
must equal the corresponding isolated actor-output bytes, and each request binds
its exact launch, session and case. Complete settled request/result observations
are required. Tool loops need a separate contract. The trusted provider observer
must additionally authenticate headers, full failed/retry journals, server
conversation/cache state and absence of appended host history, tools or memory.
Byte equality cannot prove those external properties, and no real provider
adapter is supplied or executed by this checkpoint.

Write, retrieval, compression and wrong-memory costs are recorded separately for
both arms with explicit units and original bytes. They are not blindly summed.
Unknown or unauthenticated inputs remain HOLD. Every planned HOLD/failed row
must remain in the experiment denominator; this module is not an outcome filter
or statistical adoption decision. ELIGIBLE_FOR_SCORING never means benefit.
