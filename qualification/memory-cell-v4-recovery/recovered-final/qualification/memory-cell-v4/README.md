## Implemented scope

V4 extends the existing Hepta memory research in three bounded directions:

1. A fitted language policy and learned typed layout are frozen and reused across
   four previously seen scientific series and two views of newly written retail
   events. Independent authored language is materialized only after the common
   source/protocol freeze. The serving router receives only an utterance and its
   explicit series/date slots.
2. Event cells learn signed integers and direct UTF-8 byte coordinates, without a
   categorical answer dictionary. A procedural cell fits affine maps from
   demonstrations. New inputs test composition with event reads. Ordinary exact
   codecs and ordinary least squares remain explicit strong controls.
3. The structural controller pays for complete candidate partitions, migrations,
   consolidation and actual pair merges. Changing regimes are compared with
   naturally costed fixed structures and separate matched-work controls.

V1, V2 and V3 code, results and failed gates remain unchanged. V3 native Hepta
integration and lifecycle evidence are inherited as historical evidence; V4
does not claim another full production build or production admission.
V3 lifecycle results apply to their original numeric owner. New Event/Affine
types do not inherit correction, revocation or retraining qualification merely
by sharing a memory interface.

## Boundaries that affect interpretation

The main numeric model uses rank 12; rank 4 remains a distortion control. Their
storage budgets differ. Exact parameter readout at higher capacity is not a
claim that trained parameters compress every source better than ordinary codecs.

The retail monthly view stores only a month-to-event-ID map. It selects the
first written event in each month by original source row, and calls the actual
event model for its quantity or unit price. These values are not population
monthly totals or averages. Timestamps and event identifiers are supplied,
charged address metadata; they are not claimed as hidden parameter answers.

Calendar navigation, arithmetic primitives, port types and the affine function
family are supplied. The layout learns composition from terminal feedback;
affine coefficients are fitted from demonstrations. This does not invent
arbitrary programs or new ontologies.

Semantic scope follows requested operation types. A request for an unsupported
window or statistic can be refused even if its value on one input happens to
equal a supported operation. Correct known coverage and unsupported acceptance
are separate gates; refusing all queries cannot pass.

There are 216 independent authored language expressions, reused across domains,
dates and five seeds. Repetition does not increase the independent language
sample size. The phrases are fixtures, not sampled human conversations.

## Execution

Use the pinned MiniLM model described by `../memory-cell-v2/MODEL_SOURCE.json`
and the Python packages in `requirements.txt` and the frozen environment receipt.
The measured runtime is CPython 3.12 on Linux CPU. The durable-owner qualification
uses POSIX file locks and directory fsync; Windows owner qualification is outside
this prototype. From this repository:

```bash
OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1 python qualification/memory-cell-v4/run_study.py \
  --base /absolute/path/to/all-MiniLM-L6-v2 \
  --output /absolute/path/to/new-run
```

The formal runner requires committed source bytes, a frozen protocol and exactly
the five declared new seeds. `--development` uses the disclosed development
seeds and the public development language instead. Every run needs a new output
directory. Failure receipts and partial outputs are preserved and sealed.

The run order is `transfer`, `typed_maintenance`, `structure`, `joint`. The joint study reuses the
already trained event artifact; its two field views do not train duplicate
event models. A new process loads a router deployment containing only its
selected parameter artifact and unlabeled serving requests. Training corpora,
candidate weights and caches remain separate research evidence.

The separate typed-maintenance experiment executes append, correction,
withdrawal, clean refit and replacement of a procedure fitted from new
demonstrations. Source versions and procedure versions are dependencies of
derived results. The owner checks them before returning an answer and when a
downstream node admits it. Historical evidence and withdrawn values are retained
for the audit and charged; interface revocation does not imply physical erasure.

```bash
python qualification/memory-cell-v4/verify_evidence.py /absolute/path/to/run
```

Byte/source verification establishes reproducibility bindings, not scientific
efficacy. Independent read-only audits recompute model reads, source provenance,
metrics, costs and gates from retained artifacts. Full source snapshots include
the exact inherited V3 implementation and the pinned data used in V4.

## Cost and qualification

Serving totals include model parameters, routes, addresses, schemas, bindings,
router, layout and view metadata. The frozen pretrained encoder is charged once
per system. Raw sources, replay, all alternative candidates, temporary fitting
arrays, caches and failed attempts are reported separately. Runtime libraries
are common infrastructure; serialized-state totals are not peak process RSS.

For changing structural flows, the new gate requires at least 5% normalized
quality gain and a net benefit under the declared natural and matched cost
models. Static excess MSE must be at most `0.01 * max(best_fixed_MSE, 1)`, and
natural priced loss must be at most `1.10 * best_fixed_priced_loss`. These are a
separate bounded-regret diagnostic, not a uniform 1% relative-error limit.
Passing them cannot rewrite V3 or establish
strict improvement on every static or random source.

`RESULTS.md` and `QUALIFICATION.json` are generated only after the formal run and
independent audits. Open empirical blockers remain open when measured gates
fail. Execution integrity, mechanisms and empirical qualification are distinct.
