# Public, independently worded transfer check

Lock this protocol after completing the generated panel and before retrieving any questions for this check. All seven candidate methods stay at the weights of commit 55bbe16b59a80090fd7dff512b5d8a12536d4372. This is historical public evaluation. The original authors are not enrolled participants in Hepta.

Use the public Stack Exchange API on Stack Overflow. Fetch page one, 30 earliest questions per search tagged python, ordered by creation, whose title contains respectively "multiples" and "divisible", through 2025-12-31 UTC. Take the union of question IDs, preserve all records in the accounting, and use the native post body outside code blocks. Two batches only. Retain fetch time, query, IDs and body hashes. Never train on these questions.

Before sending any of these texts to the candidate, read every retrieved question and assign one of three states. Eligible questions contain a contiguous original prose passage asking to print or list positive integers divisible by one fixed integer over an unambiguous finite interval with both divisor and upper bound explicit. Lower bound may be implicit one. The passage passed to the model is verbatim apart from HTML decoding and whitespace normalization. Ambiguous endpoints, requests for counts, sums, functions of runtime-valued parameters, multiple divisors, or other outputs remain visible as exclusions with reasons. Do not rewrite any question to satisfy the Cell. Publish assessment commitment, immutable input hashes, original source URL, and independently determined numerical gold before running the models. Avoid publishing full question bodies. Original attribution and licenses remain linked. If no eligible passage is found, report the zero scoped denominator. No extra query will be substituted. Report per-arm successes and abstentions on all eligible requests; the full source-selection denominator must accompany them. If access is unavailable, retain the failure and leave that denominator unobserved.

This checks independent historical wording within the limited numeric interface. Only the private, post-freeze A/B experiment can supply its separate registered-user result.
