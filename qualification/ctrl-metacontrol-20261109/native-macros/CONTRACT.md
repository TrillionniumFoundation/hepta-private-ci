# Native macro-pair artifact contract

This is a new macro schema. It is not primitive STOP/continuation evidence for
`metacontrol_study.py`; that reader deliberately rejects a hidden answering suffix.

The two declared control interventions share the same frozen terminal finalizer:

| Control macro | Actual native action sequence |
| --- | --- |
| STOP | WRITE_TEXT, STOP |
| READ | PREPARE_ROI, READ_ROI, WRITE_TEXT, STOP |

Source partitions must be explicit and disjoint from previously exposed sources.
Only registered train-role material cases are accepted for forced exploration.
Future macro collection stays sealed until a separate freeze/release path exists;
supplying an arbitrary pinned file does not enable it.

Branch artifact admission checks the actual isolation launch, raw actor event
digests, trajectory, unchanged model identity and the separately executed scorer's
exact delivery bytes and frozen evaluator/rubric. Hashes bind bytes relative to
the supplied plan; they do not authenticate a native owner.

Validation: one manufactured-artifact contract test passes. The fixture host is
explicitly manufactured and is not real model execution or scientific evidence.
