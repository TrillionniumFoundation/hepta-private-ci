## Interpretation and costs

The strict numerical comparison repeats each recorded gap indefinitely from its reconstructed posterior, with no future observations. It compares projected and continuous values of the same fixed reset/refractory policy. It is not the task-loss error or the remaining asynchronous trajectory's value error. A small Bellman residual, event replay, mass conservation or a local gradient check does not remove the continuation discrepancy.

The two local full attempts total 671.404215137 seconds of outer child wall time, including the failed attempt. Separately, hosted + local001 + local002 total 841.886366917 internal process wall / 829.780687521 CPU seconds. These are cumulative process measurements across concurrent/different-host runs, not elapsed calendar time. Tests, smoke, QVI, baseline and audits have separate receipts. Never add inner and outer timers from the same execution.

Fit costs include construction, complete state trace writes, evaluation, checkpoints and replay. HCSN section timings were not measured. No isolated inference throughput, energy, or equal-quality cost frontier is established.
