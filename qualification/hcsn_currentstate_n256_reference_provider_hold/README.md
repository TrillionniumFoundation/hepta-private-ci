Status: **NOT SCIENTIFICALLY ADMITTED / HOLD / `all_closed=false`**.

candidate and oracle. Draft #6313 freezes only that stream's interface. The two
existing numerical lanes both call `scipy.sparse.linalg.expm_multiply`, so they
do not provide the required independent numerical kernel.

does not implement or run a provider. A future provider must use a separately
reviewed implementation, currently identified only as a proposed certified
sparse-uniformization method. Before admission it must bind independently
reviewed generator/packet reconstruction, precision and tail-certificate
policies, an all-operator stiffness bound, and exact coverage of nonreturning
upper escape, deterministic delay, reset, signed content, discounted hit and
occupation. It must also bind a safe runtime, host, ancestor-cgroup,
allocation, calendar and cost envelope.

null. This source therefore rejects before imports, input reads or numerical
work. It does not change thresholds or qualify any of the 18,225,028 N256
coordinates or 14 capsules.
