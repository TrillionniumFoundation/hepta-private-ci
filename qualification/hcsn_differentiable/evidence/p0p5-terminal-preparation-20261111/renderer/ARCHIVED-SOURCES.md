# Original renderer review sources

The closure and roster-rebind source files remain byte for byte in
[`complete-preparation.zip`](complete-preparation.zip). The published
[archive manifest](../ARCHIVES.json) and the original reviews are unchanged.

Run `python3 restore_review_sources.py /path/to/new/renderer` from this
directory to recover the four files at their original renderer-relative paths.
This verifies the archive and member identities but does not run the review
programs or grant execution permission.
