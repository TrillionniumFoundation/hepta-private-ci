# Completed baseline36 and C1 independent subset reviewer

This new adapter consumes the unchanged fresh42 independent reviewer v2,
SHA256 `039dc18d0cec08135a6ba3108fe25b4493eaca61e0d0340081895ec93a97fbaf`.
The extracted `frozen-v2/` files are byte-bound in `bindings.json`. Its original
full42 entrypoint is not repurposed. The new adapter has separate source identities,
tests, output, costs and scope.

The intended production scope is the original 36 already completed baseline fits
plus exactly seven mechanically eligible C1 continuations. The six HCSN fits are
excluded. The original live command journal is captured as a non-atomic context;
it may append during review, but baseline terminal rows and every bound completed
artifact, source and ABC/D data file must remain unchanged. This is not a final42
audit and cannot grant HCSN numerical admission or scientific benefit.

The checker binds the original v8 and separate C1 source capsules, every prepared
ABC/D episode, fit/phase plans, original and continued result identities, retained
parent outer records, all claimed checkpoint/file hashes, common frozen tensors,
construction configuration, registered optimizer names and official parameter
hints, AdamW defaults, moment geometry/nonnegativity, and cumulative update counts.
Every original initialization is regenerated from the source's seeded constructor.
No optimizer step or training replay is executed.

Saved development logits are recomputed independently with NumPy and linked to
the first strict-best epoch across the appropriate full history. Six original
representatives are freshly evaluated: the first fit of each baseline core in
the declared roster. All seven selected C1 checkpoints are also freshly evaluated.
Fresh evaluation uses the exact original-v8 model definition, full batch32,
evaluation mode and no gradients. C1 inherited sources are separately compared
byte-for-byte first and by AST only when their bytes differ. This explicit choice
avoids pretending a cached Python module was re-imported from a different source.

The C1 journal adapter validates a phase-local renumbered view using frozen v2
journal checks; phase wall/CPU aliases are used only for finite-clock validation.
Independent phase-chain checks retain the original full outer wall before each
continued observation. Actual shortened outer ceilings, inherited strict best,
plateau anchor/stale history, all epoch permutations and final order RNG are
verified. The current C1 cores (attention, GRU and S4D with dropout zero) also
require the parent/child final Torch RNG endpoints to agree.

No resume-start snapshot exists. Parent identity, source/test evidence, complete
order recurrence and final optimizer/RNG invariants must not be described as
direct observation of the first resumed optimizer step. The original failed
memorization diagnostics remain failed even if a later D score improves.

Every original seed/LR process and added C1 phase is charged, including an attempt
whose independent audit fails. Common LR selection uses all three seeds and both
declared LR rosters; missing audited quality is not filled or dropped from a mean.
C1 waited-child CPU includes its preflight. Child report CPU samples and original
fit-entry CPU deltas are not exact exit rusage; original42 aggregate CPU remains
unavailable in this subset. No energy is imputed and no calendar-time equality is
claimed. The single-thread read-only review may overlap the original HCSN workers;
its UTC interval and costs are separately retained.

Run in a new directory only:

```
python -B run_subset_review.py \
  --base /home/qian-qi/hepta-hcsn-core-study-20261110-c385-training \
  --output /home/qian-qi/hepta-hcsn-independent-baseline36-c1-20261110-c385-v1
```

`VALIDATION.json` describes only preparation. Production outcomes belong to the
separate output directory. The earlier v1 single-fit preflight remains a distinct
unknown attempt unless its original key is reconciled; this adapter does not
restart it or overwrite its paths.
