# C2 implementation candidate

This is a source-and-software-test handoff, not an executed continuation. The original six HCSN fits remain soft-wall-censored and unchanged. C2 production optimization is still unstarted.

`source-candidate.zip` is the exact final source tested by the 21 original guards and 19 new software tests. `attempt-01` retains the earlier 16-test source and logs. `attempt-02` retains the final test invocation, original stderr and source-before/after digests. No failed attempt is omitted; both measured invocations passed. The native runtime file is an original read-only receipt, not a new runtime installation or model execution.

The runner binds original terminal outer/report/plan/data/source/runtime/checkpoints, restores only the latest complete last checkpoint, preserves full parent partial-work charges, writes an immutable before-first-step model/Adam/RNG witness, and commits each new complete epoch before advancing last/best aliases. The controller is non-retrying, keeps all six seed/LR opportunities, enforces a cumulative 43,200-second active envelope and 200 epochs, and collects per-PID exit CPU using wait4. Its default mode performs no child training launch; a future execution decision must bind the candidate manifest and contract.

The preserved v1 recording policy is supplemental no-grad evaluation on three fixed ABC episodes. The separate v2 addendum observes actual main-gradient microbatches at the resume start and fixed epoch boundaries, closes and verifies each trace before the optimizer step, and halts on truncation. Neither form establishes full training-domain numerical qualification. All new captures, failures, cache reconstruction, checkpoint I/O and replay costs are charged. The combined trace payload cap is496MiB per fit.

Software tests use explicitly synthetic tiny HCSN data and true model/Adam updates, plus labelled metadata and I/O failure fixtures. They include exact uninterrupted-versus-replayed state after discarding a real partial update, nonzero optimization visit indices without changed gradients, immutable snapshot and commit failures, source/runtime/parent binding, full wall charging, single-sample clocks, complete roster accounting and actual OS timeout/CPU collection. They are not research training evidence.

The exact candidate has not been deployed or run against the real six models. Independent source review and the original models' numerical/full-D reviews remain separate. No E data are read.
