## Recovery categories

1. **Published exact bytes:** the prior evidence appendices and source tree are
   restored from their immutable Git objects. The original three-hour numerical
   hard stop and all earlier scientific holds remain recorded there.
2. **Retained exact bytes:** the three later C2 observation archives and selected
   source files are restored from retained complete tool payloads or complete
   source-writing records, then checked against their previously recorded byte
   counts and SHA256 hashes. New enclosing recovery ZIPs have new identities.
3. **New readbacks of old remote artifacts:** the hosted science artifact is the
   same complete original ZIP by SHA256. The new download/verification receipt
   is a new receipt; it is not the lost pre-reset verifier's execution record.
4. **Captured summaries and missing originals:** a recorded hash or a tool-output
   excerpt is not the missing file. Missing test receipts, local proof bundles
   and incomplete preparation sources earn no complete-byte recovery credit.
5. **New preparation:** newly written missing modules and newly executed software
   checks must have distinct source versions and receipts. They do not inherit
   the missing old validation run's pass count or costs.

The new rare-tail note is also a new document. Its earlier uncommitted draft was
not available as complete original bytes. The new document binds the existing
committed operator and mathematical diagnosis and receives its own review.

## Cost and scientific limits

Recovery performs source copying, saved-metadata inspection, archive transfer
and software preparation. It is not another model fit, numerical-oracle run,
confirmation evaluation or completion of the original numerical audit.
Individual process measurements retain their recorded scope. Prefix clocks,
wrapper clocks, child CPU, remote API latency and nested measurements must not
be combined into an invented complete total. Unmeasured costs, energy, provider
charges and missing historical CPU components remain unknown.

The actual all-six C2 terminal auditor and extended resource analysis remain
unexecuted in this recovery snapshot. Whole-training numerical admission,
independent C2 training adequacy, real-task scientific benefit and P5 admission
are not granted by byte recovery or software preparation.
