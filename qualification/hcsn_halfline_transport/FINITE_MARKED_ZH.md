# 正不应期下，多次放电的连续空间算子

给定单个初态、固定边界、常漂移与扩散，以及确定性不应期，`finite_marked_state` 输出每代的活跃分箱和上尾、剩余不应期分箱、任意查询点的密度、累计触及和瞬时触及率。每个样本携带有符号向量。第 n 次触及发出并保持当时的标记，第 n 次释放才将标记左乘同一个可学习矩阵 R。这样保留了每代内容与状态的相关性。

## 模型和实现

相对于吸收边界的距离满足 $dX=\mu\,dt+\sigma\,dW$，初态 $x>0$。每次触及零，过程停留 $d>0$ 时间，再从 $a>0$ 重新出发。观察时长为 $T>0$。设 $k_t(x,y)$ 是吸收转移密度，$F_z$ 和 $f_z$ 是从 $z$ 首次触及零的时间分布函数和密度。正漂移允许永不触及。把不应期从时钟扣除后，各段首次触及时间的卷积等于从累计距离首次触及的时间分布。

- 零次释放时活跃密度为 $k_T(x,y)$。第 $n\ge1$ 次释放后令 $z=x+(n-1)a$、$h=T-nd$。当 $h>0$ 时，该代活跃密度在 $0<y\le a$ 为 $k_h(z+a,y)$，在 $y>a$ 为 $e^{-2\mu z/\sigma^2}k_h(a,y+z)$，携带 $R^n m_0$。
- 第 $n$ 次触及的累计概率为 $F_z(T-(n-1)d)$，瞬时率为同一时点的 $f_z$，两者均携带 $R^{n-1}m_0$。剩余不应期比例落在 $(l,r]$ 的概率为 $F_z(h+dr)-F_z(h+dl)$，非正期限对应零。
- 第 $n$ 次释放必须满足 $nd<T$；可能触及的最高代满足 $(n-1)d<T$。正初始与复位距离使零历时触及无原子。代码枚举这个有限集合，超出显式资源上限会报错。实现直接累加分布，保留概率残差。
- 区间积分使用高斯分布函数的反射差，跨越 $a$ 的箱在复位位置分段。极窄分箱、近壁反射相消或极窄时间窗改用正密度的 32 与 64 阶数值积分，两阶必须收敛。标记累积或瞬时输出超出 FP64 可表示范围会明确报错。在复位点上测空间密度时采用左侧公式，训练梯度检验使用分箱质量与事件读出。

单次空间卷积的分段恒等式在仓内已有推导和标量实现。先前正延迟的空间后继以时间卷积积分，另有 Torch 版本返回事件计数、占用和价值。本次把有限次空间后继、逐代变换标记和可训练的复位距离、不应期与时长放进同一张计算图，输出仓内原生 LayerState。[既有恒等式](../hcsn_regenerative/FIXED_RENEWAL.md) · [早期正延迟空间后继](../hcsn_regenerative/tensor_state.py) · [既有解析事件读出](../hcsn_differentiable/finite_renewal.py) · [本次实现](finite_marked.py)

## 实测

| 项目 | 结果 |
| --- | --- |
| 四种时长 0.09、0.21、0.39、0.61 | 分别覆盖 0、1、2、4 次释放，末组还包含第 5 次触及。空间分箱、点密度、不应期质量、标记与事件读出共比较 371 项，最大绝对差 $2.09\times10^{-14}$。 |
| 短时稀有释放 | 另比 60 项，首代释放上尾概率 $2.74954801665\times10^{-89}$，逐项最大相对差 $9.87\times10^{-14}$。独立实现在正常与稀有样本上另用 62 位精度作 6 个逆拉普拉斯检验。 |
| 物理与标记参数的反传 | 对 $x,\mu,\sigma,a,d,T$、两个初始标记、四个 $R$ 系数的同一标量损失做五点有限差分。参考程序独立积分正时间密度与正空间密度。全部 12 个导数非零，绝对误差最大 $2.32\times10^{-11}$。 |
| 接入原投影传播算子 | 使用原生 LayerState 和原 advance 接口做后续 0.07 时间的投影传播。末端损失对以上 12 个参数的梯度均非零，与重新运行完整链路的中心差分最大差 $2.31\times10^{-10}$。 |
| 单位复位矩阵与时间边界 | 零次、一次释放与原接口的最大差 $5.56\times10^{-16}$。在 $T=2d$ 的两侧各移动 $10^{-8}$，分箱变化低于 $3.57\times10^{-9}$。改变 R 后概率逐位相同，有符号内容 L1 变化 0.06639。 |
| 数值复核中的修正 | 初版在 $x=10^{-5}$、箱宽 $10^{-5}$ 时把首箱质量高估 15%。改用正积分后，首箱为 $3.98942280371513\times10^{-16}$。两个近壁用例的质量与距离梯度均对照 70 位独立积分；另检验正漂移及不可表示的标记瞬时率。 |
