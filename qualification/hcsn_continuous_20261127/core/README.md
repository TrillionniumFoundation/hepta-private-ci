# A recurrent Hepta Continuous Spiking Network in PyTorch

Use `from population import ContinuousSpikingNetwork`. Supply a tensor of shape (time, batch, features). The returned tensors are per-time logits and a pair of reusable layer states. Passing the final state to the next chunk makes an online encoder. Both supervised parameters and interlayer messages support ordinary PyTorch autograd. The default financial coefficients are those pinned in the parent study. A sequence optimizer must still supply a task loss and minimize it.

The state of each hidden unit consists of mass on positive log-distance-to-boundary atoms, refractory mass from the previous interval, the preceding log boundary and two preceding priced values. Inputs and delayed values modulate principal, which fixes the barrier. A jump in the barrier shifts each live atom's signed margin. Within this interval the margin follows Brownian motion with fixed drift and diffusion. The difference of a free Gaussian and its reflected, drift-adjusted Gaussian supplies survival probability to each destination bin. The hitting mass supplies the continuous spike signal. Last interval's refractory mass is deposited near the reset margin at the current interval end, making repeated spikes possible. Crossings caused by barrier jumps fire immediately. There is one discrete refractory state per hidden unit.

The current live pool is read through equity E and the monetary loss L computed from a common stationary balance sheet and bond recovery. L includes both ordinary and discounted first-hit functions. Four optional probabilities under future fixed-barrier horizons carry extra information about the population. Each receiver has one of three ports: log boundary alone; log boundary, flow and the two values; or those four messages plus four horizon probes. This implements an empirical sufficiency comparison. A population can need more observables than an individual neuron.

Exact transitions are integrated into bins, then the surviving mass is projected onto each bin's representative. Grid resolution affects forecasts across multiple steps. Runtime scales quadratically with the number of atoms in the reference implementation. The clamp to the stopped region is continuous in event mass, with one-sided derivatives at exact barrier contact. Ordinary BP is valid on smooth pieces; the test avoids treating the choice of a subgradient exactly at contact as a two-sided derivative. The architecture uses an expected flow. A sampled point process or a hardware sparsity gain would require separate evidence.

The upstream financial solution is preserved in he_xiong.py. Run `python check_population.py` to test interval and trajectory mass conservation, regeneration, financial value matching, chunking equivalence and four independent centered gradient comparisons.
