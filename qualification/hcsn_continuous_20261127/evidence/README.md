# Restore and verify the two completed research panels

Download this directory from the commit and run `python restore.py ./restored`. This validates all 35 part SHA256 digests, the combined 14,218,497-byte ZIP and each of its 94 original files before extraction.

Inside the restored directory use `python acquisition/score.py` and `python observed_passage/verify_scores.py` for independent prediction-level verification. For full ECB reconstruction set HCSN_PRIOR_ECB to the absolute path of restored/prior/external_passage and use a single BLAS thread. Run observed_passage/score.py to reproduce predictions from sealed scalar and six neural models. The pinned ECB source, old train/dev, original network weights and classical simulations are included. For the original sensor fit, acquisition/fetch.py and acquisition/prepare.py place public UCI data under /mnt/data/hcsn-9c415-inputs. The original acquisition/study.py imports the bundled top-level hx_crosscheck.py; use PYTHONPATH=. from the restored directory. Refit in a clean output directory if desired. Twenty held-out people and 11,984 decision windows were independently verified. Neither sensor task met both registered comparisons at 25% acquisition.

Discrete monitoring significantly improves the 2019–2025 four-currency externally held-out Brier loss at 3 and 12 post-fixing observations, 0.190578 vs 0.199757. Mean differences also point in the same direction on both much shorter 2026 panels. Direct and analytic-gradient Adam chose one unconditional scalar; their score differences are under 2e−9 on all panels. The matched process clock from original ZIP, including imports, preparation, selection and all three confirmations, is a five-repeat median of 2.022 s versus 4.013 s. This is evidence for this scalar subproblem only.
