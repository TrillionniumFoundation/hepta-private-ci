# Exact population message-port experiment on a held-out engine-noise source

Purpose: determine whether the newly implemented two-layer population cell can actually learn through an exclusive log-boundary channel, and whether priced/augmenting messages add quality on the same end-to-end supervised task. Use FordA, the UCR standard split of 3,601 training and 1,320 final motor-sensor recordings of length 500. Split original train into approximately 80/20 train/dev, stratified by label with the fixed normalized trace SHA as ordering key; any exact duplicated trace crossing original splits is reported. The released archive has no driver/engine IDs, so no subject-level independence is asserted. The held-out test labels are used only after all registered model identities, preprocessing and development selection are sealed.

Frames are 25 raw samples each. Supply 20 ordered frames with seven within-frame summaries (mean, RMS, mean absolute first/second difference and three relative spectral bands). All physical arms share 2 population layers, width 4, 7 positive atoms, interval 0.25, the identical killed-Gaussian transport, stationary literal E and monetary L, one refractory bin, and the same four registered probes. Routes: boundary only; boundary+flow+E+L; eight-channel augmented. A fourth parameter-matched control uses the same eight slots filled deterministically from the boundary alone (fixed scalar nonlinear basis), equality of receiver trainable dimensions to the augmented arm. Include conventional nonlinear GRU on the same 20×7 input and a stronger raw-sample convolutional network. Use two seeds 419 and 1097, common paired sampled training IDs, 192 minibatches of 24, AdamW (lr .004, weight decay .001, gradient norm 1), DEV checkpoints at 0,48,96,192. Dev uses at most 384 deterministic balanced samples (final uses all 1,320). Same loss is binary two-class cross entropy. Record parameter counts, readout sensitivity, cold fit wall, quality/time points, all weights and all final probabilities. Primary paired endpoint is mean held-out Brier for the positive class, comparing augmented with boundary and with the eight-slot scalar basis. The augmented advantage needs both paired bootstrap upper endpoints below zero; report all arms and both seeds. Between-port carry, whole-trajectory recurrence and repeat events have separate numerical tests. This panel is research on one sensor source.
