## Formal design remains separate

The unchanged research design is ten arms × two synthetic tasks × four independent training seeds × two learning rates: 160 registered fits, each with 400 updates, for a 64,000-update training budget. Tasks are delayed recall and adding. Every arm uses the same 81-state, 2,890-parameter model structure, batch size 64 and sequence length 64. The 480-second per-fit limit, 3,000-second provider-job limit and 720-second dispatch reserve are unchanged. Failures and timeouts remain in the denominator, and an UNKNOWN attempt is never replayed.

Each task-by-training-seed group contains twenty fits. All twenty require known terminal records before a validation-only selection lock is written. Test evaluation then uses the selected checkpoints. The four training seeds are the inferential units; two test episode seeds are aggregated within each selected fit and do not create extra training repeats. The exploratory analysis retains the fixed twenty-comparison family, Holm adjustment, missing p-values of one, and the predeclared 0.01 absolute MSE reduction. External retention and the complete cost boundary remain unmeasured. Deployment expansion therefore remains HOLD.

The arms test HX versus a smooth comparator, margin/call/risk/dual channels, first-passage versus endpoint, reset and refractory mechanisms, and real time versus uniform ticks. The conditional-boundary arm fixes an exogenous boundary for an entire episode. It does not solve or train a QVI boundary. The strongest comparator is selected by validation within the registered alternatives; it is not a claim about all deployable models.
