READ-ONLY REVIEW FINDINGS FOR ROOT

1. Confirmed replay bug (event_stream.py, push/query exception handlers): catching Exception does not poison on KeyboardInterrupt/SystemExit. An observe callback that changes state then raises KeyboardInterrupt leaves poisoned=False and last_order=-1; the exact same event can be pushed again, making two mutations. Reproduced locally without training; review-checks.json contains observed output. Use BaseException only to poison and re-raise, including query/advance partial effects. No source changed by reviewer.

2. Qualification boundary (comparison.py compare): expected identities bind 4 arms x seeds but there is no bound inventory of all submitted attempt IDs. Omitting a failed/OOM attempt is undetectable. Reproduced: with a failure containing one optimizer update/eight examples, report is HOLD with budget overflow; omit it and exactly the same completed records produce complete_paired_analysis and gain=True. This is not a defect if compare is strictly an algebra helper and the external caller guarantees the complete immutable ledger. It is a missing gate if its output is used to qualify complete cost accounting. Require independently reconciled attempt inventory/receipt closure upstream, and preserve that evidence in the report.

3. Integration clock/latency limitation (PrefixEncoder.encode): it copies raw prefix arrival_micros to EncodedEvent after doing contextual encoding, without a separate encode-ready timestamp or queue/encode timing. This is adequate for a logical event trace with an explicit zero-cost frontend assumption, but cannot establish a real streaming quality-latency result: a query timestamp between raw arrival and actual encoder completion can receive the feature in replay. Real runner must timestamp token-ready time on a shared monotonic clock and include capture/queue/encoder/core/readout costs. This is a qualification boundary, not a claim that the existing logical-clock tests fail.

What checked well: same-time events use separate observe calls and retain all token rows; arrival/source order are distinguished; invalid whole batches reject before core effects; ordinary exceptions poison; readout result is copied; paired contrasts use within-seed differences and Bonferroni family of five; duplicate completed attempts are rejected; missing terminal identities, over-budget attempts, unequal realized tuning counts, and unknown training cost all block contrasts; missing physical energy blocks the gain claim. Small-sample t assumptions and per-task/scale family scope should stay explicit.

No changes to repository source; reviewed SHA256 values and local reproduction are in review-checks.json.
