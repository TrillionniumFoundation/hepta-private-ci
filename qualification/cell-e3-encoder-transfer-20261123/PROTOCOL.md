# Third-encoder transfer on fresh cases

This is a prospective follow-up to #7035. The earlier binary and candidate-choice panels are exposed. Use only the archived fitting labels and training inputs from the 192 native-answer items in the preceding study, plus newly generated training examples. Retain the pretrained FLAN-T5-small and SmolLM2-135M-Instruct revisions, tokenizer hashes and candidate-string likelihood scoring of that study. Add Python API completion and English text transformation to its six domains. Students see a question and both candidate answers. Exact candidate order is counterbalanced. Both teachers score each answer independently without seeing the alternatives.

Use a third pretrained text encoder, sentence-transformers/all-MiniLM-L6-v2, with an immutable decoded revision, file hashes and its own tokenizer. Freeze the Transformer. Pool question, each answer, and both joint question-answer sequences; score antisymmetric answer feature differences, products, and pretrained cosine similarity. Fit ridge residual heads with penalty 0.2 on unit-normalized row features against the tanh of the teacher log-likelihood margin. Use both independently fitted teachers, their equally weighted targets, a fixed discovery-domain specialist, and a learned question-only top-1 router. Suppressing either graph edge must return its surviving expert. Include the best individual expert preselected by discovery teacher accuracy and an old-rehearsal-only pretrained parent. Share the old rehearsal and training pool. Quantify stored parameters, model forwards, inputs and costs. Greater storage capacity and true discovery labels used for routing are disclosed.

Fit, discovery and confirmation use distinct phrasing. Confirmation also withholds vocabulary concepts/operand ranges in translation, capitals, agreement, numeric and text domains; code-completion confirmation may reuse APIs and uses distinct examples. Per domain use 32 new fit items, 16 discovery, 24 holdout, 8 composition constituents. Form 32 disjoint two-domain pairs of constituent answers and evaluate all 16 simple old controls. Fixed and learned routing use only discovery answers; single-teacher ties favor FLAN. Freeze all learned parameters and their complete input and source bindings before drawing a fresh confirmation seed or collecting either teacher's confirmation predictions. After freeze independently reload the third-party encoder, its tokenizer, student heads and router in a worker where the only model assets are the student assets and networking is disabled. Record model identity, raw predicted choices, domain score, teacher-exclusive scores, disagreement outcomes, old retention and pair success. A post-freeze confirmation set is generated once. Reuse that seed and the same freeze for infrastructure retries.

For both teachers require a discovered domain with >=10/16, >=2 exclusive successes and a strict lead, then confirmation with >=15/24, >=2 exclusive successes and the same lead. A student supports dual inheritance on this task only when both teachers qualify, the student beats parent and the preselected single expert in total, matches or exceeds both on each teacher's confirmed exclusive subset (nonempty), on old retention and exact paired tasks. Report all arms, including every failure. The generated domains and composed pairs contain no independent human or business adoption. Any generalization is to this engineering distribution and templating process.
