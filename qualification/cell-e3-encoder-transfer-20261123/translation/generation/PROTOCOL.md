# Free generation from released and packed translation experts

This preregistered secondary diagnostic uses the original freeze and post-freeze source sample in the human-reference trial. The teacher and packed-model choice results were unavailable when the decoding and scoring rules below were committed. Use the first eight distinct English source lines of the held-out group and all eight distinct dual-language pair lines in the original saved order; request both languages, resulting in 32 source–target items on 16 distinct English sentences.

Generate text from the English source alone, excluding engineered foils or reference strings. Use greedy decoding, one beam, 80 new tokens, model EOS and original tokenizer constraints, no sampling. Compute reference-based corpus chrF++ per target and average sentence chrF++ overall with sacrebleu 2.5.1 (case sensitive, char n=6, word n=2, beta=2). Count paired source lines with sentence chrF++ >=35 for both requested translations. Report exact original-versus-packed text agreement and cost. Compare each single specialist on all requests, both language components addressed by the explicit requested code, the earlier discovery-fixed route, and the text-learned discovery gate. The explicit code route is a manual control. Its successful bilingual generation establishes functionality of separately stored open expert parameters and explicit routing. The independent choice student does not provide an autoregressive decoder.

Reconstruct free-form outputs in an isolated process using the retained packed checkpoint artifact and verify its tensors against the original trial freeze; recursively bind the original material identities. Archive all hypotheses, raw official reference strings with attribution, routing assignments, timing and reference scores. The sample is an existing corpus of human translations; it adds no enrolled live users, paid use or autonomous topology claim.
