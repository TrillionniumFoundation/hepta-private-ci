# 固定 MiniLM 表示后，直接解能省多少更新耗时

同一台 AMD EPYC 7763 主机上，同一个混合教师线性输出头，直接求解耗时中位数为 **14.65 毫秒**，PyTorch 自动微分 L-BFGS 为 **138.33 毫秒**。局部拟合加速 **9.44 倍**。加上两者共同的编码器加载与训练表示提取，在所测阶段中总时间分别是 **4.828 秒、4.952 秒**，节省 **0.124 秒，约 2.50%**。这两个阶段总时长由一次实测的共同前处理与各求解器的拟合中位数组合得到。

| 实测量 | 直接岭回归 | 自动微分 L-BFGS |
| --- | ---: | ---: |
| 7 次交错 CPU 拟合范围 | 14.15–15.40 ms | 137.97–141.89 ms |
| 每次反向传播数 | 0 | 144 |
| 最终含正则项的平方损失 | 17.138918059430814 | 17.138918059431266 |
| 历史盲测逐项与原模型同答 | 272/272 | 272/272 |
| 八域正确数、跨域双题全对、旧题保持 | 114/192、8/32、16/16 | 114/192、8/32、16/16 |

冻结编码器有 22,713,216 个参数。直接写入或用反向传播更新的都是 **1,152 个标量**。训练矩阵高 464、宽 1,152，包括 192 个旧训练样本、256 个本研究训练样本和 16 个保持样本。两种算法从零拟合原研究的同一残差和同一正则强度 0.2。权重最大绝对差为 2.32×10⁻⁷。两个求解器各用一个 CPU 线程，预热后按相反顺序交错计时。原研究的双线程模型加载为 0.217 秒，训练特征提取为 4.597 秒。教师产标、下载、测试推理、采用与结算另计。

192 个主测输入、64 个跨域配对输入、16 个旧输入均来自此前公开结果的复测，对应 32 对组合题。本次登记和比较发生在原研究公布成绩之后。该数据说明缓存表示时可缩短局部头更新的等待时间，也说明每次重新编码时只优化求解器可省下多少。更深层表示学习、全模型预训练、异构设备和真实用户任务各需对应实验。
