## 结论与选择

本轮把共同时间与学习接口、真实共享可塑参数、CfC、读出信用实验接入现有 Cell 实现，并在一个固定源码上完成三组保留真实经验实验。它同时给出工程通过与科学不晋级的结果。

1. **保留 GRU 为时序默认。** GRU-2 在 B 组优于当前 CfC 与语义线性候选；在 C 组仍输给强常数基线，不能宣称完成了新任务收益确认。
2. **保留冻结表征与私有读出作为保守隔离结构。** 真共享权重产生可重复跨任务变化；隔离使这类参数串扰精确归零。但当前神经分化方案全部输给按任务统计的训练比例和精确最近记录基线，不能把隔离直接等同于有效分化。
3. **保留普通梯度强基线。** 定向反馈在两个 tau、三个种子中都优于打乱反馈归属和普通 delayed replay SGD；仍未超越按任务统计的常数基线。继续保留为研究挑战者。
4. **CfC 实现资格通过，替换资格未通过。** 固定官方 ncps 实现的前向及梯度数值对照成功；这与真实任务收益是两项独立结论。
5. **七条谱系和两类祖细胞的结构不扩张。** 当前证据不足以决定增加类型、自动分裂/合并或退役。未用玩具对角递推冒充 Mamba-3、真实 SSM 或关联矩阵状态。

## 共同时间、状态与学习接口

`TimeContract` 使用整数微秒；输入包括零填充值、缺测掩码和以秒表示的时间差。状态观察与参数训练是独立操作。普通状态推进不会隐式更新模型参数。

| 操作 | 本轮语义 |
| --- | --- |
| 新实例 | 使用明确初始状态、episode 起点和时钟身份 |
| 重复请求 | 相同 request ID、相同绑定参数且已完成时精确重放；冲突参数拒绝，pending 请求要求恢复 |
| 乱序、跨时钟、长空闲 | 按显式契约拒绝，不静默裁剪、重排或捏造事件 |
| 原任务恢复 | 参数、运行隐藏状态、时钟/cursor 与原 owner 状态恢复 |
| 原训练恢复 | 参数、Adam 状态、数据绑定与剩余更新预算恢复；确定性的完整批次更新边界 |
| 信用恢复 | 额外恢复 pending eligibility、参考预测、归属、RNG、时钟与去重账本 |
| 跨版本迁移 | 明确拒绝不受支持迁移；没有把加载成功解释成迁移等价 |

结构实验的冷恢复同时验证旧收据重放和新的 `cold-next-prediction` 请求，避免只证明数据库缓存能够读取。时序实验同样在新 Python 进程执行新请求推理并提交 owner 收据：owner sequence 从 3 到 4，事件 cursor 仍为 2，没有继续观察新的时间事件。信用实验恢复 pending 状态，重复计算下一次真实反馈和预测。

## 一、真实共享可塑参数与分化

24 个配置 = 3 个种子 × 2 个部署参数预算 × 4 臂。18 个可学习配置经过 upper、middle、lower 两轮课程，共 432 次拟合调用、4,320 次 SGD 更新；6 个冻结配置不更新。

| 高预算：807 / 783 部署参数 | 0.187550 | 0.178034 | 0.165576 | 0.166667 |

所有 18 个可学习配置均未击败两个非零强基线；最佳单个神经配置 independent/rank2/seed1103 为 0.141589。独立参数与私有头各在 5/6 个相同种子/预算比较中优于共享组，这说明相对隔离收益值得继续研究，仍不足以晋级。

真共享组在 6/6 个种子/预算组合都产生非目标任务预测变化，最大绝对变化为 0.077637。私有头、独立参数和冻结组的非目标任务预测变化均为精确零。非零变化中既有改善也有恶化，不能把所有参数干扰统称为负迁移。

本实验近似匹配**总部署参数量**，没有同时匹配可塑参数量、活动秩与计算。低预算共享、私有头、独立组的训练 MAC 分别为 6.7392M、4.4928M、2.2464M；高预算相应翻倍。精确检索保留外部记录，其存储与神经参数预算也未完全匹配。因此当前最优检索点不构成所有资源限制下的通用最优结论。

24/24 配置都完成原 SQLite owner 的新进程恢复、旧收据精确重放与真正新请求推理，输出一致。这证明工程链路，不证明泛化收益。

## 三、固定 GRU 上的局部信用与延迟反馈

30 个配置 = 3 个种子 × tau 10/100 秒 × 5 臂。固定 GRU 宽度 4；读出使用归一化 initial64 加 GRU 隐状态4。GRU 本体全程冻结，每篇文档重新初始化状态。24 篇训练文档重复三遍，不构成 72 个新任务。

共 2,160 次主流程反馈，24 个学习配置产生 1,728 次读出更新；30 次冷恢复重复下一条反馈单独计量，不作为新的经验。所有臂在标签出现前绑定同一零参考预测；routed/shuffled 的教学向量、延迟和掩码一致，只改变归属。scalar 是信息量不同的消融。

| 最终 dev MSE，3 种子均值 | tau 10 秒 | tau 100 秒 |
| --- | ---: | ---: |
| 冻结 | 0.166667 | 0.166667 |
| 普通 delayed replay SGD | 0.145999 | 0.145999 |
| 标量 eligibility | 0.146001 | 0.144503 |
| 定向反馈 routed | **0.143397** | **0.142594** |

定向组在 6/6 配对配置中优于 shuffled 与 replay SGD，保留了归属有用的机制信号。但 24 个学习配置全部输给任务条件训练比例常数。只有 5 个训练文档和 2 个 dev 文档包含不一致的三路反馈；因此该结果不支持广泛语义分化或长期适应。

30/30 配置完成 pending checkpoint 的真实子进程恢复、下一反馈的完整学习状态对齐与 8 条恢复后预测，共 240 条恢复后样本预测。这里是线性读出 eligibility，未验证 GRU 本体 e-prop、可学习调制/更新规则、持续新任务学习或生物机制等价。

## 尚未关闭的研究问题

本轮已经完成共同接口和优先的三个实验面板，尚未形成下列能力的晋级证据：新来源确认、普通 native daemon 的真实 A→B→C→恢复闭环、长事件流、关联记忆更新、HCSN 专项、真实 Gated DeltaNet/适合规模的 Mamba-3、私有 adapter/LoRA、跨版本迁移、可学习更新规则、连续新任务适应。

下一轮应先取得未被调参使用、正负例和任务干扰均有覆盖的真实来源，冻结来源级划分与反馈可用性，再评价当前候选及强检索/比例基线。时间内核还需要相同信息下的时间消融和真正长延迟事件；信用机制需要内核层更新与连续新任务，而不只是重复当前 24 个文档。所有晋级继续要求：真实经验产生候选、独立评价确认收益、后续普通任务消费、恢复后保留能力，并同步报告完整已知成本。
