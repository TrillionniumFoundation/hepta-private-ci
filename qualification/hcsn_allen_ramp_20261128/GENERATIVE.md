# Open-loop event generation on the prespecified current ramps

Use the existing training-only or development-refit parameters sealed for the conditional event-time study. Simulate four of those models, dual-price, no-price, stochastic escape LIF, and smooth GLM, on every held sweep. At each 2-ms bin a generated event supplies the next model history and reset. Each model sees only the prescribed recorded current, its existing locked coefficients, the initially empty history, and one uniform random number per bin. The simulation receives the realized observation horizon. The target spike count and onset enter scoring after simulation.

Use 256 stochastic sequences per held sweep and method. Give the four methods identical pseudorandom variates for each specimen, sweep, simulation and bin, using NumPy PCG64 seeded by (950185, specimen, sweep). Report the finite-sample unbiased ensemble CRPS of the total spike count and the time to first event, using the observed window end as the censoring endpoint for both generated and measured onsets. Report the Brier score for silence and the absolute difference between predicted mean count and observed count. Lower is better. Also report predicted versus observed sample means and measured silence prevalence. Average sweeps within specimen and then average across the eight held specimens. Show dual minus each alternative with 10,000 paired specimen resamples seeded 950186. These exploratory summaries are conditional on the actual recorded ramp durations; stopping the stimulus in response to firing may affect the distribution of endpoints. Preserve all 256 emitted spike counts and first-bin indices for every arm and trial. The primary conditional event log-score and its prespecified success rule remain those in PROTOCOL.md.
