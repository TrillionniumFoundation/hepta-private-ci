# 双价格自由边界神经元与 Allen 原始放电时间

在从未见过的八个小鼠细胞上，双价格模型没有表现出预定的真实逐脉冲预测优势。拟合将双价格首达特征的读出斜率压到允许区间的下界 0，产生与无价格、仅股权恢复、随机逃逸 LIF 和带相同不应期的常数基线逐箱相同的概率。保留单独损失通道可略微改善整个扫迹的评分。平滑 GLM 对首脉冲的预测更好，首发之后的表现较差。

## 实验范围

从 Allen Cell Types Database 的 6,589 条 Ramp 原始候选记录出发，排除过去 Allen 研究的 132 个细胞，共有 2,117 个细胞具有至少两条候选记录。按预注册哈希顺序选出 24 个。12 个训练、4 个选型，重新拟合 16 个后封存，8 个留出。两个独立计算节点在保留集评分前共同登记主模型和硬阈值 LIF 的 SHA-256。八个测试细胞来自八个供体，与开发与训练供体均不重叠。Allen 官方原始电流按各扫迹的原采样率存档，模型每 2 ms 读取该箱的已知刺激平均电流与更早的放电记录。每个生理箱对应 0.25 个金融模型时间单位。

八个保留细胞共有 23 条扫迹、78,474 个箱、156.948 秒，全部扫迹观察到至少一次放电。508 个 Allen 官方脉冲时间分别落在 508 个不同箱中。本组没有静默保留扫迹，无法由此评估真实静默分类。24 个细胞的全部 1,096 个官方标注中，1,087 个在原始电压 −1 至 +3 ms 窗口内有超过 0 mV 的峰，局部峰值中位数 28.11 mV。模型预测从未使用刺激后的实测电压。

每项先在细胞内汇总，再对八个细胞等权。双价格减仅损失通道，每秒 NLL 差 +.107506，按细胞配对 95% bootstrap 区间 [.063426, .173344]。双价格减 GLM −13.502842 [−39.485841, +7.189064]。首发分数中双价格减 GLM +11.111940 [5.496608, 17.307311]。单独损失通道的优势限于这个模型、刺激和小样本队列，各个区间未经多重性校正。

所有扫迹都包含完整的前 1 秒与前 2 秒。等权每细胞 NLL，双价格在这两个窗口为 3.01934 和 4.71951，GLM 为 .75658 和 2.29156。首个真实脉冲以后仍有 32.672 秒和 485 个放电箱，按时间汇总的 NLL 分别为双价格 78.73006、单损失 78.19981、GLM 229.88264 nats/s。观察区间截于各真实扫迹的终止时间，可能受刺激程序终止条件影响。硬阈值 LIF 在保留集 23 条扫迹上的自主首发全部漏检，有限的 NLL 来自其校准的背景强度，单独的概率评分不能代替这个计数。

16 细胞重拟合中，双价格、只股权、去价格和随机 LIF 的截距完全相同（−5.10956947），斜率也都为 0。仅损失模型斜率 +.04659236。物理核本身在每步守恒，合法的初达通量并未保证该斜率对生理数据有可用的正信号。

## 重放和凭证

results/seal.json 和 hard-lif/seal.json 含所有候选参数、开发选型和锁定拟合参数。joint_receipt.json 登记双份模型的独立见证。results/terminal.json、hard-lif/terminal.json、score_components.json 和 donor_summary.json 保存各细胞原始求和、分母、配对区间与来源。主终点 SHA-256 为 08810ac517b15ef87166fc57706c6364d892f8b7d92ed81f6e0cae8cc2a692fa，硬 LIF 终点为 f2e7e68723bdb2992c692dada63c2ad7bfef60ba36d4481a2129c8a1c2a8b7c1。

独立实现从原采样电流和官方事件时间重新构造了 627,792 个测试概率，7 个模型在每个箱完全相同，损失单通道最大概率误差 1.27×10⁻¹⁰。逐步概率质量误差 4.44×10⁻¹⁶。模型原实现另完成逐文件逐箱精确冷重放。源码和结果不会把这项单细胞条件预测延伸为多模态预训练、能耗、跨物种或梯度训练优势。
