# Development-only calibration and timing disclosure before test retrieval

For every candidate in every method, temperature-scale raw logits by a common fixed grid 0.5,1,2,4,8,16,32 on the 12 development speakers, select smallest Brier then smallest scale and save that scalar. A positive scalar leaves class argmax unchanged. Model selection still prioritizes speaker-macro accuracy before calibrated Brier. The first engineering pass used the raw Brier for some candidates; the complete initially produced panels will be kept separately and charged as a pilot. Refit all methods under the same calibration, seal the resulting weights and temperatures as the primary panel before any cold WAV is retrieved. This corrects implementation of the original predeclared secondary criterion; it does not introduce a test-informed choice.
