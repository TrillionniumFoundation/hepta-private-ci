# 在真正的耳蜗事件上从零写入两个隐藏层，以及保留旧语言的局部突触编辑

本实验直接从独立的 Heidelberg Spiking Digits (SHD) 官方录音事件开始。在任何正式测试评分前统一封存 33 个模型。测试 2,264 条，其中整个官方训练集中从未出现的说话人是 4 和 5。开发集另留出完整说话人 3 与 10。SHD 与之前的 FSDD / UCI Arabic 是不同语料。原计时均为本次单线程 CPU。

## 两层从零训练

两个实际突触矩阵均在金融边界与非线性权益/首达读出之前安装。用当前真实训练残差按四个单元一组构造两个隐藏层，最后安装线性头。匿名训练语料不含任何预训练模型输出。综合 20 类英语/德语分类，监督构造得到 63.47% 逐录音、70.86% 等说话人、61.25% 新两人平均。相对三个同结构随机模型，等人准确率增加 23.20 个百分点，按说话人成对自助区间 [20.56,26.03]；相对训练说话人内部置乱残差控制增加 13.40 点 [10.68,16.00]。这是两个隐藏层真的学到任务方向的阳性证据。

同一构造方法换成普通平滑门达 73.68% 等人准确率，展平相同的原始时间特征做 ridge 达 77.74%。由开发表现选中的强双层时间卷积三个独立种子的等人准确率均值为 80.24%；构造的金融网络低 9.39 点 [−12.96,−5.75]，在从未出现的两人上低 11.03 点。与随机初始化同结构全参数 BP 相比，总体等人差 −0.07 点 [−5.14,+4.20]，从未出现的两人低 7.09 点。预先规定的等质量替代条件未满足。

## 改写已训练网络内部的 512 个突触

三个就英语数字独立训练的父网，使用同一个语言无关数字标签，适配德语并保留英语。固定第一层、第二层偏置和输出头，所有方法只可改变第二层 32×16 个权重。直接方法对真实非线性输出做正负探测，在 12 和 32 维子空间中计算外部交叉熵的局部二次近似，并实装所选矩阵。对照包含 KEEP、按人置乱新标签、同层全矩阵 Adam，以及同层秩 4 LoRA。所有调整均在同一开发集选择，所有臂均可保留原网。

| 方法 | 德语等说话人变化 | 英语等说话人变化 | 全新两人德语 / 英语变化 |
|---|---:|---:|---:|
| 直接写入 | +1.75 点 [0.70,2.71] | −1.48 点 [−2.65,−0.48] | +2.64 / −0.33 点 |
| 置乱标签 | +0.44 点 [−0.57,1.33] | −1.07 点 [−2.15,−0.04] | +1.30 / +0.34 点 |
| 秩 4 LoRA | +9.72 点 [7.80,11.97] | −10.63 点 [−13.72,−7.00] | +9.39 / −10.97 点 |
| 同层 Adam | +9.46 点 [7.57,11.47] | −5.84 点 [−9.89,−1.53] | +9.69 / −5.08 点 |

直接编辑在三父网上的全新两人德语变化为 +2.66、+4.02、+1.24 点；英语变化为 +0.05、−0.37、−0.67 点。两个父网过预设新任务 2 点和旧任务少于 2 点回退的点门，第三个未达到新收益。更大新语言收益与旧语言回退同时出现在所测 BP 和 LoRA 候选中。这三个固定父网及正式测试中仅两位全新说话人，限制跨人的统计解释。

## 时间与独立复算

直接构造两层并完整冷评估 1.64 秒，包含既有本地 HDF5 读取与公共特征和物理表准备约 7.33 秒；相同输入、较高准确率的直接 ridge 分别为 1.38、7.07 秒。直接局部编辑三个父网累计增量搜索与完全独立冷确认 6.67 秒，同层 Adam 13.16 秒，LoRA 10.57 秒。另有共用本地准备 5.69 秒、先前取得公共原始数据 28.253 秒、三个英语父模型的训练及独立检查 15.36 秒。编辑的提升和保持均衡与两项对照不同，不能将增量时间比解释为同等新旧质量下的速度比。附档计入已记录的失败子进程工作；公共准备时间来自阶段内部计时，不含进程启动，完整搜索与每次冷测从外部父进程计时。单宿主机、没有专属调度或功耗测量。

另一实现从所有选中模型合计 1,086,720 个逐类原始分数重算了 51 项子任务结果。它逐一检查 33 个模型及其哈希。在每个物理网络的 43 个固定录音上使用直接 FP64 权益/首达算式贯穿两层复算；28 个物理模型的最大 logit 差 5.26e−5，分类均与查表相同。本实验的事件衰减前端按全部 82,625,050 个原时间戳事件计算，不把归档中的时点当成独立说话人。网络在有限观察时刻询问平稳金融单元；重复放电、群体反复复位和稀疏芯片功耗需要各自独立的试验。

## 复现

1. 使用作者的数据目录 https://zenkelab.org/datasets/shd/ 获取 shd_train.h5.gz 和 shd_test.h5.gz，核对原作者 MD5 d47c9825dee33347913e8ce0f2be08b0 和 3062a80ec0c5719404d5b02e166543b1；解压后 SHA-256 位于 data/prepare.json。原始录音事件请从作者获取。
2. 运行 python restore.py 还原归档。也可以使用 Python 3.12 的 zipfile、hashlib 和 json 读取 archives.json，逐一核对 ZIP 的 SHA-256，按原相对路径解到本目录；校验各子文件哈希。运行 python verify.py --root . 即可离线独立核对全部保存的模型、逐例分类与准确率。将原始特征目录传入 --raw 还可做两层直接 FP64 演算。
3. 完整重训使用独立空目录 RUN，DATA 表示存有两个 .h5 的目录。安装 NumPy、SciPy、PyTorch 与 h5py，将 OPENBLAS_NUM_THREADS、MKL_NUM_THREADS、OMP_NUM_THREADS 设为 1。运行 python source/prepare.py --input DATA --out RUN/data，再运行 python source/lawtable.py --out RUN/data。逐次运行 python source/supervise.py --phase construct --root RUN，将 phase 依次换为 bp 和 edit。最后运行 python source/confirm.py --action all --source DATA --root RUN 和 python source/summarize.py --root RUN。首次封模前应保持 source 目录中的原始源码不变。
4. 模型和数据身份见 seal.json，逐候选开发选择、物理权重、时间见各归档内 fits 目录；所有独立测试输出见 test 目录；全指标与按人条件区间在 results.json。源论文为 He 与 Xiong，Journal of Finance 2012；参考实现固定为 hepta-private-ci 的 cf5aa0c954e92fbecd3a53494ccefaa37a2bb7d0，qualification/hcsn_research_20261127/literal/cell.py。原 SHD 为 Cramer、Stradmann、Schemmel 与 Zenke 的公开听觉事件数据。
