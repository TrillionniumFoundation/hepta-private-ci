# UJI pen trajectories: blinded writer transfer and two-layer construction

This experiment complements the SHD and multilingual speech protocols. It uses handwriting inputs from a different acquisition process. All model fit/selection precedes cold-test decoding. The author-distributed UJIpenchars v1 (Llorens et al.; UCI dataset 142, DOI and official reference verified separately) has 11 writer files with two repetitions each of lower-case letters, upper-case letters and digits. Frozen mirror 1a6db99d42b50f2c720ef82f4683daec82084131, data/UJIpenchars-w01 to w11; use actual raw stroke x/y and pen-down/up tokens. Use only 26 corresponding lower/uppercase identities; digits are excluded in advance. Lowercase is the initial task and uppercase the new class-invariant handwriting domain. Writers 1–5 fit, 6–7 select, 8–11 cold test, in the same split for both domains. This protocol tests actual case invariance within known letter identities; it does not model changes to event spike timing.

Model input: translate and isotropically rescale each native glyph's actual (x,y) trace; resample by within-stroke length to 12 ordered points, concatenate normalized x, y, and stroke-start flag. Retain independent writer and within-case labels. H=16 per layer. Each physically grounded unit maps synaptic drive to P=P0*(1+.28*tanh(u)), exact affine He-Xiong stationary B(P), survival margin x=.18-log(B/B0), A7 equity/20 and finite-horizon default F. Validate stationary function tabulation on [-12,12]. Two dense physical hidden matrices and linear 26-way readout. This is a static pen-shape encoder over ordered points. Its walls are updated across layers; it has no learned temporal recurrence. Compare a two-layer smooth control, ordinary ridge on original coordinates, frozen random features and ordinary tanh backprop. Independent parents use seeds 409/571/647. Targets for initial construction are lower-case only, and a separate joint training check may use both letter cases, explicitly marked. Constructive fitting starts without pretrained weights, uses supervised cross-covariance with orthogonalized class residuals to install actual weights one layer at a time, followed by fitted linear readout. Compare shuffled supervision, random hidden matrices, and two-layer joint full BP with Adam; tune major methods on development with a comparable budget. Report full timing and exposed examples, model fitting versus runner/data costs.

Freeze fresh all-BP lowercase parent tensors except actual 32-by-16 upper input weights for every editing arm. Preserve exact KEEP, same-site full Adam, rank-four LoRA, and supervised forward-only group secant and shuffled-label secant. Group secants perturb one common input coordinate for all independent upper neurons and recover each neuron's separate actual-logit response from its readout terms. Fit damped new-target residual plus soft old-output preservation in this space; test trust step candidates on the real nonlinear model; repeat at most twice. Same-site BP/LoRA use matched parent, data, candidate learning-rate grid and validation retention gate. Primary development choice: keep lowercase within 2 percentage points versus KEEP, maximize new upper-case accuracy then old/new loss. Disclose all parent-preserving arms that select KEEP. Primary test gate: in every seed, new accuracy +2 points, old accuracy >=-2 points, new paired writer-bootstrap lower 95% >=0. Only then compare equal-quality measured elapsed CO2/energy excluded absent instrumentation. Interpolate no unobserved time-to-quality, and distinguish CPU/JS from GPU/torch timing. Include raw traces or reproducible source digests, reconstructable learned parameters/predictions/class metrics, timings, code, failed arms, absolute paired per-writer effects. With four held-out writers all statements must qualify uncertainty.

The multilingual speech and actual SHD analyses retain their own source participants and precommitted estimators.
