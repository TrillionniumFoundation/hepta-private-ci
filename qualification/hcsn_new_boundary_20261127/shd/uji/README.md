# Forward construction and upper-hidden editing on UJI tablet handwriting

The UJIpenchars v1 raw UNIPEN recordings come from the Llorens et al. collection, [UCI dataset 160, DOI 10.24432/C5731G](https://archive.ics.uci.edu/dataset/160/uji+pen+characters), [research paper](https://aclanthology.org/L08-1467/). This study uses a different corpus from UCI PenDigits and from the German–English SHD speech study. Digit symbols in this dataset were excluded in advance. Each of 11 people contributes two real trajectories per lower/uppercase letter. Parent training uses 260 lowercase glyphs by 5 people, selection 104 by 2 different people, final test 208 per case from 4 further people. The 26 identities stay the same across the true lower/upper case shift. Do not generalize four people's confidence intervals to a population of unspecified size. All splits are balanced by writer and class. The source and archive manifests give the original author/mirror and SHA hashes. Raw data are redistributed under UCI's [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) with attribution; the new protocol differs from the authors' original 35-class leave-one-writer-out task.

Pretest code commit c8292a9d1fef9a98535ce3ff74b6c6237a2b4eb3. All 33 selected parameter sets/dev frontiers sealed in 173fd0e0de1630cff97267b8e04c92d0cba879e3 before fetching any of the four test writers. Use the adjacent PROTOCOL.md, SEAL.json and runner.js. Raw x,y and stroke breaks were translated, isotropically scaled, and arc-length resampled to 12 ordered pen positions with a stroke-start flag. The static shape encoder has learned input and upper matrices, with 16 neurons apiece. Principal and boundary both vary with drive, and each physical neuron returns centered A7 equity/20 and finite horizon F. Downstream synapses receive A/F. An exclusive interlayer barrier-only recurrent architecture is tested in a separate speech protocol.

## Outcomes

Three independent direct lower/upper matrix constructions on lowercase averaged 61.86% held-out accuracy. Physical all-layer Adam reached 60.10%, smooth all-layer Adam 59.46%, smooth direct construction 62.50%, literal random features 50.64%, shuffled installation with true readout 47.76%, original-coordinate ridge 56.25%. The physical constructive-minus-physical-BP paired writer effect was +1.76 points, exhaustive writer bootstrap 95% interval [-5.77,+11.86]. The four independent writer effects were -7.05,+17.31,-4.49,+1.28 points. The full 3-seed fit searches took 2.326 seconds for the physical constructive method, 34.402 for physical BP, 2.287 for smooth construction and 0.301 for ridge in one serial V8 worker. This provides direct empirical evidence for inexpensive small supervised feature construction with these settings. The broad interval, alternative smooth construction, and training/validation budgets restrict any claim about a uniquely financial or general time-to-quality advantage.

All editors started from the exact physical lowercase BP parent, changed only the 512 entries of the real 32x16 upper matrix and kept both biases, lower matrix and trained classifier frozen. Grouped probes produced hidden contributions from the true nonlinear forward map. Every backprop/LoRA/secant arm reviewed the same KEEP along with genuine candidates; all 3 true-label secants selected a nonzero update. New uppercase improved by +2.40,+1.44,+0.48 points in the three seeds. Old lowercase changed -3.37,0,-0.48 points. Mean +1.44 new points [0.32,3.04] and -1.28 old points [-2.56,0.00], with four writers resampled jointly across the same three seeds (4^4=256 draws). None of the individual seeds passed all three predeclared gates. Same-site Adam averaged +0.96 new and -0.96 old points, rank-4 LoRA +0.80 new and -0.64 old points. Full searches summed to 32.827 s for the true grouped editor, 22.306 s for the paired Adam and 24.157 s for LoRA, excluding parent fit shared by all. The frontiers include elapsed seconds at every validation checkpoint. These are CPU JavaScript observations; CPU model, energy and allocation charges were unavailable in that runtime. Treat cold test replay and shared model/data preparations separately from fit time.

## Replay

All binary archives are small ordinary ZIPs. Expand all listed archives into this directory, preserving relative paths. archives.json provides member and container SHA-256. Run with Node and Python NumPy/SciPy:

```bash
node runner.js check raw fits
node runner.js score raw fits
OPENBLAS_NUM_THREADS=1 python verify.py .
```

Recompute a fresh parent or editing arm via e.g. `node runner.js fit raw fits 409 physicalBP` and `node runner.js fit raw fits 409 secant` in an isolated copy (runtime fields will differ). fits/*.json stores real learned weights, selections, timing and complete development alternatives. predictions/*.npz contains the original V8 cold FP64 logits, person IDs and labels. The replayed Node program agreed with the archived V8 across all 356,928 class scores to 1.58e-13, with zero changed classifications. The direct FP64 NumPy/SciPy A7+F implementation independently recalculated every one of the same scores from original raw pen positions. Its greatest difference versus the table model was 0.000194 and no predicted class changed. Executing verify.py generates independent prediction evidence locally. The package.py file records how the original V8 artifacts were assembled; archived predictions are sufficient to recover the original V8 binary tensors if auditing the packager. results/summary.json contains absolute/per-writer and per-seed outcomes and costs; results/independent.json records all independent numerical checks. No original SHD files are required for this study.
