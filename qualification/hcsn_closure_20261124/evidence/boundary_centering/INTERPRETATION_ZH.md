# 最后一轮边界消息中心化确认：终局解释

本轮在预注册的短延迟任务上确认了一个受限的正结果：**使用因果输入累积，并只对跨单元传递的 boundary 消息减去固定名义基线后，纯 boundary 网络可以通过真实 BP 学会任务。** 同条件再加入 signed 通道，三个种子的最终准确率和 Brier 都变差；本轮没有支持两通道协同的证据。此前 raw boundary 与 raw joint 的失败继续保留，不能用本次新实验覆盖。

证据：[完整独立汇总](SUMMARY.json)、[逐模型审计](AUDIT.json)、[冻结协议](PROTOCOL.json)、[源与回读身份](SOURCE_IDENTITIES.json)。全部 12 个模型和预测原件已收入 [6 档封存清单](ARCHIVES.json)。

## 固定实验和改动范围

12 个独立训练槽为 4 臂 × 3 种子（25011、35011、45011），均为 N32、mixed、QVI/value-risk、原始读出特征及 qualified Fast 内核。train / dev / test 来源分别固定为 39000–39011 / 40000–40003 / 41000–41015，每个 test 来源 64 例。全部模型实际执行 512 次更新，统一 900 CPU 秒更新上限与 180 CPU 秒前缀；仅按开发集选择 checkpoint。全部 12 个 fit 终态、checkpoint、mask 与机制原件封存后才构造 test，之后没有重选或重训。

所有臂都硬关闭 unsigned 消息。`accumulate` 在控制支路的慢时钟更新前因果累积尚未消费的 cue，更新时消费一次；外部 `input_mark` 仍读取当前原始帧。由于 recurrent contribution 同时进入 drive 与 mark，不能把“外部 writer 帧原样保留”说成整个 writer 不受反馈影响。

中心化仅在交付历史 boundary 消息时计算 `b_t − b0`，`b0` 为无数据的固定名义边界；第零步仍交付零消息。模型没有学习均值、额外 gain 或选择中心化超参数。物理边界与密度动力学方程未改，原始 boundary 继续存入状态；反馈信号的改变可以改变之后的闭环轨迹。

## 测试结果

均值 ± 样本标准差以三个独立训练种子为单位，不能把 16 个 source 或 1,024 条测试序列当成额外独立训练重复。Brier 为两类概率误差平方和，越低越好。

| 臂 | 最终准确率 | Brier | 晚 cue 前准确率 | 学习门 / 数值门 |
|---|---:|---:|---:|---:|
| signed_raw | 92.1224% ± 0.5378 pp | 0.112325 ± 0.004291 | 75.1628% | 3/3；3/3 |
| boundary_accumulate_raw | 51.8555% ± 0 pp | 0.499677 ± 0.000157 | 51.8555% | 0/3；3/3 |
| boundary_accumulate_centered | 96.6146% ± 0.6647 pp | 0.055566 ± 0.007067 | 76.1393% | 3/3；3/3 |
| boundary_signed_accumulate_centered | 92.9036% ± 0.9074 pp | 0.095797 ± 0.012198 | 76.1719% | 3/3；3/3 |

两个预注册的同种子对照分别回答一个问题：

1. **同样累积输入，仅中心化 boundary。** 三个准确率差依次为 +44.2383、+45.5078、+44.5313 pp，均值 +44.7591 pp；Brier 差均值 −0.444111。未中心化臂的一个种子最终选择初始 checkpoint，但该槽仍实际训练了全部 512 次更新，费用全部保留。
2. **同样累积并中心化，仅开放 signed 通道。** 三个准确率差为 −3.8086、−3.4180、−3.9063 pp，均值 −3.71094 pp；Brier 差为 +0.039890、+0.035183、+0.045619，三个种子都恶化。这反对本任务上的协同收益解释。

两个中心化臂相对 signed_raw 的预定 accuracy / Brier 容差均通过 3/3，且各自学习与数值门也通过 3/3。但与 signed_raw 的比较同时改变了输入累积，不能把其准确率收益单独归因于 boundary 通道。容差门也不构成统计等价或总体优势证明。

原件中的其他指标同样保留：中心化纯 boundary 的最终准确率更高，但自动停止准确率 81.8359% 低于 signed_raw 的 83.5286%，停止效用 0.808696 低于 0.822772。因而不能宣称所有推理预算或停止策略均改善。

## 机制与资源

选中模型的 boundary 交付 RMS 均值从 raw 的 0.617739 降至 centered 的 0.017554；全帧 drive 饱和比例均值从 24.6939% 降至 0.0346%。三个 raw 种子并非都饱和：其中选择初始 checkpoint 的种子为零。观察结果与减小固定直流偏置的机制相符，但没有独立证明饱和是学习失败的唯一中介。

每个模型总参数 3,522，`requires_grad` 参数 3,490。单通道的结构活动 recurrent 权重为 768、扣除 mask 后活动可训练参数为 1,186；joint 分别为 1,536 和 1,954，因此不能称有效容量相等。没有新增可训练参数；每个模型增加 256 bytes 的固定 `b0` buffer。完整持久张量状态为每例 6,704 bytes，在固定评估 batch=16 时为 107,264 bytes，包含每例 48 bytes 的 pending / held 控制状态。所有臂都分配此状态，但只有 accumulate 臂把它用作 cue 记忆；Python 对象与整数时钟开销不在这个张量字节数中。

| 臂 | 完整 fit worker 墙钟秒，均值 ± SD | fit CPU 至 worker 回执，均值 | 完整 test worker 墙钟秒，均值 |
|---|---:|---:|---:|
| signed_raw | 258.117 ± 2.965 | 256.806 | 45.265 |
| boundary_accumulate_raw | 257.166 ± 3.033 | 255.801 | 48.036 |
| boundary_accumulate_centered | 261.910 ± 5.409 | 260.829 | 47.229 |
| boundary_signed_accumulate_centered | 259.946 ± 1.605 | 258.630 | 47.638 |

所有 worker 墙钟从启动到退出，包括冷启动与关闭；逐 worker CPU 在其回执处截止，不能伪称包含关闭。12 fit + 12 test 子进程的完整 CPU 合计 3,662.191673 秒；外层包括安装、真实 4 tests、4 个三步 smoke、冻结、campaign 和独立审计，共 658.297076 墙钟秒、3,700.975834 子进程 CPU 秒，协调器另为 1.000067 CPU 秒。这些为嵌套范围，不可相加。6-worker scope 实际限制为 600% CPU / 6 GiB，观测 peak memory 为 1,855,623,168 bytes，无 OOM。没有测得能耗。本轮没有显示训练时间优势。

## 核验与结论边界

真实 4 tests 和 4 个 smoke 全通过；全部 12 fit / test worker 退出成功。独立 NumPy 从封存 logits、labels 与 sources 重算 selected / initial / CPU-prefix 指标，最大误差为 2.220446049250313e−16。12 个模型各阶段的 unsigned 交付严格为零，固定中心化的消息均值恒等式通过。数值门来自原始物理诊断，本次 NumPy 指标核对没有重新积分密度方程，也不把进程退出状态当作能力门。

本轮支持“经过明确接口修正的纯边界连续通信可以在该小型任务上工作”；它不支持未修正 boundary 的普遍有效性，也不支持 boundary+signed 必然互补、长延迟记忆能力、全模态基础模型规模化优势或直接替代端到端 BP。训练仍然使用 BP。本次为最后一轮已授权的有界机制确认，正负结果全部封存，没有根据 test 再搜索。
