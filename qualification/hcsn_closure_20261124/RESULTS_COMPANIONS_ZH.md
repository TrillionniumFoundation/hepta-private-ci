# 关系能力、传统基线与长延迟：冻结实验终局

本页报告已完成的独立候选与固定测试，不构造新样本、不训练或重新选择模型。boundary/signed/joint 九槽对照已完成，采用独立协议与来源，其负结果另列于末节，不与既有训练候选合并选优。

## 结论与范围

已知规则可以编译到冻结 HCSN 表示之上的显式关系字典，实现此前读出没有提供的 AND、OR、XOR 查询。严格程序不读取标签、激活或梯度；在九个独立训练父模型及其合法坐标变换上，程序需要重新生成，不能复用旧模型的数值参数。这支持有限、结构已知的能力安装。它没有替代父模型的 BP 训练，也没有证明模型能自动发现关系规则、通用表征或多模态基础能力。

传统 GRU 与 surrogate LIF 在本次短任务、近似参数档上均取得更高准确率和更低训练成本。训练长度 12 后直接测试长度 76/140，HCSN 的 18 个条件全部未达到预声明能力门槛；固定大小状态不能推导为已验证的远距离记忆。

原始来源：[关系与基线逐种子统计](evidence/companion_results/DECISION_SUMMARY.json)、[长延迟统计](evidence/companion_results/STRESS_SUMMARY.json)、[冷进程成本复核](evidence/companion_results/COLD_COST_AUDIT.json)。完整原始档案清单见 [ARCHIVES.json](evidence/companion_results/ARCHIVES.json)。

## 1. 规则安装的真实验收

固定九父：N=8/32/64，每档三个独立训练种子 17011/27011/37011。父模型由原短任务的 train/dev 选出，未根据 test 筛选。配对任务有独立的 train 20000–20011、dev 21000–21003、test 22000–22015 来源，每个测试来源 16 对；两个序列使用独立 RNG 流。标签为两个真实任务标签的 AND、OR、XOR，不能用父模型预测代替真标签。全部九父的五方法候选封存后才构造测试集。

令两个冻结父读出的二类 logit 差为 x、y。所有方法共享预先声明的字典

$$z=(x,\ y,\ |x-y|,\ |x+y|).$$

严格程序安装 AND=(x+y−|x−y|)/2、OR=(x+y+|x−y|)/2、XOR=|x−y|−|x+y|。三行权重加偏置共 15 个可编辑标量。abs/minmax 字典本身是明确的人工结构先验，不能声称只改变原来线性头的权重便凭空发现 XOR。可观察查询 0 保留原 A 序列分类，查询 1–3 请求新关系；旧新任务的含义不冲突。

| 方法 | 信息与操作 |
|---|---|
| KEEP | 原关系头仅复制 A 的 margin，不安装规则。 |
| BP | 标签监督；从 KEEP 初始化，用 L-BFGS 优化共同 MSE+ridge 目标；最多 96 次实际 closure，允许固定梯度阈值早停。 |
| ANALYTIC | 同一监督标签、字典和目标的条件闭式岭解；偏置不罚。它是监督学习，不叫严格 WSP。 |
| STRICT_WSP | 仅读取当前二类读出权重及声明的规则；无标签、激活、梯度、搜索输入。 |
| HYBRID | 严格规则编译后，用与 BP 相同目标和预算做监督微调。 |

共同拥有规则先验不意味着实际使用的信息完全相同：监督三臂读取训练标签，严格编译器不读取。规则/字典的人工构造与发现成本未测，记为未知，绝非 0。

主指标 XOR 真标签准确率，均值 ± 样本标准差（百分比）：

| 方法 | N=8 | N=32 | N=64 |
|---|---:|---:|---:|
| KEEP | 53.39 ± 1.48 | 53.12 ± 1.35 | 53.52 ± 0.39 |
| BP | 81.64 ± 0.68 | 85.16 ± 1.17 | 85.68 ± 1.26 |
| ANALYTIC | 81.64 ± 0.68 | 85.16 ± 1.17 | 85.68 ± 1.26 |
| STRICT_WSP | 81.77 ± 0.23 | 85.03 ± 1.76 | 85.29 ± 1.93 |
| HYBRID | 81.64 ± 0.68 | 85.16 ± 1.17 | 85.68 ± 1.26 |

STRICT_WSP 在九父上全部改善 KEEP。所有非零 margin 对的程序输出与声明布尔规则一致，零 margin 对数量为 0；但对真实标签并非 100%，父表示的错误仍会传播。45/45 方法保留查询 0 的原 logits 完全一致。合法群内神经元置换与读出坐标符号变换各九次，重新生成程序后的 18/18 控制等价；直接复制旧程序的 18/18 负控不等价。两个视图属于同一父模型的控制，不能计为额外独立种子。

独立 NumPy 审计重算原预测概率、准确率、Brier 和 CE，最大误差 2.22e−16。三种监督方法的 XOR 准确率在此集相同不构成全局等价证明；严格程序与 BP 的误差、校准并不完全相同，不使用“同质量全面替代”的表述。[逐方法、规则、种子记录](evidence/companion_results/DECISION_SUMMARY.json)

## 2. 冷进程成本：避免顺序启动偏差

原五臂顺序执行记录保留。另做固定三个 N8 父×五方法共 15 个 fresh process，仅用于成本与确定性候选复核：各自承担解释器/库/优化器冷启动、父检查点校验和加载、同 train/dev 样本重建、独立特征计算、程序生成或拟合、写盘/重载与 dev 验证。不读取新 test，不重新选模型，不替换原候选。15/15 候选、特征、dev 分数与优化收据逐值一致；45 项 RESULT/WORKER/LAUNCH 收据齐全。

| 方法 | 完整独立进程 CPU 均值（秒） | 启动到退出 wall 均值（秒） | 实际 closure 数（3 父） |
|---|---:|---:|---|
| KEEP | 10.321 | 10.394 | 0, 0, 0 |
| BP | 12.402 | 12.467 | 30, 29, 19 |
| ANALYTIC | 10.474 | 10.528 | 0, 0, 0 |
| STRICT_WSP | 10.159 | 10.230 | 0, 0, 0 |
| HYBRID | 13.346 | 13.387 | 20, 19, 20 |

完整适配阶段里，BP 与严格程序 wall 均值约 12.47 与 10.23 秒；解析岭解约 10.53 秒。纯求解微步骤的巨大比值不能代表这段完整流程，更不能代表父模型训练。三个 N8 父原训练完整 wall 均值为 197.893 秒；加入已承担的父训练后，BP 与严格程序分别为 210.360 与 208.123 秒。此加总仍须另列原实验的最终 test/迁移验证费用以及未知人工发现成本，不伪装成有完整人工成本的总训练加速率。

15 个独立子进程 CPU 共 170.1054 秒，子进程 wall 之和 171.0194 秒，协调器阶段 wall 171.0330 秒、协调器 CPU 0.4118 秒。阶段、worker 与函数体为嵌套口径，不重复相加；每方法只有三个父、每父一次计时，不提供延迟置信区间。能量未测。[完整逐次成本与边界](evidence/companion_results/COLD_COST_AUDIT.json)

## 4. 长延迟压力结果

所有相关候选和短测试终态后，固定已选模型直接评价 T=76/delay64 与 T=140/delay128；每条件 8 个新 source×16 样本。没有长任务再训练或基于压力测试选模。能力门为 final accuracy≥0.8 且 final−prelate≥0.1；这是预声明工程门，不是统计显著性检验。

HCSN 0/18；GRU 与 LIF 各 0/18；Transformer 2/18，且仅在 delay64 的两个单种子上通过。总体 2/72。全部 36 worker 正常退出、独立指标重算一致（最大误差 8.88e−16）只是证据完整性；它不把失败的能力门变成通过。

## 5. 可复核性与剩余边界

19 个不可变 raw 档，共 29,226,442 字节、1,275 个 tar 成员，逐成员含 bytes/SHA256，完整 tar 另含 SHA256 与 Git blob SHA1。归档包含所有检查点、预测、features、history、成本、错误、协议/封存/声明、源码版本与 preflight；仅明确排除可再生的 __pycache__ 和 .pyc。父 HCSN 的原始训练检查点由主 63 槽档案交叉引用，未伪造副本。初版缺依赖 preflight 失败以及一次结果摘要脚本的解析失败均保留；后者没有执行模型或修改科学结果。[原始档案身份清单](evidence/companion_results/ARCHIVES.json)

当前证据支持：可微连续通量原型可训练；已知代数关系可作为严格、可迁移的权重程序安装；同一 mixed 核的工程加速可在固定训练结果下缩短耗时。当前证据尚不支持：从解析解自动获得新表征、一般知识/全模态能力；用权重编辑替代端到端预训练；或相对 GRU、传统 SNN、Transformer 已有普遍质量/效率/长记忆优势。

## 6. 原始边界、有符号通量与合用：独立九槽对照

此补充明确关闭所有 unsigned 通道，统一 N32/mixed/QVI/value-risk、原始未归一化五种读出特征、同一合格 fast 核。三臂只改变 recurrent 通道 mask：boundary_only 关闭后 2N 列，signed_only 关闭前 2N 列，boundary_signed 关闭中间 N 列。合法 sender/receiver 基础连接保持一致。配对种子 22011/32011/42011；独立 train 33000–33011、dev 34000–34003、test 35000–35015。每槽 512 更新、900 update-CPU 上限、180 update-CPU prefix；所有九槽封存后才生成测试。

三个前测全通过：signed 臂与既有 FastSigned 的 logits、features、全部五个动态状态张量、时钟及输入/参数梯度严格逐值相同；三臂未来因果、分块恢复、真实 BP 与禁用列零梯度；四类保存状态的 mask 篡改拒绝。配置中的 flow→full 是预声明等价表示变换，实际动态张量并未借此变更。正式封存与测试前再验证所有九个检查点的 initial/selected/last/cpu-prefix mask。

| 通道 | final accuracy 均值 ± SD | Brier | prelate accuracy | 学习+数值门 | 完整 fit wall 均值 |
|---|---:|---:|---:|---:|---:|
| 仅边界 | 51.17% ± 0.00% | 0.50109 | 51.17% | 0/3 | 255.31s |
| 仅有符号通量 | 91.34% ± 1.30% | 0.12738 | 74.77% | 3/3 | 250.93s |
| 边界+有符号通量 | 73.76% ± 0.31% | 0.40205 | 69.53% | 0/3 | 256.86s |

合用相对仅 signed 的三个配对 accuracy 差为 −18.457、−18.555、−15.723 个百分点，均值 −17.578 个百分点；两种 boundary 臂相对 signed 的 accuracy≥signed−0.02 且 Brier≤signed+0.02 工程容差门均 0/3。所有九个数值门通过，故这里的拒绝结论来自能力/质量，不能用正常退出或质量守恒改写。此结果针对原始编码与本次训练预算，不推断所有边界编码均不可能有效；此前 boundary 失败同样保留。

三臂分配的张量参数相同，但合用的活动 recurrent 参数是单通道的两倍：768/768/1536。因此实验识别的是给定结构与优化条件下的通信机制，不能称有效容量完全相同。全部 fit+test 子进程完整 CPU 共 2713.910s；外层含安装、前测、冻结、训练/测试与独立审计为 CPU 2733.225s、wall 720.250s。它们是嵌套口径，不能相加。systemd 实际 cpu.max 为 600000/100000、MemoryMax=6GiB；一次观测峰内存约 1.85GB且无 OOM。

九 fit、九 test 以及独立 NumPy 审计均终态成功，指标重算最大差 2.22e−16。六个新 raw 档包含数据结果、完整源码/安装器、前测和一次执行前的安装器语法错误、资源观测及审计；没有基于结果重新训练或更改既有冻结源。[固定协议](evidence/joint_boundary_signed/PROTOCOL.json)、[逐种子质量与完整成本](evidence/joint_boundary_signed/SUMMARY.json)、[真实前测](evidence/joint_boundary_signed/PREFLIGHT.stderr.log)、[归档身份清单](evidence/joint_boundary_signed/ARCHIVES.json)。
