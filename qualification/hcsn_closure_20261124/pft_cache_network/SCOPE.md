# Execution scope

The budget supervisor uses `fcntl.flock`; this is a POSIX/Linux research runner, not a cross-platform product claim. The fixed execution environment is Linux, Python 3.12.14 and NumPy 2.3.5 with one BLAS thread.

Completed `sendall` bytes indicate local socket acceptance of a complete application frame. They do not prove remote receipt. Actual `recv` bytes and unknown-delivery events are reported separately; TCP/IP headers and kernel retransmissions are not measured.

`DEPENDENCY_PROVENANCE.json` records a one-trailing-LF difference in the earlier #7198/#7200 executed helper. Its AST is identical to the repository helper; earlier artifacts and outcomes remain immutable. This runner uses the exact repository dependency bytes.
