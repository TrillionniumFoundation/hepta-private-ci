## Authority and lifetime behavior

The original accepted Unix stream and pidfd remain bound to the original A process. The actual frame reader mints a non-Clone opaque fence from its already computed deadline. That one request is moved through the queue to admission; the original checkpoint attempt is consumed before any CAS. The guarded store path borrows that same fence, checks it after temporary-file fsync immediately before rename, after directory sync, and after actual persisted readback. The issuer/Registry/Root postchecks and final frame check remain before returning Fresh. A durable write followed by failed checking is uncertain and cannot mint Fresh.

The runtime's private admitted flag is written only after successful Fresh admission and original gate installation. An A EOF before that state cancels this resident child. An A EOF after admission may leave the resident running under its independent original purpose lease, intent, fixed supervision end, and Root cancellation. A pidfd is not a resident lease. Neither a durable nonvacant observation nor a readback reply upgrades this state.

The client-only BOOTTIME pin checks actual boot identity and suspend-aware elapsed time around command transmission, reply authentication, and preclaim validation. It tightens the late-offer client window and cannot issue a new authority, rearm a consumed channel, or cancel an already admitted resident merely because A's original window ended. Server admission authority continues to use the original frame, purpose lease/intent, and Root fences.
