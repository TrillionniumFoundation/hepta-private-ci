# Finite learning decisions V1

`codex-hepta-intelligence::complete_authenticated_learning_decision_v1` records
an authenticated research conclusion without selecting or installing a model.
All four outcomes retain the exact incumbent identity for a later, separately
authorized task. No V5 update, reward or change to no-op admission is produced.

| Result | Required interpretation |
| --- | --- |
| Adoptable | Published product qualifications revalidate; complete research accounting and inventory permit independent selection. |
| NoUpdate | Independently attested absence of qualified data, completed finite search without an eligible candidate, or a predeclared budget boundary. |
| Inconclusive | Evaluation, owner terminality or any required cost category is unknown. |
| Failed | The cycle explicitly failed or exceeded its declared resources; partial evidence remains retained. |

The host must retain the plan digest before execution, then obtain exact candidate
and attempt inventories from existing owners. Caller-computed hashes alone do not
establish completeness. The artifact owner must resolve candidate IDs to exact
registered model bytes and bind the qualification's actual evaluated artifact;
terminal signatures alone do not establish that mapping. Generator, Observer and Evaluator authenticate the full
terminal statement under the current host trust; all three controllers must be
distinct. Every supplied product qualification is revalidated, including rejected
candidates. Missing qualification never becomes a measured failed evaluation.

All training, search and evaluation attempts remain in the receipt, including
failed retries. Successful retries must name the failed/stopped predecessor in
the signed native inventory; prior or unrelated successes cannot hide failures,
and unknown original tasks cannot be retried. Shared failures use the same rule.
Attempt IDs must preserve the original owner's monotonic journal order; each
original native receipt remains pinned in the canonical inventory.
Nine disjoint cost categories use the pinned normalization;
unknown values remain unknown. A budget stop requires the evaluated candidate cap,
the attempt cap, or that
the predeclared next-attempt reservation cannot fit. NoUpdate makes no assertion
about unsearched models, unperformed evaluations or an unlimited search.

This is a pure native contract with synthetic authenticated regression evidence.
It does not claim real task performance, independent organizations, native owner
inventory collection, durable publication, actual incumbent use, or production
Agentd integration. Existing proposal admission, selection and final-use owners
remain mandatory. A receipt must be durably retained by its original host before
being reported as a completed product cycle; this function grants no write or
resource-release authority and does not substitute for that acknowledgement.
The owner consumes each cycle ID and frozen terminal payload once. Revalidation
in the same valid trust window has the same receipt identity and rechecks expiry;
it is not another learning cycle or another reward.

Run the owning crate tests with `just test -p codex-hepta-intelligence`.
