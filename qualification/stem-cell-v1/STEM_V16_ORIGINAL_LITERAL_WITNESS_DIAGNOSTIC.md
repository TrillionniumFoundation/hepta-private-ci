# V16 — Original pretrained Reader, literal-answer witness diagnostic

**Research / SHADOW_ONLY / HOLD_NO_GO / DENY_ALL / no main merge / no FinalUse.**

## Question and scope
V15 provided the original 135M Reader with a publisher-annotated witness and saw only a small number of literal answer-string matches. Publisher annotations do not prove evidence sufficiency, and response changes are not evidence of correct reasoning.

V16 tests a narrower observable prerequisite: when the **original publisher answer string literally occurs in the publisher's annotated source turn**, does the same frozen Reader copy or produce that answer more often than with no evidence, BM25 retrieval or an answer-bearing-source deletion? This is explicitly **answer-dependent historical cohort selection**, not blinded enrollment, independently human-certified sufficiency, causal task utility or new-source generalization. A second negative control comprises single-witness annotated cases without the answer literal in that source.

## Source/target isolation
1. Separate `prepare` opens the complete original publisher record **only to choose answer-dependent historical cohorts**. It writes a create-only plan whose prompt material contains source and question but no publisher-answer field. This is *not source-blind experimental selection*.
2. Separate `run` opens only the SHA-pinned source-only document, original fixed BM25 rankings, immutable selected plan and original Reader weights/tokenizer. It does not take the publisher answer file as input. Each start is fsynced before model dispatch; missing/interrupted requests cannot become complete answer seals.
3. Independent token-level re-reader reconstructs every prompt, tokenizes again, decodes the original generated IDs, recounts exact model forward steps and checks all 128 expected answer identities. Original answers and dialogues remain private.
4. Separate postseal scorer opens original publisher answers and recomputes the answer-dependent plan. A separate scorer rederives literal source containment and every reported family/arm statistic. Publisher string equality and substring matches are descriptive weak proxies, **never semantic task correctness or citation entailment**.
5. A public source-only negative gate refuses an incomplete cohort, forged Reader capacity, invented human review, false production authority, fake calendar windows or a claimed Stem victory.

## Scientific interpretation
- The `literal_in_annotated_source` cohort shows literal answer availability, **not independently verified sufficient evidence**. A quote may be ambiguous or contextually unrelated. A substring in generated text may also be ungrounded or a spurious coincidence.
- The negative cohort may still contain adequate paraphrased evidence; treating its literal absence as proof of insufficiency is forbidden.
- Exact repeatable generated bytes validate deterministic execution of the candidate model runtime only. They do not prove correct model operators versus the official Hugging Face implementation, source truth or benchmark generalization.
- There are no independent future source windows, authenticated external adjudicators, physically executed stronger Reader, matched end-to-end lifecycle costs, V6 seed41 retention resolution, multi-modal task gains, NDU advantages, or 4,096-Cell production admission.

The project should next obtain independently verified sufficient evidence labels and a genuinely stronger Reader, then rerun 4×2-arm source-disjoint matched-cost original generation and blinded semantic evaluation. Until then: **HOLD_NO_GO / DENY_ALL**.

## Actual 2026-10-16 physical result and strict limit

Original BF16 checkpoint/Tokenizer was SHA-confirmed, loaded as a frozen CPU FP32 candidate. The *first* original physical trial completed **128/128 actual full Reader responses**, with **2,951 actual counted model forward calls**, **16,264 input tokens** and **2,855 generated tokens**, consuming **436.3551 CPU seconds** and **227.1259 wall seconds** inside the executing model process. No silent clipping, skipped requests or inferred success.

On the 16 publisher-answer-literal-in-witness retrospective questions, exact publisher answer as a substring of raw generated Reader text was **witness 8/16, BM25 0/16, lesion 0/16, no evidence 0/16**. On 16 publisher-annotated-source but answer-not-literal questions, the same proxy was **witness 0/16, BM25 1/16, lesion 1/16, no evidence 0/16**. Whole-answer exact casefold equality was **0/16 in every arm of both groups**. The first held group response changed in all 16 cases on witness injection. No `unknown` literal was emitted under no-evidence prompts; this is not independently scored hallucination. The four historical family roots supply four groups per cohort; 32 rows are correlated, not 32 independent families.

The new **independent original-input tokenizer/answer/model-forward recount PASS** verifies all 128 planned requests, exactly 2,951 model forwards and every original output token/text. A separate original-publisher-label implementation also reproduces every family/cohort/arm weak-literal count. This establishes reproducible **literal-extraction behavior**, not **semantic correctness, independently adjudicated sufficiency, evidence entailment or a learned Cell/Stem benefit**. There was **zero Head training** and **no stronger reference model** in this increment.
