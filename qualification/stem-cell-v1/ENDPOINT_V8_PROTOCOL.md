# V8：实体端点匹配与变量绑定的受控工程诊断

本协议在 V8 初始化、神经训练与末评前冻结。V7 的十二模型均未通过联合资格，
本轮检验在既有共享 Encoder 和 BridgeReader 上增加实体端点支路是否改善关系课程。
本轮范围止于固定末权重、完整末评和旧训练集反事实诊断；feedback/fresh 无条件关闭。
任何通过只构成制定下一独立协议的必要证据，不自动授权训练、反馈或留出评分。

## 1. 共同起点与四臂

种子固定为 41、47、53，分别复用实际 V6 bridge warmup 的 4,000、500、4,250 步权重。
不复用失败的 V6 continuation 或 V7 末权重，不重跑历史 warmup 冒充新证据。
每种子四臂完整保留同一旧 Reader 和 FactBridge 的参数名称、数值、来源与执行摘要；
“保留旧核心”指初始化与架构保留，旧参数在本轮继续学习，不是冻结旧权重。

| 臂 | 新增参数 | 总参数 | 事前角色 |
| --- | ---: | ---: | --- |
| bridge | 0 | 42,562 | 同期原架构对照 |
| endpoint | 4,160 | 46,722 | 主臂，正确端点/载荷对应 |
| broken | 4,160 | 46,722 | 同支路，破坏消息键值对应 |
| local | 4,160 | 46,722 | 等新增参数的局部 Head 对照 |

新增支路末输出权重初始化为零；四臂初始化预测须与其共同 V6 起点一致。
endpoint 与 broken 的全部新增张量初值逐字节相同，差别仅为冻结的载荷置换规则。
local 的结构不同，保存完整张量身份，不能以相同参数量声称相同初值或算力。
其四方阵初值与 endpoint 的 input/match/value/output 按角色匹配；
LayerNorm 的 64 个仿射参数与 slot 的 64 个参数含义不同，不要求它们字节相等。
所有初始化、历史权重、训练来源、架构描述和新增参数摘要在首个更新前保存。
prepare 实际执行十二臂/种子组合的旧 128 例初始面板，共 1,536 次候选观测，
要求同种子四臂保存概率逐项完全相等；保存批次成本，这不是复用历史成绩的新名称。
不增加 Cell、共享 Encoder、工作状态维度、模态、长链或 NDU 控制器。

## 2. 端点支路与破坏规则

隐藏维度 `h=32`。端点支路只读取公共原始 fact-token 及其 mask，
输入为 `x_it = LayerNorm_h(project(LayerNorm_384(raw_fact_token_it)))`。
这里的 `project` 为保留的旧投影；本支路不读取 question、candidate 或其条件化 relations。
接口的 fact 轴实际是最多 62 个 content token 的文本 chunk，自然长句可分成多个 chunk；
本节公式的 `i/j` 指这些 chunk。受控旧题和新课程的短句各恰好对应一个 chunk。
slot/跨 fact 匹配因此是 chunk 内/间的学习运算，不能称为完整句法实体抽取或长文本关系处理。
共同旧 FactBridge 照常产生 `r_common`，端点支路与它并行，不替换旧支路。

令 `z_it=GELU(W_in x_it)`。两个可学习 slot query 在各事实有效 token 内注意：
`alpha_irt=masked_softmax_t(slot_query_r dot z_it / sqrt(h))`，
`k_i=sum_t alpha_i0t*z_it`，`v_i=sum_t alpha_i1t*z_it`。
端点匹配两侧共享矩阵 `M`：`u_i=normalize(M v_i)`，`t_j=normalize(M k_j)`，L2 normalize 的 `eps=1e-8`；
`A_ij=masked_softmax_j(sqrt(h)*u_i dot t_j)`，只允许有效事实且 `j != i`。
正确消息为 `m_i=W_out sum_j A_ij W_v(v_j)`，
并以 `r'_it=r_common_it+m_i*token_mask_it` 加入旧 relations，随后沿旧 Reader 递归。
零或一个有效事实时，两种端点臂均输出零消息，不能从 padding 构造新证据。

新增参数为四个无 bias 的 `h×h` 矩阵 `W_in/M/W_v/W_out` 和 `2×h` slot query：
`4h²+2h=4,160`；`W_out=0`。支路没有额外递归状态或基于标签的实体抽取。
slot 是可学习的连续注意位置，不是提供了实体真值或预先识别出两个实体。

broken 保持原始 `k/v` 计算、匹配分数和 `A` 不变，仅将聚合中的载荷改为 `v_pi(j)`。
这里 `j!=i` 只排除接收 chunk 自身的 key 索引，不能保证 `pi(j)!=i`；
broken 仍可能回传自身 payload。恰两个有效 chunk 时，其载荷全部来自接收 chunk 自身。
因此此干预同时改变对应关系和跨 chunk/本地载荷混合，不是严格排除自身信息的对照。
对每例有效事实，以其原始公共有效 token 的 dtype/shape 前缀加连续 FP32 字节的 SHA256 排序，
前缀精确为源码的 `str((str(value.dtype), tuple(value.shape))).encode()`，随后更新原字节；
在此顺序作固定一位循环移位；相同 hash 按原 fact index 打破 tie。
排序与置换不读取 label、支持句、question、candidate 或模型成绩，不按学习结果改变。
重复事实的 tie 处理限制严格句序等变性；确定性破坏也可能被后续训练部分补偿。
因此该对照检验这一特定键值配置，不构成完全隔离变量绑定机制的因果证明。

local 在旧 Head hidden 上先作带 `2h` 仿射参数的 LayerNorm，
依次执行三个 `h×h` 无 bias 线性层加 GELU、最后一个 `h×h` 无 bias 输出层，
将结果残差加回旧 hidden 后进入原最终二类输出层；末输出矩阵为零。
它不增加跨事实信息交换或实体 slot；四方阵加 LayerNorm 共 4,160 参数。
所有臂保留相同有界 Reader 状态、输入限制、depth 和公共六张量推理接口。
标签、支持索引、配对身份只用于损失或独立评分，不能作为模型 forward 参数。

## 3. 数据、采样与固定训练预算

完整复用 V7 diverse 数据成员、顺序及各种子训练计划，不生成按结果筛选的新课程。

| 数据 | 规模 | 本轮用途 |
| --- | --- | --- |
| 自然训练 | 官方 train 的既定 64 段、722 问、3,909 候选 | natural 流与自然学习资格 |
| 新关系 augmentation | 256 组、1,024 候选、512 配对 | augmentation 流与训练诊断 |
| 旧关系训练 | 32 组、128 候选、64 配对 | old 流、保留资格与反事实诊断 |
| 旧关系内部集 | 16 组、64 候选、32 配对 | 已暴露课程资格，不反传 |
| 自然内部集 | 16 段、194 问、827 候选 | 已暴露、仅固定末尾描述 |

augmentation 的语法真值、完整双世界/双候选结构和 V7 成员摘要必须一致；
沿用其对 V4 train/tune/final 及 V5 全部角色的语义与事实来源排除，包括 reserved 域。
不访问官方 validation；fresh 不编码、不预测、不评分，也不构造其支持句诊断。
冻结词表、完整案例、数据源字节、token 缓存和采样计划，不能按成绩补样或换成员。

每臂每种子恰好 500 cycle，固定顺序为 `natural → augmentation → old`，
每流一个独立 Adam 更新，batch16、depth3、学习率 `.001`、`foreach=False`。
每模型 1,500 更新、24,000 候选曝光；每流 8,000，旧题和新题剂量四臂完全相同。
十二模型合计 18,000 更新、288,000 曝光；不把重复曝光称为新增独立案例。
同种子四臂三条采样序列逐项一致；受控 minibatch 保留完整四候选 group。
各臂独立重置 Adam，不承接 warmup 动量；全部旧参数和新增参数均可学习。
natural 使用最终 hop 二类 CE；两个受控流使用最终 CE 加 `.5×pair_margin`，margin=1。
不加教师、蒸馏、锚定、evidence loss 或其他监督，不改变最终 hop 的监督定义。

固定诊断不控制采样、学习率、步数或主臂；不早停，不选择“最好一步”。
每模型完成预算后先冻结末权重，再作固定末评；即使已有主臂失败，仍完成全部十二模型。
全部模型完成后才作全局资格判断；运行顺序和资源上限在 design 中事前固定。
达到资源上限须保留部分工作和失败收据，不能暗中续跑、补步或当作完整预算。

## 4. 沿用 V7 的联合工程门槛

主臂固定为 endpoint，其他臂不能在它失败后替代。每个种子必须同时满足以下三组：

| 检查 | 固定门槛 |
| --- | --- |
| 旧题保留 | 128 候选准确率≥.95、64 配对全对率≥.95，二者相对本种子 warmup 降幅均≤.05 |
| 已暴露内部关系 | 64 候选准确率≥.75、32 配对全对率≥.50 |
| 自然训练确实学习 | F1m≥最佳固定常数+.05；F1a≥本种子实际起点+.05；问题 EM≥.05；概率 CE≤训练先验常数 CE×.95 |

整数门槛分别至少为 122/128、61/64、48/64、16/32 和自然 EM 的 37/722。
自然起点精确复用 V7 保存的同种子实际 V6 warmup 完整 3,909 例观测，
将 `start-natural-train.json` 字节 SHA、warmup 执行参数摘要、案例顺序和来源互绑。
三份起点各由四臂共享，不重新执行自然起点评测、不四次计费、不挑选起点。
这是历史观测复用；本轮新增的十二个旧题初始化面板另行实测并计费。

固定预测为保存正类概率 `p>.5`，相等判负。F1m 沿原完整问题内 macro-F1 定义。
自然 best-constant F1m 为 `.35801425689161626`，故最低 F1m 为 `.40801425689161624`；
常数比较包含 always-positive、always-negative 及与后者相同的 train-majority。
训练正例 `1696/3909`，先验常数 CE 为 `.6843752947861224`，上限为 `.6501565300468162`。
概率 CE 为保存 FP32 概率上的 `-mean(log(max(p_gold,1e-12)))`；与 logits 训练 CE 分开报告。
逐种子保存每项失败原因，不能用均值、旧题全对或单项 CE 下降抵消其他失败。
新课程成绩完整报告但不替换三组资格；自然内部成绩不参与门槛或选臂。
这些数据已经暴露，联合通过也不是 fresh 泛化、更快新任务学习或推理涌现的证明。

## 5. 固定末尾反事实诊断

所有十二模型在同一旧 128 候选上执行下列三种诊断，不重训、不调阈值、不进入 gate。
既有旧训练 `full3` 面板复用为共同参照，不再执行或重复计费。

| 诊断 | 固定干预 |
| --- | --- |
| deleted3 | 删除每例两个支持事实，depth3、状态照常传递 |
| reset3 | 原始完整事实、depth3，真实调用 `reset_state=True` |
| full1 | 原始完整事实、同一最终权重，`steps=1` |

deleted3 只在旧训练集构造：先独立语法验证每例恰有两个支持句，且支持索引与冻结案例一致；
它们为目标物品的所有权句与其持有人的存储句，否则在执行前失败。
同时核对这四个短句各自恰为一个 fact chunk，不能把自然长句的 chunk 当作完整句使用。
将对应两个 fact 行的 token 值归零、mask 全设 False，保留另外两行及位置、Q/c、
case 顺序和原 label。支持索引仅在评估输入变换中使用，不传入模型，也不改目标标签。
这区别于清空全部 evidence；保存干预规则、所删句索引、变换摘要和物理批次。
删除后问题可能已不可答；只描述原标签下的证据敏感性与配对变化，不期待准确率提高。
复用冻结 token 缓存，不新增 Encoder 调用；变换、实际 Reader 执行及序列化均记录成本。
reset3 必须真实重置每 hop 的状态；full1 不使用另训浅模型或中途 checkpoint。
这些训练内干预不能证明未见任务推理、独立验证收益或变量绑定机制已被唯一识别。

## 6. 估计对象、成本与停止边界

endpoint 对 bridge 估计新增端点支路的配置效应，包含新增容量，不能独自识别结构贡献。
endpoint 对 local 比较等新增参数的结构配置；endpoint 对 broken 比较冻结的对应破坏配置。
四臂样本、顺序、旧题剂量、优化预算相同；参数相同或曝光相同仍不代表实际成本相同。
本轮 bridge 是同期对照；V7 diverse 可作历史一致性参照，不能取代它或据跨轮时长作因果结论。

保存每次更新原始 logits、损失、采样身份、共同起点、参数来源和训练/执行摘要；
独立审计重算语法、概率指标、门槛、曝光、权重字节及所有实际面板的覆盖范围。
分别报告完整子进程 CPU/wall/RSS、函数与物理批次的嵌套成本，不相加；未知 FLOPs 保持未知。
共享 Encoder/token 缓存和 warmup 的历史费用单列，不在四臂重复充值，也不能称为免费。
本轮没有 teacher 前向；历史教师缓存不得冒充本轮调用或叠加到训练成本。
旧 58 个 runtime 与旧协议保持不变，新 V8 源码、协议和运行 design 在首个更新前冻结。

无论主臂是否全通过，本轮 feedback/evaluation 启动和完成 marker 均须不存在。
后续真实 verifier 闭环、fresh、NDU、模态或长链需要独立冻结协议和明确执行授权。
审计代码支持、已冻结计划或单元测试通过均不等于实际神经阶段已经执行或取得收益。
