# V4 结果：真实 token 表征与原生 NDU 闭环

本轮把真实共享 Encoder、轻量 token Reader、有界递归、独立 verifier、冻结
critic 和原生 Q32 控制器接成可计量闭环。训练内联合拟合通过，但自然新留出
及受控新词表任务没有建立稳定泛化收益。当前证据不支持把更多推理计算当作
已经获得更强学习能力，也不支持推广为生产推理系统。

## 已实现并实际运行

| 部件 | 本轮实现 | 范围 |
| --- | --- | --- |
| 共享基座 | 固定 revision 的 Granite 97M，97,441,152 参数冻结 | 单一已验证基线，未证明最优 |
| 表征 | 完整内容 token，64-token 独立分块，原字符串去重缓存 | 跨块组合交给 Reader |
| 轻量核心 | 38,466 参数 Reader，token 对齐、证据注意力、有界状态 | 最大三步，未训练基座 |
| 学习 | 三种子各五个模型，每模型 1000 次更新 | 记录真实自然/合成曝光与成本 |
| 独立组件 | 每种子独立 verifier、14 参数冻结 critic | 拟合、校准来源均与 Reader 分离 |
| 控制 | 实际 propose/verify/estimate/revise 与 Rust Q32 决策 | 经验 next-correctness，不是通用 FBSDE |
| 干预 | 删除证据、状态重置、同模型一步与三步、受控关系交换 | 自然删除不制造新负标签 |

复现细节见 [runbook](TOKEN_EVIDENCE_V4_RUNBOOK_20261015.md)，
失败探针、冻结配方和解释边界见 [方法记录](TOKEN_EVIDENCE_V4_METHODS_20261015.md)。

## 自然新留出

16 个此前未评测的官方验证段落，945 个候选、187 个完整问题。三种子重复
使用相同案例；不能把 2835 次试验当成独立样本。下表是各种子指标的算术平均，
阈值仅在训练来源内的固定调参集选择。CPU 为三个种子该面板物理批次之和，
包括计量开销；不含共享 Encoder、训练或序列化外层开销，也不是逐案例延迟。

| 设置 | F1a | 问题 EM | 候选准确率 | 批次 CPU 秒 |
| --- | ---: | ---: | ---: | ---: |
| 全正基线 | 0.5832 | 3.21% | 41.16% | 不适用 |
| 全负 / 训练多数类 | 0.0000 | 0.53% | 58.84% | 不适用 |
| 等参数池化 | 0.5747 | 3.57% | 45.26% | 9.049 |
| token 一步 | 0.5792 | 3.92% | 43.84% | 10.566 |
| 干预 token 一步 | 0.5774 | 2.85% | 44.51% | 10.379 |
| 递归模型只执行一步 | 0.5719 | 3.92% | 44.94% | 11.135 |
| 同模型三步递归 | 0.5690 | 4.28% | 45.47% | 14.192 |
| 同模型每步重置状态 | 0.5719 | 3.92% | 44.94% | 14.385 |
| 独立训练的无证据模型 | 0.5799 | 3.57% | 43.07% | 11.098 |

三步相对同模型一步的 F1a 平均下降约 0.00285，EM 上升约 0.00357，
批次 CPU 增加约 27.5%。这是指标取舍，不能称作稳定推理净收益。
token 相对池化的 F1a 小幅增加，但不超过全正基线；单一指标及小留出集
不足以确立表征优势。固定 raw probability >0.5 的完整结果另存于汇总 JSON。
在统一 raw >0.5 规则下，递归与同模型一步只改变 25/2835 次判定：纠正 13 次、
损坏 12 次。各臂分别调参的阈值会另带阈值效应，不能全部归因于状态贡献。

旧 V3 的 747 个候选、152 个问题单独作回归，不计作新留出。
每个模型的参数量相同，实际成本不同；干预训练约一半更新替换自然批次，
所以干预与普通 token 模型也不是自然曝光次数相等的对照。

## 训练内可学性与关系泛化

正式小样本门槛同时得到自然训练准确率 100%、受控双世界全对 100%；删除
受控证据后准确率 50%、双世界全对为零。它只证明小样本联合优化可行。

扩大到正式训练后，受控 final 使用与合成训练不同的人名/物品词表，语法及
颜色共享。自然调参阈值下，七种设置、三个种子的双世界全对为 0–1.5625%；
F1a 为 2/3 的全正预测不代表关系推理。预注册 raw >0.5 下，递归模型的
双世界全对分别为 0%、6.25%、0%；一步分别为 0%、1.5625%、0%。
这没有建立跨词表的关系组合能力。训练内 tiny gate 不能替代扩大样本后的
保留测试，更不能解释为共享基座已经学会推理。

正式训练未记录冻结模型在完整合成训练集及已编码合成 tune 上的保留率；
六个辅助训练模型最近 50 个合成批次的平均 CE 约为 0.69。tiny gate 到正式
训练的合成案例从 16 增至 128，而合成总曝光仍约 8000，因此每例曝光约少
八倍。自然候选则从 45 增至 3909，辅助臂自然曝光总数除以候选数约为 2.1；
该平均数不意味着每例均匀访问。这些记录不足以区分失败原因，也不能据此断言
Encoder 表征不足或必须换更大基座。

## 事后训练保留诊断

为补上这个缺口，主评测完成后另行冻结诊断计划，只读取六个已冻结辅助模型、
已有 128 个合成训练候选和 64 个内部调参候选。没有新增 Encoder 调用、梯度
更新、阈值选择或官方新留出访问。以下为完整证据、raw >0.5 的双世界全对数；
分母为成对候选，不是源任务数。anchors 从训练结果复用，不重复计推理成本。

| seed / 模型 | 训练 /64 | 内部调参 /32 | 小样本锚点 /8 | 训练概率 CE |
| --- | ---: | ---: | ---: | ---: |
| 41 / 干预一步 | 0 | 0 | 0 | 0.693317 |
| 41 / 递归 | 0 | 1 | 0 | 0.687119 |
| 47 / 干预一步 | 3 | 0 | 3 | 0.700268 |
| 47 / 递归 | 1 | 0 | 0 | 0.693885 |
| 53 / 干预一步 | 1 | 0 | 0 | 0.693241 |
| 53 / 递归 | 0 | 1 | 0 | 0.693295 |

训练候选准确率为 48.44–50.78%；原自然阈值下所有训练、调参与锚点的
双世界全对和切换率均为零。已训练候选本身也未建立绑定能力，故不能只把
留出失败归因于新词迁移。正式模型独立初始化，并非从 tiny gate 权重继续，
因此锚点差不能解释为同一模型的过程遗忘。尚未隔离的原因包括优化不足、
联合干扰与表示/结构限制。

该诊断是事后解释，不是预注册 benchmark，也不参与选择。共 2304 条观测、
288 个物理批次，57 个输入文件前后摘要相同；独立语法及概率复算通过。
完整进程 CPU 10.868 秒、wall 10.070 秒；内部批次成本是其拆解，不再相加。

## 后续实现优先级

先补“扩大样本后仍保留关系学习”的训练内关卡：同时报告完整自然训练、
全部合成训练、新词表训练内调参、相反证据配对与多步长度分组成绩。
这些关卡未通过时不打开下一批新留出，不通过增加推理深度掩盖学习问题。

下一轮应单独训练并消融 verifier 反馈下的修正行为，保留错误候选、验证反馈
与修正轨迹，再训练以“相对停止的未来增益”为目标的 critic。当前关闭未训练
反馈通道的实验不提供状态修正能力证据。普通自适应 gate、等参数宽 Head、
更长链和未见任务组合仍需在相同 token 基座上补齐，才能隔离 NDU 的因果贡献。

共享 Encoder 继续作为资源摊销基线；本轮没有复制或对比多个 421M 模型，
没有图像/时间模态、Encoder 蒸馏更新或 Cell split 的生命周期收益结果。
在关系泛化和边际计算收益成立前，不据本轮结果触发生产 Cell 分裂或基座替换。
