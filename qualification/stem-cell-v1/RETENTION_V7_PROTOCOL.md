# V7：保留、关系课程与自然任务学习的联合资格协议

本协议在 V7 模型训练与起点神经评测前冻结。目标是在同一共享 Encoder、
同一 BridgeReader 和相同样本曝光下，检验关系数据多样化、旧输出锚定与低学习率。
V6 已证明三种子可拟合全部旧受控训练任务，但未建立稳定保留或关系迁移。
本轮不能以“保住旧题但没有学习自然任务”冒充持续学习成功。

## 1. 固定起点与数据身份

- 三个种子为 41、47、53；各自从实际 V6 bridge warmup 开始，分别为
  4,000、500、4,250 更新后保存的冻结权重，不用失败 continuation 替代。
- 每个种子的四臂起点具有相同架构、参数值、训练/执行两种摘要和训练来源。
  BridgeReader 为 42,562 参数；Encoder 与既有 token 特征保持冻结。
- 旧受控训练：32 组、128 候选、64 个跨世界候选配对，精确复用 V5/V6。
- 旧受控内部集：16 组、64 候选、32 个配对；V4/V6 已暴露，只作课程资格。
  不对其反向传播，也不根据其成绩选择本轮臂、学习率或训练步数。
- 自然训练：官方 MultiRC **train** 中既定 64 段、722 问、3,909 候选。
  自然内部集仍为既定 16 段、194 问、827 候选，只在固定末尾报告，不参与选择。
- V5 两个尚未评分的 fresh 受控域继续保留；二者仍是两跳任务，不是更长链。
  不读取其模型预测、成绩或官方 MultiRC validation；不增加模态或更长链主张。

数据文件、完整案例顺序、段落来源、预处理、token 缓存、起点权重、
新运行源码和协议均保存字节 SHA256。V6 的 52 个冻结 runtime 文件不改；V7 另加 6 个 runtime 文件，共绑定 58 个。

## 2. 新关系训练课程

新 augmentation 为固定 **256 组 / 1,024 候选 / 512 配对**，所有种子共用同一数据。
每组保留两个相反所有权世界及每世界两个候选；问题、候选与词频保持成对不变。
句序随机，语法真值和支持句由独立解析器复核；标签、支持索引不进入模型 forward。

新课程必须排除受控 V4 train/tune/final 和 V5 所有登记角色，包括未使用的
verifier_fit 及保留 fresh 源。排除按句序无关的完整事实来源和
`sorted(facts) + question + candidate` 语义键执行，不能只排 case_id 或原句序 SHA。
涉及保留域时只用已冻结来源/语义排除清单，不读取 fresh 分数。
人物和物品词表、采样种子、生成上限与最终成员在训练前冻结；不得按成绩补样。
新课程不得复用旧内部集专属人物/物品，以保持该词表迁移检查的解释范围。

## 3. 四个学习臂与实际预算

主臂事前指定为 **anchored**。其余臂仅作对照，不能在主臂失败后替换主臂。

| 臂 | transfer 数据 | retention 额外项 | Adam 学习率 |
| --- | --- | --- | ---: |
| repeat | 重复旧 128 候选 | 无 | .001 |
| diverse | 新 1,024 候选 | 无 | .001 |
| anchored（主臂） | 新 1,024 候选 | centered-logits MSE，λ=1 | .001 |
| low_lr | 新 1,024 候选 | 无 | .0001 |

每臂每种子执行恰好 **500 cycle**，固定顺序为
`natural → transfer → retention`，每流各一次独立优化更新、batch16、depth3。
因此每模型为 1,500 更新、24,000 曝光：自然 8,000、transfer 8,000、retention 8,000。
十二个模型合计 18,000 更新、288,000 曝光；不把重复曝光当新增独立案例。
repeat 的两个受控流都访问旧题；另外三臂 transfer 访问新课程、retention 访问旧题。

自然流使用最终 hop 的二分类 CE。两个受控流使用最终 hop CE 加
`.5 × paired margin loss`，margin=1，整组四候选不得拆散。
不改变 evidence loss、hop 监督、状态边界、Encoder 或 Reader 参数规模。
各臂独立重置相同 Adam 状态，不承接 V6 的优化器动量。

自然、新课程和旧题采样计划预生成，保存索引、case_id、来源、深度与摘要；repeat 的 transfer 与 retention 在同一 cycle 复用相同旧题批次。
同一种子四臂 natural、retention 顺序完全相同；diverse/anchored/low_lr 的
augmentation 顺序完全相同。repeat 另用固定旧题 transfer 计划。
受控采样按完整 group、每 epoch 无放回；自然采样规则沿既有固定计划。
学习率、数据、采样流不得由中途诊断控制；没有早停或“最好一步”选取。

相同曝光和参数量不等于相同实际算力。记录每次更新、失败尝试、初始化、
编码/缓存恢复、锚定、评测、序列化和完整子进程 CPU/wall/RSS；神经任务顺序执行。
若触及预先冻结的资源上限，保留实际部分工作与失败状态，不能当完成预算或静默续跑。

## 4. 旧教师与锚定定义

每种子教师为其冻结 V6 warmup，只缓存旧 128 例的原始二类 logits。
教师 logits 用实际、有成本记录的前向产生，不能从已保存的 FP32 概率逆推。
缓存与输入顺序、权重摘要、FP32 内容和文件摘要互绑，教师不参与梯度更新。
三种子的教师缓存分别建立；同种子各臂可引用同一初始观测，实际成本只记一次。

对每行 logits 定义 `center(z)=z-mean(z)`。anchored 的 retention loss 为
`CE + .5*pair_margin + mean((center(z_student)-center(z_teacher))**2)`。
最后一项对本 retention minibatch 的样本和两类坐标取平均，不增加可训练参数。
另外三个臂不加此项；anchored 的 natural/transfer 流也不加此项。
锚定保留教师行为，不能证明行为正确；本教师旧训练全对仍须由独立评分确认。

## 5. 冻结联合门槛

所有最终决策固定为保存正类概率 `p > .5`，相等时判负，不调阈值。
各种子在训练前实际测量同一冻结起点的完整自然训练成绩，得到 `F1a_start[s]`。
四臂复用同种子这一基线观测，不能重复计为四次新前向或用最终结果重定义起点。
每模型完成 500 cycle 后先冻结其权重，再作固定末评与资格判断；即使先完成的主臂失败，也继续完成其余预定臂和种子。全部十二个模型冻结并完成后，才作全局资格判断。

| 检查 | 每个种子必须同时满足 |
| --- | --- |
| 旧训练保留 | 128 候选准确率≥.95，64 配对全对率≥.95，二者相对本种子 warmup 降幅均≤.05 |
| 已暴露内部关系课程 | 64 候选准确率≥.75，32 配对全对率≥.50 |
| 自然任务确实学到 | 完整自然训练 F1m≥最佳固定常数基线+.05；F1a≥`F1a_start[s]+.05`；问题 EM≥.05；概率 CE≤类先验常数 CE 的 .95 倍 |

旧训练整数门槛为至少 **122/128 候选、61/64 配对**；内部关系门槛为
至少 **48/64 候选、16/32 配对**。自然 EM 门槛对应至少 **37/722** 个完整问题。
每一项都参与联合门槛，不能用平均种子成绩、自然 CE 单独下降或旧题全对抵消失败。

自然 F1m 沿 `multirc_data.score_multirc` 的完整问题定义：每问题按实际出现的
真值/预测类别取 macro-F1，再对问题平均；不是整批二类 macro-F1。
固定基线为 train-majority、always-positive、always-negative，全部在同一 3,909 例计算。
已知最佳基线 F1m 为 **.35801425689161626**，故门槛为 **.40801425689161624**。
always-positive 的 F1a 为 .6051739518287244；所有指标同时报告，不隐藏廉价基线。

自然正例为 1,696/3,909，令 `q=1696/3909`，固定类先验常数 CE 为
`H(q)=-q*ln(q)-(1-q)*ln(1-q)=.6843752947861224`，允许上限为
**.6501565300468162**。学生概率 CE 为保存 FP32 概率真类项的
`-mean(ln(max(p_gold,1e-12)))`；logit-space 训练 CE 另记，不把二者当可精确互换。

上述门槛是 V7 新的事前工程资格条件，不追溯修改 V6 的历史拟合或保留结论。
内部关系 75%/50% 只约束当前已暴露课程，不是未见任务泛化证明。
冻结或过小学习率若没有自然任务增益，必须失败；自然内部 827 例不参与资格或选臂。

## 6. 下游、审计与停止边界

只有 anchored 的三个种子全部满足联合门槛，才准许接入后续反馈训练。
repeat/diverse/low_lr 即使通过也不能替换失败主臂；失败后不得追加更新或改门槛。
真实反馈使用 `fit_revision_pair`，适配 BridgeReader、完整训练来源和旧独立冻结 verifier，记录实际计划与输出。反馈后的联合门槛必须用 `execute_revision` 实际执行对应 real/zero 模式：每批三次 Reader 和两次 verifier；不能以普通零反馈 forward 代替 real 闭环资格。

Fresh 开启前必须冻结本轮登记的全部模型、数据、阈值、成本策略和门槛证据，
包括实际纳入比较的反馈臂。只能进行一次独立评分，不能看结果后补训或改对照。
若训练阶段主臂联合门槛失败，feedback/fresh 的启动与完成标记必须不存在。反馈后仍须 real 主臂三种子重新通过同一联合门槛，否则 fresh 标记必须不存在。
状态重置、删证据等留出控制也保持关闭；更长链与多模态不属于本协议。

独立审计重算语法真值、概率指标、联合门槛、逐条采样与曝光、共同起点、
教师缓存、模型来源与两种参数摘要，并核对训练阶段前后字节冻结。
完整子进程成本与函数内/物理批次成本分层报告，不相加；未知 FLOPs 保持未知。
即使三种子联合通过，也只支持本训练与已暴露课程资格，不能据此声称
推理涌现、自然任务泛化、更快新任务学习、NDU 净收益或生产 Cell 分裂已经成立。
