# Cold replay of the published asynchronous event-state-space SHD model

Use the authors' Event-SSM medium checkpoint and official source commit a12766788413665cd3dcf8eaa010d551d8841eb7. Independently hash the downloadable checkpoint, decode the public weight format without optimizer mutation, feed the original event timestamps and cochlear locations and run its original model.apply in evaluation mode. Evaluate all 2,264 official examples and both new speakers separately, full logits, trainable count and elapsed time. Record exact dataset conversions and any discrepancy with the author-reported 95.9%. Include a no-timing counterfactual using the original event identity stream and constant per-event integration interval preserving utterance duration. Preserve class/speaker counts. Run inference on CPU without touching the main arms or their frozen choices.

The official SHD task config explicitly sets validate_on_test: true. This is an external, pretrained-on-task performance reference; it has a different endpoint count, parameterization, training budget and checkpoint selection convention from our new controlled from-random-initialization panel. Its wall time is a cold inference measurement. It does not enter the prospective architecture gate or supply a matched training-time comparison.
