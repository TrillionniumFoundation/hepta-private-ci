Full SHD HDF5 records timestamps in float16 seconds. The first direct wrapper multiplied this array by one million under NumPy 2.x, whose scalar-promotion behavior can keep float16. This overflowed and made the timing input invalid. That invocation was quarantined before any performance result was accepted. The corrected wrapper converts seconds to float64 before multiplication, casts to integer microseconds as in Tonic's represented stream, checks all timestamps are finite and each recording has nonzero elapsed duration, then forms millisecond differences for the original Event-SSM. New cold scores use a separate output directory. A raw timestamp of 0.73046875 s becomes 730,468 integer microseconds. This correction concerns the independent Event-SSM comparator. The HCSN original-event preprocessing already casts to float64 before binning.
