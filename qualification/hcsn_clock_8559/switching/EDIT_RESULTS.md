# Conditional wall edits and retained observables

At the finest boundary-fitted numerical resolution, a scaled minimum-norm first-order write freely moving both frictions and switching rates attained the three specified boundary displacements with maximum component errors 0.00149, 0.00245 and 0.00276. The corresponding greatest absolute changes in the equity values that were supposed to remain at their original V=100 values were 0.11665, 0.22563 and 0.22876. A successful threshold edit can disturb the paired value channel.

The four-observable Jacobian has singular values 7.76066, 1.72584, 0.01431 and 0.00192 in the registered parameter scaling. Its small singular values make certain target-and-retention combinations expensive. For all three targets the unrestricted joint linear answer crossed at least one specified parameter bound. Within the original calibration box, the multi-observable nonlinear fit reduced parts of the residual. The four-dimensional cold residual for a requested +0.10 change to the first wall was (−0.07107,−0.00814,−0.03727,+0.03095) for the two walls and the two equity values. The objective uses smooth-fit slopes divided by five and the unscaled equity errors; induced boundary errors are measured by independently solving the full forward model again. This is a result for this objective, choice of calibration bounds, numerical resolution and candidate family. It does not prove all calibrated edits impossible.

The JSON records all three target perturbations, four methods and three grid resolutions, elapsed time, off-target debt/equity changes at four other fundamental values, and cases falling outside bounds. The file FINITE_EDITS_ENDPOINTS.json is the authoritative reevaluation at closed box endpoints. A separate study widens the admissible region, runs multiple starts and includes a synthetic reachable control.
