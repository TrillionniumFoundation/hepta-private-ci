# HCSN on the original SHD spike clock

Registered before fitting the models or examining any new test predictions. This experiment tests whether a genuine recurrent finite-population free-boundary cell adds value over equally wide smooth recurrence and established temporal architectures. It is complementary to the previous SHD twelve-observation feature construction. The He–Xiong equilibrium formula is retained for the boundary and equity/loss tables. Survival, immediate crossing, reset and refractory mass are propagated within the neural population. The neural physical drift can vary with drive. All seven arms use ordinary end-to-end training here; other registered studies test constructive editing.

## Design

Use the authors' original SHD train/test HDF5, 20 English/German digit labels, 700 cochlear locations. Do not normalize a recording by its eventual duration. Use the fixed physical window [0,1.4) seconds and 28 contiguous spatial bands. Make a 28-step stream from counts per 50 ms band with log1p compression. State the number of input events outside the window. No pretrained features. Split official training speakers 3 and 10 for validation, as in the earlier experiment. Each test evaluation retains all official records, plus separate accuracy on speakers 4 and 5, absent from training. Store record, label and speaker IDs. Candidate selection uses validation only. Timing stress evaluates the exact same held-out events on 0.8 and 1.20 times the original clock, with fixed observation window; this is a controlled transform, not an independently observed population. Also evaluate silent input and within-record temporal reversal to quantify reliance on events and order. Report any cropping induced by a warp.

## Arms and budgets

* Two seven-channel families use identical trainable widths, emissions, deterministic projections, scheduling, head and optimizer. Literal uses exact He–Xiong values on four active margin atoms, a barrier-relative killed-diffusion transition, and one-step refractory mass. Smooth uses a calibrated smooth approximation to its transitions and price channels, same number of states and trainable weights, same range and first-order calibration at a reference operating point. Keep approximation residual diagnostics.
* Fixed-wall still accepts input through physical drift and common hidden drive. No-price-feedback preserves the moving wall, input, recurrence, transport and emission. These isolate adaptive boundary motion and price feedback.
* Other arms are a spiking recurrent LIF with surrogate derivative and refractory/reset dynamics, a temporal CNN, and a Transformer with multi-head attention. All receive exactly the same frame vectors and the same 20-class loss. Record actual parameter counts and clock. No claim of equal capacity if counts differ.
* Use seeds 137, 311 and 557; AdamW with gradient clipping, identical batch of 48, initial learning rate 0.001, scheduled independently of validation comparison. Fixed width 48 and two sequence-processing stages. Fixed four chronological mean features/quarters in every classifier input. Select checkpoints on equal-speaker validation accuracy. Break ties by lower validation cross-entropy then earlier step.
* Interleave CPU budget rungs 30/180/720/1800 process seconds within 7 arms × 3 seeds. Aggregate maximum training allocation is 10.5 single-core CPU hours before data setup, selection, cold validation or tests. One fixed logical CPU for the clocked panel; record thread configuration, actual wall and process durations, final updates, memory and frontier. Save resumable optimizer/model/stream state. Additional GPU runs, if available, have an independent clock. Save matched-update snapshots at fixed powers/budgets reached across arms; compare only at common realized steps. No repeated test access during fitting.
* Fit the complete matrix and seal all candidates and hashes before the primary cold test. A separately identified early-rung evaluation will be opened only after all 21 arms at that rung are committed/frozen; later budgets, candidate rule and model choices stay fixed. Keep early test results separate. Independent arithmetic verification uses stored logits and a separate process.

## Success rules

Primary endpoint is official speaker-balanced accuracy. Architecture-specific gain requires positive lower paired 95% bounds against both matched smooth and LIF, plus noninferiority to the stronger of validation-selected CNN/Transformer with a −2 percentage point margin. Report sensitivity to simultaneous versus marginal comparisons and outcomes on both wholly new speakers. Conditional two-level paired resampling draws speakers then recordings with seed averaging; the tiny number of wholly new speakers cannot support a general speaker-population claim. Report NLL, new-speaker macro accuracy, calibration, per-language, timing warps and silence/order counterfactuals. Do not turn a leading estimate or training accuracy into a pass.

Speed endpoint requires equal-quality comparisons at 60/70/80% validation speaker-macro accuracy, all three seeds, and independent test noninferiority within two points at the selected rung. Compare full recorded wall time from data processing, model construction, updates, selection, state serialization, cold restore and test. Cache-cold preprocessing and amortized reused observations are separate. Count finite rungs as bounds. If these runs cannot meet the original targets, retain failures and investigate them in a distinct prospective successor. No project-wide superiority, biological validation or completion of large-scale training can be inferred from this speech benchmark.
