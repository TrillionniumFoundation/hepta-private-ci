# Alignment of raw audio, video and text on MELD

This trial extends the image–caption and pretrained-feature results with three observed input types on the same utterance. Download the 10,878,146,150-byte original MELD.Raw.tar.gz from the authors' Michigan or declare-lab publication. Preserve SHA256, clip identities, official annotation file hashes, and a manifest of missing, empty, duplicated or unalignable clips. Do not publish raw broadcast media or transcript text. Keep train/dev/test as released. Explicitly check shared dialogue/episode identifiers and matching media byte digests across official splits. If repeated episode groups span splits, report common-source dependence; when a test clip has the same file digest as a train/dev clip, exclude it from the prespecified primary clean endpoint while showing the official aggregate.

Train all input frontends from random initialization. Use up to 8 chronological frame groups per utterance, uniformly placed in the observed duration. Decode RGB to 32×32, audio to 8 kHz mono, retaining contiguous raw windows up to 2048 samples per group, and original annotation tokens. No pretrained video, acoustic or language embeddings. Compare He–Xiong literal, matched smooth, recurrent LIF, self-attention and gated recurrence. Frontend trainables, tokenizer, optimizer and output task identical. Keep widths and seed IDs fixed at 48 and 137/311/557, batch 32, AdamW 0.001, gradient clipping 1, dropout zero. One extra text-only attention encoder and one balanced training-prior comparator check whether the modalities help at all. Use samples in the official training split alone for the vocabulary, feature normalizers and class weights. Primary output is seven-class annotated emotion, with macro-F1 and dialogue-balanced accuracy. Evaluate raw per-class recalls, NLL, calibration, and three single-modality removals. In each physical cell evaluate removing the learned inter-layer boundary component, removing both price components, and sending within-batch shuffled time-aligned boundaries (fixed permutation). Freezing the rest of each model makes these local tests of what it uses. Compare on raw held-out dialogues; no condition is a claim about an individual's mental state or general biological dynamics.

Validate at 30/180/720/1800 process seconds per architecture and seed on the host. Interleave jobs across selected physical cores at low priority. Fit-only total maximum allocation 9 single-CPU-hours for six trained models × three seeds, plus decoding, validation and cold scoring. Record affinity, peak memory and counts; evaluate and archive all selected checkpoints. Choose global macro-F1 from dev, then lower NLL, then earlier update. Before opening an early test, freeze all 18 selected weights. Finish all scheduled rungs before confirmatory testing. For paired uncertainty use 4,000 dialogue-cluster replicates, holding seeds fixed and reporting each. Architecture gate requires simultaneous one-sided positive macro-F1 gain over matched smooth and LIF, and lower bound above −0.02 vs the stronger validation-selected attention/GRU. A tri-modal gain additionally requires positive gain against text-only attention and a positive contribution of at least one non-text input supported by a paired interval. Report training cost only at jointly reached dev-quality thresholds and held-out noninferiority. This is a television-dialogue emotion classification encoder trial. Fitted encoders or negative outcomes cannot establish foundation-model scalability.

Dataset and task definitions: Poria et al., ACL 2019, https://aclanthology.org/P19-1050/ and https://affective-meld.github.io/.
