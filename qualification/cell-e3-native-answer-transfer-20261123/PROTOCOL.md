# Native-completion transfer panel

Locked on 2026-11-23 before any forward passes on this panel. This third elicitation is an exploratory follow-on to the registered binary panel. The first two elicitation procedures already had published development results. This protocol and the generator are independent of any student holdout score.

The two frozen upstream teachers, common 1,501-feature pipeline design (actual vocabulary size is refitted), independent cold workers, ridge penalty, teacher-selection thresholds and training counts follow the companion binary-panel protocol. Inputs here request German or French word translation, verb agreement, integer addition, Python list indexing and capital cities. The teachers receive the native task without either answer option in the prompt. For gold and a generated plausible foil, compute mean token log probability of the candidate continuation at the model's response boundary with teacher forcing, excluding EOS and using the stock Smol chat template. Select the higher-likelihood string (index zero wins ties). This has access to a two-option answer set; it does not test open-ended generation. The student sees both candidates appended to the query and attempts to choose the same index. Candidate order is balanced within each split and shuffled with a fixed independent seed.

For each of six domains there are 12 discovery, 32 fitting, 20 held-out and eight reserved pair components. Each split uses its own query template. Concepts can recur across splits, including repeated vocabulary and capitals, and a query can recur within a split with another foil. Disclose these limits. Confirm a discovered directional advantage on the held-out domain under the unchanged rule; also report paired teacher-exclusive counts for readers to judge sample size. Two-expert graphs have more stored weights, and their selection methods receive truth in discovery. Retention uses the same simple old control. No external users or adoptions are represented. Publication must include all arms and all domains even on gate failure.
