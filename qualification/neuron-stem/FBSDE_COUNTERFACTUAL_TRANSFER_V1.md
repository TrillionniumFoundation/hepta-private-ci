# Cross-state rule identification, scoped export, and a two-query information limit

## An actual new source capability, not free counterfactual knowledge

The experiment source can RESET a simulated three-role system to a selected
initial permutation and execute one hidden rule. This is explicitly different
from verifying an already executed event. No real environment intervention right
is created. A request binds source, scope, generation, environment, selected
state, history and call sequence. Only its callback reveals that one effect.
Two source experiments are allowed per adaptive/fixed acquisition strategy;
`full_table_six` is a separately labelled SIX-experiment reference. Every used
reset is counted, including repeats. No old episode observations are silently
added or granted a fresh allowance, and no hidden guard or program ID enters
planning. Setup, source calls, planning, export and application are measured.

The family is EXACTLY the parent's 33 rules: six constant permutations and 27
state-guarded swaps. The domain consists of all six role-colour permutations.
No new neural weights or language parser are learned. The experiment enumerates
33 private simulator rules and six first-state configurations: 198 related
finite mechanism trials, not 198 independent authors or future observations.
The public operation name does not encode its private rule ID; environments are
separate bindings. Names are alpha-renamed through the original role boundary.

## Current-answer agreement and transferable-rule agreement are different

For observed pairs h={(x,o)}, retain S(h)={theta: F_theta(x)=o for all h}.
A table may be exported ONLY when every retained program has the SAME effect at
EVERY state of the declared domain. The export keeps evidence identity, frame,
environment, scope and generation. Restoring it recomputes the support and table,
not merely its hash. It can then be applied under different actor names and
initial states of the same frame. No guessed singleton or unconstrained context
is promoted. Contradictions/nonbijective effects reject; a fully matching finite
table still does not certify hidden time dependence or arbitrary family coverage.

This is extensional identification on a finite domain. It implies correct
in-domain transitions only if observations are correct and the actual stationary
rule belongs to the declared family. The statement is not semantic correctness,
independent risk, cross-environment transfer or production final-use authority.

Active queries maximize expected fraction of domain states with unanimous
support, less .02 per experiment. This is exact finite experiment design with
one/two-step lookahead, NOT a new continuous FBSDE theorem. The independent
reference uses rational costs and exhaustive conditional outcomes. The existing
100ms process-CPU and 20k-node planning bounds remain; the original planner is
not weakened. The fixed, best-prior fixed pair, first-informative and greedy
controls receive exactly the same source port and two-call allowance.

## Observed result and exact budget ceiling

One complete run has 198 x 8 = 1,584 records and 3,132 source experiments.
With TWO calls, active and greedy strategies each identify 30 complete tables;
the prior-optimal fixed pair also identifies 30 but uses 396 calls versus 384.
First-informative identifies 12, fixed cyclic pairs 18. Complete six-state
measurement identifies all 198, but uses 1,188 calls. It has seen the whole
normalized input domain: its name-permutation replays are not unseen-state tests.
Qualified tables are restored and applied over all six actor-name orders and
six initial states. Unqueried normalized states are counted separately from
replays. No effect label is used to pick a policy after test execution.

An independent post-score enumeration tries EVERY pair of reset states for each
of the 33 possible true rules (including repetitions). Only the five nonidentity
constant rules can be uniquely identified by two effects. Thus ANY adaptive
policy with this exact observation alphabet and two resets identifies at most
5/33 of the uniform family (30/198 in this design). Each adaptive realized path
is one of the enumerated pairs. This is a finite identification bound, not an
impossibility result about richer observations, three queries, neural learning,
larger state spaces or all reasoning. Deeper computation cannot manufacture
missing source information. The reported active method reaches this ceiling
but does not beat the cheaper greedy method.
