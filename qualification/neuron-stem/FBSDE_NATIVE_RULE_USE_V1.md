# RuleSlot research consumption through existing native owners

Parent: Draft PR #1550, `626e769b24b97256a372195b96c93a1999961bb5`.
This is opt-in research composition. It installs no runtime route, issuer,
selector, activation service or parallel authorization owner. Four-Gate,
longitudinal efficacy and production qualification remain required.

## Ownership and the operation

`NativeRuleSlotConsumer` wraps the existing `DurableRuleSlot`. A new immutable
bundle contains its descriptive identity, revision, generation, context, table
and acknowledged checkpoint. A Python hash never becomes native authority.
The qualification process publishes those exact bytes through the existing
`LearningArtifactOwnerService`. A separate artifact-selector key authenticates
the exact CURRENT, manifest and selection. These keys are explicit research
fixtures, not independently operated production issuers or efficacy evidence.

`RevalidatingSelectedCandidateV1` retains the existing native verifier and
signed selection. It pins owner trust and the full manifest; every use verifies
CURRENT and selection again. CURRENT extensions require fresh selection and an
explicit new consumer. Expired/revoked selectors, foreign owner trust, forks,
revoked artifacts and failed acquisition close the consumer permanently.
Existing read-only candidate callbacks remain read-only.

`RuleArtifactConsumerV1` is an additive Agentd API with no installation callsite.
The host borrows its existing named artifact owner across the complete operation
and owns its existing OS writer fence. Before a bounded callback it persists
submission, reservation and assignment through `DurableInferenceControl`.
An independently issued, non-cloneable `VerifiedUseToken` authorizes only the
derived binding: candidate bytes, checkpoint, revision, generation, scope,
authority epoch, input, expected output, request, worker, selection and deadline.
The existing FinalUse effect fence protects entry. Fresh signed CURRENT and
selection are checked inside that fence; after copying, actual time is checked
against every retained validity bound immediately before the driver. FinalUse
expiry uses its existing protected `AuthorityClock`; it is not substituted by
the wall clock used for CURRENT and selection.

The finite CPU driver applies the selected permutation to the actual input
state. Its native receipt describes the transformed state, not merely the
permutation's coordinate names. The Python owner holds its existing slot lock
over native execution and local durable finish, and returns only after both
agree. A successful current source verification is required for this route;
the old prediction-only research `RuleSlot.finish` interface is unchanged.

## Refusal, uncertainty and recovery

Rule retirement and restart continue to invalidate every process-local handle.
Reopen quarantines an active historical table and preserves the lifetime recovery
limit of five; no artifact or selection reload reactivates it. A late source
receipt remains evidence and cannot enter native inference. Concurrent finish
calls can enter the native callback at most once.

Native intent is synchronized before the callback. Terminal observation and
actual usage are synchronized before returning. Existing requests and claimed
nonces are reconcile-only, including after restart. Driver failure can retain
Indeterminate work; a panic retains Assigned work and its fsynced entry trace.
A late Completed native observation remains in the journal while delivery is
refused. No failure returns cached output or silently retries an old operation.

Local SQLite finish can commit after native completion yet lose its reply.
The wrapper suppresses output, poisons itself and preserves the charged native
work. This composition deliberately loses availability in an uncertain case;
it is not distributed exactly-once delivery or an external outbox protocol.

The named artifact service now denies CURRENT when publication requires recovery.
It establishes the fence before fallible reconciliation. A readable ACK after
a failed sync is not a durability proof: uncertainty remains fenced until exact
reconciliation successfully synchronizes native records. Restart must also
confirm synchronized native acknowledgement before exposing CURRENT.

## Precise remaining boundary

The named artifact publication transaction currently supports exactly one
admitted Register. It has no durable Revoke/Quarantine publication API. A trial
combining registration and revocation was correctly rejected with
`RegistryPredecessorMismatch`; its raw files and transcript are retained.
Neither publication projection nor recovery was relaxed to pass that trial.

Native signed revoked-view tests use the existing, documented read-only CURRENT
verifier proxy: actual Revoke record, real immutable registry file and receipt,
fixture-signed CURRENT, then opaque native verification and consumer refusal.
That is native signature/storage/selection evidence. It is distinct from a
completed named-owner state-change publication service. A subsequent extension
needs explicit native state-change intent, projection, durability and recovery
through the same owner; rule-environment drift must not become dataset withdrawal.

Artifact selection also does not replace the existing independently evaluated
self-evolution selection or prove model improvement. This work supplies no real
pretrained weights, future Hepta data, multi-generation adoption or native
production promotion. The canonical Four-Gate and scientific profiles are intact.

## Execution and reproducibility

See [native-rule-use/README.md](native-rule-use/README.md) for the bounded protocol.
Builds copy exact native sources into a narrow composition workspace, preserve
native package/dependency/lint/profile declarations, verify resolved identities
against the repository lock, and retain source/binary provenance. This is
explicitly separate from compiling the entire Agentd product graph.

```bash
python3 qualification/neuron-stem/native-rule-use/build_shadow.py --output /absolute/native-rule-build
PYTHONPATH=qualification/neuron-stem python3 -m unittest test_fbsde_native_rule -v
PYTHONPATH=qualification/neuron-stem python3 qualification/neuron-stem/fbsde_native_rule_study.py --executable /absolute/native-rule-build/codex-rs/target/debug/native-rule-use --output /new/native-rule-study
PYTHONPATH=qualification/neuron-stem python3 qualification/neuron-stem/fbsde_native_rule_artifact_checks.py /new/native-rule-study
```

Fifteen real-file scenarios retain every native owner directory, SQLite file,
entry trace, journal, stderr, response and failure. The audit checks raw input,
output, callback inventory, native terminality and SQLite replay; mutation tests
reject altered delivery, callback counts, panic status, anchors and promotion.
The positive recovery case rejects the old handle after restart, pays fresh
relearning within the original lifetime allowance, publishes a generation-two
child through the same named owner's single-Register transaction, obtains fresh
independent selection, restarts the native owners against that exact signed head
and selection, and enters native inference again. The original native
control journal and FinalUse owner are retained. This repeats a known stationary
fixture and does not establish independent semantic improvement.
SQLite semantic auditing shares the existing reducer; native receipt signatures
are checked by native code. Neither is independent hardware attestation.

Actual wall time, Python parent CPU, child user/system CPU, journal growth,
callback time, exact payload bytes and finite-vector capacities are retained.
Parsing heap, allocator overhead and process peak memory are not inferred from
those finite buffers. Utility `COST=.02` remains an abstract experiment cost;
no CPU/energy/speedup or end-to-end production SLO is inferred from it.

The additive head/merge workflow keeps actual checked-out source and failures,
with contents:read only. The new guarded native callsite is explicitly listed
in both closed-world caller inventories; no matcher or authority rule is weakened.
Previous failed runs, resource contention, disk/links and environment-capability
failures remain in the delivery evidence alongside later successful scoped runs.
Keep Draft; never equate research completion with native production qualification.
