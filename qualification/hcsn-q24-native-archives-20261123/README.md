# Q24 原生证据原件

`q24_release.zip` 完整保存 #7013 的 musl Bazel 原始执行日志和基线分阶段观测的原始输出、来源绑定与离线核验程序。归档共 13,683,617 字节，SHA-256 为 `9a5c21eb875d1f42713104015e481fc7c0206da6907d37d4c264c681e5f12652`。前 28 卷各为 480,000 字节，末卷为 243,617 字节。分卷在仓库中按原始字节保存。

在本目录运行以下一条命令即可复原。

```sh
python3 restore.py q24_release.zip
```

程序核对 `manifest.json` 的顺序、每卷长度与 SHA-256，再验证完整归档。它在同一文件系统的临时目录拼接，用硬链接原子创建新文件；若输出路径已存在，将报告错误并保留已有文件。解包后运行 `python3 q24_release/verify.py` 可从两份原工件重新计算结果。所需依赖为系统 `zstd` 或 Python 的 `zstandard`，具体版本见内置的 `requirements.txt`。
