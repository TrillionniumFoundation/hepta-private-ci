## Capacity and evidence interpretation

Kernel ceilings are 65,536 nodes, 262,144 edges, 50,000 supports per node/edge,
1,048,576 aggregate supports and 256 MiB canonical generation encoding. Revoked
input records count before normalization. These are admission bounds, not a
process-RSS or latency SLO; source-owner limits may be stricter.

The default capacity fixture repeats 16 entity keys and 128 relation identities
across 256 source mutations. It reaches 4,096 node occurrences, 32,768 edge
occurrences, **16 canonical nodes, 128 canonical edges and 36,864 supports**
before contention. It measures support/history growth, owner product retrieval,
reopen and contention; it does not qualify a 4,096-node/32,768-edge canonical
graph. `boundedQueryWork` deliberately names its full-scan reference implementation.
Product query timings include actual indexed-view preparation.

Target-host identity strings and observed temporary-directory devices are
measurement provenance, not independent hardware/storage attestation. A finite
history probe and process-kill/WAL checks do not prove indefinite retention or
physical power-loss behavior. The budget-profile collection currently has no
operator-approved target profile; no target-host pass is invented.

## Verification and stopping rule

Run scoped Rust formatting/lint and kernel, prompt-stack and cognitive-owner
tests; explicitly select ignored crash/history/capacity probes; run both ordinary
and qualification-witness Agentd E2E; verify measurement/negative-input tests and
module source bindings. Preserve actual results and failures in the final
delivery record. A pending, skipped or zero-selected test is not a pass.

After remediation, independent review rechecks budget encoding, delta/full-cut
equivalence, indexed/reference query equality and transaction-scoped freshness.
Stop this iteration only when review produces no additional reproducible defect
within the audited scope. That finite conclusion does not assert global
optimality or certify deployment. Production/execution/activation/acceptance and
release claims remain false without their separate current evidence.
