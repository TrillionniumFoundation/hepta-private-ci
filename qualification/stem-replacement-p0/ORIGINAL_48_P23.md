## Real hosted experiment — strict phases

1. **Original source author (read-only)**: each model job separately reacquires original Parquet bytes and the historical P0 algorithm, verifies the real content SHA and produces P0 FIT / blind / owner-only human held labels locally. `multirc_source_bridge` emits the same frozen P2 input panel, label-blind complete state/question/ordered-option views and FIT-only human labels; its panel SHA is checked against the exact observed P2.2 value before loading any pretrained weights.
2. **Original model source & private 48-case frozen features**: `source_bytes.py` downloads only the named full-commit checkpoint/tokenizer inputs; `review_bytes.py` verifies actual pinned SHA/LFS bytes independently. `physical_feature_bank.make_bank()` reloads the real original model from a rechecked, clean private runtime snapshot and executes 48 full question-conditioned input forwards with *zero silent truncation*, preserving case order/source IDs. Features remain private and label-free. Laya native `noul` scores are **not** compared to Ettin CLS vectors as if they had the same semantics. The two real frozen CLS vectors each feed the common Head.
3. **Matched training producer**: only FIT labels enter `matched_head.train_one()`: **4,161 FP32 trainable parameters, frozen PCG64 v2 seed 41, 40 full-batch SGD updates**, same 128-dimensional (lossy) zero-trainable label-independent feature hashing projection. All original Encoder/tokenization/copy/projection costs are counted separately; equal Heads do not imply equal total model parameters, pretrained training cost, latency or computational efficiency. Producer seals label-free CAL/TEST raw logits, all Head tensor bytes and the full bank into a **0600 create-only, private, ephemeral Runner directory**. These files are *never* GitHub artifacts.
4. **Independent algorithmic reviewer (separate process)**: `original_48_pilot.py audit` reopens the pinned original model source bytes, checks every private file against the sealed SHA, and reimplements projection and all 40 SGD steps in NumPy-only math. It rejects corrupted features, initial parameters, final parameters, reordered cases, false training budgets, altered predictions and changed weights. This is a separate implementation and process, **not** a trusted separate host, organization or cryptographic issuer.
5. **Original human-label observer (separate process; runs only after audit)**: reopens the fixed original P0 source FIT/BLIND and original owner-only held truth. Recomputes exact group/case identity. Scores raw sigmoid of the frozen 40-step Head on CAL (8) and TEST (16), with descriptive accuracy and Brier against the unlearned constant FIT-class prevalence. The constant prevalence is **not** a genuine native-Laya no-change baseline; it is merely a trivial reference. No hidden label is passed as a producer argument, but all processes execute on one Runner; the workflow therefore does not independently prove OS-level secrecy or third-party custody. No per-case logits, labels, raw text, pretrained checkpoint or frozen feature bank is uploaded. Only tiny aggregate and audit JSON receipts may be retained.
