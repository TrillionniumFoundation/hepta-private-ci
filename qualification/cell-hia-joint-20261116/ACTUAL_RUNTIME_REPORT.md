# Actual configured runtime / HIA / Cell lane

## Outcome and scope

The fixed runtime was built from the exact clean source on the actual macOS controller. Fresh MCP stdio sessions then used the existing ai395 operator account to start the real HIA/Cell worker. Observe, prediction and the complete MEM/PRED maintenance fixture all completed. Each was subsequently read through a newly started runtime process using its original job ID, with no second process start and byte-identical output.

The qualified scope is actual configured runtime transport, real native HIA/model execution, retained state/experience, a complete controlled learning decision and completed-job cold observation. Both learning decisions were **NoUpdate**. The run establishes no adopted learning benefit, independent real-world maintenance benefit, long-term multi-round retention, Rust native FinalUse qualification, OS process isolation, deployed daemon qualification or recovery from a crash during an unfinished effect.

`ACTUAL_RUNTIME_SUMMARY.json` records exact bindings, proof counts, measurements and limits. The two archives retain original protocol records, owner databases, campaign inputs, candidates, outputs and preceding failures. Every archive SHA and every indexed member SHA was verified after transfer.

## Independent retained-evidence review

The unchanged independent verifier initially rejected the original directory because both SQLite WAL files existed. Their actual lengths are zero and their SHA is the empty-file SHA. That failure remains in `worker/campaign-readonly-v4-receipt.json` and its stderr.

A review image copied every original file byte-for-byte except those two proven-empty WAL files. SHM files were retained. All original hashes and all included copy hashes were checked again after verification. No original database was checkpointed or modified, and no nonempty WAL was ignored. `worker/campaign-review-image-v4-manifest.json` records the full mapping.

The unchanged verifier returned `READ_ONLY_CONSISTENCY_PASS`, covering 17 source modules, six version manifests, 208 compile records, native bindings, checkpoint weights/optimizer state, decisions, receipts, selected identities and cold outputs. It performed no model/native execution. It does not establish actual runtime transport; the outer protocol records establish that separate fact.

## Source repair and preserved failures

Original runtime main `d3d75c30719db966b004756f610007a7c723729e` failed its actual macOS build: an unconditional checkpoint-order import referenced a pure parser hidden by a Linux-only cfg. [Draft PR 132](https://github.com/TrillionniumFoundation/hepta-runtime/pull/132) removes exactly that cfg line. The clean fixed source passed Rust 1.95.0 fmt and locked/offline/all-features release build in 157.996 seconds. Original failure, raw stderr, fixed logs and binary identity remain preserved. Linux [PR CI](https://github.com/TrillionniumFoundation/hepta-runtime/actions/runs/43795217971) was still running at this report snapshot. No completed Linux gate or macOS clippy pass is asserted.

Earlier failed dependency preparations, rejected operator configuration, old archive-layout assumption and initial zero-WAL verifier rejection are preserved. One later archive-creation transport acknowledgment timed out without a job ID. That operation was not restarted. Its original completed archive and receipt were subsequently read and hashes verified. This archive transport event does not change the three Cell results.
