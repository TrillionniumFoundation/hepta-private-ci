# A historical public task and a frozen owned candidate

The OpenHands opt-in feedback release contains a benign Python arithmetic task repeated verbatim by the user at trajectory positions 7, 15 and 23 of row 52 (all offsets are zero-based). The session recorded agent runtime errors at positions 9 and 17 with Codestral configured. At position 19 the recorded model switched to `ollama/qwen2:7b-instruct-q5_K_M`. Its later visible edit produced a 59-byte script. The subsequent execution observation at position 30 reported a zero exit code and exactly the 14 multiples of seven between 1 and 100. The overall feedback was positive. No separate user acceptance of that edit or authenticated Hepta identity was recorded.

A locally initialized two-layer GPT-2 was trained to emit that script on the original user input. Supervision covered only the verified script and its end token. The initial failures establish historical context. No Codestral output, model reasoning, shell commands or tool wrappers entered the loss. The source reader parses one Python literal and compares the recorded numerical output with independent arithmetic. It never executes the archived code. Cold scoring compares parsed syntax to the reviewed script; it accepts the same syntax tree, and the successful candidate also matched the recorded bytes exactly.

## Reproduce

The recorded runtime used Python 3.12, PyTorch 2.6.0+cpu, Transformers 4.49.0, PEFT 0.14.0, tokenizers 0.21.4 and PyArrow 24.0.0. From the repo root, set `PUBLIC_PARQUET` to the original release and `NEW_RUN` to a fresh directory. The normal training, parent cold check, update, freeze and child cold check run in distinct processes. The output contains hashes for the source task and generated historical answers, plus raw answers for the authored retention check.

```bash
EXP=qualification/public-historical-a-qwen2-052-20261123
PYTHONPATH=scripts HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1 \
  python "$EXP/historical_a.py" "$PUBLIC_PARQUET" "$NEW_RUN"
PYTHONPATH=scripts python "$EXP/review_other_history.py" "$PUBLIC_PARQUET" "$EXCLUSION_REPORT"
```

An initial engineering attempt ran out of memory while both training and the cold reader held the full release. The final program streams one row and isolates the phases. A second pre-A parent check exposed a tokenizer mismatch. The generic tokenizer supplied segment IDs absent during training, and the old task generated repeated zeros. The final durable tokenizer supplies only input IDs and an attention mask, matching the training computation. The training seed, examples, step counts, learning rates and last-step selection stayed fixed. Neither earlier run updated a candidate on A.
