## 数学与状态

在发放时段 `[s_j,e_j)` 产生的事件保留当时的延迟 `d_j`、触界向量 `l_j`
和重置分布 `r_j`。时刻 `t` 的返回流是

\[
\sum_j 1_{[s_j,e_j)}(t-d_j)\,[p(t-d_j)l_j]r_j.
\]

因而后来缩短不应期会产生重叠返回窗口；它不会修改旧事件的释放时间。
所有概率及带符号内容通道经过同一输运。价值累计使用
`D(t)=exp(-integral_0^t rho(s) ds)`，包含当前 active/永久 upper 的运行奖励
及触界时的事件奖励。等待期间不重复支付事件奖励。终端收益仍为零。

独立实现仅用 NumPy 和 SciPy DOP853。参考网格包含参数切换、返回窗口端点
及这些端点的后续延迟传播，每段长度不超过最短延迟，所以积分器只查询已经
求出的历史。等待质量由各发放时段尚未释放区间的触界积分独立求和。
这个参考接口没有隐式干预原子；扫过边界的原子另外使用闭式标量例子验证。
