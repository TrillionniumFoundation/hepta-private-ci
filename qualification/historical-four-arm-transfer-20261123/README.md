# 一条历史 Agent 轨迹能教会 Cell 哪些动作

同一父模型的六个预登记方法，在原始任务、同义改写和改参任务上都未能独立完成四步。阶段探针显示了互补性。完整轨迹学生在给定正确环境状态时会创建、运行和结束，写入专项学生能重现正确脚本。知道这个结果后，把两个学生按阶段组合，可以完成原题。忽略新请求、按阶段复制示范的程序也完成了原题，且通过全部六种同义改写。两个系统均在十二道改参任务上失败。

## 数据与计分

训练取自公开 opt-in 的 OpenHands 历史反馈第 52 行。一位参与者重复提出同一编程任务，前两次运行出错，后续成功退出并留下正面反馈。题目要求用 Python 输出 1 至 100 中 7 的倍数。落盘数据保留重试状态、创建、写入时的脚本文本、运行及结束。四个动作是本实验定义的投影。用户逐动作确认、独立身份、当前 Hepta 登记及链上采用均未在该历史记录中得到验证。一个历史会话、一个旧能力探针和同一算术任务族，不能估计跨用户或跨域收益。

共同父模型是 41,760 参数的两层 GPT-2。每次推理最多输入 170 token、生成 80 token，每题最多四步。runner 顺序执行模型输出直到失败。写入环节按限定 Python 语法解释其实际输出数列；不执行生成的任意代码。四个阶段探针直接提供正确状态，单独计数。全程关闭外部教师。旧探针要求输出 0。

| --- | ---: | ---: | --- | ---: | ---: | ---: | ---: |
| 冻结父模型 | 0.001 | 0 | 0/4 | 0/1 | 0/6 | 0/12 | 1/1 |

| 最后一层局部 BP | 6.885 | 12,704 | 0/4 | 0/1 | 0/6 | 0/12 | 1/1 |

六个独立冷进程共调用模型 577 次，输入 70,268 token、生成 2,643 token，包含顺序作答、阶段探针及保留题。拟合计时、冷加载和推理成本分列在 results.json 与 cold.zip 中。局部 BP 与完整轨迹各做 600 次更新，写入专项提前停止于 240 次。直接编辑只求解一次带正则化的输出头，物理权重读回显示原有 28 个张量逐字节相同，另增独立输出头。局部 BP 只改变末层的 12 个张量。更新步数、被更新参数量和训练 token 呈现次数均有差别。没有任何方法达到预登记的完整任务质量，因此无法比较达到该质量的时间。检索采用单个同阶段示范，并在预算不足时截短示范文本。

## 固定双专家图与回放

这一轮在看过原题的阶段结果之后设计；执行前另行提交了 ROUTING_PLAN.json。已暴露的 19 道题用于定位成败原因，不作为新的确认集。

| 对照 | 原题 | 同义改写 | 改参 | 旧题 |
| --- | ---: | ---: | ---: | ---: |
| 创建、运行、结束交给轨迹学生，写入交给专项学生 | 1/1 | 0/6 | 0/12 | 1/1 |
| 按当前阶段复制示范，忽略新输入 | 1/1 | 6/6 | 0/12 | 1/1 |

固定图使用两个已冻结模型，各阶段只调用其中一个。runner 仅根据实际生成的动作和当前状态推进。回放程序重用同一个 7、100 脚本，所以同义改写均通过，改参全部失败。原题上的互补性说明节点职责可以组合；边需要学习、会自行产生或对新用户有益，这些假设仍需独立任务比较。routing-readback.json 按题列出从归档状态输出重建的结果。独立实现 independent.py 直接从权重重新生成全部动作。independent.zip 保留 CI 输出的逐题文本和物理权重检查，解压后文件 SHA-256 为 `44600c97303f0a87eff6bb179ba3e1d8867a7cdc22ce06e841096fbfc6a23894`。
