# Exact time scans for a restricted HCSN encoder

Test a second network mode in which each layer's principal is learned causally from its incoming feature stream, while the step does not consult the layer's own previous mass or prices. The barrier remains the endogenous He–Xiong solution conditional on that principal. With adjacent barrier levels known, each full update including killed motion and a refractory row is a row-stochastic matrix. Whole-sequence training can use an associative prefix of those matrices, with authentic predicted flows and monetary prices sent to subsequent layers. This restriction is material: connecting internal pressure to the preceding priced state generally makes the next matrix unknown until that state has been evaluated.

Implement a trainable two-layer network with the same weights under sequential vector transport and an associative pairwise prefix algorithm. Check odd and even lengths, gradients for inputs and every active parameter, causal prefixes, chunk continuation and real-arithmetic mass. Compare CPU single-thread forward and training-step times at T=16,64,256 for 8 and 12 atoms using held fixed input, width and objective. Include a fast path which computes only the prefix product across complete time blocks then applies their starts inside each block. Report exact tensor sizes; never infer GPU or external task speed from these CPU timings. This experiment measures implementation/parallelism tradeoffs, and does not pass a task-quality gate.
