# 独立只读方法学核验

审阅范围包括皮质脉冲记录、视网膜输入输出、连续极限、双层网络、真实电表费用任务和卫星图像 caption 的规模实验。未打开电表法国外部或比利时测试文件、标签或模型分数。电表数据仅读取法国开发集及 30 CPU 秒开发快照；图文部分检查公开输入图案和训练/开发文本。原有生理冷成绩在公开封存后逐事件重算。

| 核验项 | 可直接验证的结果 | 解释边界 |
|---|---|---|
| 图文开发语言重叠 | 624 句中 575 句（92.15%）在切至 20 词后与训练中某个完整编码序列完全相同 | 这一定义反映模型可见的文本；只给总体语言损失会把复用模板与新句泛化混合 |
| 图文输入量化碰撞 | 8×8 RGB332 图案在 train–dev、train–test、dev–test 的不同重复图案数分别为 1、2、1。原图过滤后各划分仍有内部量化重合 | 原照片唯一不保证模型输入唯一。这些碰撞数量小，不能据此解释所有差距 |
| 图文计数口径 | 保留的开发文本为 6,469 个普通 token，manifest 的分母为 6,527 个 | 导出清单的分母在相似图片剔除前计算 |
| 费用任务 1 小时负对照 | 费用在第 3 个半小时才收取。开发集上 30 秒模型在原本应完全不变的 1 小时概率中产生伪响应。逐种子平均绝对变化为 literal 1.76pp、smooth 1.87pp、GRU 1.90pp、attention 1.42pp | 只评价模型预测的反事实一致性。四组开发快照的 Brier 与原收据逐一重算相符 |
| 费用时间口径 | 原始评分过程中的达标序列只读取 optimizer_cpu_s。开发质量可随训练波动 | 离散未达标点不排除此前越过又回落。等外部质量墙钟须明确计入实际任务流程 |
| 皮质事件 | 三个已封存记录中，逐试次 literal 比 LIF 的平均 BCE 更低的次数为 A 13/13、B 3/9、C 5/7 | 试次数不能转换成独立神经元数 |
| 视网膜端口 | predictive 减 augmented 在 10 个试次中 6 个负、4 个正。试次等权差 −0.0003317，事件加权差 −0.0004416，1,774 个事件无同试次重复输入时刻 | 平均差异很小；记录而非视网膜神经元总体是统计范围 |
| 视网膜 LIF 时钟 | 原 C++ 衰减系数写死 2ms，却在视网膜数据库按 1ms 被调用 | 步长修正、原参数回放和全部原始预测见 synapse/clock_correction |
| 视网膜归属 | 原时间配对产生 424/832/38 个 0/1/2ms 下游匹配。严格在后的终点改变 422/1,774 个候选；仅改截距和完全重拟合的效果不同 | 同一记录、同一批试次的事后端点敏感性，见 synapse/strict_lag |

原始皮质与视网膜实验在生成所有候选的特征和预测后封存，损失选择只使用开发标签。视网膜代码甚至在封存之前将每个候选的冷输入预测存入内存。根据可核查的数据流，未发现冷标签进入候选选择；这和在全新进程加载封存权重才首次生成测试预测的隔离强度不同。本审查中新追加的时钟与归属校正按分进程流程处理。

连续模型的固定非零空间格点若单独取时间步长趋零，离散转移会趋于冻结；原定理已限定固定边界、正最低代表点及截断的病态极限。有限级联合网格收敛是数值观察。双层网络用有限个短片段的同态回放、梯度方向和合成目标下降验证可实现性；不能由此识别生理参数或推断跨模态训练速度。

重算命令需要 NumPy、Scikit-learn、PyTorch 和本工作区的已生成输入及开发权重。retina 与 neurons 的读取对象仅为既已发布的封存生理测试。
