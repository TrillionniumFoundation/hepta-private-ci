# Single-cell current-to-spike prediction

These are three measured cortical-cell recordings from Gerstner, Naud and colleagues, CRCNS ch-epfl-2009 (DOI 10.6080/K0PN93H3; see also Gerstner and Naud, Science, DOI 10.1126/science.1181936). The numerical files were obtained from the public mirror InPhyT/Quantitative_Single_Neuron_Modeling_Competition_2009 at fdaea54c2fee77e06678d434c7f69ef7093cabb8. Use current.txt and voltage_allrep.txt for A/B and current_soma.txt, current_dend.txt, voltage_soma_allrep.txt for C. Replace slashes with hyphens for local file names. The SHA-256 and file sizes are recorded in the seal. All comparisons use a new split on openly labelled recordings; official competition test targets are unavailable.

The flow/price features plus a convex readout improve held-out log loss against the equal-width smooth replacement in A, B and C. The paired 500 ms block intervals are A −0.001853 [−0.002629, −0.001130], B −0.000864 [−0.001384, −0.000355], C −0.001167 [−0.001909, −0.000454] nats/bin. The regular-spiking A cell also favors the literal model against the controlled stochastic LIF, while fast-spiking B favors LIF at the point estimate and the interval spans zero. C favors literal on the point loss difference with a wide interval. Hence the registered all-cell advantage over both controls fails. The generative interpretation of the raw price channels was not fitted; the loss is for a trained readout of a constructed bank. Pooled labels do not create additional independent biological cells.

The code compares two millisecond bins after a one-bin causal lag. Each held-out interval is 6.8 seconds, common across repetitions. Brier, precision-recall area, rate bias, all baselines, candidate parameters, solver termination, timing and paired bootstrap are included. The twelve-atom transition is evaluated by interpolation on a 1/4096 grid of boundary displacements; the seal includes a random-grid comparison with exact reference matrices. The financial coefficients use one quarter model-time per bin. No biophysical units for financial parameters are inferred. The stochastic LIF uses a mean reset/escape approximation with refractory occupancy. The table describes this comparator, not all LIF variants.

Rebuild the core at the parent commit b3fdc981568ab9ce122d2fb569372651e0b4b314. From this directory compile with `g++ -std=c++17 -O3 -fPIC -shared reservoir.cpp -o reservoir.so`. Run `python spikes.py --lib reservoir.so --data /path/to/raw --out /path/to/results --core /path/to/qualification/hcsn_continuous_20261127/core` with single-thread BLAS. The sibling reachable directory supplies the tested transition implementation. The NPZ files contain one probability per time, one observed label per original repetition, and all models. The seal is gzip-compressed for transport; its identity in scores.json is the SHA-256 of the decompressed JSON.
