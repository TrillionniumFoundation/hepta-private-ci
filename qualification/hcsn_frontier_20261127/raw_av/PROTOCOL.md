# 从原始音视频训练共享视听文本编码器

在看到目标任务的开发或留出分数前固定本实验。CREMA-D 由 Cao 等发布，固定发布源提交 1658cd342dff90010aa843eaeebd53610a08b1dc。全部 7,442 段原始 FLV 分别验证 Git LFS 指针，解码画面及同文件声音，原句和预设表演指令组成 72 条文本候选。目标为剧本及指令的联合检索，标签来自受控表演设计。只用音视频预测哪一条文本配对。91 位表演者以固定 SHA-256 排序，前 61 位训练，后续 14 位开发，余下 16 位测试，无演员交叉。采集、固定声学变换、解码时间单列；模型从头学习视觉、声学和文本映射。每个视频均匀取 12 帧灰度 28×28，原声重采样 8 kHz，256 点窗长、80 点步长的功率汇入 64 频带、12 个时间块。句子编码保留词及表演指令。压缩会损失韵律与口型细节。

共享因果编码器的所有时间混合层使用相同家族。比较四原子、带不应期和两项现金价值的 He–Xiong 群体传递；相同群体核与边界而把两项价格替换为斜率匹配的平滑对照；有代理梯度和硬复位的 LIF；含点积注意力的参数量近似对齐 Transformer。沿用已验证的 RSICD 时间层实现和 4 原子价格表。使用相同宽度、6 层、4 倍逐位置前馈、位置编码及 256 维归一化跨模态读出。小模型宽度 416、16 组；大模型宽度 4096、32 组。须从实际参数求和与稠密梯度计数确认十亿参数，不允许计入冻结表或虚置权重。使用 FP32 主权重、可用时 BF16 矩阵乘和 FP32 首达质量传播，记录后端、显存、实际步数、优化器、训练样本和参数更新证据。所有模型均从随机种子 137、311、557 开始。基于实数舍入的阳性判据与真梯度路径分别报告。

每次更新取 16 个真实训练片段，学习视听向对应自然语言的多正例对比损失及反方向损失。同批中相同联合标签的片段视为多正例。训练时音视频和文本走同一共享编码器；推理时对全部 72 条文本分别计算嵌入。固定 AdamW、学习率小模型 .0003 / 大模型 .0001，梯度范数上限 1。禁止冷集调参。记录第 4、16 次相同梯度更新、同步优化墙钟满 60 秒和终点（小模型 300 秒、大模型 600 秒）。如超时先于固定步，终点后补足 16 步并把它明确标为同样本比较。每类模型以所有预设开发观测中联合 NLL 最低的权重选择，另报告各固定端点。验证过程涉及完整正确信号，不按冷集挑模型。拟合、开发、序列化和冷启动计时独立记录。

全部模型及时间点先封存再评估演员留出集。主指标是每段 72 类候选的联合 NLL；另报联合 top-1、汇总同句/同指令概率后的分项准确率、平衡准确率、候选先验。分别在同位演员内部打乱视觉、声学或两路输入，保留真实文本候选，报告感知信号的贡献。按演员为单位做 4,000 次配对重采样，种子先平均，报告单种子和区间。固定同质量表采用全三个种子各自跨过测试 NLL 4.1、3.6 或 3.0 的首次观察计算，未达作右删失。训练只在已验证的单张 AMD Radeon 8060S（100 GiB 统一 GPU 内存）进行；前述三芯片实验各自报告。小任务、12 句受控脚本、有限说话者和数小时训练只检验多模态编码器的真实尺度可运行性与本数据的相对表现。
