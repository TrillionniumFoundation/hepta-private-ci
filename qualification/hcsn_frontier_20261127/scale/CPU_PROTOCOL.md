# Independent CPU size comparison

Run the same 24 architecture, width and seed combinations on a single pinned CPU core in float32, from the frozen 40dacfd435b5b8723ffdab24b120985ffcf5c56a7c4f735965552c3a450712d8 assembled source. The training images, quantization, scripts, loss, optimizer, order, batch size, split and cold grounding criteria are shared with the T4 protocol. CPU optimizer budgets are 15, 60, 180 and 360 active process seconds with wall time logged separately. Run every arm from scratch and retain the best weights by development NLL. Measure full cold-load/conditioning timings; permit a stronger language-only benchmark. This is an independent processor comparison motivated by the first cloud job returning without CUDA. It does not estimate GPU throughput. If a later GPU run succeeds, report it as a different hardware experiment.
