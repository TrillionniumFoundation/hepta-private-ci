# GPU size and equal-quality study on an independent satellite-caption corpus

Use the public UCM-Captions release (2,100 aerial photographs, five human captions each; Hugging Face caglarmert/UCM-captions commit 393e3704f8b004c6878407280e24e3e09632005b). Fixed train/development/test partitions, remove cross-split exact visual duplicates and in-split duplicates; identify very similar 64-bit difference-hash pairs and report them. To fit a private offline accelerator request, retain 8×8 color images quantized to RGB332, and up to three captions per image, in original order, with tokens from the training vocabulary only. Cap sequences at 20 tokens plus boundary symbols. If a stricter static package size applies, reduce captions per image then use stable image ID subsets before any training. Publish exact retained IDs and unknown-token rates. This is a small-data scaling study and the compression limits fine-detail grounding.

Train a common causal caption decoder from random initialization at two widths (384, six blocks; 640, eight blocks; four-times-width MLP), comparing a finite twelve-atom priced HCSN patch front end, a same-bandwidth smooth-hazard front end with matched local slopes and same state/width, row-mean pooling with four transmitted image embeddings, and a conventional dense sixteen-patch prefix. The physics and smooth arms use four sequential steps per patch row; each row produces one continuous spike-weighted content vector. All text decoder weights live in their own arm; no pretrained backbone. Three predetermined seeds (137,391,757); the same initialization pattern and training sampler are shared within seed and size. Measure the actual parameter count. Optimize token cross-entropy with AdamW, batch 24, mixed precision on CUDA when feasible. Log optimizer, validation, setup, model selection, inference and peak memory independently.

Nominal GPU budget per arm/seed is 360 seconds, checking at 15,60,180,360 s; 24 fits require 2.4 GPU hours. If the cloud adapter refuses the requested maximum before submitting, use the first provider-supported budget from the ordered per-fit caps 120,60,15 s, with internal rungs clipped and deduplicated. Short profiles receive only right-censored conclusions; no switching accounts after an uncertain submission. Checkpoint choices use development per-token cross-entropy only. Cold scoring follows completion of all selected weights. Report log loss on held-out images, shuffled-image grounding gain, equal-budget learning curves, and time to frozen development targets, together with paired image-level resampling. On this teaching dataset, do not infer billion-parameter or all-modality pretraining superiority from a faster GPU step or lower language loss alone.
