# 连续首达神经元上的逐次编辑与同似然训练

对 CRCNS 挑战数据 A、B、C 的同一个可微首达读出做两层比较。每个记录用 12,900 个 2 ms 时间箱拟合，开发段选参数，留出 3,400 箱。A、B、C 分别有 13、9、7 次重复刺激。A、B 用 6 个含截距的因果特征，C 用 11 个。分数单位为每次试验每时间箱的平均负对数似然，越小越好。时间段、样本和解析方程见 [原协议](PROTOCOL.md) 和 [同目标计时协议](LIKELIHOOD_PROTOCOL.md)。

| 记录 | 逆首达目标的顺序闭式解 | 真似然 BP | 解析 Fisher | 顺序闭式解减 BP 的成对 95% 区间 | BP / Fisher 墙钟秒 |
|---|---:|---:|---:|---|---:|
| A | .083299 | .065543 | .065543 | [.011845, .024212] | .5293 / .2269 |
| B | .096030 | .078247 | .078247 | [.010874, .024884] | .4629 / .2101 |
| C | .064096 | .051891 | .051891 | [.009116, .015679] | 1.8816 / .2649 |

顺序逆驱动更新在固定特征上精确复现对应批量岭回归，最大权重差 1.60e−11。每个重复放电概率先收缩再反解为驱动目标，样本在其可达范围内。以驱动平方误差拟合，在三个记录上的留出似然均次于直接似然拟合。相同的线性正交变换可运输旧充分统计量，若保持旧坐标，三组最大权重偏差分别为 .082、.156、.352。

采用解析链式导数直接优化相同的惩罚伯努利似然，手写梯度与中心有限差分的方向误差小于 2.5e−11。Fisher 迭代保留全部特征的交叉曲率项并执行回溯。七次交错计时中位数给出 2.33、2.20、7.10 倍墙钟比，进程 CPU 比为 2.24、2.15、7.13。每次计时覆盖三个岭参数的拟合和开发打分，公共电流特征提取未计入。与 BP 的留出似然差均小于 1.5e−8，单箱最大概率差小于 2.8e−6。该迭代需要输出标签和残差，更新一行读出权重。三条神经元记录、一个本地 CPU 环境构成这组比较的适用范围。

[selection.json](selection.json) 和 [heldout.json](heldout.json) 提供候选选择与 500 ms 成对块重采样。[likelihood_results.json](likelihood_results.json) 保留每次计时与全部选项。[replay.py](replay.py) 依据逐箱预测和原始重复标记重计七种方法，独立计算三种似然解的留出分数。对应 [recount.json](recount.json)、[A](A-edit.npz)、[B](B-edit.npz)、[C](C-edit.npz)。
