# Sequential edits of an identified neuronal risk readout

Liu et al., Rethinking Sequential Locate-Then-Edit: Optimality and Stability, arXiv:2611.33692, published November 25, derive batch-equivalent editing for specified locate-then-edit objectives. Test a smaller, explicitly identified family on the existing cortical A/B/C recordings. This is a retrospective mechanism benchmark; those recordings and the earlier frozen-reservoir results have already been examined. Do not attribute this specialized recursive least-squares calculation or its speed to a reproduction of that LLM paper.

Use the same 2 ms counts, training/development/held-out time windows and five causal exponential current averages per measured input. Append a unit intercept. Each input key produces a bounded principal, the nominal affine He–Xiong boundary, a log margin and the exact quarter-time first-hit probability at the published positive physical drift. The normalized pre-control margin is .18. A counted bin with k spikes among N repeats is assigned (k+beta*p_train)/(N+beta), with beta in {.5,2,8,32}. Invert its first-hit target once per distinct count by bracketed bisection to obtain an identified desired drive. Flag out-of-range targets. A single shared weight row learns a least-squares prediction of these drives; this is a local supervisory rule relying on repeated responses. The Bernoulli downstream objective used for selection is different from the squared drive objective.

Compare joint ridge and chronological rank-one recursive updates on identical readout keys, effective ridges (1e-5,.001,.03) times the number of bins. Compare last-key-only unregularized projections, exact-likelihood reverse-mode fitting of the identical risk cell and a logistic direct-current baseline. Use development log loss to select each method's designated hyperparameters and report the preserved held-out scores and 500 ms paired block intervals. Log setup, inversion, batch/online solution and all likelihood tuning wall times. For an additional representation-drift check, rotate all nonconstant key coordinates with a fixed orthogonal transform at the halfway point. Compare a properly transformed Gram statistic and weight vector against the fixed-coordinate batch, and separately measure the inconsistency when old statistics are carried forward without conversion. This known rotation cannot generally repair arbitrary deeper representation drift. No additional raw subject is introduced.
