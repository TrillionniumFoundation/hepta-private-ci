# Interpretation of the fixed budget grid and exact contract controls

Before any held-out predictive evaluation, add three descriptive checks. A fee posted in future slot 3 has exactly zero effect on the first two-slot outcome for every anchor. Quantify spurious predicted fee effects at that endpoint as an absolute difference and report paired-week uncertainty. Report violations of cumulative-horizon and reserve ordering as additional diagnostics. These checks were suggested by an independent source audit and examined on French development records, so they are named secondary controls. The original three endpoints and decision rules remain in the primary results.

At each development target report the first observed qualifying checkpoint and the preceding observed nonqualifier, along with active optimizer, sequential fit, validation and checkpoint wall time. The measured curve can be nonmonotone between checkpoints, so its mathematical first crossing may have occurred earlier. A cached-raw reconstruction separately times data preparation, import and lookup setup. Report per-method actual cold load and inference time. The data-download cost is not timed in the cached-raw measure. A development milestone alone does not establish a time advantage at matching external quality.
