## Predeclared scientific protocol

- Original **36 TRAIN / 24 historic public TEST** genuine Beans leaf photos, three original disease classes, 384D *real* DINO image vectors, and 384D *real* Granite text vectors describing **only the three TRAIN class prototypes**. Every TRAIN case maps to a paired original target text with exact digest and original producer receipt. No future labels or publisher TEST Parquet are admitted in the fit process.
- `rank=8`, 384×8 + 8×384 = **6,144** trainable Organ coefficients, 160 deterministic full-batch SGD steps and `seed=217` on TRAIN only. ReLU/gates are not added; the residual projection and normalization are specified in code. Teacher cosine logits are supervised using known original TRAIN class labels. This is a *restricted class-prototype alignment task*, not general multimodal reasoning.
- Null Organ: identical 6,144 coefficients, same train-step budget and initialization, but a **fixed global coordinate permutation/sign flip** of Granite prototypes. This preserves all text-text cosine geometry (the 3×3 Gram matrix) while removing the original visual-text coordinate correspondence. A distinct, untrained direct text/vision cosine baseline is also scored.
- After freezing each candidate Organ, train the identical two-slot three-class Head `2×(384+1)×3 = 2,310` parameters with **256 SGD updates per arm**. Shared `one_touch` and Split each modify **1,155 parameters per step** (295,680 estimated touched scalars), with identical initial Head weights, sample schedule and learning rate. Hashing original case IDs defines the two *nonsemantic* Cell types; wrong Cell routing is a required negative control. The raw DINO Shared Head is a lower-cost baseline with no Organ fitting.
- Frozen original DINO visual prototype is a **strong three-class baseline** from the exact same original upstream image-feature archive, not the weaker V9 derived binary Head. Original source/identity and predicted class strings are rechecked by the reviewer before scoring.
- Retain all paid Organ/Head training, both null arms and failures. No architecture is allowed to retrospectively pick favorable hyperparameters from TEST scores. CPU `time.process_time_ns()` is self-reported and excludes pretrained teacher/model loading and end-to-end latency. No GPU, p99, energy, warm/cold RAM, model weight pretraining cost or real 4,096 Cell service TCO is inferred.
