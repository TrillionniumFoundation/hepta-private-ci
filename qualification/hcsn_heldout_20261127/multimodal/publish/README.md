# 两项同带宽的自由边界事件实验

从配对输入选取携带有符号向量的事件，能否用较小时间或带宽传送同等有效的信息？本目录提供两项新测量。读取图像或视频帧后，发送者用监督证据调整债务本金，应用 He–Xiong 平稳边界式 (12)、股权值 (A7)、首达概率和带重置的均值传递。给定块内传输名额，将首达概率最高的位置和原始有符号特征向量发给接收者。每次只能在接收完一个块后作选择。平稳单步解析值正确描述所采用的算子；输入变化、跨步均值压缩、离散配额选择属于本实验的新建模。配额使用 argmax，本实验证明的是有限消息通信的表现。

计算使用单线程 CPU、NumPy/SciPy 以及闭式 ridge 读出。没有复用此前训练权重。宏召回按人计算，检索按图像聚类。主结论是这两项试验都没有得到边界选择器相对强同带宽对照的准确率优势。研究数据、流程与先前结果的关系如下。

| 任务 | 当前自变量与分母 | 自由边界 | 开发集所选的同带宽对照 | 密集传输 |
|---|---|---:|---:|---:|
| GRID 四类孤立词，宏召回 | 568 条真实音视频，12 人，每段 8 个时点选 2 个，450 字节 | 53.57% | 固定位置 89.28% | 85.91%，1,792 字节 |
| COCO 图文检索，双向 R@1 | 新队列 1,024/256/384 张图，8,318 条说明，测试 1,920 条说明；16 个图块选 4 个，340 字节 | 1.484% | 固定位置 1.953% | 1.719%，1,344 字节 |

GRID 已用于以往的完整模型比较。本次选择器、配额、开发选择与干预在新测试前固定。12 份原输入哈希一一匹配。两折的开发集独立选中第 4 和第 7 时间片。同带宽差为 −35.71 个百分点，按人重采样的 95% 描述区间为 [−44.74, −26.83]。保留位置但抹去传输内容，边界模型的宏召回为 26.19%。将输入音频归零为 34.27%，将视频归零为 66.82%。第一折保留双反馈，第二折选零反馈。三次独立冷复算得到相同逐行数组。完整搜索和冷测在两折相加的外部墙钟为边界 2.87 秒、固定位置 3.63 秒、两块均值 2.33 秒。位置搜索有 16 种配置，边界有 2 种。预先设定的质量容差没有通过。

COCO 从历史 4,096 训练图像扩充名单中的 1,830 张新增且有可校验本地图像中抽取，**与历史训练、开发、测试 1,600 张的 ID 交集均为零**。测试与当前研究的训练、开发隔离。图像采用 32×32 RGB 的局部颜色和边缘描述子，文本使用仅训练说明拟合的 TF–IDF。新任务未使用 CLIP。340 字节条件下，两块/时间选择器在此任务对应每行取一个图块，每张图四条消息。同带宽固定位置的配对 ΔR@1 为 −0.469 个百分点，区间 [−1.432, +0.495]，条件于固定 384 张检索集。相同带宽的分块均值 R@1 为 2.917%，R@5 为 8.333%；边界选择为 1.484%、7.344%。开发集选择完整双反馈。时间戳不变、抹去标记内容后 R@1 为 0.182%。

COCO 预先设置非劣阈值绝对 2 个百分点，宽于固定位置实际 1.953% 的完整 R@1。按这个宽松口径、包含不同规模的配置搜索（8 种位置、2 种边界）及四个冷评估视图，边界 5.33 秒、固定位置 9.63 秒、密集 6.97 秒、均值 5.64 秒。后续锁定开发选中的单一配置和正则化系数，各方法重新拟合一次、仅执行一次完整检索，5 次独立冷进程的中位数为边界 1.980 秒、固定位置 2.013 秒、分块均值 1.952 秒、密集 2.177 秒。该核验完整复现各个图像和说明排名。前者相对固定位置只缩短约 1.7%，相对密集约 9.1%。计入进程启动前后的墙钟受到调度与导入影响。内部训练/冷测试分别为边界 0.331/0.184 秒、固定位置 0.278/0.153 秒。当前结果没有确定同质量训练提速。所有方法都会在本地处理输入全部时点，报告的带宽为逻辑消息长度，没有测量物理总线或功耗。

## 复算

环境为 Python 3.12、NumPy 2.3.5、SciPy 1.17.0、scikit-learn 1.8.0。取回归档中收录的输入摘要、训练状态、逐行预测和耗时。设置 OPENBLAS_NUM_THREADS=1、OMP_NUM_THREADS=1 和 MKL_NUM_THREADS=1。先运行包内清单校验。GRID 可运行 python campaign.py fit、python campaign.py test、python summarize.py，得到两份时钟和 grid_summary.json。以保存的原始耗时比较速度；重跑生成的时钟取决于本机。新生成的 NPZ 容器元数据可变化，请用 campaign.py 的逐数组内容摘要复核。

COCO 的 python coco/replay_portable.py 从配对的图块描述量与稀疏词频权重重新拟合全部七个选定模型，核对每个模型四个视图的所有图像、说明排名。该检查在打包前重新执行，权重误差上界为 3.55e−15，所有整数排名逐项一致。python coco/summarize.py 从冷评估输出重新产生区间。为独立还原完整开发搜索，使用 coco/source_ledger.json 中的原始样本标识和哈希在官方 COCO 图片及 Karpathy 训练标注获取源数据，或使用先前扩充研究的已校验缓存运行 coco/prepare.py，随后运行 coco/campaign.py fit 和 test。COCO 原图、字幕文本和 GRID 原始录音、影像不包含在交付文件中。发送的局部统计、稀疏词权重和研究预测保留于归档。

GRID 物理公式来自 hepta-private-ci 的 cf5aa0c954e92fbecd3a53494ccefaa37a2bb7d0 中 scripts/hcsn/hepta_free_boundary_reference.py，超参数与 qualification/hcsn_research_20261127/literal/cell.py 对齐。GRID 数据集 DOI 10.5281/zenodo.3625687。COCO 来源为 MS COCO 2014，同步使用其 Karpathy 训练说明。预处理与采集此前已经发生，完整原始下载/解码时间不计入本次模型拟合或冷推理。COCO 首轮冷进程因工作盘耗尽中断；原协议、数据和权重哈希校验后，全部七臂重新用同一配置各跑两次。历史开发测量、受影响的尝试和本次重新运行有不同的成本口径。

## 供复核的文件

- PROTOCOL.md、coco/PROTOCOL.md 与对应输入和程序摘要固定了两项首次检验。
- grid_summary.json、coco/summary.json 提供分项质量和成本。coco/locked_cost.json 保存五次锁定配置的独立过程计时。
- weights/、predictions/、coco/weights/、coco/predictions/ 提供模型和测试级别原表。fit_seal.json 与 coco/fit_seal.json 记录独立验证前已选定的配置、权重和对照。
- grid_input/、coco/paired_descriptors.npz、coco/caption_tfidf.npz 与 coco/source_ledger.json 用于从数据和逐条来源复核统计。coco/portable_verification.json 记录独立重放差异。
