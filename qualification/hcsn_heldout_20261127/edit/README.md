# 三个已训练 HCSN 的接收端隐藏突触编辑

在真实的阿拉伯语到英语语音数字迁移上，直接写入 HCSN 的接收者突触，可以在个别父网同时改善新任务并维持旧任务。三个父网中，一个通过预先规定的全部质量条件。当前数据不支持稳定替代同层反向传播，也不支持全模态预训练提速。

## 改写位置与实验设计

32 个神经元中有 16 个接收者，各读取 32 个上一时刻的连续边界。候选只改动这 512 个实际连接权重。每次前向都重新传播神经元的自由边界、概率质量、标记和接收者输出。发送者、脉冲成本、归一化、原先训练好的十分类读出和其他参数保持逐字节一致。历史上直接改写过的 224 个发送者参数属于另一个位置。

新、旧训练录音各自形成真实接收键的二阶矩。广义特征向量优先选择新任务能激发、旧任务典型输入较少激发的方向。分别取 12 个正负扰动，测量冻结读出经过整段非线性网络后的响应，用新任务分类残差与旧任务分数保持项求解一次正则化最小二乘。实际计算使用前向求值，没有调用梯度。比较包括 KEEP、软保持、去掉保持项、循环错置新标签和同位置 12 步 Adam 反传。所有方法都可以在同一开发集选择 KEEP。

本次使用既有基准，其他候选在这批测例上的汇总成绩此前已公开。新候选只用分开的训练和开发资料拟合、筛选。三份父网、全部方法和权重统一封存，随后在 15 个独立进程中用原始完整网络冷测。每个模型使用未参与候选选择的 1,000 条英语录音和 2,200 条官方阿语录音。英语测试只有两位说话人。48,000 次录音与模型的组合产生 480,000 个分类分数，共用 3,200 个不同的语料记录。

## 单父网结果

| 父网 | 方法 | 英语准确率 | 阿语准确率 |
|---|---|---:|---:|
| 107 | KEEP / 软保持 / 同层 BP | 20.8% | 84.591% |
| 107 | 无保持 / 错标签 | 20.8% / 19.5% | 84.500% / 83.409% |
| 211 | KEEP / 同层 BP | 19.4% | 81.182% |
| 211 | 软保持 | 21.7% | 78.818% |
| 211 | 无保持 / 错标签 | 20.9% / 19.4% | 79.682% / 81.182% |
| 431 | KEEP / 同层 BP | 15.6% | 84.864% |
| 431 | 软保持 | 18.5% | 84.045% |
| 431 | 无保持 / 错标签 | 18.5% / 16.1% | 84.409% / 84.682% |

107 的软保持在开发集选择 KEEP。211 的软保持使两名新说话人分别多答对 3 条、20 条，同时使旧任务多错 52 条，旧准确率下降 2.364 个百分点，超过预设的 2 点上限。431 分别多答对 11 条、18 条，旧任务净少答对 18 条，下降 0.818 点。431 上无保持臂达到同样英语准确率，阿语准确率略高。就这两项外部准确率而言，没有观察到该父网上额外加入软保持项的净收益。

所有增强的 211 和 431 软保持模型均改变 512 个允许的系数。三个 BP 模型均实际执行十二次全校准集 Adam 更新，最终由开发规则选回 KEEP。这个固定配置比较不足以回答不同目标或其他学习率预算的 BP 能达到什么水平。

三个模型归集合计，软保持与 BP 分别使用 95.68 与 209.13 墙钟秒，单线程进程 CPU 合计分别为 62.05 与 112.95 秒。每种前向编辑都承担完整共享探测费用，各臂还包括开发选择和在完整原始模拟器上的冷评估。原先的特征准备、数据获取和父模型预训练属于共用既有投入。各父并行，在共享主机上测得的墙钟合计代表这些任务的加总，而非单一流水线的历时。三父一致的质量准入失败，不能将成本之比报告为相同质量下的整体加速。
