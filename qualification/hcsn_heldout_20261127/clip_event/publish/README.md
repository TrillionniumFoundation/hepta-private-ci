# 强 CLIP 图文编码器上的自由边界标记

这项研究在具有较高检索准确率的真实冻结前端上检查增量贡献。相同配对的 COCO 图像和说明进入已固定版本的 CLIP 图像及文本编码器。保留两个 512 维全局表示，另取每种模态已经归组的 4 个 32 维真实中间特征。比较原始冻结模型、He–Xiong 式自由边界首达选择、同监督显著性、时间变化、固定位置、分块均值和完整局部特征。每个稀疏接收者最多额外传递两个有符号 32 维向量和两个位置。两个模态分别以闭式岭回归学习向配对全局表示的残差，六种增量方案都允许取零。

COCO 训练、开发、测试有 1,024、192、384 张图像，测试包含 1,920 条说明。它们属于此前冻结前端研究的三个划分。这个队列与本次另一项新增 1,664 张原图研究没有图像 ID 重合。新候选及比较标准在本次评分前固定。开发集对六种增量方法全部选择零尺度。因此，测试集每张图像和每条说明的排序与直接采用冻结 CLIP 一致。双向 R@1 为 63.099%，R@5 为 89.323%，MRR 为 0.74182。1,024 张训练图像对此规模的手工分块、闭式校正没有带来可独立采用的增益。

冻结模型传输每条全局消息 2,048 字节。额外稀疏标记如被选中为 258 字节，密集额外消息为 512 字节。此处零尺度允许免算增量通道，实际新增字节为零。含拟合、开发选择及四个冷评估视图的外部进程墙钟中位数之和为边界候选 4.922 秒，原始 CLIP 基线 3.890 秒。6 份既有特征抽取回执的运行时长加总为 406.827 秒，涉及不同进程；本次只重新运行冻结特征之上的训练和排序，不能以此加总估计一次实际并行全流程墙钟。

另做了事后强制启用非零残差的诊断。对协议中原有的 0.1、0.25、0.5、1 四个数值完整检查。此时自由边界相对冻结模型的测试双向 R@1 差别依次为 −1.380、−0.781、−1.953、−5.208 个百分点。0.25 的按图像重采样区间为 [−1.979,+0.417] 个百分点。改变模型拟合规则或以测试设置进行选择都会引入新的研究问题。非零诊断保存所有候选、两个方向和同强度显著性对照。

## 复算

归档保留所有状态、逐图/逐说明的排名、不含原始媒体的 6 份冻结前端数值数组，以及其来源和内容摘要。CLIP 仓库是 Xenova/clip-vit-base-patch32，版本 6b7c523703ae26e39be4b03774966f8571c7f523；归组隐藏量的提取方式见 hepta-private-ci 的 cf5aa0c954e92fbecd3a53494ccefaa37a2bb7d0、qualification/hcsn_research_20261127/root/encode.py。token 的顺序为图像图块或文本归组的顺序。

在包含归档的独立目录，设置 CLIP_FEATURE_ROOT 为解压目录的 features 绝对路径，并将 OPENBLAS_NUM_THREADS、OMP_NUM_THREADS、MKL_NUM_THREADS 设为 1。Python 3.12、NumPy 2.3.5、SciPy 1.17.0、scikit-learn 1.8.0。运行 python replay_portable.py 从保存的特征及权重复验全部 7 个方法的基准排名。运行 python run.py fit、python run.py test、python summarize.py 可完整重训，然后运行 python nonzero.py 核验强制残差结果。目录里的 seal.json 记载七项模型在独立测试之前的权重、阈值和对照。运行时间会随硬件和调度改变。所有检索区间按图像成组、条件于固定库计算，未覆盖另取图库的变动。
