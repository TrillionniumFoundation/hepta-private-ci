# He–Xiong 的权益、货币损失与群体脉冲观测

本研究固定发表于 *Journal of Finance* 的 He–Xiong (2012) 表 I、式 (8)、式 (11) 与命题 1。研究来源和代码从提交 b2ae840e3c520146069d062ca2950623562bee01 追加。本文区分单个活跃原子的物理坐标可辨识性、群体动态所需状态，以及真实任务训练效果。

对活跃原子取 \(x=\log(V/b)\)。货币损失是保持相同流动性折现率 \(q=r+\xi k\)、票息与本金时，无违约合同价值减去式 (8) 所得的债券价格。设 \(F_H=\Pr(\tau\le H)\)、\(G_H=\mathbb E[e^{-q\tau}1_{\tau\le H}]\)、\(R=\alpha b/m\)。则
\[
 L=e^{-qH}(p-c/q)F_H+(c/q-R)G_H.
\]
若回收不超过任一剩余期限的无违约合同价值，逐路径损失非负。基准模型满足该条件。权益在选择出的边界上价值及一阶导数为零，货币损失通常具有非零右导数。

## 已运行的有限状态结果

首次工作的单机 CPU 记录以八个活跃位置 \(x=(.025,.075,.125,.18,.235,.30,.46,.70)\) 为网格，初始 \(x=.18\)，重置 \(x=.30\)，表 I 漂移和波动率。以零边界的吸收高斯镜像核积分区间存活质量。首次触界质量先进入不应期，完整休息一个后续时间间隔，在间隔末返回重置位置。每步可通过有界本金改变内生边界与神经元压力。网格末端包含概率尾部，存活分布每步投影至代表点。逐步冻结经济参数和离散不应期均属神经扩展。

- 将权益、货币损失分别除以其在 \((.18,61.68)\) 的参考值、输入以 \((.18,.28P_0)\) 缩放，基准 \(P=P_0\) 时，雅可比两奇异值在 \(x=.18\) 为 \(2.07964, .29909\)，在 \(x=.003\) 为 \(2.29182,.00968\)，在 \(x=1.3\) 为 \(6.45863,6.25\times10^{-8}\)。基准坐标的未缩放行列式为 17.47507244。边界与远离边界的稀有触及区间都有严重的逆向条件问题。
- 一个固定诊断网络中总质量误差 \(3.33\times10^{-16}\)；每单元平均累计触及质量 1.32109，已触及过至少一次的再触及质量 0.47145。四个输入、连接或反馈参数的自动微分对中心差分最大绝对误差 \(7.32\times10^{-12}\)。固定边界下首达网格误差从步长 .04 时 .002014，降至 .005 时 .0000303。
- 固定 \(P,b\) 并比较两个不同的严格正群体分布。两群体的权益、货币损失均值相同，绝对差 \(<2.3\times10^{-15}\)，而未来区间 \((.25,.50]\) 的首次触及概率相差 0.04941651。再要求 \(F_{.25}\) 也相同时仍差 0.00741631，另加 \(F_1\) 后仍差 0.00562631。这些是任意容许分布的反例。是否能从同一初值通过不同刺激达到这种状态，是另外的可达性问题。
- 设 \(A\) 的行包括总质量及已知均值，\(W\) 为要预测的一组未来目标。对已知有限支持且未知混合权重，精确恢复 \(W\) 所需额外**线性**读出数量为 \(\operatorname{rank}([A;W])-\operatorname{rank}(A)\)。在 \((1,E,L,F_{.25})\) 的秩 4 基础上，登记的未来目标组总秩为 8。增加四个首次触界读出 \(F_{.08},F_{.125},F_{.5},F_3\) 足以精确恢复有限网格上的任意读出。
- 对八个与选点分开的目标时长，逐个加入上述探针，无噪声最大最坏情况绝对误差为 .0382645、.0047042、.0020510、.00015447 及数值求解容差内的零。每个读出按其在支持上的最大绝对值标准化后，各有 1% 有界误差、总质量精确时，四个额外探针的最大最坏情况误差仍为 .0118682；相同预算下仅基准读出为 .0622510。接收者可以忽略不再增加稳健信息的探针。

## 误差与反例的理由

若目标行 \(w\) 不在 \(A\) 行空间中，则存在 \(Av=0,wv\ne0\)。在严格正的概率向量上施加足够小的正负 \(v\) 扰动得到一对合法分布，所有观测相同而目标不同。总质量必须纳入 \(A\)。无噪声时的精确 minimax 误差为 \(\inf_c\|w-A^\top c\|_\infty\)。双线性规划从任意同观测的概率对求最大目标差，其值为该误差两倍。若除质量行外的已标准化读出误差各不超过 \(\epsilon\)，对应优化在目标中加 \(\epsilon\sum_{i\ne\mathrm{mass}}|c_i|\)；其对偶允许两组概率的测量误差盒相交。
