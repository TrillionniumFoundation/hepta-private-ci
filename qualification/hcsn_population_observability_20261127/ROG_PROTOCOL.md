# ROG single-core confirmation protocol

This is an independent reconstruction after a shared cloud working directory became unavailable. Its Git revision, hashes, host, and seeds identify it separately. The previous run's 45 sealed core fits and six ordinary controls are not a substitute for transferred checkpoints or predictions. No held-out scores from that run were read. This protocol precedes ROG fit or confirmation. The original design and primary comparisons are unchanged.

Three official train/test splits are used: aeon v1.3.0 BasicMotions (wearable activity), ItalyPowerDemand (seasons inferred from measured 24-hour profiles), JapaneseVowels (recognizing known speakers from recorded utterances). Six Git blob IDs are checked. Within training, hold out 20% per class in SHA-256 order using the prefix population-v1 and the dataset name and position. Divide each record into eight temporal bins, computing mean and RMS per channel and copying the nearest available measurement for empty short bins. Center/scale using only the fitting portion, with ±8 clipping. Deduplicate records shared with training and repeated within test. Official splits establish record-level performance. Participant, site, or date grouping is missing for some data. Speaker identification is not unseen-speaker performance. Class-conditional means and class counts will accompany the results. External task observations have no financial meaning.

Causal Transformers use one block, width four or sixteen, one or two heads, 2w feed-forward width, fixed eight learned positional embeddings and final+mean pooling.

Core arms are priced equity + monetary shortfall, priced equity + first-hit probability, and a bounded smooth gate matched to both price features' local gradients in margin and principal, plus LIF and GRU. Choose an ordinary primary comparator on development among logistic, RBF, and GRU. Preserve the time and selection budgets of supplemental DTW and Transformers separately. Use frozen interventions suppressing risk only, both feedback features, or reset, and measure probability, Brier and repeated event responses. Class-stratified record-level paired bootstrap, 5,000 draws, generator seed 5251; fixed model seeds averaged before resampling. Overall promotion requires strict improvement over probability, tangent gate, LIF and selected ordinary comparator, with 95% intervals below zero across all three datasets.
