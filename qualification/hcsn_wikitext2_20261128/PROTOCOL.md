# Frozen WikiText-2 end-to-end comparison

Use the three released WikiText-2 word-level files bundled by PyTorch, pinned to commit acc295dc7b90714f1bf47f06004fc19a7fe235c4. Verify each raw byte digest before encoding. Append one EOS token per physical line. Only the official training split determines the word IDs and 33,278-word vocabulary. Official validation and test are disjoint supplied splits. No hyperparameter search.

Train on every adjacent target in every epoch, including the final partial block. Split the continuous stream into adjacent blocks of at most 128 prediction positions. Use a common seeded permutation of whole blocks in training and sequential complete official splits for evaluation. Context restarts between blocks. All comparisons use two blocks, width 32, four heads/groups, one shared exact full-support hierarchical word distribution, 1,144,579 trainable scalars per model, float32, AdamW LR .003, decay .01, gradient norm clip 1, minibatch 32 blocks. Each model receives exactly two complete training traversals per seed (137, 311, 557). Select among the two full epochs solely by minimum whole-validation NLL. Record held-out mean negative log-likelihood and its exponential perplexity plus the final state hash. Evaluation uses teacher forcing, natural logarithms and normalized word probabilities. No lexical n-gram side input.

The He–Xiong block computes exact equity and monetary credit loss on a categorical two-point safe-margin law through the original fixed-contract formulas. Principal varies per channel at every position. Its only signal to the next block is normalized log physical default boundary. SDPA uses causal PyTorch SDPA. Smooth control uses a generic tanh/sigmoid gate on the same causal exponential histories. Hard LIF uses hard threshold and reset plus a triangular surrogate derivative on the same histories. Shared embedding, output head, positional encoding and feedforward shapes, and common seeds. The language encoder is an operator-level adaptation. Its temporal law is the explicitly specified causal filter. The full reset diffusion from the half-line bistability analysis is a separate model.

For elapsed-time comparison record the first optimizer update completing after fixed training-only wall deadlines 15, 45, 120, 300, 600 s. Include data indexing, forward, backward and optimizer in this clock and exclude evaluation and checkpoint serialization. Calculate each checkpoint's complete validation and test scores; the primary matched-time score uses the largest deadline that every member of the same hardware comparison reaches, independent of quality, and reports actual per-run overshoot. Training throughput uses every target and all training steps. Process CPU time and execution configurations are retained. An evaluation-time zero cut between blocks supplies the same ablation for each model. Each trained endpoint is independent, evaluated over both full official held splits. Three seeds measure run variability; no general scaling, long-memory or multimodal claim follows from this protocol.
