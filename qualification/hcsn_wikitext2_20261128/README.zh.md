# WikiText-2 官方分割上的自由边界语言模型

四种模型使用同一训练词表、相同的 **1,144,579** 个可训练参数、最多 128 词的因果上下文和完全归一的 33,278 词空间。每种模型从空白权重出发，在三个随机种子上各训练两遍，合计处理 50,127,048 个训练目标。每次验证均覆盖全部 217,645 个相邻词预测，每次独立测试覆盖全部 245,568 个。两个训练轮次中以验证 NLL 选择终点；十二个模型均选第 2 轮。训练、验证、测试原始文本固定至 PyTorch examples 的 acc295dc7b90714f1bf47f06004fc19a7fe235c4，三个 SHA256 和词表摘要见 [语料清单](data.json)。WikiText-2 属于已将罕见词替换为 unknown 的发布版，每个物理行追加一个 EOS；这一定义影响与其他文献中 PPL 的直接比较。[发布者数据说明](https://huggingface.co/datasets/Salesforce/wikitext/blob/main/README.md)

Hepta 相对 SDPA 的净 NLL 差在三个种子分别为 −.02132、−.00539、+.00615。普通平滑与硬 LIF 在三个种子的等词数试验中都胜过 Hepta。单核交错重复八轮，Hepta 更新吞吐是 SDPA 的 1.49 倍，普通平滑算子吞吐是 Hepta 的 1.40 倍。计时比较限于当前小宽度、语境和 CPU 实现。15 秒是所有十二个运行均通过的最大预先约定时点。这个强制共同训练区间评分直接使用各自第一个跨过时限的更新，各次过冲及实际训练词数均已记录。单核交错计时独立于并行训练过程。[逐种子数据与独立词块分析](summary.json) · [固定核心顺序交错计时](benchmark.json)

## 真实金融算子与可复现的对照

模型在安全裕量 .04 与 .24 两点的概率分布上，平均原 He–Xiong 股权与货币信用损失。每个位置、每个通道的本金调制值由上下文决定。固定这些裕量时，原模型的定价及内生阈值对本金仿射，可用原式预计算的系数精确重建。股权项与信用损失项以相反符号进入块内动态。块内保留共同规格的残差与前馈映射；整个块送往后一块的唯一张量是标准化的实际对数边界。语言实验采用四种固定时间常数的因果指数滤波，不包含半轴完整复位群体的 PDE 演化。替换真实未来半块，四个编码器的前缀变化均逐点为零。41 个本金值的股权、信用损失及壁的重建绝对误差最大为 1.71e−13。枚举所有词后的概率和偏离一最大 1.88e−7。[算子与因果复核](checks.json)

将 Hepta 两块之间整条边界线置零，平均测试 PPL 从 397.34 升至 3079.25。这个消融证实信息确实经该接口。将每个测试块的前 96 个词替换成另一非重叠测试块的等长前缀，保持最后 32 词及所有位置编码原样，只评分最后 16 个目标，每个种子共 30,688 个；Hepta、SDPA、平滑、LIF 的平均 NLL 增量分别为 .00564、.02419、.00871、.00264。此处比较已训练模型对具体早期语言输入的敏感性。发送端双稳态的解析存在性与任意样本级长期回忆能力各自需要不同证据。[独立逐块计算器](src/replay.py)

编码器包括两块，宽度 32。硬 LIF 前向实际使用二元放电与清零复位，后向使用三角代理导数。所有模型共享层次词头，128 个高频词直接分配概率，其余由根类别概率乘以类内词概率，尾组屏蔽全部无效词。词表仅由训练频数定义，未使用外部预训练。流被切为相邻 128 个预测位置的块，各块重新开始上下文。每个合法预测目标只统计一次。独立重放从保存的终点参数重新计算词概率，按时间顺序逐块汇总，对正文中每个模型的整套测试 NLL 复核至 2e−7 以内。按相邻 16 块分组的条件区间只估计固定三个已训练模型的测试文本波动，三次初始化的差别应直接查阅逐种子原始值。[预先固定的试验](PROTOCOL.md)

## 复现

运行 `python src/prepare.py . --download`，可从指定 Git 提交取得公开文本并核对三个散列。运行 `python src/check.py` 做定价、因果与概率归一检查。对 hx、sdpa、smooth、lif 以及种子 137、311、557，分别执行 `python src/train.py . MODEL SEED`、`python src/replay.py . MODEL SEED`。一次独立重放会检查实际权重文件 SHA，然后计算完整测试集和前缀扰动。最后执行 `python src/aggregate.py .` 并在固定的同一 CPU 核心运行 `python src/benchmark.py .`。直接写入的完整网络实验另见 [直接写入方案](direct/PROTOCOL.md)。两遍全语料资格的结论限定在这里的预算、规模与训练起点。

## 定价通道在此语料模型中的代数边界

两点安全裕量使用相同的混合概率 $w$，定价对本金控制 $u$ 仿射。于是进入恢复/再生反馈的归一双价格组合可**精确**写作 $a+b u+c w+d uw$。在当前合约上四个系数分别是 −.9604734、.8217565、1.6737679、.3410700。真实对数阈值传输仍为 $\log(1+.2935241\tanh z)/.2935241$。因此在这个特定支持域运行 E/L 闭式或直接运行对应双线性多项式，前向与反向完全等价；两者在哪个训练数据集表现较好无法被解释成某种独有的金融表达能力。对 20,000 点的独立双精度数值与梯度复核误差均低于 $7\times10^{-16}$。[等价式检查](equivalence.json) · [全网直接写入与同位 BP](direct/README.zh.md)

独立种子 887 在 HeptaRuntime 的 ai395 CPU 上将四模型分别训练 12 遍，每模型 25,063,524 个真实训练目标。按验证 NLL 选出的测试 PPL 分别为 Hepta 327.28、SDPA 317.31、平滑 312.02、硬 LIF 316.89。延长训练后，该种子上注意力也超越了 Hepta。[实际终点、吞吐和各检查点](LONG.md)

[连续裕量的真实曲线对照](curved/README.zh.md)从三点严格证明任意双线性函数最大的归一化误差至少 .19616，并在真实语料激活上检验最优投影替换。三种子等语料测试 PPL 均值为真实曲线 398.30、从头训练的投影 400.35、同壁平滑控 399.05；等 15 秒下对应 515.39、492.61、482.50。函数的严格分离与整网同时间表现的量级不同。
