## 原金融曲线、最优投影与严格分离

实际进入动力学的是
$$F(u,t)=u+E(u,x)/E(0,.80)-L(u,x)/L(0,.02),\qquad t=2w-1.$$
$E,L$ 是相同 He–Xiong 原始权利要求的权益和货币信用损失。将实际对数裕量 $x$ 固定时，两价分别为 $E_0(x)+uE_1(x)$ 和 $L_0(x)+uL_1(x)$。本实验将四个标量函数用各自的 22 次 Chebyshev 近似表示，并在 CPU 上用双精度 Horner 同时算原价格组合和精确多项式偏导，再将神经状态舍入为 float32。四价曲线在 2,001 个独立裕量处的最大原式绝对误差为 $1.08\times10^{-12}$，另检验 17 个中间本金后最大误差为 $6.74\times10^{-13}$。对裕量坐标的四阶数值导数比较误差低于 $4.1\times10^{-8}$。实际训练内核相对双精度张量图，20,000 点前向和两偏导的绝对误差均低于 $1.20\times10^{-7}$。这些曲线近似属于数值验证。所有实际裕量在正的续存区内，本实验没有在语言序列上模拟单条资产路径的首次穿壁与复位。[误差及系数](tables.json) · [训练核和梯度](checks.json)

在独立均匀 $u,t\in[-1,1]$ 上，$F=f_0(t)+uf_1(t)$，且常数和 $t$ 正交。分别对 $f_0,f_1$ 采用系数 $\mathbb E[f_i]$ 和 $3\mathbb E[tf_i]$，即可得到 $\{1,u,t,ut\}$ 张成空间内唯一的均方最优投影。120 点高斯求积计算这四个系数并复核法方程，归一 RMSE 为 .11035。还可以给出所有双线性函数的严格一致误差下界。固定 $u=1$，任意这样的函数对 $x$ 仿射，所以它在 $.02,.41,.80$ 上的二阶差分恒为零。原价组合的二阶差分经 75 位向外舍入计算属于 [−.784639304672712,−.784639304672711]。三项误差的绝对权重之和为 4，故在整个域上任意双线性函数的最大误差至少 .1961598261。若坚持 $u<1$，由端点连续性同一下界对上确界仍成立；只用内部点 $u=0$ 也得到大于 .17351 的下界。证明直接使用原价与其积分，不依赖 Chebyshev 近似或网格扫描。[严格三点证书](separation.json) · [区间复算](separation.py)

## 最优训练分布替换

在已经训练的真实曲线模型上，每个种子/每层用 2,027,520 个训练输入标量，重新计算一次真实 $(u,t)$ 分布的最小二乘最优四系数。拟合无须测试词标签。仅将两层真实函数替换为各自训练分布的最优投影，保留其余实际权重；另外对完整测试序列逐词独立重评分。测试激活层一的归一近似 RMSE 从全域投影的 .0906–.0915 降至 .0664–.0695，层二从 .0915–.0960 降至 .0574–.0668。即便如此，替换后的测试 PPL 为 397.00 / 403.73 / 399.06，三个种子均劣于被替换的原曲线。均值 NLL 差为 .00407 nat/词。这项结果说明实际训练权重确实适应了非双线性形状；严格的表达能力分离没有转化成等时间的语言建模领先。[逐种子实测](summary.json) · [重新拟合与独立重放](diagnose.py)
