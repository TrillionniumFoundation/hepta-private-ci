# WikiText-2 全模型直接写入与同架构 BP

从同一个 **1,144,579 参数、34 个可训练张量**的 Hepta 自由边界词模型出发，三次用语料统计与逐层线性代数写入每个参数，程序运行在 `torch.no_grad()`，全部随机张量先逐个填 NaN。两个训练方式都使用 4,177,254 个训练目标呈现次数，同一 33,278 词概率空间与全量官方留出集。这个直接方法在三个种子上都成功产生有效语言模型，同时在等训练语料和等训练时间两种比较中都输给 BP。

| 种子 | 直接写入测试 PPL | 等语料 BP 测试 PPL | 同核直接时间 | 同核 BP 时间 | 等时间 BP 测试 PPL |
|---:|---:|---:|---:|---:|---:|
| 137 | 733.64 | 392.40 | 4.185 秒 | 4.191 秒 | 664.42 |
| 311 | 719.51 | 401.28 | 3.815 秒 | 3.818 秒 | 658.27 |
| 557 | 716.25 | 398.33 | 3.821 秒 | 3.821 秒 | 693.41 |

时间比较在同一 CPU 核顺次重新运行两套训练，预热框架后对双方计入从空白构造各自学习器及拟合时间，评分另计。BP 从头训练到第一次超过直接写入的实际时限，在三个种子下分别呈现 417,792、430,003、421,888 个训练目标。单独以直接法的验证 NLL 作为质量目标，对每 16 次 BP 更新进行一次全验证。三个种子上，BP 首次观测到达标用训练时间 2.80、2.79、3.74 秒，随后完整测试 PPL 704.99、705.50、709.95。上一个尚未达标的检查点分别是 2.28、2.23、3.23 秒。该间隔是观察括号，精确首次越线时刻未连续测量。[同时间实验](matched_clock.json) · [同验证目标实验](target_time.json)

## 参数如何确定

1. 第一遍完整训练邻接词对累积每个词前后类别的充分统计。16 个高频词各有一类，其余词按种子固定分入 16 类。平滑的对数条件频率写入 33,278 个词向量；词位置与后词类别的频率关系写入 128×32 位置表。条件词频写入分层词头的分类内先验。中间监督目标由训练词的上下文指纹及其类别共同构成。
2. 第二遍先按种子打乱完整训练窗口，然后把每个窗口只分配给一个阶段。两块各有四个矩阵阶段，每个阶段约占 6%；根类别与条件词序号的两个词头统计各占约 26%。每个有效目标在第二遍恰好参与一个统计阶段。报告中的十个计数相加均为 2,088,627。
3. Q、K、V 映射联合回归目标语义指纹、未来词的训练期辅助目标及其特征旋转。训练后推理只看因果输入。原股权／损失和因果滤波随已写权重确定，输出投影用带截距岭回归写入，使残差逼近真实壁映射逆函数给出的目标。FF 扩张层拟合正、负两组监督特征，压缩层拟合剩余误差。所有 LayerNorm 的缩放和平移均由对应训练阶段逐维矩写入，并转换后续矩阵，使正则化的输入坐标对齐。
4. 实际词头的根分类线性映射由收缩类均值与组内共同协方差确定。条件嵌入使用根分组的均值，条件 rank 映射按非线性隐藏特征的判别矩确定。组内经验词先验补偿共同 rank 频率。所有词的实际模型概率由原归一化词头给出。定价模型常数和明确的时间常数，在 BP 与直接写入的共同架构中都是缓冲区。
5. 实现按原架构逐项核对 34 个命名可训练张量，每项都有形状和独立字节 SHA。以 71 或 11939 初始化模型、然后擦除权重，在相同写入种子 137 下，最终所有权重合并摘要均为 `021b64c9e043820beeb2662fbd804ded60f37e63239de59091ae2ec2fa593d9c`。三个模型断开两层间唯一的边界线后，测试 PPL 分别变为 2551.57、2538.61、2636.13。[逐矩阵写入及完备性检查](write.py) · [初始化复核](direct-137-init11939.json)

直接法优化一系列局部回归与类条件判别问题，BP 优化整网词 NLL。这里没有把局部代理目标误作与全局词 NLL 等价。此实验表明解析结构允许写出整个训练器，仍缺少显示这一写入规则能在目标质量下节时的证据。另一个固定折扣 .75 的训练语料二元计数模型在约 .32 秒读取一遍语料，记录 619,592 个不同词对，官方测试 PPL 为 266.38；同一份平滑词频基线为 911.92。二元计数器没有使用神经网络、也没有进行权重编辑。它显示这个预算下，显式记住局部词对是很强的参照，直接法超越了独立词频但未达到二元表。[独立计数语言模型](count_reference.json)

运行 `python direct/write.py . 137`，对 311 与 557 重复；以 `--init 11939` 验证不同空白初始化。运行 `python direct/clock.py .`、`python direct/target_time.py .` 和 `python direct/count_reference.py .` 复算时间与词频对照。
