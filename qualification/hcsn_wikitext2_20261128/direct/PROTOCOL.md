# Frozen full-model write from a blank WikiText-2 encoder

Retain the two-block, 1,144,579-parameter He–Xiong encoder, exact normalized word head, vocabulary, context, seeds and complete official splits from the BP comparison. No trained checkpoint, pretrained embedding, teacher or numerical gradient enters the writer. No parameter fitting uses a held-out word. Two whole training-target allocations match BP's two full traversals.

The first traversal accumulates adjacent-word category counts, position/category counts and rank priors. Each of 32 buckets is a common word or one of the seeded rare-word buckets. Smoothed empirical context fingerprints write the token embedding, empirical position fingerprints write the position table, and empirical conditional histograms write rank priors. Distinct train windows in the second traversal are allocated once: 6% to each of eight token-level supervised matrix regressions, and the remaining 52% equally to root-class and conditional-rank moment fitting. Every allocated window includes all its valid targets; padding never enters a statistic. There is no held-out hyperparameter search. Each query/key/value, output, FF-expansion and FF-contraction matrix plus bias is reconstructed by a ridge linear solve using training-only target fingerprints. Every normalization affine is moment-standardized. The decoder uses shrunk common-covariance Gaussian discriminants and empirical class-prior corrections. All model tensors retaining the trainable flag in the matched BP architecture must be overwritten. Replace all initial learned tensors by NaNs before writing to detect any forbidden random-initialization path.

The optimization surrogate is successive local regression, discriminant fitting and supervised target coding. Score the same exact held word NLL as BP, including the inter-block cut. Report token exposures, physical runtime, every written matrix, checksums and resulting degradation or improvement. This constructs one explicit BP-free full-network training alternative and does not establish that local knowledge edits universally replace pretraining.
