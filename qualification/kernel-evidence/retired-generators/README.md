# Retired source-mutation workflows

These are byte-preserved historical generator workflows, moved outside
`.github/workflows` after real source edits replaced phase-one code generation.
They are not CI checks, executable module implementation, or completion evidence.
The phase-two/three Python generators remain historical plans and MUST NOT be
blindly applied to the now-diverged source. In particular, a registry signing
itself with signers it supplies is not an independent trust root.

Read-only exact-source/merge qualification workflows remain enabled. This move
neither weakens required checks nor grants production, acceptance or release.
