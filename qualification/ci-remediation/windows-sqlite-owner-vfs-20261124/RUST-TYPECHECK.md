# Windows owner VFS: bounded Rust compilation qualification

The actual vendor Rust library, its actual bundled SQLite bindings, and eight native Windows test definitions were checked for `x86_64-pc-windows-msvc` using Rust 1.96. The successful check took 0.354 seconds with exit 0 and no warnings. All seven pinned source files were unchanged during the check and still match source commit `7818bc87f8ab994171d3388988a7fe3fc25307d5` after the owner formatted and committed them.

This check uses an isolated manifest pointing to the real source files, with `windows-sys = 0.52.0` and the same required Windows feature declarations. Its small build script copies the actual bundled bindings and enables `hepta_owner_vfs`. It does **not** compile or link SQLite C, run a Windows process, or qualify the production workspace dependency graph. Native tests executed: **zero**. The independent native probe must compile the real vendor build script and C source and execute the tests before backend functionality is claimed.

The initial check found three real compiler errors: two uses of `sqlite3_close_v2`, which is absent from the crate's bundled Rust exports, and one unconstrained SID slice element type. The source owner changed the close calls to the exported `sqlite3_close`, asserted successful closure, and supplied an explicit `u8` pointer type. No generated bindings were substituted and no compiler errors were suppressed. Both failure and success logs are retained separately, with their SHA-256 identities in `rust-typecheck.json`.

The eight definitions exercise the registered VFS, actual SQLite open/close calls, actual DB/WAL/SHM/temp creation, immutable owner-policy reuse, read-only DB opening with SHM recreation, mixed private/stock SHM rejection, and unchanged rejection of wrong-owner or broad-ACL fixtures. A dedicated same-user thread-token case duplicates only the current process token, restores the thread's prior no-token state through RAII, and checks that restoration. It does not establish behavior across different accounts or elevated privilege changes. The tests' execution results remain pending.
