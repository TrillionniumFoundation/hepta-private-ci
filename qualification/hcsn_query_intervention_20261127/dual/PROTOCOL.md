# Information content of the actual stationary equity and first-hit readouts

For a single deterministic asset state and public stationary parameters, evaluate whether the exact equity and default readouts contain more than one independent state coordinate. For a population, analyze the materially different message (mean actual equity E, mean one-year default hit F), and the discounted-loss variant G. The receiver learns a new publicly disclosed, immediately imposed future constant liquidity intensity and requests its hitting probability. Before disclosure the sender had compressed its population into its two specified scalar means. This is a protocol with a revealed exogenous regime, distinct from a prior commitment to an anticipated endogenous policy.

Register before running the optimization. Use fixed Table I parameters at present intensity 1, grids of 129,257 and 513 log-spaced safe asset levels running from the present stationary boundary to 125 (endpoints included). Evaluate newly revealed post intensities 1,2,4 at horizons .125,.25,.5,1. For each, compute the SHARP largest gap in a future hit probability between two arbitrary discrete probability populations giving identical specified means. Solve the primal linear program and its independent Chebyshev uniform-approximation dual. Retain both probability witnesses and the minimax coefficients. Primary readout set is mean E and mean F; also cover E+G, E+F+G, E+F with mean log-distance, and E+F with the present quarter-year forecast. Same-regime same-horizon invariance is a null check. Test serialization of equal messages as physical FP32 scalar pairs. If values in rounding ties differ by a bit report it. Distinguish worst cases over arbitrary probability populations from histories reachable under an actual fitted neuron. Only one-dimensional deterministic-state inversion or finite-grid worst-case implications are claimed.
