# Finite-alphabet communication for a bank of possible interventions

At the risk of conflating scalar dimension with bit capacity, the earlier rank bound is deliberately restricted to affine encoders/decoders. The next test allows fully arbitrary finite-alphabet encoders and query-dependent decoders. Keep the frozen 512 reachable histories and 32 imposed future schedules (structural_results.json). For target worst absolute probability error ε, connect two histories if the maximum response discrepancy across those 32 queries exceeds 2ε. The chromatic number of that graph is the smallest admissible fixed message alphabet on this finite bank, up to explicitly stated floating-point tolerances. This follows because all histories sharing a code must be within a range of 2ε in every query coordinate. Coordinate midranges are valid decoders for a color class.

For ε in {0.0005,.001,.002,.005,.01,.02,.04}, calculate a witnessed clique (lower bound) and a concrete coloring (upper bound). Retain complete encodings and error checks. Claim exact alphabet size or exact bit width only when the bounds imply it.
