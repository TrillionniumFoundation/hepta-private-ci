# Visual population-to-population first-spike transfer across mice and contrast

Test the encoder on real simultaneous, visually evoked population recordings from Steinmetz et al. (Nature 2019; doi:10.1038/s41586-019-1787-x; original Figshare 9598406). Neuromatch Academy distributes the same experiment in three public binned archives of 39 sessions and 10 mice. Use the documented 10-ms bins starting 500 ms before stimulus onset. No wheel, decision, reward, post-anchor upstream spike, or post-anchor target observation is an input. This tasks a sender with communicating its measured population's contribution to a future event in another simultaneously recorded population; it is a cross-population prediction rather than a causal connectivity experiment.

Retain all sessions with at least twelve visual cortical units (area label starts with VIS), valid target/contrast arrays, documented 10-ms bins and unique session identity. Within each eligible session deterministically rank visual units by SHA-256 of UTF-8 'hcsn-visual-8559:' plus mouse, date, and original unit-array position separated by vertical bars. Alternate units into sender and target cohorts. The primary target at an anchor is the fraction of target neurons with at least one recorded spike within the requested horizon. Equivalently this is a binary success probability for a uniformly chosen target unit. No target-unit firing or quality cutoff is applied. Secondary anatomical split uses simultaneously recorded LP or LGd thalamus as sender and VISp as receiver if both have ≥5 units; disclose numbers of sessions/mice and any insufficient sample. Analyze it separately from the random cortical split.

Use all unique eligible mice for nested leave-one-mouse-out assessment (at least five needed for a pooled mouse-level result). Sort mice by the SHA-256 of 'hcsn-visual-mouse-8559:' plus mouse name. For each held mouse, the next in circular rank supplies validation, all others supply train. Train/validate only trials where both contrasts ≤.5 and forecast horizons 20/40 ms. Primary test on held mice uses trials with at least one side at the documented highest level 1 and forecast horizons 30/60 ms. Also report moderate contrast on the same mice without using it for tuning. Sample anchors at 0,20,...,200 ms relative to onset. Include full published archive checksums, trial and unit counts by session, case coverage and eligibility outcomes.

All models may use the known left/right stimulus values, time at the anchor, emitter firing in strictly earlier bins and the destination's pre-stimulus baseline firing estimated from the same trial between −400 and −100 ms. Compare a stimulus/baseline-only readout, a smooth current-history readout, and a boosted control, then equally dimensioned shared readouts augmented with stationary equity, default and a conditional first-hit query calculated with fixed, tangent or literal Eq12 moving boundaries. Use the same controls to interrogate trial identity: at cold scoring separately exchange a sender's recorded history with another available trial in the same session and exact left/right contrast pair, preserving receiver baseline, protocol and anchor. Use cyclic nonzero shift after deterministic trial sorting, retaining singleton strata separately. This tests conditional predictive value from the trial-specific sender history, including shared network-state effects; it does not isolate a physical synapse.

The regenerative reserve process uses the established 12 active plus one refractory atom, fixed latent dt=.25 per 10-ms bin, gain .7. Input drive combines recent observed sender activity and known contrast. For the future interval explicitly extrapolate the last available sender drive toward the contrast-only drive; no actual future sender activity can be queried. Publish the exact deterministic transform and equivalent information supplied to the controls before fitting. Use one FP32 probability for all models, regularized logistic linear readouts (.001, .01 penalties) and the locked 15-leaf/160-round boosting control. Primary score is binary expected log loss over target fractions; secondary Brier is expected per-neuron binary loss. Weight mice equally, then sessions, trials/anchors/horizons. Bootstrap paired mouse scores 10,000 draws with seed 855983; acknowledge overlap among outer-fold training sets. A universal biological-mechanism preference requires the literal augmentation to beat fixed, tangent, smooth and boosting on the primary high-contrast NLL with negative upper paired bound and lower Brier. A literal-vs-shuffled improvement without superiority to the nonlinear controls only supports conditional information transfer. Freeze model fits before out-of-fold scores. Retain shortages, nulls and adverse comparisons.
