# Locked visual sender features

A source population contributes its mean observed spike count per neuron per 10-ms bin. Within each session center and scale this quantity using only prestimulus source bins 0–39 across the session; floor its standard deviation at .01 spikes/neuron/bin and clip standardized inputs to [−6,6]. The receiver separately knows its pre-onset baseline fraction from bins 10–39 of the current trial. The known stimulus drive is R−.35L for the right and left contrasts, beginning at bin 50. A latent drive before an anchor combines the exponentially filtered standardized population and stimulus as tanh(.65 z + .7 (R−.35L)), where z=.5 times the current-bin standardized source count plus .3 times its 3-bin exponential smoother plus .2 times its 7-bin smoother. Every state output is recorded BEFORE consuming the source count at its anchor. For future bin j starting at j=0 the source forecast decays as z_last exp(−(j+1)/4) and only the commanded stimulus remains known. Interpolation in log barrier and the closed killed-diffusion relative drift use the same latent dt, reset and gain as ../crossover/features.py. Initial population is at reset. All models can use the exact same programmed stimulus and receiver baseline. Smooth controls receive source-history traces with decays of 1,3,7,15 bins and their recent changes and nonlinear transforms. Source trial shuffling preserves exact left/right contrasts within a session and substitutes only this source-dependent part; retain the actual receiving trial's baseline.

We estimate the mean stationary equity and one-year F at the existing literal-law population. Fixed/tangent/literal query-augmented readouts receive those same two features, and exactly one law-specific conditional query logit. The contrast-only arm receives the receiver baseline, programmed contrasts, horizon and relative time. The smooth arm adds only source-history features. The boosted arm uses the same exposed smooth information with the fixed registered model budget. All design scaling uses training mice only. A positive visual response effect is assessed over different held mice rather than pooled spike samples.
