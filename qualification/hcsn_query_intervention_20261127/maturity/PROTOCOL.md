# Announced rollover-liquidity interventions with endogenous equity stopping and a full debt-maturity ladder

## Registered before transition runs

Published stationary equity, bond and default-boundary solutions condition on constant coefficients. A layer interpreting an announced future intervention using a succession of instantaneous stationary boundaries makes an additional assumption. We test that assumption inside a financial/mechanistic model. There are no human, neuron or task outcomes in this experiment.

**Model.** Use the paper's Table I parameters (fixed one-year maturity, annual rollover of principal, tax-adjusted coupon, discounted secondary-market cashflows, shareholder abandonment). At a known calendar time, the liquidity shock intensity jumps permanently. Pre-jump equity chooses when to abandon; all bond prices incorporate that choice, recovery and remaining maturities. Solve in asset log-space by backwards discrete dynamic programming, with instantaneous abandonment value zero and fractional-asset debt recovery. The terminal post-jump value is the published stationary solution. The one-year issue price is computed at every earlier time. Our announced deterministic regime and calendar grid are extensions. The grid-optimal policy is not claimed to be a closed form for the continuous-time problem.

**Conditions and estimands.** Evaluate 1→1, 4→4 (stationary nulls), 1→4 and 4→1 (same present intensity contrast), and held intermediate 1→2. Use time-to-announcement distances 0, 1/32, 1/16, 1/8, 1/4, 1/2 and 1 year. Report stopping region and boundary uncertainty from grid location, one-year bond and equity at V=65, 75, 100 and 125, and state pairs where instantaneous frozen-regime decisions differ. The 1→4 minus 1→1 and 4→1 minus 4→4 difference controls lattice drift. Report value differences even if the boundary is too coarse. Compare grid sizes 64, 128, 256 and 512 time steps per year. Additional 1,024-step confirmation and changed log-grid origin allowed when needed; publish exceptions. Compare the independent closed stationary debt and equity values at the same sites, including nulls after advancing one entire year. Test default set is a lower ray. Boundaries straddled by neighboring grid nodes must not be treated as exact to several decimals.

**Independent numerical check.** For a selected grid/announcement, replay a substantial number of independent asset paths following the stored policy, with independent RNG, to value equity (accrued flows plus analytic terminal equity) and one-year debt (coupon, recovery and principal). Compare confidence intervals with dynamic programming for the same discrete law; quantify grid-to-continuum uncertainty separately. Report input-only position gradients at off-boundary points if they can be verified without changing this primary experiment. Explicitly disclose collisions between maturity and discretionary default on a time grid.

**Success and interpretation.** A quantified counterexample to the frozen-equation lookup requires an announcement contrast at a common present input which exceeds numerical error or a documented grid-matched Monte Carlo contrast: primary target is equity or issue price at 75, 1/4 year before 1→4. Generic differentiability, bio-realism and neural superiority are not endpoints. If null convergence, MC or mesh direction fails, retain the failed checks. Forecast schedules must be known to the sender or receiver, with communication and inference consequences as in earlier experiments. Report intermediate-intensity results without using them to tune the solver.
