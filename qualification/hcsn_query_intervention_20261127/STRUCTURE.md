# Query-conditioned probability and the optimal fixed linear port

For an active-state bin i and piecewise-constant imposed parameters on an interval use a killed diffusion transition Qₜ. Source mass below a new wall has already hit. For a refractory release row r and a column convention for backward values the one-first-hit survival matrix is Sₜ = [[Qₜ,0],[r,0]]. The regenerative history transition replaces Sₜ's missing active row probabilities by a transition to refractory. Every present row mass p, including any refractory mass, therefore gives a first-hit probability p·(1−S₁⋯Sₕ1). It is conditional on a particular known future protocol; no future observed spike enters the calculation. Replacing the last vector by arbitrary endpoint functions gives other conditional observables.

Let Y index n reachable test histories by m externally prescribed query schedules. If each response is the inner product of the history state with a schedule-specific first-hit vector, Y=P Q. Form Yc by subtracting column means. The smallest mean-square reconstruction error of a common k-scalar linear port with arbitrary affine query-specific decoders, even when fitted to the whole evaluation design, is sum of squared discarded singular values of Yc divided by nm. Indeed any such reconstruction has centered rank at most k. The rank-k truncated SVD attains that bound because its coordinates are Yc times the leading right singular vectors, hence are affine functions of the original history. This finite design result permits intercepts and does not bound nonlinear bit encoders. An exact query-conditioned single scalar, by contrast, can be projected at the sender after the schedule is supplied. Query traffic, recomputation and differing number of simultaneously answered futures must be counted when choosing a protocol.
