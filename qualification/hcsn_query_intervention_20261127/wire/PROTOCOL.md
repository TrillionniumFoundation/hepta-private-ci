# Measured inter-process traffic, tolerated stale replies, and actual on-demand first-hit solving

Use all 3 × 3,390 archived EPFL held-time trajectories in ../measured, their FP32 literal forecasts and recorded repeated-trial outcomes. Primary query horizons 4 and 12 ms, with the original five horizons available to a generic dense sender. Site boundaries and discrete slot clocks are pre-agreed. Measure application bytes by actual socket sends and receives across two independent OS processes on Unix stream and TCP 127.0.0.1; disclose IPC/setup costs, no energy claims or packet/link-header claims. Run three independent repetitions with a fixed physical query and demand seed, report actual wall/process CPU times, potential platform jitter and exact byte counts. Fixed-frequency means one application send per observed 2-ms slot (historical-time replay, not a 2-ms real-time scheduler). Do not equate call counts to TCP packets.

Compare dense 2-FP32 and 5-FP32 pushes with (a) tolerance-triggered updates containing a 32-bit slot and 2 FP32 replies and (b) a block-of-16 presence bitmap plus updated FP32 pairs. Keep exact previous transmitted state until either component differs by more than tolerance, and force an update at each recording boundary. Tolerances .001, .005, .01, .05 probability points. Indexed silence requires a shared clock. Bitmap batches may add up to 15 slots buffering. Evaluate reconstructed probability absolute error and measured NLL/Brier change over observed repeated trials. Count sparse payload including all indices, block masks and any required termination. Count total values originally evaluated at the source even if not transmitted.

For active requests the consumer asks a reproducible randomized subset (fractions .10,.50,1.) of slots for one of the two forecast horizons. Count explicit request and reply separately. Include 32-bit anchor and one-byte horizon; optionally append FP32 per future forcing bin when the input is not shared in advance. The source possesses the actual upstream causal population at the anchor in every condition. Compare frozen-table replies, fresh projected killed-kernel computations using the registered simplex state and stationary-boundary LUT, and fresh direct He–Xiong equation (12) plus kernel when forcing is carried in the request. Separate common causal-state preprocessing work and persistent local memory from per-request evaluation. Verify fresh answers against original frozen receipts and return precise reconstruction error. Supplied future forcing has one FP32 value per 2-ms bin. The time arrays and all probability kernels from this experiment are synthetic state estimates driven by real recorded currents; outcomes are real measured spikes.

For context also count actual event-message bytes when streaming original single-trial 0/1 crossings as 32-bit slot IDs; report per-trial rates and the different product being carried. Measure NLL only for the probability-forecast protocols. The measurement can identify operating regions where a protocol spends less wire traffic or CPU on this experiment; hardware, radio/neuromorphic energy and unmatched-task superiority remain separate.
