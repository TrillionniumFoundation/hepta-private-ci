# Public NWB pipeline units and correction before fitting

Input-only QA compared the maximum absolute high-frequency waveform summarized into 2-ms bins with Allen's published sweep amplitudes. The first export used each dataset conversion attribute across all vintages. Five of 24 cells had a 10^-12 relative current scale in that export. No learned fit, donor selection or held-out outcome score used that normalization. The official [AllenSDK get_sweep source](https://allensdk.readthedocs.io/en/v2.13.3/_modules/allensdk/core/nwb_data_set.html) documents incorrect embedded conversion metadata in early NWB pipeline versions: pipeline versions earlier than 1.1 store SI data directly, while versions 1.1 and later apply the attribute. The corrected acquisition applies that documented version rule for both current and voltage before binning. It records the raw conversion and pipeline version, checks source identities and replaces the unscored feature cache with one keyed to the corrected compact bytes. The original 24 specimen IDs, selection rank, NWB identities and splits are preserved. Noise 1 and 2 refer to two specified current commands; a distinct noise realization can have similar RMS amplitude.
