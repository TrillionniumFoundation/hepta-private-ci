The first end-to-end implementation of the registered Allen current-only panel was terminated by the local host (exit 137) while fitting larger augmented candidates. No cold scores had been computed. stream_fit.py preserves the same descriptive features, target horizons, candidate combinations, weighted summed Bernoulli loss, unpenalized intercept, L2 penalties, damping and validation decision. It computes weighted means, variances, gradients and Hessians in blocks of 8,192 rows, releases input arrays once derived features exist and checkpoints each converged candidate. Its deterministic numerical check compares the fitted logits of the two solvers before fitting. The model seal includes that error. Existing evidence from independent voltage and waveform studies has no role in this panel's candidate selection.
