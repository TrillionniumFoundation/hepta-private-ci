# Bounded, executed three-generation learning study

This qualification exercises real native fitting, publication, independent role
signatures, selection, process-input reconstruction and cognitive consumption.
It is a synthetic arithmetic instruction-retrieval task, not an LLM benchmark or
production authorization. Selection now requires the original product evaluation
runner, fenced file CAS, derived intervals and durable qualification sink. These
mechanisms do not establish general model efficacy or production governance.
Its process keys share one administrator and host.

Four actual SQLite memory records contain arithmetic instructions. The initial
model supports one query family; each of three candidate fits receives fresh
observed training tasks for one additional family and all previous families.
The generator enumerates every permitted memory action, the original signed
`LedgerWriter` records decisions and independent observer outcomes, and
`fit_tabular_operator_strict_v2` fits observed Q32 means. The required abstain
candidate remains in each decision census; it is not invented as an unobserved
learned memory action. Each fit creates a new immutable HEPTTB01 payload.

Seven subprocesses own fresh Ed25519 keys: generator, evaluator, observer,
selector, publisher, trust root and second future-material custodian. The two
holdout folds use distinct real material custodians. Each custodian durably
records the frozen candidate bytes and native instruction predictions before
creating random future operands. Each custodian seals its actual task bytes and
returns only a signed material commitment. The original frozen plan and durable
holdout journal consume the SHA-256 of the exact retained two-custodian material
manifest, including both task-byte digests and outcome-free task lineage IDs. Only then do the custodians release
the tasks for actual evaluation; the independent observer signs the ensuing real
time windows. This preserves the original holdout material semantics.
Operand populations are preregistered and disjoint: training uses odd `a`, the
first custodian uses `a % 4 == 0`, and the final custodian uses `a % 4 == 2`,
within 3–100,002; `b` is initially sampled uniformly from the same full range.
Both draws are conditioned on the predeclared rejection rules: the four action
outputs must differ, and previously drawn instances cannot repeat. The estimator
targets this conditional distribution within the final custodian stratum.
Training and future distributions intentionally
differ; this is not evidence of generalization over the entire arithmetic domain.
Each custodian rejects repeats within its own retained material history.
Training and future material are retained and
independently checked for exact semantic overlap. Hash-chained signed transcripts
retain raw tasks and actual arithmetic outputs. Separate process/key custody
here does not establish separate organizations or resistance to the host admin.

The fixed future sample is 2,048 instances per family and per custodian. Each
future task also executes an independently sampled uniform four-action logging
policy, with actual operation, output and clock values retained. The original
temporal owner fits its outcome model on earlier signed training observations,
then derives IPS confidence bounds from the second, actual final holdout window.
The first window remains distinct retention and observed longitudinal evidence.
Candidate and parent
target distributions are their actual native instruction choices. Synthetic task
lineage names the operand sampling unit, not human principals. No uncertainty
threshold is reduced to make a generation pass.

Each selected candidate passes the original four-role selection owner and the
named artifact writer's full V2 admission. The actual public ranker and Agentd
configuration consume its original immutable files. Cognitive requests use the
production read owner over canonical SQLite. The instruction lookup depends on
query family, so the native owner is called once per family; the resulting
instruction is then executed on each fresh arithmetic instance. The report does
not count those arithmetic executions as individual native cognitive requests.

The complete final selection is also serialized as raw process input and loaded
twice at new fleet launch epochs inside the native qualification process. This
exercises the ordinary-process loader and configuration, without claiming two
separately spawned Agentd daemon processes. Native owners reconstruct the proofs, replay
the exact independently retained ledger/holdout anchors, and consume the already
recorded holdout use. No opaque selection token is deserialized. A byte-identical
bootstrap placed in the body workspace and modified signature bytes under the
old descriptor digest must fail. A separately published, internally consistent
V2/V1 source with the wrong dataset must also fail model loading.

Adversarial controls use these genuine sealed qualifications: changed publication
or qualification digests, changed candidate or parent bytes, and a genuinely
re-signed invented metric must fail the canonical bridge. The compatibility
comparator may accept that signed invented metric; its token must still fail
actual published installation. Short-lived binding signatures are tested at an
advanced verification clock, separately from actual future-task observations.
Replay controls pin a valid complete descriptor, then require a new fence or
unrecorded valid plan to fail without changing any CAS bytes.

Each candidate also has a separate withdrawal control: an exact payload clone
in a distinct named registry and withdrawal scope is published, revoked and
reopened, and its cached reader refuses consumption. This is actual artifact
withdrawal evidence; it does not prove erasure of source data or parameter
unlearning. Its costs are included. The real selected candidate remains active
in the main owner throughout this separate control.

A fourth fresh fit with equal behavior measures a legal no-update result. The
current selected model remains usable after that rejection. The original named
producer remains open while the process-configured read-only CURRENT owner is
alive. It publishes an independently signed durable Revoke; the cached reader
must refuse immediately and again after producer recovery. These are separate
owner handles in the native qualification process, not a claim of full daemon
startup or multi-host fault tolerance.

## Running

Build the scoped native test library using the repository `just test` wrapper.
Then supply its actual executable path to:

```sh
python3 qualification/learning-generations/run_study.py \
  --binary /absolute/path/to/codex_hepta_agentd-test-binary \
  --output /absolute/fresh/evidence/directory
```

Final source attribution additionally requires a clean committed checkout and
the existing `scripts/hepta_ci_exec.py` exact-source owner around both the scoped
native build and this runner (`SOURCE_SHA` and `TESTED_SHA` equal that commit,
`HEPTA_CI_LANE=source-head`). Select the actual binary from the compiler/nextest
binary listing and retain its SHA-256. A runner binary hash alone does not prove
which Rust source produced it. Dirty component runs are retained diagnostics.

The ignored native test is deliberate: this study creates fresh processes,
keys, durable journals and retained evidence. An explicit run cannot silently
skip missing capabilities or substitute a mock worker. The runner rejects an
existing output, hashes the native executable before/after, retains failures,
freezes the executed custodian source beside the report, and runs
`verify_study.py` on success.

Whole-process wall time, waited descendant CPU and retained storage cover
fitting, native admission, publication, installation, inference and revocation.
The reported memory value is the maximum waited-process high-water mark;
simultaneous whole-tree RSS is unavailable because this host mounts a different
PID namespace under `/proc`. Compilation, external verification, energy and financial charges are outside
that measurement. Per-role CPU overlaps the whole-process total and must not be
added again. Native IPS intervals use the original conservative cluster bound,
maximum importance weight four and family alpha 0.05. Direct arithmetic success
counts and their descriptive intervals remain separate raw observations.

Full Agentd/App Server startup is a separate qualification: AF_UNIX socket
creation is denied on this host. This component study neither skips that fact
nor reports service readiness. It does not establish decentralized consensus,
continuous open-world learning, superiority over training from scratch, broad
model quality, independent production governance, or three-generation neural
training. Future windows occur after commitment in real local time within one
bounded run; they are not multi-day deployment or distribution-drift evidence. Those require their own material and experiments.

Historical runs before this material-binding correction consumed a protocol-label
digest rather than the actual sealed holdout-material manifest. Those runs remain
retained failure/limited-component evidence and cannot qualify this final study.
