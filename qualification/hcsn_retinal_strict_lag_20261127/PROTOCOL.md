# Retrospective endpoint sensitivity on the same retinal recording

The published target assigns a postsynaptic time to the latest retinal input at or before it if the integer lag is 0, 1 or 2 ms. In the original 10 held-out repeats 424, 832 and 38 postsynaptic events respectively had those lags. Removing zero-lag associations changes the positive base rate; freezing the old predictors and relabelling previously reversed the ordering among scalar boundary and predictive/horizon ports. The same series and these facts were already inspected. This protocol fixes the new comparisons before fitting any strict-label model. This is a post hoc endpoint sensitivity using the same recording, not independent replication. No new original-criterion training or new frozen-endpoint criterion is involved.

The alternative endpoint is an observed postsynaptic time assigned to its latest strictly preceding retinal input (searchsorted with side=left), with lag exactly 1 or 2 ms. Measure whether each eligible retinal input receives one or more such assignments. Retain original candidate times 5,000–9,997 ms, preceding warm-up, trial membership, train-only standardization, optimizers and development selection. Report per-trial and unique-event original and revised rates, original post counts by 0/1/2 ms, changed labels, and the difference from merely deleting original zero-lag matches on each split.

Compare three locked analyses of each arm. (1) Freeze the original winning readout and its input scale and evaluate its probabilities on strict test labels. (2) Recalibrate the original winning model by adding a single logistic intercept fitted to the strict training labels and original training predictions. This costs one scalar and preserves all event rankings. (3) Refit each arm's original readout on strict training labels from scratch. The family contains boundary, flow, priced, augmented, predictive, full, GLM, LIF with corrected physical 1 ms leak and adaptation, and rate. For strict refits use the original scales (0.6,1.3) crossed with penalties (0.01,0.0001), rate single candidate. Choose lowest pooled development BCE; earliest candidate wins an exact tie. Use the identical twelve-atom transition and price kernel, feature basis, labels and original per-arm representation. The corrected 1 ms LIF uses the already independently checked primitive. No other neural kernel, hidden parameter, thresholds or acquisition data are fitted. For the original and intercept-only LIF condition use the original-endpoint *corrected* LIF readout. Include previously published 2 ms legacy LIF separately in archival zero-lag summaries. Fit original readout reconstruction and all strict refits using only train/development trials; serialize source identity, original fitted probabilities provenance, all candidates, correction intercepts and selected coefficients before a separate process first calculates their strict test results.

Report pooled and equally weighted trial BCE, Brier, AP, calibration and log losses paired with whole-repeat bootstrap using seed 30588 and 6,000 draws over the ten held-out trials. Primary contrasts of interest are predictive minus augmented and predictive minus scalar boundary under all three analyses; also compare against the corrected LIF. Include all nine arms and ranks. This distinguishes correction of overall event prevalence from re-estimation of feature effects under the changed endpoint. A calibrated probability can change log loss without altering AP. Class-specific or nonlinear recalibration and new model selection are out of scope.
