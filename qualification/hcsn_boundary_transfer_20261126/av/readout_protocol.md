# Conditional physical readout and hybrid confirmation

This addendum was fixed using training progress and mechanism considerations, before any CREMA-D test predictions from the present campaign. Use the same fixed actors and checkpoints. For each of the three seeds extract the penultimate pooled vector from the selected centered-boundary, raw-boundary, and GRU candidates. All interventions freeze their encoders. Run four readout designs: raw, centered, GRU, and centered + GRU concatenation. Fit standardization on train alone, floor the per-column standard deviation at 1e-6. Use one-hot targets and an unpenalized intercept/centered response. Minimize mean squared error plus lambda times sum of squared weights, lambdas .01, .1, 1, 10, and 100. Apply softmax to the fitted linear scores for probability metrics. Choose lowest dev Brier, first lambda for exact ties.

Compare the direct positive-definite ridge solve to PyTorch L-BFGS/autograd on the same features, target, precision, lambda grid and objective, using strong-Wolfe search, max 150 iterations per lambda. Report all quality differences, separate solver/dev/model costs, prospective test predictions and reuse of parent fit and feature costs. Compare independent held-out Brier, accuracy and per-actor accuracy; count actual independent actors separately from seeds. For representation advantage require improvement in both mean Brier and mean accuracy over GRU-alone, no decline greater than 0.05 in any actor (averaged across seeds). Same-quality optimizer gate: both methods agree on all test labels and Brier gap <= 1e-4 for every seed in the design. Candidate choices must be sealed before accessing the test features in this addendum. Neither post-test tuning nor test-based retries are authorized by this protocol.
