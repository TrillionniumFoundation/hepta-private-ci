# Accelerator comparison on frozen RAVDESS retrieval scores

The local profile fixes 3 seeds (47, 83, 137), 24 paired AdamW updates, four residual networks, six source-timed 0.48-s steps, batch 8 and the published actor partitions. The separate T4 replication fixes seed 193 and four updates for centered HCSN and causal attention. It has its own process identity and contributes no local replicate. Runs are sequential on a device, with method order rotated across seeds. The held-out actors and frozen distance scores were used by prior repository research. This is a new comparison on a historical dataset, with no new actor recruitment.

Each candidate receives the same six frozen acoustic features, clock, candidate-specific acoustic distance and visual distance. The common fixed audio/video comparator is the equally weighted final-prefix score, with one positive training-only scale. Residual heads start at zero. One HCSN transmits only raw physical QVI boundaries, the other nominal-centered boundaries into the next step; both preserve the physical state, identical time clock, original generator, and original backward. Inputs arrive every step, controls on the original slow clock. This does not implement the separate cue-accumulator variant or a pretrained semantic backbone. The two reference methods are width-eight causal attention and GRU. Rank two opposite-take candidates against the same 6 prefixes, independently score each with shared weights, and report accuracy, Brier and cross-entropy at the final prefix.

Selection maximizes development accuracy and then minimizes Brier over update 0, 4, 12 and the last allowed update. Freeze every selected candidate hash before test and retention. Report gate times in independently started fit processes: first development accuracy >=62.5%, separately first >=one additional correct development query over the shared step-zero score. A claimed useful speedup requires dev improvement, >=62.5% selected test accuracy, more test queries correct than the fixed common frontend, and retained accuracy at least the shared incumbent. Denote unattained criteria explicitly. Record matched-accuracy wall ratios descriptively if both perform at least one update and match quality. Train order, development checks, checkpoint writes, cold evaluation reads and synchronized GPU costs are counted; media acquisition and shared cached preprocessing are excluded, and other applications may contend for the device.

Default settings and sources are those of hepta-private-ci commit c4ae70d44613434aaf165529a6076fa3400ca431 under qualification/hcsn_smallnet_20261124 and the imported modules. Audio/video caches are the original four NPZs under the published RAVDESS source contract 419cc6fba3ce7f1cdde6b96bbf92bc3e324c0560/qualification/hcsn_qvi_retrieval. Database: Livingstone & Russo (2018), doi:10.5281/zenodo.1188976. CC BY-NC-SA 4.0 for RAVDESS and its feature derivatives. See the pinned file digests in benchmark.py. This is an offline fixed paired-evidence benchmark, without priced acquisition or measured energy.

Run from a checkout containing the pinned source packages:
`PYTHONPATH=. python benchmark.py run --data /path/to/cache --out /new/results`.
