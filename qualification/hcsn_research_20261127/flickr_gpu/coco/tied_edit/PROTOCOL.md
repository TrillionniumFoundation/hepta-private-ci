# Closed-form tied-weight adaptation of paired image captioners

Registered before the auxiliary COCO caption experiments produced validation or test scores. The architecture, weights and hashes come from the independent Flickr8k GPU panel. The shared word table has shape 3,490 by 96. Editing it changes the incoming token features as well as the outgoing logits. The experiment reports scores after recomputing the full forward pass with the actual shared table.

## Frozen candidates and samples

Use HCSN and dense visual routers, seeds 17011, 24203, 39827, each under the original Torch CPU random initialization and the exact state sealed at twenty seconds of supervised Flickr GPU training. Exclude exact, cross-source four-byte encoding differences that produce an identical perceptual representation, and dHash Hamming distance at most 2 to any prepared Flickr image. Within COCO discard exact or dHash-at-most-2 matches to photos in earlier splits in train, validation, test order. Report retained counts. Use one support caption per retained COCO training photo indexed by its JPEG SHA256 first 8 hex digits modulo caption count. Use all five captions per retained development and test photo. Normalize and encode exactly as the Flickr training source. Keep unknown tokens and EOS in the denominator. Candidate order and support shuffling are fixed by seed.

## Treatments

* Fixed parent, with the complete unmodified tied network evaluated as a baseline.
* One rank-16 closed-form readout intervention, explicitly untying its input embedding as a diagnostic. Frozen hidden keys H produce probabilities P from the parent. With one-hot targets Y and n non-pad support tokens, C=H' H/n + 0.05 trace(H' H/n)/96 I, B=H'(Y-P)/n. The delta solves the rank-16 penalized least-squares objective for these centered probability residuals as pseudo-targets. Compute the Cholesky factor L of C, truncate L^-1 B by its leading sixteen left singular directions, then left-solve L' and transpose. Multiply the same delta by one of 1, 4, 16, 64. These solve residual-regression equations; cross-entropy is evaluated separately.
* Apply the same rank-16 delta and scales to the original tied word parameter and recompute every input representation and prediction.
* One support epoch with gradients restricted to the actual tied embedding/readout. Try AdamW learning rates 0.0001, 0.0003, 0.001, 0.003, weight decay 0.01, batch 16 photos and gradient-norm clip 1.
* One support epoch updating every trainable parameter, with the same candidate rates, batch, data, order, clipping and optimizer. This arm tests whether upstream credit assignment adds value at this budget.

All four active methods choose the lowest full-development per-token NLL (earliest/smallest scale or rate breaks ties). Every parameter candidate sees the same support photo/caption data once. The closed-form update reuses one sufficient-statistic calculation across scales and tied/untied evaluation; gradient candidates each do a separate pass. Record source extraction, factorization, candidate gradient update, complete development scoring, and final cold scoring wall and CPU separately. Report shared-cost and standalone-cost accounting. These are equal-data, four-candidate comparisons; total compute is observed, not equality constrained. COCO-based selection never modifies the ongoing Flickr experiment. No end-to-end acceleration follows from a reduction of solve-only time.

All sixty selected identities (two routers, two origins, three seeds, five treatments) must be sealed together before reading COCO test labels for scoring by this study. Use process-cold restarts, checksum verification and full causal reevaluation. Save per-photo sums for correct and cyclically shifted conditioning and scored target counts. Report mean three-seed per-token NLL, image-shift penalty, unknown fraction and all individual seeds. Use 4,000 paired image-cluster bootstrap resamples, averaging per-photo sums across the same three seeds and recomputing token denominators. Prespecified endpoints are tied closed-form minus frozen, tied-gradient and full-gradient NLL within each of four origin/router panels; no blanket new-architecture or editing-superiority claim is permitted. These uncertainty intervals condition on the fixed source and seeds. Distinguish target-domain adaptation from retention on another distribution.
