# Retrospective exact implementation cost comparison on fixed, already selected speech experiments

Stage-one official outcomes are now known. This experiment qualifies system cost on identical computation; it does not obtain new statistical evidence on task quality. Replay the original stage-one direct and BP training procedures from the identical three source checkpoints using the reduced sender trace plus reduced receiver score for both methods wherever applicable. Preserve all four regularization fractions, two Adam rates, 48 updates, four-sample gradient accumulation, the original seeded sample path, four+KEEP development choices and exact frozen head. Alternate direct-first and BP-first by seed, one cost trial active within this experiment at a time. Each method/seed gets new isolated fit and final-evaluation processes including internal and external wall, CPU process time and peak RSS. Compare selected candidates, all writable parameters, every per-example prediction, and final gate to already sealed results. Require same development winner, no final class disagreements and max abs FP32 score difference <=1e-4. The original and specialized timings may experience different shared-host load, so provide complete CPU timestamps plus process total. Keep even a failed threshold and identify host/thread scope. Use exact simulated physical calculations for BP as well as editing. Separately sum historical upstream parent cost, shared prior data preparation and any preprocessing or download not included, where recorded. Do not extrapolate this benchmark to end-to-end pretraining, GPUs or new tasks.
