# 在三个训练完成的 HCSN 中精确保留全部旧物理状态的限制

每个父网的旧数据采用同样的 440 条阿拉伯语数字校准录音。发送者在慢时钟接收输入控制和前一时刻送达的边界，接收者读取 32 个单元的前一边界。提取了实际处理器收到的 FP32 值，包含真实的名义边界平移、第一步零消息与控制缓存。

| 每个单元的真实旧键 | 列数 | 三个模型经精确证明的秩 | 三个模型在相对阈值 1% 下的数值秩 |
|---|---:|---:|---:|
| 首个慢步的输入控制和截距 | 14 | 14、14、14 | 14、14、14 |
| 所有慢步的输入控制和截距 | 14 | 14、14、14 | 14、14、14 |
| 发送者的输入、截距和前一发送者边界 | 30 | 30、30、30 | 17、17、17 |
| 接收者的前一全网边界 | 32 | 32、32、32 | 16、16、16 |

如果同一批旧样本的每一时步都必须精确保留原边界和漂移，送达下一步的旧边界也固定。在理想实数模型中，严格单调的 tanh 使相同漂移对应相同总驱动。对每个单元，保持条件由此写成 KΔw=0。满列秩意味着该单元在这些活跃输入和递归坐标上的 Δw 只能为零。要求各处成本也完全相同，则在驱动已固定、成本幅度大于零时，成本偏置也被确定。这一结论以真实校准样本为条件，适用于精确保持整条内部动态的要求。

若目标是保留旧任务的外部回答，就可以容许若干物理量变化。接收者矩阵的条件数为约 3.28 万至 20.79 万，低奇异值方向可产生很小的旧驱动变化。真实函数的浮点舍入与分数测量容差同样需要区分。实际编辑能否兼顾新任务与旧任务，取决于所选方向与新任务需要改变的方向是否一致。

非零子式证书直接利用了浮点输入具有精确二进有理表示。计量程序在素数 2^61−1 上保留线性独立行。独立验证器用带换行的消元重新计算所选方形子阵的行列式。其模素数值不为零，证明原有理子式也不为零。包中保存完整 FP32 矩阵、行号、原录音 ID、时钟、每个子式哈希、行列式及完整奇异值谱。minimum_rms 量对应固定旧键下每单位参数改变的最小驱动行均方根，经过阈值非线性后还要计入其局部斜率。
