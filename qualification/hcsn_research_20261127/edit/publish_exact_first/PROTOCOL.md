# Exact structural specialization for physical hidden editing and gradient training

The shipped 32-neuron model masks all unsigned and signed flow feedback, keeps full-width boundary feedback, and reads features only from its 16 receivers. Compare the repository forward with two exact reductions. In the first, reconstruction of editable sender drifts/keys/preactivations needs only the causal control buffer, inter-neuron boundary messages, local drifts/costs and original QVI root. In the second, logits, value/risk features and writable VJPs need the full 32-neuron boundary/drift/cost law but only receiver finite-volume state, remap, transition, reset and marks. Both are restricted to original frozen mask, readout, mixed precision and protocol. Reject a model with active flux channels or unsupported output bank; do not return a full physical continuation state. Neither method first trains an auxiliary network.

Use three historical parent weights of the first protocol. Use train or development data only for equivalence and benchmark; use all three sources for the eventual independent prediction replay. For fixed batches of 1, 7, 24 samples and sequence lengths 1, 2, 3 and 6 compare every unflattened receiver feature, frozen readout outputs at full length and all three per-step trace components against the original. Use mixed real panels from calibration, a zero/nominal control and sign-alternating ±5 inputs. Test writable VJPs with an external one-hot output loss and synthetic cotangent over receiver features at sequence lengths 3 and 6, tolerance max abs <=1e-5+2e-5*max(abs(reference)) and zero full length argmax disagreements. Compare full and reduced physical solve on all 300 English and 440 Arabic training rows; all four candidate scales must agree within 2e-5 in Frobenius norm. If original filtered winner is KEEP the identity is valid.

Run alternating paired no-grad timing (5 repetitions; before timing warm each implementation once; first test records 48 rows from fixed calibration). Compare the same calls for extracting 48 sender traces and scoring 48 audio feature vectors; record order, all raw times, median original/reduced ratios, versions, threads, CPU, resident size if available. Also measure a matched writable BP gradient step on the same four rows. Independent cold deployment packages use original and reduced implementations and the stage-one development-selected direct models to replay every recording in first-stage official Arabic and FSDD and second-stage selected Speech Commands test, after respective seals. Preserve raw classifier outputs and emitted check, old class fidelity, deployment gate max score abs <=1e-4, with no disagreements. All-prediction replay is retrospective equivalence only and cannot change any previously selected model. Any differences or failures remain visible and no speed result may be extrapolated to nonboundary masks, other devices, other tasks or original training from scratch. A faster exact BP baseline must be accounted for before any direct-edit speed claim based on specialized kernels.
