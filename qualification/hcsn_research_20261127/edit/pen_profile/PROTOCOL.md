# Adaptive, pre-test extension of the pen from-random-initialization study

The primary pen development rows have been viewed: the original direct solver chose KEEP for all three parents; a full correction had receiver-independent coefficient norm around 190 before the predeclared global cap of 2. No primary pen official test result has been evaluated. Preserve the original selecting gate and code. This extension uses identical 1,200 training trajectories, 400 dev trajectories and the official 3,498-recording test. It is independent of the first pen experiment as a hypothesis-generation process only; the same 14 test writers are reused and every comparison is labelled an adaptive extension.

**Fixed physical-coordinate ridge.** Residuals and writer cross-fitted prefix targets as in original pen study. Use the original physical 21-column sender design directly (including intercept and sender-to-sender delivered boundary) with a uniform .02 ridge in actual parameter units, avoiding the original per-coordinate RMS reweighting. Use the same two rounds, candidate fractions .25/1 and Frobenius radius 2. Four choices plus KEEP, same readout fits/regularization. This tests a diagnosed norm imbalance. Include identical shuffled-target control with the same physical ridge.

**Finite-difference variable projection.** Directly infer task-aware changes of the same 336 physical hidden coordinates, with fully eliminated training-time linear classifier. Partition the twenty training writers into the first ten and last ten in the frozen hash order. For each digit and side select 10 deterministic rows by SHA-256 sorted original IDs; the first side (100 examples) is support, the second (100) is query. For each of the 16 orthonormal directions perturb the current sender weight by plus/minus .03. On every perturbation recompute the *actual* nonlinear physical receiver features for all 200 rows and exactly refit a standardized .01-ridge on support; query raw class scores form a forward central secant matrix. Build six directions from the writable input/bias part and six from the live recurrent part of the initial supervised local corrections separated by digit and SVD, append four seeded isotropic QR directions (complete any deficient rank with Gaussian columns). This shared basis is kept fixed for both rounds. Fit a .003-regularized least squares update toward new query one-hots, with norm cap 2.0. Provide half/full from each of two rounds plus KEEP; refit final readout using all 1,200 training rows for every candidate and select via frozen dev rule. No implicit gradient, BP, autodiff, or pretrained model is used. A dimension-matched random orthobasis control uses the same true support/query labels, 32 probes per round and solve. A shuffled-label control permutes true training labels within writer for all internal basis/queries/supports only, leaving the definitive head and validation labels true. Save actual probe counts, sample counts, residuals, changes, times, states and scores. Fair BP comparator is identical original pen trial whose physical hidden layer is differentiated through the equivalence-qualified faster receiver kernel.

Seal all five arms/three seeds before cold test. The novel stroke task remains gradient-free at every training stage of these arms. Prespecified criteria mirror the first pen study: same-writer-paired 95% lower endpoint above zero and >=1pp over both original frozen features and corresponding shuffled control in all three seeds. Test profiling method vs its random-direction control as a mechanism comparison; report both positive and negative. BP replacement additionally needs test within two points and lower complete wall (all probes and readout search + fresh original-simulator test), for each seed. Existing raw, kernel and GRU comparisons remain necessary context. Across extension methods there is no new confirmatory familywise claim; all variants and failed gates are visible.
