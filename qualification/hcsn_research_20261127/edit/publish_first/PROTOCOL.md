# Cross-language physical sender editing in a frozen Arabic-digit HCSN

## Fixed question and sources

For an Arabic-digit parent with frozen nonlinear recurrent population dynamics and its original ten-class decoder, can external English digit labels specify physical hidden sender targets that improve English recognition while retaining Arabic recognition? We compare hidden writes at the same 16×13 drive weights and 16 biases (224 real parameters). The parent and frozen encoder code are those of hepta-private-ci #7149 at 8b538954e3db0763b9eb24b6159d17b80f286f26, qualification/hcsn_boundary_transfer_20261126/nobp, using its three hcsn_bp parents 107,211,431. Readout, target labels, gates and corpus choices below are fixed before opening the study's new confirmation predictions.

FSDD 26eb9aaf76e81b692f806f9140c2d2777410d7a1, an English digit corpus with six real speakers, supplies the new task. Speaker-disjoint training uses george, jackson, lucas, development yweweler, final confirmation nicolas and theo. This is a new editing protocol on a public corpus; some people appeared in earlier unrelated experiments. Train and dev take indices 0,5,...,45 per digit per speaker. Confirm all 50 examples of each of ten digits and each confirmation speaker. Exact PCM-content duplicates, if any, are reported; a cross-split PCM collision is excluded from the later split before fitting. FSDD MFCC uses 25ms Hamming windows, 10ms hop, 512 FFT, 26 triangular mel filters 0..4000 Hz, preemphasis .97 and 13 orthonormal DCT-II coefficients including zeroth, with six interpolated positions. Standardize using only the English training rows, clip at 5. This target-domain calibration is shared by all arms incl KEEP. Old examples use original Arabic features and the parent's Arabic scaler. This is supervised domain adaptation with a known domain, not blind domain inference. Each method gets identical English fit information.

Official UCI Spoken Arabic Digit archive supplies old-task data. We use the original every-tenth training row per class as in #7149, dividing those 66 rows per class cyclically (index within digit modulo 3 = 0 or 1 for old calibration; =2 for old development). Original full official TEST is an independent old-skill confirmation and was used in historical reports. Arabic individual IDs are unavailable, so do not create speaker intervals from rows. Known labels and 22 source speakers on the official test do not constitute 2200 independent domains.

## Frozen methods and evaluation

For each parent, derive a per-class per-control-time prototype from old calibration examples. Measure sender drift on the physical slow updates. For each class and time average the true sender drifts, then invert mu=mu0+s*tanh(drive) with atanh. Ridge-fit a conditioned change in the 13-to-16 physical drive and its intercept on labeled English examples to those target preactivations, with a retention penalty on the old calibration input projections. Controls use target digit (label+1) mod 10 or the label-blind mean. Use regularization .02, old projection weight .25, and the four common candidate fractions .125, .25, .5, 1. The unmodified parent KEEP is shared. The output decoder and feature scaler remain bit-identical.

Same-site ordinary BP: Adam, fixed learning rate .002 and .01, 48 minibatch steps per rate (16 new and 16 old examples each, independent seeded local shuffles); take snapshots at 12 and 48, giving four candidates. Minimize new ten-class squared error as used in the frozen parent ridge fit against one-hot targets, plus .25 old physical-score MSE to the parent. Use clip norm 2. No new task readout, no target-corpus-trained parent, and no external teacher. One search pass costs count in full including every candidate. Record complete execution and candidates rather than inferring speed from linear algebra alone.

All arms apply the same development rule: reject candidates if old development accuracy loss vs KEEP exceeds .03; among remaining candidates plus KEEP maximize new dev accuracy, then minimize new dev Brier, then minimize parameter displacement. Record both the selected candidate including KEEP and all candidate scores so an unchanged decision is distinguishable from a useful write. Save raw weights / states before final evaluation in a consolidated seal, independently reload candidates in fresh Python processes. Produce per-example scored predictions, old and new accuracy and Brier, and unpooled paired gain per English speaker. Also report fraction of old correct responses becoming incorrect and vice versa. Primary tested claim: aggregate new gain >= .02, both held-out speakers nonnegative, old loss <= .03, for each of the three parents. Relative to strong BP compare novel accuracy within .02, old accuracy within .03, and observed local edit + cold evaluation wall. Two final English speakers give descriptive confirmation, not population significance. Archive k=one updates, parent hashes, writable layer deltas, posterior physical responses and held-out scores. Distinguish fitting, candidate testing, cold reload/inference, shared input preparation and historical parent preparation.
