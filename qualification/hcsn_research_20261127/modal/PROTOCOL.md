# MHEALTH prospective split-person bimodal encoding experiment

This experiment uses UCI MHEALTH (doi:10.24432/C5TW22), the 10-subject 50 Hz motion dataset by Banos et al. A local case-insensitive literal search for MHEALTH, MobiAct, PAMAP2 and UTD-MHAD over 2,646 path-selected documents and source files on the 8b538954 research snapshot returned no matches. This establishes coverage of this search, not independence from every historical use of a public dataset. The archive is https://archive.ics.uci.edu/static/public/319/mhealth+dataset.zip; its SHA-256 is 16ad0ce709f3f00df18f348610d15bce0884b79e2143f57f446493673f02b8e0. The ten subject logs are physically separate. This is synchronized body-motion accelerometry and gyroscopy, not audiovisual or cross-room data.

The target is 12-way classification. Inside each subject, use non-overlapping 128-reading windows aligned to absolute recording start, retain windows whose 128 labels are identical and between 1 and 12, ignore null/mixed activity. Use all such windows. An eight-frame sequence uses mean and population standard deviation over consecutive 16-sample bins separately for chest 3-axis acceleration and left ankle/right arm gyros (6 axes), giving 18 features, all causal within each completed bin. Window segmentation uses ground truth and tests classification of a presegmented activity window; the device will need an onset method for continuous labeling. Training mean/std normalize each feature, floor std at 1e-4, clip [-6,6]. No participant or source-clock is fed. Never shuffle samples across people before partition.

Fold A trains persons 1,3,5, develops on 7,9 and confirms on 2,4,6,8,10. Fold B trains 2,4,6, develops on 8,10 and confirms on 1,3,5,7,9. Each person is held out once. Both schedules and model choices are fixed before either test set is scored. Use seeds 1729 and 2718. Independent biological units are ten participants; training-seed repeats are descriptive. Do not tune using results from this experiment.

Use original 8-cell centered endogenously solved QVI + signed marked message network with a same-shape 12-way output head, original six active bins and three refractory phases, mixed precision, dt=.32, same old-message convention. Add physical boundary-only ablation. GRU, causal single-head attention, binary forward surrogate LIF and smooth gated recurrent network use the same 18 raw features, time steps and final representation width 20. Include a standardized flatten/ridge classifier on exactly the same eight frames. The smooth gated network is a nonphysical control, without claiming exact parameter or FLOP equality. Count parameters and CPU seconds. Freeze all choices before inspecting test.

For each seed, fold and neural arm, train on only classes 1–6 in stage 1 for 32 AdamW updates with 24 examples per update and lr=.01, then train the same parent on all 12 classes for 96 updates with the same learning rate, sampling uniformly per class with replacement and common minibatches across arms. Clip gradient norm at 2. Check development cross-entropy at 16-update intervals in stage 2, including 0, and choose the lowest with ties going to earlier checkpoints. Measure fixed old-class slice before and after stage 2 (accuracy resolving all 12 output classes). Include ridge rows with same examples available to all arms and a development-selected lambda in [.01,.1,1,10]. Ridge is a direct feature floor and not matched to the neural number of sampled updates. Full cold worker timing includes startup+training+development+checkpoint, validation is a separate cold process with parent and candidate loading, and raw-source feature preparation is billed once and reported separately. Record update wall and time of first development top-1>=.75 among observed checkpoints. Select all checkpoints across both folds, then seal states and source before test predictions. Fit order randomized by fixed hash, run local workers on 1 CPU thread each, record contention and shared I/O limitations; timing ratios are on this host.

Primary endpoint is equal-participant mean of within-person macro recall over classes present. Secondary endpoints are multiclass Brier, micro accuracy, old-class retention, and cross-modal dependence under single-modality deletion (set standardized features of that modality to zero). A priori comparative thresholds: physical candidate within 2 percentage points of every conventional competing arm for macro recall, within .02 of best calibration Brier, no more than 2 pp old-class retention loss relative to its own stage-1 parent, and at least 10% lower fully charged cold time versus the strongest qualifying conventional method. Pair per person means over the two seeds. Report paired bootstrap 95% intervals resampling participants (10,000 replicates, RNG 19752). A joint advantage requires lower paired accuracy bound >=−.02 and cold-time reduction >=10%. Superiority requires strictly positive lower paired accuracy bound. A zero or one-modality-only failure supplies evidence about information usage, not cost or architecture superiority. Publish failed arms and any infrastructure amendments.
