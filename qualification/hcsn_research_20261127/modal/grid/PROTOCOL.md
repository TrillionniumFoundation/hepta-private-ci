# GRID paired acoustic/visual command recognition

The official GRID audiovisual sentence corpus by Cooke, Barker, Cunningham and Shao (2006), archival DOI 10.5281/zenodo.3625687, CC BY 4.0, supplies synchronized camera MPEG1 and embedded speech. The fixed #7149 path-selected text/code search found no occurrence of GRID corpus, GRID audiovisual, TCD-TIMIT, AVLetters, visual speech dataset or CUAVE. The initial s1/bbaf2n.mpg file was fetched only to establish stream layout by ffprobe. It is excluded from the cohort for every speaker. This experiment assesses command recognition across actors in one recording corpus. It cannot establish new-site transfer, scale, or population coverage beyond the twelve subjects.

Use speakers 1–12 inclusive and all four GRID command words (bin, lay, place, set). For each person and command choose the 12 lowest SHA-256 hashes of the literal ASCII string "hcsn-grid-v1/<speaker-number>/<six-character-clip-id>" among matching official .align files with six spoken words, matching command label, canonical six-character identifier, a nonempty word interval inside the clip, and a matching archived video entry. Require exactly 576 complete clips, preserving all selected IDs. A failed download stops that source for retry, without replacing a difficult observation. CRC-32 and size are checked against the official ZIP central directory, the manifest records the source-member SHA-256. The record catalogue gives archive md5; ranged MPG acquisition verifies member integrity without claiming validation of every byte of the full 12 archives. The complete alignment archive is MD5 checked. Freeze roster and published data-source metadata before feature inference/training.

Decode the sound and image from the same recording using FFmpeg single-threaded CPU. Use the supplied word boundaries (in 1/25000 second units) to select the command; this is isolated word classification with externally given segmentation. A fixed lower central crop (x fraction .25-.75, y .45-.90) is a cheap facial-motion front end without tracking or external pretraining. The audio front end is a 24-band log-spectral representation and the video front end is a 4-by-4 grid of average normalized luminance plus its first temporal difference. Eight uniform time positions within each spoken word give common-length inputs. Images and audio are never shifted by class or subject. The evaluator receives only feature arrays; IDs, durations, source files and timestamps are excluded. Train-only feature normalization applies across clips and frames. Archive only derived features, not face clips. No medical or biometric inference is attempted.

Two predeclared participant folds: odd 1,3,5,7 train, odd 9,11 development, all six even participants confirm; reverse parity with 2,4,6,8 train, 10,12 development, all six odd participants confirm. Every speaker enters confirmation exactly once. No architecture is modified in response to either fold's test and all candidates are sealed before test. Compare concatenated flattened ridge, same frozen physical QVI/marked HCSN (receiver output analytically fit), trainable standard GRU, single-head attention, LIF, ordinary gated recurrence and trainable HCSN. Keep features identical. Report per-speaker accuracy, macro recall, Brier, held-out effect of deleting each modality, and strong unimodal re-fits (ridge audio only, video only). Plain fixed features comprise no large pretrained encoder. Use seeds 1729 and 2718; two arms sharing fitted features or training examples are paired, not independent replications.

Fit neural methods using common class-balanced minibatches. First only bin/lay for 32 steps then all four words for 96 steps, 24 examples per update; AdamW lr .01 and gradient norm cap 2. Use fixed size-four microbatches. Development CE at 16-update intervals chooses checkpoint including the unchanged stage-one model. Record old-class held-out change between stage one and candidate. Ridge penalty selected from .01,.1,1,10 on development CE; one check for each lambda per fit. For a frozen physical backbone, fit the same ridge to its actual final receiver features, normalized on training only. For compatibility with fixed physical reference, dt=.125 represents normalized word duration; hence a result concerns 8-bin time-normalized words, not native wall-clock alignment. Conventional heads share 20-dimensional latent geometry, physical HCSN uses eight independent populations (20 receiver features). Count trainable parameters and log complete stage wall, then cold evaluation with common deletion interventions; raw acquisition and feature preparation reported separately.

Primary endpoint: mean source-level four-way macro recall. Equal class counts per speaker. Noninferior physical readout requires lower bound of paired speaker bootstrap 95% difference to the most accurate ordinary comparator >=−.02 and physical Brier within .02. For end-to-end training time advantage require >=10% lower cold fit + evaluation at this quality. Robustness of genuine fusion requires loss of >=.02 macro recall under deletion of either modality and performance exceeding per-speaker best unimodal frozen-feature ridge in paired comparison; deletion is sensitivity, not a proof it beats modality-aware retraining. All source-group intervals use 10,000 person-resampling draws with seed 19752. Log device, CPU threads and any failed/missing fits. Do not pool this result with sensor figures, speaker counts or performance from historical RAVDESS/CREMA-D.
