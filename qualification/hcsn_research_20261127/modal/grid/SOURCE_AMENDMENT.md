# Alignment directory reconciliation before cohort selection

The first two attempts at registering the official archive aborted before any GRID features were extracted, models fitted or test predictions opened. Seven video directory numbers matched their alignment directory numbers. For video directories 5, 6, 10, 11 and 12, zero of the 1,000 clip IDs occurs in the same-numbered alignment directory. Comparing filenames only (no pixels, audio, predictions or class performance), each video directory has exactly one official alignment directory with an identical set of all 1,000 six-character clip identifiers. Use this unique complete-set match and require that the chosen alignment directories are all different across the twelve actual video archives. Preserve the original video archive index as the speaker grouping and the hash selection index; no speaker or observation is exchanged. Record both directory numbers and the clip-set SHA-256. This resolves only the metadata directory names; IDs do not independently validate human annotation timing. The two failed registration attempts are included in the acquisition log. Training and outcome criteria are unchanged.

Video directories 1–12 map respectively to alignment directories 1, 2, 3, 4, 6, 5, 7, 8, 9, 13, 10, 11. A re-run recomputes the matching and asserts uniqueness before sealing the corpus.
