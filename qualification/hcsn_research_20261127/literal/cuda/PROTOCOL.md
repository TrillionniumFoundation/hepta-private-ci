# CUDA literal He–Xiong forward and derivative operator
Implement the published equity, finite-horizon hitting probability, endogenous log boundary and killed-kernel/reset expected next margin on a single CUDA thread per independent (margin,principal) pair. Forward-mode dual arithmetic returns both partial derivatives for each output in the same kernel; arbitrary incoming cotangents then form its local VJP. Transaction cost, reset law and published calibration match the literal CPU benchmark. Validate every small-grid output and partial derivative independently against FP64 PyTorch autodiff and SciPy quadrature checks on the CPU, retaining points on each open side of the default wall and handling the exact wall separately. Primary precision FP64, secondary native FP32. Use a conditionally ordinary tanh-gate control with the same number of outputs and derivatives to measure the computational cost of exact finance primitives.

Benchmark 256, 4096, 65536 and 262144 active cells on the physical GPU, 5 warmup and 21 measured launches per arm/size/precision, synchronized CUDA events with individual timings. Separately record device properties, first transfer/launch and end-to-end host allocation, H2D/input and D2H/output costs. No concurrent unrelated load is forcibly removed. Report the observed number of other compute processes when obtainable and whether power counters are available. This is an operator microbenchmark; its runtime cannot measure whole-network training, an event-driven SNN chip, full-model BP or all-modal inference. Keep each comparison on the same machine and disclose missing GPU energy measurements. Repeat with pageable host memory and the same explicit output layout for both arms.
