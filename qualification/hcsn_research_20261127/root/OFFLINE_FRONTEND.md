Feature extraction uses local model files, decoded images and captions. A local execution review detected an unexpected telemetry connection attempted by ONNX Runtime and stopped extraction. The extractor now enforces an OS-level deny on creating or using sockets before importing ONNX Runtime, checks a socket creation attempt fails, and explicitly calls ONNX Runtime's telemetry disable function. Official data acquisition is a separate process. The pinned model, extraction batch order and gallery assignments stay the same. Outputs from the earlier interrupted run are quarantined outside the canonical feature folder. The complete scored feature set must carry an extraction receipt from the local-only executable.
