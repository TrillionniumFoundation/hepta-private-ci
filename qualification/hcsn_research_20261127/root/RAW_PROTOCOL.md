# Independent from-random-initialization image–language encoders

This experiment charges the full encoder and has no CLIP, teacher, pretrained vocabulary or external visual weights. Use the same 1,024 train, 192 development, 384 test photographs and all human captions as the frozen-frontend study so costs and representation limitations can be compared. The cohorts within the large and small extension overlap and are compared on the same gallery; external validation needs a separately sourced dataset. Test selection is blind to every score. For optional scaling, extend training alone to the first 4,096 original train photographs using the same previously frozen ordering, preserve development and test. Memory, downloads, selected ids, run times, and completion are checked separately at each scale.

All learned encoders receive identical raw data access. The raw vision frontend resizes to 32x32 RGB, cuts into 4x4 nonoverlapping 8x8 patches ordered raster, and applies a learned affine map from 192 scaled pixels to width 32. The language frontend builds a word vocabulary on the training captions ordered by decreasing frequency then lexicographic string, retains 4,094 words, reserves PAD and UNK, uses random trainable width-32 word embeddings, first 16 word tokens with zero right pad. All arms use the same per-modality learned 16-to-4 temporal compression by mean of four consecutive vectors, then two zero read ticks and a trainable 64-D normalized embedding. A single-frontend ridge/CCA-style comparator instead uses a fixed 192-D visual descriptor from 8x8 average RGB and 512-D signed stable-hash bag-of-words. It fits a train-only shrinkage whitened cross-covariance by SVD and selects the shrinkage on development. No learned global residual is available in the from-scratch condition.

The N8 centered joint QVI/marked physical receiver, smooth gated recurrence, GRU, one-head causal Transformer, binary forward/surrogate backward LIF, time-flattened learned linear bottleneck produce width 20 per modality. To address the near-constant raw physical receiver scale common to newly initialized dynamical systems, normalize each of the 20 outputs using training-mode batch normalization (affine=False) before the 64-dimensional projection; all learned arms use the identical operation, development & test use training running statistics. Two additional direct-edit experiments freeze the random physical encoder and both frontends, whiten the frozen final unnormalized features using train-only statistics and estimate the two cross-modal last projections analytically by regularized CCA. The second uses the same analytic readout on frozen random GRU encoders. Include both the feature extraction, fit and development cost. These establish the specific feasibility of no-BP readout learning from randomly initialized features. They do not edit all layers. Test independent handwritten/voice probes cover local hidden updates separately.

AdamW .003, weight decay .01, global clip 1, bidirectional InfoNCE temperature .07, batch 16 distinct photos/minibatch with one random paired caption. Stage 1 trains 192 updates across each of three seeds 27/117/207. Select highest full development bidirectional mean R1 at steps 0,48,96,144,192, tie earliest. A prospectively defined longer-horizon experiment extends each identical seed to 1,536 updates with development selection every 192 steps, including zero; report this independently from the 192-step study. At expanded train scale run 1,536 updates and at least two complete independent seeds. Fix initialization by seed and minibatches by an independent RNG across all network arms. Analytic methods select shrinkage in {.001,.01,.1,1} by same metric, common 16 dimensions (or numerical rank if smaller), canonical directions trained from each photo's mean caption feature and normalized individual projections at scoring. Publish every trained checkpoint hash, full test ranks, development selection, trainable parameter count and separate wall costs. Select strongest conventional model by development only. Compare conditional fixed-gallery paired bootstrap at photo level with the frozen-frontend protocol's margins and endpoints. Never count number of seeds or captions as independent photos.
