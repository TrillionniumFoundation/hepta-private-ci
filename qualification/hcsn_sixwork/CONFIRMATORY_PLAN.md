## Predeclared comparisons

**H1:** same-generator minus ordinary-tanh MSE, separately for each task/clock.
The zeroed value/risk arm is diagnostic. An observed benefit must retain all
three paired seed differences; an all-three-negative pattern is descriptive,
not a significance or generalization guarantee. The complete common flow/bank
is charged in each standalone cost lower bound, while actual shared campaign
work is recorded once. This is an incremental feature-information experiment.

**H2:** Howard QVI minus full-state lookup-gate expected return for each paired
seed. Both receive the same known dynamics and independent training reward
measurements. Report full returns and gains over never-reset, all resets and
NoUpdate choices, Bellman residuals and solve/backward counts. The stochastic
gate's uniformization clock differs from a hard instantaneous intervention;
only its hard endpoints share the exact impulse equations. This cannot establish
a task-boundary advantage in a model that must learn its dynamics or hidden state.

**H3:** direct, semantic-program and program-then-BP versus local BP in A;
conditional-direct, semantic-program and program-then-BP versus joint BP in B.
Preserve the distinction between a common *eligible* mask and parameters
actually changed: conditional ridge does not solve the nonlinear outer weights.
For a descriptive quality-tolerance screen, set per seed

`tau = max(1e-6, 0.01 * incumbent_dev_MSE)`.

The incumbent is A's zero readout and B's shared initial ridge checkpoint.
This tolerance is fixed before final. A method meets the screen on a task/clock
only when its selected final MSE is no more than BP+tau on every paired seed.
Report actual differences even when the screen passes. Compare measured compute
costs separately; per-arm lower bounds and unknown design costs do not establish
reduced complete adaptation time. No post-final candidate, step budget,
hyperparameter, tolerance or namespace substitution is permitted.

**Architecture pilot:** report all six named models' MSE, actual parameter
counts, failures, NoUpdate and total measured cost. The predeclared 280±15%
parameter band matches a capacity range, not operations or recurrent state
size. One small capacity and three seeds cannot justify a large-model scaling,
