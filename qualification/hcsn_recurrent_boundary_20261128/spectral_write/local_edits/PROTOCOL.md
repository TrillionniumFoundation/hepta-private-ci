# Can analytic local probability edits close the 400-PPL gap?

The fixed spectral construction crosses 500 PPL and misses 400. This extension was designed after seeing that result. Keep the same published WikiText-2 splits, hardware protocol and three projection seeds. Initialize with the predeclared alpha=16, right prior power=.25 spectral rule. Fit improvements solely to training counts, measuring actual wall time. Do not run PyTorch autograd or backprop through the neural model. All test evaluations must wait for the three-seed development seal.

Use the actual hierarchical language probabilities. For every preceding word, fit its root-class categorical distribution plus conditional-rank distributions for observed preceding-word/rare-group pairs. Use normalized gradient residuals and positive definite, locally preconditioned probability updates on the low-rank word coordinates and class coefficients. Each correction uses only the affected feature and categorical head. Derive the physical neural parameters by inverse realization after each specified endpoint. Explicitly count data-dependent tensors, local probability-optimization steps and complete model BP calls. This is an iterative estimator in a restricted subfamily; evaluating training count gradients analytically is allowed by this protocol.

Keep the same width and trainable tensor slots. Use training-data-only shrinkage strengths 4 and 16 for root probabilities and one unit of shrinkage for each observed rare-class conditional context. Observe 1, 4, 8, and 16 paired coordinate/class corrections per candidate. Bound updates and require decrease of the smoothed count objective. Freeze the lowest development NLL across these alternatives with achieved cost. Score the default first four corrections separately. Report full search time, fixed recipe time, fitted results versus the previous 500/400 gates, and contextual-feedback-off effects. Compare normal deployment and all costs to the measured same-core BP trajectory, with a fresh run when a candidate's duration is outside its measured checkpoints. Count baseline and unchanged spectral scores remain visible. Positive or negative results require raw recoverable deployable weights and independent inference.
