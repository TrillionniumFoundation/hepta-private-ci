# A stronger iterative head on matching geometry

The returning-bank five-write scheme reached the exploratory 3.75 threshold on three seeds, while ordinary L-BFGS took up to 350 steps on poorly conditioned original features. As a post hoc fairness test, both use the same training-key Gram and class-prior curvature. This protocol was written before running the preconditioned candidates. For each of the three trained feature banks (seeds) of the returning arm, whiten the parameter coordinates by the inverse square root of the exact penalized cross-entropy Hessian at the prior. Run L-BFGS from the prior against the original regularized cross-entropy, with lambda values .001, .01 and .1; cap at 150 iterations. Center and scale training features identically, use the same fixed actor splits and 72 labels. The bias gets its own unpenalized class-covariance inverse square root on centered logits. Every eigendecomposition, training-data pass, candidate evaluation and scored checkpoint is charged. Store endpoints at 1, 5, 10, 20, 40, 80 and 150 iterations and at convergence. Choose a reference best on development and, for every observed checkpoint time in the search, the lowest development NLL observed by that time. Separately report the first development passing candidate and its subsequently held result; do not retrospectively replace that candidate if it misses on held. Lambda search order is .01, .001, .1. Seal all weights and development metrics before held rescoring. Report recipes separately because earlier studies lack first-arrival observations and cannot support a head-to-head first-arrival claim. Single-thread CPU and this previously studied actor corpus define the scope.
