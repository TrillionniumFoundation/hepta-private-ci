# 低精度的真实边界，与定长状态的随机检索上限

在已经证明双稳态的模型中，同一接收端只能读发射单元的真实边界。使用原物理基准 B₀=51.60494826，比较直接存 B，以及先在较高精度内算出 log(B/B₀) 再量化成同一数据类型。这两种等价的实数表示在硬件传输中可以产生不同结果。接收者从实际收到的数重新求整套半轴平衡。

|反馈 ε|两条真实边界|未量化接收率差|传绝对 B 的 BF16 接收率差|传中心 log 比率的 BF16 接收率差|
|---:|---|---:|---:|---:|
|0.001|51.605160 / 51.606418|0.00003073|0|0.00003075|
|0.005|51.606009 / 51.612310|0.00015396|0|0.00015452|
|0.025|51.610256 / 51.642112|0.00077700|0.00609893|0.00077816|

较强反馈时，绝对 BF16 把两条边界恰好送到毗邻量化格，夸大了真实下游差异约 7.85 倍；较弱反馈时则合为一格。FP16 在 ε=.001 也把两条绝对边界合并。中心对数需要在丢弃精度之前算好。使用同一个物理算子、相同存储位数就能实测这种区别。在等先验、独立高斯端口读出噪声的两稳态二分类实验中，最优单次读出的误判率为 Φ(−|Δlog B|/(2σₙ))；各噪声值的数表见 [verified.json](verified.json)。这些是已知两态与指定噪声的结果。

## 有限动态内存在什么任务上必然损失信息

假定独立均匀的 n 个 q 元符号被顺序送入网络，读完之后才公布一个独立、均匀的索引，需要重报该位置的原符号。模型权重在输入前固定，推理者只能使用过往输入留下的 M 比特总状态和给出的索引。令 δ 为平均误报率，则

$$M\ \ge\ n\big[\log_2q-h_2(\delta)-\delta\log_2(q-1)\big].$$

证明：令状态为 S，原符号为 Xᵢ。独立性与条件熵的次可加性给出 I(X;S)≥Σᵢ I(Xᵢ;S)，而 I(X;S)≤M。对每个位置应用 Fano 界并用二元熵的凹性平均，即得所示形式。任意基于最终状态的读出均适用。若允许读取外部缓存、再次访问前缀或传输历史边界，必须把这些可读信息纳入状态预算。

举仓内测到的一档 HCSN 流式状态 5,376 字节为例，**假设在增大上下文时它仍然是全部可访问的动态内存**，均匀 256 元符号要求 99% 准确，n 至多 5,486。n=8,192 时误报率至少 24.38%，n=32,768 时至少 73.15%。这个最坏分布的任务不能用来预测 WikiText-2 困惑度；自然语言的冗余、关注的少数线索、外部检索都会改变信息需求。与注意力相比，固定记忆在推理存储上的优势和精确随机寻址能力的约束是同一件工程决策的两个后果。检索先例见 [Arora 等](https://arxiv.org/abs/2312.04927) 和 [Wen 等](https://arxiv.org/abs/2402.18510)。
