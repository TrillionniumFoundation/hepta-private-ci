# Does a returning-regime price law improve frozen multimodal features?

Reuse the previously studied low-bandwidth CREMA-D export from the existing private GPU study. Four temporal bins each contain four visual and four audio summaries, with the same actor splits (4,984 train, 1,147 development and 1,311 held clips). Predict the original 72 transcript-emotion labels. Here labels index the existing catalog; the candidate text is not encoded, so this is audiovisual closed-set classification. No held scores for this new test have been computed when this protocol is written. Prior tests used the same actors, so there is no external replication claim.

Compare four matched physical feature banks: stationary pricing, irreversible deterioration, repeated transitions, and repeated transitions with the cross-layer wire disconnected. Include a smooth saturating recurrent feature bank, a hard-reset LIF bank and a raw input baseline. Each physical arm uses two frozen layers of 24 scalar units with seed-specific dense input maps. The second layer gets first-layer signed log margins as its only cross-layer input. Both layers start from the low liquidity state for each conditional financial quote. The input determines the diffusion asset coordinate and, where enabled, the conditional low-to-high switching intensity. This experiment evaluates conditional value and risk representations; the output is not a count of repeated spikes. A true repetitive-spike population is implemented independently in the parent project. The smooth and LIF encoders read the same input and transmit one scalar per unit. They retain a scalar state across the four frames. Read all four frames from the last layer. Include a coarse ridge classifier of the 32 raw coordinates as a control.

Training uses independent seeds 137, 311, 557 shared across arms. Direct fitting solves regularized least squares against one-hot labels, with train-only centering and scaling, a 6-value ridge grid and a 5-value positive logit scale grid, selected by development NLL. On the same features compare a multinomial cross-entropy head fitted by L-BFGS, with three regularization strengths and at most 70 iterations. The feature banks remain frozen for both methods. Include an independently optimized class-prior baseline. Record training feature construction (including the switching-law table), fitting, development selection and scoring costs, single-thread CPU. Charge a law table once per independent run per arm even if deterministic and cached across seeds. Predeclare a joint development and held NLL threshold of 4.10. A matched-quality speed statement requires that both alternatives pass for all three seeds; report elapsed complete search cost per seed. A full-encoder BP comparison is available only from the separate parent protocols. Do not compare its wall clock to these frozen-feature runs.

Seal chosen hyperparameters and hashes of weights from all arms and seeds before scoring held actors. Report held NLL and top-1. Primary contrasts are returning minus irreversible, returning minus stationary, returning minus disconnected and returning minus smooth, separately by readout. Compute paired actor-bootstrap intervals conditional on the three trained seeds (4,000 draws); use pooled per-clip denominators. Intervals are descriptive, with unadjusted coverage. Retain model and score identities for independent replay.
