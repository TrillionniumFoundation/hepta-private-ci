# 边界价格能传多少有用的视听信息

复用 7,442 个 CREMA-D 片段，每片保留四个时段各四个图像、四个声音摘要。训练、开发、留出分别有 4,984、1,147、1,311 片，演员不重叠。采用冻结的两层 24 单元特征，分类目标为 72 个固定的台词—情绪组合。上层的唯一输入线是下层的连续安全裕量。特征保存每帧股权、货币信用损失、首达率和裕量。我们在较早实验使用过相同演员；这里的检验适用于这些封存模型和这项任务。

| 冻结特征 | 直接岭写入 NLL | 交叉熵拟合 NLL | 直接写入 Top-1 | 交叉熵 Top-1 |
|---|---:|---:|---:|---:|
| 双向未来状态 | 3.87334 | 3.69451 | 10.04% | 11.34% |
| 单向恶化 | 3.87871 | 3.69219 | 9.81% | 11.29% |
| 固定状态 | 3.87788 | 3.69346 | 9.94% | 11.59% |
| 切断双向模型唯一跨层线 | 4.20563 | 4.20563 | 3.66% | 3.66% |
| 平滑递归 | 3.87468 | 3.67429 | 10.02% | 11.16% |
| 硬阈值复位 LIF | 4.01370 | 3.86612 | 8.85% | 10.27% |
| 原始 32 维输入 | 3.94513 | 3.67152 | 8.85% | 9.92% |

每种模型有三个配对的特征初始化。相对硬阈值复位，双向模型直接写入的演员配对 NLL 差为 −0.14036，95% 区间 [−0.19712,−0.08630]。相对单向恶化为 −0.00537，[−0.01365,+0.00232]。相对平滑递归为 −0.00134，[−0.01742,+0.01488]。断线后所有样本在上层得到同一特征，两个分类头都退回训练类先验。这个对照检验连通性，不能单独说明金融形状比同带宽光滑函数更好。改变未来状态机制对报价有清楚的作用，在本任务上尚无独立可分辨的分类收益。

对双向模型，直接写入和 L-BFGS 交叉熵头都在三个种子的开发与留出集通过 4.10 NLL 门。单线程完整候选搜索、特征、开发和最终计分分摊用时平均为 0.6555 和 5.8508 秒（同一物理表构建时间在每种子、每独立方法各计一次）。这里计的是全部配方成本，首次达到 4.10 的实际时刻没有观测。交叉熵法的最终 NLL 更低；用 4.10 这个共同验收线可以比较完成两种方法的费用。若只要求达到这条线，使用原始输入的直接读出仅需 0.0706 秒，也全部通过。比较仅涉及冻结表示后的分类头，迭代交叉熵采用解析梯度，未对编码层反传。

复核程序重新打开全部 42 个封存权重，沿正常路径逐字节重建全部 3,964,464 个留出分数的 SHA-256。用不同的矩阵乘积与 logaddexp 重新计分，逐片损失最大误差 2.14e−14，独立按演员聚合的配对区间最大误差 1.12e−16。协议在此次留出前已提交。附带训练输入摘要、压缩低带宽输入、模型和逐片结果。运行 `OPENBLAS_NUM_THREADS=1 python verify.py` 即可复核。重新训练时选空目录，先运行 `fit.py fit evidence/all.xz OUTPUT`，固定 seal.json 后运行 `fit.py evaluate evidence/all.xz OUTPUT`。
