# 未来可以反复切换的内生边界

当前经济状态相同，未来从紧张状态恢复的可能性是否会改变现在的价格与边界？本实验在原单向状态模型上引入返回率。在接下来两年内，状态以强度矩阵 Q 在低、高两种溢价间任意次切换。两年终点当前状态变为永久状态，以 He–Xiong 的闭式股权、任意剩余期限债价及首达概率收尾。合约本金与票息保持原值，低、高流动性溢价为 1%、5%。该有限时域和固定未来转移规律属于实验设定。源程序也是一个可重算、可求导的神经元参照算子。

对数资产使用有漂移的三点格，股权在每个监测日有停止权。令 S 表示一拍资产转移、M=exp(Q dt) 表示状态转移、D=exp((Q−diag(q))dt) 表示含流动性贴现的状态转移。状态 i 的继续债价由下一拍已选策略决定，以 D 对各剩余期限债券折现，并支付该拍票息。剩余期限零的存续债按面值成交，停止的债按当时实际资产的回收值成交。当前新债重新定价后进入当拍股权现金流。将该净流、期间资产支付和下一拍折现股权相加，与立即停止价值零取最大。到期债与所有未到期债共同采用该持有人决策。定价与偿付顺序固定之后，逆推在有限格点上给出唯一值；平局选停止。信用损失由相同状态贴现的无违约债价减去有违约的债价。首达端口用同一停止策略和未贴现转移，输出的是所设测度下的概率。

| 两年内的状态规律 | 低、高状态当前壁 | V=90 的两种股权 | V=90 的一年内触界概率 |
|---|---:|---:|---:|
| 两种状态固定 | 67.50，77.54 | 23.37，6.87 | 16.94%，46.75% |
| 低至高强度 0.70，高至低强度 0 | 74.10，77.54 | 11.08，6.87 | 35.64%，46.75% |
| 低至高 0.70，高至低 0.35 | 72.79，74.44 | 13.53，11.04 | 29.69%，34.77% |

上表为每年 384 拍的数值。允许恢复会改变两种状态的现价。静态连续时间基准壁为 67.4415、76.8493，格点监测及资产离散造成可见误差。双向模型中两壁所在格分别为 [71.44,72.90]、[74.40,75.93]。表中较多小数仅用于复算。改变空间截断后探针价格和边界变化小于 2.3e−10；改变时间和空间分辨率的影响明显更大。五档网格结果均在 verified.json 中。

在停止策略保持不变的参数邻域，使用矩阵指数的 Fréchet 导数并沿递推传播，即可求边界插值、股价、信用损失和首达率的一阶导数。改变策略的格点可能让债权人的回收跳变，此时不能声称全局可微。48 拍网格两壁对恶化强度的导数为 9.72383 和 0.74517；完整重新决策的双边差分核对，壁导数最大差 2.68e−9。独立标量递归使用 ODE 定价状态转移及首达时间密度积分，18 个点最大误差为债价 6.83e−13、股权 1.43e−13、风险概率 4.65e−14。该独立检验核查同一离散模型。连续双向自由边界的精确解及一般策略收敛仍属不同的问题。

从此目录运行 `OPENBLAS_NUM_THREADS=1 python verify.py`。依赖 NumPy、SciPy 和同仓闭式终值实现。完整结果含网格区间、端点、数值误差及硬件相关运行时长。
