# 用一套模型生成视频摘要、声音摘要和转录词

对 7,442 个演员说话片段使用三种条件补全。给定声音与原话则生成视觉摘要，给定画面与原话则生成声学摘要，给定声音与画面则逐词生成转录。只从原观察流构造前缀，每个目标由同一模型的共享词表和同一个输出头逐步预测。4,984 / 1,147 / 1,311 个演员互斥片段给出 14,952 / 3,441 / 3,933 个条件序列。视听每路保留 4 段 × 4 个真实特征的 16 级编码；文本为数据集十二句实际剧本的词串。任务可以测试多目标生成与条件依赖，不能评价原始波形、原始像素或开放主题的语言质量。[原始语料说明](https://github.com/CheyneyComputerScience/CREMA-D)

金融解码器的每单位提出真实合约、读取 E、L 和首达概率，前两者构造带方向的恢复/再生力，首达率门控记忆，再由驱动后的真实合约发出连续 log 边界。两个隐层间每个神经元只有该边界读数，没有绕过它的残差。平滑对照复用相同带宽与参数数量；硬 LIF 传二值脉冲并用代理梯度。两种因果 Transformer 都有独立 Q/K/V、输出投影、注意力残差和前馈块。梯度训练采用相同优化器、样本排序、目标和共享词表。

表中每种模型三个种子均由开发集选择 60 墙钟秒端点。HCSN 相较近等参数注意力的三个 NLL 差为 +0.57681、+0.02884、+0.01183。按演员重采样、将三个给定种子视为固定时，逐项区间为 [0.49592,0.66014]、[0.01186,0.04499]、[0.00831,0.01536]。同时重采样配对种子与演员，并对 12 个比较作联合校正后，视觉 NLL 差仍高于零 [0.2772,0.8764]，音频及文本各自的扩展区间包含零。与同宽更大注意力的三项差异在联合校正后均高于零。相对平滑递归的三个 HCSN 差异均在联合校正后包含零。[敏感性分析](sensitivity.json)

HCSN 只训练完整一遍时三项 NLL 为 2.24116、2.23948、2.04154；平滑模型为 2.16698、2.11472、1.36720。首次 60 秒试验中后台竞争导致不同模型实际取得的 CPU 时间不同。为使等样本、等机器时间与等进程算力可区别复核，另行注册并执行 [同核轮转对照](PAIRED.md)，保存每格一遍、五遍、60 墙钟秒、60 进程 CPU 秒的独立冻结端点。原观察不替换。

在 60 秒的开发选定端点，断开 HCSN 层间唯一连接后三项 NLL 变为 4.70348、4.46623、5.40223；训练集目标位置先验分别为 2.62491、2.43391、2.06447。**能生成不等于强依赖另外两种模态。** 打乱两个条件源、保持真实目标前缀时，HCSN 三项 NLL 仅升 0.00461、0.00712、0.00674。相同处理下，同宽注意力分别增加 0.01462、0.16612、0.06957。每词 NLL 使用真前文，自由生成清除真目标，之后只喂自己的 token；表中 12.46% 的整句命中揭示了这一差别。对任意更换目标后缀及截短序列做因果性检查，先前 logits 最大漂移 8.11e−6（含不同长度调用的浮点差异）。
