# Conditioning and leakage checks before opening held outputs

For each development-chosen checkpoint, evaluate the teacher-forced test again with the first, the second, and both conditioning streams permuted across held clips within the same target modality. Fix a random single cycle for each permutation so each conditioning source comes from another held recording. Keep the preceding target tokens, true target, target identifiers, position and scoring mask intact. These are interventions on association in this evaluation distribution. They can create unnatural input pairs. Report individual and joint changes by target; a small or negative change is possible even if the joint model predicts the target well. Also replace all target suffix input tokens from slot j+1 onwards and verify earlier logits remain unaffected. For a true autoregressive free-running score clear all suffix input slots first, grow the target with only its own predictions, and assign misses to absent or wrong-modality outputs.
