# 同核轮转下的三模态生成

同一物理核在每个训练小批次轮换五种模型，每个模型各用三种子。完整一遍的 15 份权重和开发分数逐字节复现先前实验。每格冻结四个端点，三个留出任务均用同一套模型。每种预算下先按演员和配对种子重采样，12 个模型/任务比较联合校正。所有分数为留出 16 位演员的逐真实目标 token NLL，越小越好。视觉和声音输出是各 16 个低带宽量化单元，文本是真实转录词。

| 模型 | 固定五遍，视觉 / 声音 / 词 | 60 进程 CPU 秒，视觉 / 声音 / 词 | 60 CPU 秒自由整句命中 |
|---|---|---|---:|
| HCSN | 1.72172 / 1.89690 / .44619 | 1.61895 / 1.87470 / .40525 | 15.56% |
| 同预算非金融平滑 | 1.76115 / 1.88975 / .43171 | 1.67275 / 1.86912 / .39799 | 15.18% |

固定五遍时每模型每种子看到 74,760 个训练序列。对近等参数注意力，HCSN 三模态 NLL 差的联合 95% 区间依次为 [−.0543,.4672]、[−.0292,.0192]、[.0088,.0472]。固定 60 进程 CPU 秒，三区间为 [.4842,.8489]、[.0161,.0851]、[.0069,.0243]。HCSN 在此预算下自由整句命中点估计较高；该项与真前缀上的逐词 NLL 衡量不同目标。此对照在首轮不等 CPU 配额结果揭盲后注册，独立外部推广仍需依据相应数据。[协议](../PAIRED.md) · [全端点](terminal.json) · [联合区间](sensitivity.json)

独立重放涉及 60 个端点、235,980 个条件样例、3,167,520 个目标 log 概率、3,161,849 个自由决策。FP32 与独立 FP64 在一次分数相差 9.61×10⁻⁷ 的 argmax 选择不同；一处沿用先前研究的一遍硬 LIF 阈值精度事件。逐序列原始打分的最终 NLL 重新汇总误差为零。[重放记录](verified.json) · [199 份原件的归档](archive/manifest.json)
