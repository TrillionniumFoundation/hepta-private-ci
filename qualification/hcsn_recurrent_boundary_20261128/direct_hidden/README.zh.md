# 利用真实边界的逆映射从头写入隐藏层

在完整的 7,442 个低带宽视听片段上，从随机初始化构造 2×32 单元的 HCSN。两层之间只传每个单元的真实 log 自由边界。把已有的 72 个真实台词与情绪标签分别投到两层各自的二值码本，先求希望该单元报出的边界，再用其解析逆推回驱动，用正则最小二乘写入当层的权重和偏置。每层使用两次求解，第二次用当前模型自由运行的历史修正回归目标。原股权的恢复项、信用损失的再生项、首达概率、递归状态保留。测试时只给音频/画面输入。与冻结随机编码器的早期实验不同，两层都由本次训练标签和真实输入确定。

金融和非金融的光滑对照使用相同层间读出形式。直接方案对光滑对照的 NLL 差 −0.02893，16 个演员分组的配对区间 [−0.04387,−0.00999]。加入五次头部更新后相差 −0.06448 [−0.08379,−0.04573]。全参 BP 后金融减光滑则为 +0.01113 [−0.00669,+0.03023]。同一金融结构内，纯直接写入与 BP 相差 +0.69772 [0.55864,0.83010]。码本边界的逐点反演误差仅 5.96e−8，真实训练输入到目标码字的拟合仍有误差；这解释了“能反求一个神经元”与“能用本监督训练网络”之间的一层实际困难。

**在同一质量门槛下测时间。** 同一 CPU 核，3 个配对种子、两次交叉顺序，24 个全新进程，从解释器启动、数据校验、原金融合约查表、根据原输入从头训练、开发选择，一直到 1,311 个留出样本重算及成功退出。每个质量门的两种算法均 6/6 通过。4.10 门槛下，纯直接写入中位 2.196 秒，BP 2.859 秒，六个配对的 BP/直接比在 1.12–1.63，中位 1.293。3.75 门槛下，带头部更新方案为 3.210 秒，BP 3.378 秒，配对比 0.92–1.20，六对中有直接方案更慢的情形。该时间结论只覆盖本机、该门槛和已使用过的演员数据；它不涵盖 3.15 的 BP 最终质量。冷进程均包含相同的终点数据重开和结果核对开销。[cold_timing.json](cold_timing.json)

原始拟合包含 24 个模型/种子配置的 48 个端点，重新载入开发和留出共 8,494,848 个分数。开发原值校验摘要相同；独立 NumPy FP64 按实际价表计算每层时序，最大 logit 差为 0.000120。断开唯一跨层连接后，同一模型的下游对全部样本给出完全相同的向量。训练、冷评分、逐种子结果和配对对照详见 [PROTOCOL.md](PROTOCOL.md)、[COLD_TIMING.md](COLD_TIMING.md)、[panel.json](panel.json)、[terminal.json](terminal.json)。全部原始权重、开发/留出分数和封存文件按段保存，并记录整体及逐项 SHA-256。[archive/manifest.json](archive/manifest.json)
