# 永续双向流动性切换下的自由边界

He–Xiong 固定流动性解给出边界与估值的解析基准。这里允许两种流动性状态按连续时间 Markov 链来回切换，比较相同合约参数下冻结状态、坏状态永久和可恢复三种经济体。两种状态的贴现溢价分别为 0.01 和 0.05；债券期限一年，企业股权永续。切换持续到任意未来。这是原模型的一项数值扩展。

每个状态 i 在对数资产网格上，用共同扩散生成元与两状态跳转生成元联合定价。新券先解有限期限的抛物型边值问题；股权再解含展期净现金流的定常方程。联立两状态的值匹配 Eᵢ(Bᵢ)=0 与光滑粘贴 ∂logV Eᵢ(Bᵢ+)=0 求两条内生边界。当流动性跳转使当前资产已落入新状态停区时，当场吸收，并按跳转时真实资产水平计算回收。首次到达概率和货币违约损失各有独立输出。

|坏状态转换率（正常→紧张，紧张→正常）|正常态边界|紧张态边界|V=90 时的一年首次到达概率（正常 / 紧张）|
|---|---:|---:|---:|
|0，0|67.4400|76.8483|0.17344 / 0.44333|
|0.7，0|75.8301|76.8483|0.41853 / 0.44333|
|0.7，0.35|73.3089|73.8959|0.33086 / 0.34099|

双向切换时，V=90 的股权分别为 11.8940、11.0204。在本参数下，承认坏状态可恢复会降低两个当前状态的一年触界概率，并缩小边界差。前一项 [有限切换期实验](../returning_regimes) 让切换在两年后结束，本项让切换永续，两个问题的数值各自对应不同远期条件。

用 96、192、384、768、1,536 格及对应债券时间步执行自收敛检查。最后两级可恢复边界最大差约 0.00425；保持网格间距再扩大远端，边界移动小于 0.00003。零转换率恢复固定流动性解析阈值，两个状态完全相同时恢复单态解。还校验了续存区域的非负股权、概率范围、有限组停区采样点的继续经营剩余和边界斜率。六个状态与资产的组合，各自独立模拟 300,000 条带连续 Brownian bridge 触界与精确截断击中时间的路径，债券价格和击中率与 PDE 相差最多 2.29 个模拟标准误。以上是数值验证，有限格和有限停区采样不能给出整个参数空间的存在唯一性定理。
