# 双向切换、内生自由边界与两个价格的可微神经算子

在永续的两状态流动性模型中，根据候选的两条壁解出股权及债券价格，再联立两个光滑接触条件解出壁。该构造在空间上直接求分段常系数 ODE，避开人为上端和空间网格。变换域按解析式计算，回到给定期限时用 Euler 加速的数值 Laplace 反演，最后的两维根也用数值法求解。工程实现包含股权 E、货币损失 L=无违约债价−风险债价、首达概率 F、真实边界 B 与反向传播。

对从低壁到高壁的对数距离 h，低于高壁时仅低状态可续存，低态向高态跳转立即吸收；债券回收须按跳转时的 V 计算。高于两壁时，令 Q 为跳转生成元、D=σ²/2、μ=r−δ−D，对贴现率 q，矩阵算子为 M=sI+diag(q)−Q。跨状态衰减模的生成元为

$$K=\frac{-\mu I-\sqrt{\mu^2 I+4DM}}{2D}.$$

在两壁间的标量方程中，常数、资产线性项与两个指数即可满足源项和低端条件。高壁处对持续存活的低状态要求值和导数连续；刚好吸收的高状态则按具体合约兑付。债券初始本金与票息给出常数强迫项。权益转化为第二个定常 resolvent，强迫中包括当前新发债券、展期本金、税后票息与资产现金流。由于债券由上述指数构成，权益亦可逐模解出。最后求两状态各自的右侧权益斜率均为零。F 与 L 使用各自的边界条件。针对本次合约及正双向速率，BP 对内生壁后向求解 2×2 转置线性系统，再把梯度传回转换率和流动性溢价。

|切换率（正常→紧张，紧张→正常）|正常壁|紧张壁|
|---|---:|---:|
|0，0|67.44151539|76.84927461|
|0.7，0|75.83122244|76.84927461|
|0.7，0.35|73.31052537|73.89734219|

可恢复状态、V=90 时的权益为 11.89287 / 11.01912。实际切换风险反向传播到两壁的 Jacobian（行为正常/紧张边界，列为变坏/恢复强度）为 [[3.24226, −5.06427], [2.61966, −5.84937]]。该点的边界光滑接触 Jacobian 条件数 1.385。局部良态且两条壁可排序时，隐函数定理提供真实的后向通路。合并壁、分支切换与接触处的全局光滑性不据此推断。

- 在两个零转换状态和三个固定资产点，权益、债券、首达和两壁对单状态母式的最大绝对差 1.71e−8。
- 双向切换时，对照 [独立 PDE 与路径模拟](../stationary_switching)，1,536 格数值壁与这里的解最大差 0.00160；调节数值反演的项数与路径，壁最多移动 1.01e−7。
- 在包含即时吸收、两壁间、两壁之上的 5 个资产点，独立实现与 Torch 首达及债券的前向差不超过 4.58e−10；对资产、时点、两壁、两转换率、两贴现溢价及噪声的一阶导数与四阶差分最大缩放误差 1.44e−7。
- 将两个壁也纳入计算图，按 3 套合约、含交换状态的壁顺序，比较 E、L、F、B 四项，最大前向差 9.50e−9；沿包含两个金融通道与首达率的复合损失反传 12 个转换率/溢价导数。逐次扰动再独立求整个均衡，最大缩放误差 1.91e−6。

使用情形和依赖可由 [verify.py](verify.py) 与 [verify_endogenous.py](verify_endogenous.py) 复现。下面接口通过普通 PyTorch autograd 求导。当前隐式求壁前向使用 CPU 双精度 NumPy，防止对内部分支求根控制流求导；调用只对两状态的强度和溢价开放梯度，其他经济参数在该接口内固定。仅直接验证一阶反传。

```python
import torch
from torch_equity import EndogenousWalls, equity_and_slopes

torch.set_default_dtype(torch.float64)
j = torch.tensor([0.7, 0.35], requires_grad=True)
premium = torch.tensor([0.01, 0.05], requires_grad=True)
walls = EndogenousWalls.apply(j, premium)
equity, slopes = equity_and_slopes(torch.tensor([90.0]), walls, j, premium)
equity.sum().backward()
```

切换扩散的解析首达已有矩阵 Wiener–Hopf 路线。这里的研究内容是本展期定价、状态别真实吸收壁、双价格与可微神经单元的结合。参见 [Jiang 与 Pistorius](https://arxiv.org/abs/0803.2302) 及 [Hieber](https://www.sciencedirect.com/science/article/abs/pii/S0167715214001941)。原始输出保存在 [verified.json](verified.json) 和 [endogenous_verified.json](endogenous_verified.json)。
