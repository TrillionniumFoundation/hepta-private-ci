## Additional fair-cost clarification

The **common repair solver** is identical across arms. Its base and runtime may be shared only when the dependency is actually the same and actually used. A retrieval-only policy must not be forced to retain or load the 135M memory base, PEFT runtime, or another memory-exclusive dependency simply to make a “common base” line appear in every ledger.

When the memory base is separate from the repair solver, its complete retained weights, runtime requirements, loading/inference work and byte-time are **memory-arm incremental cost**. They cannot be canceled as shared cost. Where true sharing exists, retain evidence of the actual identical dependency and distinguish physical experiment sharing from each standalone deployment closure. Fixed adapter values do not mean equal whole-system parameters, storage or cost.
