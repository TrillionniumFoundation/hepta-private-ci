# V8 闭环研究与原生接入：完成事项、拒绝结论和剩余边界

## 结论

**V8 完整 H8 网格与 remaining-to-terminal32 两项研究均已执行、独立回放并保留完整分母；两项均未通过预先冻结的确认进入规则。没有新的科学合格候选。** 原生 08 格式、报告适配器和 owner/recovery 路径的限定工程资格已经完成，但未发出真实候选的准入签名、安装真实 profile 或激活生产 owner。

这份报告把“完成一个待回答问题”和“候选通过所有门槛”分别列明。研究可以以可复核的拒绝结束；没有以缩小分母、放宽阈值或继续消耗独立样本来把拒绝改成通过。PFT 与 Hepta 的关系及具体研究 comments 见 [配套评论](./CELL_FIELD_V8_RESEARCH_COMMENTS.md)。

## 2. 直到真实终点 32 的第二项研究

为进一步检验预测终点，单独冻结 remaining-to-terminal32 实验。全部 24 warmup 都运行 H1、Loss2 remaining、Full adjoint remaining 和 terminal field8 remaining，共 **96/96 完成 32 步、0 实际异常**。后三者在实际第 k 步使用 `32−k` 的名义零控制尾部、只采用首个安全动作，再重规划；H1 的内部提议目标仍是下一步。共同的是实际终点、逐步提交、动作盒、价格和安全器。[完整终点研究][remaining]

实际执行使用 129 文件闭包。原 127 文件 plain writer 未执行真实 fit；压缩存储修订只新增无损 writer 和测试，原 127 文件及科学规则不变。控制输出先封存，再进行独立回放，最后才读取历史 DEV 评分。[完整终点研究][remaining]

独立回放核验 **3,072 个实际更新**与全部 **3,072 项提议**，另构建 **38,784 个零尾参考更新**和 **36,480 个前向 JVP 步**。Full/field **24/24** 的动作、完整数值状态和旧损失完全相同。首动作响应矩阵最大误差 `3.2526065174565133e-18`；这比只核对保存矩阵的乘法更直接地检查了系数来源。[完整终点研究][remaining]

## 3. 开发进入规则与科学确认不能混用

两项研究的开发进入规则要求：全部实际控制完整执行、Full/field 等价、16 项 future 均值都 `≤−.006`、8 项 old 均值都 `≤−.020`、8 个完整策略 CPU 比都 `≤3`。这些是运行前冻结的开发筛选幅度，不是本轮新得到的置信区间。[网格协议][grid-protocol] [终点进入规则][remaining-entry]

原科学规则保持不变：新的独立来源、12 项 family、Bonferroni 单侧置信上界、future 严格 `<−.001`、old `≤0`，以及完整执行和 `≤3×` 成本。两项开发都没有达到启动新确认的条件，因而没有选择、编码或打开新的确认 cohort，也没有真实科学审阅签名。[完整网格报告][grid] [完整终点研究][remaining]

本轮 old 规划面板上的全部已采用动作满足零松弛阈值；网格最大 old excess 为 `−5.828226790072222e-12`。这证明这些反复查询的经验面板上的执行条件得到满足。历史 DEV old 均值下降、局部安全证明和独立总体保留证书是不同结论。

## 4. 已关闭的机制问题与未得到的主张

共同 J32 实验实际执行 144 条完整轨迹：Full 只改终点且只放开首动作时，相对 H1 单动作在 24/24 上改善；Full 放开前八动作时相对零控制 23/24 改善，Loss2 仅 12/24。对 Loss2 自己选的相同动作，Full 的预测 RMS 为 .000277559，Loss2 为 .00487894。方向、幅度、目标计价和非线性余项分别保留。[共同终点报告][common]

98 个原停止状态诊断中，原单射线单独成功 43 个，joint 单独成功 72 个；其中 joint 独有 55 个，原搜索独有 26 个。固定先 ray 后 joint 的整块选择在这些已执行诊断中覆盖 98/98。搜索预算不同，且旧失败意图没有完整保存，因此这是对相同新提议的比较，不是缺失历史意图的重演，也不是 joint 在所有状态都优于原搜索。[停止状态报告][stop]

八维终点场保留指定名义轨迹中八个终点输出的一阶动作响应；系数仍依赖完整优化器状态与已知训练上下文，每步重新计算并计费。实验证明本局部问题的 Full 等价，不证明自治八维非线性 Markov 状态、免费系数、一般全 LLM 充分性，或真实闭环未来的完美预测。[研究 comments][comments]

## 8. 剩余处置

本候选族在已冻结开发规则下的结果已经确定：**不进入新的确认实验，不晋升真实 native owner**。后续若研究新机制，应重新提出与本次失败相对应的假设、预先固定协议和进入规则；不能继续修改当前门槛后仍沿用本轮确认身份。

科学上的剩余问题是外部效用、保留泛化和可接受实际成本能否同时成立。本轮没有回答“成立”，而是提供完整反例与适用边界。原生工程路径已经具备限定承接能力，仍等待未来科学合格、来源匹配且经过真实审阅的候选。

将含私有组织代码、研究输出和模型参数的证据包保存到 ChatGPT Library，曾被自动审批拒绝；理由是缺少针对这个目的地的明确授权。包、清单和回执准备完成后，需要单独获得该保存动作的批准。此项存储审批不改变上述研究拒绝或原生资格结论。
