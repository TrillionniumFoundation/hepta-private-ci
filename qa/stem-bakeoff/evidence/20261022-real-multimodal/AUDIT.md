# 真实 COCO 图文研究独立审计

结论：原始数据、工件、预测和指标重算通过，`quality_qualified=true` 与预声明研究门槛一致。未发现使该有限研究 screen 失效的实现错误。该结果不支持“门控显著优于线性”，也不支持缺失模态鲁棒性、一般视觉推理或生产可用性。

## 审计范围与方法

只读核查 `/tmp/hepta-coco-research-v1`、`/tmp/hepta-coco-bank-v1`、`/tmp/hepta-coco-cohorts-v1` 和冻结源码。独立脚本未导入实验实现：直接用 NumPy 重算指标/配对组 bootstrap，用 Torch functional 从 6 份 NPZ 权重和原 bank 重算 20 份 ledger。最大 logit 差为 `4.76837158203125e-06`；77 个结果工件及全部源码 pin 一致。未修改实验输出、模型或源码。详细数值在 [audit.json](audit.json)。

## 数据隔离与泄漏边界

384 张真实 COCO-val2017 JPEG 的源字节、解码 RGB、caption 注释均核验。样本确为许可筛选后固定 hash 顺序的前 384 张，各图 caption 也按预定 hash 选取，无模型挑样。train/dev/calibration/test 分别为 128/64/64/128 张图，256/128/128/256 行；每个两图 block 包含 2 正例、2 负例，两个端点均不跨 split。每张图、每条 caption 在本 split 正负各出现一次。

原图、caption、标准化 caption 与精确像素无跨 split 重复；实际最小 dHash 距离为 12，高于预声明阈值 4。图像和文字的 model input 不含标签或 source ID。冻结 Encoder 预先提取 test 特征没有使用 test 标签更新参数。公共 COCO 是否出现在基础模型预训练中、跨照片真实人物/实体是否重合，均未排除；不能把这些局部完整性检查称为第三方盲测证明。

## 为什么 98% 合理，以及它能说明什么

任务是“caption 是否来自该原图”的来源匹配。随机负配通常较容易，且冻结的多模态 embedding 已具备很强的对齐信号。事后只用于解释的原始 cosine 分数，在 test 上 AUROC 为 `0.9964599609375`；正例 cosine 中位数约 `0.82930`，负例约 `0.69255`。这个诊断未用于训练选择或资格判定。因此 98.05% 不异常，但主要说明预训练表示加轻量任务读出能够完成该窄任务。

标签为不同原图来源的 caption，不代表语义必然矛盾；同主题误配尤其可能语义接近。不可把来源配对准确率改写成“语义判断准确率”或“综合视觉理解准确率”。具体误差仍存在：原图 `551304` 显示装饰马桶，模型却以 `0.99999933` 置信度接受“有两个牙刷架的洗手池”这一其他原图 caption；实际查看原图 `386352` 可见持拍网球选手；正、负 caption 分别描述“刚完成击球”和“准备击球”。这里比较的是源 caption 的文字差异，并未从单张图像独立认定击球前后的时间状态。

## 门控与线性：没有显著优势证据

gated 为 251/256，linear 为 250/256；仅一个 block 中的一条样本不同。净增 `0.390625` 个百分点，配对组 bootstrap 下界为 0；唯一 discordant block 的精确单侧符号概率为 0.5（双侧 1.0）。当前证据不能宣称门控显著优于线性，也不能据此判定门控是最优投入。线性 Head 仍基于含乘积、绝对差和 cosine 的人工交互特征，并非原始输入上的线性系统。

gated 校准集 128/128，诚实地按预定网格选中最低温度 0.25；在 test 上 NLL 从未校准的 `0.055821` 恶化为 `0.167118`，而校准后的 linear 为 `0.060530`。gated 的 5 个错误均被接受且置信度至少 0.9568；ECE 较小不等于置信概率能安全外推。不得看过 test 后改温度，再沿用本次资格结论。

## 缺失、打乱与少数类诊断

- 缺任一模态时，gated 接受全部 256 行、全判负：准确率 50%、风险 50%、正例召回 0%。`missing_mask` 被保存，但当前 `predict_task` 不消费它作拒答/路由。该结果满足的是“联合结果依赖两模态”的敏感性检查；缺失模态使用存在实际退化问题，未获得安全回退资格。
- 每个 block 是完整 2×2 配对。交换两个图像后，仍是原来四个输入的置换，来源标签翻转。保留原标签时准确率自然接近 `1 - 原准确率`；重标后恢复原值。已逐行核验该置换。它不是独立鲁棒性实验或新的分布。
- minority 是同一 test 的固定相关子集：32 正例来自 29 个 pair block，加全部 128 负例，总 160 行。模型、温度、阈值和 logits 均未改变。gated 正例召回 32/32、准确率 98.75%、AP 99.9053%。这是描述性诊断，不是独立复现；经验 bootstrap 的 recall 下界等于 1 是零观察错误造成的退化，不能表示真实召回保证 100%。

## 同预算和资源结论的准确含义

同一 mode 的三个模态对照共享冻结 owner、3073 维读出、训练行数、4200 步搜索预算和线程设置；本次均选中 3000 步。gated 实际可训练参数 33,814，linear 6,148，训练参数/计算并不相等。两者都保留完整 52,258 参数容器，因此当前线性内存数字不是去除未用 adapter/action/value/uncertainty 后的最小线性实现。

图像通道含固定中性文本 `Image.`；文字和图像分别一次编码、随后晚期融合，不能称为 caption 与原图联合 token cross-attention 实验。bank 实际使用一个 text+image owner：438,760,448 个已加载参数、1,755,045,092 字节驻留 tensor、0 可训练 Encoder 参数；text/image 各 192 次双样本 forward，bank 2,359,296 字节。模态 Encoder FLOPs、能耗和延迟没有被等同；4096 Head 只做算术外推，没有在本次物理分配或设备验收。action/value/uncertainty 与有状态 policy 均未训练。

## 可发布的结论

固定真实预训练共享 Encoder + 私有轻量任务 Head，已经完成可复跑的真实 COCO 图文来源配对学习、校准、独立分组测试、序列化和资源核算，并通过预声明有限研究 screen。门控相对线性的显著收益、缺失模态鲁棒性、困难语义负例、基础模型预训练去污染、完整有状态策略及目标设备性能仍未被本次实验证明。`authority=DENY_ALL`、`production_activation_allowed=false` 保持成立。
