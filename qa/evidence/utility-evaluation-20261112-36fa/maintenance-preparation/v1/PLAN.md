## Failure and Unknown handling

A command is marked attempted before dispatch. Its original result is retained before postprocessing. If execution or postimage preservation is incomplete, the wrapper reports Unknown and does not start the next stage. A real nonzero fix or fmt remains a recorded command failure. A source/Git-integrity failure is never converted into a successful maintenance result.

Final source/input capture is independent and runs after available failures within its separate record budget. A postprocessing error cannot turn an attempted command into not_run, and a result file alone cannot prove complete durable supervision. Partial output is kept for the original job's reconciliation.
