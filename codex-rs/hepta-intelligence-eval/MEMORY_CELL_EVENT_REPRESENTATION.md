This continuation starts at `c9dd3aeff958fbdc4356a98718e96dec47f9b820`.
It reuses, rather than reclaims, the inherited observed-event corpus, calibrated
persistent hybrid index, event projection, two frozen readers and six controls.
No default production reader, wire version, independent reviewer or authorization
is introduced. No policy or knowledge-module optimizer runs in this stage.

## Correction closure

The old organized selector only inspected direct supersedes edges in retrieved
candidates. In a -> b -> c, a retrieved pair (a, c) could retain a when b was not
retrieved. `event_revision_closure.select_current` consults the complete already
admitted event projection at the declared logical revision. It removes obsolete
candidate facts, including chained ancestors, but never supplies an out-of-pool
successor to the reader. Missing current/conflicting heads cause an incomplete
result; it never releases one side of a conflict merely because the other was
not retrieved. Whole conflict groups either fit the budget or remain unavailable.

Current withdrawal and source/identity validation still use EventProjection.
Full-view event/edge work is counted. Logical revisions are sandbox versions,
not verified calendar time. This is deterministic structured-schema processing,
not arbitrary language understanding. Historical organized controls remain
unchanged. The chain regression establishes the defect and repair mechanically;
it does not by itself establish improved model answers or statistical advantage.

## Isolate input representation from model and memory gains

`event_reader_view` appends a deterministic English schema explanation alongside
EVERY unchanged selected original JSON document. It does not summarize away the
source, add missing facts, select evidence using answers, or repair generated text.
The derived sentences, derivation profile and original source digests are explicit
in the model receipt. Original sources still occupy the prompt. Both raw and
expanded prompts must fit the inherited 2,048-token ceiling. All added tokens are
charged; this is the same ceiling, not a claim of identical actual token/FLOP cost.

Only a controlled compile hook is added to FrozenBundleReader. Its default output
is unchanged and tested for exact equality. The presentation subclass inherits
the same frozen BF16/eager model constructor, original system instruction,
64-token deterministic decoder and final source validation. Query, actual source
selection and model weights are fixed; the input view is the only new intervention.
Qwen2.5-3B remains research-only under the existing staging license restrictions.
The original raw-reader run is not relabelled as new-head model generation.

The new runner consumes the externally pinned original artifact 11669174727 from
run 38051933126. All 8 test cases and 6 conditions (48 answers per reader) remain.
The corpus has 8 separate calibration cases. New facts, explicit corrections,
composition and constrained procedure choices are authored controlled scenarios.
The procedure does really execute a fixed allowed transform, but these are not
production build histories or independent natural-language judgments. The program
support condition is not substituted for the pending human sufficiency reviews.

Raw model responses and exact delivered-source audit requests are synced before
the scorer parses target values. All failures remain and fail execution. Scoring
uses the inherited narrow identifier grammar and actual constrained procedure
verification. It is not semantic citation adjudication; no marker repair occurs.
Empty conditions still invoke the model. The report keeps actual input/read costs,
original extraction/index receipts and unknown production maintenance costs.
Total lifecycle cost remains null when components have not been measured.

## Execution and next-stage boundaries

The read-only workflow runs the repository formatter, all Python regressions and
then the real pretrained models in separate processes. It checks the externally
pinned ZIP, complete inner inventory and exact original plan before consumption.
Formatting diagnostics may produce a patch artifact, never a branch write.
Local mechanism tests use explicit tokenizer/model stand-ins; hosted original
model execution is the only pretrained result. Repetition is not independence.

Any presentation gain must be reported separately from event organization, reader
size/family and learned memory. If sufficient-context reading remains weak, fix
that diagnosed bottleneck rather than train another adapter. Independently reviewed
natural-language capability, beneficial past-only knowledge writing, retention,
real future windows and deployed cutover/recovery still need their actual evidence.
No permission is granted by this guide or by a successful diagnostic run.
