## What was reproduced

Across five source commits, all **40 calibration query×arm inputs** and all **72 evaluation query×arm inputs** had identical candidate-pool identity, ordered delivered source bytes, reader profile, full prompt token digest and input token count. They are the **same 8 questions**, not 40 independent cases. The five Qwen runs show **4 calibration** and **9 evaluation** query×arm entries with any output-token/answer drift; **two** of the 72 evaluation entries have changing *task outcomes* among repeated runs, both confined to the weaker Hybrid k6 or reversed-k4 variants. The fifth run introduced **no newly divergent query×arm output** beyond those already observed in the first four runs. These observations warn against mistaking deterministic decoding for exact answer reproducibility on different CPU hosts.
