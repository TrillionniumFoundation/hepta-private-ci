# Real Git bytes → matched frozen Reader capacity (non-promoting)

## Why this experiment is needed

The earlier 40-calibration/72-evaluation Qwen study only covers eight already exposed authored event tasks. The subsequent 160-call three-cohort result cannot certify sufficient evidence or learned-memory superiority. The newer PR #2067 preregistration and independent scorer pass deterministic fixtures, but until a reader generates new answers their gates demonstrate integrity, not learned ability.

This opt-in research workflow adds **new real pretrained inference on already SHA-frozen public source bytes**, not new historically unseen software projects or authenticated human-review judgments. It is deliberately narrower than real PR bug fixing: a controlled exact function-declaration lookup with a mechanically checked single-line requirement. This is a diagnostic of context use, distraction, copying and citation behavior. No tool execution, source evaluation, software build, LoRA training or production switch is performed.

## Matched controls and measurements

Every frozen model uses the same question wording, delivered evidence bytes, 1,024-input/64-output token ceilings, instruction, deterministic decoding and no tools. The two research-model tiers are the existing exact-publisher-pinned `SmolLM2-135M-Instruct` and `SmolLM2-1.7B-Instruct` `ReferenceReader` paths; model capacity is a **separate diagnostic axis**, never a MemoryCell learning benefit.

| Evidence intervention | Meaning |
| --- | --- |
| `none` | Same question, no evidence. |
| `hybrid_k4` | Label-blind lexical rank over all complete files in that repository before choosing four byte-exact excerpts. |
| `mechanical_support` | The original function declaration with its marker; mechanically source-sufficient *for the narrow lookup only*. |
| `removed_declaration` | The same original source marker but with lines containing the target declaration symbol removed; tests shortcut guessing, not independently proven necessity. |

A new original generation journal records every attempt (including failed calls), unmodified answer bytes, input/output token counts, actual source labels, frozen reader identity/profile and durations. An independent scoring job reopens the original corpus, reconstructs all nine expected file identities, checks all 72 planned answers from two readers/four conditions and counts strict answers and original citation labels separately. Question/corpus mismatch, altered source, missing/duplicate original attempt, invalid reader receipt or unexpected resource budget fails closed. No score is generated by synthetic regression tests or historical replay.

This study may be informative even if the stronger Reader answers all mechanically sufficient cases: it cannot establish human-grounded PR change intent, minimum semantic evidence, real program execution success, new fact/update/composition generalization, learned Cell superiority, source-family independent N≥200, deployed maintenance, revocation, recovery or production TCO. Raw source retention remains a cost; unknown maintenance and revocation are `null`, not zero. `independent_human_sufficiency_review=false`, `learned_memory_gain_established=false`, `production_qualified=false`.

## Original-delivery and CI-head correction (October 15 continuation)

The independent scoring process no longer trusts only a model journal's
self-reported evidence SHA. For every successful original answer it reconstructs
the exact expected Reader-side `EvidenceBundle` (query, source roots, original
bytes, ordered spans, byte offsets, source digests, `[E...]` labels, bundle
seal and delivered excerpts), using the separately reopened original Git ZIP.
A journal with a changed delivered excerpt, span identity or input binding is
rejected. Only the code-path and byte consistency are independently checked;
model tensor bytes and human semantic sufficiency remain outside this scorer's
authority. Input token-ID digests remain self-reported, because the independent
score job deliberately does not load model weights/tokenizers.

The exact-head check in the independent scorer now uses the same PR HEAD
expression as its checkout and reader shards, rather than `github.sha`,
which can refer to the synthetic PR merge commit instead of the original branch.
Mechanical complete-citation success now requires *exactly* the target-source
citation set: citing a correct target plus an unrelated source is not complete
citation fidelity. Three additional mutation regressions exercise these cases.
Verified source-only lexical retrieval already includes the target file in all
nine preregistered cases (9/9); that is **not** evidence of a learned selector
or a new RAG recall improvement. These are research-only source and CI fixes.

## Forward-only versioned lesion correction — v2

The original **v1 plan** is preserved as a retired historical profile at
SHA-256 `005025a81f40759dddd6576c21e3ef10114158e74456600ab5f4b0e39fef164b`. Before qualifying any new model result, source-only
inspection found that its removed-premise arm delivered **one evidence
source and that source's only marker**. Because the question asks for that
marker, deleting the function declaration did not hide the correct marker;
a successful answer would not prove the declaration unnecessary.

The **v2 plan** (`hepta.memory.real-git-reader-function-probe.v2`) uses
`b44eea2857291f3040ac03c14826cfbbfd2a925578c2130f771bbc57eaec3412`. For each of the nine cases the lesion retains the **exact same
2–4 label-blind retrieved source markers, positions and distractors** as
`hybrid_k4`, while removing the queried declaration-bearing lines from
the target source only. Every non-target excerpt remains byte-identical.
This is still a controlled source-first diagnosis, not independent semantic
necessity proof. The v1 SHA is explicitly recorded in v2 plan metadata;
v1 and v2 answer scores must never be pooled or substituted.

For the v2 source-only experiment, all nine lexical retrievals contain the
target source (seven at rank one, two at rank two). That establishes a 9/9
retrieval ceiling on these exposed mechanical lookups; new learned-memory
recall gain is **not** established. Reader/model evidence remains unqualified
until completed source-head inference and independent review receipts exist.
No source has been relabeled or edited; original Git ZIP identities remain
unchanged and production qualification remains false.
