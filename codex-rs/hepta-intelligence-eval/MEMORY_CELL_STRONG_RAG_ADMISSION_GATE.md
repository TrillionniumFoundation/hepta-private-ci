The `reader_admission_gate.py` entrypoint **does not run a model or train a
parameter**. It verifies three externally SHA-pinned GitHub Actions ZIPs, all
**81 inner manifest members**, the original source-plan SHA, generating/auditing
commit identity, complete raw/scored 40+72 question/arm census, original answer
immutability, reader identity, strict success and token sums, selected k,
separate replayed contrasts, the formal-citation summary, and same-input
reproducibility. A missing row, changed source, modified raw answer, duplicate
JSON field or fabricated published success must fail closed. A SHA pin proves
which bytes were audited, not the semantic truth of a citation.

**Graph/organization incremental task successes over full-path = 0/8**.
Incremental complete program-declared citation chains = **0/8**. Extra
organization saves **573 prompt tokens over 8 reads**, or **71.625 tokens per
read** (9.96% of full-path prompt inputs), *without* a demonstrated task or
citation-chain gain. This isolated prompt saving is not yet a lifecycle or
production cost advantage because ingestion, organization, retention, revocation
and recovery measurements are unavailable.

The frozen top-k policy chose k=1, but leave-one-calibration-question-out
reselection chose k=2 once out of eight folds. The corresponding overlapping
LOO held-out results are 3/8 for selected-k versus 4/8 fixed k=4. The original
program-defined support set is not human-certified necessary evidence.

## Hard research disposition

**NO-GO for claims that the complex organizer adds answer accuracy or
parametric-memory capability on these authored development cases.** Do not
train for longer against the same test question population to make it pass.
There is no independent future source family here, no independently certified
semantic entailment or ≥99% citation precision, and no end-to-end operational
cost or rollback record. The gate emits `candidate_accepted=false` and
`production_accepted=false` unconditionally for this exact evidence source.
This refusal does **not** forbid testing future independently precommitted
real-world histories with the same reader and strongest full-path/RAG controls.
It does forbid borrowing this eight-question result as qualification.
