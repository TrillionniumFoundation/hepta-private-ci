# Controlled executable events before new parametric memory

This opt-in experiment reuses the existing PersistentIndex, frozen Encoder,
EvidenceBundle, ReferenceReader and unsigned citation capture. It creates no
production writer, model adoption, future observation or independent reviewer.
The inherited eight-case human-review request and failed capability screens
remain unchanged. This is an additional controlled diagnosis, not their substitute.

## Actual scope and hypotheses

A fixed isolated Python probe produces observations for sixteen authored test
scenarios: eight retrieval-calibration and eight evaluation cases. The evaluation
contains two new-fact, two explicit-correction, two two-hop composition and two
constrained-program-choice cases. The latter really execute a selected sort or
reverse transform and compare the produced result; no generated code or shell is
executed. Correct and incorrect probes precede collection of a successful-mode
fact. Other observed fields originate in authored test configurations, not a
real project history or independent real-world measurement. Logical revisions
are sandbox state versions, not historical valid-times or future calendar dates.

The structured projection is deterministic; it does not claim to extract arbitrary
language. It preserves original source bytes, entity/attribute identity, revisions
and explicit correction edges. Newer timestamps do not by themselves supersede
old events. Conflicting heads remain visible, and a capacity limit cannot choose
only one of them. Relation traversal is confined to the common retrieved pool.
A current withdrawn root invalidates this conservative projection and its index.

All indices build before query payloads are read. Five lexical/dense mixing weights
are calibrated on the separate eight-case calibration set. The shared persistent
BM25+dense index, original data and candidate pool are identical across methods.
This is a tuned baseline on the controlled corpus, not a state-of-the-art natural
language RAG qualification. Every model uses the same original control plan:
empty, hybrid top four, entity/revision filtering, correction-aware relation
completion, program-bound support, and one required source omitted. The last two
are explicit diagnostics using the test-program dependency manifest, NOT
human-certified sufficient/minimal evidence. Omission never changes the gold fact.

Both pinned SmolLM2-1.7B and Qwen2.5-3B research readers reuse the existing BF16,
eager-attention constructor and unchanged 2,048-input/64-output decoder. Model
size/family is a reference axis, never credited as learned memory improvement.
All six conditions invoke the model, including empty evidence. No citation is
inserted or answer text repaired. Qwen remains subject to the existing research-
only use restriction; no weights or generated teacher dataset are released.

## Outcomes and costs

Raw answers are durably written before final expected values are read. Primary
success uses a preregistered narrow output grammar: one original site_/mode_
identifier with optional original source labels. Verbose, conflicting or negated
answers fail this grammar rather than being silently repaired. Procedure answers
also pass through the same fixed probe; success requires the actual transform's
output to match its target. These metrics are intentionally restricted to the
controlled schema. They are not independent semantic language judgments or 99%
citation precision. No general-purpose model competence follows from a pass.

Reports retain all attempts/failures, exact source and model identities, retrieval
calibration, query/read costs, extraction/projection/encoding/index time and
physical retained data bytes. Training is zero because no optimizer runs. Actual
production maintenance, independent retention and distributed recovery costs are
unknown, NOT silently zero. Total lifecycle cost stays null until they are measured.
The current report can support a bounded organization diagnosis, not lifecycle
compression or production superiority. Authored templates are not independent
source groups for confidence claims.

No learned policy or parametric module is trained/adopted by this experiment.
Those phases require genuine useful-reader evidence, authorized independent
training/validation data and a pre-task frozen write path; long-term qualification
still requires real future observations and deployed lifecycle evidence. Missing
human review cannot be replaced with this program's manifest.

**Attribution, not superiority:** Qwen's five additional successes with
program-bound support are reader-family/capacity effects, not parameter-memory
gains. In all eight Qwen hybrid examples, the original scored receipts say that
the required source IDs were covered; nevertheless five answers were wrong.
The organizer selected exactly the same original IDs, in the same order, as the
program-support condition on all eight cases, while hybrid always selected four
documents and organization selected only one or two. The controlled 8/8 versus
3/8 difference therefore cannot be credited to *missing support recall*; it
may be due to distractor filtering, packing or how the fixed reader uses the
evidence. A stronger, independently calibrated top-k hybrid reader baseline is
needed before any claim beyond this authored corpus.

**Necessary-premise gate fails:** In both composition tasks and both procedure
tasks the Qwen reader still succeeded after a purportedly required source was
removed (**4/8** ablation successes). These observations do not prove the
missing source necessary; possible redundant evidence, shortcut decoding and
fixture construction must be investigated. The previous PR comment that
reported **0/8** for this particular Qwen ablation is contradicted by this
exact archived scored file and must not be used as an acceptance claim.

Only two examples of each task kind were tested, all authored rather than
independent real-world histories. There is no validated independence-adjusted
confidence interval, human-signed sufficiency or citation entailment verdict,
qualified prospective task advantage, deployed maintenance/recovery observation
or production admission. The research-only Qwen license and preserved source
storage still apply.
