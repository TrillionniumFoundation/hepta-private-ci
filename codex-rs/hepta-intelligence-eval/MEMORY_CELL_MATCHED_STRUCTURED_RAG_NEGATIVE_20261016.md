## Qualification boundary

This does not establish a universal tie between retrieval schemes: the dataset is only eight exposed development questions with a deterministic *typed* parser. It does not establish learned MemoryCell gain, independent annotation, a stronger neural Reader, a new future-window sample, real coding-agent task success, or production qualification.

**Admission decision:** reject nonparametric task-success gain claims here; do not train a parameter candidate just to beat a weaker neural baseline. Future experiments must share the same decoder and tools as strong Hybrid RAG, use prospectively frozen independent project families, validate real program execution and independent citation correctness, and measure extraction, indexing, storage, inference, maintenance, revocation and recovery including unknown terms.

Auditor and tests are provided as a conversation evidence artifact; the repository holds this compact provenance-bound summary, **not a claim that the external audit source is versioned here**.
