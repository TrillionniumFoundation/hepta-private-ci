# Iteration ingress adapter stage

The registered IterationEnvelopeV1 has fourteen fields. Its existing learning-artifacts Rust type is an authority-free subset: it lacks allowedPaths, deniedAuthorities, wallTimeMicros, computeBudget and mandatoryChecks; its expiry is seconds rather than the registered milliseconds, its maximumDiffBytes differs from maximumBytes, and it represents Git IDs as Digest32. This patch preserves that type and introduces a separate, immutable canonical wire adapter. It never synthesizes missing policy defaults or converts away those fields.

The adapter rejects duplicate/unknown/missing fields, noninteger/overflowing numbers, unknown compute profiles, unsupported paths and duplicate policy entries. It retains all policy bytes under lexical compact JSON and a SHA-256 pin. Array order remains significant. The nested compute profile is explicit in PROTOCOL_SCHEMAS.json. A frozen Python JSON/hash vector provides an independent oracle.

Generator authentication uses the existing LearningEvidenceVerifierV1, including its host-owned signer mapping, scope, objective, authority epoch, expiry and revocation semantics. The new payload is domain-separated from existing signatures: ASCII `hepta.agentd.iteration-envelope.v1`, NUL, then canonical envelope bytes. Existing SignedLearningEvidenceV1 encoding is unchanged. Verification also requires a separately supplied exact host policy digest and the envelope's millisecond deadline. The policy pin must be loaded from trusted owner configuration; accepting a pin from the same remote request would authenticate only a caller assertion.

This is an additive codec/authentication unit. A valid Generator signature proves a submission, not path permission, sandbox enforcement, evaluator independence, candidate selection, production installation or release. No live iteration starts here. The non-test control.engineering caller, trusted envelope configuration binding, bounded request conversion, current final-use revalidation and dispatch into the retained plasticity owner remain the next integration stage. Existing proposal G/O/E checks and rollback-domain commit remain mandatory.

Independent review found that Serde-derived structs also accept positional arrays. Object-only map visitors now reject both top-level and nested array forms while retaining duplicate-field rejection; both array regressions failed before the fix. The hosted architecture workflow requires all nine focused tests in the actual Agentd library before broader owner gates. The small local harness qualifies the exact source/dependencies, not the full Agentd graph.

Clock profile: this Agentd submission uses Unix milliseconds for current time, principal authentication/expiry, evidence issuance/expiry/revocation and envelope expiry. Existing plasticity_runtime.rs installs authbus_ingress::now_ms, keeps last_observed_unix_ms and forwards that clock to propose_agentd_plasticity_with_clock_v1 and LearningEvidenceVerifierV1. The generic verifier does not declare its own unit. Other contexts must not pass seconds-based evidence into this profile or rescale signed fields. A realistic epoch fixture verifies millisecond evidence and rejects an otherwise valid signature whose evidence timestamps were encoded as seconds.
