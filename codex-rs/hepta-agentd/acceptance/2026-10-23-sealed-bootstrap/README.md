# Root public bootstrap sealed descriptor producer

The original frozen source passed 48 scoped tests without retry, the real
Root sealed-descriptor custody test, and both Root/UID60001 SSD five-lane
component compositions. The positive service test took 4.62s, with its actual
writer-proof read at 28ms and feed read at 11ms. The expired-consumer negative
retained its original deadline and refused acknowledgement. Scoped fix and
default plus explicit committed-range formatter/check passed; no semantic
test followed that finish phase. Original WIP bytes, final mechanical source,
retained qualified test binary hash and all command outputs are separate records.

The producer returns a descriptor only after bounded serialization, root PID
validation, complete write, mode 0400, all four irreversible seals, exact
descriptor metadata and full retained-byte readback. The real Root test proved
that write, shrink, grow and adding seals failed with EPERM and retained bytes
were unchanged. Non-root creation and over-bound appends were also refused.

The service fixture reads these actual sealed bytes before controlled stdin
transport. This does not qualify production SCM_RIGHTS transfer, the desktop
loader, Asterinas custody, a trusted fresh store/Current initializer, actual
Notes/HOS2 effects, full Prepare/Commit image publication or crash recovery.
The fresh SSD fixture is not installed production authority. Private keys,
private persistent state and raw private syscall traces are excluded.
