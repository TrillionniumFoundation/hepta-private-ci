## Method

`system2_reader_tag_label_audit.py` reopens the *externally pinned* original ZIP, rechecks all internal SHA256 manifests, the exact generating commit/tree and Git blob for the producer, pinned Qwen model/revision, the twenty fixed source question IDs, nine planned slots each, and all 180 start journals and raw answers. It verifies the immutable original raw pre-scoring SHA256 and independently reruns the producer's deterministic **synthetic** grading function, asserting exact equality of the historical post-seal summary.

It also reconstructs the real `EvidenceBundle` for every completed prediction and checks exact source-original excerpt bytes, delivered labels, bundle seal, question/model IDs, trainable-parameter count, output-postprocessing status, input/output token fingerprints and observed CPU/wall time. No answer labels or gold targets enter a new prompt: **there are no new prompts**. Recorded label fields are either present or stripped from otherwise identical rendered user evidence, but the prompt token lengths can differ.

The readout includes, separately for every condition and label profile:
- strict exact output of the expected `TAG-xxxxxxx` token;
- appropriate abstention, over-abstention, unsupported TAG copying and `E1/E2`-only echo;
- actual input/output token totals and decoder CPU nanoseconds;
- each 20-question paired 2x2 table: both correct, labeled-only correct, unlabeled-only correct, neither correct, plus actual per-question prompt-token gap.

We do **not** merge refusal into answer yield, impute unavailable attempts, compare unrelated question contexts as independent subjects, equate changed prompt-token lengths to compute-matched causality, or claim human semantic judgment. Lexical-family transformations, the grammar oracle and the shared synthetic facts are explicitly not naturally sampled language tasks.
