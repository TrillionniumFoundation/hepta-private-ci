## What changed mathematically

The primary 78-parameter Stem uses six layer/regime matrices plus a shared
4->4->2 tanh network. Its output is smoothly bounded to [-2.5,2.5], and directly
changes the next internal representation. Thus the learned feedback evolution
is nonlinear. The primitive plant remains known and affine; it is NOT an unknown
world-model dynamics learner. The target contains a nondiagonal transform,
a cross-coordinate product and a sine component; three fixed readouts evaluate
that shared target. These are not three independent semantic domains.

The terminal task cost has quadratic AND quartic errors. Conditional continuation
uses an entropic recursive aggregator (eta=.4, gamma=.93). The 32 initial
state/regime cases and 256 leaves are fully enumerated. No second-moment closure
or Riccati label can solve this objective as written. Known observed Markov
preferences are a restricted NDU profile, not learned endogenous preference or
a general continuous-time FBSDE/viscosity theorem.

C computes explicit population costates and their parameter derivatives, then
uses trust-exact steps accepted against the original scalar objective. Ordinary
AD trust-exact, AD L-BFGS, gradient-root and Adam are retained. Explicit adjoints
and AD compute the SAME derivative/objective, checked against each other and
finite differences. Risk-tilted reach probabilities must appear in recursive
credit; replacing them with physical transition probabilities is incorrect here.
No fitted arm uses an optimal-action label or reference optimizer.

## Independent optimality brackets, not solver-status assertions

For each fixed initial case the adapted-action tree has 14 variables (30 at
horizon four). Affine state evolution, convex quadratic/quartic costs and monotone
convex log-sum-exp recursion make the BOX-CONSTRAINED ACTION problem convex.
The shared neural parameter problem remains nonconvex and more restricted.

The NumPy reference independently evaluates objective, gradient and Hessian in
action coordinates. Only the canonical problem coefficients/target definition
are shared; no Torch differentiation, neural forward implementation or costate
solver is used for this reference. For any feasible v, gradient g and box U,

    F(v)-g dot v-U*||g||_1 <= optimal action-tree cost <= F(v).

This follows by minimizing the supporting hyperplane over the box. It remains
a real-arithmetic bound without assuming convergence of the reference optimizer.
The reported bounds use ordinary FP64, NOT outward-rounded interval arithmetic.
The maximum per-case width over 200 independently solved reference cases is
1.18557995e-7. Reference computation used 21,813 objective/derivative evaluations;
all work is paid and recorded. The richer adapted-action optimum does not prove
the 78-weight family can attain it. D is recomputed for changed problems and is
not a frozen learned competitor.

All 280 saved panels were replayed exactly. Separate NumPy evaluation of actual
candidate actions for both initial regimes of the first state in every panel
agrees to 9.99e-16. This is 560 independent implementation cross-checks, not full
independent re-evaluation of every leaf or new empirical task data.

## Root solving and transfer: contrary evidence retained

The nonlinear gradient-root control has the lowest new-state regret in this
particular comparison, but has substantially HIGHER training cost and negative
Hessian minima (-.01677, -.02024, -.00804). True gradient infinity norms remain
3.27e-5, 7.28e-5 and 4.34e-7. These are budget-exhausted, non-optimal candidates,
not certified solutions to the training optimization problem. Good performance
on this one transfer law does not validate selecting a saddle as a general rule.

The six-scalar root terminates with true gradient about 3.52e-13 but Hessian
minimum -.0738851, a numerical near-stationary negative-curvature point, not a
local minimum. Explicit C's own gradients also remain around 3.25e-5 to 1.11e-4
with slightly negative curvature at the cap. No C global/local optimum claim.

## What knowing the full distribution means here

The ENTIRE finite corner training population is known. The new continuous-valued
initial cases are a DIFFERENT population. This experiment does not refute the
claim that solving the true common target-population problem can be useful.
It refutes treating more accurate optimization on these corners as an automatic
guarantee between them, even with a known generator and a valid adjoint.

An illustrative nonidentification construction in a larger continuous policy
class adds epsilon*(x1^2-.64)*v to the pre-squash policy. This changes no training
trajectory because every training x1 is +/- .8 and x stays fixed, but it can
change interior-state behavior. The tanh keeps action feasibility. This is a
logical illustration for a broader function class, NOT a representation theorem
or lower bound for the exact 78-parameter family used in the primary experiment.

A substantive next experiment should fix a continuous parent state distribution,
use nested deterministic integration with measured integration error for ALL
methods, retain the same-family AD-trust/root/L-BFGS controls, and freeze new
validation probes before testing coverage or regularization. That experiment
has NOT been executed here. No favorable post-hoc refit is substituted for R5.
