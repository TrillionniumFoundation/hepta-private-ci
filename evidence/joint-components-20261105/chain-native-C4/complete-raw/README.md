# Complete original C4 raw evidence

Three lossless archives retain the original native preparation/checks/four-kernel, legal/reused/from-zero strategy, and two-target Sparse records. Native samples and original readers were not rerun to create these exports. Their independently verified raw inventories contain 91, 136 and 36 original files respectively; the export index in each archive is additional. Actual empty outputs remain empty, and actual retained native ELF bytes are included.

`C4-native-receipts.tar.xz` is stored whole. For the strategy and Sparse archives, concatenate only the ordered relative paths in `C4-strategy-delivery.json` and `C4-synthetic-delivery.json`. Verify every part's offset, length and SHA-256, then the total archive length and hash, before inspecting or extracting. The original remote part manifest and complete export indexes are retained separately. Root's three archive reviews compare every tar member with the original index and independently hash every expanded file and ELF.

The strategy transfer also retains all 495 response metadata records, original response byte lengths/hashes and the exact payload archive. Root compared each actual saved response with its archive slice. `reconstruct_strategy_responses.py NEW_DIRECTORY` reproduces every original response byte-for-byte, including the actual one or two trailing line feeds, and checks every original response hash. This is deduplicated lossless storage of the transport records, not a new network observation. Absolute desktop/workspace paths in the records are historical provenance, not required live paths. The one actual admission refusal is retained separately; only the never-submitted offset was retried, and transfer concurrency was reduced from eight to four.

The independent cost reports explain the denominators, producer reuse, failed attempts, clocks and correlated inputs. Availability of complete raw records does not turn the finite measurements into a universal work lower bound or qualify the original hosted public-service gate.
