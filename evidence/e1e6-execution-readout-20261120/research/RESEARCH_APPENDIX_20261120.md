# 研究附录：从用户轨迹到 Cell 协作与共同学生

**性质：有原始来源支持的研究附录，不构成新增实验结果。** 本文核对五项论文及已留存的 HIA/Circuit 源码，不报告新模型调用、训练、native 执行或资格通过。候选设计不修改 E1–E6 的身份、来源顺序、预算、原始结果与准入条件。出处、检索 ref、局限和本地字节身份见 [SOURCES.json](SOURCES.json)。E6 正在推进的实际状态由主执行报告维护，本附录不提前更新。

## 1. 愿景有可研究的实现路线，但三次跨越需要分别证明

可行的设计起点是：把获准使用的可见用户任务、教师动作、工具输入输出和实际结果绑定成训练材料；以共同学生及私人适配器承接学习，用公共专长 Cell 提供受预算约束的协作；再检验协作能力能否进入共同学生的参数。此处是架构推断。更多用户可能带来更多不同任务和算力，也可能增加重复数据、相互矛盾的监督、排队和验证成本，不能直接推出能力增长。

| 跨越 | 尚需取得的决定性证据 | 原实验对应 |
| --- | --- | --- |
| 观察教师轨迹 → 学生会独立完成任务 | 学生真实执行后，在其自己访问的状态取得获准的纠正；在预先冻结、未用于调参的任务上，优于相同信息及成本的旧学生/检索对照，并保留旧能力。只拟合教师日志不能覆盖全部学生错误状态。 | E1 学习增益；E2 真实反馈的额外作用 |
| 多个 Cell → 有效 Neural Circuit | 教师确有互补；现实路由达到可执行增益；在同预算强单模型多次调用对照下仍有优势；删边、置乱消息、取消学习能分别识别连接、信息和学习的作用。 | E3 互补与负迁移；E4 路由、消息和对照 |
| 协作系统 → 新共同学生/基础模型 | 共同学生真实更新且推理使用了更新；离开原教师服务仍保有跨任务增益；新任务与新来源持续改善，旧能力不明显退化，成本和数据污染受控。任务路由图本身不证明这些条件。 | E1/E2 参数与效果；E5 两条增长曲线；E6 安全采用与真实后续使用 |

DAgger 的核心是迭代收集当前策略访问的状态，再取得专家动作并聚合训练；其理论有专家反馈和学习假设，并非现代 AI agent 的无条件保证。[P1] 因而，“用户同时使用其他 agent”可以提供材料入口；只记录可见的获准动作和结果，不假定能够取得教师的私有推理。额外学生试做、纠正、隐私处理和验证都有成本，必须进入同一实验账本。

## 2. 高效 Circuit 应共同优化效用、保留能力与物理成本

**以下是待独立冻结的设计建议，不是原实验新增预算。** 一个任务先调用少量有专长的 Cell，只有预先定义的条件满足时才扩展；固定总调用、消息字节、队列等待、墙钟时间及验证开销，并保留拒绝和回退路径。稀疏图的选择要同时依据增量效用、旧能力保留、消息/延迟/验证成本，不能只按边少或吞吐高排序。

Switch 在一个共同训练模型内部实现可学习的单专家路由和容量控制；它提供稀疏计算的机制参考，不能把其 TPU 内部 token 通信结果直接移植成跨互联网 Cell RPC 的性能结论。[P2] 对 Hepta 更合适的起始假设是任务或子任务级稀疏路由。路由器、消息编码器与共同学生应分别记录参数变化和独立效果，避免把固定编排误计成路由学习。

每条消息至少绑定任务/运行身份、发送者模型与适配器版本、可见输入承诺、消息内容、消费步骤及实际执行回执。绑定可以证明“谁在何任务中发出、被谁消费”，内容是否有帮助仍需实验验证。语义对照应包含同样格式/长度的无关或置乱消息，以及删边后将省下预算交给强单模型的对照；保留真实零消息/拒绝情况。仅观察两个节点都成功，无法归因给这条边。

同基座节点也须锁定 revision、层、张量形状、编码及量化约定后，才能研究局部潜表示通信；不同基座优先使用可验证的类型化动作、证据和结果。潜表示对齐与消息学习都须实际训练和消融。广域网优先交换粗粒度轨迹、兼容适配器/更新或批量证据，不先假定每个 token 都跨主机交换隐藏状态。

DiLoCo 的外层更新来自同一模型参数空间的副本，局部多步后再聚合；论文自身指出规模、工作节点假设和计算/数据效率限制。[P3] 因此它支持研究“减少同步频率”，不证明任意基座可以直接平均，也不解决私有联邦更新的真实性、恶意更新或隐私泄漏。来自私人节点的更新仍需来源授权、版本和作用域绑定、独立验证及回滚；签名或哈希只能绑定字节，不能把更新变成可信增益。

## 3. HIA 有用之处是受控执行，不是自动产生智能

审计快照中的 [HIA bridge 原文](references/hia_bridge.md) 实现单次 Cell 调用的 native continuation：管理调用、结果、取消请求及未知状态恢复；非空 continuation 不再次派发 `INVOKE_CELL`，恢复不会隐式重放。运行时仍须先持久化 pending/请求身份，再通过原获准入口执行；取消请求也要等待实际结果。文档明确不自行授予执行、模型采用或写权限，不单独保证外部效果 exactly-once。

[Circuit 源码](references/cross_neural_circuit.rs) 提供有界、可版本化的候选图，绑定路由策略、参数和资源配置摘要，并编译到既有 TaskFlow owner。后继候选绑定前驱，不能自行扩大 capability；编译回执的 `authority_granted` 为 `false`。节点/边上限是结构约束，不是效用或性能证明。

因此，HIA 可成为学习系统的受限执行接口，Circuit 可以承载经独立评价的路由候选；学习机制产生候选、原 authority 决定是否采用、原 owner 执行和恢复，应保持责任分离。现有两份源码没有证明图拓扑会因用户增加而自行学成，也没有证明统一基础模型已经形成。这是对上述具体快照的判断，不宣称它们逐字代表所有后续分支。

## 4. 多教师融合必须最终落到真实学生学习

FuseLLM 把异构教师的输出分布经过 token 对齐和融合，用于共同目标模型的继续训练；论文验证了特定模型和任务，未保证保留每个教师的全部能力。[P4] 如果接入对象只暴露最终文本或动作，不能声称复现了完整分布蒸馏。可研究的替代是带来源和验证结果的行为监督，但须重新明确可观察信息、监督目标、相同总预算和负迁移测量。

初期可保留共同骨干、私人适配器和公共专长 Cell 的组合；不同用户的私有数据不应仅因参与协议就成为公共训练材料。是否公开轨迹、共享更新或蒸馏到共同学生，应由实际授权范围决定。教师之间错误相关、某教师能力无法由可见轨迹辨识、学生容量不足，都可能限制融合。真正“综合长处”的证据，应是预声明能力集合中的可实现改善及旧能力保留，而非教师数量、模型文件数量或事后 oracle union。

## 5. PoUW 应把计算事实、增量效用和采用权限分开记账

Proof-of-Learning 研究用训练轨迹/检查点验证优化过程；同篇官方实现以检查点间隔和抽查预算执行验证，报告的实现范围包括 CIFAR-10/100。[P5] 本附录未做该证明方案的安全性复核，不能把它当成 Hepta 的无信任安全证明。即使某次训练被证明真实发生，也尚未证明模型变好、样本独特、贡献者身份独立或具备结算权限。

一个可研究的贡献量是：在预先冻结的独立任务集和相同总预算下，加入贡献后的质量，相对无此贡献且可合理重分配资源的对照提高多少。对单个 Cell、消息、数据批次和共同更新分别做有限的因果对照；合作贡献可能相互依赖，不能假定逐项增益可以相加。报告不确定性、回归、重复内容和失败成本，并将生成、训练、消息、验证、等待及采用费用分别记账；父/子嵌套墙钟不可直接相加。

这仍不是可直接结算的公式。独立评测难以保持秘密、重复贡献与合谋、奖励对测试集的适应，以及私有更新无法完全重放，都是尚需明确威胁模型和真实拒绝控制的问题。E6 的权限/当前状态/恢复/后续使用证据与 Chain 的原窗口和结算门不能由学习分数替代；完整成本缺失时，不能宣称单位收益或经济闭环成立。
