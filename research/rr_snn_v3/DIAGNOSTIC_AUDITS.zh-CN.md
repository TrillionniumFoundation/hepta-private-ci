# 冻结候选的补充审计：优化已收敛，但当前诊断不能充当效用任务

本补充保留原来的权重、训练协议、留出结果与自由生成负面结果。
它增加两个确定性审计，不训练新候选，不选择新的统计接受阈值，也不声称完成 R4。

## 1. 少发放不能合理归因于 Adam 未收敛

重新生成的路径仅来自原训练种子 10000–10127，两个神经元分别有 1142 和 1203 条分段统计记录。
在参考 V8 执行中，归档权重下重新计算的完整训练梯度与原结果逐元素一致。
独立 Node 复跑的两个梯度最大差分别为 9.99e-15 和 4.88e-15，保留在真实回执中；不宣称跨运行环境逐位相同。

每个神经元的固定目标为
F(theta) = lambda/2 * ||theta||² + sum(E_r exp(f_r·theta) - N_r f_r·theta)，lambda=0.01。
曝光时间 E_r 非负，所以 Hessian = lambda I + sum(E_r exp(f_r·theta) f_r f_r^T) >= lambda I。
声明的 -40 <= f_r·theta <= 40 是线性闭带的交集，仍是凸域。
因此对该域的唯一最优解，有 F(theta)-F* <= ||gradient F(theta)||²/(2 lambda)。

| 最终梯度二范数 | 3.6517214877e-5 | 6.5143460276e-6 |
| 总训练目标与最优值的差距上界 | 6.6675349120e-8 | 2.1218352084e-9 |

正则项按每个参数向量施加一次。优化器对梯度统一除以记录数没有改变最小点。
固定上跳通道的常数也不影响这个结论。界使用 Float64 梯度计算，没有定向舍入的区间认证。
参数界不是脉冲数、路径分布或效用的误差界。

所以不应通过改成 Newton、继续 Adam 或复用已打开的生成样本来追求“通过”。
原独立生成结果仍是 fitted-minus-teacher = -0.1240234375 pulses/episode，
条件于该拟合模型的区间为 [-0.1533203125,-0.09375]，没有生成等效性通过结论。

## 2. 当前诊断的自然代理评分存在沉默策略退化

当前事件诊断没有给普通随机脉冲分配未来查询或传递有价值信息的任务收益。
本节审计的是由已有继续值和账本拼出的描述性评分：

U = 0.2 * 终端总预算 + 1.2 * 保留数 + 已输出奖励 - 续约损失。

这不是事先注册的 R4 主指标。它只能用于检查“直接拿当前代理值做任务评分”是否有效。

期限处，每续约一个义务的增量为 1.2 - 0.2*1 - 0.15 = 0.85。
输出还要支付额外输出费和物理脉冲费，总计 2，最高输出价值只有 0.4。
把一个可行输出替换为续约会释放一个预算单位，并提高目标至少 0.85。
因此期限决策从不选择输出，并按预算尽量续约。
审计覆盖预算 0–8、证据 0/1、同时到期数 1/2、已保留数 0–2，共 108 个组合。

对每个神经元，记普通脉冲数 p、保留数 r、实际补充 a、实际冲击扣款 z，
公布的冲击额度 s 属于 {0,2}。固定诊断有初始预算 6、两个义务、补充额度 1。
实际计分等于

U = 0.2*(6+a-z-p-r) + 1.05*r。

零普通脉冲控制可全部保留，并达到 U0=3.1-0.2*s。
任意路径与它的差为

U0-U = 0.2*((1-a)+(z+p-s)) + 0.85*(2-r)。

其中 a<=1、r<=2，且 z+p>=s。最后一条不能忽略冲击的预算截断：
冲击前预算为 6-p_pre-r_pre；当总 p<=2 时预算至少 2，s=2 会足额扣款；
当 p>=3 时，仅 p 就超过 s。进一步，只要 p>=1，就有 z+p>=s+1。
所以零普通脉冲控制逐路径占优，任何含普通脉冲的路径至少损失 0.2。
补充上限只可能使 a 更小，不能逆转这个结论。

等价的整数缩放为 20*(U0-U)=4*((1-a)+(z+p-s))+17*(2-r)，避免把小数舍入当作证明。
该命题只覆盖固定诊断中完整、未中止的轨迹；工作上限触发或非法参数拒绝不是取得效用的路径。
108 项枚举包含少量不可同时出现的保留/到期组合，构成无害的检查超集；路径证明仍使用真实 r<=2。

## 3. 对验收的明确影响

- 优化收敛疑问已在固定目标内解决；生成偏差继续保留。
- 当前代理评分不适合作为有用信息的终端效用。用它比较大量模型会奖励沉默。
- 新版本的强基线公平效用实验仍未完成。该缺口不是执行器故障造成的：
  hosted Node 能运行合适的合成比较，但必须实际实现并冻结价值、未来查询与脉冲传递的共同语义。
- 旧 V2 的价值任务及负面结果保持原样；本审计没有把它们重命名为 v3 的公平比较。
- 真实 Hepta owner、dot、未来窗口与真实 64/256/1024/4096 Cell 回执仍缺失。
- 已通过的研究专项验证与继承的整仓 CI 失败分别记录。没有开放 legacy authority 写入口来消除编译失败。

总状态继续为 allBlockersClosed=false、heptaQualified=false、activationAllowed=false。
这是对限定诊断的证明，不是一般 RR-SNN 不可能有用或所有相关模型必然失败的证明。
