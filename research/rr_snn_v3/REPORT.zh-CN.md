# RR-SNN v3：本轮实现、实验结果与未通过的验收项

## 结论

本轮已经把研究原型推进到实际脉冲、资源与期限事件、可训练循环网络、完整状态恢复，以及真实 Linux 进程崩溃恢复。最终 Node 执行的 11 个入口全部成功，19 份可执行源码与运行收据一致。

总体科研与 Hepta 验收仍未通过。新的固定模型虽然改善了留出路径似然，但独立生成轨迹的发放数量低于合成真模型；新版本还没有完成同规格终效用架构比较，也没有真实 Hepta owner、独立真实未来窗口或真实 Cell 规模的资源收据。验收账本明确保留 allBlockersClosed=false、heptaQualified=false、activationAllowed=false。

[最终 Node 执行](https://github.com/TrillionniumFoundation/hepta-private-ci/actions/runs/40870313419)对应源码提交 13712a4a024a85f60dde6eb9a55877d34f186e03。环境为 GitHub 托管 Linux x64、Node v22.23.4。本报告中的实际进程结果来自该运行；它不能代表 dot 目标机的性能。

## 1. 从 He 与 Xiong 模型迁移了什么

[He 与 Xiong 的原论文](https://www.princeton.edu/~wxiong/papers/rollover.pdf)把债务到期时的续借损失纳入继续经营价值，从而使停止边界内生变化。对神经模型有价值的结构是：当前状态之外，未来承诺、到期时间和续存成本一起决定继续保留信息是否值得。

本轮的有限模型使用贴现续值算子 C(g)=exp(-rho*dt)*exp(Q*dt)*g。在已公告期限，模型共同枚举续约、释放和输出动作，先执行共享预算与状态转移，再计算后续价值。未来损失位于其发生时点，尚未观察的未来费用使用公开先验；没有把未来真实结果当成当前输入。

另一个模块实现常系数、固定吸收边界的 Brownian 首达与存活核。输入切换时，仍未发放者的端点必须按 killed density / survival 传播。这里的首达密度、存活概率和吸收转移公式是已有数学结果，见 [Molini 等人的原始论文](https://arxiv.org/abs/1009.0557)。逆 CDF 和积分是数值求值，适用条件与数值域写在 [BROWNIAN.md](BROWNIAN.md)。

实际训练的循环网络采用有限状态 marked jump 模型、真实发放和显式不应期。它使用一个声明的、参数独立的期限续值代理。该实现不等于已经求解任意 Brownian 移动自由边界，也不构成架构新颖性证明。

## 3. “状态相同、期限结构不同”的反事实已经运行

固定相同随机种子 9010，两个场景的初始证据、每单元预算 6、每单元记忆数量 2、平均期限 2、trace 和发放次数完全一致。A 的期限为 [1,3]，B 为 [2,2]。完整期限列表对模型及消融均可见；均值消融在内部压缩这些观测。

| 实现 | A 的首单元初始发放强度 | B 的首单元初始发放强度 | A 首次实际脉冲 | B 首次实际脉冲 |
| --- | ---: | ---: | ---: | ---: |
| 完整期限特征 | 1.5228521518 | 1.5118592612 | 0.8487132599 | 0.8541612847 |
| 均值期限消融 | 1.5118592612 | 1.5118592612 | 0.8541612847 | 0.8541612847 |

两者在第一个期限之前就产生了不同的实际发放时刻。这个开发实例证明实现能够根据期限结构提前调整；它没有证明这种调整提高了信息价值，也没有证明同样获得完整期限观测的其他模型无法做到。

另一个有界数学实例还保持期限数量、均值、最小值、最大值和总费用一致：分散期限 [0.2,0.4,1.6,1.8] 与聚集期限 [0.2,1,1,1.8]。在明确声明的两种固定强度与控制成本下，两者优选动作不同。快控制成本经过刻意构造，故该实例只用于证明期限分布包含决策信息。[完整数值](evidence/term_structure_counterfactual.json)保留这一范围限制。

## 4. 梯度、删失与训练结果

### 4.1 有限 CTMC 参数恢复

协议先于数据生成提交。固定 512 条训练路径、400 次梯度更新，以及另一个随机流的 2048 条留出路径。生成 rates 为 [1.2,0.65]；学得 [1.215819105861122,0.6557116693442029]，与独立 count/exposure 解析 MLE 的最大相对差为 1.45e-11。

| 留出指标 | 拟合模型 | 生成真参数 | 故意漏掉最终删失的错误估计 |
| --- | ---: | ---: | ---: |
| 完整路径 NLL / path | 1.423737 | 1.423545 | 1.785417 |
| 首次事件 Brier | 0.169307 | 0.169189 | 0.204032 |

错误估计是回归反例，不是强架构基线。两状态解析金标准、三状态独立有限差分和续值联合导数均有单独误差记录，见 [梯度报告](GRADIENTS.md)。

### 4.2 两神经元循环网络的固定训练

最终代码与协议冻结提交为 16ecf52b7faaa43e9ab0612cc22b5dd35345f063，先于第一次训练和留出数据生成。模型有两个物理神经元、0.1 与 0.15 的正突触延迟，每单元学习五个 pulse-rate 权重，共 10 个参数。实际内部跳跃、发放、预算和不应期均完整观察。

训练固定为 128 条完整网络路径、300 次 Adam 更新；随后首次生成 128 条独立留出路径。没有按留出结果选择检查点或架构。路径似然保留所有 eligible exposure 和最后未发放区间；报告绝对 NLL 时加回固定 up 通道的项，留出似然不包含 L2 正则化。

| 留出完整双神经元路径 NLL / episode | 数值 |
| --- | ---: |
| 零权重初始化 | 3.569095 |
| 固定训练后的模型 | 3.006773 |
| 已知生成真参数 | 2.974467 |
| 拟合减初始化的配对差 | -0.562322 |
| 预定 95% bootstrap 区间 | [-0.765525, -0.357431] |

重采样单位是整条双神经元 episode，并保持四个期限/冲击分层。区间条件于这一次拟合，不包含重新训练的变异。数个系数与真参数仍有明显差别；上述结果不能用于声称每个参数都已正确恢复。

内生的延迟输入由已发生的源脉冲确定。在完整联合路径似然中不重复给投递事件增加随机 likelihood。若将来只能观察输出脉冲、看不到普通内部跳跃，则需要新的潜在状态推断方法。

## 5. 独立生成诊断发现了需要保留的偏差

生成诊断的脚本与协议先在 c391e8b7d8ceada0765b6b9d454d2736b98e04dc 冻结，再生成种子 60000..61023。真参数与已冻结拟合模型各运行 1024 条完整轨迹，共 2048 条。四层各 256 对，同一对使用相同种子，但各自按实际事件路径消费随机流。

全部路径满足预算非负、费用守恒、状态有限及事件/队列上限。每单元初始预算 6、最多增加 1、每次物理脉冲至少扣 1，因此在本固定窗口每单元最多发放 7 次、全网络最多 14 次。这是有限窗口的结构界。

| 整网络指标 | 真参数模型均值 | 拟合模型均值 | 拟合减真参数 | 逐指标 95% 区间 |
| --- | ---: | ---: | ---: | --- |
| 物理脉冲数 | 6.489258 | 6.365234 | -0.124023 | [-0.153320, -0.093750] |
| 零脉冲指示 | 0 | 0 | 0 | [0,0] |
| 终点预算总量 | 1.740234 | 1.855469 | 0.115234 | [0.086914,0.143555] |
| retained 义务数量 | 3.778320 | 3.788086 | 0.009766 | [0,0.020508] |

本次固定拟合模型在四个分层中均产生更少的脉冲。剩余预算更高与活动减少相伴，不能据此认定任务效用提高。retained 数量没有信息价值权重，也不能代替未来效用。

两套模型都没有观察到零脉冲轨迹，经验 bootstrap 因而退化为 [0,0]；这不能证明真实零事件概率或概率差精确为零。协议没有预设等价界，本轮没有给出“校准通过”的结论。

[诊断报告](NETWORK_CALIBRATION.md)、[完整分层指标](network_calibration_results.json)和四份配对轨迹审计文件保留全部结果。Node 与先前 V8 执行的完整原始结果规范摘要均为 29bc1011586538c94466f4932c46ef51f7a2024711d6d9f6ddf9c41b8dd07040；复现不增加统计样本数。

## 6. 修复的实际实现问题

- Brownian 近边界生存概率发生相消：x=1e-16 的一个实例相对误差约 -24.55%。修复后，两处 log difference 要求 gap>1e-6；不可分辨的极窄正态区间及反射项下溢也明确拒绝。此门槛是保守数值域保护，非所有参数的误差定理。
- 幸存神经元的端点传播保留 killed-law 条件化；没有用无条件高斯替代。
- 明确区分真实自脉冲计数与不变的有限 evidence index。仅有状态生成元会丢失 self-spike 信息。
- 不应期继续推进期限、输入和资源时钟；每次物理发放都支付正 pulseDebit，期限输出的额外结算成本另行扣除。
- RNG 初始种子加入版本化混合，修复相邻种子首次随机数的强关联；保留确定性回归向量。
- 数值 rate 相同的不同输入仍保留各自 feature regime，避免训练时丢掉不同的梯度特征。
- JSON 对象键顺序不再导致合法 checkpoint 被误拒；数组和物理值仍逐项检查。
- 绝对完整路径 NLL 加回固定 up 通道，保留最终删失；检查目标或梯度累计溢出。
- 恢复绑定完整动态状态与历史，能够拒绝重新计算摘要后的未来输入、残余危险率和特征零空间篡改；修复序号上限及合法 maxRecords+1 regimes 边界。

这些问题均已进入对应回归或执行证据。独立数学审查针对函数体；完整文件的字节身份另由实际 Node 收据核对。

## 7. 真实恢复证据及其范围

在循环网络 t=1.9 的 checkpoint 中，每个单元各有一个来自真实源脉冲的待投递输入。恢复保留这些动态队列、特征历史、全局时钟和每个单元的物理随机状态。7 个保存点的完整 snapshot、statistics、records 与 pulses 均与不中断运行一致。

单神经元与循环网络分别执行四个实际故障点：追加之前、部分尾记录、完整追加之后但 witness 之前、witness 推进之后但发布之前。独立 Node 子进程被 SIGKILL 后从真实文件重启；每次最终状态一致，精确重试追加数量为零。过期头、排他锁冲突、完整记录损坏和已确认历史回滚按预期类别拒绝。

[单神经元实际结果](evidence/fs_single_neuron_results_40870313419.json)与[网络实际结果](evidence/fs_network_results_40870313419.json)保留环境及源码身份。网络 profile 为可靠核对历史而从初态重放，代价明确，尚未优化为可扩展生产恢复；监督式进程崩溃测试也不等于断电持久性或任意多写者证明。

较广义的 Brownian 循环网络和一般内生移动边界属于尚未完成的范围扩展；当前结论限定在本文声明的有限 marked 模型与标量 Brownian 原语。

## 补充审计：优化收敛与诊断目标退化

[完整补充及证明](DIAGNOSTIC_AUDITS.zh-CN.md)确认：原固定训练目标已经近乎最优，其两个参数向量的目标差距上界分别为 6.67e-8 和 2.12e-9；没有重训或改变原生成结果。

另一个更根本的结论是，若直接采用当前“剩余预算＋保留数”的代理评分，普通脉冲只有成本，没有有价值信息的任务收益。108 个期限决策组合、4 个实际零脉冲网络运行及路径级代数证明共同确认：在这个限定诊断中，零普通脉冲控制占优。这说明该诊断不能直接承担 R4 的效用比较；它不意味着一般 RR-SNN 不可能有用。新版本强基线价值任务仍未实现，不能把这一缺口归因于执行环境。总验收保持不通过。
