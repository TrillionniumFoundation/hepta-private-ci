### Findings, counterfactuals and corrections

| Finding | Confirmed consequence | Correction and coverage |
|---|---|---|
| Host configuration/feed validation reopens the path and reads without a hard cap | The checked file identity, private mode and size need not describe the bytes later read. A hardlink input is accepted by the original helper. | Retain one descriptor, use an actual bounded read and compare descriptor/path identity before and after reading. Unix rejects symlinks, hardlinks, foreign ownership, nonprivate mode and nonregular inputs. Tests cover replacement at both open/read cuts, growth, same-length rewrite, exact bounds and atomic replacement between reads. |
| The external trust snapshot can block on a FIFO | The original read-only open waits for a writer before validating file type; the bounded regression times out. | Add `NONBLOCK` to the existing no-follow descriptor open and retain all ownership/type checks. The same regression returns a rejection promptly. |
| Fleet uses caller time after the authority owner sampled a different time | With owner time 20,000, a caller time of 2,000 issues an allocation expired at 9,000 on a host expired at 10,000. Future caller time can also distort committed capacity. | Remove caller time from the Fleet authority port. Its existing one-shot dispatch carries the coherent, final owner-lock-scoped interval. Host/allocation validity must contain that interval; prior allocations retain capacity until definitely expired. Tests cover the final sample advancing after binding, interval expiry, capacity and changed host generation. |
| Bootstrap chmod follows a substituted directory path before admission rejects it | The original preparation changes an unrelated symlink target from 0755 to 0700, even though the real FinalUse owner later rejects the link. | Remove redundant Agentd path creation/chmod. The existing FinalUse private-leaf constructor owns creation and descriptor validation. The target-preservation test checks permissions, sentinel bytes and directory contents; the counterfactual old prelude fails it. The registered parent remains trusted. |
| Expired Fleet renewal resurrects capacity already reassigned | Renewing an expired allocation after another allocation consumes its capacity succeeds in the original code. | Require the current allocation to remain live before renewal. Tests at, before and after expiry prove rejection and complete state preservation where required. |
| Generation overflow occurs after mutation | At `u64::MAX`, failed renewal changes expiry and failed revocation changes revoked state. | Compute the next generation before obtaining the mutable record. Both overflow regressions compare the complete host and allocation maps before and after the error. |
