Audit date: 2026-10-01 (Asia/Shanghai). Starting source: `997e7beef8151160065df36b024bc8da5c989e93`. Scope: Browser owner, persistence/recovery, private worker and Agentd handoff, current-pin Servo embedder source, documentation and CI selection. This record reports source inspection and actual local verification; it does not issue activation, operator acceptance, promotion or release.

## Placement and completion boundary

`browser.servo` is the checked, isolated, stateful adapter in `LANE-B-RUNTIME`. It owns `browser_profile_state` and browser effect identities. `kernel.authority` owns grants/revocation and live final-use authority; `runtime.agentd` owns the product caller. Page/model content proposes actions and never grants authority. Browser must preserve indeterminate external effects across transport loss and restart without redispatch.

The module has detailed technical documentation: `TECHNICAL.md` covers ownership, contracts, state transitions, durability, failures, security, bounds, operation and completion; `SERVO_WORKER.md` covers concrete protocols, Linux isolation, current-pin worker and evidence gates; the implementation map and dossier bind the public owner operations to source/tests. At the audit baseline, these documents disagreed about current worker/caller source and Linux root mounts. The audit updates those descriptions while preserving the distinction between source presence and successful native/target execution.

## Baseline verification

The initial Browser Node suite reported **87 tests: 59 passed, 28 failed**. Part of the failure set came from fixture workers retaining the removed Node 24 `--experimental-default-type` option; other failures concerned durable replay/operation state and transport semantics. This is an observed failing baseline, not a successful completion receipt. The revised Node suite passes **139 tests**; its scope and the remaining native/target limits are recorded below.

Deterministic Node workers test transport/owner semantics. They do not compile or execute the Servo embedder. `real-worker-smoke.js` only starts and stops the selected worker inside Bubblewrap; boot and private protocol success alone do not prove page navigation, DOM effects, remote business outcomes or cross-profile storage isolation.

## Durable recovery and performance

The journal cache is guarded by local filesystem `dev`, `ino`, `size`, `mtimeNs` and `ctimeNs`; external mutation/replacement forces full strict replay. This optimization assumes reliable coherent local-file metadata and qualified fsync semantics. It does not certify a network filesystem or allow a checksum-invalid/torn tail to be repaired automatically.

An uncertain write/fsync or crashed journal owner preserves `<journal>.writer-lock`. The owner must confirm the previous writer has stopped, inspect and reconcile the durable prefix and unresolved operation identities, establish and sync the reviewed journal state, then explicitly remove the retained lock. No stale timeout/PID heuristic steals it. No repair may delete an unresolved effect identity or authorize redispatch. The tradeoff is deliberate recovery unavailability until owner disposition rather than falsely blessing page-cache bytes after a failed sync.

Local journal-scale probe results, on this execution host rather than a qualified product target:

| Probe                         | Baseline                                | Revised |
| ----------------------------- | --------------------------------------- | ------- |
| 512 operations, total         | 5.48 s                                  | 1.11 s  |
| 512 operations, p95           | 24.05 ms                                | 5.66 ms |
| 2048 operations, total        | Not measured in the baseline comparison | 3.99 s  |
| 2048 operations, p95          | Not measured in the baseline comparison | 6.18 ms |
| Identical retry append growth | Redundant append risk existed           | 0 bytes |

The improvement removes repeated full-file replay on an unchanged admitted file and avoids redundant records. File/directory sync, lock exclusion, tamper validation and no-redispatch semantics remain in the measured source path. These small local measurements are not production throughput or crash-durability receipts.

## Remaining real-worker and activation work

1. Obtain a successful native build of the existing Servo embedder against `servo/servo@84bcc9ac701874fa9819e5cdee06356b961d736c` and a reviewed committed dependency lock. Verify the selected feature graph and embedding API; preserve compiler/toolchain, patch/source, reproducibility, dynamic-library and SBOM identities.
2. Exercise real navigation and DOM effects with a qualified delivery path. Top-level navigation-origin admission is not a complete network policy, and the current Bubblewrap namespace intentionally prevents direct external web access.
3. Prove operation-specific remote terminality and reconciliation across late callbacks, competing navigation, worker crash, host restart, acknowledgement loss and lost process-local state. Durable host identities prohibit redispatch; they do not manufacture missing remote terminal evidence.
4. Prove real cookie/cache/storage and credential isolation across principals/profile generations, stale element/document behavior, listener absence, descendant cleanup and filesystem exposure on the selected host/kernel/Bubblewrap/worker tuple.
5. Compose persistent product sessions and a trusted live authority/revocation owner. The private service and named one-shot caller are useful source components but do not establish an activated browser daemon.
6. Connect credential/file/download capabilities only through dedicated bounded brokers and observers. Keep raw secret bytes out of Browser JSON, journal entries, logs and receipts.
7. Provide and qualify equivalent macOS/Windows isolation if those systems are product targets. A Linux result cannot certify another platform.
8. Measure real worker RSS, renderer descendants, descriptors, page/DOM observation costs, queue depth, reconciliation latency and resource exhaustion. The dossier's 16-tab pilot remains a target; the current worker source creates one WebView.
9. Obtain independent operator acceptance and separately authorized promotion/release. Local audit, fixtures, CI definitions and author statements do not issue those decisions.
10. Package and bind an immutable Node service/runtime closure. `service_sha256` currently covers the Node entrypoint file only, excluding imported JavaScript modules, Node, Bubblewrap and other runtime bytes. Persistent caller composition, brokers and closure binding remain source work, not merely missing external approval.
