## Evidence rule

A source reference shows where a check is implemented. A passing claim must identify the exact commit, tree, toolchain, original command and execution artifact. Record initial failures and any original-profile retries separately. Cancelled, skipped, stale or unrelated runs do not qualify the candidate. A JSON self digest provides consistency, not independent authentication or an immutable storage guarantee.
