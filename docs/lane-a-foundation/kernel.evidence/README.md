# kernel.evidence documentation index

This directory is the authoritative engineering entry point for `kernel.evidence`.
Specifications are reviewed prose; current readiness is generated and must never
be inferred from historical qualification archives.

## Read in this order

1. [ARCHITECTURE.md](ARCHITECTURE.md) — components, ownership, transactions and frontier state machine.
2. [STORE_V1.md](STORE_V1.md) — SQLite records, append, query, integrity and repair storage contract.
3. [RECOVERY_FRONTIER_V1.md](RECOVERY_FRONTIER_V1.md) — retained legacy/local frontier format and recovery boundary.
4. [SECURITY_MODEL.md](SECURITY_MODEL.md) — integrity, authenticated truth and independent rollback domains.
5. [INTEGRATION_GUIDE.md](INTEGRATION_GUIDE.md) — typed library and Agentd composition.
6. [OPERATIONS_RUNBOOK.md](OPERATIONS_RUNBOOK.md) — startup, publication, recovery and incident procedures.
7. [COMPATIBILITY.md](COMPATIBILITY.md) — schema, API and on-disk compatibility.
8. [READINESS_MANIFEST.md](READINESS_MANIFEST.md) — exact-candidate identity, retained-log byte audit and post-merge requalification.
9. [generated/CURRENT_STATUS.md](generated/CURRENT_STATUS.md) — generated checked-in source status.

The exact tested candidate is represented only by the runtime
`READINESS_MANIFEST.json` artifact generated by
`.github/workflows/kernel-evidence-readiness.yml`. It binds the source head,
base, deterministic merge, GitHub synthetic merge, workflow object, runner,
target triple, lockfile, tests, migrations, implementation map, documentation
and retained artifacts. Its final receipt audit reopens the retained log bytes;
receipt-declared digests alone are not trusted. A post-merge run must bind the
real merge SHA; PR-head receipts do not transfer.

## Authority boundary

Repository source and CI may prove implementation and execution. They cannot
self-issue independent acceptance, external monotonic-anchor deployment,
operator activation, canary acceptance, promotion or release approval. Those
states remain false until their distinct retained authority receipts exist.
